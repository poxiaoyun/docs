## 概述

BOSS 侧边栏中的「系统模板」对应控制台的**产品模板（product）**功能，入口为 Rune 智算管理下的 `/rune/products`。产品模板是向 Rune 用户提供的可部署条目：每个产品带有 `id`、名称、业务域（`domain`）、分类（`category`）和描述，并可关联版本信息。

控制台路由：

| 目的 | 路由 |
|------|------|
| 产品列表 | `/rune/products` |
| 创建产品 | `/rune/products?action=create` |
| 编辑产品 | `/rune/products/:product?action=edit` |
| 产品介绍 | `/rune/products/:product/introduction` |
| 版本列表 | `/rune/products/:product/version` |

> ⚠️ 注意: 本页描述的是**产品模板**。Rune 集群里的私有镜像、系统镜像市场与内置系统镜像属于另外的功能，见 [私有镜像](/boss/rune-admin/templates)、[系统镜像市场](/boss/rune-admin/system-market) 与 [内置系统镜像](/boss/rune-admin/systems)。

## 字段说明

产品表单字段与校验见 `src/pages/boss/rune/products/components/form.tsx:58-64`。

| 字段 | 字段名 | 控件 | 必填 | 说明 |
|------|--------|------|------|------|
| **ID** | `id` | 文本 | ✅ | 产品唯一标识；**编辑时禁用**，创建后可改 |
| **名称** | `name` | 文本 | ✅ | 产品显示名称 |
| **业务域** | `domain` | 下拉选择 | ✅ | 取值 `user` / `system` |
| **分类** | `category` | 下拉选择 | ✅ | 选项随 `domain` 变化，见下节；未选 `domain` 时禁用 |
| **描述** | `description` | 多行文本（4 行） | — | 产品描述 |

创建时，若用户尚未手动改过名称，`id` 的变化会自动同步到 `name`（`form.tsx:115-136`）；一旦手动编辑 `name` 即停止同步。

### 业务域与分类

`domain` 与 `category` 的映射定义在 `src/pages/boss/rune/products/components/filter.tsx:24-29`：

| `domain` | 可选 `category` |
|----------|-----------------|
| `user` | `inference`、`tune`、`im`、`experiment`、`evaluation`、`app` |
| `system` | `system`、`storage` |

选择 `domain` 后 `category` 才可编辑；切换 `domain` 时，若当前 `category` 不属于新域的可选集合，会被自动清空。

### 头像

编辑已存在的产品时会显示头像上传控件（上传 + 裁剪，单文件上限 3MB，见 `form.tsx:183-213`），创建表单不渲染该控件。

## 创建与编辑

1. 在产品列表点击**新建产品**。
2. 填写 `id`、`name`、`domain`、`category`、`description`。
3. 点击**确认**提交。
4. 如需调整，进入编辑页修改（此时 `id` 锁定）。

> 💡 提示: 分类是产品自身的属性，用于列表归类与筛选；它不等同于「镜像/运行时配置的 Schema 校验」。产品表单只做必填校验，不包含 `enum` / `pattern` 之类的参数校验。

## 列表筛选与排序

产品列表的筛选栏见 `filter.tsx`，提供：

| 控件 | 说明 |
|------|------|
| **业务域按钮** | 按 `domain` 过滤，可点击取消 |
| **分类按钮** | 按 `category` 过滤，选项随所选 `domain` 收敛 |
| **搜索框** | 关键词搜索 |
| **时间排序** | 排序值 `creationTimestamp-` |
| **推荐排序** | 排序值 `recommendation-` |
| **显示未发布** | 开关，用于包含未发布（`published = false`）的产品 |
| **刷新** | 手动刷新列表 |

## 版本

产品支持版本维度：在 `/rune/products/:product/version` 可查看版本列表（`TemplateVersionListView`）。产品对象上的 `published`、`versions`、`chart` 等字段见 `src/types/template`。

> ⚠️ 注意: 控制台中没有「提交审核 / 灰度发布 / 版本冻结为 Deprecated」这类审批流程，也没有 Git Webhook 自动发布；产品表单不读取或校验 Helm `schema`。这些能力在前端源码中不存在，本页不再描述。

## 常见问题

### 产品模板和私有镜像有什么区别？

产品模板（本页）是 `/rune/products` 下的可部署产品条目，关注业务域与分类；私有镜像、系统镜像市场、内置系统镜像属于 Rune 集群侧资源，入口见概述中的链接。

### 能否只显示已发布的产品？

可以，列表默认过滤未发布产品；需要查看全部时打开「显示未发布」开关。
