## Overview

The "System Templates" entry in the BOSS sidebar maps to the console's **product template** feature under Rune Admin at `/rune/products`. A product template is a deployable entry offered to Rune users: each product has an `id`, name, business domain (`domain`), category (`category`), and description, and can carry version information.

Console routes:

| Purpose | Route |
|---------|-------|
| Product list | `/rune/products` |
| Create product | `/rune/products?action=create` |
| Edit product | `/rune/products/:product?action=edit` |
| Product introduction | `/rune/products/:product/introduction` |
| Version list | `/rune/products/:product/version` |

> ⚠️ Note: This page describes **product templates**. Private images, the system image market, and built-in system images in Rune clusters are separate features — see [Private Images](/boss/rune-admin/templates), [System Image Market](/boss/rune-admin/system-market), and [Built-in System Images](/boss/rune-admin/systems).

## Fields

Field definitions and validation: `src/pages/boss/rune/products/components/form.tsx:58-64`.

| Field | Name | Control | Required | Description |
|-------|------|---------|----------|-------------|
| **ID** | `id` | Text | ✅ | Unique identifier; **disabled when editing**, editable on create |
| **Name** | `name` | Text | ✅ | Display name |
| **Domain** | `domain` | Select | ✅ | `user` / `system` |
| **Category** | `category` | Select | ✅ | Options depend on `domain` (below); disabled until `domain` is chosen |
| **Description** | `description` | Textarea (4 rows) | — | Product description |

On create, if the user has not manually edited the name, changes to `id` are auto-synced to `name` (`form.tsx:115-136`); once `name` is edited manually the sync stops.

### Domain and Category

The `domain` → `category` mapping is defined in `src/pages/boss/rune/products/components/filter.tsx:24-29`:

| `domain` | Available `category` |
|----------|----------------------|
| `user` | `inference`, `tune`, `im`, `experiment`, `evaluation`, `app` |
| `system` | `system`, `storage` |

`category` becomes editable only after choosing a `domain`; switching `domain` clears the current `category` if it is not valid for the new domain.

### Avatar

Editing an existing product shows an avatar upload control (upload + crop, single file up to 3MB, `form.tsx:183-213`); the create form does not render it.

## Create and Edit

1. Click **Create Product** on the product list.
2. Fill in `id`, `name`, `domain`, `category`, `description`.
3. Click **Confirm** to submit.
4. To adjust later, open the edit page (where `id` is locked).

> 💡 Tip: Category is a product attribute used for grouping and filtering; it is not the same as "Schema validation of image/runtime configuration". The product form only enforces required fields and does no `enum` / `pattern` parameter validation.

## List Filtering and Sorting

The product filter bar (`filter.tsx`) provides:

| Control | Description |
|---------|-------------|
| **Domain buttons** | Filter by `domain`; click again to clear |
| **Category buttons** | Filter by `category`; options narrow to the selected `domain` |
| **Search box** | Keyword search |
| **Time sort** | Sort value `creationTimestamp-` |
| **Recommendation sort** | Sort value `recommendation-` |
| **Show unpublished** | Toggle to include products with `published = false` |
| **Refresh** | Manually refresh the list |

## Versions

Products have a version dimension: `/rune/products/:product/version` shows the version list (`TemplateVersionListView`). See `src/types/template` for `published`, `versions`, `chart`, and related fields.

> ⚠️ Note: The console has no approval / gradual rollout / "freeze version as Deprecated" workflow, and no Git Webhook auto-publish; the product form neither reads nor validates a Helm `schema`. These capabilities do not exist in the frontend source and are no longer described here.

## FAQ

### How do product templates differ from private images?

Product templates (this page) are deployable product entries under `/rune/products`, organized by domain and category; private images, the system image market, and built-in system images are Rune cluster-side resources — see the links in the Overview.

### Can I show only published products?

The list filters out unpublished products by default; turn on **Show unpublished** to see all.
