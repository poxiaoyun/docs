# 价格

**价格** 页回答一个具体问题：**我这个账户，调这个模型，每 100 万 Token 花多少钱。**

页面顶上那行说明写得很直白——「展示当前账户在运营平台关联的费率方案中的模型价格。」所以这里看到的是**你的专属价**，不是一张公开的通用价目表：同一个模型，不同账户看到的数字可能不一样。

:::tip 打个比方
像员工内购价目表：标价签是平台统一印的，但你手里那张表上印的是「你这个部门谈下来的价」。**价格** 页就是你自己那张表。
:::

![价格页：顶部说明「展示当前账户在运营平台关联的费率方案中的模型价格」，表格按模型名列出输入价 / 输出价 / 缓存读取价 / 缓存写入价 / 按次价](/assets/screenshots/airouter/prices-01.png)

## 开始之前

- 已登录账号即可，不需要额外角色。
- 账户需要已经在运营平台关联了**费率方案**。没有关联时，页面会显示「当前账户还没有关联费率方案。」，需要联系管理员处理。
- 这里只**看**价格，不能改。价格由管理员在运营平台配置，用户侧没有编辑入口。

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 费率方案 | 管理员给账户挂上的一套模型价目表，里面逐条写着「哪个模型、什么价」 |
| 专属费率 | 绑在具体 API 密钥（令牌）上的价，只有用那把密钥调用才生效，优先于其他层级 |
| 套餐费率 | 买了套餐之后随订阅生效的价 |
| 账户费率 | 直接挂在你这一个账户上的价 |
| 租户默认 | 你们整个租户共用的默认价 |
| 平台默认 | 全平台兜底的默认价 |
| 缺省统一价 | 上面几条都没命中时，所有模型统一按这一个价计费 |
| 按次价 | 不按 Token 计费的模型（如图片、语音）按「调一次多少钱」计价 |

## 价格表怎么看

页面就是一张表，一行一个模型。左侧五列是模型信息，右侧五列是价格：

| 列 | 含义 |
| --- | --- |
| **模型名** | 模型 ID。左边还有图标，方便扫读 |
| **上下文** | 这个模型一次能记住多少内容，显示成 `32K`、`128K`、`1M` 这样的形式；没配则显示 `-` |
| **能力** | 模型的类别标签，例如 **视觉**、**推理**、**Coder**；没配则显示 `-` |
| **类型** | **对话**、**生图**、**视频**、**语音**、**嵌入**、**重排序**；没配则显示 `-` |
| **参数规模** | 模型参数量，单位 `B`（十亿），超过 1000 显示成 `T`；没配则显示 `-` |
| **输入价** | 你发给模型的内容（提问和上下文）按这个价计费。单位：**元 / 百万 Token** |
| **输出价** | 模型生成出来的内容按这个价计费。单位：**元 / 百万 Token** |
| **缓存读取价** | 命中缓存、直接复用已有上下文时的价格。单位：**元 / 百万 Token** |
| **缓存写入价** | 把上下文写入缓存时的价格。单位：**元 / 百万 Token** |
| **按次价** | 按次计费的模型用这个价。单位：**元 / 次** |

:::info 单位别读错
五个价格列的单位写在列标题下面：前四个是「**元 / 百万 Token**」，最后一个是「**元 / 次**」。也就是说输入价 `2` 表示**每 100 万 Token 收 2 元**，不是每条消息 2 元。
:::

### 三种价格状态

价格单元格有且只有三种样子，颜色就代表状态：

| 样子 | 含义 | 你该怎么理解 |
| --- | --- | --- |
| 绿底、带数字 | **已定价** | 就是这个模型当前的单价，直接按它算 |
| 黄底、写 **统一价** | 这个模型自己没有单独定价，落到缺省统一价 | 实际按页面里 **缺省统一价** 那一行的数算 |
| 灰标签 **未定价** | 这一项没有价格 | 不能用于计费场景；找管理员补价 |

### 同一模型为什么有多行

如果一个模型下有多条价格（通常是不同渠道各有各的价），模型名右侧会出现 **更多价格** 按钮：

1. 点 **更多价格**，模型下面展开若干 **渠道** 行，每行标题形如「**渠道（渠道名）**」。
2. 其中**优先级最高**的那一行会带一个黑底 **默认价** 标签——不指定渠道调用时，就按它算。
3. 再点 **收起** 把这些行折叠回去。

:::tip 为什么会有多渠道价
同一个模型可能接了多个来源，来源的成本不一样，价格自然也不一样。默认价就是「你不指名道姓时走的那条路」的价格。
:::

### 缺省统一价那一行

表里有一行模型名写作 **缺省统一价**（内部对应的是「所有模型」这个通配条目）。它旁边有一个信息图标，鼠标悬停会提示「未设置价格的模型按照统一价计费。」

有这一行时，说明账户已经配了一个兜底价：**没有单独定价的模型都按它算**。没有这一行时，未单独定价的模型就是真的未定价。

## 我的实际价格由谁决定

一次调用到底按哪个价扣钱，是按下面的顺序从上往下找，**找到第一条就用它**，不再往下看：

| 顺序 | 计价层级 | 通俗解释 |
| --- | --- | --- |
| 1 | **专属费率** | 这次调用用的密钥有专属费率，就用它 |
| 2 | **套餐费率** | 你的订阅带了费率，用套餐内的价 |
| 3 | **账户费率** | 挂在你这一个账户上的价 |
| 4 | **租户默认** | 你们租户的默认价 |
| 5 | **平台默认** | 全平台的默认价 |
| 6 | **缺省统一价** | 前面都没命中，按统一价兜底 |

:::warning 这些配置都在管理员手里
优先级顺序是固定规则，但**每一层填什么值、有没有开这一层，全部由管理员在运营平台配置**。用户侧看不到也改不了。发现价格和预期不一致时，把模型 ID 和看到的单价一起发给管理员核对。
:::

## 找不到价格怎么办

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 整页显示「当前账户还没有关联费率方案。」 | 账户没挂任何费率方案 | 联系管理员关联费率方案 |
| 某个模型整行价格都是 **未定价** | 这个模型在费率方案里没条目，也没有统一价兜底 | 联系管理员补价；在此之前该模型不能用于 [模型体验](./experience.md) |
| 想看某个模型的调用实际花了多少 | 这一页只是单价表 | 到 [调用分析](./usage-statistics.md) 看金额，到 [API 密钥](./token.md) 的 **请求日志** 看逐条明细 |
| 某些单元格显示 `-` | 该模型的上下文、能力、类型或参数规模没配 | 不影响计费，只影响可读信息 |
