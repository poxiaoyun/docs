# 模型广场

**模型广场** 是聚合网关里「挑模型」的地方。进入对话之前先来这一页，你能看到自己能用哪些模型、每个模型能记住多长的内容、每 100 万 Token 收多少钱，然后一键跳到对话页开始用。

:::tip 打个比方
模型广场像手机应用商店的列表页：卡片告诉你这个「应用」是干什么的、多大、多少钱；点开详情再决定要不要装（开始对话）。
:::

## 开始之前

- 已登录账号即可，不需要额外角色。
- 这里只能看到**你有权使用**的模型。一个都看不到，说明管理员还没给你开通模型渠道。

## 页面长什么样

| 区域 | 位置 | 说明 |
| --- | --- | --- |
| 筛选区 | 左侧（窗口窄时移到卡片上方） | 按 **类型**、**类别**、**厂家**、**上下文**、**参数规模** 分组筛选 |
| 可见范围标签 | 顶部左侧 | **全部** / **公开** / **租户内** / **个人**，标签后的数字是该范围内的模型数量 |
| 搜索与排序 | 顶部右侧 | 搜索框按名称或关键词查找；下拉框可选 **按名称排序** 或 **最新发布** |
| 模型卡片 | 页面中间 | 按窗口宽度自动排成 1~4 列，每张卡片对应一个模型 |
| 模型数量 | 卡片区下方 | 显示「共 N 个模型」 |

![模型广场整页：左侧是分组筛选，顶部是可见范围标签、搜索框与排序，中间是模型卡片](/assets/screenshots/airouter/marketplace-01.png)

对照上图看这一页的骨架：最左边一列是 **类型 / 类别 / 厂家 / 上下文 / 参数规模** 五组筛选，顶部左侧是可切换的可见范围标签（截图里「全部」为 35 个），右侧是搜索框和排序下拉，中间区域铺模型卡片。

## 挑一个模型

1. 顶部导航点 **模型广场**。
2. 先定范围：点顶部的 **全部**、**公开**、**租户内**、**个人** 之一。
3. 再用左侧筛选收窄。每组的标签**点一下选中，再点一下取消**，不同组可以叠加使用：
   - **类型**：如「对话」。
   - **类别**：如「视觉」「推理」「Coder」。
   - **厂家**：如 DeepSeek、Qwen、智谱、Kimi、OpenAI。
   - **上下文**：`< 32K`、`32K - 128K`、`128K - 1M`、`≥ 1M`。
   - **参数规模**：`< 10B`、`10B - 30B`、`30B - 100B`、`100B - 300B`、`≥ 300B`。
4. 还找不到就直接打字搜：在搜索框输入模型名称或关键词，模型 ID、厂家、渠道、租户、工作空间都能匹配。
5. 想换个顺序看，在搜索框右边的下拉框选 **按名称排序** 或 **最新发布**。
6. 卡片区出现结果，页面下方显示「共 N 个模型」。没有结果时显示「暂无匹配模型」，按提示放宽条件即可。

## 卡片上的信息怎么看

| 卡片元素 | 什么意思 |
| --- | --- |
| 模型图标 + 模型名 | 调用接口时用的就是这个 ID，卡片上不能复制 |
| 提供者 | 这个模型由谁提供 |
| 右上角 **New** | 最近新增的模型 |
| 右上角彩色标签 | 可见范围：**公开**（全平台可用）、**租户内**（仅本租户）、**个人**（仅个人或本工作空间） |
| 描述 | 模型的一句话介绍，最多显示两行 |
| 底部标签 | 类型、类别（最多显示 2 个）、**上下文**、参数规模、自定义标签（最多显示 2 个），完整标签在详情里看 |

:::info 想复制模型 ID
这一页的卡片和详情面板都没有复制按钮。到 [模型体验](./experience.md) 或 [模型对比](./compare.md) 左侧的模型列表里，点模型名右边的复制图标（悬停提示 **复制模型 ID**）就能复制。
:::

### 上下文长度是什么意思

指模型一次对话能记住的内容上限。卡片上标的 `128K`、`1M` 就是这个上限，数字越大越能应付长文档、长代码。超出上限后模型会忘掉最早的内容，甚至直接报「上下文长度超出限制」。

### 参数规模是什么意思

单位是 `B`（十亿）。`7B` 就是 70 亿参数。参数越多通常能力越强，但速度、价格和显存占用也会不同，实际以卡片价格为准。

### 怎么知道模型支不支持图片

页面没有单独的「支持图片」开关，看**类别**标签：出现 **视觉** 就表示这个模型能处理图片。在 [模型体验](./experience.md) 页，输入框工具栏上的图片按钮可以把图片一起发给模型。

## 打开模型详情

1. 点任意一张卡片，右侧滑出详情面板。
2. 面板顶部是模型名、可见范围、提供者、描述和全部标签，还有 **体验模型** 与 **API 文档** 两个按钮。
3. 中间是 **可用渠道（N）**：列出这个模型的每个接入来源、**所属租户** 和 **优先级**。
4. 下方是 **价格信息**。
5. 想看调用示例，点 **API 文档**，面板里会展开 **调用示例**，可在 curl、Python、Go 三个标签页之间切换，页面同时给出 **网关地址**。

:::tip 同一个模型为什么有多个渠道
一个模型可能接入了多个来源。它们只会合并成一张卡片，详情里按**优先级**从高到低排列；点 **体验模型** 时会默认使用优先级最高的那个渠道。
:::

![模型详情面板：顶部是模型名与标签，中间是可用渠道，下方是四项价格](/assets/screenshots/airouter/marketplace-02.png)

截图里的 **价格信息** 分四格：**输入价格**、**输出价格**、**缓存读价格**、**缓存写价格**，每格右下角都带单位 `CNY / 1M`。这一页把四个价格项的含义逐条列在下面。

## 价格怎么读

| 价格项 | 含义 |
| --- | --- |
| **输入价格** | 你发给模型的内容（提问和上下文）按这个价格计费 |
| **输出价格** | 模型生成出来的内容按这个价格计费 |
| **缓存读价格** | 命中缓存、直接复用已有上下文时的价格 |
| **缓存写价格** | 把上下文写入缓存时的价格 |

单位是「每 100 万 Token 的价格」，页面上显示成类似 `0.5 CNY / 1M` 的样子。某个价格项没有配置数据时显示 `-`。

## 开始对话

1. 在详情面板顶部点 **体验模型**。
2. 页面跳到 **模型体验**，并且已经自动选中这个模型。
3. 在底部输入框里输入问题，按 **Enter** 发送。

:::warning 会清空当前对话
从广场点 **体验模型** 进入时会重新开始一次对话，之前聊过的内容不会保留。想留住结果请先复制或截图。
:::

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 显示「暂无匹配模型」 | 搜索词或筛选条件太窄 | 按提示调整搜索条件或筛选范围后重试 |
| 想看某个模型却找不到卡片 | 它不在当前可见范围标签下 | 切到 **全部** 或对应的可见范围再看 |
| 同一个模型有多个渠道，不知道用哪个 | 一个模型可能接入多个来源 | 打开详情看 **可用渠道** 的优先级，默认会用优先级最高的 |
| 价格显示 `-` | 该价格项没有配置 | 参考其他价格项，或到 [调用分析](./usage-statistics.md) 看实际产生的费用 |
