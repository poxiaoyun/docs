# 模型广场

**模型广场** 是聚合网关里「挑模型」的地方，也是登录后默认停的那一页。在这里你能看到自己能用哪些模型、每个模型能记住多长内容、支持什么能力，然后一键跳到对话页开始用。

这一页**不显示价格**。要知道自己实际按什么单价计费，点顶部 **价格**（见 [价格](./prices.md)）。

:::tip 打个比方
模型广场像手机应用商店的列表页：卡片告诉你这个「应用」是干什么的、能记多长、有什么标签；点开详情再决定要不要用。
:::

## 开始之前

- 已登录账号即可，不需要额外角色，也不需要 API 密钥。
- 这里只能看到**你有权使用**的模型。一个都看不到，说明管理员还没给你开通模型渠道。

## 页面长什么样

| 区域 | 位置 | 说明 |
| --- | --- | --- |
| 筛选区 | 左侧（窗口窄时移到卡片上方） | 按 **类型**、**类别**、**厂家**、**上下文**、**参数规模** 五组筛选 |
| 可见范围标签 | 顶部左侧 | **全部** / **公开** / **内部** / **私有**，标签后的数字是该范围内的模型数量 |
| 搜索与排序 | 顶部右侧 | 搜索框按名称或关键词查找；下拉框可选 **按名称排序**（默认）或 **最新发布** |
| 模型卡片 | 页面中间 | 按窗口宽度自动排成 1~4 列，每张卡片对应一个模型 |
| 模型数量 | 卡片区下方 | 显示「共 N 个模型」 |

![模型广场整页：左侧是分组筛选，顶部是可见范围标签、搜索框与排序，中间是模型卡片](/assets/screenshots/airouter/marketplace-01.png)

对照上图看这一页的骨架：最左边一列是 **类型 / 类别 / 厂家 / 上下文 / 参数规模** 五组筛选，顶部左侧是可切换的可见范围标签（标签上的数字就是该范围的模型数），右侧是搜索框和排序下拉，中间区域铺模型卡片。

## 挑一个模型

1. 顶部导航点 **模型广场**。
2. 先定范围：点顶部的 **全部**、**公开**、**内部**、**私有** 之一。
3. 再用左侧筛选收窄。每组的标签**点一下选中，再点一下取消**，不同组可以叠加使用：
   - **类型**：**对话**、**生图**、**视频**、**语音**、**嵌入**、**重排序**。
   - **类别**：**视觉**、**MoE**、**推理**、**Tools**、**FIM**、**Math**、**Coder**。
   - **厂家**：DeepSeek、Qwen、智谱、Kimi、OpenAI、Anthropic、Google、MiniMax、豆包。
   - **上下文**：`< 32K`、`32K - 128K`、`128K - 1M`、`≥ 1M`。
   - **参数规模**：`< 10B`、`10B - 30B`、`30B - 100B`、`100B - 300B`、`≥ 300B`。
4. 还找不到就直接打字搜。搜索框占位是「搜索模型名称或关键词」，能匹配 **模型 ID、厂家、描述、类型、类别、自定义标签、渠道、租户、工作空间**。
5. 想换个顺序看，在搜索框右边的下拉框选 **按名称排序** 或 **最新发布**。
6. 卡片区出现结果，页面下方显示「共 N 个模型」。同一模型接了多个渠道时，**多个渠道算一个模型**。没有结果时显示「暂无匹配模型」和「请调整搜索条件或筛选范围后重试。」，按提示放宽条件即可。

## 卡片上的信息怎么看

| 卡片元素 | 什么意思 |
| --- | --- |
| 模型图标 + 模型名 | 调用接口时用的就是这个 ID |
| 提供者 | 这个模型由谁提供 |
| 右上角 **New** | 最近新增的模型 |
| 右上角彩色标签 | 可见范围：**公开**（全平台可用）、**内部**（仅本租户）、**私有**（仅自己或本工作空间） |
| 描述 | 模型的一句话介绍，最多显示两行 |
| 底部标签 | 类型、类别（最多显示 2 个）、**上下文**、参数规模、自定义标签（最多显示 2 个），完整标签在详情里看 |

:::info 这一页不能复制模型 ID
卡片和详情面板上都没有复制按钮。要完整模型 ID，直接照卡片上的文字抄；用 **调用示例** 时，示例里已经把模型 ID 填好了。
:::

### 上下文长度是什么意思

指模型一次对话能记住的内容上限。卡片上标的 `128K`、`1M` 就是这个上限，数字越大越能应付长文档、长代码。超出上限后模型会忘掉最早的内容，甚至直接报「上下文长度超出限制」。

### 参数规模是什么意思

单位是 `B`（十亿）。`7B` 就是 70 亿参数。参数越多通常能力越强，但速度、价格和显存占用也会不同。

### 怎么知道模型支不支持图片

页面没有单独的「支持图片」开关，看**类别**标签：出现 **视觉** 就表示这个模型能处理图片。在 [模型体验](./experience.md) 页，输入框工具栏上的图片按钮可以把图片一起发给模型。

## 打开模型详情

1. 点任意一张卡片，右侧滑出详情面板。
2. 面板顶部是模型 ID、可见范围、提供者、描述和全部标签（类型、类别、上下文、参数规模、自定义标签，以及模型的 **任务** 标签）。
3. 下面是两个按钮：**体验模型** 和 **调用示例**。
4. 再往下是 **可用渠道（N）**：列出这个模型的每个接入来源、**所属租户** 和 **优先级**。
5. 想看怎么用程序调它，点 **调用示例**，面板里会展开调用说明。

:::tip 同一个模型为什么有多个渠道
一个模型可能接入了多个来源。它们只会合并成一张卡片，详情里按**优先级**从高到低排列；点 **体验模型** 时会默认使用优先级最高的那个渠道。
:::

## 调用示例里有什么

点 **调用示例** 后会展开一块「怎么用程序调这个模型」的内容：

| 内容 | 说明 |
| --- | --- |
| **网关地址** | 形如 `https://你的站点域名/airouter-data`，这是所有接口的根地址 |
| Chat API 地址 | 在网关地址后面加上 `/v1/chat/completions` |
| 渠道 ID / 任务标签 | 说明这次调用走的是哪个渠道、这个模型属于什么任务 |
| 示例代码 | 顶部有 **curl**、**Python**、**Go** 三个标签页，切换查看；示例里已填好模型 ID 和请求头 |
| 鉴权 | 示例统一用 `Authorization: Bearer YOUR_TOKEN`，把 `YOUR_TOKEN` 换成你自己的 API 密钥 |

更完整的接口清单（含 Anthropic 协议）见 [API 文档](./api-docs.md)。

## 开始对话

1. 在详情面板顶部点 **体验模型**。
2. 页面跳到 **模型体验**，并且已经自动选中这个模型。
3. 在底部输入框里输入问题，按 **Enter** 发送。

:::warning 会清空当前对话
从广场点 **体验模型** 进入时会重新开始一次对话，之前聊过的内容不会保留。想留住结果请先复制或截图。
:::

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 显示「暂无匹配模型」 | 搜索词或筛选条件太窄 | 按提示调整搜索条件或筛选范围后重试 |
| 想看某个模型却找不到卡片 | 它不在当前可见范围标签下 | 切到 **全部** 或对应的可见范围再看 |
| 同一个模型有多个渠道，不知道用哪个 | 一个模型可能接入多个来源 | 打开详情看 **可用渠道** 的优先级，默认会用优先级最高的 |
| 找不到价格 | 这一页本来就不显示价格 | 点顶部 **价格**，那里是当前账户的单价 |
| 想复制模型 ID 找不到按钮 | 这一页不提供复制 | 照卡片上的文字抄，或用 **调用示例** 里已填好的 ID |
