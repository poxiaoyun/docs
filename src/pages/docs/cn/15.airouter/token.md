# API 密钥

**API 密钥** 页管理的是**调用聚合网关模型接口**时用的身份凭证。你在 [模型体验](./experience.md) 页手动聊天要用它，把模型接进自己的程序时更要用它——程序拿着这把密钥，才能证明「这次调用是我发的」。

这一页同时提供**请求日志**，可以逐条核对你（或你的程序）发出去的每一次调用。

:::warning 和账户中心里的 API 密钥不是一回事
账户中心的 API 密钥用于管理平台自身的接口；这里的密钥只用于**对话模型接口**。两边不能混用。
:::

## 开始之前

- 已登录账号即可，不需要额外角色。
- 你只能看到和管理自己账号下的密钥。
- **限速（RPM / TPM）和访问 IP 白名单由管理员配置，用户侧不能改、也没有编辑入口。** 需要调整请联系管理员。

## 页面有两个标签页

| 标签页 | 看什么 |
| --- | --- |
| **API 密钥** | 密钥列表与创建、启用、禁用、删除 |
| **请求日志** | 每次调用的明细记录 |

两个标签页是同一页的两个视图：**API 密钥** 看「有哪些钥匙」，**请求日志** 看「用这些钥匙发生过什么」。

## 密钥列表怎么看

| 列 | 说明 |
| --- | --- |
| **名称** | 点名称进入详情 |
| **API 密钥** | 只显示前 6 位加 `************`，右边的复制按钮可以复制完整值 |
| **状态** | **启用** / **已禁用** / **已过期**。被管理员封禁的密钥还会多一个盾牌图标，鼠标悬停显示「该 API 密钥已被管理员封禁，无法自行启用，请联系管理员。」 |
| **过期时间** | 显示 **永不过期** 就是长期有效；已过期会标红并带「已过期」标签，此时密钥无法再调用 |
| **创建时间** | 密钥建立的时间 |

:::info 这一页看不到限速值
列表里**没有 RPM、TPM、白名单这三列**。这三项由管理员配置，只能在密钥详情页看只读值。
:::

行末的操作菜单里能做的事：

| 操作 | 什么时候可点 | 说明 |
| --- | --- | --- |
| **启用** | 密钥已被**自己**禁用时 | 恢复这把密钥的访问权限 |
| **禁用** | 密钥当前是启用状态时 | 用这把密钥发起的**新**请求会被拒绝，已经开始的请求不会中断 |
| **删除** | 任何状态 | 弹确认框，需要手动输入密钥名称才能继续 |

被**管理员**封禁的密钥只能看不能动——你自己启用会失败，需要联系管理员。

## 创建一把密钥

1. 顶部导航点 **API 密钥**。
2. 点页面右上角 **创建 API 密钥**。
3. 在弹出的 **创建 API 密钥** 表单里填写：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | **名称** | 例如 `my-app-prod` | 必填，前后空格会被去掉；创建后**不能再改** |
   | **永不过期** | 默认开启 | 关掉开关后，下面会出现 **过期时间** |
   | **过期时间** | 选一个日期时间 | 只有关掉 **永不过期** 才出现，且必须填 |

4. 点 **确定**。想放弃就点 **取消**。

创建成功后回到列表，就能看到这把新密钥。新密钥默认**不限速、不限制来源 IP**；需要限制时找管理员配置。

:::warning 名称要想清楚
名称创建后不可修改，也不可重命名。用「应用 + 环境」的命名习惯（例如 `crm-prod`、`crm-test`），以后几十把密钥也不容易搞混。
:::

## 拿到密钥的完整值

列表和详情页里，密钥本身始终是脱敏的（前 6 位 + 星号）。要拿到完整值，点密钥旁边的**复制按钮**。

:::warning 复制出来的就是完整密钥
拿到完整密钥后请立刻存到安全的地方（例如密码管理器或程序的环境变量里），不要贴进聊天工具、文档或代码仓库。密钥泄露等于别人可以拿你的额度去调用模型。
:::

## 这把密钥能做什么

1. 在 [模型体验](./experience.md) 和 [模型对比](./compare.md) 页发起对话——页面会自动挑账号下的第一把可用密钥，也可以在页面里切换。
2. 给你自己的程序调用模型接口。接口清单和鉴权写法见 [API 文档](./api-docs.md)；单个模型的现成示例，在 [模型广场](./marketplace.md) 详情里点 **调用示例** 也能拿到。
3. 在示例里把 `YOUR_TOKEN` 换成你复制的密钥，把 `YOUR_MODEL` 换成卡片上的模型 ID，就能跑通第一次调用。

## 查看密钥详情

在列表里点密钥**名称**进入详情页，标题是「API 密钥 / 你的密钥名」，能看到：

| 字段 | 说明 |
| --- | --- |
| 密钥 | 脱敏显示，带复制按钮 |
| 归属 | 这把密钥归属的对象 |
| 创建时间 | 建立时间 |
| 过期时间 | 没有设置时显示 **永不过期** |
| **RPM** | 每分钟最大请求数。显示 `∞` 表示不限制 |
| **TPM(K)** | 每分钟最大 Token 数，展示值已从 K 换算成具体数字。显示 `∞` 表示不限制 |
| **访问 IP 白名单** | 显示 `*` 表示所有 IP 都能用 |

后三项是**只读展示**，显示的是管理员配置的值，这一页改不了。

要停用或删除，点右上角 **操作** 菜单，里面只有 **禁用** / **启用** / **删除**——**没有编辑**。要改限速或白名单，请联系管理员。

## 查看请求日志

切到 **请求日志** 标签页，可以看到账号下每次调用的记录：

1. 顶部先选时间范围：**今日**（默认）、**昨日**、**近 3 日**、**近一周**、**自定义**。选 **自定义** 时会出现 **开始日期** 和 **结束日期**。
2. 下面有四个筛选：
   - **API 密钥**：输入密钥名称，输入后会自动过滤。
   - **渠道**：按渠道名过滤。
   - **模型**：按模型名过滤。
   - **结果**：**全部**、**成功**、**失败**、**已拦截**、**超出配额**。
3. 点 **刷新** 重新拉取，点 **重置** 清空所有筛选条件并回到 **今日**。
4. 表格里每一行是一条调用，列见下表。
5. 想看某一条的细节，点时间那一列旁边的眼睛图标（悬停提示 **查看详情**）打开详情弹窗。

| 列 | 说明 |
| --- | --- |
| **时间** | 请求发起时间，下面一行是结果色点和结果文字 |
| **渠道** | 走的是哪个渠道，附供应商、租户、集群、工作空间信息 |
| **API 密钥** | 这次调用用的是哪把密钥 |
| **模型** | 调用的模型 ID |
| **请求 ID** | 这次请求的编号 |
| **耗时** | 首 token 耗时和总耗时 |
| **Token 数** | 输入、输出、合计 |
| **费用** | 这次调用折算的金额 |
| **标准** | 这次计费用的计价标准（例如按哪个费率方案） |

:::tip 时间列上的小图标
- **红色/绿色的点 + 文字**：这次调用成功还是失败。失败的行左侧还会有一条红色竖线标记，方便一眼扫出问题。
- **警告图标**：这次调用命中了敏感内容检测。悬停能看到具体提示。
- **眼睛图标**：打开这一条的详情。
:::

排查调用失败时，**请求 ID** 和 **结果** 这两列最有用：把请求 ID 交给管理员，对方能直接定位到这次调用。

**请求日志** 页的样子如上。它和 **API 密钥** 是同一页的两个标签页，切换不用重新进入。截图里账号当天没有调用记录，所以表格是空的；正常有调用时会按时间倒序列出每一次请求。

## 额度怎么算

这个页面**不设置额度**，也不限制你花多少。影响你能不能用、花多少钱的，是下面这几处：

| 位置 | 管什么 |
| --- | --- |
| [价格](./prices.md) | 每个模型的单价。调用花费按这个价折算 |
| [账户](./billing.md) | 余额、当前套餐、套餐点数用量、周额度 |
| [订阅](./subscribe.md) | 买套餐；**超额扣费** 开关在下单时设定 |

因此出现这类提示时，问题不在密钥上：**余额不足** 看账户余额，**套餐点数已用完** 去开超额扣费或买新套餐，**周额度已用完** 等周期重置或换更高档套餐，**账户已冻结或停用** 只能找管理员。逐条对照见 [模型体验](./experience.md) 的常见问题。

## 安全建议

| 建议 | 说明 |
| --- | --- |
| 一个应用一把密钥 | 不同程序、不同环境分开建，方便单独停用和计量 |
| 能删就删、能停就停 | 不再使用的密钥直接删除，临时不用的先禁用 |
| 设置过期时间 | 非必要的场景不要长期使用永不过期 |
| 定期轮换和清理 | 定期换新密钥，删掉旧的；轮换前先确认新密钥已生效 |
| 需要限速找管理员 | RPM / TPM / IP 白名单由管理员配置，别指望用户侧自己收口 |
