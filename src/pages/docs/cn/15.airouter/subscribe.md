# 订阅

**订阅** 页用来买套餐：挑一个商品，选一档套餐，确认计费周期，然后从**账户余额**付钱。买完之后，对话会优先消耗套餐里的**点数**，点数用完再按你下单时选的规则处理。

这一页解决：怎么找到想买的套餐、四态按钮分别是什么意思、确认弹窗里那几个开关要不要打开、升级和重置有什么区别。

:::tip 打个比方
像给手机买流量包：商品是「流量套餐」，档位是 5G / 20G / 50G，计费周期是月包还是年包。套餐里的点数是「流量」，用完之后的超额扣费开关决定「用完是断网还是继续按量扣钱」。
:::

![订阅页：Coding Plan 商品的 Plus / Ultra / Pro 三档套餐卡片，按钮分别是「当前订阅不可变更」「你当前的套餐」「升级到此档」](/assets/screenshots/airouter/subscribe-01.png)

## 开始之前

- 已登录账号即可，不需要额外角色。
- **账户余额要够。** 所有支付都从账户余额扣，页面里**没有充值入口**——余额不足时提示「余额不足，无法购买。充值请联系管理员。」，需要找管理员充值。
- 想先看单价再决定买不买，去 [价格](./prices.md) 对比；想先看现在剩多少点数，去 [账户](./billing.md)。

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 商品 | 一组套餐的集合，例如「标准版」「企业版」。顶部 **订阅** 下拉里列的就是商品 |
| 套餐 | 商品里的一档，例如「入门档 / 专业档 / 旗舰档」。等级越高通常额度越大 |
| 计费周期 | 这一档按**月**、**季**还是**年**卖 |
| 点数 | 套餐里的计价单位，**1 点 = 0.01 元**。卡片上会写「包含 N 点（价值 ¥X）」 |
| 额度重置 | 套餐额度是否**每月清零重算**。不按月重置的套餐，额度只在购买时给一次 |
| 周额度 | 套餐附带的周期性调用上限，在 [账户](./billing.md) 里看剩余 |
| 自动续费 | 到期时自动从余额再扣一期的钱续上 |
| 超额扣费 | 点数用完后，允不允许继续从余额按价扣费 |
| 专属计划 | 只给特定账户开放的商品，下拉里和页面上都会单独标出来 |

## 挑一个套餐

1. 顶部导航点 **订阅**，下拉里会列出你可买的商品；专属商品带 **专属计划** 标签。没有商品时下拉显示 **暂无套餐**，正在加载时显示 **正在加载套餐**。
2. 点一个商品，进入它的套餐页。页面顶部是商品名和商品描述，专属商品下方还有 **专属计划** 标签。
3. 套餐卡按等级从左到右排列，每行 4 张；超过 4 档时可以横向滚动。每张卡上有：

   | 卡片元素 | 含义 |
   | --- | --- |
   | 套餐名 | 这一档的名字，字最大 |
   | **推荐** 标签 | 商品主推的那一档，卡片带主色边框 |
   | 一句话卖点 + 描述 | 这一档适合谁、能干什么 |
   | 按钮 | 见下方四态说明 |
   | 价格 | 形如 `¥99 / 月`、`¥299 / 季`、`¥999 / 年` |
   | 卖点列表 | 包含多少点（价值多少钱）、额度是否每月重置、到期是否自动续费 |

4. 按钮有四种状态，点之前先认清：

   | 按钮文字 | 含义 | 能点吗 |
   | --- | --- | --- |
   | **开始订阅** | 你还没有生效中的订阅，这一档可以买 | 能 |
   | **升级到此档** | 你已有订阅，这一档是同一商品里更高的等级 | 能 |
   | **你当前的套餐** | 这就是你现在生效的那一档 | 不能，按钮置灰 |
   | **当前订阅不可变更** | 这一档不能选：降级、同级、跨商品，或套餐没分级 | 不能，按钮置灰 |

:::info 为什么只能升不能降
规则是：已有生效订阅时，**只能升级到同一商品内更高等级的套餐**。想降级要先取消当前订阅，或者等到期。页面不会给你绕过的入口。
:::

## 确认订阅

点按钮后弹出确认窗，窗里的内容和金额要逐项核对：

| 弹窗内容 | 说明 |
| --- | --- |
| 标题 | 首次购买是 **确认订阅**；升级是 **确认升级订单** |
| **套餐** | 显示成「商品名 · 套餐名」，下面一行是「包含 N 点（价值 ¥X）」 |
| 金额 + 周期 | 右上角显示这一档的价格，下面是 **每月** / **每季** / **每年** |
| **计费周期** | **按月** / **按季** / **按年** |
| **额度重置** | **每月重置** 或 **不按月重置** |
| **支付方式** | 固定为 **账户余额**，不能改 |
| **到期自动续费** | 开关，见下一节 |
| **超额扣费** | 开关，见下一节 |
| **应付金额** | 这次实际扣多少 |
| 底部按钮 | 左边 **取消**，右边 **确认订阅 · ¥x**（升级时是 **确认升级**） |

:::warning 这两个开关只在此时设定一次
**到期自动续费** 和 **超额扣费** 都只在确认订阅的这一步设定。买完之后，[账户](./billing.md) 页**没有**修改这两个开关的地方，也**没有**取消订阅的按钮。之后要改，请联系管理员。
:::

### 到期自动续费

开关打开后，下面会显示「到期后将自动扣除 ¥x / 每月」（季付、年付会换成对应周期）。

- **打开**：到期那天自动从余额扣一期，扣成功就继续用；余额不足则到期停用。
- **关闭**：到期就结束，不会自动扣钱，需要你自己回来再买。

:::tip 什么时候该关
试用、临时项目、或者想让消费完全可控时关掉它。长期稳定使用再打开，免得中途忘续费导致调用突然中断。
:::

### 超额扣费

开关下面的说明是：「套餐点数用完后，继续从余额按价扣费。关闭后，即使账户还有余额也会停止调用。」

- **打开**：点数用完不中断，超出部分从余额按 [价格](./prices.md) 里的单价继续扣。
- **关闭**：点数一到上限就停止调用，哪怕余额还很多。这时对话会提示「套餐点数已用完。开启超额扣费后可继续使用，超出部分从余额扣。」

:::warning 关掉它，余额再多也调不动
这是最容易踩的坑：以为「我账户里还有钱」就能继续用，结果被拦住。要么开超额扣费，要么及时买新套餐。
:::

## 升级与降级

| 想做的事 | 允许吗 | 怎么做 |
| --- | --- | --- |
| 升级到同一商品里更高档 | 允许 | 点那一档的 **升级到此档**，弹窗标题为 **确认升级订单** |
| 降级到更低档 | 不允许 | 提示「当前订阅只能升级到同一商品内更高等级的套餐，降级请先取消或等到期。」 |
| 换到另一个商品 | 不允许直接换 | 同上，需要先结束当前订阅 |
| 买同一档 | 不允许 | 按钮显示 **你当前的套餐**，置灰 |

升级是按**新套餐原价购买**，不是补差价。弹窗里会有一段提示：你当前的套餐会随之结束，并按**未用点数比例**退回账户余额（页面会给出预计退款金额，实际以入账时的未用点数为准）。

:::info 升级前算一笔账
因为升级要按原价再付一次，只是把旧套餐未用点数退回，所以**接近到期时升级并不划算**——未用点数已经不多，退款也少。想换档可以等旧套餐到期后再买。
:::

## 重置当前套餐

「重置」不是续费，而是**按原价重买一份当前套餐**：扣一次全款，当前点数清零，未用点数**不退**。

1. 到 [账户](./billing.md)，在 **当前套餐** 卡片上点 **重置套餐**。
2. 弹窗标题是 **重置套餐**，里面只有套餐、周期、支付方式、应付金额，**没有**自动续费和超额扣费开关（这两项沿用原订阅的设定）。
3. 如果当前还有未用点数，必须勾选「我知道未使用的点数不会退款」才能继续。
4. 点 **确认重置 ¥x**。

:::warning 这个动作不可逆
重置之后旧点数立即作废、不折算、不退钱。只是想让额度回到满值、且剩下的点数本来也用不完时，才值得这么做。
:::

## 找不到想买的套餐

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 下拉里显示 **暂无套餐** | 你没有任何可购买的商品 | 联系管理员开通商品或套餐 |
| 下拉里显示 **正在加载套餐** 一直不动 | 套餐数据没拉回来 | 刷新页面；仍不行就联系管理员 |
| 页面提示「这档套餐当前不可购买。」 | 链接里的商品不存在或已下架 | 从顶部 **订阅** 下拉重新选一个商品 |
| 弹窗提示「这档套餐还没配置好额度或价目，暂时无法购买，请联系管理员。」 | 这一档缺额度或价目配置 | 找管理员补齐，或先选别的档 |
| 弹窗提示「余额不足，无法购买。充值请联系管理员。」 | 余额不够这一次的全款 | 找管理员充值后再买 |
| 弹窗提示「这笔购买已经用在别的套餐上，请重新发起。」 | 上一次订单已被占用（重复提交或页面重放） | 关掉弹窗重新走一遍购买流程 |
| 点按钮没反应且是灰的 | 那是 **你当前的套餐** 或 **当前订阅不可变更** | 按上面的升级/降级规则处理 |
