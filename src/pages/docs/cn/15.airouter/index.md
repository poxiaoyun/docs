# 聚合网关

聚合网关是平台内置的**网页版模型使用入口**：跟模型对话、把模型接给程序调用、查价格、买套餐、看账单，都在这里。在页面上它默认显示为「模型体验」，名称可由管理员在 Boss 运营平台的**网关设置**里修改。

这一页解决三个问题：从哪进、顶部那一行八个入口分别管什么、第一次用要按什么顺序走。具体的操作细节，每一页各有专页。

:::tip 打个比方
智算平台像一栋写字楼，水电网、房间、门禁都归它管；聚合网关像楼里的一间服务大厅——你走进去找坐席（模型）提问，也能在前台查价目表（价格）、办套餐（订阅）、对账单（账户）。模型本身由平台管理员配置好，你直接挑现成的用。
:::

## 怎么进入聚合网关

1. 看页面**左上角**，找到「当前产品名 + 下拉箭头」的按钮。
2. 点它，会弹出标题为 **产品与服务** 的菜单。
3. 在菜单里选择这一项——文档里统一叫它 **聚合网关**，界面上默认显示为 **模型体验**（管理员改过名的话，以菜单里实际显示的文字为准）。
4. 进入后默认停在 **模型广场** 页。

![聚合网关左上角的「产品与服务」菜单，展开后列出智算平台、魔哈Hub、模型网关三个子系统](/assets/screenshots/airouter/index-01.png)

图里就是入口本身：点左上角的**产品与服务**按钮，菜单里第三项即聚合网关。这一项显示的名字由管理员在 [网关设置](../20.boss/03.settings/chatapp.md) 里改，所以以你菜单里实际看到的文字为准。

## 顶部八个入口各管什么

聚合网关没有左侧菜单，所有功能都在**页面顶部这一行**。八个入口里有**两个是下拉**，点开才会看到子项：

| 入口 | 形态 | 在这里做什么 |
| --- | --- | --- |
| **模型广场** | 直链 | 挑模型。看有哪些模型可用、上下文多长、支持什么能力，并查看调用示例 |
| **模型对话** | 下拉 | 点开有两个子项：**模型体验**（跟单个模型聊天）和 **模型对比**（同一个问题问两个模型）|
| **API 密钥** | 直链 | 创建和管理给程序调用用的密钥，并查看每次调用的日志 |
| **调用分析** | 直链 | 看用量看板：调用次数、Token 消耗、费用、成功率 |
| **价格** | 直链 | 查当前账户在费率方案里的模型单价，见 [价格](./prices.md) |
| **订阅** | 下拉（商品列表） | 下拉里列出可买的商品，选一个进入套餐选购页；专属商品带「专属计划」标签，没有商品时显示「暂无套餐」，见 [订阅](./subscribe.md) |
| **账户** | 直链 | 看余额、当前套餐、套餐用量与周额度，翻充值和消费流水，见 [账户](./billing.md) |
| **API 文档** | 直链 | 接程序用的接口清单与鉴权写法，见 [API 文档](./api-docs.md) |

:::info 名字对不上是正常的
文档分区叫「聚合网关」，左上角产品菜单里默认显示「模型体验」，顶部导航里另有一个父项叫「模型对话」。三个名字指的是同一个子系统：**聚合网关**是文档的叫法，**模型体验**是产品名，**模型对话**是顶部那个下拉。
:::

## 开始之前

- 用一个**已登录**的账号就行，聚合网关不额外限制角色。
- **模型广场**、**价格**、**API 文档** 只要登录就能看，不需要密钥。
- 要用 **模型体验** 或 **模型对比** 发消息，账号下至少要有一把 **API 密钥**；没有的话，页面上会提示「未找到 API 密钥」，点提示里的 **创建 API 密钥** 就能建（见 [API 密钥](./token.md)）。
- 账号下至少要能看到**一个可用模型**。一个都看不到，说明管理员还没给你开通模型渠道。
- 要买套餐，账户余额得够；**页面里没有充值入口**，余额不足请联系管理员。

## 走通第一次对话

1. 左上角点 **产品与服务**，选 **模型体验**（就是本文说的聚合网关），进入后停在 **模型广场**。
2. 在 **模型广场** 里挑一个模型（卡片上「上下文」越大，越能记住长内容），点卡片打开右侧详情。
3. 在详情里点 **体验模型**。
4. 页面跳到 **模型体验**，并且已经自动选中刚才那个模型。
5. 在底部输入框里输入问题，按 **Enter** 发送。
6. 回答会逐字出现。想看它的推理过程，展开 **查看思考**。
7. 想换话题，点右上角 **清除对话**；想看花了多少，切到 **调用分析**。

以后再进来，也可以直接点顶部 **模型对话** → **模型体验**，不必每次都从模型广场绕。

## 结果确认

助手气泡里出现回答内容，并且回复下方多出一行 Token 用量数字，就说明这次对话成功了。

## 先弄懂这几个词

| 名词 | 通俗解释 |
| --- | --- |
| 模型 | 会回答问题的「大脑」。不同模型擅长的事、价格、能记住的长度都不一样 |
| 渠道 | 同一个模型可能有多个接入来源，价格和可用性可能不同 |
| 可见范围 | 模型能被谁看到：**公开**（全平台）、**内部**（本租户）、**私有**（仅自己或本工作空间） |
| Token | 模型计量的最小单位，可以粗略理解成「字数」；费用按 Token 算 |
| 上下文长度 | 一次对话里模型最多能记住多少内容，超了它就会忘掉最前面的部分 |
| 系统提示词 | 对话开始前给模型定的规矩或人设，例如「你是一个AI助手」 |
| 深度思考 | 让模型先把推理过程过一遍再回答，答案更稳，但更费 Token |
| API 密钥 | 给程序用的身份凭证，让外部程序也能调用这些模型 |
| 费率方案 | 管理员给账户配的一套模型价目表，决定你实际按什么单价计费。见 [价格](./prices.md) |
| 套餐 | 一次买断一段时间的用量包，里面装的是**点数**；对话优先消耗点数 |
| 点数 | 套餐里的计价单位，1 点折合 0.01 元；点数用完才从余额扣（取决于有没有开超额扣费） |
| 周额度 | 套餐附带的周期性调用上限，用完后要等本周期重置，或联系管理员 |
| 余额 | 账户里能直接扣的钱，买套餐、超额调用都从这里扣 |
| 超额扣费 | 套餐点数用完后，允不允许继续从余额扣费。下单时设定 |
| 流水 | 每一笔充值、扣费、退款、调整、买套餐的记录。见 [账户](./billing.md) |

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| **模型体验** 提示「未找到 API 密钥」 | 账号下还没有密钥 | 点提示里的 **创建 API 密钥**，先建一个 |
| **模型体验** 提示「暂无可用模型」 | 当前账号没有任何模型渠道 | 联系平台管理员，在网关里为你开通模型 |
| 消息发出去报错 | 触发限流、内容审查、上下文超长等 | 打开 [模型体验](./experience.md)，按里面的常见问题对照报错文案 |
| 提示「余额不足，请求被拒绝」 | 余额扣不动了 | 到 [账户](./billing.md) 看余额；页面没有充值入口，请联系管理员 |
| 提示「套餐点数已用完」 | 点数用完，且没开超额扣费 | 到 [订阅](./subscribe.md) 买新套餐，或请管理员开启超额扣费 |
| 提示「当前模型不在套餐覆盖范围内」 | 这个模型不在这份套餐里 | 换一个模型，或开启超额扣费按余额计费 |
| 提示「账户已冻结或停用」 | 账户状态异常 | 只能联系管理员处理 |
| 看不懂某个模型的单价 | 价格随费率方案、套餐、渠道不同而不同 | 到 [价格](./prices.md) 看你的账户单价 |
