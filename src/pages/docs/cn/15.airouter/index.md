# AIRouter

AIRouter 是平台内置的**网页版对话工具**（在页面上默认显示为「模型体验」，名称可由管理员在 Boss 运营平台里修改）。打开它，挑一个模型，敲一句话，就能看着模型一个字一个字地写出回答——不用写代码，不用装软件，也不用懂模型是怎么部署的。

它和智算平台（Rune）是**平级的两个子系统**。智算平台管的是算力、集群、实例、存储这些「地基」；AIRouter 只管两件事：跟模型对话，以及把模型接给外部程序调用。模型本身由平台管理员在网关里配置好，你在 AIRouter 里直接挑现成的用。

:::tip 打个比方
智算平台像一栋写字楼，水电网、房间、门禁都归它管；AIRouter 像楼里的一间服务大厅，你走进去找个坐席（模型）就能提问。
:::

## 怎么进入 AIRouter

1. 看页面**左上角**，找到「当前产品名 + 下拉箭头」的按钮。
2. 点它，会弹出标题为 **产品与服务** 的菜单。
3. 在菜单里选择 **AIRouter**（页面上默认显示为「模型体验」）。
4. 进入后默认停在 **模型广场** 页。

## 顶部五个入口各管什么

AIRouter 没有左侧菜单，所有功能都在**页面顶部这一行**：

| 入口 | 在这里做什么 |
| --- | --- |
| **模型广场** | 挑模型。看有哪些模型可用、每个模型的上下文长度和价格，复制模型 ID，查看调用示例 |
| **模型体验** | 跟单个模型对话。选模型、发消息、传图片、开深度思考、调参数 |
| **模型对比** | 同一个问题同时问两个模型，左右并排对照结果 |
| **API 密钥** | 创建和管理给程序调用用的密钥，并查看每次调用的日志 |
| **调用分析** | 看用量看板：调用次数、Token 消耗、费用、成功率 |

## 开始之前

- 用一个已登录的账号就行，AIRouter 不额外限制角色。
- 账号下至少要有**一个 API 密钥**。没有的话，**模型体验** 页会直接提示「未找到 API 密钥」，点提示里的 **创建 API 密钥** 就能建（详见 [API 密钥](./token.md)）。
- 账号下至少要能看到**一个可用模型**。一个都看不到，说明管理员还没给你开通模型渠道。

## 走通第一次对话

1. 左上角点 **产品与服务**，选 **AIRouter**，进入后停在 **模型广场**。
2. 在 **模型广场** 里挑一个模型（卡片上「上下文」越大，越能记住长内容），点卡片打开右侧详情。
3. 在详情里点 **体验模型**。
4. 页面跳到 **模型体验**，并且已经自动选中刚才那个模型。
5. 在底部输入框里输入问题，按 **Enter** 发送。
6. 回答会逐字出现。想看它的推理过程，展开 **查看思考**。
7. 想换话题，点右上角 **清除对话**；想看花了多少，切到 **调用分析**。

## 结果确认

助手气泡里出现回答内容，并且回复下方多出一行 Token 用量数字，就说明这次对话成功了。

## 先弄懂这几个词

| 名词 | 通俗解释 |
| --- | --- |
| 模型 | 会回答问题的「大脑」。不同模型擅长的事、价格、能记住的长度都不一样 |
| 渠道 | 同一个模型可能有多个接入来源，价格和可用性可能不同 |
| Token | 模型计量的最小单位，可以粗略理解成「字数」；费用按 Token 算 |
| 上下文长度 | 一次对话里模型最多能记住多少内容，超了它就会忘掉最前面的部分 |
| 系统提示词 | 对话开始前给模型定的规矩或人设，例如「你是一个AI助手」 |
| 深度思考 | 让模型先把推理过程过一遍再回答，答案更稳，但更费 Token |
| API 密钥 | 给程序用的身份凭证，让外部程序也能调用这些模型 |

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| **模型体验** 提示「未找到 API 密钥」 | 账号下还没有密钥 | 点提示里的 **创建 API 密钥**，先建一个 |
| **模型体验** 提示「暂无可用模型」 | 当前账号没有任何模型渠道 | 联系平台管理员，在网关里为你开通模型 |
| 消息发出去报错 | 触发限流、配额不足、内容审查等 | 打开 [模型体验](./experience.md)，按里面的常见问题对照报错文案 |
