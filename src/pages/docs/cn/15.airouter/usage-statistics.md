# 调用分析

**调用分析** 是账号在聚合网关里的用量看板。想知道这几天模型被调用了多少次、烧掉多少 Token、折算成多少钱，来这一页看就行，不用自己一笔笔统计。

:::tip 打个比方
像手机账单：上面是「本月话费」几个大数字，下面是每天用量的柱状图，能一眼看出哪天用得多。
:::

## 开始之前

- 已登录账号即可，不需要额外角色。
- 数据只统计**当前登录账号**的调用，看不到别人的用量。

## 怎么进入

顶部导航点 **调用分析**，页面默认显示 **今日** 的数据。

## 怎么筛选时间

1. 在页面顶部的筛选栏里点一个时间范围：
   **今日**（默认）、**昨日**、**近 3 日**、**近1 周**、**近一月**、**自定义**。
2. 选 **自定义** 时，右侧会出现 **开始时间** 和 **结束时间**，各选一个日期即可。
3. **时间粒度** 是只读的，由页面按范围自动决定，你不用选：
   - **今日**、**昨日**：**按小时**。
   - **近 3 日**、**近1 周**、**近一月**：**按天**。
   - **自定义**：跨度在 240 小时以内按小时，超过就按天。
4. 想立刻拿到最新数字，点 **刷新数据**。
5. 想回到初始状态，点 **重置筛选**，会重新回到 **今日**。

:::info 页面会自动刷新
看板每 30 秒自动刷新一次，放着不动数字也会更新。手动点 **刷新数据** 可以马上刷新。
:::

## 五张指标卡

页面顶部一排是概括性数字，每张卡都带「较上一周期」的涨跌：

| 指标卡 | 含义 |
| --- | --- |
| **总调用量** | 这段时间里一共发起了多少次调用 |
| **Token 消耗** | 这段时间一共用掉多少 Token |
| **总消费** | 折算出的金额。费用当然越低越好，所以它的涨跌方向和别的指标是反的 |
| **成功率** | 成功调用占全部调用的比例。拿不到上一周期数据时，卡片上会直接显示「暂无上一周期数据」 |
| **API Key 数量** | 当前账号下活跃的密钥数量 |

## 四张图表

| 图表 | 说明 |
| --- | --- |
| **调用趋势** | 按时间桶展示请求数。哪根柱子高，说明那段时间调用集中 |
| **模型用量** | 按模型堆叠展示用量。排名靠后的模型会合并成「其他模型」 |
| **费用趋势** | 按时间桶展示费用变化，用来找「钱花在哪一段时间」 |
| **模型排行** | 按总调用量排序，取前 **10** 名，逐行列出每个模型的调用量、Token 和费用 |

:::tip 图表怎么配合看
先用 **调用趋势** 找到用量高峰，再用 **模型用量** 看高峰是哪个模型贡献的，最后用 **模型排行** 确认该模型的累计花费。
:::

## 这些数字从哪来

- 看板汇总的是**当前账号**在所选时间范围内的调用记录；换账号登录看到的就是那个账号的数据。
- 费用按调用时使用的**模型价格**折算，所以同一批调用换个模型，费用会不一样。
- 想核对某一次调用，去 [API 密钥](./token.md) 的 **请求日志** 标签页按时间和模型筛选，那里是逐条明细。
- 页面顶部出现红色提示，说明这次拉取数据失败了，点 **刷新数据** 重试。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 所有数字都是 0 | 这段时间确实没有调用，或时间范围选偏了 | 点 **重置筛选** 回到今日，或换一个更宽的范围 |
| 有调用记录，但**总消费** 是 ¥0 | 对应模型没有配置输入/输出价格 | 到 [模型广场](./marketplace.md) 详情里确认价格，或找管理员补全 |
| **模型排行** 里只有几个模型 | 排行只取调用量前 10 名 | 想看全部模型，去 **请求日志** 按模型筛选 |
| 成功率和请求日志的条数对不上 | 两边的时间范围或筛选条件不一致 | 把时间范围对齐后再比较 |
| **模型用量** 和 **模型排行** 提示「当前区间暂无模型调用数据」 | 这个区间没有按模型维度统计到的调用 | 换一个时间范围，或确认这段时间确实调用过模型 |
