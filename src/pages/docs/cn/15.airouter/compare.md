# 模型对比

**模型对比** 让你把**同一条问题同时发给两个模型**，左右并排看它们各自怎么回答。做模型选型、比较不同版本、试验参数效果时，这一页比来回切换有效率得多。

页面固定是左右两栏，所以一次最多只能比两个模型，没有「再加一个」的入口。

:::tip 打个比方
像面试两个候选人：同一道题同时问，把他们答的内容、速度、花销放在一起对照。
:::

## 开始之前

- 已登录账号即可，不需要额外角色。
- 账号下至少要有**一把 API 密钥**（见 [API 密钥](./token.md)）。
- 账号下至少有**一个可用模型**就行：两侧可以选不同的模型，也可以选同一个模型。
- 建议用**宽窗口**操作。窗口偏窄时左侧模型列表会隐藏，模型就选不了了。

## 页面分成三块

| 区域 | 位置 | 说明 |
| --- | --- | --- |
| 模型列表 | 最左侧 | 上下两块，分别是 **左侧模型** 和 **右侧模型** |
| 对话栏 | 中间 | 左、右两栏各自显示一个模型的回答 |
| 共享输入框 | 最底部 | 一个输入框，一条消息同时发给两侧 |

## 选好两个模型

1. 顶部导航点 **模型对比**。
2. 在最左侧上半部分的 **左侧模型** 列表里点一个模型。
3. 在最左侧下半部分的 **右侧模型** 列表里点一个模型。
4. 两侧可以选**不同模型**（比能力），也可以选**同一个模型**（比参数）。

模型列表和 [模型体验](./experience.md) 里的一样，按可见范围 → 渠道 → 模型分组，可以搜索、可以复制模型 ID。

## 确认两侧的密钥

- 每一栏的顶部都有自己的密钥选择器，默认都用账号下的第一把密钥。
- 想换其中一侧的密钥，在那一栏的顶部选择器里改，**不会影响另一侧**。

## 发一条消息

1. 两侧都选好模型后，底部输入框才会亮起，提示语是「输入内容与模型进行对话...」。
2. 输入你的问题，按 **Enter** 或点发送按钮。
3. 同一条消息会**同时**发给两侧，两栏各自流式输出，互不等待。

## 结果怎么看

| 想比较什么 | 怎么看 |
| --- | --- |
| 内容质量 | 左右两栏直接对照，看谁更准确、更完整、更贴题 |
| 响应速度 | 看两栏逐字出现的快慢 |
| 推理过程 | 开着 **深度思考** 时，分别展开两侧的 **查看思考** 对照推理思路 |
| Token 消耗 | 看两栏回答下方的用量数字 |
| 指令遵循 | 在两侧的 **参数配置** 里填同样的 System，比较谁更听话 |

## 哪些是共用的，哪些是各自的

| 配置 | 左栏 | 右栏 |
| --- | --- | --- |
| 模型 | 各自选 | 各自选 |
| API 密钥 | 各自选，默认取第一把 | 各自选，默认取第一把 |
| 对话参数 | 各自设置 | 各自设置 |
| 消息记录 | 各自独立 | 各自独立 |
| 报错与停止 | 各自独立，一侧出错不影响另一侧 | 各自独立 |
| **深度思考** | 共用一个开关 | 共用一个开关 |

对话参数通过每栏顶部的 **参数配置** 图标打开，两侧互不影响。具体每一项怎么填，见 [参数配置](./debug.md)。

## 停下和清空

| 想做的事 | 怎么做 |
| --- | --- |
| 只停一侧 | 点那一栏消息区里的停止图标 |
| 两侧一起停 | 点底部输入框的 **停止** 按钮 |
| 只清空一侧 | 点那一栏顶部的清空图标，悬停提示是 **清空聊天** |
| 重新换模型 | 直接在左侧列表里点另一个模型，那一栏的对话会被清空 |

## 对比的小技巧

1. **一次只改一个变量**。比模型就两边选不同模型、参数保持一致；比参数就两边选同一个模型，只让一侧的 Temperature 或 Top P 不同。
2. 想比同一模型的不同渠道，两侧选同一个模型名下的不同渠道即可。
3. 用同一批业务问题连续测几轮，比只问一句更可靠。

:::warning 刷新就没了
对比记录只保存在当前页面里，刷新或关闭页面后会全部清空。重要结果请先截图或复制走。
:::

## 结果确认

两侧都开始逐字输出回答，就说明这次对比发送成功。只有一侧有反应，通常是那一侧的模型或密钥没选好，检查顶部选择器即可。
