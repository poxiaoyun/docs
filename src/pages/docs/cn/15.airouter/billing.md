# 账户

**账户** 页是聚合网关的「钱包 + 套餐看板」：上面两张卡告诉你**还剩多少余额**、**当前是什么套餐、用了多少额度**；下面是流水，逐笔列出充值和消费。

一个常见困惑先在这里说清：**这一页只负责「看」和「重置额度」，没有充值入口，也没有取消订阅、关闭自动续费、关闭超额扣费的开关。** 这些都要联系管理员。

:::tip 打个比方
像手机营业厅的「我的账户」：余额、当前套餐、本月已用流量都在上面；下面是账单明细。想改套餐或充值，得走另外的流程。
:::

## 开始之前

- 已登录账号即可，不需要额外角色。
- 数据都是**当前登录账号**的；换账号登录看到的就是另一个账号的余额和流水。

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 余额 | 账户里能直接扣的钱。买套餐、超额调用都从这里扣 |
| 当前套餐 | 你现在生效的那一份订阅，显示「商品 · 套餐名」和到期日 |
| 套餐用量 | 套餐里的**点数**还剩多少、总共多少，以及用掉的百分比 |
| 点数 | 套餐的计价单位，**1 点 = 0.01 元** |
| 周额度 | 套餐附带的周期性调用上限，可能有多条（按不同指标算），也可能没有 |
| 额度重置券 | 允许你把周额度已用量清零的次数，来自套餐 |
| 流水 | 每一笔充值、扣费、退款、调整、买套餐的记录 |

## 余额卡怎么看

第一张卡标题是 **余额**，中间的数字就是可用余额（带币种），右上角有一个 **充值** 按钮。

:::warning 充值按钮是灰的
这个按钮目前**不可点**。页面没有自助充值入口，余额不足时请直接联系管理员充值。看到按钮点了没反应，不是坏页，是设计如此。
:::

余额什么时候会被扣：

- 买套餐（见 [订阅](./subscribe.md)）；
- 套餐点数用完、且开了超额扣费时的超额调用；
- 没有套餐、直接按 [价格](./prices.md) 里的单价调用。

## 套餐卡怎么看

第二张卡标题是 **当前套餐**：

| 卡片元素 | 说明 |
| --- | --- |
| 套餐名 | 显示为「商品名 · 套餐名」；名下没有生效订阅时显示 **无套餐** |
| 到期日期 | 形如「到期 2026-11-30」。没有到期日（或根本没套餐）时不显示 |
| **重置套餐** | 按原价重买当前套餐，点数清零重算。见下一节 |
| **剩余额度重置 N 次** | 用一张额度重置券，把周额度已用量清零。N 是当前持有券数 |
| **套餐用量** | 「已用 / 上限 点」，右边是百分比和进度条。没配点数时显示「暂无用量」 |
| **周额度** | 每条额度一行，「已用 / 上限」，右边是百分比和进度条；一条都没有时显示 **无限制** |

「重置套餐」和「剩余额度重置」两个按钮只有在你**有生效中的套餐**时才出现，没套餐时整块只看得到 **无套餐**。

### 重置套餐

1. 在 **当前套餐** 卡片上点 **重置套餐**。
2. 确认弹窗里核对套餐、周期、支付方式、应付金额。
3. 如果还有未用点数，必须勾选「我知道未使用的点数不会退款」。
4. 点 **确认重置 ¥x**。

:::warning 会按原价重扣一次
重置 = 再买一份当前套餐，不是免费续期。旧点数立刻清零且**不退款**。只是想让额度回到满值、且旧点数本来也用不完时，才值得这么做。
:::

### 剩余额度重置 N 次

这个按钮消耗的是**额度重置券**，跟钱和点数都无关：

1. 点 **剩余额度重置 N 次**。
2. 弹窗标题是 **重置周额度**，中间提示：「确认后会扣掉 1 次额度重置券，并清零当前额度计划的已用量。套餐点数和账户余额不变。」
3. 点 **确认重置**。

按钮不可点时，通常是下面某一条不满足：

- 当前订阅状态不是**生效中**；
- 手上**没有**可用的额度重置券（N 为 0）；
- 周额度不是**恰好一条**（有多条时无法判断清哪一条）；
- 订阅**已到期**。

:::tip 什么时候用得上
周额度是「按周期自动恢复」的上限。急着继续调用、又不想等到周期结束，就用券手动清零。券是用一张少一张，先确认真正需要再用。
:::

## 流水怎么看

下面有两个标签页：

| 标签页 | 收录哪些类型 |
| --- | --- |
| **充值流水** | **充值**、**退款**、**调整** |
| **消费流水** | **扣费**、**购买套餐** |

两个标签页的列完全一样：

| 列 | 说明 |
| --- | --- |
| **时间** | 这笔账发生的时间 |
| **类型** | **扣费** / **充值** / **退款** / **调整** / **购买套餐** |
| **金额** | 带正负号。**充值流水**里显示 `+`，**消费流水**里显示 `-`，一眼能看出钱是进来还是出去 |
| **余额** | 这笔账发生后的余额 |
| **说明** | 这笔账的由来，超过 36 个字会截断，鼠标悬停看全文 |
| **请求ID** | 关联的请求编号，用来和 [API 密钥](./token.md) 的 **请求日志** 对账 |

:::info 对不上账时
拿 **请求ID** 去 **请求日志** 里搜同一条，两边的时间、模型、费用就能对上。找不到对应请求时，多半是充值、退款、调整这类与调用无关的账。
:::

## 为什么对话突然报错

| 页面/对话里的提示 | 真正的原因 | 去哪里解决 |
| --- | --- | --- |
| 余额不足，请求被拒绝。 | 余额扣不动了 | 本页看余额；充值找管理员；或去 [订阅](./subscribe.md) 买套餐 |
| 套餐点数已用完。 | 点数用完，且没开超额扣费 | 去 [订阅](./subscribe.md) 买新套餐；或请管理员开启超额扣费 |
| 当前模型不在套餐覆盖范围内。 | 这个模型不在这份套餐里 | 换模型；或请管理员开启超额扣费按余额计费 |
| 周额度已用完，将于某时间重置。 | 周额度到上限 | 等提示里的时间；急用可用 **剩余额度重置**（有券时） |
| 账户已冻结或停用，请联系管理员。 | 账户状态异常 | 只能联系管理员 |

:::warning 本页不能改计费开关
自动续费和超额扣费都是**下单时**在确认弹窗里设定的，本页没有对应的开关，也没有取消订阅的入口。要改请找管理员。
:::
