# 模型体验

**模型体验** 是聚合网关的主对话页。你在这一页挑一个模型，输入问题，就能看到它一个字一个字地写出回答。选模型、上传图片、开关深度思考、调参数，全部在这一页完成。

入口在顶部导航的 **模型对话** 下拉里：点 **模型对话** → **模型体验**。

:::tip 打个比方
这一页就像聊天软件的对话框：左边是「联系人列表」（模型列表），中间是聊天记录，底下是输入框。
:::

## 开始之前

- 已登录账号即可，不需要额外角色。
- 账号下至少要有**一个 API 密钥**，否则整页只会显示「未找到 API 密钥」，点里面的 **创建 API 密钥** 先去建一个（见 [API 密钥](./token.md)）。
- 账号下至少要有**一个可用模型**，否则显示「暂无可用模型」。
- 左侧列表只收**对话类、且已定价**的模型。生图、视频、语音、嵌入、重排序类模型，以及还没有配价格的模型，都不会出现在这里。
- 建议用**宽窗口**。窗口较窄时左侧模型列表会隐藏，右侧信息面板（模型信息 / 参数设置）也会收起，改用对话区顶部的图标。

## 页面分成三块

| 区域 | 位置 | 说明 |
| --- | --- | --- |
| **模型列表** | 左侧 | 三层折叠列表：可见范围 → 模型 → 渠道 |
| 对话区 | 中间 | 顶部信息栏 + 消息列表 + 底部输入框 |
| **模型信息** / **参数设置** | 右侧 | 窗口足够宽（`1536px` 以上）才显示；窗口窄时右侧收起，改为在对话区顶部用图标打开 |

![模型体验未选模型时的界面：左侧模型列表、中间四张提问卡片、底部输入框](/assets/screenshots/airouter/experience-01.png)

刚进来时是这样：左侧 **模型列表** 只展开「公开」分组，中间标题是「从一个问题开始」、副标题是「请选择模型」，四张提问卡片是灰的（选好模型后才能点）。注意截图里没有右侧面板——窗口宽度不到 `1536px` 时右侧会收起。

## 选一个模型

1. 顶部导航点 **模型对话** → **模型体验**。
2. 看左侧 **模型列表**。它分三层：第一层是**可见范围**（**公开** / **内部** / **私有**），第二层是**模型**（后面跟着这个模型的渠道数量），第三层是**渠道**。点前两层可以展开或收起。
3. 模型多于 5 个时，列表顶部会出现 **搜索模型** 输入框，可以按模型 ID、租户、工作空间、渠道、提供者搜索。
4. 点**渠道**条目（显示为「供应商：渠道名」）即完成选中。选中后条目会加框高亮。
5. 同一个模型有多个渠道时，各渠道是独立可选条目——它们的价格和可用性可能不同。

:::warning 选模型会清空当前对话
只要切换模型，当前聊天记录就会被清空。需要保留的内容先复制走。
:::

![选中 deepseek-v4-flash 后的模型体验：右侧对话区出现模型名、密钥选择器与清除对话按钮](/assets/screenshots/airouter/experience-02.png)

选中模型后界面就活了：左侧条目被框住；中间顶部出现模型 ID 和「提供者 · 渠道」，右侧出现 **密钥选择器** 与 **清除对话**；中间提示改成「正在使用 deepseek-v4-flash，输入内容即可开始对话」。

:::info 想看模型更多信息
类型、可见范围、所属租户、工作空间、任务、创建时间，都在右侧 **模型信息** 面板里（窗口够宽时才显示）。
:::

## 确认用的是哪把密钥

对话是用 **API 密钥** 的身份发出的，所以发送前要确认当前选中的密钥没有问题。

- 窗口较窄时：在对话区顶部的密钥选择器里点开，挑一把密钥。
- 窗口较宽时：右侧 **参数设置** 面板里顶部那个 **API 密钥 / 访问凭证** 下拉框是同一个设置。
- 默认会自动选中账号下的第一把**可用**密钥。
- 下拉列表里**已过期**的密钥会标上 `Expired`，**已禁用**的密钥会置灰——这两种都不可选，换一把。
- 密钥值不会明文展示，页面上显示的是「前 8 位…后 4 位」。

![点开对话区顶部的密钥选择器，下拉里列出账号下的两把密钥](/assets/screenshots/airouter/experience-03.png)

上图是密钥选择器展开的样子：每一条给出密钥名称和一段打码后的值。截图里能选的有 `link` 与 `test` 两把，当前选中的那把会高亮。密钥值截图已做模糊处理。

## 开始一次对话

1. 选好模型和密钥后，看底部输入框，提示语是「输入内容与模型进行对话...」。
2. 输入你的问题。
3. 按 **Enter** 发送，或者点右下角的圆形发送按钮。
4. 回答会逐字流式出现。
5. 想换行就按 **Shift + Enter**（用中文输入法时，拼音还没选完的 Enter 不会误发）。

没选模型、或者输入框是空的，发送按钮会是灰色不可点。

![一次完整的对话：上方是提问气泡，助手回答里先折叠了思考过程，回答下方是 Token 用量](/assets/screenshots/airouter/experience-04.png)

一次完整对话的样子如上：右侧是你说的话，左侧助手气泡里先是一行 **隐藏思考**（推理过程，可展开），接着才是正文，最下面一行是这次用掉的 Token 数。多轮追问时这些内容会一起发给模型。

## 接着追问（多轮对话）

不用重新开始，直接在同一个输入框里继续输入、继续按 **Enter** 就行。前面的聊天记录会一起发给模型，所以它能接着上文回答。

只有两种情况会打断上下文：**切换模型**，以及点 **清除对话**。

## 预览模型生成的网页

如果模型的回答是一段可以直接打开的网页代码，回答里会出现预览入口。点它之后，对话区右侧会打开一块 **预览** 面板：

| 按钮 | 作用 |
| --- | --- |
| 全屏 | 把预览铺满整个窗口，适合看完整页面效果 |
| 关闭 | 收起预览，回到正常对话宽度 |

:::tip 什么时候会用上
让模型「写一个能直接打开的小页面」时最有用：不用把代码复制到本地另存文件，直接在预览里看效果、点按钮、看排版。预览只渲染模型输出的内容，不影响你的账号和其他页面。
:::

## 改系统提示词（给模型定人设）

系统提示词就是对话开始前给模型立的规矩，例如「你是一个AI助手」。它**只在填了内容时才生效**。

1. 点对话区顶部的调参图标（悬停提示 **参数配置**）打开参数弹窗。
   - 窗口足够宽时，也可以直接在右侧 **参数设置** 面板里操作：点 **更多参数** 展开。
2. 在多行的 **System** 输入框里写内容，例如「你是客服助手，回答不超过三句话」。
3. 关掉弹窗即可，改动会立刻记住。
4. 改完后发送的新消息才会按新规矩回答，已经发出的消息不受影响。

每个参数具体管什么，见 [参数配置](./debug.md)。

## 把图片发给模型

输入框只支持发**文字和图片**，没有语音、视频的上传入口，也**没有联网搜索**。

1. 点输入框底部工具栏里最左边那个图片按钮（悬停提示 **上传图片**）。
2. 选择一张或多张图片；也可以直接把剪贴板里的图片粘贴进输入框。
3. 选中的图片会以缩略图排在输入框上方，并显示「已选 N 张图片」。
4. 想删掉某张，点缩略图右上角的关闭图标。
5. 正常按 **Enter** 发送即可，图片会跟着这条消息一起发给模型。

要能看懂图片，需要选**类别**里带 **视觉** 的模型（在 [模型广场](./marketplace.md) 可以看到）。

## 深度思考

输入框工具栏上的 **深度思考** 按钮默认是**开启**的。开启时按钮是实心状态，模型会先把推理过程想一遍再给结论；模型支持的话，回复里会出现一段思考内容，可以点 **查看思考** / **隐藏思考** 折叠展开。

再点一下按钮就关闭，按钮变成描边状态。深度思考会让回答更稳，但也会**消耗更多 Token**。

## 生成中想停下、想重来

| 想做的事 | 怎么做 |
| --- | --- |
| 停止生成 | 点输入框区域的 **停止** 按钮；已经生成出来的内容会保留 |
| 让模型重答这一条 | 点这条回答下方的重试图标。会从这条回答重新生成，它之后的内容不再保留 |
| 复制回答 | 点回答下方的复制按钮 |
| 看这次用了多少 Token | 看这条回答下方的用量，依次是输入 Token、输出 Token 和合计 |

## 清除对话

1. 确认已选中模型，对话区右上角会出现 **清除对话** 按钮。
2. 点它，当前消息列表、思考内容都会被清空，模型和参数保持不变，可以重新开始。

## 刚进来时没有消息

页面会显示「从一个问题开始」，并给出 4 张现成的提问卡片（解释一个概念、制定实施方案、分析关键问题、生成项目模板）。选好模型后点任一卡片，会直接把卡片里的问题发出去。

## 结果确认

- 成功：助手气泡里出现回答，回答下方多出一行 Token 用量数字。
- 失败：消息位置显示「生成失败」或一段错误提示。对照下表处理。

## 常见问题

### 模型和密钥

| 页面提示 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 未找到 API 密钥 | 账号下还没有密钥 | 点提示里的 **创建 API 密钥** 建一个 |
| 暂无可用模型 | 当前账号没有任何模型渠道 | 联系平台管理员为你开通模型 |
| 无效的 API 密钥 | 密钥被删除、被禁用或已过期 | 到 [API 密钥](./token.md) 确认状态，换一把有效的 |
| 该模型尚未定价，请联系管理员。 | 这个模型还没配价格，不能用来对话 | 换一个模型；或找管理员在运营平台配价 |
| 选不到某个模型 | 它不是对话类模型，或还没有定价 | 在 [模型广场](./marketplace.md) 看它属于什么类型 |

### 限流与内容策略

| 页面提示 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 请求过于频繁，请稍后再试 | 触发了速率限制（令牌或通道的 RPM / TPM 用完） | 等一会儿再发，或降低发送频率 |
| 上下文长度超出限制 | 聊天内容超过了模型能记住的长度 | 点 **清除对话** 重新开始，或换上下文更大的模型 |
| 请求因触发内容审查或安全策略被拦截 | 内容命中安全策略 | 换一种问法，去掉可能违规的内容 |
| 模型因命中敏感内容策略提前结束了回复 | 回复中途被策略中断 | 改问法后重试；回复里可能带上游请求 ID，排查时提供给管理员 |
| 生成中突然没有反应 | 网络抖动或连接被中断 | 点 **停止**，再重试这条消息 |

### 余额与套餐（这类错误与参数无关）

| 页面提示 | 意思 | 怎么办 |
| --- | --- | --- |
| 余额不足，请求被拒绝。可以购买套餐或开启超额扣费；充值请联系管理员。 | 余额扣不动了 | 到 [账户](./billing.md) 看余额；买套餐见 [订阅](./subscribe.md)；充值找管理员 |
| 账户已冻结或停用，请联系管理员。 | 账户状态异常 | 只能联系管理员处理 |
| 套餐点数已用完。开启超额扣费后可继续使用，超出部分从余额扣。 | 点数用完，且没开超额扣费 | 买新套餐，或请管理员开启超额扣费 |
| 当前模型不在套餐覆盖范围内。开启超额扣费后可继续使用。 | 这个模型不在这份套餐里 | 换模型，或开启超额扣费按余额计费 |
| 周额度已用完，将于某时间重置。也可联系管理员。 | 周额度到上限了 | 等提示里的时间重置；急用请联系管理员或购买更高档套餐 |

:::info 报错后面那串 ID 是干什么的
多数错误提示末尾会追加「(上游请求 ID: xxx)」。这是模型服务方给这次请求编的号，找管理员排查时把它一起提供过去，对方能直接定位。
:::
