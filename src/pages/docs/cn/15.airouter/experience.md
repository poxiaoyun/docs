# 模型体验

**模型体验** 是 AIRouter 的主对话页。你在这一页挑一个模型，输入问题，就能看到它一个字一个字地写出回答。选模型、上传图片、开关深度思考、调整参数，全部在这一页完成。

:::tip 打个比方
这一页就像聊天软件的对话框：左边是「联系人列表」（模型列表），中间是聊天记录，底下是输入框。
:::

## 开始之前

- 已登录账号即可，不需要额外角色。
- 账号下至少要有**一个 API 密钥**，否则整页只会显示「未找到 API 密钥」，点里面的 **创建 API 密钥** 先去建一个（见 [API 密钥](./token.md)）。
- 账号下至少要有**一个可用模型**，否则显示「暂无可用模型」。

## 页面分成三块

| 区域 | 位置 | 说明 |
| --- | --- | --- |
| **模型列表** | 左侧 | 按可见范围 → 渠道 → 模型分组的折叠列表 |
| 对话区 | 中间 | 顶部信息栏 + 消息列表 + 底部输入框 |
| **模型信息** / **参数设置** | 右侧 | 只有窗口足够宽时才显示；窗口窄时右侧收起，改为在对话区顶部用图标打开 |

## 选一个模型

1. 顶部导航点 **模型体验**。
2. 看左侧 **模型列表**。它按 **公开** → **个人** → **租户内** 分组，每组下再按渠道分组，最后才是模型条目；点分组标题可以展开或收起。
3. 模型多于 5 个时，列表顶部会出现 **搜索模型** 输入框，可以按模型名、租户、工作空间、渠道、提供商搜索。
4. 点模型条目即可选中。条目上会显示类型（`LLM`、`VLM`、`Embedding`）、可见范围，以及所属租户和工作空间；名称旁的复制按钮可以复制模型 ID。

:::warning 选模型会清空当前对话
只要切换模型，当前聊天记录就会被清空。需要保留的内容先复制走。
:::

## 确认用的是哪把密钥

对话是用 **API 密钥** 的身份发出的，所以发送前要确认当前选中的密钥没有问题。

- 窗口较窄时：在对话区顶部的密钥选择器里点开，挑一把密钥。
- 窗口较宽时：右侧 **参数设置** 面板里的 **API 密钥 / 访问凭证** 下拉框就是同一个设置。
- 默认会自动选中账号下的第一把密钥。下拉列表里已过期的密钥会标上 `Expired`，不要选它。

## 开始一次对话

1. 选好模型和密钥后，看底部输入框，提示语是「输入内容与模型进行对话...」。
2. 输入你的问题。
3. 按 **Enter** 发送，或者点右下角的圆形发送按钮。
4. 回答会逐字流式出现。
5. 想换行就按 **Shift + Enter**（用中文输入法时，拼音还没选完的 Enter 不会误发）。

没选模型、或者输入框是空的，发送按钮会是灰色不可点。

## 接着追问（多轮对话）

不用重新开始，直接在同一个输入框里继续输入、继续按 **Enter** 就行。前面的聊天记录会一起发给模型，所以它能接着上文回答。

只有两种情况会打断上下文：**切换模型**，以及点 **清除对话**。

## 改系统提示词（给模型定人设）

系统提示词就是对话开始前给模型立的规矩，例如「你是一个AI助手」。它**只在填了内容时才生效**。

1. 点对话区顶部的调参图标（悬停提示 **参数配置**）打开参数弹窗。
   - 窗口足够宽时，也可以直接在右侧 **参数设置** 面板里操作：点 **更多参数** 展开。
2. 在多行的 **System** 输入框里写内容，例如「你是客服助手，回答不超过三句话」。
3. 关掉弹窗即可，改动会立刻记住。
4. 改完后发送的新消息才会按新规矩回答，已经发出的消息不受影响。

## 把图片发给模型

1. 点输入框工具栏上的图片按钮（悬停提示 **上传图片**）。
2. 选择一张或多张图片；也可以直接把剪贴板里的图片粘贴进输入框。
3. 选中的图片会以缩略图排在输入框上方，并显示「已选 N 张图片」。
4. 想删掉某张，点缩略图右上角的关闭图标。
5. 正常按 **Enter** 发送即可，图片会跟着这条消息一起发给模型。

要能看懂图片，需要选**类别**里带 **视觉** 的模型（在 [模型广场](./marketplace.md) 可以看到）。

## 深度思考

输入框工具栏上的 **深度思考** 按钮默认是**开启**的。开启时按钮是实心状态，模型会先把推理过程想一遍再给结论；模型支持的话，回复里会出现一段思考内容，可以点 **查看思考** / **隐藏思考** 折叠展开。

再点一下按钮就关闭，按钮变成描边状态。深度思考会让回答更稳，但也会**消耗更多 Token**。

## 生成中想停下、想重来

| 想做的事 | 怎么做 |
| --- | --- |
| 停止生成 | 点输入框区域的 **停止** 按钮；已经生成出来的内容会保留 |
| 让模型重答这一条 | 点这条回答下方的刷新图标。会从这条回答重新生成，它之后的内容不再保留 |
| 复制回答 | 点回答下方的复制按钮 |
| 看这次用了多少 Token | 看这条回答下方的用量，依次是 `prompt_tokens`（发出去的输入）、`completion_tokens`（模型生成的输出）、`total_tokens`（合计） |

## 清除对话

1. 确认已选中模型，对话区右上角会出现 **清除对话** 按钮。
2. 点它，当前消息列表、思考内容都会被清空，模型和参数保持不变，可以重新开始。

## 刚进来时没有消息

页面会显示「从一个问题开始」，并给出 4 张现成的提问卡片（解释一个概念、制定实施方案、分析关键问题、生成项目模板）。选好模型后点任一卡片，会直接把卡片里的问题发出去。

## 结果确认

- 成功：助手气泡里出现回答，回答下方多出一行 Token 用量数字。
- 失败：消息位置显示错误提示或「生成失败」。对照下表处理。

## 常见问题

| 页面提示 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 未找到 API 密钥 | 账号下还没有密钥 | 点提示里的 **创建 API 密钥** 建一个 |
| 暂无可用模型 | 当前账号没有任何模型渠道 | 联系平台管理员为你开通模型 |
| 无效的 API 密钥 | 密钥被删除或已过期 | 到 [API 密钥](./token.md) 确认状态，换一把有效的 |
| 请求过于频繁，请稍后再试 | 触发了速率限制 | 等一会儿再发，或调低发送频率 |
| 配额不足 | 账号额度用尽 | 联系管理员处理额度 |
| 上下文长度超出限制 | 聊天内容超过了模型能记住的长度 | 点 **清除对话** 重新开始，或换上下文更大的模型 |
| 请求因触发内容审查或安全策略被拦截 | 内容命中安全策略 | 换一种问法，去掉可能违规的内容 |
| 模型因命中敏感内容策略提前结束了回复 | 回复中途被策略中断 | 改问法后重试；回复上方可能带上游请求 ID，排查时提供给管理员 |
| 生成中突然没有反应 | 网络抖动或连接被中断 | 点 **停止**，再重试这条消息 |
