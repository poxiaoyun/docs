# Rune 智算平台

Rune 是一个把「准备模型和数据 → 训练调优 → 部署成服务 → 交付给团队使用」串在一起的 AI 工作台。
登录后你只需要一个浏览器：左侧是功能菜单，顶部有两个下拉框——**区域**（用哪个机房）和**工作空间**（用哪间办公室）。
平台上可创建的东西统称「实例」，创建方式完全一样：选一个模板、填几个参数、点确定。
读完这页，你会知道每个菜单能帮你做什么，以及作为新手第一步该点哪里。

:::tip 一句话理解 Rune
把 Rune 想成一家 AI 工厂：区域是厂区，工作空间是车间，模板是标准作业指导书，
实例就是你按指导书开动起来的一条生产线。
:::

## 左侧菜单总览

按左侧菜单从上到下的真实顺序：

| 菜单项 | 能帮你做什么 | 点进去看哪篇文档 |
| --- | --- | --- |
| **首页** | 一眼看清当前工作空间有多少实例、用了多少资源、有没有异常 | [Rune 控制台首页](/rune/console/dashboard) |
| **应用市场** | 浏览平台提供的全部模板，挑一个直接部署 | [应用市场](/rune/console/app-market) |
| **工作台 → 推理服务** | 把模型变成别人能调用的服务 | [推理服务](/rune/console/inference)、[从零跑通一次推理](/rune/guide/inference) |
| **工作台 → 训练与微调** | 拿现成模型再用自己的数据训练，让它更懂你的业务 | [训练与微调](/rune/console/finetune) |
| **工作台 → 开发服务** | 开一台带加速卡的在线开发环境（SSH / VSCode / 远程桌面） | [开发服务](/rune/console/devenv) |
| **工作台 → 应用实例** | 部署通用应用，例如自己的 Web 服务 | [应用实例](/rune/console/app) |
| **工作台 → 我的模板** | 把调好的一套配置存成模板，下次一键复用 | [我的模板](/rune/resources/templates) |
| **工作台 → 文件存储** | 建一块可反复使用的网络硬盘，放模型文件、数据集 | [文件存储](/rune/console/storage) |
| **可观测性 → 指标** | 部署实验跟踪服务，记录和对比训练数据 | [指标](/rune/console/experiment) |
| **可观测性 → 日志** | 按时间和关键词查实例的运行日志 | [日志](/rune/console/logging) |
| **可观测性 → 模型评测** | 部署评测服务，给模型打分 | [模型评测](/rune/console/evaluation) |

:::info 有些菜单你可能看不到
**工作台**和**可观测性**这两组菜单只对租户的**管理员**和**开发者**显示。
如果你登录后只能看到「首页」和「应用市场」，说明你的角色是普通成员，需要联系租户管理员调整权限。
:::

## 新手第一步

1. 先读[开始之前](/rune/guide/prerequisites)，确认账号、角色、区域、工作空间都准备好了。
2. 再读[创建工作负载](/rune/guide/workloads)，搞清几种工作负载分别是什么、你该选哪个。
3. 最后照着[从零跑通一次推理](/rune/guide/inference)做一遍，亲手把一个模型跑成服务。

## 三个绕不开的上下文

| 名词 | 通俗解释 |
| --- | --- |
| 租户 | 你所在公司的独立账号空间，和别的公司互相看不到 |
| 区域 | 一栋机房大楼，选它就等于选了用哪里的机器 |
| 工作空间 | 大楼里的一间办公室，同办公室的人共享里面的实例和文件 |
| 实例 | 你实际创建出来的「机器」，推理服务、微调任务、开发环境都算 |
