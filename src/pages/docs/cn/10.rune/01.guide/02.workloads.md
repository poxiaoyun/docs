# 创建工作负载

在 Rune 里创建出来的东西统称**实例**，也可以叫「工作负载」。
推理服务、训练与微调、开发服务、应用实例、指标、模型评测都是实例，区别只在于你选的模板不同。
好消息是：**它们共用同一套创建流程**——选模板 → 填基本信息 → 填参数 → 点确定。

:::tip 类比
模板像一份标准作业指导书，实例是你照着指导书开动起来的一条生产线。
指导书不同，产出的东西不同；但「翻开指导书、照着填、按启动键」这个动作完全一样。
:::

## 核心概念

| 名词 | 准确解释 | 可以理解成 |
| --- | --- | --- |
| 实例 | 平台里可创建对象的总称，一个实例就是一份跑在集群上的工作负载 | 一台开起来的「机器」 |
| 模板 | 预先写好的部署方案，决定实例长什么样、要填哪些参数 | 一份标准作业指导书 |
| 版本 | 同一个模板的不同修订，参数可能不一样，创建前要选清楚 | 指导书的第几版 |
| 规格 | 实例能用的 CPU、内存、加速卡数量 | 这台机器配的发动机有多大 |
| 副本数 | 同一个实例同时运行几份 | 同样的机器同时开几台 |
| 参数 | 模板要求你填的详细配置，例如用哪个模型、挂哪块存储卷 | 指导书上的必填栏位 |

## 我想做的事 → 该用哪个功能

| 我想做的事 | 用哪个菜单 | 界面上的创建按钮 |
| --- | --- | --- |
| 把模型变成别人能调用的接口 | **工作台 → 推理服务** | **创建推理服务** |
| 用自己的数据把模型再训练一遍 | **工作台 → 训练与微调** | **创建训练与微调任务** |
| 要一台带加速卡的在线环境写代码、调试 | **工作台 → 开发服务** | **创建开发服务** |
| 部署自己的 Web 应用或其他服务 | **工作台 → 应用实例** | **创建应用实例** |
| 记录和对比训练实验数据 | **可观测性 → 指标** | **创建指标** |
| 给模型跑评测、打分 | **可观测性 → 模型评测** | **创建模型评测** |
| 不知道选哪个 | **应用市场** | 浏览全部模板，按分类找 |

:::info 几种工作负载有什么区别
- **推理服务**：模型部署好后对外提供调用地址，关注「能不能被访问」。
- **训练与微调**：跑一次训练任务，关注「训练过程和结果」。
- **开发服务**：一台能登录进去的开发机（支持 SSH、VSCode、远程桌面），关注「能不能连上去写代码」。
- **应用实例**：部署通用应用，是上面几种之外的兜底选项。
- **指标 / 模型评测**：配套工具类服务，用来跟踪实验和给模型打分。
:::

## 创建步骤

不同功能的入口不一样，但流程完全一致。

1. 先确认左上角**区域**和**工作空间**已经选好（见[开始之前](/rune/guide/prerequisites)）。
2. 左侧菜单点击你要创建的类型，例如 **推理服务**。
3. 点击页面右上角的创建按钮，例如 **创建推理服务**。其他类型同理：训练与微调是 **创建训练与微调任务**，开发服务是 **创建开发服务**，应用实例是 **创建应用实例**。
4. 进入模板列表后，找到想要的模板卡片，点击卡片上的 **部署**。
5. 确认 **版本**：页面右上角有「版本: xxx」按钮，点开可以切换；不切换就用最新版本。
6. 填写**基础信息**：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 名称 | 例如 `my-first-service` | 必填，以后列表里显示的就是它 |
   | ID | 不用手动填 | 跟着「名称」自动生成，显示在名称输入框下方；确实要改就点旁边的铅笔图标 |
   | 描述 | 例如 `测试用推理服务` | 选填，只给人看 |

7. 填写**参数配置**：表单由模板自动生成，不同模板字段不同。参数卡片右上角的代码图标可以在**表单模式**和 **JSON 模式**之间来回切换，只有确定要手写参数时才用 JSON 模式。
8. 点击页面底部的 **确定** 提交。

:::warning JSON 模式写错就不能提交
切到 JSON 模式后，如果内容不是合法的 JSON 格式，页面会标红并禁止提交。
改动前建议先切回表单模式看一眼，或先留一份原始参数。
:::

## 结果确认

提交成功后，页面会回到对应类型的实例列表：

1. 列表里出现刚创建的实例，名称就是你填的名称。
2. 「状态」列先显示**执行中**或**状态同步中**，表示正在创建；等它变成**健康**或**运行中**就表示成功了。
3. 点击名称进入详情页，可以看**概览 / 监控 / 日志 / 事件**四个页签。

常见状态含义：

| 状态 | 意思 |
| --- | --- |
| 执行中 / 状态同步中 | 正在创建或更新，等着就行 |
| 等待中 | 正在排队等资源 |
| 健康 / 运行中 | 正常可用 |
| 已暂停 | 被你手动停掉了，可以再启动 |
| 处理失败 | 创建失败，进详情页看**事件**找原因 |
| 删除中 | 正在删除 |

## 常用操作

| 操作 | 在哪里点 |
| --- | --- |
| 启动 / 停止 | 列表里这一行最右侧的 **⋮** 图标，或详情页右上角的 **操作** 按钮 |
| 编辑 | **⋮** 菜单里的**编辑**，可改参数，改完同样点 **确定** |
| 扩缩容 | 详情页右上角 **操作** 按钮里的**扩缩容**，调整副本数；只有带副本数的实例才有这一项 |
| 删除 | **⋮** 菜单里的**删除**，需要二次确认 |

:::warning 删除不可恢复
点**删除**会弹出确认窗口，里面写明要删的实例和后果；确认后实例被移除、占用的资源被释放，**无法恢复**。
实例里没存到存储卷上的临时数据会一起消失，请先确认重要文件已经放进存储卷。
:::
