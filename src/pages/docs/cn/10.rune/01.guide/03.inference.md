# 推理托管

这篇文档带你**从零跑通一次推理**：选一个模板，把模型部署成推理服务，再把它发布到网关，让别人也能调用。
全程在页面上点鼠标，不需要写代码，也不需要命令行。

:::tip 推理服务是什么
把模型想成一位专家。模型文件是他待在家里的状态，推理服务就是给他开一间办公室并挂上招牌——
别人拿着地址就能来提问。发布到网关，相当于把招牌挂到公司大堂，外部的人也能找到。
:::

## 核心概念

| 名词 | 准确解释 | 可以理解成 |
| --- | --- | --- |
| 推理服务 | 用某个推理框架把模型加载起来、对外提供调用地址的一个实例 | 给专家开一间办公室并挂上招牌 |
| 模板 | 预置的部署方案，决定用哪个推理框架、要填哪些参数 | 一份标准的装修图纸 |
| 端点 | 服务对外暴露的访问地址，调用方通过它发起请求 | 办公室的门牌号 |
| 发布服务 | 把这个地址登记到平台网关，让其他用户或系统也能调用 | 把门牌号挂到公司大堂的导览牌上 |
| 可见性 | 谁能访问：公开（所有人）/ 租户内可见（本租户）/ 私有（仅自己） | 门禁卡的权限范围 |

## 开始之前

- 你的租户角色需要是**管理员**或**开发者**，否则左侧看不到「工作台 → 推理服务」。
- 左上角**区域**和**工作空间**已经选好（见[环境准备](/rune/guide/prerequisites)）。
- 当前工作空间还有可用的加速卡配额。
- 应用市场里能看到「推理」分类的模板。

## 步骤一：创建推理服务

1. 左侧菜单点击 **工作台 → 推理服务**。
2. 点击右上角的 **创建推理服务**，进入模板列表。
3. 在模板列表里找到想要的模板卡片，点击卡片上的 **部署**。
4. 进入部署页后，先看右上角的 **版本**——默认是最新版本，点开可以更换。新手保持默认即可。
5. 填写**基础信息**：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 名称 | 例如 `qwen-demo` | 必填，也是列表里显示的名字 |
   | ID | 不用填 | 跟着名称自动生成，显示在名称下方；要改就点旁边的铅笔图标 |
   | 描述 | 例如 `体验用推理服务` | 选填 |

6. 在**参数配置**区按模板要求填写，常见的有：

   | 参数 | 说明 |
   | --- | --- |
   | 模型 | 要部署的模型，通常从平台模型库或存储卷里选 |
   | 规格 | 这台服务配多少 CPU、内存、加速卡，从可用规格里选 |
   | 副本数 | 同时跑几份，越多并发越高、占用资源也越多 |

7. 点击页面底部的 **确定** 提交。

:::warning 参数以页面为准
不同模板的参数字段不完全一样，上面列的只是常见项。页面上没有出现的字段，就是这个模板不需要填。
:::

## 步骤二：确认服务跑起来了

1. 回到左侧 **工作台 → 推理服务**，列表里能看到刚创建的服务。
2. 看「运行状态」列：先是**状态同步中**，等变成**健康**就说明服务起来了。
3. 如果一直停在**等待中**，多半是在排队等资源；如果显示**处理失败**，点服务名称进入详情，在**事件**页签里看原因。
4. 在**访问入口**列能看到服务地址；点名称进入详情，在**概览**页签里能看到更完整的端点信息。

:::info 必须先跑起来才能发布
服务状态是**健康**（或**已安装**）时，「发布服务」菜单才可点击；否则这一项会置灰，鼠标移上去提示「实例必须处于运行状态才能发布服务」。
:::

## 步骤三：发布到网关

1. 在推理服务列表里找到刚创建的服务，在这一行的「操作」列点 **⋮** 图标。
2. 点击 **发布服务**。
3. 在弹出的窗口里填写：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 端点 | 默认已自动填好第一个端点 | 必填，且必须是合法地址；下拉里能选这个服务的其他端点，也可以手动输入 |
   | 可见性 | 默认 **私有** | 可选**公开**（所有人可调用）、**租户内可见**（本租户内可用）、**私有**（仅自己） |
   | 推理引擎 | 默认 `openai` | 下拉里只有 `openai` 和 `vllm` 两个值 |
   | 适配器 | 一般不用填 | 点 **创建适配器** 新增一条，每条要填**适配器名称**和**适配器路径**；不要的点 **移除** |

4. 点击 **确认**。

:::tip 端点下拉是空的怎么办
窗口里会提示「无可用端点？可能是服务未成功启动或实例未配置端点。」这时先回列表确认状态是**健康**，再回来重试；也可以手动把地址填进去。
:::

## 结果确认

发布成功后，回到推理服务列表：

1. **访问入口**列里，网关状态会从**未注册网关**变成**运行中**，旁边显示你选的可见性。
2. 再点这一行的 **⋮** 图标，原来的**发布服务**会变成**网关配置**，说明已经注册成功，之后可以随时回来改配置。
3. 调用方拿「访问入口」列里的地址就能访问这个模型。

## 取消发布

已经发布过的服务，在「操作」列点 **⋮** 图标，会多出一项**取消发布**，点它就能把服务从网关移除。

:::warning 取消后别人就调不到了
确认时页面上会提示「取消发布后，用户不能通过模型网关访问模型！」。
服务实例本身还在，但外部调用会失败；需要时重新发布即可。
:::

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 模板列表里没有可选模板 | 这个分类下暂时没有可用模板 | 去**应用市场**看「推理」分类，或联系管理员 |
| 状态一直是**等待中** | 资源不够或在排队 | 检查工作空间配额，或联系管理员扩容 |
| 状态是**处理失败** | 参数填错或镜像问题 | 进详情页看**事件**和**日志** |
| **发布服务**是灰的 | 实例还没到**健康** | 等服务健康后重试 |
| 发布时提示端点为必填 | 服务还没产生可用端点 | 确认服务已健康；端点通常会自动带出，也可手动填 |
