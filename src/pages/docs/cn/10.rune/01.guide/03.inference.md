# 推理托管

推理服务的类型标识是 `category=inference`。它和别的工作负载一样，先由模板 + Schema 表单部署成实例；在此之上，推理实例多了一项**网关注册**能力：把实例的某个端点注册到平台网关，供其他用户或系统调用。

> ⚠️ 注意: 旧版本文档中出现的 TLS 证书上传、域名绑定、灰度发布、QPS 限流、熔断重试、公网/内网出口等能力，在当前 Console 代码里并不存在，已按实际实现移除。

## 前置条件

- 已有状态为 `Healthy` 或 `Installed` 的推理实例。代码判断为 `instanceStatus === 'Healthy' || 'Installed'` 时允许发布；不满足时菜单项会置灰并提示「实例必须处于运行状态才能发布服务」。
- 该实例的 `status.endpoints` 中至少有一个可用端点 URL。

## 注册入口

| 位置 | 操作 |
| --- | --- |
| 推理服务列表 → 行操作菜单 | 「发布服务」（未注册）或「网关配置」（已注册） |
| 推理服务详情 → 右上角「操作」菜单 | 同上 |

注册与注销都会在实例暂停/恢复、删除时联动：实例暂停会同步把注册记录的 `paused` 置为对应值，实例删除会尝试删除对应注册记录。

## 注册表单字段

表单以弹窗形式出现（`src/pages/rune/inferences/infreg.tsx`），实际渲染的字段如下：

| 字段 | 控件 | 必填 | 说明 |
| --- | --- | --- | --- |
| `endpoint` | 自动补全（可自由输入） | ✅ | 必须是合法 URL；候选来自实例的所有端点 |
| `accessLevel` | 下拉 | — | 访问级别：`public`（公开）/ `tenant`（租户内）/ `private`（私有），默认 `private` |
| `engine` | 下拉 | — | 推理引擎，可选 `openai` / `vllm`，默认 `openai` |
| `adapters` | 数组（可增删） | — | LoRA 适配器列表，每项含 `name` 与 `path` |

`name`、`tenant`、`tenantName`、`workspace` 等字段由前端根据当前上下文自动填充，不出现在表单中。

### 暂无 UI 的字段

`models`（模型名称数组）和 `key`（认证密钥）在后端契约里存在（zod 定义中为可选），但**当前表单没有对应的输入控件**，因此无法在界面上填写。

> ⚠️ 注意: 本节涉及的 `models`、`key` 字段虽在后端契约中，但前端未提供输入控件，文档按「暂无 UI」标注。

### 访问级别说明

| 级别 | 含义 |
| --- | --- |
| `public` | 公开 |
| `tenant` | 仅租户内可见 |
| `private` | 私有（默认） |

## 网关状态

前端只对注册记录建模了 `paused` 布尔值和一组 `status` 字段（`phase` / `message` / `synced` / `adapterStatuses`），**没有定义可枚举的网关状态集合**。

> ⚠️ 注意: 网关状态枚举在后端契约中，前端未做约束（仅有 `paused` 布尔），文档暂未确认。

## 注销

在实例操作菜单点击「取消发布」（i18n key `instance_reference_un_register`），确认后调用删除注册记录接口。
