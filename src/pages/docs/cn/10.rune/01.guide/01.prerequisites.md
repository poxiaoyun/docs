# 环境准备

Rune 控制台不提供命令行工具，也不需要在本地安装任何客户端。开始创建实例之前，只需要确认下面这些由管理员预先准备好的上下文与资源。

> ⚠️ 注意: 截至本版本，Rune 前端没有任何 CLI（没有 `install.sh`、`rune` 可执行文件、访问密钥文件或 `rune template pull` 之类的能力）。所有操作都在控制台页面完成。

## 前置条件清单

| 条件 | 说明 |
| --- | --- |
| 可登录账号 | 能正常登录站点并完成鉴权 |
| 已分配租户 | 顶部上下文处于一个有效的租户下 |
| 已接入集群（区域） | 顶部已选中一个可用集群，否则会跳转到无区域提示页 |
| 已有工作空间 | 当前集群下至少有一个你是成员的工作空间 |
| 配额充足 | 当前工作空间的 CPU / 内存 / 加速卡 / 存储配额足够本次部署 |
| 有可用模板与规格 | 目标集群下能看到对应类别的产品模板和可选择的 Flavor |

## 上下文从哪里来

1. **租户**：由平台管理员在 BOSS 侧创建并授权。
2. **集群 / 区域**：由平台管理员在 BOSS 侧接入集群，控制台顶部通过区域选择器切换。
3. **工作空间**：在集群内创建，绑定独立的 Kubernetes Namespace。租户管理员可在 `/rune/tenants/:tenant/clusters/:cluster/workspaces` 创建。
4. **配额**：租户级配额在 `/rune/tenants/:tenant/quotas` 查看（需要先选择集群）；工作空间配额在工作空间详情下的配额页维护。
5. **规格（Flavor）**：在 `/rune/tenants/:tenant/flavors` 查看当前租户可见的算力规格。

## 没有工作空间或区域时会怎样

前端对这两种情况做了拦截，页面不会直接渲染功能页：

| 场景 | 表现 |
| --- | --- |
| 未选择集群 | 跳转 `/rune/noregion`，提示先选择区域 |
| 当前上下文没有工作空间 | 显示空态，租户管理员会看到一个跳转到工作空间列表的「去创建工作空间」按钮；非管理员只看到提示文案 |

对应实现见 `src/routes/sections/rune.tsx` 中的 `WorkspaceGuard`。
