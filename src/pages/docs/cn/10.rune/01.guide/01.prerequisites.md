# 环境准备

在 Rune 里创建任何东西之前，只需要确认三件事：**你用什么账号登录、你在租户里是什么角色、管理员帮你准备好了哪些资源**。
Rune 不需要你在电脑上安装软件，也没有命令行工具，所有操作都在浏览器页面里完成。

:::tip 为什么先做这一步
就像去健身房要先办卡、存包、换衣服，缺任何一步都会被挡在门口。
Rune 里最常见的「按钮点不动」，原因基本都是区域或工作空间没准备好。
:::

## 自查清单

| 要确认的事 | 具体怎么看 |
| --- | --- |
| 我能登录 | 能正常进入控制台，没有提示账号或密码错误 |
| 我有租户 | 控制台顶部显示的是你要用的那个租户 |
| 我选好了区域 | 顶部**区域**选择器里已经选中一个可用区域（机房） |
| 我选好了工作空间 | 顶部**工作空间**选择器里已经选中一间办公室 |
| 配额还够 | 创建时若提示资源不足，就是配额不够，需要管理员调整 |
| 模板和规格可用 | 应用市场里能看到模板，创建时能选到可用的资源规格 |

## 我的角色是什么

Rune 的租户角色有三种：**管理员**、**开发者**、**普通成员**。

| 角色 | 能用哪些功能 |
| --- | --- |
| 管理员 | 管理成员、配额、工作空间，能使用全部功能 |
| 开发者 | 创建工作负载、看指标和日志，能使用全部功能 |
| 普通成员 | 只能看到「首页」和「应用市场」，看不到「工作台」和「可观测性」 |

:::info 怎么判断自己是不是管理员/开发者
看左侧菜单里有没有**工作台**和**可观测性**这两组。
有，说明你是管理员或开发者；没有，说明你是普通成员——这不是故障，是权限设置。
:::

## 需要管理员帮你准备好什么

下面这些资源你自己创建不了，需要租户管理员或平台管理员提前配置好：

| 资源 | 谁准备 | 没有会怎样 |
| --- | --- | --- |
| 租户与成员身份 | 平台管理员 | 登录后看不到任何业务内容 |
| 区域（集群）授权 | 平台管理员 | 顶部没有可选区域，页面提示**暂无可用的集群** |
| 工作空间 | 租户管理员 | 页面提示**暂无可用的工作空间**，无法创建实例 |
| 配额 | 租户管理员 | 创建时报资源不足 |
| 可用规格 | 平台管理员 | 创建时选不到能用的算力规格 |

:::warning 看到空页面不一定是出错
如果没有区域，页面会提示「暂无可用的集群，请联系管理员创建集群或为您分配集群」。
如果当前区域下没有工作空间，会提示「暂无可用的工作空间，请联系管理员创建工作空间或为您分配工作空间」。
租户管理员在这两个提示页上能直接点**去创建工作空间**；其他人请联系管理员。
:::

## 结果确认

当左侧菜单能完整看到**首页 / 应用市场 / 工作台 / 可观测性**四组，并且顶部**区域**和**工作空间**都选好了具体名称时，环境就算准备好了。
