# 环境准备

在 Rune 里创建任何东西之前，只需要确认三件事：**你用什么账号登录、你在租户里是什么角色、管理员帮你准备好了哪些资源**。
Rune 不需要你在电脑上安装软件，也没有命令行工具，所有操作都在浏览器页面里完成。

:::tip 为什么先做这一步
就像去健身房要先办卡、存包、换衣服，缺任何一步都会被挡在门口。
Rune 里最常见的「按钮点不动」，原因基本都是区域或工作空间没准备好。
:::

## 自查清单

| 要确认的事 | 具体怎么看 |
| --- | --- |
| 我能登录 | 能正常进入控制台，没有提示账号或密码错误 |
| 我有租户 | 点右上角头像打开菜单，能看到「租户 xxx」，并且是你要用的那个 |
| 我选好了区域 | 页面左上角的**区域**选择器里已经选中一个可用区域（机房） |
| 我选好了工作空间 | 页面左上角的**工作空间**选择器里已经选中一间办公室 |
| 租户开通了这个集群 | 内容区没有整页的「当前租户尚未开通此集群」提示 |
| 配额还够 | 创建时若提示资源不足，就是配额不够，需要管理员调整 |
| 模板和规格可用 | 应用市场里能看到模板，创建时能选到可用的资源规格 |

## 我的角色是什么

Rune 的租户角色有三种：**管理员**、**开发者**、**成员**（界面上就叫「成员」）。

| 角色 | 能用哪些功能 |
| --- | --- |
| 管理员 | 全部功能，还能管理成员、配额和工作空间 |
| 开发者 | 全部业务功能（创建实例、看指标和日志）；但租户的**成员**页签只有管理员能进 |
| 成员 | 只能看到「首页」和「应用市场」，看不到「工作台」和「可观测性」 |

:::info 怎么判断自己是不是管理员/开发者
看左侧菜单里有没有**工作台**和**可观测性**这两组。
有，说明你是管理员或开发者；没有，说明你是成员——这不是故障，是权限设置。
:::

## 集群没开通时会看到什么

即使角色对了，**租户还得先开通这个区域（集群）**，才能在里面创建东西。
未开通时，左侧菜单还在，但右侧内容区会被整页替换成一段状态说明，页面上不会出现创建按钮。

| 页面提示 | 含义 | 你能做什么 |
| --- | --- | --- |
| 当前租户尚未开通此集群 | 租户还没申请，或申请还没提交 | 管理员填**申请说明**后点**申请开通**；其他成员联系租户管理员 |
| 开通申请正在审核 | 申请已提交，等平台管理员审核 | 等审核结果，点**刷新状态**看有没有变化 |
| 开通申请未通过 | 审核被拒，页面会显示拒绝原因 | 管理员按原因调整**申请说明**后点**重新提交** |
| 正在开通当前集群 | 审核通过，系统正在准备资源 | 等几分钟后点**刷新状态** |
| 集群开通失败 | 系统没能完成开通 | 点**刷新状态**重试；仍失败请联系平台管理员 |
| 当前租户的集群访问已禁用 | 平台侧关掉了这个租户对该集群的访问 | 联系平台管理员确认开通状态 |
| 当前集群暂不可用 | 已开通，但集群资源当前不可用 | 稍后点**刷新状态**，或联系管理员 |
| 无法读取集群开通状态 | 状态接口读取失败 | 检查网络后按页面按钮重试 |

:::warning 申请说明只有管理员能提交
「申请说明」输入框和**申请开通 / 重新提交**按钮只对**租户管理员**出现。
如果你是开发者或成员，只能看到提示文字和**刷新状态**按钮，需要找管理员发起申请。
:::

## 需要管理员帮你准备好什么

下面这些资源你自己创建不了，需要租户管理员或平台管理员提前配置好：

| 资源 | 谁准备 | 没有会怎样 |
| --- | --- | --- |
| 租户与成员身份 | 平台管理员 | 登录后看不到任何业务内容 |
| 区域（集群）授权 | 平台管理员审核，租户管理员申请 | 内容区被开通状态页替换，无法创建实例 |
| 工作空间 | 租户管理员 | 顶部工作空间选择器为空，无法创建实例 |
| 配额 | 租户管理员 | 创建时报资源不足 |
| 可用规格 | 平台管理员 | 创建时选不到能用的算力规格 |

**规格** 决定了实例能配多少 CPU、内存和加速卡。这些规格由平台管理员按集群预先定义，你自己创建不了；创建实例时下拉里选不到想要的配置，就是这一层没有配全。

## 去哪里查这些配置

配额、规格、工作空间都不是控制台侧边栏的一级菜单，而是归在**租户集群**里：

1. 点右上角头像，在菜单里点 **租户 你的租户名**。
2. 左侧点 **租户集群**，进入集群列表。
3. 点集群名称，页面顶部出现 **概览 / 配额 / 规格 / 工作空间** 四个页签。

完整入口说明见[租户集群](/rune/console/tenant-clusters)。

:::info 看不到这四个页签是正常的
集群详情里的四个页签只对**管理员**和**开发者**显示。成员进入后只能看到租户的基本信息。
:::

## 结果确认

当左侧菜单能完整看到**首页 / 工作台 / 可观测性**三组（首页分组下有首页和应用市场两项），左上角**区域**和**工作空间**都选好了具体名称，并且内容区没有出现开通申请提示时，环境就算准备好了。
