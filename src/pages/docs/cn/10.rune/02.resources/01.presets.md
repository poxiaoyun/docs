# 我的预设

「我的预设」保存的是一份**可以重复使用的实例配置**。
把一个调好的推理服务或微调任务「保存为实例预设」，下次要开一个差不多的实例时，直接从这份预设部署，就不用再从头填一遍参数。

:::tip 预设帮你省掉了哪些填写
没有预设时，每创建一个实例都要重新选应用、重新填一堆参数。
有预设后，应用、版本、类型和所有参数都已经帮你记好了——部署时你只需要填一个 ID。
把常用的那套配置存成预设，就是把「每次都填一遍」变成「填一次、用很多次」。
:::

## 认识概念

| 名词 | 通俗解释 | 可以理解成 |
| --- | --- | --- |
| 预设 | 一份存下来的实例配置快照，包含来源应用、版本和全部参数 | 一道菜的固定配方 |
| 应用 | 这份预设是从哪个应用、哪个版本存下来的 | 配方出自哪本菜谱的第几版 |
| 类型 | 预设属于哪一类：推理服务或微调任务 | 这是道主菜还是甜点 |
| 部署 | 用这份预设创建一个新实例 | 照配方再做一份 |

## 开始之前

- 你的租户角色需要是**管理员**或**开发者**，否则左侧看不到「工作台 → 我的预设」。
- 左上角**区域**和**工作空间**已经选好。预设是**按工作空间隔离**的，只有同一个工作空间的成员才能看到。
- 手头已经有一个配置满意的实例（推理服务或微调任务），否则没有东西可保存。

## 把已有实例保存为预设

1. 左侧菜单点击 **工作台 → 推理服务**（微调任务同理，点 **训练与微调**）。
2. 找到要保存的实例，点这一行最右侧的 **⋮** 图标。
3. 点击 **保存为实例预设**。
4. 在弹窗里填写：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 名称 | 例如 `Qwen 推理标准配置` | 必填；下方会自动生成 ID，需要改就点旁边的铅笔图标 |
   | 预设描述 | 例如 `8B 模型 + 1 卡，团队通用` | 选填，建议写清用途和前提 |

5. 点击 **确认**，出现「保存实例预设成功」的提示就完成了。

:::info 训练与微调有两个保存入口
除了列表行菜单，**训练与微调** 的实例详情页右上角 **操作** 菜单里也有 **保存为实例预设**，效果一样。
:::

:::info 预设里到底存了什么
保存时会记下这个实例所属的租户、区域和工作空间，以及它的应用、版本和全部参数。
所以预设只在**同一个工作空间**里能用来创建新实例，这也是它能被团队共享的原因。
:::

## 用预设部署新实例

1. 左侧菜单点击 **工作台 → 我的预设**。
2. 在列表里找到要用的预设，点这一行最右侧的 **⋮** 图标。
3. 点击 **部署**。
4. 在「从实例预设部署」弹窗里填写：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | ID | 默认自动生成 | 新实例的系统标识，创建后不能改 |
   | 实例描述 | 例如 `给测试组用` | 选填，便于以后辨认 |

5. 点击 **确认**。
6. 系统会带着预设里的应用和参数创建新实例，随后自动跳到对应类型的实例列表页。

:::tip 部署时不用再取名字
预设已经带上了配置，弹窗里只需要一个 ID（通常保持自动生成即可）。
:::

## 预设列表怎么看

**我的预设** 列表长这样：

![我的预设列表：应用、预设名称、预设描述、类型、创建时间五列，行尾有部署入口](/assets/screenshots/rune/presets-01.png)

图里这条 `lla-template` 是从 `llamaFactory 0.152` 这个应用存下来的，类型是 **微调任务**，以后就能直接用它建同款微调实例。

列表里有这些列：

| 列 | 看什么 |
| --- | --- |
| 应用 | 来自哪个应用，下面一行小字是版本号 |
| 预设名称 | 预设的名字 |
| 预设描述 | 你写的用途说明 |
| 类型 | 推理服务或微调任务 |
| 创建时间 | 什么时候建的；单元格下方小字是创建人 |

列表支持搜索、多选、刷新和删除；每一行最右侧的 **⋮** 菜单里还有 **部署** 和 **编辑**。

## 编辑预设

1. 在预设列表里点这一行最右侧的 **⋮** 图标，点击 **编辑**。
2. 在编辑页的**基础信息**里可以改**名称**和**描述**。
3. 在**参数配置**里改参数。参数卡片右上角的图标可以在**表单模式**和 **JSON 模式**之间切换：
   - 表单模式：按模板自动生成表单，适合日常改几个值。
   - JSON 模式：直接编辑参数文本，适合批量替换。
4. 点击 **确认** 保存。

:::warning 编辑前先想清楚
预设是给团队共用的，改参数会影响之后所有从它部署出来的新实例（已经部署好的实例不受影响）。
如果只是想试一套新参数，建议保留原来的预设，另存一份新名字。
:::

:::info 参数表单可能加载不出来
如果这个应用的版本已经不可用，页面会提示「应用 … 已不可用，仅支持编辑基础配置和 JSON 参数」。
这时只能改基础信息和 JSON 参数，不能再切回表单模式。
:::

## 删除预设

在列表里勾选一条或多条预设后点 **删除**，或点行尾 **⋮** 菜单里的 **删除**；系统会要求你**输入预设名称**做二次确认，确认后才会真正删除。

:::warning 删除不可恢复
删除后这份预设**无法恢复**。
不过删除预设**不会**影响已经用它部署出来的实例，那些实例照常运行。
:::
