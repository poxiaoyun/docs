# 资源与配额

这一组页面讲的不是某个实例怎么运行，而是**创建实例前后会用到的共享配置和资源边界**：
有哪些模板可以复用、这个租户一共能用多少资源、能选哪些规格、实例放在哪个工作空间里。
读完你能分清这四个概念，并知道去哪里查看。

:::tip 一句话区分
模板决定「怎么部署」，配额决定「能部署多少」，规格决定「用多好的机器」，工作空间决定「部署在哪里」。
:::

## 四块内容一览

| 页面 | 它回答什么问题 | 去哪里看 |
| --- | --- | --- |
| [我的模板](/rune/resources/templates) | 有没有现成调好的配置可以直接拿来用 | 左侧菜单 **工作台 → 我的模板** |
| [配额](/rune/console/quota) | 这个租户最多能用多少 CPU、内存、加速卡、存储 | 点右上角头像打开账户面板，点**租户 你的租户名**，在顶部页签里选**配额** |
| [规格](/rune/console/flavor) | 创建实例时能选哪些机器配置 | 同上，页签选**规格** |
| [工作空间](/rune/console/workspace) | 实例放在哪间办公室，谁能看到 | 同上，页签选**工作空间** |

:::info 看不到配额/规格/工作空间页签是正常的
这三个页签属于租户设置，只有租户的**管理员**或**开发者**能看到。
如果打开后只看到部分页签，那是权限使然，需要时联系租户管理员。
:::

## 推荐阅读顺序

1. 先看[我的模板](/rune/resources/templates)：理解一套配置怎么被存下来、下次怎么一键复用。
2. 再看[配额](/rune/console/quota)：确认这个租户的资源上限，避免创建到一半被卡住。
3. 然后看[规格](/rune/console/flavor)：确认当前区域里真正能选的机器配置。
4. 最后看[工作空间](/rune/console/workspace)：理解实例之间是怎么互相隔离的。
