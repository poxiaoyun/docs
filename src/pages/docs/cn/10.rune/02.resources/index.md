# 资源与配额

这一组页面讲的不是某个实例怎么运行，而是**创建实例前后会用到的共享配置和资源边界**：
有哪些配置可以复用、这个租户一共能用多少资源、能选哪些规格、实例放在哪个工作空间里。
读完你能分清这四个概念，并知道去哪里查看。

:::tip 一句话区分
预设决定「怎么部署」，配额决定「能部署多少」，规格决定「用多好的机器」，工作空间决定「部署在哪里」。
:::

## 四块内容一览

| 页面 | 它回答什么问题 | 去哪里看 |
| --- | --- | --- |
| [我的预设](/rune/resources/presets) | 有没有现成调好的配置可以直接拿来用 | 左侧菜单 **工作台 → 我的预设** |
| [配额](/rune/console/quota) | 这个租户最多能用多少 CPU、内存、加速卡、存储 | 头像 → **租户 你的租户名** → 左侧 **租户集群** → 点集群名 → **配额** 页签 |
| [规格](/rune/console/flavor) | 创建实例时能选哪些机器配置 | 同上，改选 **规格** 页签 |
| [工作空间](/rune/console/workspace) | 实例放在哪间办公室，谁能看到 | 同上，改选 **工作空间** 页签 |

上面「去哪里看」里的四步值得单独记一下，很多人在控制台侧边栏里找不到这些入口：

1. 点右上角头像，打开账户抽屉。
2. 在菜单里点 **租户 你的租户名**。
3. 左侧点 **租户集群**，进入集群列表。
4. 点你要看的**集群名称**，页面顶部才会出现 **概览 / 配额 / 规格 / 工作空间** 四个页签。

:::info 看不到配额/规格/工作空间页签是正常的
集群详情的四个页签只对租户的**管理员**或**开发者**显示；
而「租户概览 / 成员」是另一个页面，属于账号管理范围，见[租户管理](/account/iam/tenant)。
:::

:::info 别和「控制台」混了
配额、规格、工作空间**不在**控制台左侧的三组菜单里（首页 / 工作台 / 可观测性）。
控制台侧边栏装的是实例和存储，这几个是租户级配置。
:::

## 推荐阅读顺序

1. 先看[我的预设](/rune/resources/presets)：理解一套配置怎么被存下来、下次怎么一键复用。
2. 再看[配额](/rune/console/quota)：确认这个租户的资源上限，避免创建到一半被卡住。
3. 然后看[规格](/rune/console/flavor)：确认当前集群里真正能选的机器配置。
4. 最后看[工作空间](/rune/console/workspace)：理解实例之间是怎么互相隔离的。
