# 资源与配额

「资源与配额」栏目对应 Rune 中偏「共享资源与治理」的能力，重点不是单个实例的运行过程，而是实例创建前后会反复复用的模板、配额和规格。这些能力在控制台中的入口集中在侧边栏的「我的模板」菜单，以及租户设置下的「配额 / 规格 / 工作空间」三个页签。

## 与控制台的关系

| 能力 | 控制台位置 | 关注重点 |
| --- | --- | --- |
| 我的模板 | 侧边栏「工作台 → 我的模板」 | 将已有实例沉淀成模板，复用到新的部署任务 |
| 配额 / 规格 / 工作空间 | 租户设置页签 | 资源边界、可用资源组合与实例隔离单元 |

## 当前覆盖范围

| 页面 | 说明 |
| --- | --- |
| [我的模板](/rune/resources/templates) | 将已有实例沉淀成模板，复用到新的部署任务 |
| [配额](/rune/console/quota) | 查看租户配额，并理解工作空间配额如何逐级分配 |
| [规格](/rune/console/flavor) | 查看当前租户在指定集群中可使用的资源规格 |
| [工作空间](/rune/console/workspace) | 创建与维护承载实例的最小隔离单元 |

## 推荐阅读顺序

1. 先看模板，理解实例如何沉淀成可复用配置。
2. 再看配额，确认当前租户和工作空间的资源边界。
3. 最后看规格，选择当前集群里真正可用的资源组合。
