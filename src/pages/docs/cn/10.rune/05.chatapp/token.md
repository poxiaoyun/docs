# API 密钥

**API 密钥** 页管理的是**调用 ChatApp 模型接口**时用的身份凭证。你在 [模型体验](./experience.md) 页手动聊天要用它，把模型接进自己的程序时更要用它——程序拿着这把密钥，才能证明「这次调用是我发的」。

:::warning 和账户中心里的 API 密钥不是一回事
账户中心的 API 密钥用于管理平台自身的接口；这里的密钥只用于**对话模型接口**。两边不能混用。
:::

## 开始之前

- 已登录账号即可，不需要额外角色。
- 你只能看到和管理自己账号下的密钥。

## 页面有两个标签页

| 标签页 | 看什么 |
| --- | --- |
| **API 密钥** | 密钥列表与创建、编辑、删除 |
| **请求日志** | 每次调用的明细记录 |

## 密钥列表怎么看

| 列 | 说明 |
| --- | --- |
| **名称** | 点名称进入详情 |
| **API 密钥** | 只显示前 6 位加 `************`，右边的复制按钮可以复制完整值 |
| **RPM** | 每分钟最大请求数；显示 `∞` 表示不限制 |
| **TPM(K)** | 每分钟最大 Token 数，单位是 K；显示 `∞` 表示不限制 |
| **访问IP白名单** | 显示 `*` 表示所有 IP 都能用 |
| **过期时间** | 显示 **永不过期** 就是长期有效；已过期会标红「已过期」，此时密钥无法再调用 |
| **创建时间** | 密钥建立的时间 |

## 创建一把密钥

1. 顶部导航点 **API 密钥**。
2. 点页面右上角 **添加API 密钥**。
3. 在 **API 密钥配置** 表单里填写：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 名称 | 例如 `my-app-prod` | 必填；创建后**不能再改** |
   | RPM | 例如 `60` | 每分钟最多请求次数，范围 0 ~ 10000；留空或填 `0` 表示不限制 |
   | TPM(K) | 例如 `100` | 每分钟最多 Token 数，单位 K（1K = 1000 Token/分钟），范围 0 ~ 100000；留空或填 `0` 表示不限制 |
   | 访问IP白名单 | 默认 `*` | 只有清单里的地址能调用；填写规则见下一节 |
   | 永不过期 | 默认开启 | 关掉开关后，会出现 **过期时间**，必须选一个时间 |

4. 点 **确定**。想放弃就点 **取消**。

创建成功后回到列表，就能看到这把新密钥。

### 访问IP白名单怎么写

| 写法 | 示例 |
| --- | --- |
| 单个 IP | `192.168.1.100` |
| 网段 | `10.0.0.0/24`，斜杠后的掩码只能是 0 ~ 32 |
| 所有 IP | `*` |

多个值用**英文逗号**或**换行**分隔。注意每一段数字只能是 0 ~ 255，并且**不能带前导零**（写 `01` 会校验不通过）。

## 拿到密钥的完整值

列表和详情页里，密钥本身始终是脱敏的。要拿到完整值，点密钥旁边的**复制按钮**。

:::warning 复制出来的就是完整密钥
拿到完整密钥后请立刻存到安全的地方（例如密码管理器或程序的环境变量里），不要贴进聊天工具、文档或代码仓库。密钥泄露等于别人可以拿你的额度去调用模型。
:::

## 这把密钥能做什么

1. 在 [模型体验](./experience.md) 和 [模型对比](./compare.md) 页发起对话——页面会自动挑账号下的第一把密钥，也可以在页面里切换。
2. 给你自己的程序调用模型接口。到 [模型广场](./marketplace.md) 打开任意模型详情，点 **API 文档**，里面给出了 **网关地址** 和可直接抄用的 curl、Python、Go 示例。
3. 在示例里把 `YOUR_TOKEN` 换成你复制的密钥，把 `YOUR_MODEL` 换成卡片上的模型 ID，就能跑通第一次调用。

## 额度怎么算

这个页面**不设置额度**，也不限制你花多少。费用的算法是：

每次调用的花费按**模型价格**计算——也就是 [模型广场](./marketplace.md) 详情里看到的输入价格、输出价格（单位是每 100 万 Token），累计起来就是 **调用分析** 页里的「总消费」。想控制花销，可以从两方面下手：给密钥设一个合理的 RPM / TPM，或者换用更便宜的模型。

如果账号整体额度用尽，调用会直接返回「配额不足」，这时需要联系管理员处理额度。

## 编辑和删除

- **编辑**：在列表里用某一行末端的操作菜单选 **编辑**，进入编辑表单。名称输入框是锁定的，改不了；RPM、TPM、白名单、过期设置都能改，改完点 **确定**。也可以在详情页右上角点 **操作** → **编辑**。
- **删除**：在列表的操作菜单里选 **删除**，或在详情页 **操作** → **删除**。删除会弹出确认框，并需要手动输入这把密钥的名称才能继续。

:::warning 删除后无法恢复
删除后，所有正在使用这把密钥的请求会**立即失败**，操作不可撤销。删除前请先确认没有程序还在用它。
:::

## 查看密钥详情

在列表里点密钥**名称**进入详情页，能看到：密钥值（脱敏，带复制按钮）、归属、创建时间、过期时间、RPM、TPM(K)、访问IP白名单。

要改配置或删除，点右上角 **操作** 菜单。

## 查看请求日志

切到 **请求日志** 标签页，可以看到账号下每次调用的记录：

1. 顶部先选 **时间范围**：**今日**（默认）、**昨日**、**近 3 日**、**近一周**、**自定义**。选自定义时会出现 **开始日期** 和 **结束日期**。
2. 可以再按 **Token**、**渠道**、**模型**、**结果** 过滤；结果可选 **全部**、**成功**、**失败**、**已拦截**、**超出配额**。
3. 点 **刷新** 重新拉取，点 **重置** 清空所有筛选条件。
4. 表格里每一行是一条调用，列出时间、渠道、Token、模型、请求 ID、耗时（含首 token 耗时）、Token 数、费用、标准。
5. 想看某一条的细节，点时间那一列旁边的眼睛图标打开详情。

排查调用失败时，**请求 ID** 和 **结果** 这两列最有用：把请求 ID 交给管理员，对方能直接定位到这次调用。

## 安全建议

| 建议 | 说明 |
| --- | --- |
| 一个应用一把密钥 | 不同程序、不同环境分开建，方便单独停用和计量 |
| 配好白名单 | 只允许程序所在机器的 IP 调用，别一直用 `*` |
| 设置过期时间 | 非必要的场景不要长期使用永不过期 |
| 设合理的 RPM / TPM | 防止程序异常时把额度瞬间打光 |
| 定期轮换和清理 | 定期换新密钥，删掉不再使用的旧密钥 |
