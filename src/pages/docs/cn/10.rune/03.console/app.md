# 应用实例

应用实例用来**部署通用应用**：带 Web 界面的工具、内部服务、别人打包好的现成应用，都可以放在这里。它和其他功能一样是实例，只是偏「一整套应用」而不是「一个模型服务」。这一页讲怎么部署，以及它比别的实例多出来的**存储卷列表**怎么看。

:::tip 应用市场和应用实例，别混了

- **应用市场**是模板货架，摆的是别人做好的模板，本身不占资源。
- **应用实例**是你从货架上挑一个部署出来的运行实体，会真的占用算力和存储。

先在市场挑，再在实例列表里管理。

:::

## 开始之前

- 你的租户角色需要是 **管理员** 或 **开发**。
- 左上角先选好 **区域** 和 **工作空间**。
- 想长期保存应用的数据，先建好一块 **文件存储**，见 [文件存储](/rune/console/storage)。
- 确认配额足够，尤其是打算部署带加速卡的应用时。

## 部署一个应用实例

先看列表页。下图这个工作空间里已经有一个应用实例：

![应用实例列表：每行显示名称、应用、资源规格、状态、创建人和创建时间，右上角是「创建应用实例」按钮](/assets/screenshots/rune/app-01.png)

图里这条 `test-app` 状态是 **已暂停**，说明它被手动停过，需要时可以在行操作菜单里点 **启动**。

1. 左侧 **工作台** 分组里点击 **应用实例**。
2. 点击右上角的 **创建应用实例**，进入模板选择页。

![应用库模板选择页：每个模板一张卡片，卡片上有工具标签、版本下拉和「部署」按钮](/assets/screenshots/rune/app-02.png)

3. 选一个应用模板，确认 **版本**，点 **部署**。
4. 填写基础信息：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 名称 | 例如 `my-webui` | 必填，显示用；下方的 ID 会跟着自动生成 |
   | ID | 默认自动生成 | 想自定义就点铅笔图标；创建后不能改 |
   | 描述 | 例如「内部试用」 | 选填 |

5. 填写模板参数（见下一节）。
6. 点击页面底部的 **确定** 提交。

:::tip 也可以从应用市场一键部署
到 [应用市场](/rune/console/app-market) 找到想要的模板，进详情页选好 **版本**，点 **部署**，会直接跳到带模板信息的部署表单，省去中间的挑选步骤。
:::

## 参数怎么填

应用类模板的可填项差异较大，下面这些是通用应用模板里最常见的几块。**具体有没有，以你选的模板为准。**

| 表单项 | 怎么填 | 说明 |
| --- | --- | --- |
| 资源规格 | 选 CPU / 内存 / 加速卡规格 | 大多数模板必填 |
| 镜像地址 | 选镜像仓库里的镜像，或手填地址 | 例如公开镜像；私有仓库要再填用户名和密码 |
| 镜像拉取策略 | 一般保持默认 | 控制什么时候重新拉取镜像 |
| 副本数 | 默认 `1` | 并发高时可以调大 |
| 协议 + 端口 | 选协议，填容器监听的端口 | 端口范围 1–65535，默认 `80`；这是**应用自己监听的端口**，不是让你随便填 |
| 对外暴露 | 需要外部访问就打开 | 打开后可为 HTTP / gRPC 类协议生成访问入口 |
| 访问域名 | 对外暴露时才填 | 外部用来访问这个应用的域名 |
| 启动命令 / 参数 | 一般留空 | 镜像已有默认启动方式时才需要改 |
| 环境变量 | 按 `KEY=VALUE` 添加 | 应用需要的配置项 |
| 存储挂载 | 选择新建或已有的存储卷 | 应用要持久保存数据时必填 |
| 自动伸缩 | 默认关闭 | 打开后按 CPU / 内存利用率自动增减副本 |

:::warning 端口填错就打不开
端口要和应用实际监听的端口一致（很多应用是 `80`，也有的是 `8080` 之类）。填错的话实例能跑起来，但点 **访问** 会打不开页面。不确定就先看模板详情页的说明。
:::

## 结果确认

回到 **应用实例** 列表：

1. 能看到这条实例，**状态** 列先是 **等待中** 或 **执行中**，稍后变成 **运行中** 或 **健康**。
2. 点实例名称进详情，**概览** 页签里有基本信息、容器组列表和存储卷列表。
3. 应用暴露了访问入口时，在访问地址区能找到对外地址，点开即可访问。

:::warning 状态显示「处理失败」怎么办
常见原因是镜像拉取失败、端口配置不对或配额不足。进详情页看 **事件** 和 **日志**，改好参数后点 **编辑** 重新提交，不用删掉重建。
:::

## 存储卷列表是什么

应用实例的 **概览** 页签比别的类型多一个 **存储卷列表**，列出这个应用用到的持久化存储。它和你在模板里选的 **存储挂载** 是配套的：挂载了几块，这里就能看到几块，包括名称和当前状态。

想往里面放文件、下载文件，到 [文件存储](/rune/console/storage) 里打开对应存储卷的文件管理器操作。

## 日常管理

在列表行操作菜单或详情页 **操作** 菜单里：

| 操作 | 说明 |
| --- | --- |
| 编辑 | 改名称、描述和模板参数；改了参数要重新提交才会生效 |
| 启动 / 停止 | 停止会释放计算资源；恢复后再点 **启动** |
| 扩缩容 | 只有模板声明了副本数时才会出现，填新的副本数后点 **确认** |
| 删除 | 二次确认后删除实例并释放资源，无法恢复 |

:::warning 删除前确认数据已备份
删除应用实例会连同它的运行环境一起清理，**无法恢复**。持久化数据只有放在挂载的存储卷里才保得住。
:::

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 实例运行中但访问打不开 | 端口和应用实际监听的不一致 | 编辑参数改成正确端口后重新提交 |
| 没有对外访问地址 | 没打开 **对外暴露**，或协议不支持 | 编辑时打开对外暴露，并选 HTTP / gRPC 类协议 |
| 应用里的数据重启后没了 | 没配存储挂载 | 编辑时选一块存储卷挂上 |
| 列表没有状态筛选和批量启停 | 当前版本未提供 | 用名称搜索定位，逐条操作 |
