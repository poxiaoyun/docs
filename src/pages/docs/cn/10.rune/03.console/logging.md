# 日志

日志记录了实例运行时打印出来的每一行信息，是排查问题最直接的地方。推理服务报错、微调任务跑不动、开发环境起不来时，第一件事就是来看日志。

Rune 控制台里有两个入口：**实例级日志**看某一个实例，**工作空间级日志**看整个工作空间里所有实例的日志。在实例详情里还能进一步下钻到**某个 Pod、某个容器**的日志。

:::tip 日志怎么看
可以把它当成「聊天记录」：出问题时先看最后几条（最近的），再从后往前找第一条报错。
:::

## 开始之前
- 角色：你的租户角色需要是**管理员**或**开发**。
- 上下文：先在页面顶部选好**集群**和**工作空间**。
- 实例已经启动并产生过日志。

## 进入日志页
| 想看什么 | 怎么进 |
| --- | --- |
| 某个实例 | 进入该实例详情，点 **日志** 页签 |
| 整个工作空间 | 左侧菜单 **可观测性** → **日志** |
| 某个 Pod / 容器 | 进入实例详情 **概览**，在容器列表里点该行的日志图标 |

> 在 **概览** 的容器列表里点日志图标，会弹出一个标题形如「Pod 名 日志」的窗口，用来精确查看某个 Pod 里某个容器的日志。

## 按时间和内容筛日志
日志页顶部是工具栏，从左到右：

![日志页：工具栏依次是查询框、时间范围、条数、排序、查询和实时开关，下面是日志输出区](/assets/screenshots/rune/logging-01.png)

工具栏下方是日志输出区，按时间顺序滚动显示匹配到的结果。截图里显示「没有找到日志」，是因为当时这个工作空间没有运行中的负载——没有负载就没有日志可查，换个时间范围或工作空间再看。

| 控件 | 作用 |
| --- | --- |
| 查询框 | 输入要匹配的内容，支持正则，例如 `error\|exception`；回车或点 **查询** 执行 |
| 时间范围 | 选最近 1 分钟 / 5 分钟 / 15 分钟 / 1 小时 / 6 小时 / 1 天 / 7 天，或自定义开始与结束时间 |
| 条数 | 每次最多取回多少条，可选 50 / 100 / 200 / 500 / 1000（默认 100） |
| 排序 | 在「最新在前」和「最新在后」之间切换 |
| 查询 | 按当前条件重新查询 |
| 实时 | 打开或关闭实时日志（见下一节） |

### 按标签过滤
查询框最左边有一个过滤器图标（**添加过滤器**），点开可以按日志的标签缩小范围：

1. 点过滤器图标，弹出标签列表，也可以在框里搜标签。
2. 选一个标签，再勾选它的值（可以选多个）。
3. 选中的条件会变成一个个小标签（形如 `pod="xxx"`）显示在查询框里，可用小叉号单独删掉。
4. 点查询框右侧的清除图标，可以一次清空所有过滤条件。

常用标签：

| 标签 | 说明 |
| --- | --- |
| namespace | 日志来自哪个工作空间 |
| pod | 日志来自哪个 Pod |
| container | 日志来自哪个容器 |

## 实时看日志
1. 点工具栏右侧的 **实时**，进入实时日志视图。
2. 新日志会不断追加，默认**自动滚动到底部**。
3. 当你往上滚动去看旧内容时，页面会**冻结**当前显示范围，不再跟着跑；此时右下角会出现一个带数字的向下箭头按钮，数字是期间新到的条数，点它就回到最新。
4. 底部状态栏会显示 **最后接收: 多长时间前**，以及当前显示多少条、缓存了多少条。
5. 想停下来时，点底部的 **退出实时**；也可以 **清除** 当前内容或 **下载** 日志。
6. 为保证流畅，实时视图最多同时显示最近 1000 条。

:::warning 实时日志断开后不会自动重连
实时日志靠一条长连接推送。如果网络抖动或连接被断开，页面**不会自动重新连接**，需要你手动再点一次 **实时**。而且两个入口的表现不同：

- 在**工作空间级 / 实例级**日志页，断开时页面不会给出明确提示，只是不再有新日志进来；
- 在**实例概览里的 Pod 日志弹窗**中，断开时会显示一条断开原因提示（正常关闭时不提示）。

所以发现日志长时间不更新时，先退出实时，再重新打开。
:::

## Pod 日志弹窗里的其他控件
从实例概览的容器列表打开的日志窗口，顶部还有一排控件：

| 控件 | 作用 |
| --- | --- |
| 容器 | 一个 Pod 里有多个容器时，在下拉里切换要看哪个容器 |
| 跟随 / 停止 | 打开或关闭实时跟随最新日志 |
| 上一次 | 查看上一次已终止容器的日志，适合排查「刚崩溃重启过」的场景 |
| 关闭 | 关掉弹窗 |

## 下载日志
日志内容支持导出为 `TXT`、`JSON`、`CSV` 三种格式：点 **下载**，再选格式即可。

## 常见问题
| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 搜索不到日志 | 时间范围不对，或实例还没产生日志 | 把时间范围调大，等实例启动后再看 |
| 日志加载很慢 | 查询范围太大 | 缩短时间范围，或加标签过滤 |
| 实时没有新内容 | 连接已断开 | 退出实时后重新点 **实时** |
| 找不到某个标签 | 对应 Pod 还没产生日志 | 让实例先跑起来，刷新页面再试 |
| 日志显示乱码 | 程序输出的编码不是 UTF-8 | 检查程序的日志编码设置 |
| 很早的日志查不到 | 历史日志有保留期限 | 需要长期留存请提前导出保存 |

:::tip 历史日志能保留多久
日志系统有存储时效，超过保留期限的历史日志会被清理，具体保留时间由平台配置决定。需要长期保存的日志，建议用 **下载** 提前导出。
:::
