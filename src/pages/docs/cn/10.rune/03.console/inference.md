# 推理服务

推理服务就是**把模型「开门营业」**：部署成功后，你的模型会得到一个访问地址，同事的程序或应用可以调用它。这一页带你从零部署第一个推理服务，并告诉你部署完去哪儿拿地址、怎么判断成功、出问题看哪里。

:::tip 三个类比

- 模板 ≈ 一张装机清单，选好清单，系统自动把机器和软件装好。
- 实例 ≈ 用清单开出来的一台机器，推理服务就是这台机器。
- 资源规格 ≈ 这台机器配几核 CPU、多少内存、几张加速卡。

:::

## 开始之前

- 你的租户角色需要是 **管理员** 或 **开发者**。
- 左上角先选好 **区域** 和 **工作空间**。
- 如果模型文件在你自己手里，先建好一块 **文件存储** 并上传模型，见 [文件存储](/rune/console/storage)。用平台模型库或在线模型的话可以跳过这一步。
- 确认当前工作空间的配额足够，否则会创建失败。

## 从零部署一个推理服务

1. 左侧 **工作台** 分组里点击 **推理服务**。
2. 点击页面右上角的 **创建推理服务**，进入模板选择页。
3. 在一张推理模板卡片上点进去，确认要用的 **版本**，点 **部署**。
4. 等表单出现后，先填基础信息：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 名称 | 例如 `qwen-chat` | 必填，显示用；下方的 ID 会跟着自动生成 |
   | ID | 默认自动生成 | 想自定义就点名称下方的铅笔图标；创建后不能改 |
   | 描述 | 例如「客服问答试用」 | 选填 |

5. 填写模板参数（见下一节「参数怎么填」）。
6. 点击页面底部的 **确定** 提交。

:::tip 拿到地址不一定要走推理服务菜单
也可以直接从 **应用市场** 找模板：进模板详情、选 **版本**、点 **部署**，效果完全一样。
:::

## 参数怎么填

除了「名称 / 描述」，其余表单项**由模板决定**，不同模板长得不一样。以常用的 vLLM 推理模板为例，你会看到这些：

| 表单项 | 怎么填 | 说明 |
| --- | --- | --- |
| 资源规格 | 选一套加速卡规格 | 必填。选之前先确认配额够用 |
| 模型配置 | 选平台模型，或填在线模型名 | 必填。选「本地存储」时会关联你建好的文件存储卷 |
| 模型名称 | 例如 `qwen-7b` | 必填。客户端调用时要带这个名称 |
| API 访问密钥 | 留空或自定义一串字符 | 留空则调用方无需认证；填了就要求请求头带这个密钥 |
| 显存占用比例 | 默认 `0.9` | 可选 70%–100%。调高提升吞吐，但可能显存不足 |
| LoRA 配置 | 默认关闭 | 打开后会挂载共享存储，加载微调产物 |
| 定时自动伸缩 | 默认关闭 | 需要集群支持；按时间段自动调整副本数 |

:::warning 关于镜像和端口
推理模板的**镜像和端口由模板预先设定好**，部署表单里通常不会出现，你不需要自己填。只有个别模板会额外暴露「镜像设置」或「网络配置」，那时才按模板说明填写。
:::

不确定某个参数是什么意思时，点表单右上角的 **AI 配置指导**，它会结合当前模板和你已填的内容，说明关键配置项、必填项和部署前的风险点。也可以点图标切到 JSON 模式直接改底层参数，但新手建议先用表单模式。

## 结果确认

提交后回到 **推理服务** 列表：

1. 能看到这条服务，**状态** 列先是 **等待中** 或 **执行中**。
2. 等到 **状态** 变成 **运行中** 或 **健康**，就表示服务已经可用。
3. 点服务名称进详情，**概览** 页签里能看到基本信息、容器组列表；**监控** 看资源曲线，**日志** 看运行输出，**事件** 排查失败原因。

:::tip 要等多久
没有固定时长，取决于镜像拉取和模型下载速度：小模型快，大模型首次加载明显更慢。期间状态会一直停在 等待中 / 执行中，属正常现象，不用重复提交。
:::

## 在列表里找服务、批量删除

服务多了以后，用列表顶部的工具栏定位：

| 控件 | 怎么用 |
| --- | --- |
| 搜索框 | 按 **服务名称 / 模型 / 模版** 搜索 |
| **状态** | 在 全部 / 健康 / 需关注 / 已暂停 之间切换 |
| **模版** | 只看用某个模版部署出来的服务 |
| **资源** | 按所用资源筛选 |
| **可见性** | 按服务的可见范围筛选（如 公开 / 租户内 / 个人） |

要一次清理多条：勾选行首的复选框，工具栏会出现垃圾桶图标（**批量删除**），点它并确认即可。

:::warning 没有批量启停
批量操作只支持**删除**。启动、停止、扩缩容这些要逐条做——进每条自己的操作菜单，或进详情页的 **操作** 菜单。
:::

## 去哪里拿访问地址

进入实例详情页，在 **概览** 里能找到 **访问地址**。地址按网络范围分三类：

| 类型 | 谁能访问 |
| --- | --- |
| 集群内网络 | 只有集群内部的实例能访问 |
| 内部网络 | 租户内网可以访问 |
| 外部网络 | 可以从外部调用 |

## 把服务发布到网关

要让调用方通过统一网关访问模型，可以在列表行操作菜单或详情页 **操作** 菜单里点 **发布服务**：

1. 实例状态必须是 **健康** 或 **已安装**，否则菜单项会置灰。
2. 在弹窗里确认 **访问地址**（可从实例地址里选，也能手填），选择 **访问级别**（公开 / 租户内 / 个人）。
3. 需要时展开 LoRA 配置，选择引擎并填写适配器名称和路径。
4. 点击 **确定**。

发布成功后，同样的位置会变成 **网关配置**，可随时修改；不想继续对外提供时，点 **取消发布**。

:::warning 取消发布后外界就调不到了
取消发布后，用户不能再通过模型网关访问这个模型。确认没有调用方依赖时再操作。
:::

## 日常管理

在列表行操作菜单或详情页 **操作** 菜单里：

| 操作 | 说明 |
| --- | --- |
| 编辑 | 改名称、描述和模板参数 |
| 启动 / 停止 | 停止会释放计算资源；恢复后再点 **启动** |
| 扩缩容 | 只有模板声明了副本数时才会出现，填新的副本数后点 **确认** |
| 保存为任务模版 | 把当前配置存成模板，下次一键复用 |
| 解密模型 | 部署了加密模型时，输入解密密码后点 **确认解密** |
| 删除 | 二次确认后删除实例并释放资源，无法恢复 |

:::warning 状态显示「处理失败」怎么办
先不要急着删除重建，进详情页的 **事件** 和 **日志** 页签，通常能看到具体原因（配额不足、镜像拉取失败、模型路径错误等）。处理完可以直接 **编辑** 再提交。
:::

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 长时间停在等待中 | 资源不足，排队调度 | 检查配额，或换更小的规格 |
| 状态变成处理失败 | 参数填错、模型路径不对、配额不足 | 看 **事件** 和 **日志** 定位 |
| 找不到入口/端口在哪填 | 该模板不暴露端口 | 端口由模板固定，服务就绪后在 **访问地址** 里拿链接 |
| 想批量启停却发现没有按钮 | 批量操作只支持删除 | 启停要逐条做：行操作菜单或详情页 **操作** 菜单 |
