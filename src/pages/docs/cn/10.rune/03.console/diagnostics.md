# AI 诊断助手

AI 诊断助手是页面右侧一个会跟着你走的**悬浮小助手**，作用是**帮你看实例为什么起不来**。它会读取当前工作空间里实例的状态和配置，你只要描述现象，它就把排查过程和结论一步步讲给你听。

它不是一个独立页面，而是一个随时能叫出、随时能收起的侧边抽屉。

:::tip 诊断助手是什么
把它理解成一位坐在旁边、能翻看当前工作空间情况的运维同事：你描述问题，它去查数据，然后告诉你大概是哪里出了问题。
:::

## 开始之前
- 开关：这个助手由管理员在平台设置里开启。如果右侧看不到它，说明当前环境没有打开。
- 上下文：你需要已经进入某个**工作空间**，助手才会出现。
- 模型：环境里要配置好可用的对话模型。

## 打开助手
1. 在页面**右侧边缘**找到竖着的助手标签（默认叫 **晓石 AI助手**）。
2. 点一下标签，右侧滑出对话面板。
3. 标签可以**上下拖动**，拖到你顺手的位置，松手后就停在那里。

## 做一次诊断
1. 在面板底部确认 **模型** 下拉里选中了一个可用模型（加载好后会默认选第一个）。
2. 在输入框里描述问题，例如「为什么这个实例没有正常运行？」。
3. 如果想针对某个具体实例，在输入框里输入 `@`，从候选列表里选一个实例；选中的实例会作为一个标签显示在输入框上方，跟着这次提问一起发给助手。在推理服务、应用实例、训练与微调、开发服务、指标、模型评测这些列表页下，`@` 会列出对应类型的实例。
4. 按回车，或点右下角的发送按钮。回答会**一个字一个字地流式显示**出来。
5. 中途不想看了，点 **停止** 可以中断生成。

面板打开时还会给几个快捷入口和推荐问题，直接点就能提问：

| 快捷入口 | 适合什么场景 |
| --- | --- |
| 异常资源定位 | 快速定位当前工作空间里状态异常的实例 |
| 实例运行诊断 | 诊断某个实例的运行状态与健康 |
| 服务不可达排查 | 服务访问不通时，排查链路问题 |

## 结果怎么看
助手的回答分两部分：

1. **诊断阶段**：它会在回答里列出正在做哪些步骤，例如 **读取诊断技能**、**收集 Rune 诊断数据**、**更新诊断阶段**。每个阶段会显示进行中，完成后变成成功；如果某个步骤失败，会标红并给出说明。
2. **结论与建议**：正文给出判断和下一步该怎么办。你可以照着建议去对应页签继续查，比如去 **日志** 看具体报错、去 **事件** 看调度信息。

助手对话是有上下文的，可以继续追问，例如接着问「那我该怎么改配置？」。

## 其他操作
| 操作 | 怎么用 |
| --- | --- |
| 清空聊天 | 面板顶部的垃圾桶图标，清掉当前对话 |
| 关闭 | 面板顶部的关闭图标，收起抽屉；下次点标签还能打开 |

## 常见问题
| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 右侧没有助手标签 | 管理员没有开启，或还没进入工作空间 | 联系管理员，或先选好工作空间 |
| 模型下拉是空的 | 环境里没有配置可用模型 | 找管理员确认模型配置 |
| 回答中途停住 | 生成被中断 | 重新发送问题，或检查网络 |
| 提示某个操作需要人工确认 | 该诊断动作需要人工授权 | 按提示找管理员处理 |
