# 工作空间

工作空间是 Rune 里装实例的「房间」：你在页面上创建的推理服务、微调任务、开发环境、应用和存储卷，全部归属于某个工作空间。同一个工作空间对同事共享，不同工作空间的资源互相隔离。这一页讲清「区域」和「工作空间」的关系、怎么切换、怎么创建，以及怎么给空间分配配额。

## 认识概念：区域和工作空间是什么关系

| 名词 | 通俗解释 |
| --- | --- |
| 租户 | 一家公司的独立账号空间，成员、配额都在这一层 |
| 区域（集群） | 一栋机房大楼，里面有很多台机器 |
| 工作空间 | 大楼里的一间办公室，同事共享同一间 |
| 命名空间 | 办公室在系统里的门牌号，创建空间时系统自动生成 |

关系只有一句话：**一栋楼里有很多间办公室，你的实例都放在办公室里**。所以要先选楼（区域），再选房间（工作空间），才能开始干活。

:::tip 为什么要有「工作空间」这一层
如果所有人在同一片资源上干活，A 删除的东西可能影响 B。工作空间把大家分到不同办公室：同空间内互相可见、可协作，跨空间互不打扰，配额也能按空间单独分配。
:::

## 开始之前

- 切换和查看工作空间：所有成员都可以。
- 创建工作空间：只有 **管理员**（租户管理员）才能看到创建按钮。前提是该租户在这个集群下已经配置过资源配额，否则会提示「当前租户未配置该集群的资源配额，无法创建工作空间」。
- 给工作空间分配配额：租户管理员。

## 怎么切换区域和工作空间

两个选择器都在页面左上角，所有菜单的数据都会跟着变。

1. 点击左上角的 **区域**，在弹出的列表里选一栋「大楼」。
2. 点击旁边的 **工作空间**，在弹出的列表里选一间「办公室」。

| 操作 | 会发生什么 |
| --- | --- |
| 切换区域 | 系统自动帮你选中该区域下的第一个工作空间，原有的工作空间选择被清空 |
| 切换工作空间 | 左侧所有实例列表、首页数据全部刷新成新空间的资源 |
| 打开实例详情或存储卷详情 | 两个选择器变成不可点，防止误切换；想切先返回列表页 |

:::warning 切换前先确认没在编辑
正在填部署表单或编辑实例时切换空间，页面会跳走，未提交的内容会丢失。先提交或取消，再切换。
:::

如果某个区域下没有任何工作空间，顶部的工作空间选择器会是空的，页面提示**暂无可用的工作空间**。这种情况需要租户管理员去创建，见下一节。

## 创建工作空间

工作空间由租户管理员在**租户集群**里创建。

1. 点右上角头像，在菜单里点 **租户 你的租户名**。
2. 左侧点 **租户集群**，点你要操作的**集群名称**。
3. 在顶部点 **工作空间** 页签。
4. 点右上角的 **创建工作空间**。
5. 填写表单：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 名称 | 例如 `算法组空间` | 必填，显示用，用中文或英文都行 |
   | ID | 默认跟着名称自动生成 | 系统标识，创建后不能修改；点名称下方的铅笔图标可手动改 |
   | 描述 | 例如「算法组日常实验用」 | 选填 |

6. 点击 **确定**。

![创建工作空间表单：名称、ID、描述三个字段，没有集群选择器](/assets/screenshots/rune/workspace-02.png)

:::info 表单里没有「集群」
工作空间创建在**你当前所在的那个集群**下，所以不需要再选一次集群。要建到别的集群，先切到那个集群，再点 **创建工作空间**。
:::

:::warning ID 的规则要守住
ID 必须以小写字母开头，只能包含小写字母、数字和连字符 `-`，长度不超过 63 位。填错会提示格式不正确；它参与系统内部命名，**创建后无法修改**。
:::

## 工作空间列表怎么看

回到 **工作空间** 页签，每行是一个工作空间：

| 列 | 说明 |
| --- | --- |
| 名称 | 工作空间的名字，下方小字是描述 |
| 命名空间 | 它在集群里的技术标识，创建后系统自动生成 |
| 状态 | **就绪** 表示已经可用；其他状态说明还在创建或异常 |
| 创建时间 | 什么时候创建的 |

行操作里有 **配额**，点它进这个空间的配额页。**创建 / 编辑 / 删除** 只有租户管理员能做，其他角色看不到这些按钮。

## 结果确认

回到 **工作空间** 页签，能看到刚创建的空间，**状态** 列从创建中变为**就绪**。之后在控制台左上角的 **工作空间** 选择器里就能切到它。

## 给工作空间分配配额

工作空间详情页只有 **概览** 和 **配额** 两个页签，**没有成员页签**——成员是按租户管理的，不在工作空间里加。分配方法见[配额](/rune/console/quota)。

:::info 要给同事加权限去哪
工作空间的可见范围由租户成员身份决定。加人、改角色请到 **租户管理 → 成员**，见[租户管理](/account/iam/tenant)。
:::

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 页面提示「暂无可用的工作空间」 | 当前区域下还没有空间，或没给你分配 | 联系租户管理员在 **租户集群 → 工作空间** 里创建 |
| 创建按钮不见了 | 你不是租户管理员 | 找管理员创建或分配空间 |
| 提示未配置资源配额，无法创建 | 该租户在这个区域还没有配额 | 先到 [配额](/rune/console/quota) 配置配额 |
| 左上角选择器点不动 | 你正处在实例详情或存储卷详情页 | 先返回列表页再切换 |
| 工作空间里找不到「成员」页签 | 工作空间详情只有概览和配额 | 成员在 **租户管理 → 成员** 里管理 |
