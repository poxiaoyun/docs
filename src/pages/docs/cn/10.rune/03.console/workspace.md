# 工作空间

工作空间是 Rune 里装实例的「房间」：你在页面上创建的推理服务、微调任务、开发环境、应用和存储卷，全部归属于某个工作空间。同一个工作空间对同事共享，不同工作空间的资源互相隔离。这一页讲清「区域」和「工作空间」的关系、怎么切换、怎么创建，以及怎么把同事加进来。

## 核心概念：区域和工作空间是什么关系

| 名词 | 通俗解释 |
| --- | --- |
| 租户 | 一家公司的独立账号空间，成员、配额都在这一层 |
| 区域（集群） | 一栋机房大楼，里面有很多台机器 |
| 工作空间 | 大楼里的一间办公室，同事共享同一间 |
| 命名空间 | 办公室在系统里的门牌号，创建空间时系统自动生成 |

关系只有一句话：**一栋楼里有很多间办公室，你的实例都放在办公室里**。所以要先选楼（区域），再选房间（工作空间），才能开始干活。

:::tip 为什么要有「工作空间」这一层
如果所有人在同一片资源上干活，A 删除的东西可能影响 B。工作空间把大家分到不同办公室：同空间内互相可见、可协作，跨空间互不打扰，配额也能按空间单独分配。
:::

## 开始之前

- 切换和查看工作空间：所有成员都可以。
- 创建工作空间：只有 **管理员**（租户管理员）才能看到创建按钮。前提是该租户在这个区域下已经配置过资源配额，否则会提示「当前租户未配置该集群的资源配额，无法创建工作空间」。
- 给工作空间加成员：需要能进入工作空间的 **成员** 页签。

## 怎么切换区域和工作空间

两个选择器都在页面左上角，所有菜单的数据都会跟着变。

1. 点击左上角的 **区域**，在弹出的列表里选一栋「大楼」。
2. 点击旁边的 **工作空间**，在弹出的列表里选一间「办公室」。

| 操作 | 会发生什么 |
| --- | --- |
| 切换区域 | 系统自动帮你选中该区域下的第一个工作空间，原有的工作空间选择被清空 |
| 切换工作空间 | 左侧所有实例列表、首页数据全部刷新成新空间的资源 |
| 打开实例详情或存储卷详情 | 两个选择器变成不可点，防止误切换；想切先返回列表页 |

:::warning 切换前先确认没在编辑
正在填部署表单或编辑实例时切换空间，页面会跳走，未提交的内容会丢失。先提交或取消，再切换。
:::

如果某个区域下没有任何工作空间，页面会显示空态，管理员可以在那里点 **去创建工作空间** 直接去创建。

## 创建工作空间

1. 点击右上角头像，在菜单里点 **租户 <你的租户名>**，进入租户设置页。
2. 在顶部页签里点 **工作空间**。
3. 点击 **添加工作空间**。
4. 填写表单：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 名称 | 例如 `算法组空间` | 必填，显示用，用中文或英文都行 |
   | ID | 默认跟着名称自动生成 | 系统标识，创建后不能修改；点名称下方的铅笔图标可手动改 |
   | 区域 | 选择这间「办公室」属于哪栋楼 | 必填，创建后不能修改 |
   | 描述 | 例如「算法组日常实验用」 | 选填 |

5. 点击 **确定**。

:::warning ID 的规则要守住
ID 必须以小写字母开头，只能包含小写字母、数字和连字符 `-`，长度不超过 32 位。填错会提示格式不正确；它参与系统内部命名，**创建后无法修改**，只能重建空间。
:::

## 结果确认

回到 **工作空间** 列表，能看到刚创建的空间，**状态** 列从创建中变为就绪；列表还会显示它的 **命名空间** 和 **创建时间**。之后用左上角的 **工作空间** 选择器就能切到它。

## 给工作空间添加成员

1. 用左上角选择器切到目标 **工作空间**。
2. 点击右上角头像，进入 **租户 <租户名>**，再点 **工作空间** 页签，进入该空间的详情页。
3. 在 **成员** 页签里点击 **创建成员**。
4. 填写表单：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 用户 | 从租户成员里选一个人 | 必填，只列出当前租户已有的成员 |
   | 角色 | 选一个角色 | 必填，**只能选一个**；下拉里是当前空间可用的角色，显示为角色名称 |

5. 点击 **确定**。

成员列表会显示 **用户名、邮箱、角色、加入时间**，需要改角色或移除成员时，用行末的操作菜单。

## 配额

工作空间详情页的 **配额** 页签，可以把租户配额进一步分配到具体空间，控制这个空间能用多少算力。分配方法见 [配额](/rune/console/quota)。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 页面提示「暂无可用的工作空间」 | 当前区域下还没有空间，或没给你分配 | 管理员点 **去创建工作空间**；普通成员联系管理员分配 |
| 创建按钮不见了 | 你不是租户管理员 | 找管理员创建或分配空间 |
| 提示未配置资源配额，无法创建 | 该租户在这个区域还没有配额 | 先到 [配额](/rune/console/quota) 配置配额 |
| 左上角选择器点不动 | 你正处在实例详情或存储卷详情页 | 先返回列表页再切换 |
