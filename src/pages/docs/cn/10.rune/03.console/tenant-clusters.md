# 租户集群

「租户集群」是你所在租户能用的集群清单，也是**配额、规格、工作空间**这三个配置的唯一入口。
很多人会在控制台左侧菜单里翻半天找不到它们——因为它们不在那里，而在租户空间里。
读完这一页，你能正确进入集群、读懂开通状态、并知道四个页签分别管什么。

:::tip 一句话理清关系
**租户**是公司的账号空间，**集群**是租户申请开通的机房，机房里的**配额 / 规格 / 工作空间**才决定你能创建什么样的实例。
顺序是：先开通集群，再分配配额，然后建工作空间，最后才谈得上创建实例。
:::

![租户集群页：左侧「租户管理」下的概览 / 成员 / 租户集群 / 工作台，右侧表格每行是一个集群（类型 + 名称），行尾可进入集群](/assets/screenshots/rune/tenant-clusters-01.png)

## 认识概念

| 名词 | 通俗解释 | 可以理解成 |
| --- | --- | --- |
| 租户集群 | 这个租户已经开通（或正在申请开通）的集群列表 | 公司名下的机房清单 |
| 集群开通状态 | 这个租户对这个集群的准入状态 | 机房的通行证办到哪一步了 |
| 配额 | 这个租户在这个集群里分到的资源上限 | 分到多少电和机位 |
| 规格 | 创建实例时能选的机器配置 | 可选机型目录 |
| 工作空间 | 集群内部的资源边界 | 机房里的独立车间 |

## 从哪里进

1. 点右上角头像，打开账户抽屉。
2. 在菜单里点 **租户 你的租户名**（这就是进入租户的入口）。
3. 进入后，左侧导航里有 **租户集群** 一项，点它。
4. 想切到别的租户，用抽屉底部的 **切换租户**。

![账户抽屉：租户菜单项与底部「切换租户」按钮](/assets/screenshots/rune/tenant-drawer-01.png)

:::info 概览和成员不在这一页
进入租户后，左侧还有 **概览** 和 **成员**（仅管理员可见）。这两项属于账号管理范围，说明见[租户管理](/account/iam/tenant)。
本页只讲 Rune 这边的**租户集群**。
:::

## 租户集群列表

列表很简单，只有 **名称** 一列——就是集群的名字。点名称进入该集群的详情页。

如果列表是空的，说明这个租户还没有任何可用或申请中的集群，需要先申请开通。

## 集群开通

未开通时，控制台的内容区会被整页替换成开通状态页（不是弹窗，也不是报错），上面有状态说明和最多两个按钮。

| 页面提示 | 含义 | 谁能操作 | 能做什么 |
| --- | --- | --- | --- |
| 当前租户尚未开通此集群 | 还没有申请 | 管理员可申请 | 填 **申请说明** → **申请开通** |
| 开通申请正在审核 | 已提交，等平台管理员审核 | 所有人只读 | **刷新状态** |
| 开通申请未通过 | 被拒绝，页面同时显示拒绝原因 | 管理员可重提 | 按原因调整 **申请说明** → **重新提交** |
| 正在开通当前集群 | 审核通过，系统正在准备资源 | 所有人只读 | **刷新状态** |
| 集群开通失败 | 系统未能完成开通 | 所有人只读 | **刷新状态** 重试，仍失败联系平台管理员 |
| 当前租户的集群访问已禁用 | 平台侧关闭了这个租户对该集群的访问 | 所有人只读 | 联系平台管理员 |
| 当前集群暂不可用 | 已开通，但集群资源当前不可用 | 所有人只读 | **刷新状态** 或联系管理员 |
| 无法读取集群开通状态 | 状态读取失败（网络等原因） | 所有人只读 | 检查网络后重试 |

:::warning 申请说明是给审核人看的
**申请说明** 只有租户管理员能填，也是审核人判断要不要开通的依据。写清用途、需要的资源量和使用时间，比写「需要开通」通过得快。
:::

:::info 开发者 / 成员只能看
如果你不是租户管理员，页面只会显示状态和 **刷新状态** 按钮，没有输入框。找管理员发起申请。
:::

## 集群详情：四个页签

点集群名称后，页面顶部出现四个页签（只有**管理员**或**开发者**能看到）：

| 页签 | 这里看什么 | 能否修改 |
| --- | --- | --- |
| 概览 | 集群的名称、ID、描述 | 只读 |
| 配额 | 这个租户在这个集群里每种资源的保障配额、配额上限和已用量 | 租户级只读 |
| 规格 | 创建实例时能选的机器配置清单 | 只读，由平台配置 |
| 工作空间 | 集群里的工作空间列表，以及每个空间的配额 | 管理员可增删改 |

### 配额

按 **类型 / 资源池 / 配额** 三列展示，用量同时给出保障配额与上限，状态分保障内、超出保障、已达上限、已超上限、无可用配额。详见[配额](/rune/console/quota)。

### 规格

按 **名称 / 资源配置 / 资源池** 三列展示，可按类型、资源、状态筛选；页面上**没有创建按钮**。详见[规格](/rune/console/flavor)。

### 工作空间

列出这个集群里的工作空间（名称、命名空间、状态、创建时间），行操作里可以进它的配额页；创建 / 编辑 / 删除仅管理员可用。
点工作空间名称进入详情后，只有 **概览** 和 **配额** 两个页签——**没有成员页签**。详见[工作空间](/rune/console/workspace)。

:::warning 工作空间里没有「加成员」
工作空间的成员由租户成员身份决定。要给同事开权限，去 **租户管理 → 成员**，不是在工作空间里加。
:::

## 结果确认

- 集群列表里能看到目标集群，点进去四个页签都在 → 这个集群已经开通且你有查看权限。
- 配额页签里各项有额度、工作空间页签里至少有一个「就绪」的空间 → 可以回控制台创建实例了。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 左侧菜单里找不到「配额 / 规格 / 工作空间」 | 它们是集群详情的页签，不是一级菜单 | 头像 → 租户 → **租户集群** → 点集群名 |
| 进入集群只看到「概览」 | 你不是管理员或开发者 | 联系租户管理员 |
| 内容区整页都是「尚未开通此集群」 | 租户没开通这个集群 | 管理员填申请说明后申请开通 |
| 创建工作空间提示未配置资源配额 | 租户在这个集群还没有配额 | 先让平台管理员给租户分配配额 |
| 想看租户成员 | 成员在账号管理的另一个入口 | 见[租户管理](/account/iam/tenant) |
