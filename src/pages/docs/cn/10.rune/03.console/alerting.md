# 告警

告警负责在你没盯着页面的时候替你盯着：实例的资源指标超过你设的阈值，平台就按规则把消息推到站内信、飞书或邮件。
读完这一页，你会知道两个入口分别解决什么问题——**顶部铃铛**看已经发生的告警，**实例详情的告警页签**配规则和看历史。

:::tip 一条告警的旅程
**规则**（监控什么、超过多少、持续多久）→ **触发**（条件成立并持续够时间）→ **通知**（发到你选定的渠道）→ **收件箱 / 历史**（你在页面上看到它）。
没收到告警，通常是这条链上某一环没配好。
:::

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 告警规则 | 一条判断条件：监控哪个指标、超过多少（阈值）、持续多久（持续时间）才算告警 |
| 告警模板 | 平台提供的规则模板，决定这条规则能监控哪些指标、参数范围是多少 |
| 严重等级 | 严重 / 警告 / 提示，用来区分处理优先级 |
| 通知渠道 | 告警发到哪里：**站内信（内置）**、飞书、邮件 |
| 通知间隔 | 同一个告警持续触发时，最多隔多久再通知一次，避免刷屏 |
| 告警站内信 | 页面右上角铃铛里的消息收件箱 |
| 告警历史 | 某个实例上已经发生过的告警记录 |

## 开始之前

- 你的租户角色需要是**管理员**或**开发者**。
- 左上角**区域**和**工作空间**已经选好，站内信与实例告警都按当前租户 / 空间统计。
- 想发到飞书或邮件，需要平台先配好对应的**告警渠道**。没配也能用，只是消息只进站内信。

## 顶部告警铃铛：看已经发生的告警

页面右上角有一个铃铛图标：

1. 有未读告警时，铃铛右上角有一个红点，旁边还会显示未读条数。
2. 点铃铛，右侧滑出 **告警站内信** 抽屉，标题下面写着「未读 N 条」。
3. 抽屉顶部可以在 **全部** 和 **仅未读** 之间切换。
4. 每条消息显示标题、严重等级、状态、未读 / 已读标记，以及告警对象、告警规则、条件、当前值、集群、触发时间等明细。
5. 点某条消息即可把它标记为已读；未读不止一条时，右上角有 **全部标记已读**。
6. 每条消息右下角有删除图标，可以直接删掉这条站内信。

抽屉里没有内容时会分别提示「暂无告警通知」或「没有未读告警」。

![告警站内信抽屉：未读条数、全部/仅未读切换、单条消息的等级与明细](/assets/screenshots/rune/alerting-01.png)

:::warning 删掉站内信不等于问题解决了
站内信只是通知的副本，删除只影响你自己的收件箱。规则还在、指标还超阈值，下一条告警照样会来。
:::

## 给某个实例配告警

告警是**按实例**配的，所有实例类型（推理服务、训练与微调、开发服务、应用实例、指标、模型评测）都有这个页签。

1. 在列表里点实例名称，进入实例详情。
2. 点顶部的 **告警** 页签。
3. 在 **告警规则** 区块点 **添加告警规则**。
4. 在弹窗里填：

   | 字段 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 规则名称 | 例如 `gpu-util-high` | 必填；字母、数字、`-`、`_`、`.`，最长 63 个字符 |
   | 告警模板 | 从下拉里选 | 决定这条规则监控什么指标、有哪些参数 |
   | 严重等级 | 严重 / 警告 / 提示 | 一条规则选一个等级 |
   | 阈值 | 按模板给的范围填数值 | 比如 CPU 使用率 90 表示 90% |
   | 持续时间 | 例如 `30s`、`5m`、`1h` | 条件持续满足这么久才真正告警，避免抖动误报 |
   | 通知间隔 | 默认 `10m` | 持续触发时的重复通知间隔；留空用系统默认 |
   | 通知渠道 | 勾选渠道 | **站内信（内置）** 默认带上；还能勾飞书、邮件（若已配置） |

5. 点 **确认**，规则出现在 **告警规则** 表里。

规则表的列是 **规则名称 / 条件 / 持续时间 / 通知间隔 / 通知渠道 / 状态**。行菜单里可以：

| 操作 | 作用 |
| --- | --- |
| 编辑告警规则 | 改阈值、持续时间、渠道等；规则名称能不能改由平台决定 |
| 暂停告警 / 恢复告警 | 临时关掉这条规则，不删配置 |
| 删除 | 彻底删掉这条规则 |

:::tip 阈值怎么定
先用「明显不正常」的值起步，比如 CPU 90%、显存 95%，观察一两周再收紧。一上来就设 60% 会被误报淹没，最后没人看告警。
:::

## 看告警历史

同一个 **告警** 页签下方是 **告警历史**，列有 **规则名称 / 状态 / 级别 / 发生时间 / 触发次数 / 说明**（说明里带条件和当前值）。

- 状态取值：**告警中 / 待确认 / 未触发 / 已暂停 / 已恢复 / 未知 / 错误**。
- 级别取值：**严重 / 警告 / 提示**。
- 勾选多条后可以批量删除历史记录；行上也能单条删除。

:::info 删除历史只是清理记录
删掉历史记录不会影响规则本身，也不会让已经发生的问题消失。
:::

## 收不到告警时先查什么

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 铃铛一直没有红点 | 还没配任何规则，或规则被暂停了 | 进实例详情的 **告警** 页签看状态是不是「已暂停」 |
| 规则是「已启用」但没消息 | 指标没超过阈值，或持续时间还没到 | 先把阈值调低、持续时间调短做一次验证 |
| 站内信有、飞书 / 邮件没有 | 平台没配这个渠道，或规则里没勾选它 | 找平台管理员确认告警渠道，编辑规则时勾上 |
| 消息重复太多 | 通知间隔太短 | 把 **通知间隔** 调大，例如 `1h` |
| 一条消息都看不到 | 你的角色不是管理员或开发者 | 联系租户管理员调整角色 |
