# 文件存储

存储卷是一块**可以反复使用的网络硬盘**。你把模型文件、数据集放进去，之后创建推理服务、微调任务或开发环境时挂载它，实例重启或删除后里面的文件都还在。没有存储卷，实例里的文件会随实例一起消失。

在 **文件存储** 菜单里，你能完成这些事：创建存储卷、查看用量、扩容、删除，以及往里面上传文件或从外部仓库导入数据。

:::tip 为什么要有存储卷
可以把存储卷理解成一块「U 盘」：推理服务、微调任务、开发环境这些「电脑」可以随时换，但只要插上同一块 U 盘，文件就还在。
:::

## 开始之前
- 角色：你的租户角色需要是**管理员**或**开发者**，否则左侧看不到「文件存储」菜单。
- 上下文：先在页面顶部选好**集群**和**工作空间**。
- 存储后端：集群里要有可用的存储类，创建时才能选到。

## 在哪里找到它
1. 在左侧菜单找到 **工作台** 分组。
2. 点击 **文件存储**。

## 创建一块存储卷
1. 点击列表右上角的 **创建存储卷**。
2. 在表单里填写：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 名称 | 例如 `my-model-files` | 只能用小写字母、数字和连字符，必须以字母或数字开头和结尾，最多 63 个字符；创建后不能修改 |
   | 存储类 | 从下拉里选一个 | 决定文件实际存放在哪个存储上；创建后不能修改 |
   | 容量 | 例如填 `20`，单位选 `Gi` | 数值至少为 1；单位可选 `Mi`、`Gi`、`Ti`，默认 `Gi` |
   | 读写权限 | 默认 **读写** | 选 **只读** 后，挂载它的实例只能读，不能写 |
   | 存储卷类型 | 默认 **不设置** | 只是分类标记，可选 **模型** 或 **数据集**，方便你区分，不影响功能 |
   | 描述 | 可不填 | 一句话说明这块盘放什么 |

3. 点击 **确认**。

## 结果确认
回到 **文件存储** 列表，能看到新存储卷。

- **状态** 列先显示创建过程，就绪后显示 **未挂载**（还没被实例使用）或 **已挂载**（已经挂在某个实例上，鼠标悬停能看到是哪些应用在用）。
- 只有就绪的存储卷，**名称才能点击**进入详情页。

## 列表上还有什么
- 顶部四张统计卡片：**使用率**（已用 / 总量）、**总存储卷**（含已挂载、未挂载）、**文件总数**、**存储类型**。这些数据只作参考，取决于存储后端是否提供统计。
- 工具栏右侧有 **只看已挂载** 开关，打开后只显示正在被实例使用的存储卷。
- 支持按名称搜索、刷新，以及勾选多条后 **批量删除**。

列表各列含义：

| 列 | 说明 |
| --- | --- |
| 名称 | 存储卷名称，旁边小图标表示卷类型（模型 / 数据集）；下方是描述 |
| 状态 | 未挂载 / 已挂载；还没就绪时显示创建时的状态 |
| 存储集群 | 文件实际所在的存储，也就是创建时选的「存储类」 |
| 使用率 | 已用 / 容量，并显示百分比；用量偏高时这里会出现 **扩容** 入口 |
| 文件数 | 里面的文件总数 |
| 读写权限 | 读写 / 只读 |

## 扩容：容量只能调大，不能调小
1. 在 **使用率** 列点击 **扩容**（用量偏高时才会出现这个入口）。
2. 在弹出的 **扩容文件存储** 窗口里填写：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 当前容量 | 只读，显示现在的容量 | — |
   | 目标容量 | 填一个不小于当前容量的数字 | 至少为 1 |
   | 单位 | `Mi`、`Gi` 或 `Ti` | 可以和当前容量的单位不同 |

3. 点击 **确认**。

:::warning 容量只能调大
如果目标容量比当前容量小，系统会拦下来，并提示「不允许缩小存储卷容量，新容量必须大于或等于当前容量」。存储卷一旦创建，容量就**只能增加，不能减少**。
:::

## 详情页：概览 / 文件管理器 / 存储作业
点存储卷名称进入详情页，顶部有 **概览**、**文件管理器**、**存储作业** 三个页签，其中 **文件管理器** 只在支持的存储卷上出现。

### 概览
- 可以就地修改 **容量**、**读写权限**、**存储卷类型**（容量同样只能调大）。
- 显示 **S3 账户**：S3 端点、存储桶、访问密钥、秘密密钥，每项都能一键复制；秘密密钥默认打码，点眼睛图标才显示。拿到这些信息后，你也能用命令行或其他 S3 工具直接读写这块盘。
- 右侧可以渲染存储卷里的 `README.md`；没有的话会提示 **创建 README**，上传一个 `README.md` 就能看到内容。

> 只有受支持的存储卷才有 S3 账户和文件管理器。普通 PVC 存储卷会提示「普通 PVC 存储卷不提供 S3 访问凭据」「普通 PVC 存储卷不支持文件管理、上传和预览」。

### 文件管理器
在网页上直接管理文件：进入文件夹、**上传**（可以选文件，也可以选整个文件夹，支持拖拽）、下载、删除、预览文本和图片，还能按文件路径前缀搜索。顶部有面包屑，点 **返回上级目录** 或 **根目录** 可以快速跳转。

:::warning 删除文件也会真的删掉
在文件管理器里删除文件是**立刻生效、无法恢复**的。删除前请确认文件已经备份。
:::

### 存储作业：从外部导入数据
「存储作业」用来把外部仓库的数据**下载或克隆到这块存储卷里**。它支持 Git、HuggingFace、ModelScope、Moha 和 Python Environment 五种类型。

在详情页点击 **存储作业** 页签，就能看到该存储卷上的作业列表，列有：名称、作业类型、仓库、分支、状态、更新时间。每行可以 **查看**（预览配置）、**日志**（看运行输出）、编辑或删除。

#### 创建一个导入作业
1. 在 **存储作业** 页签点击右上角的 **创建存储作业**。
2. 在 **存储作业配置** 里选择 **作业类型**。
3. 按所选类型填写下面的字段。
4. 点击 **确认**。作业名会自动生成（存储卷名加一段随机后缀），不用自己起。

**Git —— 克隆代码仓库**

| 表单项 | 怎么填 | 说明 |
| --- | --- | --- |
| 仓库地址 | 例如 `https://github.com/user/repo.git` | 必填 |
| 分支 | 默认 `main` | 不填就拉默认分支 |
| 用户名 | 私有仓库才需要 | 可不填 |
| 密码或凭证 | 私有仓库才需要 | 可不填 |

**HuggingFace —— 下载模型或数据集**

| 表单项 | 怎么填 | 说明 |
| --- | --- | --- |
| 类型 | **模型** 或 **数据集** | 必填，默认 **模型** |
| HuggingFace 仓库 | 形如 `组织名/仓库名` | 必填 |
| 仓库分支 | 默认 `main` | 不填就下载默认分支 |
| 访问令牌 | 私有仓库或不限速下载才需要 | 可不填 |

**ModelScope —— 从阿里云 ModelScope 下载**

| 表单项 | 怎么填 | 说明 |
| --- | --- | --- |
| 类型 | **模型** 或 **数据集** | 必填，默认 **模型** |
| ModelScope 仓库 | 形如 `组织名/仓库名` | 必填 |
| 仓库分支 | 默认 `master` | 注意：这里默认是 `master`，不是 `main` |
| 令牌 | 私有仓库才需要 | 可不填 |

**Moha —— 从 Moha 平台仓库下载**

| 表单项 | 怎么填 | 说明 |
| --- | --- | --- |
| 类型 | **模型** 或 **数据集** | 必填 |
| 可见性 | **公开**、**组织内** 或 **私有** | 必填，默认 **公开** |
| Moha 仓库 | 从下拉里选 | 必填；下拉候选由「类型 + 可见性」决定 |
| 仓库分支 | 从下拉里选 | 必填；要先选好仓库才会出现分支 |

**Python Environment —— 在存储卷里准备 Python 环境**

| 表单项 | 怎么填 | 说明 |
| --- | --- | --- |
| 重置 | **重置** 或 **正常** | 必填 |
| 依赖包 | 例如 `tensorflow==2.5.0;fastapi==0.63.0` | 多个用 `;` 分隔，可不填 |
| Python 版本 | 默认 `3.9` | 必填 |
| Python 服务器 | pip 源地址 | 可不填，默认使用阿里云镜像 |
| Conda 资源 | conda 源地址 | 必填，默认使用清华镜像 |

作业状态：

| 状态 | 含义 |
| --- | --- |
| 等待中 | 排队中 |
| 运行中 | 正在下载或安装 |
| 已完成 | 成功 |
| 失败 | 出错，点 **日志** 看原因 |
| 删除中 | 正在删除 |
| 不健康 | 作业异常 |

## 删除存储卷
1. 在列表勾选一条或多条存储卷，点 **批量删除**；或在详情页右上角的 **操作** 菜单里点 **删除**。
2. 在二次确认弹窗里按提示确认。
3. 点击确认后，存储卷进入「删除中」，稍后从列表消失。

:::warning 删了就找不回来
删除存储卷会同时删除里面的**所有文件**，并且**无法恢复**。删除前请先把需要的文件备份到别的地方。
:::

## 常见问题
| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 名称点不进详情 | 存储卷还没就绪 | 等状态变成未挂载 / 已挂载再点 |
| 没有「文件管理器」页签 | 这是普通 PVC 存储卷，不支持网页文件管理 | 用挂载它的实例去读写文件 |
| 扩容报「不允许缩小」 | 目标容量比当前小 | 改成不小于当前容量 |
| 作业失败 | 地址、令牌填错，或网络不通 | 打开作业 **日志** 逐行看错误 |
| 统计卡片数据为空 | 该存储后端不提供统计 | 以实际使用为准，忽略卡片 |
