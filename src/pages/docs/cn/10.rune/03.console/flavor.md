# 规格

规格回答的是「**我能申请多大的一台机器**」。一个规格就是一组打包好的资源组合——CPU 几核、内存多大、有没有加速卡——你在创建实例时直接从下拉里选一个，平台就按这个组合给你分配。

规格由平台管理员按集群预先配置，你这边**只能看，不能创建或修改**。

:::tip 规格和配额的区别
- **规格**：一次能用「多大一台」，也就是能选哪些资源组合。
- **配额**：这段时间总共能用「多少额度」。
两个都满足，实例才建得出来。
:::

## 开始之前

- 角色：你的租户角色需要是**管理员**或**开发**，否则看不到集群详情的四个页签。
- 上下文：先按下面的路径进入某个集群；规格是按集群算的。

## 在哪里看规格

1. 点右上角头像，在菜单里点 **租户 你的租户名**。
2. 左侧点 **租户集群**，进入集群列表。
3. 点你要看的**集群名称**。
4. 页面顶部点 **规格** 页签。

![集群详情·规格页签：顶部四页签、类型/资源/状态筛选条、名称/资源配置/资源池三列](/assets/screenshots/rune/flavor-01.png)

这个页面**没有「创建规格」按钮**——规格不在租户侧维护，配不出来的规格要找平台管理员。

## 规格列表怎么看

| 列 | 说明 |
| --- | --- |
| 名称 | 规格的名字，名字后面带一个类型标签（CPU / GPU / 共享GPU 等） |
| 资源配置 | 这个规格包含的资源组合，例如 CPU 几核、内存多大、几块卡 |
| 资源池 | 这个规格归在哪个资源池下 |

筛选条上有四个控件：**类型**、**资源**、**状态** 和搜索框，可以组合使用。

## 按条件筛选规格

1. 先选 **类型**（例如 GPU），列表会立刻收窄。
2. 再选 **资源**，进一步只看某种型号。
3. 需要时再选 **状态**。
4. 想取消某个条件就再点一次它，或清空筛选条。

## 「我还剩多少额度」去哪里看

规格页只告诉你**能选什么**，不显示用量。要看还剩多少，去同一个集群的 **配额** 页签：

1. 按上面的路径进入集群详情，点 **配额** 页签。
2. 在 **配额** 列看每种资源的已用量、保障配额和配额上限。

想看某个**工作空间**分到了多少额度，进 **工作空间** 页签，打开具体工作空间，再点 **配额**。

:::tip 为什么选不了某个规格
即使列表里能看到某个规格，也不代表一定部署得出来。还需要当前工作空间在对应资源上还有配额。创建失败时，先去配额页确认额度，而不是只看规格是否存在。
:::
