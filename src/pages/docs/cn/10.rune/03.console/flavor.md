# 规格

规格回答的是「**我能申请多大的一台机器**」。一个规格就是一组打包好的资源组合——CPU 几核、内存多大、有没有加速卡、是哪一款——你在创建实例时直接从下拉里选一个，平台就按这个组合给你分配。

规格由平台管理员在后台配置，你这边**只能看，不能创建或修改**。

:::tip 规格和配额的区别
- **规格**：一次能用「多大一台」，也就是能选哪些资源组合。
- **配额**：这段时间总共能用「多少额度」。
两个都满足，实例才建得出来。
:::

## 开始之前
- 角色：你的租户角色需要是**管理员**或**开发**。
- 区域：先在页面顶部**选好集群**。没有选集群时，规格页不会去查询，也就没有数据。

## 在哪里看规格

规格挂在**集群**下面，所以先选好集群再看列表。

1. 顶部导航点击 **智算平台**，进入集群列表。
2. 点开你要看的集群。
3. 在左侧 **资源管理** 分组里点击 **资源规格**。

![资源规格列表：左侧「资源管理」分组下选中「资源规格」，页头右上角可切换集群](/assets/screenshots/rune/flavor-01.png)

页头右上角的 **集群** 选择器决定看哪个集群的规格；右侧的 **创建规格** 按钮只有平台管理员能点。列表里每行是一个规格，按当前集群配置出来。

## 规格列表怎么看
| 列 | 说明 |
| --- | --- |
| 名称 | 规格的名字，下方小字是它的说明 |
| 类型 | 资源大类，例如 CPU、GPU、共享GPU |
| 型号 | 加速卡型号（含厂商） |
| 规格 | 这个规格包含的资源组合，例如 CPU 几核、内存多大、几块卡 |
| 资源池 | 这个规格归在哪个资源池下 |
| 状态 | **启用** 表示可用；**未启用** 的规格选不到 |

工具栏最左边有搜索框，可以按名称快速定位；旁边还有 **状态** 筛选。

## 按条件筛选规格
工具栏下面还有一条筛选条，按 **类型 → 厂商 → 型号** 逐级筛选：

1. 先点 **类型**（例如 GPU），下面的厂商和型号会跟着变化。
2. 再点 **厂商**。
3. 最后点 **型号**，列表就只剩符合条件的规格。

再点一次已选中的条件即可取消它。

## 「我还剩多少额度」去哪里看
规格页只告诉你**能选什么**，不显示用量。要看还剩多少，去租户的 **配额** 页：

1. **账户管理** → **租户管理**，点开你的租户。
2. 在 **配额** 页的 **配额** 列看到「已用 / 总量」和进度条，就是要看的使用情况。

想看某个**工作空间**分到了多少额度，同一位置进入 **工作空间**，打开具体工作空间，再点 **配额** 页签。

:::tip 为什么选不了某个规格
即使列表里能看到某个规格，也不代表一定部署得出来。还需要当前工作空间在对应资源上还有配额。创建失败时，先去配额页确认额度，而不是只看规格是否存在。
:::
