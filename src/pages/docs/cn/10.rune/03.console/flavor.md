# 规格

规格回答的是「**我能申请多大的一台机器**」。一个规格就是一组打包好的资源组合——CPU 几核、内存多大、有没有加速卡、是哪一款——你在创建实例时直接从下拉里选一个，平台就按这个组合给你分配。

规格由平台管理员在后台配置，你这边**只能看，不能创建或修改**。

:::tip 规格和配额的区别
- **规格**：一次能用「多大一台」，也就是能选哪些资源组合。
- **配额**：这段时间总共能用「多少额度」。
两个都满足，实例才建得出来。
:::

## 开始之前
- 角色：你的租户角色需要是**管理员**或**开发者**。
- 区域：先在页面顶部**选好集群**。没有选集群时，规格页不会去查询，也就没有数据。

## 在哪里看规格
1. 点击右上角的头像。
2. 在菜单里进入 **租户**（后面会带出你所在的租户名称）。
3. 在租户页签里点击 **规格**。

## 规格列表怎么看
| 列 | 说明 |
| --- | --- |
| 名称 | 规格的名字，下方小字是它的说明 |
| 类型 | 资源大类，例如 CPU、GPU、共享GPU |
| 型号 | 加速卡型号（含厂商） |
| 规格 | 这个规格包含的资源组合，例如 CPU 几核、内存多大、几块卡 |

本页不支持搜索，只能通过筛选条来缩小范围。

## 按条件筛选规格
列表上方有一条筛选条，按 **类型 → 厂商 → 型号** 逐级筛选：

1. 先点 **类型**（例如 GPU），下面的厂商和型号会跟着变化。
2. 再点 **厂商**。
3. 最后点 **型号**，列表就只剩符合条件的规格。

再点一次已选中的条件即可取消它。

## 「我还剩多少额度」去哪里看
规格页只告诉你**能选什么**，不显示用量。要看还剩多少，去同一组租户页签里的 **配额**：

1. 头像 → **租户** → 页签 **配额**。
2. 在 **配额** 列看到「已用 / 总量」和进度条，就是要看的使用情况。

想看某个**工作空间**分到了多少额度，则在租户页签里进入 **工作空间**，打开具体工作空间，再点 **配额** 页签。

:::tip 为什么选不了某个规格
即使列表里能看到某个规格，也不代表一定部署得出来。还需要当前工作空间在对应资源上还有配额。创建失败时，先去配额页确认额度，而不是只看规格是否存在。
:::
