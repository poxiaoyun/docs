# 指标

「指标」是 Rune 控制台里专门用来跑**实验跟踪服务**的一类实例，常见的是 MLflow 这类工具。训练模型时，把每轮实验的参数、指标、模型文件记到它里面，之后就能在一个网页上对比不同实验的结果。

读完后你能做到三件事：**部署一个指标服务**、**拿到它的访问地址**、**在训练时把指标记录进去**。

:::tip 指标服务是什么
把它理解成「实验室的记录本服务器」：训练任务负责写，它负责存和展示。
:::

## 开始之前
- 角色：你的租户角色需要是**管理员**或**开发者**，否则左侧看不到「指标」菜单。
- 上下文：先在页面顶部选好**集群**和**工作空间**。
- 模板：指标服务由模板创建，能部署哪一种取决于你的集群里有哪些指标类模板。

## 在哪里找到它
1. 在左侧菜单找到 **可观测性** 分组。
2. 点击 **指标**，进入指标服务列表。

## 部署一个指标服务
1. 点击列表右上角的 **创建指标**。
2. 页面跳到模板选择页，挑一个指标类模板和它的版本。
3. 填写基本信息，再填写模板参数。参数由模板决定，可在「图形 / JSON」两种模式之间切换填写。
4. 点击提交，回到 **指标** 列表等待部署完成。

> 基本信息、模板参数的具体字段由所选模板给出，各模板可能不同，页面会实时提示哪些是必填项。

## 指标服务列表怎么看
| 列 | 说明 |
| --- | --- |
| 名称 | 实例名称，点击进入详情页 |
| 指标服务 | 这条实例用的是哪个模板 |
| 资源规格 | 占用的 CPU、内存、加速卡 |
| 状态 | 运行状态，见下表 |
| 访问 | Web、SSH 等快捷访问按钮 |
| 创建人 | 谁创建的 |
| 创建时间 | 实例创建时间 |

常见状态：

| 状态 | 含义 |
| --- | --- |
| 等待中 | 在排队，或正在拉取镜像 |
| 执行中 | 正在部署 |
| 运行中 / 健康 | 部署成功，可以访问 |
| 已暂停 | 被手动停止 |
| 处理失败 | 出错了，去「日志」页签看原因 |
| 删除中 | 正在删除 |

鼠标悬停或选中一行，还能在行操作菜单里做 **启动 / 停止**、**编辑**、**删除** 等操作。

## 进入详情页能做什么
点实例名称进入详情页，顶部有四个页签：

| 页签 | 内容 |
| --- | --- |
| 概览 | 基本信息卡片、容器列表 |
| 监控 | 实例资源监控面板 |
| 日志 | 实例运行日志 |
| 事件 | 系统事件流，用于排查调度、挂载等问题 |

右上角 **操作** 菜单里有 **编辑**、**启动 / 停止**、**扩缩容**、**删除**。删除不可恢复，会先弹二次确认。

## 把指标接入训练任务
部署好指标服务后，部分**微调**模板会在部署表单里提供一个填写「实验跟踪地址」的选项，你可以从已部署的指标服务里挑一个。这样训练过程中的指标就会记录到那个指标服务里。

是否出现这个选项、具体叫什么名字，取决于你选择的微调模板。详见[训练与微调](/rune/console/finetune)。

## 结果确认
回到 **指标** 列表，能看到新实例，且 **状态** 变成「运行中」或「健康」，就说明部署成功。此时在 **访问** 列点 Web 图标即可打开指标服务的界面；有的模板不提供 Web 界面，只提供 SSH。

## 常见问题
| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 状态一直是等待中 | 集群资源临时不足，或镜像还在拉取 | 等几分钟，或去「事件」页签看提示 |
| 状态是处理失败 | 参数填错，或模板与资源不匹配 | 打开「日志」页签看报错行 |
| 访问按钮点不开 | 服务尚未就绪，或该模板不提供 Web 界面 | 等状态变成运行中再试，否则改用 SSH |
| 创建后找不到实例 | 上下文切错了集群或工作空间 | 检查页面顶部的集群和工作空间 |
