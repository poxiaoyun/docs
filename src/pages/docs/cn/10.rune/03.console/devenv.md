# 开发服务

开发服务帮你**在浏览器里开一台带工具的机器**：打开网页就是 Jupyter 或类似的在线 IDE，可以写代码、跑脚本、调试模型；需要命令行时还能打开终端，用 VSCode 远程连上去也行。这一页讲怎么创建、怎么进去，以及停止、重启、删除到底有什么区别。

:::tip 开发环境和推理、微调有什么不同
推理服务是「一直开着对外提供服务」，微调是「跑完就结束的任务」，开发环境是「你自己坐进去用的机器」。它同样是一个实例，只是用途偏交互。
:::

## 开始之前

- 你的租户角色需要是 **管理员** 或 **开发**。
- 左上角先选好 **区域** 和 **工作空间**。
- 想让代码和大文件在实例关掉后还在，先建好一块 **文件存储**，见 [文件存储](/rune/console/storage)；不挂存储卷的话，里面的文件会随实例一起消失。
- 想用 VSCode 远程连接，准备好你的 SSH 公钥。

## 创建一个开发环境

创建路径和其他工作负载一样：列表页 → 模板选择页 → 部署表单。先看列表页：

![开发服务列表：右上角是「创建开发服务」按钮](/assets/screenshots/rune/devenv-01.png)

这个工作空间还没有开发环境，列表底部显示「共 0 条」；有实例后每一行会显示 **名称 / 开发环境 / 资源规格 / 状态 / 创建时间 / 连接**，创建人显示在创建时间单元格下方的小字里。

1. 左侧 **工作台** 分组里点击 **开发服务**。
2. 点击右上角的 **创建开发服务**，进入模板选择页。

![开发模板选择页：每个模板一张卡片，卡片上有框架标签、版本下拉和「部署」按钮](/assets/screenshots/rune/devenv-02.png)

3. 选一个开发环境模板（例如带 Jupyter 的 Notebook 模板），确认 **版本**，点 **部署**。
4. 填写基础信息：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 名称 | 例如 `my-dev` | 必填，显示用；下方的 ID 会跟着自动生成 |
   | ID | 默认自动生成 | 想自定义就点铅笔图标；创建后不能改 |
   | 描述 | 例如「算法调试用」 | 选填 |

5. 填写模板参数。以 Notebook 模板为例：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 资源规格 | 选 CPU / 内存规格 | 必填 |
   | 访问密码 | 自定义，或留空 | 留空时系统会自动生成一个 24 位随机密码，**部署后请立刻保存** |
   | 授权用户 | 选一个或多个租户用户的 SSH 公钥 | 不选就不会创建外部 SSH 访问入口，也就没法用 VSCode 远程连 |
   | 文件存储 | 选一块已有存储卷 | 挂载到工作目录；留空则用临时目录，**实例结束后里面的文件会清空** |

6. 点击底部的 **确定** 提交。

:::warning 别让工作成果随实例一起消失
不挂 **文件存储** 时，Notebook 用的是临时目录，实例停止或删除后里面的文件会被清掉。有需要保留的代码和数据，务必选一块存储卷。
:::

## 从页面进去（Web IDE / Jupyter / 终端）

实例状态变成 **运行中** 或 **健康** 后，有三种进去的方式。

### 方式一：网页版 IDE（推荐新手）

1. 在 **开发服务** 列表的 **连接** 列，或在实例详情页的访问地址区，点击 **访问**。
2. 浏览器新标签页会打开实例的 Web 界面，例如 JupyterLab，直接在里面写代码、跑单元格。
3. 如果模板设置了 **访问密码**，按提示输入；留空自动生成的密码，用你部署时记下的那串字符。

### 方式二：容器终端（要用命令行时）

1. 进入实例详情页，找到 **概览** 里的容器组列表。
2. 在要操作的容器那一行点 **终端**，页面会打开一个命令行窗口，可以直接执行命令。

### 方式三：VSCode 远程连接（本机装好 VSCode）

1. 在 **连接** 列点 **连接 VSCode**，或在下拉里选 **使用 VSCode**，本机会自动发起远程连接。
2. 不想自动打开时，选 **复制 SSH 命令**，把命令粘到终端里执行。
3. 实例暴露了多个 SSH 地址时，下拉列表会为每个地址分别列出选项。

:::tip 连不上先检查两件事
一是实例 **状态** 是否为运行中或健康（未就绪时按钮会置灰）；二是创建时有没有在 **授权用户** 里选择你的 SSH 公钥，没选就不会有 SSH 入口。
:::

## 把当前环境保存成镜像

调试好一套环境后（装好了包、改好了配置），不必每次重建都重装一遍：可以把这台机器当前的容器状态**保存成一个镜像**，之后用这个镜像开新实例。

### 从操作菜单创建镜像

1. 进入开发服务实例详情页，点右上角 **操作**。
2. 点 **保存当前环境**。
3. 在弹窗里确认这几项：

   | 字段 | 说明 |
   | --- | --- |
   | 源 Pod | 从当前实例的 Pod 里选一个；没有可选 Pod 时会提示「当前实例没有可用的 Pod」 |
   | 源容器 | 这个 Pod 里要保存的容器 |
   | 源镜像 | 所选容器当前用的镜像，只读 |
   | 容器运行时 | 镜像构建使用的运行时 |
   | 目标镜像 | 保存到哪里，例如 `registry.example.com/team/my-dev` |
   | Tag | 这次保存的版本标记，格式不对会直接提示 |

4. 点 **创建镜像**。提交后出现「保存任务已创建」，任务在后台执行，可以关掉弹窗。

:::warning 镜像里没有你的存储卷
**镜像快照** 只保存所选容器的**可写层**。挂载的存储卷（PVC）、Secret、ConfigMap、临时目录（emptyDir）都不会进镜像。
所以：把代码和数据放在存储卷里，把环境和依赖装在容器里，才是可复用的组合。
另外，可写层里如果有密钥、令牌等敏感文件，也会一起被打进镜像，创建前先清理。
:::

### 在「镜像快照」页签看进度

实例详情页有一个 **镜像快照** 页签（只有开发服务有），列出这台实例的所有保存任务：

| 列 | 看什么 |
| --- | --- |
| 保存任务 | 任务名称，点进详情 |
| 状态 | 等待中 / 执行中 / 已完成 / 失败 |
| 创建时间 | 什么时候发起的 |
| 执行时长 | 这次保存花了多久 |
| 结果 | 成功时显示生成的镜像和 Tag |

点任务可以打开 **环境保存任务详情**，里面有分阶段进度：**校验环境 → 生成镜像 → 推送镜像 → 清理临时资源**，每个阶段都能看日志。日志流临时断开时页面会自动重连。

## 停止、重启、删除有什么区别

在列表行操作菜单或详情页 **操作** 菜单里能操作实例。三者差别很大，别点错：

| 操作 | 会发生什么 | 数据会丢吗 | 什么时候用 |
| --- | --- | --- | --- |
| 停止 | 释放计算资源，停止计费；实例本身还在列表里 | 挂载了存储卷就不会丢；临时目录会丢 | 一段时间不用，想省资源 |
| 启动 | 重新分配资源把实例跑起来 | 不涉及 | 继续用之前停掉的实例 |
| 保存当前环境 | 把容器当前状态保存成镜像，任务在**镜像快照**页签里跟进 | 不影响正在运行的实例 | 环境调好了，想固化成镜像 |
| 删除 | 二次确认后彻底移除实例及其关联资源 | **无法恢复**，存储卷里的文件除外 | 确定不再需要时 |

:::tip 想「重启」怎么办
平台没有单独的「重启」按钮。需要重启时，先点 **停止**，等状态变成 **已暂停**，再点 **启动** 即可。
:::

:::warning 删除是不可逆的
删除会同时释放实例占用的计算资源和关联资源，且无法恢复。数据只有放在挂载的存储卷里才能保住，删之前先确认。
:::

## 结果确认

- 列表里能看到这条实例，**状态** 从 等待中 / 执行中 变成 **运行中** 或 **健康**。
- **连接** 列出现 **访问** 或 **连接 VSCode** 按钮，说明实例已就绪。
- 点 **访问** 能打开 Web 界面，就表示开发环境可以用了。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 连接按钮是灰的 | 实例还没就绪，或被停止了 | 等状态变成运行中，或先点 **启动** |
| 没有 SSH / VSCode 入口 | 创建时没选 **授权用户** | 重新部署并选择你的 SSH 公钥 |
| 打开 Web 界面要求输入密码 | 模板设置了访问密码 | 用你填的密码；自动生成的要找回部署时的记录 |
| 实例里的文件重启后没了 | 没挂存储卷，用的是临时目录 | 重新部署并挂上 **文件存储** |
| 新建的镜像里没有我的代码 | 代码在存储卷里，镜像只保存容器可写层 | 代码继续走存储卷，镜像只固化环境 |
| 停止后想接着用 | 停止只释放资源，不删实例 | 在列表或详情页点 **启动** |
