# 模型评测

「模型评测」是 Rune 控制台里专门用来跑**模型评测任务**的一类实例。它替你拿一份评测数据集去考一考模型，给出分数，帮你判断「这个模型行不行，换个版本有没有变好」。

评测任务同样由模板创建：能考哪些能力、看哪些指标，由你选的评测模板决定。

:::tip 评测是什么
可以把它理解成「给模型安排一场考试」：评测数据集是试卷，评测框架是阅卷老师，指标就是分数。
:::

## 开始之前
- 角色：你的租户角色需要是**管理员**或**开发者**，否则左侧看不到「模型评测」菜单。
- 上下文：先在页面顶部选好**集群**和**工作空间**。
- 模板：集群里需要有评测类模板。

## 在哪里找到它
1. 在左侧菜单找到 **可观测性** 分组。
2. 点击 **模型评测**，进入评测任务列表。

![模型评测列表：右上角是「创建模型评测」按钮，空列表时显示「暂无数据」](/assets/screenshots/rune/evaluation-01.png)

评测任务和推理服务、微调任务一样都是实例，列表列有名称、评测引擎、资源规格、状态、访问、创建人和创建时间，只是「评测引擎」这一列替换成了对应的模板名。

## 创建一个评测任务
1. 点击列表右上角的 **创建模型评测**。
2. 在模板页选择评测模板和它的版本。

![评测模板选择页：每个模板一张卡片，卡片上有框架标签、版本下拉和「部署」按钮](/assets/screenshots/rune/evaluation-02.png)

3. 填写基本信息，再填写模板参数（例如模型路径、评测数据集、批次大小，是否需要 GPU 也由模板决定）。参数可在「图形 / JSON」两种模式之间切换填写。
4. 点击提交，回到 **模型评测** 列表等待任务运行。

> 基本信息、模板参数的具体字段由所选模板给出，页面会实时提示哪些是必填项。

## 评测列表怎么看
| 列 | 说明 |
| --- | --- |
| 名称 | 任务名称，点击进入详情页 |
| 评测引擎 | 这条任务用的是哪个评测模板 |
| 资源规格 | 占用的 CPU、内存、加速卡 |
| 状态 | 运行状态，见下表 |
| 访问 | Web、SSH 等快捷访问按钮 |
| 创建人 | 谁创建的 |
| 创建时间 | 任务创建时间 |

常见状态：

| 状态 | 含义 |
| --- | --- |
| 等待中 | 在排队，或正在拉取镜像 |
| 执行中 | 正在启动评测 |
| 运行中 / 健康 | 正在评测或已就绪 |
| 已完成 | 任务结束；若有样本失败会显示「已完成（有失败）」 |
| 已暂停 | 被手动停止 |
| 处理失败 | 出错了，去「日志」页签看原因 |
| 删除中 | 正在删除 |

鼠标悬停或选中一行，还能在行操作菜单里做 **启动 / 停止**、**编辑**、**删除** 等操作。

## 评测结果在哪里看
评测结果由所选评测框架自己产出，入口通常是这几个：

| 想看什么 | 去哪里 |
| --- | --- |
| 网页版报告 | 列表 **访问** 列点 Web 图标，或详情页的访问区 |
| 命令行输出目录 | 详情页 **概览**，在容器列表进入容器终端查看 |
| 运行过程日志 | 详情页 **日志** 页签 |

:::tip 基准和指标由模板决定
平台本身不预设固定的评测基准清单。能跑哪些数据集、输出哪些指标，取决于你选择的评测模板；请以模板的说明和页面上的字段为准。
:::

## 进入详情页能做什么
点任务名称进入详情页，顶部有四个页签：

| 页签 | 内容 |
| --- | --- |
| 概览 | 基本信息卡片、容器列表 |
| 监控 | 实例资源监控面板 |
| 日志 | 实例运行日志 |
| 事件 | 系统事件流，用于排查调度、挂载等问题 |

右上角 **操作** 菜单里有 **编辑**、**启动 / 停止**、**扩缩容**、**删除**。删除不可恢复，会先弹二次确认。

## 结果确认
在 **模型评测** 列表看到新任务，**状态** 变成「运行中」或「已完成」，说明评测在跑或已经跑完。若状态是「处理失败」，请打开「日志」页签定位原因。

## 常见问题
| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 状态一直是等待中 | 资源不足，或镜像还在拉取 | 等几分钟，或去「事件」页签看提示 |
| 状态是处理失败 | 参数或数据路径填错 | 打开「日志」页签看报错行 |
| 看不到任何基准 | 该模板不提供对应能力 | 换一个评测模板 |
| 创建后找不到任务 | 上下文切错了集群或工作空间 | 检查页面顶部的集群和工作空间 |
