# 训练与微调

微调就是**拿现成模型再补课**：用你自己的数据继续训练，让模型更懂你的业务。这一页带你从零提交第一个微调任务，说明关键参数怎么填、产物存到哪、怎么判断训练成功。部署方式与其他功能一致，都是「选模板 → 填参数 → 提交」。

:::tip 先记住三个词

- **基座模型**：还没针对你的业务训练过的通用模型，是这次训练要「补课」的底子。例如某个开源大模型。
- **数据集**：你用来补课的教材，需要先在平台里准备好、能选到。
- **LoRA**：一种只训练少量额外参数、不动原始权重的微调方式。省显存、产物小，新手推荐先用它。

:::

## 开始之前

- 你的租户角色需要是 **管理员** 或 **开发者**。
- 左上角先选好 **区域** 和 **工作空间**。
- 准备好数据和模型。数据集要在平台数据集里能选到；想长期保存训练产物，先建好一块 **文件存储**，见 [文件存储](/rune/console/storage)。
- 确认配额足够。7B 模型 LoRA 微调建议至少 24GB 显存，13B 建议 40GB 以上。

## 从零提交一个微调任务

1. 左侧 **工作台** 分组里点击 **训练与微调**。
2. 点击右上角的 **创建训练与微调任务**，进入模板选择页。
3. 选一个微调模板，确认 **版本**，点 **部署**。
4. 填写基础信息：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 名称 | 例如 `qwen-lora-test` | 必填，显示用；下方的 ID 会跟着自动生成 |
   | ID | 默认自动生成 | 想自定义就点铅笔图标；创建后不能改 |
   | 描述 | 例如「客服语料 LoRA 实验」 | 选填 |

5. 填写模板参数（见下一节）。
6. 点击页面底部的 **确定** 提交。

## 参数怎么填

以常用的 LLaMA-Factory 微调模板为例，表单分几大块。所有块都可以折叠，**带必填标记的必须填**。

| 表单项 | 怎么填 | 说明 |
| --- | --- | --- |
| 资源规格 | 选一套加速卡规格 | 必填。按模型大小选：7B 至少 24GB 显存，13B 至少 40GB |
| 运行模式 | 新手选 `快速微调` | 另有 `专家微调`（显示全部高级参数）和 `WebUI 界面`（启动图形界面，交互式操作） |
| 模型 | 从平台模型库选，或填外部模型 ID | 例如 `Qwen/Qwen2.5-7B-Instruct` |
| 数据集 | 从平台数据集里选，可多选 | 也可以填数据集路径或内置数据集名 |
| 对话模板 | 默认 `自动` | 会自动按模型名推断，一般不冲突就别改 |
| 训练阶段 | 新手选 `SFT` | 指令微调最常用；另有预训练、奖励模型、PPO/DPO/KTO 等 |
| 微调方法 | 新手选 `LoRA` | 省显存；`QLoRA` 更省；`全参数` 效果最好但最吃显存 |
| 输出目录 | 默认 `output` | 训练产物保存位置；启用了共享存储后此项不生效 |
| 学习率 | 默认 `5e-05` | LoRA 常用 1e-4~5e-5；太大不收敛，太小收敛慢 |
| 训练轮数 | 默认 `3` | 通常 1–5 轮，太多容易过拟合；可以填小数，如 0.5 表示半轮 |
| 批次大小 | 默认 `2` | 越大越稳但越吃显存，从 2 起逐步加 |
| 梯度累积步数 | 默认 `8` | 显存不够时靠它模拟大批次 |
| 截断长度 | 默认 `1024` | 超出长度的样本会被截断 |
| 最大样本数 | 默认 `100000` | 每个数据集最多用多少条；先填小值可以快速验证配置 |
| 验证集比例 | 默认 `0.1` | 抽 10% 数据监控训练效果，设为 0 则不划分 |
| 启用共享存储 | 想把产物给推理服务直接用就打开 | 打开后要再选一块 **共享文件存储** |
| 共享文件存储 | 选你建好的存储卷 | 训练产物写入该存储卷，推理服务可直接加载 |
| TrackIO 服务地址 | 可留空 | 从下拉里选一个已部署的指标服务，或手填地址；留空就不上报训练曲线 |
| 合并权重 | 默认关闭 | 把 LoRA 权重合并进基座模型，生成一个可独立使用的完整模型 |
| 推送到模型仓库 | 默认关闭 | 打开后需要填 **目标仓库**（HuggingFace Hub 或 ModelScope 魔搭）、**仓库模型 ID** 和 **仓库访问令牌** |

:::warning 关于镜像和端口
微调任务的**镜像由模板预设**，表单里不会让你选；也**没有需要你暴露的端口**。只有选了 **WebUI 界面** 模式，才需要访问图形界面，那就等实例就绪后用列表 **访问** 列里的按钮打开。
:::

不确定参数含义时，点参数卡片右上角的 **AI 配置指导**，它会结合当前模板和你已填的内容，逐项说明关键配置、必填项和风险。也可以点图标切到 JSON 模式直接改底层参数。

## 结果确认

提交后回到 **训练与微调** 列表：

1. 能看到这条任务，**状态** 列先显示 **等待中**，然后变成 **运行中**。
2. 训练结束时变成 **已完成**；中途出错会变成 **处理失败**。
3. 点任务名称进详情，**监控** 看指标曲线，**日志** 看训练输出，**事件** 排查失败原因。

:::tip 要等多久
取决于模型大小、数据量和你选的规格，没法给固定时长：小样本的 LoRA 明显快于全参数训练。训练期间可以关掉页面，任务在后台继续跑。
:::

## 去哪里拿产物

训练完成后（状态 **已完成**）：

1. 产物保存在模板参数指定的输出位置。
2. 如果启用了 **共享存储**，产物就在你选的那块存储卷里；否则在 **输出目录** 指定的路径下。
3. 进入 [文件存储](/rune/console/storage) 打开对应存储卷的文件管理器，就能浏览和下载模型文件。
4. 训练日志和检查点也在这份产物里，按保存步数保留最近的若干个检查点。

## 日常管理

在列表行操作菜单或详情页 **操作** 菜单里：

| 操作 | 说明 |
| --- | --- |
| 编辑 | 改名称、描述和参数 |
| 启动 / 停止 | 停止会释放计算资源；恢复后再点 **启动** |
| 保存为任务模版 | 把当前配置存成模板，下次一键复用 |
| 删除 | 二次确认后删除任务，无法恢复 |

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 状态停在等待中 | 资源不足，排队中 | 检查配额，或换更小的规格 |
| 处理失败，日志报显存不足 | 规格太小或批次太大 | 减小批次大小、打开梯度检查点，或换更大规格 |
| 训练完了找不到产物 | 输出路径没注意，或没挂共享存储 | 到对应存储卷的文件管理器里按输出目录找 |
| 「访问」列没有按钮 | 当前模板不提供 Web 访问 | 非 WebUI 模式属正常，看日志和监控即可 |
