# 首页

首页是你登录 Rune 控制台后默认打开的页面，用来在**当前区域 + 当前工作空间**的范围内，一眼看清家底：有多少实例、配额还剩多少、存储用了多少、有没有需要处理的问题。你不用逐个菜单点进去翻，先看这一页就能判断「今天有没有事要处理」。

:::tip 把首页当成汽车的仪表盘
它不负责开车，只负责告诉你油量（配额）、水温（资源利用率）、故障灯（需要关注）。看到异常再点进去处理。
:::

## 开始之前

- 已登录并选择租户。
- 页面左上角要先选好 **区域** 和 **工作空间**。没选工作时，页面只显示一句提示：请选择区域和工作空间后查看概览数据。
- 没有权限限制，所有成员都能看首页。

## 页面从上到下有哪些区块

打开首页，先对照下图有个整体印象：

![首页：顶部是待关注横幅和六项概览卡片，中部是资源配额与平均资源利用率，下方是数据存储与存储卷使用情况](/assets/screenshots/rune/dashboard-01.png)

图里这块数据取自一个演示工作空间：待关注横幅显示「当前无待关注项」，说明当时没有需要处理的问题。你看到的是黄色横幅时，就点它右侧的 **查看详情** 去处理。

| 区块 | 你能看到什么 |
| --- | --- |
| 页头 | 标题「工作空间概览」和右侧的 **刷新** 按钮 |
| 待关注横幅 | 一条汇总：有几项需要关注、其中几个异常工作负载、几项配额到阈值、几个存储卷容量偏高；点右侧 **查看详情** 跳到下面的问题清单 |
| 概览卡片 | 工作负载总数、运行中 / 健康、处理中、异常、配额告警、存储使用 |
| 资源配额 | 资源配额占用情况，以及最近 24 小时的平均资源利用率 |
| 数据存储 | 存储总容量、已使用、可用容量、存储卷数量、整体存储使用率 |
| 工作负载状态 | 按类型统计实例状态分布 |
| 需要关注 | 一张问题清单，点 **查看** 直接跳到对应实例或配额页 |

:::tip 数据不对先点刷新
右上角的 **刷新** 按钮会重新拉取这一页所有数据。数据加载期间按钮会转圈并暂时不可点，属正常现象。
:::

## 怎么看懂这几块数据

### 概览卡片

最上面一排是「一句话结论」，数字有异常时优先看这里：

| 卡片 | 含义 |
| --- | --- |
| 工作负载总数 | 当前空间里一共有多少实例 |
| 运行中 / 健康 | 正常工作的实例数 |
| 处理中 | 正在创建、启动或调整中的实例数 |
| 异常 | 需要你介入的实例数 |
| 配额告警 | 达到告警阈值的配额项数量 |
| 存储使用 | 存储的整体使用情况 |

### 资源配额

展示算力配额（CPU、内存、加速卡）和最近 24 小时的平均资源利用率。如果某项已经接近上限，新建实例时可能因为配额不足而失败，需要先去 [配额](/rune/console/quota) 里调整。

### 数据存储

展示存储总容量、已使用、可用容量和存储卷数量，下面还有一张「存储卷使用情况」表，列出每个存储卷的名称、存储集群、使用率、挂载状态（已挂载 / 未挂载）和状态（正常 / 容量偏高）。

### 工作负载状态

按类型分组统计实例状态：推理服务、微调任务、开发环境、应用、评测任务、实验。每条任务的状态归为五类：

| 状态 | 含义 |
| --- | --- |
| 运行中 | 实例正常工作 |
| 调度中 | 正在等待资源或正在创建 |
| 已完成 | 任务型实例（如微调）已经跑完 |
| 已暂停 | 被手动停止 |
| 异常 | 失败或状态异常，需要处理 |

### 需要关注

这一块是一张表，列有 **名称、对象类型、问题、更新时间、操作**。常见问题包括 **运行失败**、**状态异常**、**容量偏高**、**使用率偏高**。点最右侧的 **查看** 会直接跳到对应的实例详情、存储卷或配额页面。清单为空时会显示「当前无待关注项」。

## 结果确认

- 看到六项概览卡片有数字，说明当前工作空间的数据已经正常加载。
- 如果页头下方出现黄色提示「部分概览数据暂时不可用，其余模块仍可正常使用。」，说明有个别数据源暂时取不到，其他区块仍然可用，刷新或稍后再看即可。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 只有一句「请选择区域和工作空间后查看概览数据」 | 还没选工作空间 | 用左上角的选择器选一个工作空间 |
| 所有数字都是 0 | 当前工作空间下确实还没有实例 | 去对应菜单创建实例，或切换到别的工作空间 |
| 顶部出现「部分概览数据暂时不可用」 | 个别数据源短暂异常 | 点右上角 **刷新** 重试 |
| 加速卡 / 利用率显示暂无数据 | 该指标暂时不可用 | 稍后再看，或到实例详情页的 **监控** 查看 |
