# 应用市场

应用市场是平台的**模板货架**：推理、微调、开发环境、实验、应用五大类的现成模板都摆在这里。你在这里只做一件事——挑一个合适的模板，点 **部署**，把它变成自己的实例。这一页讲怎么逛、怎么看详情、怎么一键部署，以及它和「应用实例」的区别。

:::tip 一句话区分市场和你部署出来的东西

- **应用市场**是货架：模板是别人做好的「菜谱」，摆着不占你的资源。
- **应用实例**是你按菜谱做出来的「菜」：会占用算力、配额，会出现在对应的实例列表里。

市场里选模板 → 实例列表里管理运行结果。

:::

## 开始之前

- 应用市场属于**首页**分组，所有成员都能浏览，没有额外角色要求。
- 左上角先选好 **区域** 和 **工作空间**；部署时会把实例创建到当前工作空间。
- 想部署某个模板，你的租户角色需要是该模板类型对应的权限（工作台类模板一般要求 **管理员** 或 **开发者**）。

## 逛市场

左侧 **首页** 分组里点击 **应用市场**。

| 区域 | 怎么用 |
| --- | --- |
| 推荐轮播 | 页面最上面是推荐模板，每 10 秒自动切换；鼠标移上去出现左右箭头，可手动翻 |
| 分类按钮 | 选 全部 / 推理 / 微调 / 开发 / 实验 / 应用，每个按钮后面带模板数量 |
| 搜索框 | 输入关键词，对模板名称和描述做模糊搜索，输入后稍等片刻自动出结果 |
| 刷新按钮 | 重新拉取模板列表 |
| 模板卡片 | 展示图标、名称、简介、分类和版本，点击进入详情 |
| 分页 | 列表下方的翻页控件，按分类分页浏览 |

:::tip 找不到模板怎么办
市场只支持「分类 + 关键词搜索」，没有按语言、框架、操作系统、工具筛选的标签。定位不到时，换个关键词，或进详情页看模板介绍。
:::

## 看模板详情

点击任意模板卡片进入详情页，页面分三块：

| 区域 | 内容 |
| --- | --- |
| 顶部页签 | **介绍**（模板能做什么、怎么用）和 **版本说明**（这个版本的变更） |
| 右侧信息卡 | 模板名称、**版本** 下拉按钮、描述，以及 **部署** 按钮 |
| 信息卡下方 | 分类、创建时间 |

**版本** 按钮上显示当前选中的版本，点开下拉可以切换。切换版本后，右侧描述和部署时用到的参数都会跟着变，**部署前先确认版本选对了**。

## 从市场一键部署

1. 在模板详情页点 **版本** 下拉，选一个版本。
2. 点击 **部署**。
3. 页面会跳到对应类型的实例列表，并自动弹出部署表单（已经带上了你选的模板和版本）。
4. 填写基础信息：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 名称 | 例如 `my-service` | 必填，显示用；下方的 ID 会跟着自动生成 |
   | ID | 默认自动生成 | 想自定义就点铅笔图标；创建后不能改 |
   | 描述 | 例如「试用模板」 | 选填 |

5. 填写模板参数。参数多少由模板决定，不确定的项可以点右上角的 **AI 配置指导** 让它解释。
6. 点击底部的 **确定** 提交。

:::tip 也可以从功能菜单进
不想先逛市场也行：直接进 **推理服务 / 训练与微调 / 开发服务 / 应用实例** 等菜单，点右上角的 **创建…** 按钮，一样会进入模板选择页，选好模板再点 **部署**。
:::

## 结果确认

提交后，页面回到对应类型的**实例列表**：

1. 列表里能看到刚创建的实例，**状态** 列先是 **等待中** 或 **执行中**。
2. 稍后变成 **运行中** 或 **健康**，表示部署成功。
3. 之后在左侧对应菜单里就能找到并管理它。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 部署按钮点了没反应 / 提示先去选工作空间 | 左上角没选工作空间 | 先选好 **区域** 和 **工作空间** 再部署 |
| 部署表单字段和我预期的不一样 | 参数由所选**版本**的模板决定 | 回详情页确认版本；不同版本参数不同 |
| 找不到标签筛选 | 市场没有标签筛选能力 | 用分类 + 关键词搜索替代 |
| 搜索没立刻出结果 | 搜索框有短暂输入延迟 | 停顿一下等结果刷新 |
