# SDK 介绍

魔哈 SDK 是一套让你**不打开网页也能操作魔哈仓库**的工具：装一次，就能在终端里用 `moha` 命令登录、上传、下载、管理仓库，
也可以在 Python 代码里调用同一套能力。如果你经常批量传模型、写自动化脚本，它比网页点击省事得多。

## 它由两部分组成

| 部分 | 是什么 | 你怎么用 |
| --- | --- | --- |
| 命令行工具 `moha` | 装好后就有的终端命令 | 在终端里敲 `moha <子命令>` |
| Python 库 | 一组可以在代码里 import 的函数和类 | 在 `.py` 文件里 `from xiaoshiai_hub import ...` |

两部分安装在同一个包里，装一次两个都能用。

## 能做什么

| 能力 | 命令行 | Python |
| --- | --- | --- |
| 登录与退出 | `moha login` / `moha logout` | `login()` / `delete_token()` |
| 选择当前组织 | `moha organization use` | `save_current_organization()` |
| 列出、创建、查看、更新、删除仓库 | `moha list` / `create` / `info` / `update` / `delete` | `HubClient` 上的对应方法 |
| 管理分支 | `moha refs` / `branch-create` / `branch-delete` / `branch-list` | `get_repository_refs()` / `create_branch()` 等 |
| 上传下载 | `moha upload` / `download` | `upload_file()` / `upload_folder()` / `moha_hub_download()` / `snapshot_download()` |
| 发布和管理空间（Space） | `moha deploy` / `status` / `logs` | `deploy_space()` / `get_space_status()` |
| 加密大模型文件 | `moha upload --encrypt` | `upload_file(encryption_password=...)` |
| AI 助手 | `moha ai` | 无 |

## 最小可运行示例

装好之后，终端里跑一句就能列出当前组织下的仓库：

```bash
moha list model
```

在 Python 里做同一件事：

```python
from xiaoshiai_hub import HubClient

# 用登录后保存的令牌连接平台
client = HubClient()
repos = client.list_repositories(
    repo_type="models",
    scope="organization",
    organization="<组织名>",
)
for repo in repos:
    print(repo.name)
```

逐项解释：

| 代码 | 含义 |
| --- | --- |
| `HubClient()` | 创建一个连接平台的对象；不传令牌时会自动读取本机登录时保存的令牌 |
| `repo_type="models"` | 只列模型仓库；也可换成 `"datasets"` 或 `"spaces"` |
| `scope="organization"` | 只看某个组织；此时必须再给 `organization` |
| `organization="<组织名>"` | 要查看的组织名 |
| `repo.name` | 仓库名 |

:::info 令牌从哪来
`HubClient()` 不传令牌也能用，是因为你先运行过 `moha login`，令牌被保存到了本机。详见 [认证与令牌管理](./authentication)。
:::

## 和 HuggingFace 生态的关系

平台提供了一套与 HuggingFace Hub 兼容的接口。已经装了 `transformers`、`datasets`、`huggingface_hub` 的机器，
只要把地址指到平台，原来的代码基本不用改：

```bash
export HF_ENDPOINT=https://<平台地址>/moha/huggingface
export HF_TOKEN=<访问令牌>
```

参数说明：

| 参数 | 说明 |
| --- | --- |
| `HF_ENDPOINT` | 指向平台的兼容接口地址，必须以 `/moha/huggingface` 结尾 |
| `HF_TOKEN` | 你的访问令牌，公开仓库可以不填 |

除了 SDK，平台上的每个仓库也提供 Git 地址，可以直接 `git clone` 拉取，大文件走 Git LFS。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| `import xiaoshiai_hub` 报错找不到模块 | 没装或装到了别的 Python 环境 | 用装包时同一个 Python 运行代码；参考 [安装与环境配置](./install) |
| 连接的是内网测试地址而不是你的平台 | 环境变量里残留了旧地址 | 检查并清理 `MOHA_ENDPOINT` 后再试 |
