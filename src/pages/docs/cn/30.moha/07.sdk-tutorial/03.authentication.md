# 认证与 Token 管理

认证就是让魔哈平台知道「你是谁」。认证一次之后，令牌会存在你电脑上，以后所有命令都自动用它，不用每次重输。

你可以用两种方式认证：**访问令牌**（推荐，安全）或**账号密码**（最省事，登录后平台会替你换成令牌）。

## 开始之前

- 你有一个魔哈平台账号（用户名 + 密码）。
- 你知道平台地址，形如 `https://<平台地址>`。

## 怎么拿到访问令牌

方式一：直接在网页上复制（已经有平台账号就能做）

1. 登录平台，进入 **魔哈Hub**。
2. 在首页左侧栏点击 **访问令牌**（在 **我喜欢的** 下面）。
3. 页面上会显示你当前的访问令牌，点击旁边的复制按钮即可复制。
4. 把复制到的内容当作 `<访问令牌>` 使用。

方式二：不用手动拿，直接用账号密码登录（推荐新手）

运行 `moha login` 时输入账号密码，平台会自动发放令牌并保存到本机，你不需要看到令牌原文。

:::warning 令牌等于你的密码
访问令牌能代表你访问平台资源，**不要**把它贴到聊天群、公开代码仓库或截图里。泄露后请立刻重新登录以更换令牌。
:::

## 怎么在命令行登录

最省事的方式是交互式登录，命令只需要平台地址：

```bash
moha login https://<平台地址>
```

回车后终端会依次问：

1. `Token (leave empty to log in with username/password):` — 直接回车。
2. `Username:` — 输入用户名，回车。
3. `Password:` — 输入密码，回车（不显示字符是正常的）。
4. 如果列出了多个组织，输入你要用的编号或组织名，回车。

成功后终端显示 `Login succeeded`，并打印当前组织和配置文件路径。

如果你手上已经有访问令牌，可以一步到位：

```bash
moha login https://<平台地址> --token <访问令牌>
```

参数说明：

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `https://<平台地址>` | 是 | 无 | 平台地址，**必须带 `https://`**，不能只写域名 |
| `--token <访问令牌>` | 否 | 无 | 用已有令牌登录；不填则交互输入账号密码 |
| `--username` / `-u` | 否 | 无 | 直接写用户名，跳过交互输入 |
| `--password` / `-p` | 否 | 无 | 直接写密码，跳过交互输入 |
| `--token-dir` | 否 | `~/.moha` | 换个目录保存登录信息 |

登录完成不代表一定要记住账号：之后运行 `moha whoami` 可以看到当前登录状态：

```bash
moha whoami
```

## 令牌存在哪里

登录信息保存在你电脑的用户目录下：

| 项目 | 位置 / 表现 |
| --- | --- |
| 配置文件 | `~/.moha/config.json` |
| 里面存了什么 | 访问令牌、平台地址、用户名、当前组织 |
| 文件权限 | 仅本人可读写（不会被同机器其他用户读到） |
| 自定义位置 | 登录时加 `--token-dir <目录>` 可改 |

:::info 换机器或换目录
在别的机器上没有这个文件，所以需要重新 `moha login`，或者临时用环境变量 `MOHA_TOKEN` 提供令牌。
:::

## 怎么换令牌 / 换账号

换令牌不需要先删旧的，重新登录一次就会覆盖：

```bash
moha login https://<平台地址> --token <新访问令牌>
```

如果要彻底退出，让本机不再保留登录信息：

```bash
moha logout
```

如果只是想在某一条命令里临时用另一个令牌（不改本机保存的），可以现场指定：

```bash
moha download <组织名>/<模型名> --token <临时访问令牌>
```

或者在当前终端会话里设置环境变量：

```bash
export MOHA_TOKEN=<临时访问令牌>
```

认证信息的优先级从高到低是：**命令里指定的** > **环境变量** > **本机保存的**。

## 令牌过期或被吊销后怎么办

令牌过期、被管理员吊销，或者你改了密码，之后运行命令会报认证失败。处理方法都一样：**重新登录一次**。

```bash
moha login https://<平台地址>
```

对照表：

| 现象 | 可能原因 | 怎么做 |
| --- | --- | --- |
| 命令报认证失败、401 未授权 | 令牌过期或被吊销 | 重新运行 `moha login` |
| 之前能用、突然全部命令失败 | 账号被停用或密码被改 | 先在网页上确认能正常登录，再重新 `moha login` |
| `moha whoami` 显示未登录 | 本机没有保存的登录信息 | 运行 `moha login` |
| 一直提示用户名或密码错误 | 密码输错或账号不存在 | 核对账号密码，或改用访问令牌登录 |

## 公开仓库和私有仓库的差别

| 仓库类型 | 不登录能不能用 | 说明 |
| --- | --- | --- |
| 公开仓库 | 能下载，也能列出 | 无需令牌，任何知道仓库名的人都能拉取 |
| 私有 / 内部仓库 | 不能 | 必须用有权限的账号登录后才能下载、上传、查看 |

所以第一次使用前，**先登录一次**最省心；只有当你确定只下载公开仓库时，才可以不登录。

## 在 Python 代码里使用

如果你用代码调用，登录一次后可以不传令牌，库会自动读取本机保存的信息：

```python
from xiaoshiai_hub import HubClient

client = HubClient()  # 自动使用本机保存的令牌
```

也可以显式传令牌，适合写自动化脚本时从环境变量取值：

```python
import os

from xiaoshiai_hub import HubClient

client = HubClient(token=os.environ["MOHA_TOKEN"])
```

常用的认证函数：

| 函数 | 作用 |
| --- | --- |
| `login(username, password, base_url)` | 用账号密码登录，并把令牌保存到本机 |
| `save_token(token, base_url, username)` | 手动保存令牌到本机 |
| `load_token()` | 读取本机保存的令牌、平台地址、用户名 |
| `delete_token()` | 删除本机保存的令牌（等价于 `moha logout`） |
