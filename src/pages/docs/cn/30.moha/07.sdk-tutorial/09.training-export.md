# 模型训练与导出工作流

这一页解决一件事：**训练完的模型，怎么让它出现在魔哈的模型仓库里**。
从「从平台拉基础模型和数据集」开始，到「模型在网页上能看到」为止，中间每一步都写清楚。训练部分用的是通用写法，重点在最后两步的导出与回传。

## 开始之前

- 已装好 SDK：`pip install moha-hub`，并且已经登录或准备好访问令牌。
- 要训练的话再装：`pip install transformers datasets torch`（用 LoRA 再加 `pip install peft`）。
- **目标仓库要先建好**。上传不会自动建仓库，仓库不存在会直接报错。
- 训练环境（显卡、显存）由你自己的机器或平台上的开发环境提供，这一页不涉及。

## 最小可运行示例

假设模型已经训练完并保存在 `./output`，把它传上去并确认只用三步：

```bash
# 1. 先建好仓库（组织名换成你自己的）
moha create model ai-lab/my-finetuned-model --description "微调模型"

# 2. 上传模型目录
moha upload ai-lab/my-finetuned-model ./output --message "上传微调模型"

# 3. 确认仓库已经能看到
moha info model ai-lab/my-finetuned-model
```

:::tip 上传前先想清楚传什么
训练输出目录里常有 `checkpoint-100`、`optimizer.pt` 这类中间文件，它们对使用模型没有帮助，只会让上传变慢。建议只传最终那份模型文件，或用过滤参数跳过大文件。
:::

## 第一步：从平台取基础模型和数据集

```python
from xiaoshiai_hub import snapshot_download

base_dir = snapshot_download(
    repo_id="ai-lab/qwen2-7b",
    local_dir="./base/qwen2-7b",
    token="<访问令牌>",
)

data_dir = snapshot_download(
    repo_id="ai-lab/training-data",
    repo_type="datasets",
    local_dir="./data/training-data",
    token="<访问令牌>",
)
print(base_dir, data_dir)
```

之后 `transformers` / `datasets` 只面对这两个本地目录，不用再联网。

## 第二步：训练并保存

### 最简全量微调

```python
from datasets import load_dataset
from transformers import (
    AutoModelForCausalLM,
    AutoTokenizer,
    Trainer,
    TrainingArguments,
)

base_dir = "./base/qwen2-7b"
out_dir = "./output"

tokenizer = AutoTokenizer.from_pretrained(base_dir)
model = AutoModelForCausalLM.from_pretrained(base_dir)

dataset = load_dataset("json", data_files="./data/training-data/*.jsonl", split="train")

def preprocess(examples):
    result = tokenizer(examples["text"], truncation=True, max_length=512)
    result["labels"] = result["input_ids"].copy()   # 因果语言模型：标签就是输入本身
    return result

dataset = dataset.map(preprocess, batched=True, remove_columns=["text"])

trainer = Trainer(
    model=model,
    args=TrainingArguments(
        output_dir=out_dir,
        num_train_epochs=1,
        per_device_train_batch_size=1,
    ),
    train_dataset=dataset,
)
trainer.train()

# 保存最终模型（Safetensors 格式，平台推荐）
model.save_pretrained(out_dir, safe_serialization=True)
tokenizer.save_pretrained(out_dir)
```

- 显存不够时优先调小 `per_device_train_batch_size`，或者改用下面的 LoRA。
- `safe_serialization=True` 会写成 `.safetensors`，这是平台上最通用、加载最快的格式。

### 用 LoRA 省显存

LoRA 只训练一小部分参数，产出的适配器目录很小，上传特别快。

```python
from peft import LoraConfig, get_peft_model, TaskType

peft_config = LoraConfig(
    task_type=TaskType.CAUSAL_LM,
    r=8,
    lora_alpha=32,
    lora_dropout=0.1,
    target_modules=["q_proj", "v_proj"],
)
model = get_peft_model(model, peft_config)

# ……照常 trainer.train()……

model.save_pretrained("./lora-adapter")   # 只存适配器，很小
tokenizer.save_pretrained("./lora-adapter")
```

要不要把适配器合并进完整模型，取决于你怎么用：

| 你的场景 | 传什么 |
| --- | --- |
| 只想保存这次微调的成果、按需叠加 | 直接传适配器目录 |
| 想要一个能独立加载的完整模型 | 先合并再传（见下） |

```python
from peft import PeftModel
from transformers import AutoModelForCausalLM

base = AutoModelForCausalLM.from_pretrained("./base/qwen2-7b")
merged = PeftModel.from_pretrained(base, "./lora-adapter").merge_and_unload()
merged.save_pretrained("./merged-model", safe_serialization=True)
```

## 第三步：导出成平台认识的格式

魔哈仓库本质上是「文件仓库 + 版本管理」，你传什么格式它就存什么格式。区别在于**别人能不能直接用 `transformers` 加载**。

| 格式 | 怎么来 | 说明 |
| --- | --- | --- |
| Safetensors | `save_pretrained(..., safe_serialization=True)` | 推荐。`transformers` 能直接加载，平台上的模型基本都是它 |
| PyTorch bin | `save_pretrained(..., safe_serialization=False)` | 能加载，但没有 Safetensors 安全、快 |
| ONNX | 用你自己的工具链转换 | 传给别的推理引擎用，`transformers.from_pretrained` 不认 |
| TorchScript | 用你自己的工具链转换 | 同上 |
| GGUF | 用对应生态的转换脚本 | 给 CPU 侧推理工具用 |
| TensorRT | 用对应的转换工具 | 给 NVIDIA GPU 高性能推理用 |

:::warning 转换格式由你自己完成
平台只负责存储和分发文件，不提供在线格式转换。ONNX、GGUF、TensorRT 这些要在本地用各自的工具转好，再把产物当普通文件上传。另外，加了转换之后如果目录里缺少 `config.json` 那套结构，`from_pretrained` 就不一定能直接加载，传之前最好本地验证一次。
:::

## 第四步：把产物传回魔哈

### 先建仓库

```bash
moha create model ai-lab/my-finetuned-model --description "基于 qwen2-7b 微调"
```

也可以在 Python 里建（见 [HubClient API 详解](./hub-api)）：

```python
from xiaoshiai_hub import HubClient

client = HubClient(base_url="<平台地址>", token="<访问令牌>")
client.create_repository(
    organization="ai-lab",
    repo_type="models",
    repo_name="my-finetuned-model",
    description="基于 qwen2-7b 微调",
    visibility="internal",
    base_model=["ai-lab/qwen2-7b"],
    relationship="finetune",
)
```

### 再上传目录

```python
from xiaoshiai_hub import upload_folder

upload_folder(
    folder_path="./output",
    repo_id="ai-lab/my-finetuned-model",
    commit_message="上传微调模型",
    ignore_patterns=[
        "checkpoint-*",      # 中间检查点
        "optimizer.pt",      # 优化器状态，用不到
        "scheduler.pt",
        "rng_state.pth",
        "training_args.bin",
        "__pycache__/*",
        "*.pyc",
    ],
)
print("上传完成")
```

- `repo_type` 默认就是 `models`，不太需要改。
- 上传的文件大于等于 5 MB 时会自动走大文件通道并显示进度；模型权重通常都会走这条。
- 想把文件放进仓库的子目录，加 `path_in_repo="v1.0"`。

命令行等价写法：

```bash
moha upload ai-lab/my-finetuned-model ./output \
  --exclude "checkpoint-*" \
  --exclude "optimizer.pt" \
  --message "上传微调模型"
```

## 第五步：确认模型已经在平台上

```python
from xiaoshiai_hub import HubClient

client = HubClient(base_url="<平台地址>", token="<访问令牌>")

info = client.get_repository_info("ai-lab", "models", "my-finetuned-model")
print(info.organization, info.name, info.visibility)

# 看看文件有没有都在
content = client.get_repository_content(
    "ai-lab", "models", "my-finetuned-model", branch="main"
)
for item in content.entries or []:
    print(item.type, item.path, item.size)
```

命令行：`moha info model ai-lab/my-finetuned-model`。

看到权重文件、`config.json`、tokenizer 相关文件都在，就说明模型已经在平台上了，别人可以直接下载或按 [与 Transformers & Datasets 集成](./transformers-datasets) 里的方式加载。

## 完整端到端示例

```python
from datasets import load_dataset
from transformers import (
    AutoModelForCausalLM,
    AutoTokenizer,
    Trainer,
    TrainingArguments,
)

from xiaoshiai_hub import HubClient, snapshot_download, upload_folder

BASE_REPO = "ai-lab/qwen2-7b"
DATA_REPO = "ai-lab/training-data"
TARGET_REPO = "ai-lab/my-finetuned-model"
ORG, NAME = TARGET_REPO.split("/")

# 1. 从平台取基础模型和数据
base_dir = snapshot_download(repo_id=BASE_REPO, local_dir="./base/qwen2-7b")
data_dir = snapshot_download(
    repo_id=DATA_REPO, repo_type="datasets", local_dir="./data/training-data"
)

# 2. 训练
tokenizer = AutoTokenizer.from_pretrained(base_dir)
model = AutoModelForCausalLM.from_pretrained(base_dir)
dataset = load_dataset("json", data_files=f"{data_dir}/*.jsonl", split="train")

def preprocess(examples):
    result = tokenizer(examples["text"], truncation=True, max_length=512)
    result["labels"] = result["input_ids"].copy()
    return result

dataset = dataset.map(preprocess, batched=True, remove_columns=["text"])

trainer = Trainer(
    model=model,
    args=TrainingArguments(
        output_dir="./output", num_train_epochs=1, per_device_train_batch_size=1
    ),
    train_dataset=dataset,
)
trainer.train()
model.save_pretrained("./output", safe_serialization=True)
tokenizer.save_pretrained("./output")

# 3. 在平台上建仓库（已存在会报错，可以跳过这步）
client = HubClient(base_url="<平台地址>", token="<访问令牌>")
client.create_repository(
    organization=ORG,
    repo_type="models",
    repo_name=NAME,
    description="基于 qwen2-7b 微调",
    base_model=[BASE_REPO],
    relationship="finetune",
)

# 4. 上传产物
upload_folder(
    folder_path="./output",
    repo_id=TARGET_REPO,
    commit_message="上传微调模型",
    ignore_patterns=["checkpoint-*", "optimizer.pt", "scheduler.pt", "training_args.bin"],
)

# 5. 确认
info = client.get_repository_info(ORG, "models", NAME)
print(f"模型已在平台：{info.organization}/{info.name}")
```

## 常见报错

| 报错 | 含义 | 怎么办 |
| --- | --- | --- |
| `RepositoryNotFoundError: Repository not found: ... Please create the repository first.` | 还没建仓库就直接上传 | 先 `moha create model 组织/仓库名` |
| `FileNotFoundError: File not found: ...` | 要上传的目录路径不对 | 确认 `folder_path` 指向的是训练输出目录 |
| `ValueError: Path is not a directory: ...` | 把文件路径给了 `upload_folder()` | 传文件请用 `upload_file()` |
| 网页上看不到刚传的权重 | 进了子目录，或上传到了别的分支 | 用 `get_repository_content()` 列目录；确认 `revision` 分支对不对 |
| 上传很慢 | 把中间检查点和优化器状态一起传了 | 用 `ignore_patterns` 跳过 `checkpoint-*`、`optimizer.pt` |
| 别人 `from_pretrained` 加载失败 | 目录里缺 `config.json` 或权重不是标准命名 | 用 `save_pretrained()` 保存，别手动拷贝零散文件 |
| `UploadError: Upload failed: ...` | 上传被服务端拒绝 | 多为权限或配额问题，看后面的具体原因 |
