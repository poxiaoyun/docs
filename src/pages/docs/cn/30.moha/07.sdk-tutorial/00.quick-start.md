# 5 分钟快速开始

这一页带你从零装好 `moha` 命令行工具，然后依次跑通登录、下载一个仓库、把本地文件传上去。
全程只需要你会复制粘贴命令，不需要写 Python 代码。

:::tip 你会用到三样东西

- 一台能联网、装了 Python 的电脑
- 魔哈平台的地址（形如 `https://<平台地址>`，问你的管理员要）
- 你的平台账号密码，或者一个访问令牌

下面的示例里，`<平台地址>`、`<组织名>`、`<模型名>` 这些尖括号内容都要换成你自己的真实值。

:::

## 开始之前

- 确认电脑上装了 **Python 3.10 或更高版本**。在终端里运行 `python3 --version`，看到 `3.10` 以上即可。
- 如果你还没装 Python，先去 [Python 官网](https://www.python.org/downloads/) 下载安装。
- 准备好平台**地址**和**账号密码**（或访问令牌）。

## 第 1 步：安装命令行工具（约 30 秒）

把下面这行完整复制到终端里回车：

```bash
pip install moha-hub
```

装完后再运行一条命令确认工具能用：

```bash
moha --version
```

看到类似 `moha 2.0.1` 的版本号，就说明装好了。

参数说明：

| 参数 | 说明 |
| --- | --- |
| `pip install moha-hub` | 从 Python 官方软件源安装魔哈命令行工具，包名固定为 `moha-hub` |
| `moha --version` | 打印已安装的版本号；看不到版本号说明没装成功 |

## 第 2 步：登录（约 1 分钟）

把平台地址换成你自己的，运行：

```bash
moha login https://<平台地址>
```

回车后终端会依次问你几件事，照着做：

1. 出现 `Token (leave empty to log in with username/password):`，**直接回车**（表示用账号密码登录）。
2. 出现 `Username:`，输入你的平台用户名，回车。
3. 出现 `Password:`，输入密码，回车（输入时屏幕不显示字符，是正常的）。
4. 如果平台上有多个组织，会列出组织编号，输入你要用的**编号或组织名**，回车。

登录成功后，终端会显示 `Login succeeded`，并告诉你当前组织和配置文件路径。

参数说明：

| 参数 | 说明 |
| --- | --- |
| `https://<平台地址>` | 平台地址，**必须带 `https://` 前缀**，不能只写域名 |
| `--username <用户名>` | 可选。不想交互输入用户名时，直接写在命令里 |
| `--password <密码>` | 可选。不想交互输入密码时，直接写在命令里 |
| `--token <访问令牌>` | 可选。已有访问令牌时，用它代替账号密码登录 |

:::warning 关于平台地址
地址一定要写成 `https://<平台地址>`。只写 `moha.example.com` 这种不带前缀的形式会直接报错，提示地址格式不对。
:::

## 第 3 步：下载一个仓库到本地（约 1 分钟）

用别人分享给你的仓库 ID（格式是 `组织名/仓库名`），运行：

```bash
moha download <组织名>/<模型名>
```

例如：

```bash
moha download demo/my-model
```

命令跑完会显示 `Download completed` 和本地路径。
不指定目录时，文件会下载到当前目录下的 `./downloads/<组织名>_models_<仓库名>/`。

参数说明：

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<组织名>/<仓库名>` | 是 | 无 | 要下载的仓库，第一次参数 |
| `--local-dir` | 否 | `./downloads/<组织名>_models_<仓库名>/` | 指定下载到哪个目录 |
| `--repo-type` | 否 | `model` | 仓库类型，可选 `model`、`dataset`、`space` |
| `--revision` | 否 | 仓库默认分支 | 指定下载哪个分支或标签 |

## 第 4 步：把本地文件传上去（约 2 分钟）

先 `cd` 进入你放了文件的目录，然后运行：

```bash
moha upload <组织名>/<模型名> ./你的文件或文件夹
```

例如把本地的 `config.yaml` 传上去：

```bash
moha upload demo/my-model ./config.yaml
```

命令跑完会显示 `Upload succeeded`。

参数说明：

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<组织名>/<仓库名>` | 是 | 无 | 传到哪个仓库，第一次参数**是仓库** |
| `./本地路径` | 是 | 无 | 要上传的文件或文件夹，第二次参数**是本地路径** |
| `--revision` | 否 | `main` | 上传到哪个分支 |
| `--message` | 否 | 无 | 本次上传的提交说明 |

:::tip 顺序别搞反
上传命令两个参数，**先写仓库、后写本地路径**。如果写反了（先本地路径、后仓库），新版本仍能识别，但建议记住「仓库在前」这个顺序。
:::

## 结果确认

- 登录成功：终端显示 `Login succeeded`，之后运行 `moha whoami` 会显示 `Login Status: Logged in`。
- 下载成功：终端显示 `Download completed`，并且用 `ls ./downloads` 能看到一个以仓库名命名的文件夹。
- 上传成功：终端显示 `Upload succeeded`；回到魔哈网页打开这个仓库，能在文件列表里看到你刚传的文件。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| `command not found: moha` | 没装成功，或命令没在 PATH 里 | 先确认 `pip install moha-hub` 没报错；再运行 `python3 -m pip show moha-hub` 看是否装上 |
| 登录提示地址格式不对 | 地址没带 `https://` | 改成 `https://<平台地址>` 重新登录 |
| 登录提示用户名或密码错误 | 账号密码不对 | 核对账号密码；或改用访问令牌登录 |
| 下载报仓库不存在 | 仓库名写错，或没有访问权限 | 核对 `组织名/仓库名` 拼写；私有仓库要先用有权限的账号登录 |
| 上传报 `--encrypt` 需要密码 | 加了 `--encrypt` 却没给密码 | 去掉 `--encrypt`，或补上 `--encryption-password <密码>` |
