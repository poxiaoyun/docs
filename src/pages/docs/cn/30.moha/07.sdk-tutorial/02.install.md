# 安装与环境配置

这一页帮你把魔哈的 `moha` 命令和 Python 库装到电脑上，并确认真的装好了。
安装本身只有一条命令，容易卡住的地方是「Python 版本不够」和「网络连不上软件源」，下面都给了排查办法。

## 开始之前

| 前置条件 | 要求 | 怎么检查 |
| --- | --- | --- |
| Python | 3.10 或更高版本 | 运行 `python3 --version`，输出 3.10 及以上即可 |
| pip | 随 Python 一起安装 | 运行 `python3 -m pip --version`，能打印版本号即可 |
| 网络 | 能访问 Python 软件源 | 普通公网环境即可，公司内网可能需要配置镜像源 |

:::info 不需要装 Git LFS
魔哈 SDK 上传下载走的是平台接口，**不依赖 Git 和 Git LFS**，不用额外安装 `git` 或 `git-lfs`。
只有当你打算用 `git clone` 方式拉取仓库时，才需要本机有 Git，大文件才需要 Git LFS。
:::

## 安装

把下面这行复制到终端回车，就完成了主体安装：

```bash
pip install moha-hub
```

如果使用 `pip` 报「找不到命令」，换成下面这种写法（更稳，不依赖 PATH）：

```bash
python3 -m pip install moha-hub
```

参数说明：

| 命令 | 说明 |
| --- | --- |
| `pip install moha-hub` | 安装最新版；包名固定是 `moha-hub`（小写、中间是短横线） |
| `pip install "moha-hub[upload]"` | 额外安装上传功能依赖，想用上传命令时建议装这个 |
| `pip install "moha-hub==2.0.1"` | 安装指定版本，把 `2.0.1` 换成你要的版本号 |

:::tip 装到虚拟环境里更干净

如果你电脑上有多个 Python 项目，建议先建一个独立环境再装，避免互相干扰：

```bash
python3 -m venv moha-env
source moha-env/bin/activate     # Linux / macOS
pip install moha-hub
```

用完运行 `deactivate` 退出环境。Windows 的激活命令是 `moha-env\Scripts\activate`。

:::

## 验证安装成功

安装命令跑完不代表成功，请依次运行下面两条命令确认。

第一步，查看命令是否存在并能打印版本号：

```bash
moha --version
```

第二步，查看帮助，确认命令能正常启动：

```bash
moha --help
```

参数说明：

| 命令 | 期望看到的结果 |
| --- | --- |
| `moha --version` | 一行 `moha 2.0.1` 这样的版本号 |
| `moha --help` | 一屏命令列表，列出了 `login`、`upload`、`download` 等子命令 |
| `python3 -c "import xiaoshiai_hub; print(xiaoshiai_hub.__version__)"` | 打印版本号，说明 Python 库也装好了 |

两条命令任何一条报「找不到 moha 命令」，都说明没装成功，请对照下面的「常见安装报错」排查。

## 环境变量

除了登录保存，你也可以用环境变量把认证信息直接传给命令和代码。

| 环境变量 | 用途 | 示例 |
| --- | --- | --- |
| `MOHA_TOKEN` | 访问令牌，优先级最高 | `export MOHA_TOKEN=<访问令牌>` |
| `MOHA_USERNAME` / `MOHA_PASSWORD` | 用账号密码认证 | `export MOHA_USERNAME=<用户名>` |
| `MOHA_ORGANIZATION` | 指定当前组织 | `export MOHA_ORGANIZATION=<组织名>` |
| `MOHA_ENDPOINT` | Python 代码默认连接的平台地址 | `export MOHA_ENDPOINT=https://<平台地址>` |
| `MOHA_ENCRYPTION_PASSWORD` | 上传加密时的密码 | `export MOHA_ENCRYPTION_PASSWORD=<加密密码>` |
| `MOHA_AI_API_BASE` / `MOHA_AI_API_KEY` / `MOHA_AI_MODEL` | AI 助手使用的大模型配置 | 见 [CLI 工具完整参考](./cli-reference) |

:::warning 环境变量里的地址不会覆盖登录保存的地址
命令行工具以 `moha login` 时保存的平台地址为准；`MOHA_ENDPOINT` 主要给 Python 代码当默认地址用。
如果你换了平台，重新运行 `moha login https://<新平台地址>` 即可。
:::

## 常见安装报错

| 现象 | 可能原因 | 怎么做 |
| --- | --- | --- |
| `moha: command not found` | 包装到了 PATH 之外，或装到了别的 Python 环境 | 先 `python3 -m pip show moha-hub` 确认已安装；再把它所在的 `bin`/`Scripts` 目录加入 PATH，或改用 `python3 -m` 方式运行脚本 |
| 安装时 `ERROR: Could not install packages due to an EnvironmentError: [Errno 13] Permission denied` | 没有系统目录写权限 | 加 `--user` 装到当前用户：`pip install --user moha-hub`；或改用虚拟环境 |
| 安装卡住、`Read timed out` | 网络访问软件源太慢 | 换国内镜像源：`pip install -i https://pypi.tuna.tsinghua.edu.cn/simple moha-hub`，或加长超时：`pip install --default-timeout=1000 moha-hub` |
| 安装时提示 `No matching distribution found for moha-hub` | Python 版本低于 3.10，或系统位数不匹配 | 运行 `python3 --version` 确认 ≥ 3.10；不满足就先升级 Python |
| `pip` 本身提示需要升级 | pip 版本过旧 | 按提示运行 `python3 -m pip install --upgrade pip` 后重试 |
| 装了却在代码里 `import xiaoshiai_hub` 报错 | 运行代码用的 Python 和装包的 Python 不是同一个 | 用同一个解释器：`python3 -m pip install moha-hub`，再用 `python3 your_script.py` 运行 |
| 公司内网装不上 | 无外网，或需要走代理 | 配好代理或内网镜像源后再装；也可在有网机器上下载离线包拷过去安装 |
