# 与 Transformers & Datasets 集成

你已经在用 Hugging Face 那套写法（`AutoModel.from_pretrained(...)`、`load_dataset(...)`），想直接吃平台上的模型和数据集。
这一页给你两条可跑通的路，并说清各自要装什么、有什么限制。

## 开始之前

要额外安装的东西：

| 你要做什么 | 需要安装 |
| --- | --- |
| 只下载文件 | `pip install moha-hub` |
| 加载模型、跑推理 | 再加上 `pip install transformers torch` |
| 加载数据集 | 再加上 `pip install datasets` |
| 用「平台直连」方式 | 再加上 `pip install huggingface_hub` |

平台地址和访问令牌从环境变量传入最省事：

```bash
export MOHA_ENDPOINT="<平台地址>"
export MOHA_TOKEN="<访问令牌>"
```

## 两条路怎么选

| 方式 | 怎么用 | 优点 | 代价 |
| --- | --- | --- | --- |
| 先下载到本地，再本地加载 | 用 SDK 下载目录，把本地路径交给 `from_pretrained()` / `load_dataset()` | 最稳，不依赖网络状况，可离线复用 | 要自己占磁盘、自己管目录 |
| 把平台当作 Hugging Face 端点 | 设 `HF_ENDPOINT`，让 `transformers` / `huggingface_hub` 直接按仓库名拉取 | 代码改动最小，按需只拉用到的文件 | 需要令牌；只覆盖仓库读写那一类接口 |

**建议先用第一条**，跑通之后再决定要不要换成端点方式。

## 方式一：先下载到本地，再交给库加载

这是最不容易出错的路子：SDK 负责把文件拉下来，`transformers` / `datasets` 只面对本地目录。

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
from xiaoshiai_hub import snapshot_download

# 1. 把整个模型仓库拉到本地
local_dir = snapshot_download(
    repo_id="ai-lab/qwen2-7b",
    local_dir="./models/qwen2-7b",
    token="<访问令牌>",
)
print("模型已下载到：", local_dir)

# 2. 之后完全按本地目录的常规写法加载
tokenizer = AutoTokenizer.from_pretrained(local_dir, trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained(local_dir, device_map="auto")
```

只想拉部分文件时，用过滤参数，避免把不需要的权重也下下来：

```python
local_dir = snapshot_download(
    repo_id="ai-lab/qwen2-7b",
    local_dir="./models/qwen2-7b",
    allow_patterns=["*.json", "*.safetensors", "*.model"],
    token="<访问令牌>",
)
```

数据集的加载方式取决于仓库里存的是什么格式，用 `load_dataset` 按格式指定文件：

```python
from datasets import load_dataset

# 仓库里是 parquet
ds = load_dataset("parquet", data_files="./data/train-*.parquet", split="train")

# 仓库里是 json / jsonl
ds = load_dataset("json", data_files="./data/train.jsonl", split="train")

print(ds[0])
print("样本数：", len(ds))
```

`data_files` 支持本地路径和通配符，所以先把数据集目录下载下来（`repo_type="datasets"`），再按格式加载即可。

## 方式二：把平台当作 Hugging Face 端点

平台提供了一个与 Hugging Face 兼容的只读接口，`huggingface_hub` 和 `transformers` 可以把它当成 `HF_ENDPOINT` 来用。

:::warning 环境变量要在 import 之前设置
`HF_ENDPOINT` 是在 `huggingface_hub` / `transformers` 首次导入时读取的。写在 `import` 之后会不生效，务必先设环境变量再导入。
:::

```python
import os

# 必须先设，再 import
os.environ["HF_ENDPOINT"] = "<平台地址>/moha/huggingface"
os.environ["HF_TOKEN"] = "<访问令牌>"

from transformers import AutoModelForCausalLM, AutoTokenizer

# 仓库名直接写「组织/仓库」
tokenizer = AutoTokenizer.from_pretrained("ai-lab/qwen2-7b", trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained("ai-lab/qwen2-7b", device_map="auto")
```

只想下某个文件，或者想自己控制放到哪：

```python
from huggingface_hub import hf_hub_download, snapshot_download

path = hf_hub_download(
    repo_id="ai-lab/qwen2-7b",
    filename="config.json",
    revision="main",
)
print(path)

snapshot_download(
    repo_id="ai-lab/qwen2-7b",
    revision="main",
    local_dir="./qwen2-7b",
)
```

### 这个端点支持什么

| 能力 | 是否支持 |
| --- | --- |
| 查仓库信息（含文件清单） | 支持 |
| 列目录树、按目录浏览 | 支持 |
| 列分支与标签 | 支持 |
| 按分支/标签下载单个文件 | 支持 |
| 批量查询若干文件的信息 | 支持 |
| 数据集在线自动转换、网页预览类接口 | 没有，请走本地文件加载 |

关于版本：`revision` 要填**分支名或标签名**（用 `moha refs <组织/仓库名>` 能看到有哪些），不要填提交 SHA，镜像端点只按名字解析引用。

想精确复现某个冻结版本时，用该冻结记录对应的标签名。

### 私有仓库

端点这一层需要认证，所以**始终设置 `HF_TOKEN`** 最稳妥。仓库是私有时，用平台生成的访问令牌；令牌无效或过期会直接拉到 404 或认证失败。

## 完整示例：加载模型和数据，跑一次推理

```python
import os

os.environ["HF_ENDPOINT"] = "<平台地址>/moha/huggingface"
os.environ["HF_TOKEN"] = "<访问令牌>"

from datasets import load_dataset                       # noqa: E402
from transformers import AutoModelForCausalLM, AutoTokenizer  # noqa: E402
from xiaoshiai_hub import snapshot_download              # noqa: E402

# 模型：直接走端点按需下载
MODEL_ID = "ai-lab/qwen2-7b"
tokenizer = AutoTokenizer.from_pretrained(MODEL_ID, trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained(MODEL_ID, device_map="auto")

# 数据集：先下到本地，再按格式加载（更稳妥）
data_dir = snapshot_download(
    repo_id="ai-lab/my-dataset",
    repo_type="datasets",
    local_dir="./data/my-dataset",
)
ds = load_dataset("json", data_files=f"{data_dir}/*.jsonl", split="train")
print("样本示例：", ds[0])

# 推理
prompt = "用一句话介绍你自己："
inputs = tokenizer(prompt, return_tensors="pt").to(model.device)
outputs = model.generate(**inputs, max_new_tokens=64, do_sample=True, temperature=0.7)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
```

## 常见报错

| 报错 | 含义 | 怎么办 |
| --- | --- | --- |
| `HF_ENDPOINT` 设了但请求的还是 huggingface.co | 设置时机太晚 | 把 `os.environ[...]` 提到所有 `import` 之前 |
| `RepositoryNotFoundError` / 404 | 仓库不存在、没权限，或 `HF_TOKEN` 没生效 | 核对「组织/仓库名」；确认令牌有效且已设 `HF_TOKEN` |
| `RevisionNotFound` | `revision` 写的名字在仓库里不存在 | 用 `moha refs <组织/仓库名>` 查看可用分支和标签 |
| `EntryNotFound` | 仓库里没有这个文件/路径 | 核对 `filename`，或先列目录看真实文件名 |
| `OSError: ... does not appear to have a file named config.json` | 这是个数据集或纯权重仓库，不是完整的 transformers 模型 | 确认加载的是模型仓库；或按实际文件结构手动加载 |
| `load_dataset("组织/名称")` 报找不到数据文件 | 端点没有数据集自动转换能力 | 先把数据集下载到本地，再用 `load_dataset("<格式>", data_files=...)` |
| `snapshot_download` 无权限 | 私有仓库缺令牌 | 设 `HF_TOKEN`，或改用 SDK 的 `snapshot_download(token=...)` |
