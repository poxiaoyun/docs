# CLI 工具完整参考

`moha` 是随 SDK 一起安装的命令行工具，让你不写代码就能完成登录、创建仓库、上传下载、发布空间等操作。
这一页按子命令列出每一项的**用途、用法、参数和示例**，需要时按需查找即可。

## 开始之前

- 已经装好工具（运行 `moha --version` 能看到版本号）。
- 建议先 `moha login https://<平台地址>` 登录一次，后面所有命令都会用保存好的令牌。

## 通用规则

几条规则适用于下面的所有命令，先看一遍能省不少事。

1. **全局选项写在子命令前面**，例如 `moha --organization <组织名> list model`。
2. **认证参数**（`--token`、`--username`、`--password`）绝大多数命令都能用；不指定时自动读取登录保存的信息或环境变量。
3. **仓库 ID 写成 `组织名/仓库名`**；如果你已经用 `moha organization use <组织名>` 选好当前组织，也可以只写仓库名。
4. **资源类型别名**：下表几种写法等价，任选一种。

| 资源 | 可用的写法 |
| --- | --- |
| 模型 | `model`、`models`、`m` |
| 数据集 | `dataset`、`datasets`、`ds` |
| 镜像 | `image`、`images`、`img` |
| 空间 | `space`、`spaces`、`s` |

**命令别名**：`list` 可用 `ls`，`create` 用 `c`，`info` 用 `i`，`update` 用 `u`，`delete` 用 `del`，`upload` 用 `ul`，`download` 用 `dl`，`branch-create` 用 `bc`，`branch-delete` 用 `bd`，`branch-list` 用 `bl`。

:::warning 删除操作需要二次确认
`delete` 和 `branch-delete` 是**不可逆**操作。运行时终端会要求你原样输入 `--yes-i-really-mean-that` 才会执行；
加 `--force` 可跳过这一步（脚本里常用，但要自己确保删对了）。
:::

调试时可以在命令前加 `-v`：`-v` 看基本信息，`-vvv` 看详细请求日志（密码和令牌会自动打码）：

```bash
moha -vvv download <组织名>/<模型名>
```

## 认证与组织

### `moha login`

**用途**：登录平台，把令牌和地址保存到本机。

**用法**：

```bash
moha login <平台地址> [选项]
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<平台地址>` | 是 | 无 | 必须带 `https://`，例如 `https://<平台地址>` |
| `--token` | 否 | 无 | 用已有访问令牌登录 |
| `--username` / `-u` | 否 | 无 | 指定用户名 |
| `--password` / `-p` | 否 | 无 | 指定密码 |
| `--token-dir` | 否 | `~/.moha` | 登录信息保存目录 |

**示例**：

```bash
# 交互式登录（会依次询问令牌、用户名、密码）
moha login https://<平台地址>

# 用访问令牌直接登录
moha login https://<平台地址> --token <访问令牌>
```

**用途**：退出登录，删除本机保存的令牌。

**用法**：

```bash
moha logout
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--token-dir` | 否 | `~/.moha` | 指定要清理的配置目录 |

**示例**：

```bash
moha logout
```

### `moha organization list`

**用途**：列出你有权访问的组织，当前组织前面会标 `*`。

**用法**：

```bash
moha organization list [选项]
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--type` | 否 | 无 | 按类型筛选，可选 `organization`、`user` |
| `--member` | 否 | 无 | 只列出某个用户名加入的组织 |
| `--mine` | 否 | 无 | 只列出当前用户加入的组织 |

**示例**：

```bash
moha organization list
moha org list --mine
```

### `moha organization use`

**用途**：设置当前组织；设置后，仓库命令可以省略组织名前缀。

**用法**：

```bash
moha organization use <组织名> [选项]
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<组织名>` | 是 | 无 | 要设为当前组织的名称 |
| `--no-verify` | 否 | 无 | 跳过服务端校验（一般不用） |

**示例**：

```bash
moha organization use <组织名>
moha org use <组织名>
```

## 仓库管理

### `moha list`

**用途**：列出某类资源（模型、数据集、镜像、空间）。

**用法**：

```bash
moha list <资源类型> [选项]
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<资源类型>` | 是 | 无 | `model` / `dataset` / `image` / `space`（含别名） |
| `--organization` | 否 | 当前组织 | 指定组织（全局选项，写在 `list` 前） |
| `--all` / `-a` | 否 | 无 | 当前组织资源 + 全部组织的公开资源 |
| `--mine` / `-m` | 否 | 无 | 只列我创建的 |
| `--favorite` / `-f` | 否 | 无 | 只列我收藏的 |

:::info 三个筛选互斥
`--all`、`--mine`、`--favorite` 只能选一个。都不选时，默认列出**当前组织**的资源，所以要先 `moha organization use <组织名>`。
:::

**示例**：

```bash
# 列出当前组织的模型
moha list model

# 列出我收藏的镜像
moha list image --favorite

# 列出指定组织的空间
moha --organization <组织名> list space
```

### `moha create`

**用途**：创建一个模型、数据集、镜像或空间仓库。

**用法**：

```bash
moha create <资源类型> <仓库名> [选项]
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<资源类型>` | 是 | 无 | `model` / `dataset` / `image` / `space` |
| `<仓库名>` | 是 | 无 | 仓库 ID，写成 `组织名/仓库名` 或只写仓库名 |
| `--description` / `-d` | 否 | 无 | 仓库描述 |
| `--visibility` / `-v` | 否 | `internal` | 可见性，可选 `public`、`internal`、`private` |
| `--license` | 否 | 无 | 许可证，可重复传多次 |
| `--tasks` | 否 | 无 | 任务类型，可重复 |
| `--languages` | 否 | 无 | 语言，可重复 |
| `--tags` | 否 | 无 | 标签，可重复 |
| `--frameworks` | 否 | 无 | 框架，可重复 |
| `--base-model` | 否 | 无 | 基础模型，可重复，格式 `组织名/模型名` |
| `--relationship` | 否 | 无 | 与基础模型的关系，可选 `adapter`、`finetune`、`quantized`、`merge`、`repackage` |

创建**镜像**时，上面最后两项换成镜像专用参数：

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--repo` | 否 | 无 | 上游镜像仓库地址 |
| `--readme` | 否 | 无 | 镜像说明内容 |
| `--alias` | 否 | 无 | 显示别名 |
| `--media-type` | 否 | 无 | 镜像媒体类型 |

**示例**：

```bash
# 创建模型仓库
moha create model <组织名>/my-model --description "我的模型"

# 创建数据集仓库
moha create dataset <组织名>/my-dataset --description "我的数据集"

# 创建镜像仓库
moha create image <组织名>/my-runtime --repo <镜像仓库地址> --visibility internal

# 创建空间仓库
moha create space <组织名>/my-space --description "我的应用"
```

### `moha update`

**用途**：修改仓库的描述、可见性、元数据等。

**用法**：

```bash
moha update <资源类型> <仓库名> [选项]
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<资源类型>` | 是 | 无 | `model` / `dataset` / `image` / `space` |
| `<仓库名>` | 是 | 无 | 仓库 ID |
| `--description` / `-d` | 否 | 不变 | 新描述 |
| `--visibility` / `-v` | 否 | 不变 | `public`、`internal`、`private` |
| `--license` / `--tasks` / `--languages` / `--tags` / `--frameworks` | 否 | 不变 | 元数据，可重复 |

**示例**：

```bash

```

**用途**：删除仓库（不可逆）。

**用法**：

```bash

```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<资源类型>` | 是 | 无 | `model` / `dataset` / `image` / `space` |
| `<仓库名>` | 是 | 无 | 仓库 ID |

## 分支管理

### `moha refs` / `moha branch-list`

**用途**：列出仓库的全部分支（含提交hash、是否默认分支）。两个命令等价。

**用法**：

```bash
moha refs <仓库名>
moha branch-list <仓库名>
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<仓库名>` | 是 | 无 | 仓库 ID |
| `--repo-type` / `-t` | 否 | `model` | 仓库类型 |

**示例**：

```bash
moha refs <组织名>/my-model
moha bl <组织名>/my-model
```

### `moha branch-create`

**用途**：从现有分支创建一个新分支。

**用法**：

```bash
moha branch-create <仓库名> <新分支名> [选项]
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<仓库名>` | 是 | 无 | 仓库 ID |
| `<新分支名>` | 是 | 无 | 要创建的分支名 |
| `--from` / `-f` | 否 | `main` | 从哪个分支复制 |
| `--repo-type` / `-t` | 否 | `model` | 仓库类型 |

**示例**：

```bash
moha branch-create <组织名>/my-model dev --from main
moha bc <组织名>/my-model dev
```

### `moha branch-delete`

**用途**：删除分支（不可逆）。

**用法**：

```bash
moha branch-delete <仓库名> <分支名> [选项]
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<仓库名>` | 是 | 无 | 仓库 ID |
| `<分支名>` | 是 | 无 | 要删除的分支名 |
| `--force` | 否 | 无 | 跳过二次确认 |
| `--repo-type` / `-t` | 否 | `model` | 仓库类型 |

**示例**：

```bash
moha branch-delete <组织名>/my-model dev
moha bd <组织名>/my-model dev --force
```

## 上传与下载

### `moha upload`

**用途**：上传一个本地文件或整个文件夹到仓库。

**用法**：

```bash
moha upload <仓库名> <本地路径> [仓库内路径] [选项]
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<仓库名>` | 是 | 无 | 目标仓库 ID，**写在第一个** |
| `<本地路径>` | 是 | 无 | 要上传的文件或文件夹 |
| `[仓库内路径]` | 否 | 本地文件名 | 放到仓库里的哪个子目录或文件名 |
| `--revision` / `-r` | 否 | `main` | 上传到哪个分支 |
| `--repo-type` / `-t` | 否 | `model` | 仓库类型 |
| `--commit-message` / `--message` / `-m` | 否 | 无 | 提交说明 |
| `--commit-description` | 否 | 无 | 提交的补充说明 |
| `--include` | 否 | 无 | 只上传匹配的文件，可重复 |
| `--exclude` | 否 | 无 | 排除匹配的文件，可重复 |
| `--ignore` / `-i` | 否 | 无 | 忽略匹配的文件，可重复 |
| `--temp-dir` | 否 | 自动创建 | 加密时的临时目录 |
| `--disable-tqdm` | 否 | 关 | 关闭进度条 |
| `--quiet` / `-q` | 否 | 关 | 减少输出并关闭进度条 |
| `--encrypt` / `-e` | 否 | 关 | 对模型大文件加密后上传 |
| `--encryption-password` | 否 | 无 | 加密密码，也可用环境变量 `MOHA_ENCRYPTION_PASSWORD` |
| `--algorithm` / `-a` | 否 | `AES` | 加密算法，可选 `AES`、`SM4`、`AES-256-CTR`、`SM4-CTR` |

**示例**：

```bash
# 上传整个文件夹
moha upload <组织名>/my-model ./my_model

# 上传单个文件，并放到指定子目录
moha upload <组织名>/my-model ./config.yaml configs/config.yaml

# 忽略临时文件后上传
moha upload <组织名>/my-model ./my_model --ignore "*.log" --exclude ".git*"

# 加密上传大模型文件
moha upload <组织名>/my-model ./model.safetensors \
  --encrypt \
  --encryption-password <加密密码>
```

### `moha upload-file`

**用途**：上传单个文件（参数和 `upload` 略有不同）。

**用法**：

```bash
moha upload-file <本地文件> <仓库名> [选项]
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<本地文件>` | 是 | 无 | 要上传的文件路径 |
| `<仓库名>` | 是 | 无 | 目标仓库 ID |
| `--path-in-repo` / `-p` | 否 | 文件名 | 文件在仓库内的路径 |
| `--repo-type` / `-t` | 否 | `model` | 仓库类型 |
| `--revision` / `-r` | 否 | `main` | 目标分支 |
| `--commit-message` / `--message` / `-m` | 否 | 无 | 提交说明 |
| `--encryption-password` | 否 | 无 | 加密密码 |
| `--encrypt` / `-e`、`--algorithm` / `-a` | 否 | 关 / `AES` | 同 `upload` |

**示例**：

```bash
moha upload-file ./config.json <组织名>/my-model
moha upload-file ./model.bin <组织名>/my-model --path-in-repo weights/model.bin
```

### `moha download`

**用途**：下载整个仓库，或只下载指定的几个文件。

**用法**：

```bash
moha download <仓库名> [文件...] [选项]
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<仓库名>` | 是 | 无 | 要下载的仓库 ID |
| `[文件...]` | 否 | 无 | 只下载这些文件；不写则下载整个仓库 |
| `--local-dir` / `-o` | 否 | 整仓下载时是 `./downloads/<组织名>_<仓库类型>_<仓库名>/`；只下指定文件时是当前目录 | 下载到哪个目录 |
| `--repo-type` / `-t` | 否 | `model` | 仓库类型 |
| `--revision` / `-r` | 否 | 仓库默认分支 | 下载哪个分支、标签或提交 |
| `--include` | 否 | 无 | 只下载匹配的文件，可重复 |
| `--exclude` / `--ignore` / `-i` | 否 | 无 | 排除匹配的文件，可重复 |
| `--disable-tqdm` / `--quiet` / `-q` | 否 | 关 | 关闭进度条 |

**示例**：

```bash
# 下载整个仓库（默认到 ./downloads/... 目录）
moha download <组织名>/my-model

# 指定下载目录
moha download <组织名>/my-model --local-dir ./models

# 只下载 yaml 文件
moha download <组织名>/my-model --include "*.yaml"

# 只下载两个文件
moha download <组织名>/my-model config.yaml tokenizer.json
```

### `moha download-file`

**用途**：下载仓库里的单个文件，默认存到当前目录。

**用法**：

```bash
moha download-file <仓库名> <文件路径> [选项]
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<仓库名>` | 是 | 无 | 仓库 ID |
| `<文件路径>` | 是 | 无 | 文件在仓库内的路径 |
| `--local-dir` / `-o` | 否 | 当前目录 | 保存到哪个目录 |
| `--repo-type` / `-t` | 否 | `model` | 仓库类型 |
| `--revision` / `-r` | 否 | 仓库默认分支 | 分支、标签或提交 |
| `--disable-tqdm` / `--quiet` / `-q` | 否 | 关 | 关闭进度条 |

**示例**：

```bash
moha download-file <组织名>/my-model config.json --local-dir ./configs
```

## 空间（Space）管理

### `moha deploy` / `moha redeploy` / `moha stop`

**用途**：发布、重新发布、停止一个空间。

**用法**：

```bash
moha deploy <仓库名>
moha redeploy <仓库名>
moha stop <仓库名>
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<仓库名>` | 是 | 无 | 空间仓库 ID |

**示例**：

```bash
moha deploy <组织名>/my-space
moha redeploy <组织名>/my-space
```

### `moha status`

**用途**：查看空间运行状态和访问地址。

**用法**：

```bash
moha status <仓库名>
```

**示例**：

```bash
moha status <组织名>/my-space
```

### `moha logs`

**用途**：查看空间运行日志。

**用法**：

```bash
moha logs <仓库名> [选项]
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `<仓库名>` | 是 | 无 | 空间仓库 ID |
| `--pod` | 否 | 自动选择 | 指定 Pod 名称；有多个时会提示你选 |
| `--container` / `-c` | 否 | 自动选择 | 指定容器名；有多个容器时必须指定 |
| `--follow` / `-f` | 否 | 关 | 实时滚动输出 |
| `--tail-lines` / `-n` | 否 | `100` | 只显示末尾多少行 |
| `--previous` | 否 | 关 | 查看上一个容器实例的日志 |
| `--timestamps` | 否 | 关 | 每行带上时间戳 |

**示例**：

```bash
moha logs <组织名>/my-space
moha logs <组织名>/my-space -f -c web
```

## AI 助手

### `moha ai`

**用途**：用自然语言让 AI 助手帮你查仓库、看文件、发布空间等（删除类操作不会由助手执行）。

**用法**：

```bash
moha ai [选项]
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--prompt` / `-p` | 否 | 无 | 直接执行一条指令后退出，不进交互模式 |
| `--api-base` | 否 | 无 | 大模型接口地址，也可用 `MOHA_AI_API_BASE` |
| `--api-key` | 否 | 无 | 大模型密钥，也可用 `MOHA_AI_API_KEY` |
| `--model` / `-m` | 否 | 无 | 模型名称，也可用 `MOHA_AI_MODEL` |
| `--no-stream` | 否 | 关 | 关闭流式输出，等回答完整再显示 |

**示例**：

```bash
moha ai
moha ai --prompt "列出我创建的模型"
```

### `moha ai-config`

**用途**：配置 AI 助手用的大模型接口。

**用法**：

```bash
moha ai-config [选项]
```

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `--api-base` | 否 | 不变 | 大模型接口地址 |
| `--api-key` | 否 | 不变 | 大模型密钥 |
| `--model` / `-m` | 否 | 不变 | 模型名称 |
| `--show` / `-s` | 否 | 关 | 只显示当前配置 |

**示例**：

```bash

moha ai-config --show
```

## 常见报错

| 现象 | 可能原因 | 怎么做 |
| --- | --- | --- |
| `unknown command` | 子命令拼写错误 | 按提示改用正确命令，或运行 `moha --help` 查看全部命令 |
| 报认证失败 / 未授权 | 没登录或令牌过期 | 运行 `moha login https://<平台地址>` 重新登录 |
| 提示需要先选择当前组织 | 没设当前组织，却省略了组织名 | 运行 `moha organization use <组织名>`，或在命令里写全 `组织名/仓库名` |
| `Invalid repository ID` | 仓库名格式不对 | 改成 `组织名/仓库名`，或先设置当前组织后只写仓库名 |
| 删除时命令无反应 | 在等你输入确认短语 | 原样输入 `--yes-i-really-mean-that` 回车，或用 `--force` |
| `--encrypt requires an encryption password` | 开了加密却没给密码 | 补上 `--encryption-password <密码>`，或设置 `MOHA_ENCRYPTION_PASSWORD` |
| 文件过滤不生效 | shell 把通配符提前展开了 | 给模式加引号，例如 `--include "*.yaml"` |
