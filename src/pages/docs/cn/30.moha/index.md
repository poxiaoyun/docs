# 魔哈仓库

魔哈是平台的**模型与数据集托管平台**。你可以把训练好的模型、整理好的数据集传上来，配上说明，分享给同事或公开给所有人；也可以在广场里搜别人的成果，直接下载回来用。

它不需要你懂服务器或存储，页面上点几下，或者复制一条命令，就能把几百 MB 到几十 GB 的文件传上来。

:::tip 用「文件夹」来理解魔哈
一个**仓库**就是一个文件夹，仓库的每一次改动就是给这个文件夹拍的一张存档照片（叫**版本**）。
平台替你保存全部历史，哪次改坏了都能翻回去。
:::

## 先把几个词弄明白

| 名词 | 通俗解释 |
| --- | --- |
| 仓库 | 一个放模型或数据集的文件夹，名字形如 `ai-lab/qwen2-7b` |
| 版本 | 这个文件夹在某个时刻的存档，可以随时切回去看 |
| 卡片 | 仓库的详情页介绍，让别人一眼知道这是什么、怎么用 |
| Git LFS | Git 的一个扩展，专门负责搬几个 G 的大文件（普通 Git 搬不动） |
| 访问令牌 | 代替密码的通行证，命令行和 SDK 靠它证明「你是你」 |

## 你能在魔哈里做什么

| 我想…… | 去哪里 |
| --- | --- |
| 找别人做好的模型 | 顶部导航 **模型库** |
| 找别人整理好的数据集 | 顶部导航 **数据集** |
| 看我自己上传了什么 | 首页左侧 **我创建的** |
| 把本地文件传上去 | 仓库详情页 **文件** 标签页，或命令行、SDK |
| 把模型下载到本地 | 模型详情页右上角 **下载模型** |

## 开始之前

- 先用平台账号登录，才能看到自己的资源和私有资源。
- 要访问私有模型或私有数据集，需要先创建一个**访问令牌**，见[访问令牌](/moha/quickstart/token)。
- 想用命令行或 SDK 传文件，本机要先装好 Git、Git LFS 和 SDK，见[模型的上传](/moha/models/upload)。
