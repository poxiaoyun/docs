# 我的收藏

「我的收藏」是魔哈个人工作台中的一个视图，用于集中查看你收藏（Star）过的模型、数据集、镜像和 Space。

## 进入路径

魔哈首页左侧菜单 -> **我的收藏**

真实路由：`/moha/home/liked-by-me`

## 页面结构

| 区块 | 说明 |
| --- | --- |
| 类型标签页 | 在模型 / 数据集 / 镜像 / Space 之间切换，标签上带收藏数量 |
| 工具栏 | 关键字搜索、高级筛选、结果总数与刷新 |
| 资源列表 | 以统一的数据卡片展示当前类型的收藏资源 |

## 类型与统计

页面通过 `type` 查询参数决定当前展示的类型，默认 `models`：

| 标签 | 参数值 | 统计字段 |
| --- | --- | --- |
| 模型 | `models` | `statistics.models` |
| 数据集 | `datasets` | `statistics.datasets` |
| 镜像 | `images` | `statistics.images` |
| Space | `spaces` | `statistics.spaces` |

统计数据来自 `getMyFavoriteDataManagersStatistics`；切换类型时会更新 URL 查询参数并回到第 1 页。

## 列表与筛选

- 列表数据来自 `listMyFavoriteDataManagers`，默认每页 `size=24`。
- 支持按名称/关键字搜索。
- 支持高级筛选：筛选面板以 `kind: 'my-favorite'` 作为取值范围，模型与数据集分别使用各自的 faceted 接口。
- 列表项沿用统一的数据卡片样式，可直接进入仓库详情。

## 适用场景

- 快速回到此前收藏的模型或数据集继续使用。
- 从收藏视角检查某类资源是否有更新。
- 与[我创建的资源](/moha/home/created-by-me)、[组织空间](/moha/home/organizations)互补，覆盖「我维护的 / 我收藏的 / 团队共享的」三种视角。
