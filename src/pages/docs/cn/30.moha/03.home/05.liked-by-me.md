# 我的收藏

这一页把你**点过心形图标**的资源集中到一起，模型、数据集、镜像、空间分成四类。左侧菜单里它叫 **我喜欢的**，进来后就是这份收藏清单。

## 进入路径

顶部导航点击 **首页**，在左侧菜单点击 **我喜欢的**。

## 怎么收藏一个资源

1. 打开任意一个仓库的详情页（模型、数据集、镜像、空间都可以）。
2. 在标题右侧找到**心形图标**按钮，点击它。
3. 心形图标变红，说明收藏成功；再点一次可取消收藏。

![我喜欢的：四个页签统计收藏数量（模型 10 / 数据集 4 / 镜像 2 / 空间 3），下面是已收藏的卡片](/assets/screenshots/moha/home-liked-01.png)

被收藏的卡片右下角是实心红心，再点一次即可取消。收藏是个人行为，不改变资源可见性，别人看不到你收藏了什么。

## 页面分几块

| 区域 | 给你看什么 | 你能做什么 |
| --- | --- | --- |
| 类型标签页 | 模型 / 数据集 / 镜像 / 空间，页签上带收藏数量 | 点击切换类型 |
| 搜索框 | 按名称或别名搜索收藏 | 输入关键字后回车 |
| 高级搜索 | 分类、组织等筛选条件 | 展开后勾选 |
| 刷新图标 | 刷新按钮 | 重新拉取最新收藏 |
| 资源列表 | 当前类型下你收藏的仓库卡片 | 点击卡片进入详情 |

## 查看收藏

1. 在页面上方点击 **模型**、**数据集**、**镜像** 或 **空间** 页签。
2. 页签右侧的数字是你在该类型下收藏的数量。
3. 想找特定的收藏，在搜索框输入名称；条件较多时用高级搜索。
4. 找到后点击卡片，直接回到该仓库详情页。

## 结果确认

- 页签上的数字与你实际收藏的数量一致。
- 列表里的卡片标题下方，心形图标是红色实心的。
- 如果列表显示 **暂无数据**，说明该类型下还没有收藏。
