# 组织空间

**组织**是魔哈里的团队空间，可以理解成公司里的一间大办公室：同一个组织的人把各自的模型、数据集放进来，彼此都能看见。组织主页就是这间办公室的资源总览。

## 进入路径

顶部导航点击 **首页**，然后用两种方式进入组织主页：

1. 在左侧菜单上方点击 **组织主页** 按钮。
2. 在左侧 **其他组织** 区块点击某个组织的头像。

![组织主页：左侧组织卡片与「其他组织」列表，右侧类型页签 + 可见性单选（公开/内部/私有）+「我创建的」开关 + 24 张资源卡片](/assets/screenshots/moha/org-home-01.png)

注意资源区上方的 **可见性** 单选项和 **我创建的** 开关——前者按可见性过滤，后者只留下你自己建的资源。截图里 System 组织的卡片右上角还标着各自的可见性。

## 组织主页长什么样

| 区域 | 给你看什么 | 你能做什么 |
| --- | --- | --- |
| 左侧组织名片 | 组织名称、别名和描述 | 确认当前看的是哪个组织 |
| 左侧 **其他组织** | 你所属的其他组织列表，标题后带数量 | 点击切换到别的组织 |
| 顶部类型页签 | 模型 / 数据集 / 镜像 / 空间，页签上带数量 | 点击切换资源类型 |
| 可见性筛选 | **公开** / **内部** / **私有** 三个单选项 | 只留某一档可见性的资源 |
| **我创建的** 开关 | 打开后只显示你创建的资源 | 快速确认自己在团队里传了什么 |
| 资源卡片区 | 当前筛选条件下的资源，一屏 24 个 | 搜索、查看详情、刷新 |

组织里没有资源时，卡片区会显示空态，提示该组织暂时没有这一类资源。

## 按类型和可见性筛选

1. 在顶部页签点击 **模型**、**数据集**、**镜像** 或 **空间**。
2. 在资源区上方点一个可见性单选项：

| 选项 | 筛出什么 |
| --- | --- |
| **公开** | 所有人都能看到的资源 |
| **内部** | 只有本组织成员能看到的资源 |
| **私有** | 只有创建者（和被授权的成员）能看到的资源 |

3. 想再缩小范围，在搜索框输入名称或关键字，或点右上角的 **高级搜索** 勾选分类、框架等条件后点 **应用筛选**。
4. 点右上角刷新图标可以重新拉取一次列表。

资源是一次加载一屏（24 个），往下滚到底会自动接着加载，没有页码按钮。

## 只看我创建的

资源区上方有一个 **我创建的** 开关。打开后，当前类型的资源只显示你自己创建的那些；再点一次关闭，恢复显示全组织资源。

这个开关可以和可见性筛选叠加使用：例如先选 **内部**，再打开 **我创建的**，就只看你在组织里创建的内部资源。

## 切换组织

在左侧 **其他组织** 区块点击目标组织的名字，即可切到那个组织的主页。组织数量多时，列表可以上下滚动；你只属于一个组织时，这一栏会显示「暂无组织」。

:::tip 组织、可见性到底是什么

- **组织** ≈ 一个团队空间，里面的人共享仓库。
- **可见性** ≈ 这个仓库谁能看到，分公开、内部、私有三档。

:::

## 结果确认

- 切换页签后，资源区内容随之变化，页签上的数字和实际数量一致。
- 点可见性单选项后，卡片右上角的可见性标记全部变成你选的那一档。
- 打开 **我创建的** 开关后，列表只剩你自己创建的资源。
