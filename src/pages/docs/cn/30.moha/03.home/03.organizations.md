# 组织空间

**组织**是魔哈里的团队空间，可以理解成公司里的一间大办公室：同一个组织的人把各自的模型、数据集放进来，彼此都能看见。组织主页就是这间办公室的资源总览。

## 进入路径

顶部导航点击 **首页**，然后用两种方式进入组织主页：

1. 在左侧菜单上方点击 **组织主页** 按钮。
2. 在左侧 **加入的组织** 区块点击某个组织的头像。

## 组织主页长什么样

| 区域 | 给你看什么 | 你能做什么 |
| --- | --- | --- |
| 左侧组织名片 | 组织头像、别名和描述 | 确认当前看的是哪个组织 |
| 左侧 **其他组织** | 你所属的其他组织列表 | 点击切换到别的组织 |
| 顶部类型页签 | 模型 / 数据集 / 镜像 / 空间，页签上带数量 | 点击切换资源类型 |
| 资源区 | 当前类型的全部资源，按可见性分段展示 | 浏览、搜索、进入详情 |

## 浏览团队资源

1. 在顶部页签点击 **模型**、**数据集**、**镜像** 或 **空间**。
2. 下方的资源会分成三段显示，每段标题后面带数量：
   - **公开资源**：所有人可见。
   - **租户内**：只有本组织成员可见。
   - **私有**：只有创建者自己可见。
3. 某一段资源较多时，标题下方会出现 **查看全部…** 按钮，点击展开；展开后按钮变成 **收起…**。
4. 想快速定位，在搜索框输入名称或关键字；点右上角刷新图标可重新拉取。

## 只看我创建的

资源区上方有一个 **我创建的** 开关。打开后，三类资源都会只显示你自己创建的那些，方便你确认自己在团队里传了什么。

## 切换组织

在左侧 **其他组织** 区块点击目标组织的名字，即可切到那个组织的主页。组织数量多时，列表可以上下滚动。

:::tip 组织、可见性到底是什么

- **组织** ≈ 一个团队空间，里面的人共享仓库。
- **可见性** ≈ 这个仓库谁能看到，分公开、租户内、私有三档。

:::

## 结果确认

- 切换页签后，资源区内容随之变化，页签上的数字和实际数量一致。
- 打开 **我创建的** 开关后，列表只剩你自己创建的资源。
- 点任意资源卡片能进入它的详情页。
