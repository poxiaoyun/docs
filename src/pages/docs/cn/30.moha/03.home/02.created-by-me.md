# 我创建的资源

这一页是你在魔哈的**资产清单**。你自己创建的模型、数据集、镜像和空间都会汇总到这里，按类型分好类，方便你一眼确认「我传过什么、传成功没有」。

## 进入路径

顶部导航点击 **首页**，在左侧菜单点击 **我创建的**。

![我创建的：顶部按模型 / 数据集 / 镜像 / 空间四个页签统计数量，工具栏有搜索、高级搜索与创建按钮，下面是我创建的卡片列表](/assets/screenshots/moha/home-created-01.png)

四个页签分别是 **模型 47 / 数据集 18 / 镜像 13 / 空间 28**，点页签切换列表，右上角按钮也会跟着变成 **创建数据集 / 创建镜像 / 创建空间**。

## 页面分几块

| 区域 | 给你看什么 | 你能做什么 |
| --- | --- | --- |
| 类型标签页 | 模型 / 数据集 / 镜像 / 空间 四个页签，页签上带数量 | 点击切换查看的类型 |
| 搜索框 | 按名称或别名搜索 | 输入关键字后回车 |
| 高级搜索 | 分类、组织、许可证等筛选条件 | 展开后勾选，缩小范围 |
| 刷新图标 | 刷新按钮 | 点一下重新拉取最新列表 |
| 创建按钮 | 右上角的 **创建模型** 等按钮 | 直接进入对应类型的创建页 |
| 资源列表 | 当前类型下你创建的仓库卡片 | 点击卡片进入仓库详情 |

## 按类型查看

1. 在页面上方点击 **模型**、**数据集**、**镜像** 或 **空间** 页签。
2. 页签右侧的数字是你在该类型下创建的数量。
3. 下方列表会同步切换成对应类型的资源。

## 找某个资源

1. 在搜索框输入名称，或按 `组织/名称` 的格式输入，例如 `ai-lab/qwen2-7b`。
2. 需要更细的条件时，点击搜索框右侧的筛选按钮，在抽屉里勾选分类、组织或许可证。
3. 已生效的条件会显示成搜索框下方的小标签，点标签上的叉可以取消。

## 新建一个资源

1. 点击右上角的创建按钮：**创建模型**、**创建数据集**、**创建镜像** 或 **创建空间**。
2. 注意创建按钮会跟着当前页签变化，你正在看哪个类型，就创建哪个类型。
3. 填完表单提交后，新资源会出现在当前列表里。

## 结果确认

- 切换页签时，列表内容和页签上的数字会同步变化。
- 新建成功后，列表里会出现刚创建的资源，点进去能看到详情。
- 如果列表显示 **暂无数据**，说明该类型下你还没有创建过资源。
