# 访问令牌与公告

魔哈首页左侧有两个高频的小页面：**访问令牌**只做一件事——把当前令牌交给你；**公告**则是平台发布消息的地方。两者都在左侧菜单里，点一下即可进入。

## 访问令牌

### 进入路径

顶部导航点击 **首页**，左侧菜单点击 **访问令牌**。

![访问令牌页：一行说明文字加一个令牌框，右侧的复制图标把令牌拷进剪贴板](/assets/screenshots/moha/token-01.png)

一整页只有这一个令牌框，没有生成、刷新或吊销按钮——截图里的令牌已做模糊处理。这串字符等同于你的身份，命令行、Git 和 SDK 共用同一个。

### 页面上有什么

| 元素 | 说明 |
| --- | --- |
| 令牌值 | 当前登录这把令牌，一整串字符 |
| 复制按钮 | 点击后令牌进入剪贴板 |

页面上方有一句说明：访问令牌用于验证你的身份、访问受限资源，以及调用魔哈 API-Inference 等其他服务。

### 怎么用

1. 点击复制按钮，把令牌粘贴到安全的地方。
2. 在命令行登录时用它：`moha login https://<平台地址> --token <令牌>`。
3. 在 Git 拉取私有仓库时，密码处填令牌。

:::warning 令牌等于你的身份
拿到令牌的人就能以你的名义操作。不要提交进代码仓库，不要发到聊天群，也不要放进截图。令牌泄漏后的处理，见[访问令牌](/moha/quickstart/token)。
:::

## 公告

### 进入路径

顶部导航点击 **首页**，左侧菜单点击 **公告**。

![公告页：表格只有标题 / 内容 / 时间三列，当前没有公告时显示「暂无数据」，底部是每页行数与翻页](/assets/screenshots/moha/home-announcements-01.png)

这一页是只读的：只有搜索框和刷新按钮，没有新建入口。表格为空只说明平台没有发布中的公告，是正常状态，不是权限问题。

### 表格里有哪些列

| 列 | 说明 |
| --- | --- |
| 标题 | 公告的名字，点击它打开全文 |
| 内容 | 公告正文的摘要 |
| 时间 | 公告的生效时间 |

### 怎么看

1. 点击任意一行的 **标题**，弹出窗口显示公告全文。
2. 看完点击弹窗里的 **关闭** 返回列表。
3. 公告较多时，用表格上方的搜索框输入标题关键字过滤。

公告常用来发布平台更新、维护通知、活动信息等，建议定期回来看一眼。
