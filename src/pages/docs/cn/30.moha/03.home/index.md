# 首页与个人工作台

魔哈首页不是一张欢迎海报，而是一个**个人工作台**：左边一栏固定放着你自己的东西（我创建的、我喜欢的、访问令牌、公告）和你所属的组织，右边随你点哪一项而变。

## 进入路径

在魔哈顶部导航点击 **首页**，就进入这个工作台。

## 左侧这一栏有什么

| 区域 | 给你看什么 | 你能做什么 |
| --- | --- | --- |
| 顶部名片 | 你的名字、邮箱和头像 | 确认当前登录的是谁 |
| **组织主页** 按钮 | 你当前的组织 | 点击进入该组织的资源页 |
| 菜单 | 概览、我创建的、我喜欢的、访问令牌、公告 | 点击任意项，右侧切换成对应页面 |
| 加入的组织 | 你所属的每个组织（显示头像） | 把鼠标移上去看名字，点击进入该组织主页 |

如果「加入的组织」下面是空的，会显示 **暂无组织**，说明你的账号还没加入任何组织，可以去[账号设置](/moha/quickstart/account)里创建一个。

## 五个页面分别看什么

| 菜单 | 这一页给我看什么 | 详细说明 |
| --- | --- | --- |
| 概览 | 推荐资源、快捷创建入口、平台公告 | [首页概览](/moha/home/overview) |
| 我创建的 | 我自己上传的模型、数据集、镜像、空间 | [我创建的资源](/moha/home/created-by-me) |
| 我喜欢的 | 我收藏过的资源 | [我的收藏](/moha/home/liked-by-me) |
| 访问令牌 | 当前登录这把令牌和复制按钮 | [访问令牌与公告](/moha/home/token-announcements) |
| 公告 | 平台发布的全部公告 | [访问令牌与公告](/moha/home/token-announcements) |

## 个人视角和团队视角

- 只看**我自己的**东西：用「我创建的」和「我喜欢的」。
- 看**整个团队**的东西：点 **组织主页**，进入[组织空间](/moha/home/organizations)。
