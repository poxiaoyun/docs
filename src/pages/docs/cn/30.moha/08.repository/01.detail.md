# 仓库详情页结构

打开一个模型、数据集、镜像或空间，你会看到同一个版式：**顶部信息栏 + 一排页签 + 页签内容**。看懂这一页，后面每个页签就都知道从哪进了。

## 打开一个仓库
1. 在魔哈顶部导航选择资源类型：**模型**、**数据集**、**镜像** 或 **空间**。
2. 在列表里点击任意卡片。

打开后默认停在第一个页签（介绍页），顶部会显示仓库名称。

## 顶部信息栏
不同资源类型的顶部略有差别：

| 位置 | 你可以做什么 |
| --- | --- |
| 左上 **返回** | 回到进入前的列表页 |
| 组织名 / 仓库名 | 点击组织名进入该组织的资源页；仓库名旁边的复制按钮可以复制「组织/仓库名」 |
| 收藏按钮（心形 + 数字） | 点击即收藏或取消收藏，数字是收藏数 |
| 元数据标签 | 分组、框架、许可证、标签、语言、类型等，帮你快速判断这个资源适不适合你 |
| 右上操作按钮 | 模型有 **下载**、**部署**、**使用模型**；数据集有 **下载**、**使用数据集**；镜像有 **下载镜像** |

空间详情页的顶部还多两个东西：一个显示运行状态的标签，和右边一个 **操作** 按钮（发布、停止、重新发布、日志）。

## 页签怎么切
点击页签名即可切换，页面不会重新加载。可用的页签按资源类型决定：

| 页签 | 模型 | 数据集 | 镜像 | 空间 |
| --- | --- | --- | --- | --- |
| 介绍（模型介绍 / 数据集介绍 / 镜像介绍 / 概览） | 有 | 有 | 有 | 有 |
| 文件 | 有 | 有 | 无 | 有 |
| 快照 | 有 | 有 | 无 | 有 |
| 标签 | 无 | 无 | 有 | 无 |
| 交流反馈 | 有 | 有 | 无 | 有 |
| 设置 | 有权限时 | 有权限时 | 有权限时 | 有权限时 |

## 为什么我看不到「设置」
**设置** 页签只对有管理权限的人显示。满足下面任意一条即可看到：

- 系统管理员。
- 这个仓库的所有者。
- 这个仓库所属组织的管理员。
- 被加进这个仓库、且角色是 **管理员**（模型、数据集、镜像还允许 **读写** 角色）。

如果你需要管理这个仓库却看不到设置，请在 **交流反馈** 里留言，或联系仓库所有者/组织管理员，请对方在设置页把你加为成员。

:::tip 想确认自己有没有权限
先看页签里有没有 **设置**。没有，就说明当前账号在该仓库没有管理权限；有，就能改可见性、成员和元数据。
:::

## 结果确认
- 切换页签时地址栏末段会跟着变化（如 `/content`、`/file`、`/freezes`、`/setting`），刷新页面也能回到同一个页签。
- 收藏按钮变实心、数字加一，说明收藏成功。
