# 仓库详情页结构

详情页顶部会显示资源类型与仓库名称，并在下方根据资源类型和权限渲染不同标签页。

## 进入方式

可以从模型、数据集、镜像或 Space 列表页点击卡片进入。

典型路径示例：

- `/moha/models/:organization/:id/content`
- `/moha/datasets/:organization/:id/file`
- `/moha/images/:organization/:id/tags`
- `/moha/spaces/:organization/:id/setting`

## 标签页组成

标签页不是固定列表，按资源类型和权限动态拼装：

| 标签 | value | 出现条件 |
| --- | --- | --- |
| 模型卡片 / 数据集卡片 / 镜像卡片 / 概览 | `content` | 始终（标签名随资源类型变化） |
| 文件 | `file` | 非镜像资源 |
| 版本冻结 | `freezes` | 非镜像资源 |
| 标签 | `tags` | 仅镜像资源 |
| 讨论 | `discussion` | 支持讨论的资源 |
| 设置 | `setting` | 满足下方权限条件之一时 |

## 权限控制

设置页不是对所有用户开放。当前前端会按以下条件决定是否显示“设置”标签：

- 系统管理员
- 仓库 Owner
- 组织管理员（组织成员 `role === 'admin'`）
- 仓库管理员（`role === 'admin'`）或具备读写权限的成员（`role === 'readwrite'`）

## 页面价值

- 用统一的操作范式降低不同资源类型的学习成本。
- 支持在资源详情、文件、版本冻结、讨论与设置之间快速切换。
- 为团队协作、审阅与发布提供固定工作入口。
