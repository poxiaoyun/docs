# 协作

模型、数据集、镜像和空间虽然是四种不同的资源，但打开它们时用的是**同一套页面结构**：顶部一排页签，下面是内容。你只要学会看一个仓库，其他几种都会看。

## 怎么打开一个仓库
- 从任意列表页点击卡片：**模型库**、**数据集**、**镜像仓库**、**空间**。
- 在列表页的搜索框输入名称，点击搜索结果。
- 从首页的 **我创建的** 或 **我的收藏** 点进去。

打开后，页面顶部会显示仓库名称，右上角能看到「喜欢」「下载次数」等信息，下面是页签。

![模型仓库的全部页签：模型介绍 / 文件 / 快照 / 交流反馈 / 设置，右上角是下载模型、部署、使用模型](/assets/screenshots/moha/repo-model-content-01.png)

五类资源的页签并不相同：模型和数据集是「介绍 / 文件 / 快照 / 交流反馈 / 设置」，空间是「概览 / 文件 / 快照 / 交流反馈 / 设置」，镜像最少，只有「镜像介绍 / 标签 / 设置」。

## 五种资源分别有哪些页签
| 页签 | 出现在哪些资源 | 你可以在这里做什么 |
| --- | --- | --- |
| 模型介绍 / 数据集介绍 / 镜像介绍 / 概览 | 全部 | 看介绍正文和右侧信息；空间在这里直接运行应用 |
| 文件 | 模型、数据集、空间 | 浏览文件、预览内容、看提交记录、上传或下载 |
| 快照 | 模型、数据集、空间 | 给仓库拍存档照、对比差异、回滚 |
| 标签 | 镜像 | 查看镜像标签与安全扫描结果 |
| 交流反馈 | 模型、数据集、空间 | 提问、反馈，就代码变更发起合并请求 |
| 设置 | 有权限时 | 改可见性、成员、元数据、部署参数，或删除仓库 |

:::tip 「快照」是什么
快照相当于**给仓库当前状态拍一张存档照**。你可以随时把仓库回滚到某张快照，所以发布重要版本前拍一张，之后就不怕改坏。同一个仓库可以有多张快照。
:::

## 页签不是每个人都一样
- **文件**、**快照**、**交流反馈** 对所有能打开这个仓库的人可见。
- **设置** 只对有管理权限的人显示：系统管理员、仓库所有者、组织管理员，或者被授予管理/读写权限的成员。
- 镜像仓库没有 **文件**、**快照**、**交流反馈**，取而代之的是 **标签** 页签。

## 常见问题
| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 看不到 **设置** 页签 | 你的账号在这个仓库里没有管理权限 | 找仓库所有者或组织管理员，让他在设置页把你加为成员 |
| 镜像仓库找不到 **文件** | 镜像仓库用 **标签** 页签管理版本 | 到 **标签** 页签查看 |
