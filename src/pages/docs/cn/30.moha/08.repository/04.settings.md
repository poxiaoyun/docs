# 仓库设置与发布

**设置** 页签是仓库的「管理后台」：控制谁能看到它、哪些同事能改它、补充检索信息、给空间换封面和调部署参数，最后是删除仓库。不同资源类型显示的卡片略有差别，卡片顺序是固定的。

## 开始之前
只有满足下面任意一条的人才能看到 **设置** 页签：

- 系统管理员；
- 这个仓库的所有者；
- 这个仓库所属组织的管理员；
- 被加进这个仓库、角色是 **管理员**（模型、数据集、镜像还允许 **读写**）。

## 卡片总览
页面从上到下依次是这些卡片：

| 卡片 | 出现在 | 你可以做什么 |
| --- | --- | --- |
| **可见性** | 全部 | 点 **更改可见性**，把资源改成 公开 / 内部 / 私有 |
| **基本信息** | 全部 | 改别名和描述 |
| **成员** | 全部 | 加人、改角色、移除 |
| **元数据** | 全部（内容不同） | 补许可证、分类、标签等检索信息 |
| **简介** | 镜像 | 编辑镜像的说明文字 |
| **封面** | 空间 | 上传或更换封面图 |
| **部署配置** | 空间 | 改运行规格和环境变量 |
| **定时运行** | 空间 | 让空间只在指定时段运行 |
| **删除…** | 全部 | 删除整个仓库 |

![设置页可见性卡片：可见性 / 当前 两个字段 + 「更改可见性」按钮，以及点开后弹窗里的 公开 / 内部 / 私有 三选与「确认更改」](/assets/screenshots/moha/repo-setting-01.png)

可见性卡片上不直接给单选项，只显示 **可见性**、**当前** 的取值和一个 **更改可见性** 按钮——所有变更都要走弹窗二次确认。

## 改可见性
1. 在 **可见性** 卡片点 **更改可见性**。
2. 弹窗标题会写成「将 XXX 的可见性设为“YYY”」，选一个目标档位。

| 选项 | 谁能看到 | 弹窗里的说明 |
| --- | --- | --- |
| **公开** | 任何人都可以查看，包括未登录访客 | 设为公开后，任何人都可以查看该资源；提交权限仍由仓库权限规则决定 |
| **内部** | 该资源所属组织的成员 | 设为内部后，访问范围限于所属组织，仍按仓库权限规则授权 |
| **私有** | 仓库成员和被单独授权的人 | 设为私有后，不再公开或向组织整体开放，访问按仓库成员与权限规则授权 |

3. 点 **确认更改** 提交。

三档都可以来回改，改完不会锁定。**公开** 之后任何人（含未登录访客）都能看到这个仓库的可见内容。

:::tip 公开化没有单独的按钮
平台没有单独的「发布」或「提交审核」按钮——把可见性改成 **公开** 就是公开化。是否需要人工审核由平台管理员处理，这一页不提供审核入口。
:::

## 改别名和描述
1. 在 **基本信息** 卡片里填写 **别名**，这是页面上展示的名字。
2. 填写 **描述**，简单说明这个资源是做什么的。
3. 点 **更新**。

## 管理成员
1. 在 **成员** 卡片点 **添加成员**。
2. 在 **用户名** 里输入或从下拉列表选择组织内的成员。
3. 选择 **角色**：

| 角色 | 权限 |
| --- | --- |
| **管理员** | 可以管理成员并拥有读写权限 |
| **读写** | 拥有读写权限 |
| **只读** | 仅有只读权限 |

4. 点 **确定**。

已加入的成员会显示在列表里，并带上 **加入时间**。点铅笔图标可以改角色，点垃圾桶图标可以移除。你不能修改或移除自己。

## 补元数据
元数据决定你的资源能不能被搜到、能不能被推荐，值得认真填。不同资源类型要填的内容不同：

| 资源 | 主要字段 |
| --- | --- |
| 模型 | 许可证、分类、行业/业务域、适用场景、框架、语种、硬件后端、最低显存、自定义标签 |
| 数据集 | 行业/业务域、项目阶段、语种、文本类型、数据质量等级、获取方式、标签 |
| 镜像 | 分类、加速框架 |
| 空间 | 许可证、领域、场景 |

填写的上限：每个维度最多 30 个值，单个标签不超过 32 个字符，单个值不超过 128 个字符。填完点 **更新**。

## 编辑镜像简介
镜像的 **简介** 卡片对应镜像详情页里那段 Markdown 正文，可以直接在卡片里编辑，改完点 **更新**。

![镜像仓库的设置页：可见性、基本信息、成员、元数据与简介](/assets/screenshots/moha/repo-image-setting-01.png)

## 给空间换封面
1. 在 **封面** 卡片点 **上传封面**，选择本地图片。
2. 静态图片会被自动裁成 20:9 的横图；GIF、APNG、动态 WebP/AVIF 和动画 SVG 会保留动画。
3. 点 **更新**。

支持的格式有 jpg、png、apng、webp、gif、avif、svg，图片最大 5 MB。

![空间仓库的设置页：可见性、基本信息、成员、元数据与封面，成员列表里能看到角色与加入时间](/assets/screenshots/moha/repo-space-setting-01.png)

## 改空间的部署配置
空间的 **部署配置** 卡片就挂在设置页里，不需要回到创建流程。

1. 在 **部署配置** 卡片里设置 **规格**（决定分到多少 CPU / 内存 / 加速卡）和 **环境变量**（变量名 + 变量值，可添加多组）。
2. 点 **更新**。

**接入SDK**（应用模板）和 **部署工作空间** 在创建时确定，之后以只读方式显示。保存部署配置后系统会**自动重新发布**这个空间，不需要你再手动点一次 **重新发布**。

:::info 改完配置就等于重新发布
部署配置保存会触发一次重新发布，空间会短暂不可用。业务高峰期改之前先和用的人打个招呼。
:::

## 定时运行（只有空间有）
**定时运行** 卡片让空间只在指定时段运行，时段外副本数降为 0，省下空闲时段的开销。

1. 打开 **开启定时运行** 开关。
2. 选择 **运行方式**：

| 运行方式 | 还要填什么 |
| --- | --- |
| **每天固定时段** | 开始时间、结束时间 |
| **按星期运行** | 运行日（可多选，如周一、周三）、开始时间、结束时间 |
| **仅运行一次** | 开始日期、结束日期、开始时间、结束时间 |

3. 填写 **时区**，使用 IANA 写法，例如 `Asia/Shanghai` 或 `UTC`。
4. 保存后生效。尚未部署的空间会在下次部署时应用这套配置。

:::tip 跨午夜的时段
结束时间早于开始时间时，系统会认为运行到次日结束。例如 `22:00` 到 `02:00`，表示每晚十点到第二天凌晨两点。
:::

## 删除仓库
1. 拉到页面最下方，在 **删除模型 / 删除数据集 / 删除镜像 / 删除空间** 卡片里，把仓库名**原样输入**到输入框。
2. 名称完全一致后，**确定** 按钮才可以点击。
3. 点击 **确定** 完成删除。

:::warning 删除不可撤销
删除会**永久删除该资源及其所有关联文件和资源**，无法恢复。删除前请确认数据已经备份，或先创建一张快照留档。
:::

## 结果确认
- 每次点 **更新** 后，卡片上方会出现「更新成功」的提示。
- 改完可见性后，卡片上的 **当前** 会立刻变成新选中的那一档；回到列表页也能确认它出现在预期范围内。
- 保存部署配置后，空间详情的状态标签会短暂变成部署中的状态，稍后恢复为运行中。
- 定时运行保存后重新进入设置页，开关和时段仍然是刚才填的值。
