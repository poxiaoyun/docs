# 仓库设置与发布

设置页用于维护仓库的基础属性和协作权限。不同资源类型会显示不同的配置卡片，卡片顺序与实现一致。

## 设置页可见条件

只有满足以下任一条件的用户才能看到 **设置** 标签：

- 系统管理员
- 仓库 Owner（`data.owner === user.name`）
- 组织管理员（组织成员 `role === 'admin'`）
- 仓库成员且角色为 `admin` 或 `readwrite`

## 设置卡片

| 顺序 | 卡片 | 适用范围 | 说明 |
| --- | --- | --- | --- |
| 1 | 可见性（Visiable） | 全部 | 在 `public` / `internal` / `private` 之间切换 |
| 2 | 别名（Alias） | 全部 | 更新面向用户展示的名称 |
| 3 | 成员（Members） | 全部 | 管理仓库成员及角色 |
| 4a | 数据元数据（MetadataData） | 模型 / 数据集 | 许可证、任务、框架、标签、语言等 |
| 4b | 镜像元数据（MetadataImage） | 镜像 | 镜像元数据 |
| 4c | 代码元数据（MetadataCode） | Space | `license` / `domain` / `scene` 等 |
| 4d | 封面（Cover） | Space / 镜像 | 上传或修改封面图 |
| 4e | README | 镜像 | 编辑镜像说明文档 |
| 5 | 部署（Deploy） | Space | 部署参数配置 |
| 6 | 删除（Delete） | 全部 | 删除当前资源仓库 |

## 关于「公开化」

魔哈没有独立的「发布 / 提交审核」按钮：把资源的**可见性设为 `public`** 即为公开化。是否需要人工审核由 BOSS 侧管理，租户端的仓库设置页不提供审核入口。

> 💡 提示: BOSS 控制台在 `/boss/moha/audit` 提供审核页（`src/pages/boss/moha/audit`），并可在 `/boss/moha/:type` 创建/编辑数据管理器、在 `/boss/moha/mirrors` 维护镜像源。租户端只负责设置可见性。

## Space 部署

Space 的设置页额外提供部署卡片（Deploy）：

- 修改部署参数后会先保存（`updateDataManager`），再自动重启 Space（`restartSpace`）。
- 因此调整部署配置后可不必手动再点一次重启。

> ⚠️ 注意: 设置页直接影响资源可见性和团队协作权限，建议由仓库 Owner 或管理员统一维护。
