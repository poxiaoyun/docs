# 快照

**快照** 是给仓库当前状态拍的一张**存档照**：拍照之后，无论后面怎么改，你都能回到拍这张照时的样子。模型、数据集和空间都有这个页签，发布重要版本前先拍一张，之后改动就不怕出错。

:::tip 快照不是复制仓库
快照只是记录「当时是哪些文件、哪个提交」，不会把你的文件复制一份，所以创建起来很快，也不会额外占用一份存储。
:::

## 开始之前
登录魔哈账号，并且能打开这个仓库。镜像仓库没有快照页签。

## 打开快照页
进入任意模型、数据集或空间仓库，点击 **快照** 页签。

![快照列表的六列：标题、分支、提交信息、创建者、创建于与操作，操作里是差异 / 回滚 / 删除快照](/assets/screenshots/moha/repo-model-freezes-01.png)

**提交信息** 一列显示的是快照对应的提交短哈希（截图里是 `13448952dbda`），拿它可以和文件页的提交记录对上。

## 认识列表
列表里每一行就是一张快照：

| 列 | 含义 |
| --- | --- |
| 标题 | 这张快照的名字；创建时没填标题就显示编号，标题下方会显示创建原因 |
| 分支 | 快照拍的是哪个分支 |
| 提交信息 | 拍快照时所在的那次提交 |
| 创建者 | 谁拍的 |
| 创建于 | 拍摄时间 |
| 操作 | **差异**、**回滚**、**删除快照** |

## 创建一张快照
1. 在 **快照** 页签点右上角的 **冻结** 按钮。
2. 在弹出的窗口里填写：
   - **标题**：给这张快照起个能认出来的名字，最多 32 个字符；
   - **原因**：说明为什么拍这张快照，可以多行，也可以不填。
3. 点 **确定**。

:::tip 什么时候该拍快照
准备大改文件之前、准备对外发布之前、或者刚调通一个可用版本时，都是拍快照的好时机。
:::

## 对比差异
1. 在列表里找到要看的快照，点 **差异**。
2. 弹窗会用左右分栏显示「这张快照」与「当前状态」的区别，只列出有变化的文件。
3. 如果改动太大（数据超过 4 MiB），页面不会渲染内容，而是提示差异过大，请缩小对比范围或直接看具体文件。

## 回滚到某张快照
1. 在列表里点 **回滚**。
2. 弹窗会显示即将回滚到的分支和提交，请核对是否正确。
3. 点 **确定**，仓库会重置到这张快照对应的提交。

:::warning 回滚会改写提交历史
回滚会把目标分支重置到快照对应的提交，**该提交之后的记录可能被丢弃**。这是一步不可逆操作，执行前请确认目标快照没错，必要时先给当前状态也拍一张快照。
:::

## 删除快照
在列表里点 **删除快照**，确认后会移除这条存档记录。

:::warning 删除快照不影响当前文件
删除快照只是删掉这条存档记录，**仓库当前的文件内容不会改变**，但你以后就不能再回滚到这张快照了。
:::

## 在文件页看快照内容
快照也会出现在 **文件** 页签左上角的分支选择器里：点开 **分支: xxx**，在 **快照** 分组里选一张，就能像切换分支一样把文件视图切到那一刻的样子，方便查看历史文件。

## 结果确认
- 创建成功后，列表里立即出现新的快照行，并提示「快照已创建」。
- 回滚成功后提示「回滚完成」，页面会刷新为回滚后的内容。
