# 版本冻结

「版本冻结」是模型、数据集与 Space 仓库共有的标签页（`value` = `freezes`），用于把某个分支/提交冻结为不可变快照，并支持对比与回滚。

## 进入路径

仓库详情页 → **版本冻结** 标签

```text
/moha/<type>/<organization>/<repository>/freezes
```

> 💡 提示: 冻结也会出现在文件页顶部的分区切换器里，可像选择分支一样把当前视图切到某个冻结。

## 冻结列表

列表默认请求 `size=100`，展示字段如下：

| 列 | 字段 | 说明 |
| --- | --- | --- |
| 标题 | `title` | 为空时回退显示冻结 `id` |
| 分支 | `ref` | 冻结所在的引用 |
| 提交 | `commit` | 提交哈希（列表中截断展示前 12 位） |
| 创建人 | `createdBy` | 冻结创建者 |
| 创建时间 | `createdAt` | 时间格式化展示 |
| 操作 | — | 对比 / 回滚 / 删除 |

标题下方会额外展示 `reason`（冻结原因）。

## 创建冻结

点击 **创建冻结**，在弹窗中填写：

| 字段 | 说明 |
| --- | --- |
| `title` | 标题，最多 32 个字符 |
| `reason` | 多行原因说明（可选） |

提交时使用 `reference`（默认 `main`）与可选的 `commit` 定位被冻结的版本。

## 对比差异

点击 **对比（diff）** 会请求该冻结相对当前的差异，并以左右分栏方式渲染：

- 只展示有变更的文件，逐个文件显示 diff。
- 差异数据超过 4 MiB（`4 * 1024 * 1024`）时不渲染内容，改为提示数据过大。

## 回滚

点击 **回滚（rollback）** 会把仓库重置到该冻结：

- 调用参数为 `{ ref: freeze.ref, mode: 'reset' }`。
- 回滚属于破坏性操作，弹窗会展示将要回滚到的 `ref` 与 `commit` 并要求确认。

> ⚠️ 注意: 回滚会改变仓库当前状态，请确认目标冻结正确后再执行。

## 删除冻结

点击 **删除冻结** 会移除该条冻结记录（不影响仓库当前文件内容）。

## 与其他页面的关系

- 文件页的分支选择器会同时列出分支与冻结项。
- 版本能力的整体说明见[模型版本](/moha/models/version)。
