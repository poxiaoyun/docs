# 文件浏览与版本查看

文件页是仓库协作的核心页面之一，适合查看目录结构、预览文件内容以及追踪历史变更。

## 支持能力

| 能力 | 说明 |
| --- | --- |
| 文件树浏览 | 浏览目录与子文件 |
| 文件内容预览 | 根据文件类型切换目录视图或文件视图 |
| 提交记录 | 查看指定引用下的提交历史 |
| 差异对比 | 查看文件在不同版本间的差异 |
| 发起变更 | 从文件页进入 Pull Request 流程 |
| 下载与拉取 | 结合 Token 做文件下载或 Git 操作 |

## 典型路径

文件相关路由都挂在 `/moha/:type/:organization/:id/file` 之下（`:type` 取 `models` / `datasets`；Space 使用 `/moha/spaces/:organization/:id/file`）：

- 文件树：`/file/:reference`
- 指定文件：`/file/:reference/:file`
- 提交记录：`/file/:reference/commits`、`/file/:reference/:file/commits`
- 差异对比：`/file/:reference/diff`、`/file/:reference/:file/diff`
- 发起变更：`/file/:reference/:file/pullrequest`

## 使用建议

1. 先选定引用版本或分支（`reference`）。
2. 浏览目录找到目标文件。
3. 需要审查历史时进入提交记录或差异页面。
4. 修改完文件后从差异页面进入 Pull Request，配合讨论页记录变更背景。

> 💡 提示: 镜像仓库没有文件页，只有「标签」页；`freezes`（版本冻结）是独立标签，不挂在文件页下。
