# 文件浏览与版本查看

**文件** 页签就是仓库的「文件夹视图」：你可以一层层点开目录、预览文件内容、切换到某个分支或快照看当时的样子，也能在这里上传和修改文件。模型和数据集的下载按钮在页面顶部，空间的下载入口在文件页右上角。

## 开始之前
- 登录魔哈账号，并且能打开这个仓库。
- 想上传、修改或删除文件：你的账号需要在 **设置** 页签里被加为成员（管理员或读写角色），并且仓库没有加密。

:::tip 镜像仓库没有文件页
镜像用 **标签** 页签管理版本，没有文件树。这一页只适用于模型、数据集和空间。
:::

## 页面构成
| 位置 | 作用 |
| --- | --- |
| 左上 **分支: xxx** | 切换分支或快照，决定你看到的是哪个版本 |
| 路径文字 | 显示当前所在目录；点其中的任一段可跳回上一层 |
| **提交记录** | 查看历史提交，按钮上会显示提交次数 |
| **添加文件** | 上传文件、上传文件夹、新建文件、新建文件夹（模型/数据集） |
| **下载** | 空间在右上角，提供 Git 与 SDK 两种下载方式 |

## 切换分支或快照
1. 点左上角的 **分支: xxx**。
2. 在弹出的菜单里选择：
   - **分支** 组：切换到某个分支的当前状态。
   - **快照** 组：切换到某张历史存档。只有这个仓库创建过快照时才会出现这一组。
3. 选好后页面立即刷新为那个版本的内容。此时页面上是**只读**的，想改内容要先切回分支。

## 浏览与预览文件
1. 点击文件夹进入下一层；点路径里的上一段返回。
2. 点击文件名打开预览：
   - 文本、代码、JSON 会直接显示内容；
   - 图片会直接显示出来；
   - Markdown 会渲染成排版后的样子。
3. 文件太大（超过 5 MB）时不会显示内容，页面会提示你下载后查看。
4. 用 Git LFS 存储的大文件同样只显示「该文件使用 Git LFS 存储……您仍然可以下载」的提示。

文件预览页顶部有三个按钮：

| 按钮 | 作用 |
| --- | --- |
| **原始内容** | 在新标签页打开该文件的原始内容 |
| **提交记录** | 查看这个文件的提交历史 |
| **创建合并请求** | 只有文本文件才有，用于把修改走一遍评审流程 |

## 查看提交记录与差异
1. 在文件页点右上角 **提交记录**（或进入某个文件后点 **提交记录**）。
2. 列表里可以看到每次提交的时间、作者和提交信息。
3. 想看某次提交改了什么，进入差异（Diff）视图：新增的行和删除的行会分别着色对比。

## 下载文件
### 模型、数据集
用页面顶部信息栏里的 **下载** 按钮，弹窗里有 **Git** 和 **SDK** 两个页签，命令可以直接复制：

| 页签 | 提供的命令 |
| --- | --- |
| **Git** | `git lfs install`、`git clone <仓库地址>`、`GIT_LFS_SKIP_SMUDGE=1 git clone <仓库地址>`（不含大文件的克隆） |
| **SDK** | `pip install moha-hub`、`moha download --repo-type models <组织>/<仓库>`，以及 Python 版 `snapshot_download` 示例 |

### 空间
空间的文件页右上角有下载按钮，同样提供 Git 与 SDK 两种方式。

## 上传、新建、编辑、删除文件（模型 / 数据集）
1. 点 **添加文件**，选择要做的操作：**上传文件**、**上传文件夹**、**新建文件夹** 或 **新建文件**。
2. 上传时把文件拖进弹窗，或点入口选择；新建时输入名称。
3. 填写 **提交信息**（必填）。
4. 点 **提交更改**。

如果目标路径已经存在同名文件，弹窗会提示「文件已存在」，你可以选择 **覆盖并提交**。

### 在线修改单个文件
在文件行右侧点 **编辑文件**，改完填提交信息再提交。以下情况不能在线编辑：

- 文件夹；
- 使用 Git LFS 存储的大文件；
- 加密仓库里的文件；
- 超过在线编辑大小限制的文件；
- 图片、模型权重等二进制文件（只支持文本）。

:::warning 删除不可撤销
删除文件或文件夹时，必须手动输入名称确认。文件夹会连同里面所有内容一起删除，且无法恢复。删掉后可以用 **提交记录** 里的回滚功能找回，但操作前请确认清楚。
:::

### 浏览器上传的限制
| 项目 | 限制 |
| --- | --- |
| 一次上传的文件数 | 最多 100 个 |
| 一次上传的总大小 | 最多 100 MB |
| 单个在线新建文件 | 最多 2 MiB |

超过这些限制时，请改用 Moha SDK 上传，见 [SDK 教程](/moha/sdk-tutorial/transfer)。

## 结果确认
- 提交成功后右上角会出现「提交成功（提交号）」的提示，文件列表随之刷新。
- 切换分支或快照后，路径旁和列表内容会一起变化。

## 常见问题
| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 看不到 **添加文件** | 没有写权限，或仓库已加密 | 让管理员在 **设置** 里给你读写权限；加密仓库改用 Git 上传 |
| 按钮提示「该文件不支持在线编辑」 | 是非文本文件、LFS 文件或太大 | 改用 **上传文件** 覆盖，或用 Git/SDK 修改 |
| 提交后列表没变化 | 页面缓存 | 点刷新，或重新进入该页签 |
