# 讨论与协作

**交流反馈** 页签是这个仓库的「留言板 + 代码评审区」。你遇到使用问题、想提改进建议，或者想请别人审阅一次文件改动，都在这里进行。讨论会一直留在仓库里，比口头沟通更容易追溯。

## 开始之前
登录魔哈账号，并且能打开这个仓库。镜像仓库没有这一页。

## 页面构成
顶部有三个子页签，用来筛选列表内容：

| 子页签 | 显示什么 |
| --- | --- |
| **所有** | 讨论和合并请求全部显示 |
| **讨论** | 只看提问、反馈类话题 |
| **合并请求** | 只看针对代码变更的评审 |

右上角的 **添加讨论** 用来发起新话题。列表里每条会显示标题、发起人、创建时间和回复数；合并请求还会显示 **已合并** 或 **已关闭** 的状态。

## 发起一个讨论
1. 进入仓库的 **交流反馈** 页签。
2. 点右上角 **添加讨论**（手机端在页面右侧的菜单图标里）。
3. 填写 **标题**（必填）。
4. 填写 **内容**（必填），支持排版、列表、代码块等富文本。
5. 点 **确定**。

## 查看和回复
1. 在列表里点击某条讨论的标题，进入详情。
2. 在详情页底部输入内容后提交，即可回复。
3. 自己发布的内容可以点 **编辑内容** 修改；点删除可以删掉整条讨论。

:::warning 删除讨论会连带删除回复
删除讨论后，这条讨论下**所有回复也会一起删除**，且无法恢复。删除单条回复则只影响该条回复。
:::

## 评审代码变更（合并请求）
合并请求用来「改文件 → 请人评审 → 合并」：

1. 先到 **文件** 页签修改文件，或在文件预览页点 **创建合并请求**。
2. 进入 **创建合并请求** 页面，确认改动内容后提交。它会自动出现在 **交流反馈** 的 **合并请求** 列表里。
3. 在列表里对某条合并请求可以：
   - **查看**：用左右分栏对比改动前后的差异；
   - **合并**：把改动正式合入；
   - **关闭**：标记为 **已关闭**，暂不合并；
   - **重新打开**：把已关闭的再打开。

:::warning 合并前先看差异
**合并** 会把改动正式写入仓库。建议先点 **查看** 确认每一处差异都符合预期，再执行合并。
:::

## 结果确认
- 发起讨论后，列表里立即出现这条话题，回复数从 0 开始。
- 合并请求合并成功后，状态显示为 **已合并**；被关闭的显示为 **已关闭**。
