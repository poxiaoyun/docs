# 空间

空间是**用代码搭建好、并发布到网上的在线 AI 应用**。它不是个人主页，也不是一堆文件：别人打开链接就能直接在浏览器里用，不用下载、不用装环境。你在空间里放的是一段能跑起来的应用代码，平台负责把它构建好、运行起来，并分配一个访问地址。

:::tip 和模型、数据集的差别
模型和数据集的仓库里主要放文件，别人下载回去自己用；空间里放的是「能跑起来的应用」，别人点开链接就能用。
:::

## 开始之前
- 浏览公开空间：登录魔哈账号即可，不需要额外权限。
- 自己发布空间：需要能创建仓库的账号，并准备一份可运行的应用代码（例如 Gradio、Streamlit 或 Docker 应用）。

## 核心概念
| 名词 | 通俗解释 |
| --- | --- |
| 空间 | 用代码搭建并发布到网上的在线应用，别人打开链接就能用 |
| 应用模板 | 平台的「脚手架」，例如 Gradio、Streamlit 或 Docker，决定应用怎么跑起来 |
| 发布 | 把应用真正跑起来并分配访问地址，相当于「开门营业」 |
| 快照 | 给仓库当前状态拍张存档照，随时能回到这个状态 |

## 浏览别人发布的空间
1. 在魔哈顶部导航点击 **空间**，进入空间列表。
2. 页面上的 **精选** 区展示被推荐的空间；下方 **全部** 区按当前条件列出所有空间。
3. 在搜索框输入名称查找；也可以用 **领域**、**场景** 两组按钮缩小范围。
4. 点击任意空间卡片，进入它的详情页。

进入空间详情后，顶部有这几个页签：

| 页签 | 你可以在这里做什么 |
| --- | --- |
| 概览 | 应用运行正常时，这里会直接显示应用界面，你可以当场使用 |
| 文件 | 查看空间仓库里的代码和文件 |
| 快照 | 查看历史存档，对比差异或回滚 |
| 交流反馈 | 提问、反馈，或就代码变更发起合并请求 |
| 设置 | 修改可见性、成员、封面和部署参数（需要有权限） |

## 发布自己的空间
1. 在空间列表点击 **创建空间**。
2. 填写名称、别名、描述、可见性，并选择许可证、领域、场景。
3. 在 **部署配置** 里选择 **接入SDK**（应用模板）、**部署工作空间**（先选区域，再选工作空间）、**规格**，需要的话再添加 **环境变量**。
4. 提交后进入这个空间的仓库，把应用代码推送上去。
5. 回到空间详情页，点右上角 **操作**，选择 **发布**，再点 **确定**。
6. 等待 **概览** 页出现应用界面。若长时间未就绪，点 **操作** 里的 **日志** 查看构建输出。

## 结果确认
- 空间列表里出现你创建的空间卡片。
- 详情页 **概览** 里显示出应用界面，说明已经发布成功。
- 右上角状态标签会显示当前运行状态；已发布的空间，**操作** 菜单里会出现 **停止**、**重新发布**、**日志**。

:::warning 停止会释放资源
**停止** 会下线应用并释放占用的算力资源，访问地址随之不可用。需要重新使用时再点 **重新发布**。
:::
