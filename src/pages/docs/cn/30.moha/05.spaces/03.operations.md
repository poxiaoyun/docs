# 发布、停止与重新发布

空间创建好、代码推上去之后，还要**发布**才会真正跑起来。这一页讲清楚上线、下线、重启分别怎么做，状态标签卡在某一档时该看哪里。

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 发布 | 启动应用实例并分配访问地址，相当于「开门营业」 |
| 停止 | 下线应用、释放算力，访问地址失效，之后可以再发布 |
| 重新发布 | 用当前配置重启实例，改过配置或代码后用它生效 |
| 日志 | 实例启动和运行过程中的输出，出问题时先看这里 |

### 状态标签怎么读

空间详情页顶部有一个状态标签，取值和含义如下：

| 状态 | 含义 |
| --- | --- |
| **未知** | 平台还没拿到运行状态 |
| **部署中** | 正在创建实例、拉取镜像、启动进程 |
| **已安装** | 依赖或应用已装好，还没进入可服务状态 |
| **运行中** | 应用已就绪，概览页会直接显示应用界面 |
| **状态同步中** | 平台正在核对实际状态，稍等即可 |
| **处理失败** | 部署或启动失败，需要看日志定位 |
| **已完成（有失败）** | 部分步骤成功、部分失败，同样要看日志 |
| **已暂停** | 被主动停止，实例已释放 |
| **已缩容至 0** | 由定时运行把副本数降到 0，到时段会自动恢复 |
| **删除中** | 空间正在被删除 |

## 操作按钮在哪

**操作** 按钮不在页面右上角，而在**页签行的右侧**（**概览**、**文件**、**快照**、**交流反馈**、**设置** 那一行的最右边），点开是一个下拉菜单。

:::warning 只有空间管理员看得到
这个按钮只对空间的管理员（仓库成员里角色是 **管理员** 的人）显示。所有者、组织管理员和系统管理员同样能看到。角色是 **读写** 的成员看不到这个按钮，也就不能发布或停止。
:::

## 发布：让空间跑起来
刚创建、还没有实例的空间，菜单里只有 **发布** 一项。

1. 进入空间详情页，点 **操作** → **发布**。
2. 弹窗标题是「发布空间 XXX」，说明是「发布会启动该空间的应用实例，并应用当前保存的部署配置」。
3. 点 **确定** 提交。

提交后状态标签先显示 **部署中**，等它就绪会变成 **运行中**，概览页里会出现应用界面。

:::info 「提交成功」不等于「已经跑起来」
弹窗里的提示说明：请求成功只代表平台已受理，运行状态随后才更新。点完 **确定** 后不要反复重试，等状态标签变化即可。
:::

## 停止：下线并释放资源
已经有实例的空间，菜单里有 **停止**、**重新发布**、**日志**。

1. 点 **操作** → **停止**。
2. 弹窗提示停止会暂停应用实例、释放计算资源，之后可以重新发布恢复。
3. 点 **确定**。

停止后状态变成 **已暂停**，访问地址失效。需要再用时点 **重新发布**。

:::warning 停止会中断所有正在使用的人
停止会立即释放算力，正在访问这个空间的用户会断开。要停之前先确认没有人在用。
:::

## 重新发布：让改动生效
改过部署配置、环境变量或者推送了新代码之后，需要重新发布。

1. 点 **操作** → **重新发布**。
2. 弹窗说明会重启应用实例并重新应用当前部署配置。
3. 点 **确定**。

:::tip 改部署配置会自动重新发布
在 **设置** → **部署配置** 里保存规格或环境变量时，系统会自动触发一次重新发布，不必再手动点这里。只有改代码（推送提交）之后才需要手动重新发布。
:::

## 看日志

1. 点 **操作** → **日志**，弹出日志面板。
2. 面板里按时间顺序显示实例的输出，可以直接定位「镜像拉取失败」「依赖装不上」「应用启动报错」这类问题。
3. 状态是 **处理失败** 或 **已完成（有失败）** 时，日志是唯一能看出原因的地方。

概览页在空间还没就绪时也会给一个 **日志** 入口，效果相同。

## 定时运行：按时段自动启停
定时运行和手动操作是两套机制：手动 **停止** 是暂停，定时运行是让副本数按时段在「有」和「0」之间切换。

1. 进入 **设置** 页签，找到 **定时运行** 卡片。
2. 打开 **开启定时运行**，选择 **运行方式**（每天固定时段 / 按星期运行 / 仅运行一次），填好时段和 **时区**。
3. 保存后生效。时段外状态会显示 **已缩容至 0**，到时段自动恢复。

还没部署过的空间，这套配置会在下次部署时应用。

## 修改规格与环境变量
1. 进入 **设置** → **部署配置**。
2. 改 **规格** 或 **环境变量**，点 **更新**。
3. 保存后系统自动重新发布，稍等状态回到 **运行中**。

**接入SDK** 和 **部署工作空间** 在创建时确定，这里只能看不能改。

## 结果确认

- 发布后状态从 **部署中** 变为 **运行中**，概览页出现应用界面。
- 停止后状态变为 **已暂停**，概览页不再显示应用界面，而是给出上手说明。
- 重新发布后状态会短暂回到 **部署中**，随后恢复。
- 改完部署配置保存后，状态标签会自动经历一次「部署中 → 运行中」，说明自动重新发布已生效。
