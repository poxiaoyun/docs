# Space 列表与筛选

Space 列表页（`/moha/spaces`）在交互上与模型、数据集、镜像保持一致，但额外提供**精选推荐区**和按 `domain` / `scene` 的分类筛选。

## 页面结构

| 区块 | 说明 |
| --- | --- |
| 工具栏 | 关键字搜索、结果总数、刷新、排序 |
| 精选推荐区 | 依据推荐指数挑选的推荐 Space |
| 全部 | 按当前筛选条件分页展示的 Space 卡片列表 |

## 搜索与结果数

工具栏提供按名称/关键字的搜索框，并展示当前条件下的结果总数（`total`），同时提供刷新按钮。

## 精选推荐区

精选推荐区独立于「全部」列表，取数逻辑为：

1. 以 `sort=recommendation`、候选上限 100 条请求推荐列表。
2. 过滤出标注 `RECOMMEND_SCORE > 0` 的资源。
3. 按 `RECOMMEND_SCORE` 降序排序，最多展示 8 条。

因此只有被打过推荐指数的 Space 才会出现在精选区；搜索条件也会同时作用于精选区。

## 排序

| 值 | 含义 |
| --- | --- |
| `''` | 综合排序（默认） |
| `downloads` | 按下载量 |
| `likes` | 按点赞/收藏 |

## 可见性切换

列表支持在 `public` / `private` / `internal` 之间切换：

- `public` 走全平台资源列表接口。
- `private` / `internal` 走「我的资源」接口，按当前组织范围查询。

## 分类筛选

筛选面板由 `domain`（领域）与 `scene`（场景）两组构成，选项来自 Space 元数据：

- `domain` 与 `scene` 均为多选语义，选中后写入查询 `selector` 并重置到第 1 页。
- `scene` 面板默认最多显示 4 个选项，可展开查看全部。
- 只有对应选项列表非空时才会渲染该组筛选。

## 分页

列表默认每页 `size=12`，采用分页/继续加载（`continue`）方式翻页。

## 适用场景

- 查找可直接体验的 Demo 或应用模板。
- 按领域/场景筛选组织内共享的交互式应用。
- 进入某个 Space 的仓库详情后继续查看文件、讨论和部署配置。
