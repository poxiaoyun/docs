# 空间列表与筛选

空间列表是发现和挑选空间的地方。这一页帮你按名称搜索、按领域和场景缩小范围、按热度排序，最后点进某一个空间去体验或者查看它的代码。

## 开始之前
登录魔哈账号即可，浏览公开空间不需要额外权限。

## 打开空间列表
在魔哈顶部导航点击 **空间**。

![空间列表的结构：四步条与创建按钮、领域 / 场景筛选、搜索与排序、精选区，再往下是全部列表](/assets/screenshots/moha/spaces-list-01.png)

**精选** 由平台运营挑选，和下面「全部」列表的内容会重复——同一张卡片可能既在精选里又在全部里。

## 页面结构
| 区块 | 你可以在这里做什么 |
| --- | --- |
| 筛选区 | 按 **领域**、**场景** 缩小范围 |
| 工具栏 | 搜索、查看结果总数、刷新、排序 |
| **精选** | 平台挑选的推荐空间 |
| **全部** | 符合当前条件的空间卡片列表 |

## 搜索
1. 在工具栏的搜索框输入空间名称。
2. 按回车开始搜索。

搜索框右侧会显示当前条件下的结果总数（例如「12 条结果」）。点击刷新按钮可以重新加载。

## 排序
点击排序下拉框，可以在这三种之间切换：

| 选项 | 效果 |
| --- | --- |
| 综合排序 | 默认，按平台综合权重排列 |
| 下载次数 | 下载/使用多的排前面 |
| 喜欢数量 | 被「喜欢」多的排前面 |

## 按领域和场景筛选
1. 在筛选区找到 **领域** 或 **场景**。
2. 点击某个选项，列表会立即按该选项刷新，并回到第 1 页。
3. 再点一次同一个选项，可取消该筛选。

**场景** 默认只显示前几个选项，点击 **更多** 可以展开查看全部。领域和场景的具体选项由平台下发，例如领域里的「多模态」「计算机视觉」「自然语言处理」。只有存在可选项时，对应的那一组才会显示出来。

## 精选区与全部列表
- **精选** 区独立于 **全部** 列表，只展示被平台标记为推荐的空间，最多 8 个。
- 你的搜索和筛选条件会同时作用于 **精选** 区和 **全部** 列表。

## 翻页
**全部** 列表每页展示 12 个空间，翻到下一页继续浏览。

![空间仓库的概览页：仓库名、状态、更新时间与三个计数，下面是「基础介绍」里的 git 克隆、示例 app.py 与提交三步](/assets/screenshots/moha/repo-space-content-01.png)

空间仓库的 **概览** 默认给的就是一份上手说明：`git lfs install` → `git clone` → 写 `app.py` → `git push`。勾选右上角的「使用我的 Token」会把克隆地址换成带令牌的形式，私有空间也能直接克隆。

## 进入一个空间
点击任意空间卡片，即可进入它的详情页；详情页里的 **概览**、**文件**、**快照**、**交流反馈**、**设置** 页签见 [仓库详情页结构](/moha/repository/detail)。

## 结果确认
列表里出现空间卡片、结果总数随之变化，就说明搜索或筛选已经生效。
