# 镜像仓库

**镜像**是别人（或你自己）做好的**现成运行环境**：一个已经装好操作系统、Python、驱动和依赖的「系统盘」，拿去就能开机用，不用自己一个个装软件。镜像仓库就是收集这些环境的地方。

用它来沉淀训练、推理或空间运行所需的基础环境，需要的时候让同事直接拉走，省去重复搭建。

:::tip 用「系统盘」理解镜像
可以把它想成装系统用的**系统盘模板**：你用它开出一台机器，里面该有的软件都已经装好了。同类型的环境，大家用同一块盘，结果就一致。
:::

## 进入路径

顶部导航点击 **镜像仓库**，进入镜像列表页。

## 几个名词

| 名词 | 通俗解释 |
| --- | --- |
| 镜像 | 一个打包好的运行环境，能直接拉下来跑 |
| 标签 | 环境的版本号，例如 `v1.0`、`latest` |
| 镜像扫描 | 检查这个环境里有没有已知的安全漏洞 |
| 可见性 | 谁能看到它：公开、租户内、私有 |

![创建镜像表单：镜像区块（名称、ID、组织、描述）与「简介」正文框，下面是分类、框架与成员](/assets/screenshots/moha/create-image-01.png)

镜像的创建表单里有一段 **简介** 富文本，它对应镜像详情页里那段 Markdown 正文；模型和数据集没有这一项，它们的正文来自仓库根目录的 README。

## 和模型、数据集有什么区别

| 对比 | 模型 | 数据集 | 镜像 |
| --- | --- | --- | --- |
| 里面装什么 | 训练好的权重 | 训练和评测数据 | 一整套运行环境 |
| 怎么拿走 | 网页下载、Git、命令行 | 同左 | 用 `docker pull` 拉取 |
| 详情页有什么 | 介绍、文件、快照 | 介绍、文件、快照 | 介绍、**标签**、设置 |

镜像的详情页没有「文件」和「快照」页签，取而代之的是「标签」页签——同一个镜像的不同版本都在那里。

![镜像仓库列表：左侧按分类 / 框架 / 架构 / 组织筛选，卡片上标注分类与架构](/assets/screenshots/moha/images-list-01.png)

镜像页比模型、数据集多一个 **架构** 筛选维度（截图里有 `CPU`、`CANN(昇腾)`、`Musl(摩尔线程)`），因为同一个镜像往往要按 amd64 / arm64 分别发布。

## 你能在这里做什么

| 我想…… | 去哪里 |
| --- | --- |
| 浏览有哪些镜像 | [镜像列表与筛选](/moha/images/gallery) |
| 看某个镜像有哪些版本 | 打开镜像，进 **标签** 页签 |
| 检查镜像有没有漏洞 | 在 **标签** 页签里点 **镜像扫描** |
| 改动镜像的可见性、简介 | 打开镜像，进 **设置** 页签（需要维护权限） |
