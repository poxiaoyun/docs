# 镜像列表与筛选

镜像仓库的列表页用来**找环境**：按分类、框架、架构筛选出合适的镜像，点进去看它有哪些版本、有没有漏洞，再把拉取命令复制到自己的机器上。

## 开始之前

- 浏览**公开**镜像不需要登录。
- 查看**租户内**或**私有**镜像，需要登录并且属于对应组织。

## 找到想要的镜像

1. 顶部导航点击 **镜像仓库**。
2. 在搜索框输入镜像名称或别名，快速定位。
3. 用左侧的筛选面板缩小范围，按需要切换页签勾选：
   - **分类**：网络、安全、机器学习等用途分类。
   - **框架**：CUDA、CANN、ROCm 等加速框架。
   - **架构**：X86 或 ARM。
4. 需要排序时，点击右上角的排序按钮，可选 **综合排序**、**下载次数**、**喜欢数量**。
5. 找到目标后，点击卡片进入镜像详情页。

:::info 列表默认只给你看公开镜像
镜像列表默认展示**公开**镜像。你所在组织里的**租户内**和**私有**镜像，请到[组织空间](/moha/home/organizations)或[我创建的资源](/moha/home/created-by-me)里查看。
:::

## 镜像详情页有什么

进入镜像后，顶部有三个页签：

| 页签 | 给你看什么 | 你能做什么 |
| --- | --- | --- |
| 镜像介绍 | 镜像的说明文字 | 了解这个环境装了什么、怎么用 |
| 标签 | 这个镜像的所有版本和漏洞扫描结果 | 复制拉取命令、发起扫描 |
| 设置 | 可见性、别名、成员、元数据、简介、删除 | 只有维护者能看到并修改 |

## 查看版本并拉取到本地

1. 在详情页点击 **标签** 页签。
2. 每个版本是一张卡片，上面显示标签名，以及一张架构表（摘要、架构、镜像扫描、大小）。
3. 卡片右上角有一条 `docker pull ...` 命令和复制按钮，点击复制。
4. 把命令粘贴到本机命令行执行，即可把镜像拉到本地。

私有镜像拉取前需要先登录镜像仓库：

1. 在详情页右上角点击 **下载镜像**。
2. 弹窗里第一条是 **登录镜像仓库** 命令，包含你的用户名和令牌，复制后先在命令行执行一次。
3. 弹窗里另外两条是 **标记镜像** 和 **推送镜像** 命令，上传自己的镜像时才会用到。

:::warning 登录命令里带着你的令牌
`docker login` 命令里包含你的访问令牌。复制和执行时注意不要在共享屏幕上暴露，也不要把它贴到公开的地方。
:::

## 检查镜像有没有漏洞

1. 在 **标签** 页签的某张版本卡片上，点击 **镜像扫描**。
2. 扫描过程中按钮变成 **停止扫描**，想中断就点它。
3. 扫描完成后，卡片上会显示四档漏洞数量：**严重**、**高危**、**中危**、**低危**。
4. 点击这些数量标签，弹出 **CVE 报告**，可以逐条查看漏洞编号、包名、严重程度和修复版本。
5. 卡片右上角的刷新图标可以重新拉取最新的扫描结果。

## 结果确认

- 点击卡片能进入镜像详情页，页签在 **镜像介绍**、**标签**、**设置** 之间正常切换。
- 在 **标签** 页签能看到至少一个版本卡片和它的 `docker pull` 命令。
- 扫描完成后，卡片上出现漏洞档位数量，或提示没有发现漏洞。
