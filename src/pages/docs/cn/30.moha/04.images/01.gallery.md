# 镜像列表与筛选

镜像列表页沿用魔哈统一列表框架，适合从资产发现和镜像治理两个角度使用。

## 列表能力

| 能力 | 说明 |
| --- | --- |
| 可见性切换 | 在 `public` / `private` / `internal` 之间切换，默认 `public` |
| 搜索 | 通过名称或关键字定位镜像 |
| 排序 | `''`（综合）、`downloads`、`likes`（镜像不提供 `rating` 排序） |
| 分页 | 默认每页 `size=16` |
| 数据卡片 | 查看镜像基础信息并进入详情页 |

## 镜像详情标签

进入镜像仓库后，标签页为 `content`、`tags`、`setting`：

- `content`：镜像卡片/README。
- `tags`：镜像标签列表与安全扫描。
- `setting`：可见性、别名、成员、镜像元数据、README 与删除（镜像没有文件与冻结标签）。

## 镜像标签与安全扫描

标签页（`tags`）用于管理镜像版本与漏洞扫描结果：

| 能力 | 说明 |
| --- | --- |
| 标签列表 | 展示镜像仓库中的 Tag 及其信息 |
| Trivy 扫描 | 对 Tag 触发或停止漏洞扫描，并查看扫描状态 |
| 漏洞严重程度 | `critical` / `high` / `medium` / `low` 四档分别统计，可展开查看 CVE 明细 |

> ⚠️ 注意: 扫描报告的字段以 Trivy 报告解析结果为准；页面只统计以上四个严重级别。

## 使用建议

- 面向全平台复用的公共基础镜像，建议维护清晰的说明和标签。
- 若镜像只服务于特定团队，可采用私有或内部可见性。
- 需要维护镜像元数据时，进入仓库设置页更新元数据、封面、README 与成员。
