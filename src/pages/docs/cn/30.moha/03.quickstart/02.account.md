# 账号设置

魔哈里没有单独一页「账号设置」。账号、密码、手机和邮箱都在**个人设置**（也叫用户中心）里统一管理，从页面右上角的头像进入。

这一页告诉你个人设置里每个页签能做什么，以及魔哈的**访问令牌**和平台**API 密钥**到底有什么区别。

## 开始之前

- 你已经登录平台，并且能看到页面右上角的头像。

## 打开个人设置

1. 点击右上角的**头像**。
2. 在右侧滑出的面板里点击 **个人设置**。
3. 页面顶部会显示 **用户中心**，下面是一排页签，点页签即可切换。

头像面板里还有两个常用按钮：

- **切换租户**：换一个组织工作。
- **登出**：退出当前账号。

## 个人设置里每个页签做什么

| 页签 | 你能做什么 |
| --- | --- |
| 基本信息 | 查看和修改昵称等个人信息 |
| 密码 | 修改登录密码，需要先填旧密码，再填两次新密码 |
| 邮箱 | 绑定或更换邮箱，需要输入验证码 |
| 手机号码 | 绑定或更换手机号 |
| API Key | 生成和管理用于**调用模型接口**的密钥 |
| SSH 密钥 | 添加本机 SSH 公钥，用于免密拉取代码仓库 |
| 多因素认证 | 开启双因素认证，用手机上的验证器 App 一起验证登录 |
| 主题 | 切换界面主题 |

## 换一个组织

1. 点击右上角**头像**。
2. 点击 **切换租户**。
3. 在 **选择您的租户** 页面选中目标组织，点击 **进入平台**。
4. 如果列表里没有你要的组织，点击 **创建租户** 自助创建一个。

## 访问令牌和 API 密钥不是一回事

两者都叫「密钥」，但用途完全不同，别拿错：

| 名称 | 在哪里 | 用来干什么 |
| --- | --- | --- |
| 访问令牌 | 魔哈 **首页 → 访问令牌** | 命令行下载/上传、Git 拉取推送、SDK 认证 |
| API Key | 个人设置 → API Key | 调用模型推理接口（AI 能力） |

在魔哈里做下载、上传，用的是**访问令牌**，见[访问令牌](/moha/quickstart/token)。

:::warning Secret Key 只显示一次
生成 API Key 时会同时给出 Access Key 和 Secret Key，其中 Secret Key **只出现这一次**。看到后立刻复制保存；关掉弹窗就再也看不到，只能重新生成。
:::

:::tip SSH 公钥怎么找
添加 SSH 密钥时需要粘贴公钥内容，通常保存在本机的 `~/.ssh/id_rsa.pub` 或 `~/.ssh/id_ed25519.pub` 里。用文本编辑器打开、整行复制即可，不要粘贴私钥（没有 `.pub` 后缀的那个文件）。
:::
