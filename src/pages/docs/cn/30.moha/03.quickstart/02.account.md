# 账号设置

魔哈里没有单独一页「账号设置」，账号、密码、手机和邮箱都在**个人设置**里统一管理，入口是页面右上角的头像。这一页说清个人设置的四个页签各管什么，以及魔哈的**访问令牌**和平台**API Key** 到底有什么区别——这两个最容易搞混。

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 个人设置 | 管你这个人：头像、昵称、邮箱、手机、密码、密钥、界面偏好 |
| 访问令牌 | 命令行和 Git 用来证明「你是你」的通行证，在魔哈首页复制 |
| API Key | 用来调用模型推理接口的密钥，在个人设置的 **访问密钥** 里生成 |
| SSH 密钥 | 一对公私钥，配好之后 Git 可以免密拉取推送，公钥存在 **访问密钥** 里 |

:::tip 个人设置和「组织」是两层
个人设置管的是**你这个人**，全平台通用；左侧或头像面板里的租户（组织）管的是**团队**，换组织只换看到的数据，不换账号。
:::

## 开始之前

- 你已经登录平台，并且能看到页面右上角的头像。
- 想改密码，先记住当前的旧密码；想开多因素认证，手机上先装一个验证器 App。

## 打开个人设置

1. 点击右上角的**头像**。
2. 在右侧滑出的面板里点击 **个人设置**。
3. 页面顶部标题是 **个人设置**，下面一排页签，点页签即可切换。

![打开个人设置：点右上角头像，弹出的面板里点「个人设置」](/assets/screenshots/moha/avatar-menu-01.png)

头像面板里还有两个常用按钮：**切换租户**（换一个组织工作）和 **登出**（退出当前账号）。面板里的 **主页** 只是回首页，别和 **个人设置** 点混。

## 四个页签各管什么

| 页签 | 你能做什么 |
| --- | --- |
| **基本信息** | 换头像；看用户名（只读）；改昵称；添加或更换邮箱、手机号码 |
| **账户安全** | 修改密码（旧密码 + 两次新密码）；开启多因素认证 |
| **访问密钥** | 生成和管理 API Key；添加、查看、删除 SSH 公钥 |
| **偏好设置** | 切换 **偏好模式**（浅色 / 深色等）、**色彩**、**语言偏好** |

![个人设置页：顶部标题「个人设置」，四个页签 基本信息 / 账户安全 / 访问密钥 / 偏好设置，当前停在基本信息，可见头像、用户名、昵称、邮箱、手机号码五行](/assets/screenshots/moha/account-settings-01.png)

## 改头像、昵称、邮箱和手机号码

1. 进入 **基本信息**。
2. 换头像：点头像区域选择本地图片上传（最大 3 MB）。
3. 改昵称：在 **昵称** 一行点 **修改**，填新昵称后点 **保存**。
4. 改邮箱或手机号：在对应一行点 **修改**（还没绑定过时按钮是 **添加**），按提示完成验证。
5. 用户名不可改；邮箱和手机号没绑定时显示 **未绑定**。

## 改密码与开多因素认证

### 修改密码

1. 进入 **账户安全**，在 **密码与认证** 区块找到 **密码** 一行。
2. 点右侧的 **修改密码**（还没设过密码的账号显示 **设置密码**），打开弹窗。
3. 填写 **旧密码**（已有密码时才需要）、**新密码**、**确认密码**。
4. 点 **保存**。

新密码的规则由平台配置，**以密码框下方的提示为准**（常见的是至少若干位、含大小写字母和数字、含特殊字符）。两次输入不一致时会提示 **密码不一致**。

### 开启多因素认证

1. 在 **账户安全** 的 **密码与认证** 区块找到 **多因素认证**，右侧状态标签是 **未启用**。
2. 点 **设置身份验证器**，把手机验证器 App 上生成的验证码填进去完成绑定。
3. 绑定成功后弹窗会切到 **恢复码** 一屏，给出**多条**恢复码，每条右侧有复制按钮。
4. 逐条复制保存，然后点 **已保存恢复码，继续**，这一步才算走完。
5. 完成后状态标签变成 **已启用**，按钮变成 **更换身份验证器**。之后每次登录除了密码还要填 App 上生成的验证码。

:::warning 恢复码只在这一屏出现
手机丢了、验证器 App 用不了时，**恢复码是唯一的备用登录方式**。关掉这个弹窗后不会再显示同一批恢复码，请当场逐条复制到安全的地方。
:::

:::warning 换手机前先重新绑定身份验证器
验证器 App 跟着手机走。换机或卸载 App 前，先在 **账户安全** 里点 **更换身份验证器**，在新手机上重新扫码、填入新手机上生成的验证码即完成迁移；否则旧手机一丢就可能登不进来。
:::

## 管理访问密钥

**访问密钥** 页签里有两块：**API Key** 和 **SSH 密钥**。

### API Key

平台一个账号只保留**一个** API Key。

1. 进入 **访问密钥**，找到 **API Key** 区块（说明是「用于通过 API 访问服务」）。
2. 点 **生成**，确认后得到一对 Access Key 和 Secret Key。
3. 已经有密钥时按钮变成 **重新生成**：它会**立即替换**现有密钥，旧密钥随即失效。

:::warning Secret Key 只显示一次
生成时给出的 Secret Key **只出现这一次**。看到后立刻复制保存；关掉弹窗就再也看不到，只能重新生成。
:::

### SSH 密钥

1. 在 **SSH 密钥** 区块点 **添加 SSH 密钥**。
2. 填一个能认出这台机器的 **名称**。
3. 粘贴公钥内容：可以从已有密钥里选，也可以直接粘一条完整的单行 OpenSSH 公钥。
4. 点 **添加**。列表里会显示名称和创建时间，点删除可以移除。

:::tip SSH 公钥怎么找
公钥通常保存在本机的 `~/.ssh/id_rsa.pub` 或 `~/.ssh/id_ed25519.pub` 里。用文本编辑器打开、整行复制即可，**不要粘贴私钥**（没有 `.pub` 后缀的那个文件）。
:::

## 换一个组织

1. 点击右上角**头像**。
2. 点击 **切换租户**。
3. 在 **选择您的租户** 页面选中目标组织，点击 **进入平台**。
4. 如果列表里没有你要的组织，点击 **创建租户** 自助创建一个。

## 访问令牌和 API Key 不是一回事

两者都叫「密钥」，但用途完全不同，别拿错：

| 名称 | 在哪里 | 用来干什么 |
| --- | --- | --- |
| 访问令牌 | 魔哈 **首页 → 左侧栏 → 访问令牌** | 命令行上传下载、Git 拉取推送、SDK 认证 |
| API Key | 个人设置 → **访问密钥** | 调用模型推理接口（AI 能力） |

在魔哈里下载、上传模型和数据集，用的是**访问令牌**，见[访问令牌](/moha/quickstart/token)。

## 结果确认

- 改完昵称、邮箱、手机号后，**基本信息** 里立刻显示新值；没绑定过的显示 **未绑定**。保存**不会**弹「更新成功」，弹窗关闭、页面值更新就是成功。
- 如果看到「修改已保存，但当前会话资料刷新失败：…」，说明资料其实已经存好，只是页面上的资料没刷新；点提示里的重试即可，**不要重复提交**。
- 改密码保存成功后，下次登录必须用新密码。
- 多因素认证开启后，**账户安全** 里这一行的状态标签变成 **已启用**。
- SSH 密钥添加成功后出现在列表里，带名称和创建时间。
