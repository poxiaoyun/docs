# 账号设置

魔哈仓库没有独立的账号设置页。账号信息、安全策略与凭据统一由 **IAM 账号中心** 管理，从右上角头像菜单进入。

## IAM 账号中心

| 页面 | 路径 | 说明 |
| --- | --- | --- |
| 通用 | `/iam/account/general` | 个人信息 |
| 修改密码 | `/iam/account/change-password` | 修改登录密码 |
| 修改邮箱 | `/iam/account/change-email` | 绑定/更换邮箱 |
| 修改手机 | `/iam/account/change-mobile` | 绑定/更换手机 |
| 双因素认证 | `/iam/account/mfa` | MFA 设置 |
| API Key | `/iam/account/api-key` | 管理 API Key |
| SSH Key | `/iam/account/ssh-key` | 管理 SSH 公钥 |
| 主题 | `/iam/account/theme` | 界面主题 |

## 租户与组织

- 登录后可切换/选择租户（`/auth/select-tenant`），也可注册租户（`/auth/regist-tenant`）。
- 组织成员与角色在组织的详情页管理，见[组织空间](/moha/home/organizations)。

> ⚠️ 注意: 魔哈侧只提供访问令牌的查看与复制（`/moha/home/token`）；令牌的创建、轮换与吊销请使用 IAM 的 API Key / SSH Key 页面。
