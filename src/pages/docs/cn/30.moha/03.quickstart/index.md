## 快速开始

帮助您快速上手魔哈仓库的核心功能。

## 准备工作

使用魔哈仓库前，请确认：

1. **拥有平台账户** — 联系管理员创建账户或自行注册
2. **选择租户/组织** — 模型、数据集等资源归属于组织，需先选择或创建组织
3. **获取访问令牌** — 用于 Git 操作和 API 调用的身份认证

## 快速上手流程

```mermaid
flowchart LR
    A["登录"] --> B["选择租户/组织"]
    B --> C["获取访问令牌"]
    C --> D["创建仓库并上传文件"]
    D --> E["加载使用或部署 Space"]
```
