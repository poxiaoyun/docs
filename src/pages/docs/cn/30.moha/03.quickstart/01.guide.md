# 快速开始

本文帮助你在较短时间内跑通魔哈仓库的核心流程：登录 → 创建仓库 → 上传文件 → 使用资源 → 部署 Space。

## 前置条件

1. 拥有平台账号并完成登录（`/auth/sign-in`）。
2. 选择或加入一个租户/组织（`/auth/select-tenant`）。
3. 在[访问令牌](/moha/quickstart/token)页面确认可以拿到当前令牌，用于 Git 与 API 认证。

## 第一步：进入魔哈

登录后进入魔哈首页，默认跳转到概览页：

```text
/moha  →  /moha/home/overview
```

首页侧栏包含：概览、我创建的、我的收藏、访问令牌、公告。

## 第二步：创建仓库

| 类型 | 列表页 | 创建后 |
| --- | --- | --- |
| 模型 | `/moha/models` | `/moha/models/:organization/:id/content` |
| 数据集 | `/moha/datasets` | 同上（`type` 为 `datasets`） |
| 镜像 | `/moha/images` | `/moha/images/:organization/:id/tags` |
| Space | `/moha/spaces` | `/moha/spaces/:organization/:id/content` |

创建表单需要选择 `organization`，并填写 `name`（`^[a-zA-Z0-9][a-zA-Z0-9._-]*$`）与 `alias`；`visibility` 默认为 `private`，在组织上下文创建时强制为 `internal`。

详细字段见[数据集的创建](/moha/datasets/create)与[模型的上传](/moha/models/upload)。

## 第三步：上传文件

以模型为例，进入仓库详情 → **文件** 标签：

```bash
# Git 方式（仓库地址格式：/moha/<type>/<organization>/<repository>.git）
git lfs install
git clone https://moha.your-domain/moha/models/ai-lab/my-model.git
cd my-model
cp /path/to/weights/* .
git add . && git commit -m "上传模型权重" && git push origin main
```

也可使用 SDK：

```bash
pip install moha-hub
moha download --repo-type models ai-lab/my-model
```

## 第四步：使用资源

魔哈提供 HuggingFace 兼容端点，配置后可直接用 Transformers / Datasets 加载：

```bash
export HF_ENDPOINT=https://moha.your-domain/moha/huggingface
export HF_TOKEN=<你的访问令牌>
```

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("ai-lab/my-model", torch_dtype="auto", device_map="auto")
tokenizer = AutoTokenizer.from_pretrained("ai-lab/my-model")
```

更多示例见[与 Transformers & Datasets 集成](/moha/sdk-tutorial/transformers-datasets)。

## 第五步：部署 Space

Space 用于承载可交互应用：

1. 创建 Space 时填写 `spaceMetadata`（`cluster` / `namespace` / `flavorID` / `product` / `gitAddress` 等）。
2. 创建后在仓库详情页点击 **上线** 启动实例。
3. 运行中可 **停止 / 重启 / 查看日志**；设置页修改部署参数后会自动重启。
4. 需要版本快照时使用 **版本冻结**。

> 💡 提示: 判断 Space 是否已部署的依据是 `spaceMetadata.status` 是否为空；为空表示未部署，只显示「上线」。
