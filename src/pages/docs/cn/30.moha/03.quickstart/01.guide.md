# 快速开始

这一页把「第一次用魔哈」的完整动作从头到尾排好队：打开站点、注册账号、登录、选中组织、复制访问令牌，最后在你自己的电脑上把第一个模型下载下来。

请从头到尾按顺序做，中间不要跳步。每一步都写了「点哪里、填什么、会看到什么」，看到提示就算这一步成功。

:::tip 做完你会得到什么
一个能用的魔哈账号、一把访问令牌，以及一个已经下载到本地的模型文件夹。之后无论下载还是上传，用的都是这套账号和令牌。
:::

## 开始之前

- 准备一个能收邮件的邮箱，注册时要收验证码。
- 电脑上装好 Python 3.10 或更高版本，第 5 步要用。可以打开命令行输入 `python --version` 确认，能显示 `Python 3.10` 以上就可以。
- 如果管理员关闭了自助注册，注册入口会看不到，这时请联系管理员帮你开通账号，再从第 3 步继续。

## 第 1 步：打开站点

在浏览器里输入管理员给你的平台地址（通常形如 `https://<平台地址>`），回车。

看到登录页面，说明站点是通的。

## 第 2 步：注册一个账号

如果已经有了账号，直接跳到第 3 步。

1. 在登录页下方找到 **没有账户？现在就注册**，点击 **现在就注册**。
2. 填写注册表单：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 用户名 | 例如 `zhangsan` | 登录时要用，注册后建议不要改 |
   | 密码 | 你自己设定的密码 | 记牢，后面登录要用 |
   | 邮箱 | 你常用的邮箱 | 用来接收验证码 |
   | 手机号码 | 你的手机号 | 选好国家/地区后再填 |
   | 验证码 | 去邮箱里找刚收到的数字码，填进来 | 收不到就检查垃圾邮件 |
   | 我已阅读并同意《服务条款》与《隐私政策》 | 勾选 | 不勾选，下面的按钮点不动 |

3. 点击 **注册账户**。
4. 注册成功后会自动跳回登录页，提示你去登录。

## 第 3 步：登录并选中你的组织

1. 在登录页填写 **用户名/邮箱/手机号** 和 **密码**，勾选协议，点击 **登录**。
2. 如果页面弹出图形验证码或滑块，按提示输入数字或拖动滑块，再点 **验证并登录**。
3. 登录后进入 **选择您的租户** 页面：
   - 如果列表里有你所属的组织，选中它，点击 **进入平台**。
   - 如果列表是空的，点击 **创建租户**，按提示为自己创建一个组织，再回到这一步进入。
4. 进入平台后，你会看到平台首页。
5. 打开魔哈：在页面左上角找到产品名称，点它右侧的下拉箭头，弹出 **产品与服务** 菜单，选择 **魔哈**。
   - 如果找不到这个入口，直接在浏览器地址栏把地址换成管理员给你的魔哈地址。

进入魔哈后，顶部导航会显示 **首页**、**模型库**、**数据集**、**镜像仓库**、**空间**。

:::info 组织是什么
「组织」就是这里的「租户」，可以理解成一个团队空间：你的模型、数据集都放在某个组织里，同一个组织的同事默认能看到彼此的东西。
:::

## 第 4 步：复制访问令牌

令牌是命令行替你「刷身份」用的通行证，不用自己申请，登录后就已经有了。

1. 顶部导航点击 **首页**。
2. 在左侧菜单点击 **访问令牌**。
3. 页面上会显示一串令牌，点击它右侧的复制图标，令牌就进了剪贴板。
4. 先粘贴到一个安全的地方（例如密码管理器），下一步要用。

:::warning 令牌等于你的身份
拿到令牌的人就能以你的名义操作。不要把它贴到聊天群、公开代码或截图里。
:::

## 第 5 步：在电脑上安装命令行工具

打开命令行窗口（Windows 用 PowerShell，macOS 用「终端」），执行：

```bash
pip install moha-hub
```

安装完成后输入下面这条命令，能打印出一行版本号就算装好了：

```bash
moha --version
```

## 第 6 步：让命令行认识你的账号

把上一步的令牌交给命令行，并把平台地址一起告诉它：

```bash
moha login https://<平台地址> --token <你的访问令牌>
```

- `<平台地址>` 换成第 1 步你在浏览器里打开的那个地址，**必须带 `https://`**。
- `<你的访问令牌>` 换成第 4 步复制的令牌。

执行成功后会打印一张表，形如：

```text
Token saved
Current Organization  <你的组织名>
Endpoint              https://<平台地址>
Config File           ~/.moha/config.json
```

看到 **Token saved** 就说明命令行已经认识你了。可以用下面这条命令再次确认：

```bash
moha whoami
```

显示登录状态为 `Logged in` 即可。

## 第 7 步：下载第一个模型

1. 回到浏览器，在魔哈顶部导航点击 **模型库**。
2. 随便点开一个模型，在页面上找到它的「组织 / 名称」，例如 `ai-lab/qwen2-7b`。
3. 回到命令行，执行下载命令（把 `ai-lab/qwen2-7b` 换成你要下载的模型）：

```bash
moha download ai-lab/qwen2-7b
```

4. 稍等片刻，命令行会打印下载进度，结束后给出一张表：

```text
Download completed
Local Path  <模型在本地的文件夹路径>
```

## 结果确认

- 命令行最后出现了 **Download completed** 和一行 **Local Path**。
- 按那个路径打开文件夹，能看到模型文件（例如 `config.json` 和权重文件）。
- 用 `moha whoami` 看到的用户名和组织，和你浏览器里登录的一致。

这三条都对，说明整条链路已经跑通。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 注册表单提交没反应 | 没勾选协议，或验证码填错 | 勾选协议，重新去邮箱取验证码 |
| 登录页进不去，提示锁定 | 密码连续输错太多次 | 等提示的时间过后重试；忘记密码可点 **忘记密码？** 用邮箱重置 |
| 选租户页面是空的 | 你的账号还没有归属任何组织 | 点 **创建租户** 自助创建一个，或找管理员把你加进组织 |
| `moha login` 报错说地址无效 | 地址没带 `https://` | 补上 `https://` 再执行 |
| 下载提示没有权限 | 这是私有或租户内模型 | 确认令牌有效、且你属于该组织；必要时换一个公开模型试 |
| 找不到魔哈入口 | 产品菜单里没有 | 直接使用管理员给你的魔哈地址 |
