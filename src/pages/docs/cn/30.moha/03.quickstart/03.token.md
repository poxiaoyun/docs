# 访问令牌

访问令牌用于 Git 操作与 API 调用的身份认证。

## 获取令牌

魔哈本身**不提供令牌的创建/删除界面**。令牌页面只做一件事：展示当前登录会话对应的有效令牌，并提供复制。

进入路径：

```text
/moha/home/token
```

| 元素 | 说明 |
| --- | --- |
| 令牌值 | 当前登录态对应的认证令牌 |
| 复制按钮 | 一键复制到剪贴板 |

> ⚠️ 注意: 令牌与当前登录会话关联，属于敏感凭据，请勿在公开代码或文档中泄露。

## 更细粒度的凭据管理

如果需要管理多把 API Key、SSH Key 或双因素认证，请使用 IAM 的账号安全设置：

| 能力 | 路径 |
| --- | --- |
| 账号信息 | `/iam/account/general` |
| 修改密码 | `/iam/account/change-password` |
| API Key | `/iam/account/api-key` |
| SSH Key | `/iam/account/ssh-key` |
| 双因素认证 | `/iam/account/mfa` |

## 在 Git 中使用令牌

```bash
# 方式 1：在 URL 中携带用户名与令牌
git clone https://<用户名>:<令牌>@moha.your-domain/moha/models/my-org/my-model.git

# 方式 2：配置凭据缓存
git config --global credential.helper 'cache --timeout=3600'
```

> ⚠️ 注意: `credential.helper store` 会把令牌明文写入磁盘，共享环境中不建议使用。

## 在 API 中使用令牌

```bash
curl -H "Authorization: Bearer <令牌>" \
  https://moha.your-domain/api/moha/organizations/my-org/models/my-model
```

> ⚠️ 注意: 文档中接口路径以仓库 resolve 接口为准（`/api/moha/organizations/<organization>/<type>/<repository>/...`）；具体可用接口以后端契约为准，此处未逐一确认。

## 在 SDK 中使用令牌

```bash
pip install moha-hub
```

```python
from xiaoshiai_hub import snapshot_download

snapshot_download(
    repo_id="my-org/my-model",
    repo_type="models",
    username="your-username",
    password="<令牌>",
)
```
