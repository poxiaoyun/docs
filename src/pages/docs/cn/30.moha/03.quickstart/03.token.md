# 访问令牌

**访问令牌**是一串很长的字符，作用是**代替密码**证明「你是你」。命令行、Git、SDK 都没法用浏览器里的登录状态，所以它们靠令牌来上班。

:::tip 令牌像什么
可以把它想成一张**门禁卡**：你本人（浏览器登录）原本就能进出，但机器（命令行）没有手，只能刷卡。卡丢了要立刻挂失，别人捡到就能进你家仓库。
:::

## 开始之前

- 你已经登录，并且能进入魔哈。

## 找到并复制令牌

1. 顶部导航点击 **首页**。
2. 在左侧菜单点击 **访问令牌**。
3. 页面上会显示当前令牌，点击右侧的复制图标即可复制。
4. 粘贴到安全的地方保存，例如密码管理器。

魔哈里只展示**当前登录这一把**令牌，不提供新建多把、按用途分权限的界面，也就是说：复制出来的就是你现在这把。

## 为什么命令行下载私有仓库必须用令牌

- **公开**仓库谁都能拉，不需要身份。
- **租户内**和**私有**仓库只有你或你的组织成员能拉，命令行必须出示令牌才能证明你有资格。

如果不用令牌去拉私有仓库，命令行会直接报「没有权限」或要求输入密码——这时**密码就填令牌**。

## 令牌的权限范围

令牌没有可以勾选的权限范围，它**完整继承你账号的权限**：

| 令牌能做到 | 说明 |
| --- | --- |
| 下载你能访问的仓库 | 公开、租户内、私有，取决于你账号能看到哪些 |
| 上传到你有写权限的仓库 | 和你登录后手动上传的范围一致 |
| 调用魔哈相关接口 | 供命令行和 SDK 使用 |

| 令牌做不到 | 说明 |
| --- | --- |
| 越权访问 | 你账号本来无权看的私有仓库，令牌也看不了 |
| 长期有效 | 登出或会话失效后，旧令牌立即作废 |

:::warning 令牌没有「只看不改」这种选项
因为它和你的账号权限完全一致，所以不能靠缩小范围来降风险。唯一的办法就是**保管好**：不要提交进代码仓库，不要贴进聊天群，不要发在截图里。
:::

## 在命令行里用令牌

安装命令行工具后登录一次，令牌会保存在本机配置文件里，之后都不用再输入：

```bash
pip install moha-hub
moha login https://<平台地址> --token <你的访问令牌>
```

登录成功后执行 `moha whoami` 能看到登录状态。也可以不改配置文件，用环境变量临时传入：

```bash
export MOHA_TOKEN="<你的访问令牌>"
```

## 在 Git 里用令牌

下载私有仓库时，Git 会问用户名和密码，密码处填令牌。也可以直接写进地址：

```bash
git clone https://<用户名>:<访问令牌>@<平台地址>/moha/<组织>/models/<仓库名>.git
```

为了少输几次，可以临时缓存凭据：

```bash
git config --global credential.helper 'cache --timeout=3600'
```

:::warning 不要用 store 保存
`credential.helper store` 会把令牌明文写进磁盘文件，共享电脑或服务器上非常危险。优先用 `cache`，或者干脆手动输入。
:::

## 在 SDK 里用令牌

```python
from xiaoshiai_hub import snapshot_download

repo_path = snapshot_download(
    repo_id="ai-lab/qwen2-7b",
    repo_type="models",
    token="<你的访问令牌>",
)
print(repo_path)
```

## 令牌丢了或泄漏了怎么办

1. **立刻登出**：点击右上角头像，在面板底部点击 **登出**。旧令牌随即失效。
2. **重新登录**：用账号密码重新登录，再到访问令牌页复制一把新的。
3. **检查动静**：如果你把令牌贴到过公开的地方，顺手确认一下自己的仓库有没有被改动过（看仓库的提交记录）。
4. **换密码**：如果不确定令牌是怎么泄漏的，顺手在个人设置里改一次密码，见[账号设置](/moha/quickstart/account)。
