# 模型的上传

模型仓库创建后，文件通过仓库详情页的 **文件** 标签管理。文件页提供 Web 上传入口，同时提供 Git / SDK 两种命令行方式获取仓库地址；模型页的 **使用方式** 弹窗则给出加载与推理示例。

## 三种上传/获取方式

| 方式 | 入口 | 适用场景 |
| --- | --- | --- |
| Web 上传 | 文件页 → 上传文件 | 少量文件、单文件快速提交 |
| Git 推送 | 文件页 → 下载/上传弹窗 → Git 标签 | 大文件、批量文件、需要保留 Git 历史 |
| SDK | 文件页 → 下载/上传弹窗 → SDK 标签 | 脚本化上传/下载（`moha-hub`） |

## Web 上传

1. 进入模型仓库详情页，切换到 **文件** 标签。
2. 点击 **上传文件**，选择本地文件或整个目录。
3. 上传以一个「上传会话」为单位执行，提交后生成一次 Commit。

上传会话由服务端下发能力开关（`uploadFiles`、`uploadFolder`、`createFile`、`createDirectory`、`editFile`、`deleteFile` 等），只有 `canWrite` 为真时才能写入；单个仓库可能只开放其中一部分操作。

> ⚠️ 注意: 前端自身有硬性兜底上限——单次最多 100 个文件、合计不超过 100 MiB（`BROWSER_UPLOAD_MAX_FILES = 100`、`BROWSER_UPLOAD_MAX_TOTAL_BYTES = 100 * 1024 * 1024`）。在此基础上，服务端还会通过 `limits`（`maxFiles`、`maxTotalBytes`、`maxManifestBytes`、`maxPathBytes`、`maxEditableBytes`）下发更严格的限制，两者取小。文档中此前的「单文件不超过 5GB」在前端代码中查无依据，按未确认处理。

## Git 推送

在文件页点击下载/上传按钮，弹窗的 **Git** 标签会给出当前仓库的克隆命令。仓库地址格式为：

```bash
# 仓库地址：<控制台地址>/moha/<资源类型>/<组织>/<仓库名>.git
git lfs install
git clone https://moha.your-domain/moha/models/ai-lab/my-model.git

# 只拉取指针文件（不下载 LFS 大文件）
GIT_LFS_SKIP_SMUDGE=1 git clone https://moha.your-domain/moha/models/ai-lab/my-model.git
```

随后在本地提交并推送：

```bash
cd my-model
git lfs track "*.safetensors" "*.bin" "*.pt"
cp /path/to/model/* .
git add .
git commit -m "上传模型权重文件"
git push origin main
```

## SDK 上传/下载

弹窗的 **SDK** 标签使用 `moha-hub` 包：

```bash
pip install moha-hub

# 命令行下载
moha download --repo-type models ai-lab/my-model
```

```python
from xiaoshiai_hub import snapshot_download

repo_path = snapshot_download(
    repo_id="ai-lab/my-model",
    repo_type="models",
    username="your-username",
    password="your-password",
)
print(f"Repository downloaded to: {repo_path}")
```

## 使用模型文件

模型详情页提供 **使用方式** 弹窗，按用途给出示例：

| 用途 | 说明 |
| --- | --- |
| Transformers | `pipeline` 与 `AutoModelForCausalLM` 加载示例 |
| vLLM | `pip install vllm` + `vllm serve`，并给出 OpenAI 兼容接口调用示例 |
| SGLang | `pip install "sglang[all]"` + `python -m sglang.launch_server` |

这些示例统一通过 HuggingFace 兼容端点访问魔哈仓库：

```bash
export HF_ENDPOINT=https://moha.your-domain/moha/huggingface
export HF_TOKEN=<你的访问令牌>
```

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("ai-lab/my-model", trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained(
    "ai-lab/my-model",
    torch_dtype="auto",
    device_map="auto",
    trust_remote_code=True,
)
```

> 💡 提示: 常见约定是 `.safetensors` 存储权重；大文件走 Git LFS，避免直接提交到普通 Git 对象。
