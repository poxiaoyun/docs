# 模型的上传

把本地的模型文件传到魔哈的模型仓库。平台提供三种方式，**按文件大小来选**：

| 方式 | 适合什么场景 | 限制 |
| --- | --- | --- |
| 网页上传 | 少量小文件、随手补一个配置文件 | 单次最多 100 个文件，合计不超过 100 MiB |
| Git 命令行 | 大模型、批量文件、想保留每次改动记录 | 大文件必须走 Git LFS |
| SDK 命令 | 脚本化上传，或文件较多较大 | 无明显文件个数限制 |

## 开始之前

- 你需要是仓库的**管理员**或**读写**成员，否则 **文件** 页面里没有上传入口。
- 大文件（超过 5 MB）不要用普通 Git 直接提交，否则推送会被拒绝。请用 Git LFS 或 SDK。
- 用命令行上传前，先在本机装好 Git 和 Git LFS。
- 用 SDK 前，先执行 `pip install "moha-hub[upload]"` 安装，再登录一次。

## 方式一：网页上传

1. 打开模型仓库详情页，点击 **文件** 标签页。
2. 点击右上角 **添加文件**，在下拉菜单里选择：
   - **上传文件**：选择一个或多个文件；
   - **上传文件夹**：选择整个目录，目录结构会一起保留；
   - **新建文件** / **新建文件夹**：直接在网页上建一个小文件或空目录。
3. 在弹出的上传窗口里确认文件清单，填写 **提交信息**（例如 `上传模型权重`），点击提交。
4. 上传完成会提示 **提交成功**，并显示这次提交的编号。

:::warning 网页上传的大小上限

- 一次最多 100 个文件，合计不超过 100 MiB。
- 超出时会提示「请使用 Moha SDK 上传」，此时请改用下面的 SDK 方式。

:::

## 方式二：Git 命令行上传

适合体积较大的模型。先在本地把仓库克隆下来，再提交推送。

1. 打开模型仓库详情页，点击右上角 **下载模型**。
2. 弹窗选 **Git** 标签，复制 **克隆仓库** 的命令，在终端执行：

```bash
git lfs install
git clone <仓库地址>
cd <仓库名>
```

3. 把模型文件放进这个目录，并告诉 Git LFS 哪些大文件归它管：

```bash
# 让 LFS 接管常见的模型权重文件
git lfs track "*.safetensors" "*.bin" "*.pt"

# 把本地模型文件复制进来
cp /path/to/model/* .

git add .
git commit -m "上传模型权重文件"
git push origin main
```

推送成功后回到网页刷新，文件就会出现在 **文件** 列表里。

:::tip 为什么大文件要走 LFS
普通 Git 对超过 5 MB 的新文件会直接拒绝推送，并提示改用 Git LFS 或 Moha SDK。
`git lfs track` 只是「登记」哪些文件走 LFS，务必在 `git add` 之前执行，登记结果会保存到仓库的 `.gitattributes`。
:::

## 方式三：SDK 命令行上传

适合脚本化上传，没有网页那种文件个数限制。

```bash
pip install "moha-hub[upload]"
moha login https://<平台地址> --token <访问令牌>
```

上传整个文件夹，或只传单个文件：

```bash
# 上传文件夹（目录结构会保留）
moha upload ai-lab/my-model ./my_model

# 上传单个文件，并指定它在仓库里的路径
moha upload ai-lab/my-model ./config.yaml configs/config.yaml
```

也可以加上提交信息、目标分支和忽略规则：

```bash
moha upload ai-lab/my-model ./my_model \
  --message "上传模型权重" \
  --revision main \
  --exclude "*.log"
```

在 Python 代码里上传：

```python
from xiaoshiai_hub import upload_folder, upload_file

# 上传整个文件夹
upload_folder(
    folder_path="./my_model",
    repo_id="ai-lab/my-model",
    repo_type="models",
    commit_message="上传模型权重",
    ignore_patterns=["*.log", ".git*"],
    token="<访问令牌>",
)

# 上传单个文件
upload_file(
    path_file="./config.yaml",
    path_in_repo="config.yaml",
    repo_id="ai-lab/my-model",
    repo_type="models",
    commit_message="补充配置文件",
    token="<访问令牌>",
)
```

## 上传后怎么用这个模型

回到模型详情页，点击右上角 **使用模型**，按用途选择示例：

| 用途 | 说明 |
| --- | --- |
| Transformers | 用 `pipeline` 或 `from_pretrained` 加载模型 |
| vLLM | 启动兼容 OpenAI 接口的推理服务 |
| SGLang | 用 SGLang 启动模型服务 |

这些示例都通过魔哈的 HuggingFace 兼容接口访问，先在环境变量里配置：

```bash
export HF_ENDPOINT=https://<平台地址>/moha/huggingface
export HF_TOKEN=<访问令牌>
```

再按示例加载：

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("ai-lab/my-model")
model = AutoModelForCausalLM.from_pretrained(
    "ai-lab/my-model",
    torch_dtype="auto",
    device_map="auto",
)
```

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 提示文件数量超过 100 个 | 网页上传有条数上限 | 改用 SDK 上传 |
| 提示文件总量超过 100MB | 网页上传有容量上限 | 改用 SDK 上传 |
| 推送被拒绝，提示超过大小限制 | 大文件没走 Git LFS | 先 `git lfs track`，重新提交 |
| 看不到 **添加文件** 按钮 | 你对该仓库没有写权限 | 找仓库管理员给你 **读写** 权限 |
| 上传后模型文件只有几 KB | 大文件被当成指针对待 | 确认已安装并启用 Git LFS，重新上传 |
