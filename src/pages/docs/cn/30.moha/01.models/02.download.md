# 模型的下载

从魔哈仓库把模型文件下载到本地。文件页的 **下载/上传** 弹窗会给出 Git 与 SDK 两种命令。

## Web 界面下载

1. 进入模型详情页 → **文件** 标签页。
2. 浏览文件树定位目标文件。
3. 点击文件右侧的下载按钮，或进入文件详情下载。

> 💡 提示: Web 下载适合单文件或小体积模型；大型模型建议用 Git 克隆。

## Git 克隆

仓库地址格式为 `<控制台地址>/moha/<资源类型>/<组织>/<仓库名>.git`：

```bash
git lfs install
git clone https://moha.your-domain/moha/models/ai-lab/qwen2-7b.git
```

只拉取指针文件（不下载 LFS 大文件）：

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone https://moha.your-domain/moha/models/ai-lab/qwen2-7b.git
```

## SDK 下载

```bash
pip install moha-hub
moha download --repo-type models ai-lab/qwen2-7b
```

```python
from xiaoshiai_hub import snapshot_download

repo_path = snapshot_download(
    repo_id="ai-lab/qwen2-7b",
    repo_type="models",
    username="your-username",
    password="<访问令牌>",
)
```

## 下载指定版本

克隆后切换到目标分支，或直接指定冻结对应的提交：

```bash
git checkout v1.0
```

## 认证配置

下载私有模型需要认证。令牌获取方式见[访问令牌](/moha/quickstart/token)：

```bash
git clone https://<用户名>:<访问令牌>@moha.your-domain/moha/models/ai-lab/my-private-model.git
```

> ⚠️ 注意: 请妥善保管访问令牌，不要在公开代码或文档中泄露。

## 选择性下载 LFS 文件

```bash
git lfs pull --include="*.safetensors"
```
