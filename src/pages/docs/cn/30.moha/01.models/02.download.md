# 模型的下载

把魔哈上的模型拿到本地。平台提供三种方式，**按文件大小和用途来选**：

| 方式 | 适合什么场景 | 需要装什么 |
| --- | --- | --- |
| 网页直接下载 | 只拿一两个小文件（如配置文件、说明） | 什么都不用装 |
| Git 命令行 | 整个仓库、几十 GB 的大模型、想保留版本历史 | Git 和 Git LFS |
| SDK 命令 | 写脚本批量拉取，或在 Python 代码里直接加载 | Python 和 moha-hub |

## 开始之前

- 下载**公开**模型不需要登录；下载**私有**或租户内模型需要一个**访问令牌**，见[访问令牌](/moha/quickstart/token)。
- 用命令行下载前，先在本机装好 Git 和 Git LFS。
- 用 SDK 前，先执行 `pip install moha-hub` 安装，再登录一次。

![模型详情页：右上角是「下载模型 / 部署 / 使用模型」三个按钮，左侧是模型卡片正文，右侧是评分、下载次数与模型系谱](/assets/screenshots/moha/repo-model-content-01.png)

网页下载就是点右上角的 **下载模型**。如果只想拿其中几个文件，更快的做法是进 **文件** 页逐个下载，见本节后面的「只下载部分大文件」。

## 方式一：网页直接下载

适合小文件。大模型在网页下载容易中断，建议用下面的 Git 方式。

1. 打开模型仓库详情页，点击 **文件** 标签页。
2. 在文件列表里找到目标文件，点击该行右侧的下载图标（悬停会显示 **下载文件**）。
3. 浏览器会把文件保存到默认下载目录。

## 方式二：Git 命令行下载

适合下载整个模型。命令不用自己拼——在页面上直接复制即可。

1. 打开模型仓库详情页，点击右上角 **下载模型**。
2. 弹窗里选 **Git** 标签，按顺序复制这几条命令执行：

| 命令 | 作用 |
| --- | --- |
| `git lfs install` | 让 Git LFS 在你的电脑上生效，只需执行一次 |
| `git clone <仓库地址>` | 把整个模型仓库克隆到本地，大文件由 Git LFS 自动下载 |
| `GIT_LFS_SKIP_SMUDGE=1 git clone <仓库地址>` | 只下载文件名和指针，不下载大文件（想先看看目录结构时用） |

仓库地址格式为 `https://<平台地址>/moha/<组织>/<资源类型>/<仓库名>.git`，例如 `https://<平台地址>/moha/ai-lab/models/qwen2-7b.git`。

:::tip 为什么必须装 Git LFS
普通 Git 不擅长传几个 G 的大文件，会让仓库变得又慢又臃肿。Git LFS 是 Git 的扩展，专门负责搬运这类大文件。
没有它，克隆下来的模型文件可能只是一个小小的「指针」，不是真正的权重。
:::

下载私有模型时，Git 会提示输入用户名和密码，**密码填你的访问令牌**。也可以直接把令牌写进地址：

```bash
git clone https://<用户名>:<访问令牌>@<平台地址>/moha/<组织>/models/<仓库名>.git
```

## 方式三：SDK 命令下载

适合批量或写进脚本。先安装并登录：

```bash
pip install moha-hub
moha login https://<平台地址> --token <访问令牌>
```

然后下载整个仓库：

```bash
moha download --repo-type models ai-lab/qwen2-7b
```

也可以直接指定保存目录，或只下载某几个文件：

```bash
moha download ai-lab/qwen2-7b --local-dir ./my-model
moha download ai-lab/qwen2-7b config.json tokenizer.json
```

在 Python 代码里下载：

```python
from xiaoshiai_hub import snapshot_download

# 下载整个仓库，返回本地目录路径
repo_path = snapshot_download(
    repo_id="ai-lab/qwen2-7b",
    repo_type="models",
    token="<访问令牌>",

    # 可选：只下载匹配的文件，忽略日志等杂项
    allow_patterns=["*.safetensors", "*.json"],
    ignore_patterns=[".git*", "*.log"],
)
print(repo_path)
```

## 下载指定版本

模型仓库用**分支**和**快照**区分版本。

- 网页/命令行：先按上面的方式克隆仓库，再切到目标分支：

```bash
git checkout v1.0
```

- SDK：加上 `--revision` 参数指定分支、标签或提交：

```bash
moha download ai-lab/qwen2-7b --revision v1.0
```

## 只下载部分大文件

先跳过 LFS 大文件克隆下来，再按需拉取某几类文件，能省不少时间和流量：

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone <仓库地址>
cd qwen2-7b
git lfs pull --include="*.safetensors"
```

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 克隆下来的模型文件只有几 KB | 没装 Git LFS，只拿到了指针文件 | 安装 Git LFS 后执行 `git lfs install`，重新克隆 |
| 提示没有权限 | 下载的是私有 / 租户内模型 | 配置访问令牌后重试 |
| 克隆到一半失败 | 网络中断 | 进入已克隆的目录，执行 `git lfs pull` 续传 |
