# 模型版本

模型会不断改进：换个权重、补个配置、修个说明。魔哈用两个东西帮你管理这些变化——**分支**和**快照**。

| 名词 | 通俗解释 |
| --- | --- |
| 分支 | 仓库的一条时间线，默认在 `main` 上；想试验新改动就开一条新分支 |
| 快照 | 给当前状态拍一张照片存档，以后随时能回到这个状态 |
| 回滚 | 把某条分支恢复到某张快照对应的状态 |

:::tip 快照就是「存档点」
玩游戏时你会手动存一个档，之后打输了大不了读回来。快照就是这个存档点：
做一次快照，等于把当时的所有文件固定下来；后面改坏了，一键回滚就能回到那一刻。
:::

## 怎么切换版本

模型仓库没有独立的「版本」标签页，版本切换在 **文件** 标签页左上角：

1. 打开模型仓库，点击 **文件** 标签页。
2. 点击左上角的 **分支：main** 按钮，展开下拉菜单。
3. 菜单分两组：
   - **分支**：列出仓库的所有分支，选中后文件列表按该分支显示；
   - **快照**：列出所有快照，选中后文件列表显示该快照对应的状态。

选中的版本会显示在按钮上，文件列表和预览内容都会跟着变。

## 怎么产生一个新版本

版本本质上是新的提交或新的分支。改动在本地做完再推送上来：

```bash
cd my-model

# 基于当前分支开一条新分支（想直接在 main 上改就跳过这句）
git checkout -b feature/v2

# 改动文件后提交并推送
git add .
git commit -m "更新模型权重"
git push origin feature/v2
```

也可以用 SDK 建分支：

```bash
moha branch-create ai-lab/my-model v2 --from main
```

## 怎么拍快照

需要把一个稳定版本固定下来时，做一次快照。入口在 **提交记录** 里，不在 **快照** 页——因为快照必须挂到某一个具体提交上。

1. 打开模型仓库，点击 **文件** 标签页。
2. 右上角点击 **提交记录**，进入提交时间线。（按钮上会显示提交次数。）
3. 找到要固定的那个提交，点它右侧的 **冻结**。
4. 填写：
   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 标题 | 例如 `v1.0.0` | 最多 32 个字符，用版本号最直观 |
   | 原因 | 例如 `首个正式发布版本` | 可留空，写清楚方便日后查找 |
5. 点击 **确认**，页面提示 **快照已创建**。

建好的快照会在 **快照** 标签页里列出来，每张显示 **标题**、**分支**、**提交信息**、**创建者**、**创建于**；在 **文件** 页左上角的 **分支:xxx** 下拉里也能选到。

> 建议用语义化版本号命名，例如 `v1.0.0`、`v1.1.0`，一眼能看出是修 bug 还是加了新功能。

## 查看差异、回滚、删除

在 **快照** 标签页，每条记录右侧有三个操作：

| 操作 | 作用 |
| --- | --- |
| **差异** | 对比这张快照和当前状态的文件变化，逐个文件看增减 |
| **回滚** | 把快照所在分支重置到这张快照对应的状态 |
| **删除快照** | 删掉这条快照记录 |

:::warning 回滚和删除都不可逆

- **回滚**：会把目标分支重置到快照对应的提交，**提交历史可能被改写**。回滚前请确认没有别人正在基于这条分支工作。
- **删除快照**：删除后无法恢复，请先确认没有其他地方正在引用这张快照。

:::

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 下拉里看不到某条分支 | 那是平台内部使用的分支 | 这类分支只会以「快照」的形式出现在列表里 |
| 差异看不全 | 差异内容过大 | 请在本地用 Git 对比具体文件 |
| 推送到冻结相关的引用被拒绝 | 快照引用受保护 | 快照只能在页面上管理，不能直接推送覆盖 |
