# 模型版本

魔哈仓库的版本能力基于 Git 分支与提交实现，入口分散在**文件**页和**冻结**页，不存在独立的「版本」标签页。

## 仓库详情页的真实标签

模型、数据集仓库（非镜像）的标签页固定为：

| 标签 | `value` | 说明 |
| --- | --- | --- |
| 模型卡片 / 数据集卡片 | `content` | README、评分、推荐、血缘、相关资源、硬件需求 |
| 文件 | `file` | 文件树、文件预览、提交记录、分支切换 |
| 版本冻结 | `freezes` | 冻结记录列表（创建 / 对比 / 回滚 / 删除） |
| 讨论 | `discussion` | 讨论与回复 |
| 设置 | `setting` | 仅对系统管理员、Owner、组织管理员或仓库 admin/readwrite 可见 |

镜像仓库的标签为 `content`、`tags`、`setting`（没有文件与冻结标签）。

> ⚠️ 注意: 此前文档中的「切换到版本标签页、顶部版本下拉框」与实现不符，已按实际改写。

## 查看与切换版本

1. 进入模型仓库详情页，切换到 **文件** 标签。
2. 点击页面顶部的 **分支（branch）** 选择器。
3. 在下拉中，`branch` 分组列出所有分支；若存在冻结记录，会额外出现 `freeze` 分组。

选择分支后，`reference` 变为该分支名，文件树按该分支渲染；选择某个冻结项时，`reference` 变为该冻结对应的 Commit。

> 💡 提示: 内部用于冻结的分支（`freezes/*`）不会出现在 `branch` 分组里，只会以冻结项的形式展示。

## 创建新版本

版本本质上是新的提交或分支，操作在本地完成后推送：

```bash
cd my-model
git checkout -b feature/new-version
git add .
git commit -m "更新模型权重"
git push origin feature/new-version
```

需要给稳定版本做一个不可变快照时，使用**版本冻结**（见 [版本冻结](/moha/repository/freezes)）：冻结会锁定某个分支/Commit，并支持对比与回滚。

> 💡 提示: 建议用语义化版本号（如 `v1.0.0`）命名分支或冻结标题，便于识别不兼容变更与修复版本。
