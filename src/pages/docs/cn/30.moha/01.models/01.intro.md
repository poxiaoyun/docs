# 模型广场介绍

模型广场即模型列表页，集中展示平台上可见的模型资源，帮助您快速发现和选择模型。

## 进入路径

魔哈顶部导航 -> **模型**，路由 `/moha/models`。

## 列表能力

| 能力 | 说明 |
| --- | --- |
| 关键字搜索 | 按名称/关键字搜索 |
| 元数据筛选 | 按任务类型、框架、许可证、语言等元数据组合过滤，选中项以 Chip 形式展示并可清除 |
| 排序 | `''`（综合）、`downloads`（下载量）、`likes`（点赞）、`rating`（评分） |
| 可见性 | 在 `public` / `private` / `internal` 之间切换，默认 `public` |
| 分页 | 默认每页 `size=16` |

> 💡 提示: 列表以卡片网格展示（默认窄屏 1 列、中屏 2 列），没有独立的表格视图。

## 模型卡片

| 信息 | 说明 |
| --- | --- |
| 名称 | 组织/模型名，如 `ai-lab/qwen2-7b` |
| 可见性 | `public` / `internal` / `private` |
| 描述 | 模型简要说明 |
| 标签 | 任务类型、框架、语言等元数据 |
| 下载量 | 历史下载总次数 |
| 收藏数 | 被收藏的次数 |

## 收藏模型

在卡片或详情页点击收藏（Star），资源会加入个人收藏，可在[我的收藏](/moha/home/liked-by-me)中按类型查看。
