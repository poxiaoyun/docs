# 模型库介绍

模型库就是**模型列表页**，把你在这个平台上能看到的所有模型摆在一起。想找某个模型、或者想看看别人都上传了什么，从这里开始。

## 进入路径

顶部导航点击 **模型库**。

## 找模型：搜索、筛选、排序

页面顶部有一个搜索框，左侧是一列筛选条件，右上角可以切换排序方式。

| 我想…… | 怎么操作 |
| --- | --- |
| 按名字找 | 在顶部搜索框输入模型名，回车；也可以用 `组织/模型名` 的形式精确定位 |
| 按条件缩小范围 | 点搜索框右侧的 **高级搜索**，勾选任务、框架、许可证等条件后点 **应用筛选** |
| 按分类看 | 左侧点 **分类**（如文本生成、图像分类） |
| 按框架看 | 左侧点 **框架**（如 PyTorch、Transformers） |
| 按许可证看 | 左侧点 **许可证**（如 apache-2.0） |
| 按标签看 | 左侧点 **标签**（自定义标签） |
| 按上传方看 | 左侧点 **组织** |
| 换排序方式 | 点右上角 **排序：综合排序**，在弹出的菜单里选 |

排序菜单里有四项：

| 选项 | 含义 |
| --- | --- |
| 综合排序 | 平台默认的推荐顺序 |
| 下载次数 | 下载最多的排前面 |
| 喜欢数量 | 被收藏最多的排前面 |
| 用户评分 | 评分最高的排前面 |

选过的筛选条件会以标签形式显示在列表上方，点标签上的叉号可以单独去掉，点 **清空** 一次去掉全部。

> 搜索结果按卡片展示，每页 16 个，用列表下方的 **上一页** / **下一页** 翻页。

## 卡片上有什么

每个模型是一张卡片，把鼠标移上去能看到更多信息：

| 卡片上的信息 | 含义 |
| --- | --- |
| 名称 | 模型名；后面可能跟小图标：下载量高是火苗、平台推荐是点赞、加密模型是锁 |
| 描述 | 一句话说明这个模型能干什么 |
| 标签 | 任务分类、框架、语言等；放不下会折叠，点开看全部 |
| 卡片底部一行 | 组织、更新时间、下载次数、收藏数，鼠标悬停能看到每项的含义 |

## 收藏一个模型

列表卡片上的爱心只是展示「有多少人收藏」，不能点。要收藏，进模型详情页，点标题右侧的 **爱心按钮**（按钮上就是当前收藏数），模型就进了你的收藏列表，之后在首页左侧的 **我喜欢的** 里能找到。再点一次取消收藏。
