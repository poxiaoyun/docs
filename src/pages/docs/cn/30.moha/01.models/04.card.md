# 模型卡片

模型仓库详情页默认进入 **模型卡片**（`content`）标签。它由 README 正文与右侧信息栏两部分组成，右侧区块随资源类型和元数据动态出现。

## 页面结构

| 区域 | 区块 | 出现条件 |
| --- | --- | --- |
| 左侧（主区） | README 渲染区 | 始终 |
| 右侧（信息栏） | 评分与下载统计 | 非镜像资源 |
| 右侧（信息栏） | Safetensors 信息 | 存在 Safetensors 统计 |
| 右侧（信息栏） | 推荐语 | 存在 `RECOMMEND_COMMENT` 标注 |
| 右侧（信息栏） | 血缘（模型族谱） | 模型资源且存在 `genealogy.parents` 或 `genealogy.children` |
| 右侧（信息栏） | 训练关系 / 被 Space 使用 | 模型或数据集资源 |
| 右侧（信息栏） | 硬件需求 | 模型资源 |

## README 渲染区

仓库根目录的 `README.md` 会作为卡片正文渲染（markdown）。渲染前会把相对路径的图片、视频、附件链接重写为仓库 `resolve` 接口地址，因此 README 里可以直接引用仓库内的资源文件。

镜像仓库若没有 README，会显示空状态提示而不是空白页面。

## 评分与下载统计

| 字段 | 来源标注 key | 说明 |
| --- | --- | --- |
| 用户评分 | `RECOMMEND_RATE_COUNT` | 平均分；已有评分时只读，未评分时可打分 |
| 下载量 | `RECOMMEND_DOWNLOAD_COUNT` | 数字按 `fNumber` 格式化展示 |

## Safetensors 信息

当统计中带有 Safetensors 数据时，会展示：

- `model_size`：模型体积
- `tensor_type`：张量类型
- `chat_template`：仓库根目录存在 `chat_template.jinja` 时出现，点击在右侧抽屉中以 `handlebars` 语法只读查看

Safetensors 统计状态为 `partial` 时会额外标注。

## 推荐语

当元数据中存在 `RECOMMEND_COMMENT` 标注时，右侧出现「推荐」卡片，展示推荐指数（`RECOMMEND_SCORE`）与推荐说明。

## 血缘（模型族谱）

仅模型资源展示。依据 `genealogy` 的 `parents` / `children` 以树形展开父模型与衍生模型，节点可悬浮查看信息。

## 训练关系与被 Space 使用

模型与数据集资源都会出现该区块，内部由两部分组成：

| 组件 | 说明 |
| --- | --- |
| 训练关系（TrainingRelations） | 模型看数据集、数据集看模型，展示用于训练的关联资源 |
| 被 Space 使用（UsedBySpaces） | 展示引用该资源的 Space |

点击后会打开右侧抽屉，抽屉内以 `datasets` / `models` / `spaces` 三个 tab 分类展示完整列表。

## 硬件需求

仅模型资源展示，依据模型元数据渲染运行所需的硬件配置信息。

## 编写模型卡片的建议

- 使用 Markdown 编写 README，结构清晰、可检索。
- 在 README 中补充模型介绍、训练数据与方法、使用示例、评测结果、局限与许可。
- 元数据尽量填全（许可证、任务类型、框架、标签），右侧区块与筛选都依赖它们。

> 💡 提示: 右侧的评分、推荐、血缘、训练关系和硬件需求都由仓库元数据驱动，只有在相应字段存在时才会出现。
