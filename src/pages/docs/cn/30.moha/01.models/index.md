# 模型仓库

模型仓库是魔哈里专门放**模型**的地方。你可以把自己训练的模型传上来，配上介绍，再分享出去；也可以浏览别人上传的模型，一键下载或直接在线调用。

一个模型对应一个**仓库**，仓库里有文件、版本、说明和各种设置。

## 进入路径

顶部导航点击 **模型库**，进入模型库（模型列表页）。

## 我第一次上传模型，该走哪几步

1. 进入首页，左侧点击 **我创建的**，切到 **模型** 分类。
2. 点击右上角 **创建模型**，填好名称和组织，点 **确定**。创建时会自动生成一个空仓库。
3. 进入这个仓库的 **文件** 标签页，把模型文件传上去。文件大就用命令行或 SDK，见[模型的上传](/moha/models/upload)。
4. 在 **模型介绍** 标签页写好 README，让别人看懂这个模型是干什么的，见[模型卡片](/moha/models/card)。
5. 需要固定一个稳定版本时，进 **文件** 标签页点 **提交记录**，在对应的提交上点 **冻结**，见[模型版本](/moha/models/version)。

![模型仓库的文件页：顶部是仓库名、标签与全部页签（模型介绍 / 文件 / 快照 / 交流反馈 / 设置），右上角是下载模型 / 部署 / 使用模型](/assets/screenshots/moha/repo-model-file-01.png)

五个页签里 **模型介绍** 是别人看你的第一眼，**文件** 是真正放文件的地方，**设置** 决定可见性。右上角三个按钮从右到左依次是使用模型、部署、下载模型。

## 仓库里有哪些标签页

打开任意模型仓库，顶部会看到这些标签：

| 标签 | 里面是什么 |
| --- | --- |
| 模型介绍 | 模型的 README 正文和右侧信息栏（评分、下载量、模型系谱等） |
| 文件 | 文件列表、在线预览、提交记录、分支切换，上传也在这里 |
| 快照 | 给某个版本拍下的存档记录，可查看差异、回滚 |
| 交流反馈 | 和其他人讨论这个模型 |
| 设置 | 改可见性、成员、封面等；要有管理权限才看得到（仓库管理员、读写成员、租户管理员等） |

仓库右上角还有三个按钮：

- **下载模型**：弹出下载窗口，给出克隆命令和 SDK 命令。
- **部署**：跳转到智算平台创建推理服务。
- **使用模型**：给出 Transformers、vLLM、SGLang 的加载示例。
