# 模型仓库

模型仓库用于托管、版本化和分发 AI 模型，支持从列表发现资源、上传与下载文件、维护模型卡片，并通过分支与冻结管理版本。

## 进入路径

魔哈顶部导航 -> **模型**，路由 `/moha/models`。

## 本模块内容

| 页面 | 说明 |
| --- | --- |
| [模型广场介绍](/moha/models/intro) | 列表页的搜索、筛选、卡片与收藏 |
| [模型的下载](/moha/models/download) | Web、Git 与 SDK 下载方式 |
| [模型的上传](/moha/models/upload) | 文件页上传、Git 推送与 SDK |
| [模型卡片](/moha/models/card) | 详情页 README 与右侧信息区块 |
| [模型版本](/moha/models/version) | 分支切换与版本冻结 |

## 相关能力

- 创建模型时填写组织、名称、可见性与元数据，可声明基础模型与血缘关系。
- 仓库详情页的标签、文件、讨论与设置统一在[协作](/moha/repository)中说明。
- 模型版本不是独立标签页，而是文件页的分支选择器与「版本冻结」页。
