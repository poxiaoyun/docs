# CI/CD 流程

魔哈的资源本质是 Git 仓库，因此流水线集成围绕 **Git 推送/克隆** 与 **SDK** 展开，而不是专用 CLI。魔哈没有名为 `moha-cli upload` 的命令。

## 前置准备

1. 在 IAM 中创建一把用于 CI 的 API Key / SSH Key（见[账号设置](/moha/quickstart/account)）。
2. 在流水线中把令牌以 Secret 形式注入（例如 `MOHA_TOKEN`）。

## 推送产物（模型 / 数据集 / Space 代码）

```yaml
name: Publish to Moha

on:
  push:
    branches: [main]

jobs:
  publish:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Install Git LFS
        run: git lfs install

      - name: Clone and push artifacts
        env:
          MOHA_TOKEN: ${{ secrets.MOHA_TOKEN }}
        run: |
          git clone https://ci-user:${MOHA_TOKEN}@moha.your-domain/moha/models/my-org/my-model.git target
          cd target
          cp -r ../dist/* .
          git add .
          git commit -m "publish ${GITHUB_SHA}"
          git push origin main
```

> 💡 提示: 若只做校验而不需要下载 LFS 大文件，克隆时设置 `GIT_LFS_SKIP_SMUDGE=1`。

## 拉取资源

```yaml
- name: Install Moha SDK
  run: pip install moha-hub

- name: Download model
  run: moha download --repo-type models my-org/my-model
```

## 触发 Space 重启

Space 部署参数变更后需要在界面确认，但在流水线中可通过接口触发重启：

```bash
curl -X POST -H "Authorization: Bearer ${MOHA_TOKEN}" \
  https://moha.your-domain/api/moha/organizations/my-org/spaces/my-space:restart
```

相关生命周期接口：`:online`（上线）、`:restart`（重启）、`:delete`（删除实例）。运行状态与日志可通过 `.../spaces/{repository}:status`、`.../pods`、`.../pods/{pod}/logs` 查询。

## 使用 HuggingFace 兼容端点

在评测/部署流水线中，可让 Transformers、Datasets 等库直接指向魔哈：

```bash
export HF_ENDPOINT=https://moha.your-domain/moha/huggingface
export HF_TOKEN=${MOHA_TOKEN}
```

> ⚠️ 注意: 上例中的域名与凭据需替换为你的实际控制台地址与令牌；`CI` 中的权限范围由令牌对应的账号决定。
