# 社区贡献

魔哈里没有积分、徽章、论坛这类社区玩法。「贡献」落在很具体的地方：**把有价值的内容公开出来、把说明写清楚、在仓库里和别人协作**。做完这几件事，你的模型、数据集或空间就能被别人搜到、用起来。

## 开始之前
需要一个能创建资源的账号。只要你能创建模型、数据集、镜像或空间，就能按下面的步骤贡献内容。

## 一、把内容公开出去
1. 打开你要公开的资源，进入 **设置** 页签。
2. 在 **可见性** 卡片选择 **公开**。
3. 点 **更新**。

预期效果：这个资源出现在公开列表和搜索结果里，其他账号无需授权即可浏览、下载、引用。

:::warning 公开之前先检查三件事
- README 是否写清了用途、用法和依赖；
- 里面有没有不该公开的数据、密钥或内部信息；
- 许可证是否已填写，别人能不能合法使用。
:::

## 二、把说明写清楚
内容公开只是一半，能不能被别人**找到并看懂**更重要：

| 做什么 | 怎么做 |
| --- | --- |
| 写 README | 在仓库根目录维护 README，它会直接成为介绍页的正文 |
| 补元数据 | 在 **设置** 的 **元数据** 卡片里填许可证、分类、框架、标签、语言等，决定能否被搜到 |
| 传封面 | 空间可以在 **设置** 的 **封面** 卡片上传一张横图，列表里更醒目 |

## 三、和别人协作
| 方式 | 怎么做 |
| --- | --- |
| 加成员 | **设置** → **成员** → **添加成员**，给 **管理员**、**读写** 或 **只读** 角色 |
| 讨论 | 在 **交流反馈** 里发起话题、回复，把问题沉淀下来 |
| 合并请求 | 改完文件后 **创建合并请求**，请人评审、合并 |
| 拍快照 | 发布稳定版本前先拍一张快照，随时能回到这个状态 |
| 回退历史 | 在 **提交记录** 里用 **回滚（保留历史）** 抵消某次提交，或用 **回滚（不保留历史）** 丢弃它之后的提交 |

## 四、收藏、评分与统计
这些是平台里的「反馈信号」，用得越多，好内容越容易浮上来：

| 能力 | 怎么用 |
| --- | --- |
| 收藏 | 资源页右上角的心形按钮，收藏后可在 [我的收藏](/moha/home/liked-by-me) 集中查看 |
| 评分 | 模型、数据集的介绍页里可以打星，页面会显示平均分和参与人数 |
| 下载次数 | 系统自动统计，列表可按下载次数排序 |
| 精选推荐 | 是否登上精选区由平台运营设置，租户端没有自助入口 |

:::tip 想被推荐，先把基础做扎实
把 README 写清楚、元数据补全、格式规范、持续维护，比任何技巧都有效。
:::

## 权限速查
| 想做的事 | 需要什么 |
| --- | --- |
| 浏览公开资源 | 登录即可 |
| 浏览租户内资源 | 是同一个组织的成员 |
| 浏览个人资源 | 是仓库成员 |
| 修改设置、删除仓库 | 系统管理员、仓库所有者、组织管理员，或仓库管理员/读写成员 |
| 发起讨论、提合并请求 | 登录用户 |

## 结果确认
- 公开成功后，换个账号或在未登录状态下也能打开这个资源。
- 元数据保存后，在列表页用对应标签筛选，能筛出你的资源。
