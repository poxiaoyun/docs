# 社区贡献

魔哈中的「贡献」体现为在仓库内的协作与共建。前端没有积分/徽章/论坛等社区运营功能。

## 分享资源

- 创建公开（`public`）的模型、数据集、镜像或 Space。
- 在仓库根目录维护 README，作为模型卡片/数据集卡片的正文。
- 补齐元数据（许可证、任务类型、框架、标签等），便于被检索与推荐。

## 协作方式

| 方式 | 说明 |
| --- | --- |
| 成员协作 | 添加仓库成员并设置 `admin` / `readwrite` 等角色；组织管理员与仓库 Owner 也可管理 |
| 讨论 | 在 `discussion` 标签发起话题、回复与关闭 |
| Pull Request | 基于分支的变更，可在讨论中查看 diff、提交与合并 |
| 提交与回退 | 通过文件页的提交记录做 Reset / Revert |
| 版本冻结 | 用冻结固化稳定版本，供他人引用与回滚 |

## 社区反馈

| 能力 | 说明 |
| --- | --- |
| 收藏（Star） | 收藏资源后可在[我的收藏](/moha/home/liked-by-me)集中查看 |
| 评分 | 模型/数据集卡片支持打分，统计平均分 |
| 推荐 | 运营侧可为资源设置推荐指数 `RECOMMEND_SCORE` 与推荐语，进入 Space 精选推荐区等位置 |
| 下载统计 | 自动统计下载量，用于排序与列表展示 |

## 权限参考

| 操作 | 要求 |
| --- | --- |
| 浏览公开资源 | 所有用户 |
| 浏览内部资源 | 同组织成员 |
| 浏览私有资源 | 仓库成员 |
| 修改仓库设置 / 删除 | 系统管理员、Owner、组织管理员或仓库 admin/readwrite |
| 发起讨论 / PR | 登录用户 |

> 💡 提示: 争议与评审尽量沉淀在讨论/PR 中，便于后续回溯；稳定产出用版本冻结固化。
