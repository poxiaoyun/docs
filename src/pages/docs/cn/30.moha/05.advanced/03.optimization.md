# 性能优化

大模型动辄几十 GB，下载慢通常不是网络的问题，而是**下了太多根本用不到的文件**——同一个模型往往同时放了 `.safetensors`、`.bin`、多种精度版本，全量下载自然又慢又占硬盘。这一页给出几条立刻能用的做法，每条都写清了命令和预期效果。

## 开始之前
安装 SDK 并登录：

```bash
pip install moha-hub
moha login https://<你的控制台地址> --token <你的访问令牌>
moha org use <你的组织名>
```

:::warning 先说清楚一件事
`moha` 的下载是**逐个文件按顺序进行**的，目前没有提供「开多个线程并发下载」的参数。所以真正有效的提速手段是**减少下载量**，而不是去调并发参数。
:::

## 方法一：只下载需要的文件（最有效）
### 明确列出文件名
```bash
moha download <组织>/<仓库> config.json tokenizer.json --local-dir ./model
```
预期效果：只把列出的这两个文件下到 `./model`，其余一概不拉。

### 用通配符挑选
```bash
moha download <组织>/<仓库> \
  --include "*.safetensors" \
  --include "*.json" \
  --exclude "*.bin" \
  --local-dir ./model
```
预期效果：只下权重和配置文件，跳过 `.bin` 这类重复权重。很多模型同时提供两种格式的权重，跳过其中一种能省掉接近一半的体积。

| 参数 | 作用 |
| --- | --- |
| `--include` | 只下载匹配的文件，可以重复写多条 |
| `--exclude` / `--ignore` | 跳过匹配的文件，可以重复写多条 |
| `--local-dir` / `-o` | 指定下载到哪个目录 |

## 方法二：只下载单个文件
临时缺一个文件时，不必重下整仓：

```bash
moha download-file <组织>/<仓库> model.safetensors --local-dir ./model
```
预期效果：只下载这一个文件，几乎瞬间完成。

## 方法三：Git 克隆时跳过 LFS 大文件
魔哈仓库用 Git LFS 存放大文件。克隆时先跳过它们，拿到的是一个「只有目录结构」的轻量副本：

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone https://<你的控制台地址>/moha/<组织>/models/<仓库>.git
cd <仓库>
git lfs pull --include="*.safetensors"
```
预期效果：克隆步骤秒级完成；第二条命令只把你真正需要的那类大文件拉下来，其余保持为指针。

:::tip 什么时候用这招
在流水线里只想校验目录结构、跑静态检查，或者你只需要其中某一类权重时，用这个方法最省时间。
:::

## 方法四：不下载，让框架按需读取
如果只是要跑推理或加载数据集，可以完全不落地整份文件，让框架自己去取需要的分片：

```bash
export HF_ENDPOINT=https://<你的控制台地址>/moha/huggingface
export HF_TOKEN=<你的访问令牌>
```

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

# 框架会通过上面的 HF_ENDPOINT 拉取所需文件，而不是从 huggingface.co
tokenizer = AutoTokenizer.from_pretrained("demo/my-model", trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained("demo/my-model", device_map="auto")
```
预期效果：按需读取，跳过与本次运行无关的文件（例如你只用 CPU 推理时的 GPU 专用权重）。

## 方法五：大文件改用 SDK 上传
浏览器上传一次最多 100 个文件、总计 100 MB，超过就必须改用命令行，否则只能干等或分很多次传：

```bash
moha upload <组织>/<仓库> ./my_model --message "upload model" --exclude "*.log"
```
预期效果：不受浏览器限制，大目录一次传完。

## 顺带：选对文件格式
- 权重优先用 `.safetensors`：加载更快，模型详情页还能直接显示模型体积和张量统计。
- 数据集优先用 Parquet、JSONL 这类列式或流式格式，配合 Git LFS 存储。

这两点不影响下载速度，但影响你后续加载和读取的速度。

## 效果对照
| 做法 | 适合场景 | 大概能省多少 |
| --- | --- | --- |
| `--include` 只拉需要的文件 | 已知需要哪些文件 | 视情况，常能省一半以上 |
| `moha download-file` | 只缺一两个文件 | 几乎全部时间 |
| `GIT_LFS_SKIP_SMUDGE=1` + 按需 `git lfs pull` | 只校验、只需部分权重 | 克隆阶段几乎瞬时 |
| `HF_ENDPOINT` 按需读取 | 直接跑推理/加载数据集 | 免去整仓落地 |
