# API 集成

魔哈前端的接口统一挂在 `/api/moha` 前缀下，大部分资源接口以 `organization` + `type` + `repository` 定位。

## 认证

请求通过 `Authorization: Bearer <令牌>` 携带访问令牌，令牌来源见[访问令牌](/moha/quickstart/token)。

```bash
curl -H "Authorization: Bearer <令牌>" \
  https://moha.your-domain/api/moha/organizations/my-org/models/my-model
```

## 接口分组

| 领域 | 典型路径 |
| --- | --- |
| 列表与推荐 | `/api/moha/{type}`、`/api/moha/{type}/recommendation` |
| 个人数据 | `/api/moha/my-create/{type}`、`/api/moha/my-favorite/{type}`、`/api/moha/my-favorite/summary` |
| 组织 | `/api/moha/organizations`、`/api/moha/organizations/{organization}/summary` |
| 仓库基础 | `/api/moha/organizations/{organization}/{type}/{repository}` |
| README / 文件 | `.../readme`、`.../raw/{ref}`、`.../resolve/{ref}`、`.../contents/{ref}` |
| 引用与提交 | `.../refs`、`.../commits/{ref}`、`.../commit/{ref}/diff`、`.../refs/{ref}:reset`、`.../refs/{ref}:revert` |
| 版本冻结 | `.../freezes`、`.../freezes/{id}`、`.../freezes/{id}/diff`、`.../freezes/{id}:rollback` |
| 讨论 / PR | `.../discussion`、`.../discussion/{name}`、`.../{name}:close|:open|:merge`、`.../discussion/{name}/diff` |
| 收藏 | `.../favorite`（GET 状态 / POST 更新） |
| 成员 | `/api/moha/organizations/{organization}/members`、`.../{type}/{repository}/members` |
| 上传会话 | `/moha/{organization}/{type}/{repository}/api/upload-sessions[/capabilities|/{id}|/{id}:finalize]` |
| Space 生命周期 | `.../spaces/{repository}:online|:restart|:delete`、`.../{repository}/pods`、`.../pods/{pod}/logs` |
| Space 部署选项 | `/api/moha/organizations/{organization}/clusters`、`.../clusters/{cluster}/workspaces`、`.../flavors`、`.../products` |

> ⚠️ 注意: 上表来自前端 `src/services/moha.ts` 的调用路径，是前端实际使用的接口面。请求体字段与响应结构以后端契约为准，本文未逐一确认。

## 创建与更新资源

- 创建：`POST /api/moha/organizations/{organization}/{type}`。
- 更新：`PUT /api/moha/organizations/{organization}/{type}/{name}`。
- 删除：`DELETE /api/moha/organizations/{organization}/{type}/{name}`。

创建时请求体包含 `name`、`alias`、`description`、`organization`、`visibility`、`metadata`、`members`，模型还可带 `requestgenealogy`（`baseModel` + `relationship`）。

## 上传会话

Web 上传走「上传会话」流程：

1. `GET .../api/upload-sessions/capabilities` 获取能力与限制。
2. `POST .../api/upload-sessions` 初始化（请求头带 `Idempotency-Key`）。
3. 上传文件后 `POST .../api/upload-sessions/{sessionId}:finalize` 提交。

## SDK 与兼容端点

SDK 包为 `moha-hub`（Python 模块名 `xiaoshiai_hub`）：

```bash
pip install moha-hub
moha download --repo-type models my-org/my-model
```

```python
from xiaoshiai_hub import snapshot_download

snapshot_download(
    repo_id="my-org/my-model",
    repo_type="models",
    username="your-username",
    password="<令牌>",
)
```

如需用 Transformers / Datasets 直接加载，配置 HuggingFace 兼容端点：

```bash
export HF_ENDPOINT=https://moha.your-domain/moha/huggingface
export HF_TOKEN=<令牌>
```

> ⚠️ 注意: SDK 的 `HubClient` / `MOHA_ENDPOINT` / `base_url` 等参数不在本前端仓库内，文档暂未确认其取值语义，请以 SDK 官方文档为准。
