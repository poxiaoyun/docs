# API 集成

用 HTTP 接口直接读写魔哈里的模型、数据集、空间和镜像，适合写脚本、做数据同步，或把魔哈接进你自己的系统。

:::tip 能用 SDK 就别手写 HTTP
官方 SDK（`moha-hub`）已经把认证、分页、上传都封装好了，出错更少。只有在你不能用 Python 的时候，才需要直接调 HTTP。SDK 用法见 [SDK 教程](/moha/sdk-tutorial/quick-start)。
:::

## 开始之前
- 一个**访问令牌**：到 [访问令牌](/moha/quickstart/token) 页面生成。
- 你的**控制台地址**，就是你平时打开魔哈网页时地址栏里的那串地址。
- 一个能发 HTTP 请求的工具：`curl`、Postman，或任意编程语言。

## 认证：带上访问令牌
每个请求都要加这一行请求头：

```text
Authorization: Bearer <你的访问令牌>
```

:::warning 令牌等于密码
不要把令牌写进代码仓库、贴在聊天里或打进公开日志。在 CI/CD 里请用平台的 Secret 功能注入。
:::

## 最小可运行示例
把下面三个占位值换成你自己的，然后在终端执行：

```bash
# 查询一个模型仓库的基本信息
curl -s -H "Authorization: Bearer <你的访问令牌>" \
  "https://<你的控制台地址>/moha/v1/organizations/demo/models/my-model"
```

返回一段 JSON，里面有仓库名称、可见性、元数据等信息，就说明地址和令牌都正确。

## 接口怎么组织
所有接口都在 `/moha/v1` 下面，用「组织 / 资源类型 / 仓库名」三段来定位一个仓库。资源类型取 `models`、`datasets`、`spaces`、`images`（用复数）。

| 想做什么 | 请求方法与路径 |
| --- | --- |
| 列出公开资源 | `GET /moha/v1/{资源类型}` |
| 列出某个组织内的资源 | `GET /moha/v1/organizations/{组织}/{资源类型}` |
| 查看仓库信息 | `GET /moha/v1/organizations/{组织}/{资源类型}/{仓库}` |
| 列出分支和标签 | `GET /moha/v1/organizations/{组织}/{资源类型}/{仓库}/refs` |
| 浏览目录 | `GET .../{仓库}/contents/{分支}` |
| 读取某个文件的内容 | `GET .../{仓库}/contents/{分支}/{文件路径}` |
| 下载某个文件 | `GET .../{仓库}/resolve/{分支}/{文件路径}` |

换一个资源类型或仓库名，同一套路径就通用。

## 上传文件
HTTP 上传比下载绕，要分三步：先创建「上传会话」声明要传哪些文件，再按会话返回的地址把文件逐个传上去，最后通知会话结束、由服务端生成一次提交。

过程容易出错，**推荐直接用 SDK** 的 `upload_file()` / `upload_folder()`，见 [上传、下载与文件同步](/moha/sdk-tutorial/transfer)。

## 用 Transformers / Datasets 直接加载
把 Hugging Face 的地址指向魔哈，就能不下载整仓、直接在代码里加载：

```bash
export HF_ENDPOINT=https://<你的控制台地址>/moha/huggingface
export HF_TOKEN=<你的访问令牌>
```

```python
from datasets import load_dataset

# 会通过上面的 HF_ENDPOINT 从魔哈拉取，而不是从 huggingface.co
dataset = load_dataset("demo/my-dataset")
print(dataset)
```

## 常见报错
| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| `401` | 没带令牌，或令牌已失效 | 检查 `Authorization` 请求头；令牌过期就重新生成一个 |
| `403` | 令牌有效，但没有这个仓库的权限 | 私有仓库需要你被加为成员；确认账号所属组织 |
| `404` | 路径写错了 | 逐段检查组织名、资源类型（要复数）、仓库名 |
| 上传到一半失败 | 文件太大或网络中断 | 改用 SDK 上传，它会分片并支持重试 |
