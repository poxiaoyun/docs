# 数据集维护

管理和维护日常数据集，确保数据质量。

## 版本管理

使用 Git 分支管理数据集版本，用**版本冻结**固化不可变快照：

- **分支**：`main` 为正式版本，可创建其他分支用于数据清洗、试验。
- **版本冻结**：在「版本冻结」标签创建冻结，锁定分支/提交，支持对比差异与回滚（见[版本冻结](/moha/repository/freezes)）。
- 文件页顶部的分支选择器可同时切换分支与冻结。

> 💡 提示: 数据发布给他人引用前，建议先创建版本冻结，避免后续提交影响对方。

## 数据更新

### 追加数据

```bash
cd my-dataset
cp /path/to/new-data/*.parquet .
git add .
git commit -m "追加 2025-01 训练数据"
git push origin main
```

### 回滚版本

如果新数据有问题，可回退到之前的版本：

```bash
git revert HEAD
git push origin main
```

## 清理与归档

- **清理无用文件**：删除过期或无用的数据文件
- **归档历史版本**：将旧版本数据归档到独立分支

> ⚠️ 注意: 大型数据集的 Git 历史可能占用大量存储空间。建议定期清理不再需要的历史大文件。需要固定某个可用版本时，优先使用仓库的「版本冻结」而不是长期保留全部分支。
