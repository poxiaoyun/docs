# 数据集介绍

数据集广场就是**数据集列表页**，把你在这个平台上能看到的数据集摆在一起。想找训练数据、或者看看团队里都有哪些数据，从这里开始。

## 进入路径

顶部导航点击 **数据集**。

## 找数据集：搜索、筛选、排序

页面顶部有搜索框，左侧是一列筛选条件，右上角可以切换排序方式。

| 我想…… | 怎么操作 |
| --- | --- |
| 按名字找 | 在顶部搜索框输入数据集名，回车；也可以用 `组织/数据集名` 精确定位 |
| 按条件缩小范围 | 点搜索框右侧的 **高级搜索**，勾选语种、数据质量等级、获取方式等条件后点 **应用筛选** |
| 按分类看 | 左侧点 **分类**（如文本分类、问答） |
| 按行业看 | 左侧点 **行业/业务域**（如金融、医疗健康） |
| 按许可证看 | 左侧点 **许可证** |
| 按上传方看 | 左侧点 **组织** |
| 换排序方式 | 点右上角的 **排序：综合排序**，在弹出的菜单里选 |

排序菜单里有四项：

| 选项 | 含义 |
| --- | --- |
| 综合排序 | 平台默认的推荐顺序 |
| 下载次数 | 下载最多的排前面 |
| 喜欢数量 | 被收藏最多的排前面 |
| 用户评分 | 评分最高的排前面 |

选过的筛选条件会显示在列表上方，点标签上的叉号可以单独去掉，点 **清空** 一次去掉全部。

## 卡片上有什么

| 卡片上的信息 | 含义 |
| --- | --- |
| 名称 | 数据集名；左上角小图标是上传它的组织 |
| 描述 | 一句话说明这份数据是什么 |
| 标签 | 任务分类、行业、语言等 |
| 更新时间 | 最近一次改动的时间 |
| 下载次数 | 一共被下载了多少次 |
| 喜欢 | 被收藏（点赞）的次数 |

## 收藏一个数据集

在卡片上点击收藏图标，数据集就会进入你的收藏列表，之后可以在首页左侧的 **我喜欢的** 里快速找到。
