# 数据集介绍

数据集广场即数据集列表页，展示平台上可见的数据集资源。

## 进入路径

魔哈顶部导航 -> **数据集**，路由 `/moha/datasets`。

## 列表能力

| 能力 | 说明 |
| --- | --- |
| 关键字搜索 | 按名称/关键字搜索 |
| 元数据筛选 | 按任务类型、语言、框架、标签、数据规模等元数据组合过滤 |
| 排序 | `''`（综合）、`downloads`（下载量）、`likes`（点赞）、`rating`（评分） |
| 可见性 | 在 `public` / `private` / `internal` 之间切换，默认 `public` |
| 分页 | 默认每页 `size=16` |

> 💡 提示: 列表以卡片网格展示，没有独立的表格视图。

## 数据集卡片

| 信息 | 说明 |
| --- | --- |
| 名称 | 组织/数据集名 |
| 可见性 | `public` / `internal` / `private` |
| 描述 | 数据集用途简介 |
| 标签 | 数据类型、领域、语言等 |
| 下载量 | 下载总次数 |
| 收藏数 | 被收藏的次数 |

## 收藏

点击卡片或详情页的收藏（Star）按钮，数据集会加入个人收藏，可在[我的收藏](/moha/home/liked-by-me)中查看。
