# 数据集

数据集是魔哈里专门放**训练和评测数据**的地方。把整理好的数据传上来，配上说明，团队里谁要用谁就下载，不用再靠聊天软件传压缩包。

数据集和模型用的是同一套仓库，所以用法几乎一模一样：都有文件、快照、交流反馈和设置。

| 名词 | 通俗解释 |
| --- | --- |
| 仓库 | 一个放数据集的文件夹，例如 `ai-lab/chinese-qa` |
| 分支 | 数据的一条时间线，默认在 `main` 上 |
| 快照 | 给当前数据状态拍的存档照片，随时能回到那一刻 |

## 进入路径

顶部导航点击 **数据集**，进入数据集广场（列表页）。

![数据集列表：左侧按分类 / 领域 / 许可证 / 组织筛选，右侧结果卡片标注分类、领域、语种与体积](/assets/screenshots/moha/datasets-list-01.png)

数据集的筛选里没有 **框架**（那是模型和镜像才有的维度），换成了 **领域**——截图里 alpaca-gpt4-data-zh 就同时标了「交通与物流」领域和「阿拉伯语（阿尔及利亚）」语种。

## 我第一次上传数据集，该走哪几步

1. 进入首页，左侧点击 **我创建的**，切到 **数据集** 分类。
2. 点击右上角 **创建数据集**，填写名称、组织等信息，点 **确定**，见[数据集创建](/moha/datasets/create)。
3. 进入仓库的 **文件** 标签页，把数据文件传上去，见[数据集的上传](/moha/datasets/upload)。
4. 在 **数据集介绍** 标签页写好 README，说明数据内容、字段含义和许可证，见[数据集卡片](/moha/datasets/card)。
5. 需要固定一个可用版本时，到 **快照** 标签页做一次快照，见[数据集的维护](/moha/datasets/maintain)。

| [数据集文件规范](/moha/datasets/rules) | 名称规则、目录组织、平台的大小限制 |
