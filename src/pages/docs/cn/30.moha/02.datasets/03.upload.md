# 数据集的上传

数据集创建后，在仓库详情页的 **文件** 标签上传数据文件。

## Web 上传

1. 进入数据集详情页 → **文件** 标签页。
2. 点击 **上传文件**，选择文件或整个目录。
3. 提交后生成一次 Commit。

上传以「上传会话」为单位：先请求能力与限制，再初始化会话、上传、最终提交。能否上传文件/目录、能否新建/编辑/删除，由服务端下发的 `supports` 决定。

> ⚠️ 注意: 前端自身有硬性兜底上限——单次最多 100 个文件、合计不超过 100 MiB（`BROWSER_UPLOAD_MAX_FILES = 100`、`BROWSER_UPLOAD_MAX_TOTAL_BYTES = 100 * 1024 * 1024`）。服务端还会通过 `limits`（`maxFiles`、`maxTotalBytes`、`maxManifestBytes`、`maxPathBytes`、`maxEditableBytes`）下发更严格的限制，两者取小。文档中此前的「单文件 5GB」在前端代码中查无依据，按未确认处理。

## Git 推送

```bash
git lfs install
git clone https://moha.your-domain/moha/datasets/my-org/my-dataset.git
cd my-dataset

git lfs track "*.parquet" "*.csv.gz" "*.tar.gz"
cp /path/to/data/* .
git add .
git commit -m "上传数据集 v2"
git push origin main
```

## SDK

```bash
pip install moha-hub
moha download --repo-type datasets my-org/my-dataset
```

## 常见数据格式

| 格式 | 扩展名 | 适用场景 |
| --- | --- | --- |
| CSV | `.csv` | 表格数据 |
| Parquet | `.parquet` | 列式存储，大规模数据 |
| JSONL | `.jsonl` | 结构化文本数据 |
| 图片 | `.jpg` / `.png` | 视觉数据集 |
| 音频 | `.wav` / `.mp3` | 语音数据集 |
| 压缩包 | `.tar.gz` / `.zip` | 批量打包 |

> 💡 提示: 文件页支持在线预览 Markdown、JSON、YAML 等文本类文件，便于上传后快速核对。
