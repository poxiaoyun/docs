# 数据集的上传

数据集仓库建好之后，接下来把数据文件传进去。平台提供三种方式，**按文件大小和数量来选**：

| 方式 | 适合什么场景 | 限制 |
| --- | --- | --- |
| 网页上传 | 少量小文件，随手补一份说明或配置 | 单次最多 100 个文件，合计不超过 100 MiB |
| Git 命令行 | 大批数据、想保留每次变更记录 | 大文件必须走 Git LFS |
| SDK 命令 | 脚本化上传，或文件较多较大 | 无明显文件个数限制 |

## 开始之前

- 你需要是仓库的 **管理员** 或 **读写** 成员，否则 **文件** 页面没有上传入口。
- 单文件超过 5 MB 的，请走 Git LFS 或 SDK，不要用普通 Git 直接提交，否则推送会被拒绝。
- 用命令行上传前，先在本机装好 Git 和 Git LFS。
- 用 SDK 前，先执行 `pip install "moha-hub[upload]"` 安装，再登录一次。

## 方式一：网页上传

1. 打开数据集仓库详情页，点击 **文件** 标签页。
2. 点击右上角 **添加文件**，在下拉菜单里选择：
   - **上传文件**：选择一个或多个数据文件；
   - **上传文件夹**：选择整个目录，目录结构会一起保留；
   - **新建文件** / **新建文件夹**：直接在网页上建一个小文件或空目录。
3. 在弹窗里确认文件清单，填写 **提交信息**（例如 `添加训练数据`），点击提交。
4. 上传完成会提示 **提交成功**，并显示这次提交的编号。

:::warning 网页上传的大小上限

- 一次最多 100 个文件，合计不超过 100 MiB。
- 超出时会提示「请使用 Moha SDK 上传」，此时请改用下面的 SDK 方式。

:::

## 方式二：Git 命令行上传

适合成批的数据文件。先克隆仓库，再提交推送。

1. 打开数据集仓库详情页，点击右上角 **下载数据集**。
2. 弹窗选 **Git** 标签，复制 **克隆仓库** 的命令，在终端执行：

```bash
git lfs install
git clone <仓库地址>
cd <仓库名>
```

3. 把数据文件放进这个目录，并告诉 Git LFS 哪些大文件归它管：

```bash
# 让 LFS 接管常见的数据文件
git lfs track "*.parquet" "*.jsonl" "*.csv.gz" "*.tar.gz"

# 把本地数据复制进来
cp /path/to/data/* .

git add .
git commit -m "上传数据集 v1"
git push origin main
```

推送成功后回到网页刷新，文件就会出现在 **文件** 列表里。

:::tip 大文件必须走 LFS
普通 Git 对超过 5 MB 的新文件会直接拒绝推送，并提示改用 Git LFS 或 Moha SDK。
`git lfs track` 务必在 `git add` 之前执行，登记结果会保存到仓库的 `.gitattributes`。
:::

## 方式三：SDK 命令行上传

适合脚本化上传，没有网页那种文件个数限制。

```bash
pip install "moha-hub[upload]"
moha login https://<平台地址> --token <访问令牌>
```

上传整个目录，或只传单个文件：

```bash
# 上传文件夹（目录结构会保留）
moha upload ai-lab/my-dataset ./my_dataset

# 上传单个文件，并指定它在仓库里的路径
moha upload ai-lab/my-dataset ./train.parquet data/train.parquet
```

也可以加上提交信息、目标分支和忽略规则：

```bash
moha upload ai-lab/my-dataset ./my_dataset \
  --message "上传训练数据" \
  --revision main \
  --exclude "*.log" --exclude ".git*"
```

在 Python 代码里上传：

```python
from xiaoshiai_hub import upload_folder

upload_folder(
    folder_path="./my_dataset",
    repo_id="ai-lab/my-dataset",
    repo_type="datasets",
    commit_message="上传训练数据",
    ignore_patterns=["*.log", ".git*"],
    token="<访问令牌>",
)
```

## 常见数据格式

| 格式 | 扩展名 | 适用场景 |
| --- | --- | --- |
| CSV | `.csv` | 表格数据，人眼可读 |
| Parquet | `.parquet` | 列式存储，体积小、读取快，适合大规模数据 |
| JSONL | `.jsonl` | 一行一条记录，适合指令、对话类数据 |
| 图片 | `.jpg` / `.png` | 视觉数据集 |
| 音频 | `.wav` / `.mp3` | 语音数据集 |
| 压缩包 | `.tar.gz` / `.zip` | 零散文件先打包再传 |

## 结果确认

回到 **文件** 标签页，新文件会出现在列表里，并显示文件大小。点击文件名可以在线预览文本类文件，用来快速核对内容。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 提示文件数量超过 100 个 | 网页上传有条数上限 | 改用 SDK 上传 |
| 提示文件总量超过 100MB | 网页上传有容量上限 | 改用 SDK 上传 |
| 推送被拒绝，提示超过大小限制 | 大文件没走 Git LFS | 先 `git lfs track`，重新提交 |
| 大文件想直接看内容 | 文件超过在线预览大小限制 | 下载到本地查看 |
| 看不到 **添加文件** 按钮 | 你对该仓库没有写权限 | 找仓库管理员给你 **读写** 权限 |
