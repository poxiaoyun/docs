# 数据集卡片

数据集仓库详情页默认进入 **数据集卡片**（`content`）标签。与模型卡片一样，它的正文来自仓库根目录的 `README.md`，右侧按元数据动态渲染若干信息区块。

## 页面结构

| 区域 | 区块 | 出现条件 |
| --- | --- | --- |
| 左侧（主区） | README 渲染区 | 始终 |
| 右侧（信息栏） | 评分与下载统计 | 数据集资源 |
| 右侧（信息栏） | 推荐语 | 存在 `RECOMMEND_COMMENT` 标注 |
| 右侧（信息栏） | 训练关系 / 被 Space 使用 | 模型或数据集资源 |

数据集不会出现血缘（模型族谱）与硬件需求区块，这两块仅在模型资源下渲染。

## README 渲染区

在数据集仓库根目录创建 `README.md` 即可作为数据集卡片。渲染前会把相对路径的图片、视频、附件链接重写为仓库接口地址，因此 README 里可以直接引用仓库内的文件。

README 里的相对链接会按当前查看的分支（reference）解析，切换分支后引用内容也会随之变化。

## 评分与下载统计

| 字段 | 来源标注 key | 说明 |
| --- | --- | --- |
| 用户评分 | `RECOMMEND_RATE_COUNT` | 平均分；已有评分时只读，未评分时可打分 |
| 下载量 | `RECOMMEND_DOWNLOAD_COUNT` | 数字按 `fNumber` 格式化展示 |

## 推荐语

当元数据中存在 `RECOMMEND_COMMENT` 标注时，右侧出现「推荐」卡片，展示推荐指数（`RECOMMEND_SCORE`）与推荐说明。

## 训练关系与被 Space 使用

数据集与模型都会出现该区块，内部由两部分组成：

| 组件 | 说明 |
| --- | --- |
| 训练关系（TrainingRelations） | 数据集看模型，展示使用该数据集训练出的模型 |
| 被 Space 使用（UsedBySpaces） | 展示引用该数据集的 Space |

点击后会打开右侧抽屉，抽屉内以 `datasets` / `models` / `spaces` 三个 tab 分类展示完整列表。

## 编写数据集卡片的建议

推荐在 README 中覆盖以下内容：

```markdown
# 数据集名称

## 概述
简述数据集的用途和来源。

## 数据内容
- 数据量：10 万条
- 格式：JSONL
- 语言：中文

## 字段说明
| 字段 | 类型 | 说明 |
|------|------|------|
| text | string | 原始文本 |
| label | int | 类别标签 |

## 使用方式
说明如何加载和使用数据集。

## 许可证
数据使用的许可证信息。
```

> 💡 提示: 完善的数据集卡片可以显著提高数据集的可发现性和使用率，右侧区块与筛选也依赖仓库元数据，建议一并填写完整。
