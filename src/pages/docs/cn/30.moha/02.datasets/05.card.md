# 数据集卡片

数据集卡片就是数据集详情页的**介绍页**，打开仓库时默认看到的那一页（页签叫 **数据集介绍**）。左边是正文，右边是一栏概况信息。

别人不了解你的数据时，全靠这一页判断「要不要用」。花十分钟写清楚，能省掉很多来回问的沟通。

## 正文来自哪里

正文就是仓库根目录里的 `README.md`，改这个文件卡片就跟着变。

1. 打开数据集仓库，点击 **文件** 标签页。
2. 在文件列表里找到 `README.md`，点击行末的编辑图标。
3. 用 Markdown 写内容，填好 **提交信息**，提交。
4. 回到 **数据集介绍** 标签页，就能看到更新后的卡片。

还没有 `README.md` 时，在 **文件** 页点 **添加文件**，选 **新建文件**，文件名填 `README.md`。

> 在线编辑只支持不超过 2 MiB 的文本文件。README 很大就用 Git / SDK 传上来，见[数据集的上传](/moha/datasets/upload)。

:::tip README 里可以直接放仓库里的图片
用相对路径引用同仓库的文件，例如 `![字段示例](images/sample.png)`，平台会自动把它替换成能访问的地址。
切换分支或快照时，这些引用也会跟着切到对应版本。
:::

这一栏的数据都是平台自动统计的，不需要你手填。评分旁边括号里的数字是参与人数（截图里是 1 人参与），人数很少时分数参考价值有限。

## 右侧信息栏有什么

右侧区块**根据仓库信息自动生成**，只有对应信息存在时才会出现，不需要手动配置。

| 区块 | 出现条件 | 里面是什么 |
| --- | --- | --- |
| 用户评分 / 下载次数 | 一定会出现 | 平均分、参与人数、累计下载量 |
| 推荐 | 平台标注了推荐语 | 推荐指数和推荐说明 |
| 训练关系 / 被空间使用 | 一定会出现 | 使用该数据集训练出的模型、引用该数据集的空间 |

数据集不会出现「模型系谱」和「硬件依赖」区块，这两块只在模型仓库里显示。

## 关于评分

- 评分是一到五星，点一次就生效。
- 已经有人评过分后，星级变为只读，不能改。

## 写好数据集卡片的建议

推荐按下面的结构写 README：

```markdown
# 数据集名称

## 概述
这份数据用来做什么，从哪里来。

## 数据内容
- 数据量：10 万条
- 格式：JSONL
- 语言：中文
- 质量等级：银级

## 字段说明
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| text | string | 原始文本 |
| label | int | 类别标签 |

## 使用方式
一行加载示例，或推荐的处理流程。

## 局限与注意事项
不适合什么场景，是否有敏感内容。

## 许可证
允许别人怎么用这份数据。
```

:::tip 元数据也要填
详情页右侧区块和数据集广场的筛选条件，都依赖创建仓库时填的分类、行业、语种、质量等级等信息。
在 **设置** 标签页里可以把这些元数据补全。
:::
