# 数据集创建

数据集以**仓库**为单位创建。创建一个空仓库只要一分钟，之后再把数据文件传进去。

## 开始之前

- 你需要先登录平台账号。
- 准备好一个能看懂的数据集名字，例如 `chinese-qa-v2`。

## 创建数据集

1. 进入首页，左侧点击 **我创建的**，切到 **数据集** 分类。
2. 点击右上角 **创建数据集**。
3. 在 **数据集** 卡片里填写基本信息：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 名称 | 例如 `中文问答数据集 v2` | 必填，是给别人看的显示名，之后还能改 |
   | ID | 自动生成，一般不用管 | 名称下方会显示 `ID: xxx`，这是仓库标识，用于仓库地址和命令行 |
   | 组织 | 从下拉里选 | 必填，决定这个数据集归谁所有 |
   | 描述 | 例如 `10 万条中文问答对` | 可留空，建议一句话说清用途 |

   > ID 由名称自动生成，中文会转成拼音，只保留小写字母、数字和短横线。
   > 也可以点名称下方的铅笔图标手动指定。手动指定时必须以小写字母开头，只能包含小写字母、数字和短横线。
   > **ID 创建后不能修改**，请提交前确认。

4. 在 **元数据** 卡片里补充分类信息（都可以留空，但填得越全，别人越容易搜到）：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 许可证 | 从下拉里选，例如 `apache-2.0` | 说明别人可以怎么用这份数据 |
   | 分类 | 多选，例如 `问答`、`文本分类` | 任务类型 |
   | 框架 | 多选，也可自己输入 | 相关框架或工具，列表里最多显示 5 个 |

5. 在 **数据分类与质量** 卡片里继续补充（可选）：

   | 表单项 | 说明 |
   | --- | --- |
   | 行业/业务域 | 这份数据用在哪个行业 |
   | 项目阶段 | 调研、开发、生产等 |
   | 语种 | 数据包含哪些语言 |
   | 文本类型 | 对话、问答、指令、代码等 |
   | 数据质量等级 | 铜级 / 银级 / 金级 |
   | 获取方式 | 第一方采集、公开采集、合成生成等 |
   | 自定义标签 | 你自己定义的标签，方便检索 |

   > 每个维度最多填 30 个值，单个标签不超过 32 个字符，单个值不超过 128 个字符。

6. 在 **成员** 卡片里给同事分权限（可选）：
   - 点击 **添加成员**，填 **用户名**，选 **角色**，点 **确定**。
   - 角色有 **管理员**（可管理成员并有读写权限）、**读写**、**只读**。
7. 点击 **确定** 提交。想放弃就点 **取消**。

:::tip 创建出来的数据集谁能看到

- 从 **我创建的** 进来的，新建数据集默认是 **个人**（只有你自己能看到）。
- 想分享给同事或公开，创建后到 **设置** → **可见性** 里改成 **租户内** 或 **公开**。
- 如果是从组织主页里创建，可见性会直接定为 **租户内**，组织成员都能看到。

:::

## 结果确认

提交后会跳回 **我创建的** 列表，能看到刚建好的数据集。点进去就是它的仓库详情页，此时是空的，接着去 **文件** 标签页上传数据，见[数据集的上传](/moha/datasets/upload)。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 提交时提示「必填项」 | 名称或组织没填 | 补全后重新提交 |
| 提示名称格式不对 | 名称用了中文标点或特殊符号 | 换一个纯字母数字的名称 |
| 找不到 **创建数据集** 按钮 | 当前不在 **数据集** 分类下 | 先切换到 **数据集** 分类 |
