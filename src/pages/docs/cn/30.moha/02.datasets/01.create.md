# 数据集创建

数据集以仓库为单位创建。入口有两类：

- 全局列表页：`/moha/datasets` → 新建数据集，创建到个人空间（`/moha/my/datasets/create`）。
- 组织列表页：`/moha/organizations/:organization/datasets` → 新建数据集（`/moha/organizations/:organization/datasets/create`），此时资源归属该组织。

## 表单字段

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `organization` | 下拉选择 | 是 | 数据集归属的组织或个人空间；未选择时提交会报「必填」 |
| `name` | 文本 | 是 | 仓库标识，用于 URL 与 Git 操作 |
| `alias` | 文本 | 是 | 面向用户展示的名称 |
| `description` | 多行文本 | 否 | 用途说明 |
| `visibility` | 单选 | 是 | 默认 `private`；在组织上下文创建时强制为 `internal` |
| `license` | 自动补全 | 否 | 取自 `LICENSE_OPTIONS` |
| `tasks` | 任务选择器（多选） | 否 | 任务类型元数据 |
| `frameworks` | 自动补全（多选，可自由输入） | 否 | 取自 `LIBRARY_OPTIONS`，列表表单最多展示 5 个标签 |
| `members` | 成员管理 | 否 | 仓库级成员，角色为 `admin` / `member` |

### 名称校验

`name` 必须匹配：

```text
^[a-zA-Z0-9][a-zA-Z0-9._-]*$
```

即首字符为字母或数字，其后可包含字母、数字、`.`、`_`、`-`。

> ⚠️ 注意: 名称创建后不可修改，请确认后再提交。

### 可见性规则

| 场景 | `visibility` |
| --- | --- |
| 默认 | `private` |
| 在组织上下文创建 | 强制 `internal`（不受表单选择影响） |

## 创建后的上传

数据集创建完成后进入仓库详情页，在 **文件** 标签上传数据文件：

### Web 上传

文件页 → **上传文件**，可上传文件或整个目录；上传以「上传会话」为单位，一次提交生成一次 Commit。

### Git 推送

```bash
git lfs install
git clone https://moha.your-domain/moha/datasets/my-org/my-dataset.git
cd my-dataset

git lfs track "*.parquet" "*.csv" "*.jsonl"
cp /path/to/data/* .
git add .
git commit -m "添加训练数据"
git push origin main
```

### SDK

```bash
pip install moha-hub
moha download --repo-type datasets my-org/my-dataset
```

> 💡 提示: 大型数据文件建议走 Git LFS，并优先使用 Parquet、JSONL 等高效格式；也可直接使用 HuggingFace 兼容端点 `${origin}/moha/huggingface`。
