# 数据集的下载

把魔哈上的数据集拿到本地，或者在代码里直接读。平台提供三种方式，**按用途来选**：

| 方式 | 适合什么场景 | 需要装什么 |
| --- | --- | --- |
| 网页直接下载 | 只拿一两个小文件 | 什么都不用装 |
| Git 命令行 | 整份数据、几十 GB 的大数据集 | Git 和 Git LFS |
| SDK 命令 | 写脚本批量拉取，或在 Python 里直接加载 | Python 和 moha-hub |

## 开始之前

- 下载**公开**数据集不需要登录；下载**私有**或租户内数据集需要**访问令牌**，见[访问令牌](/moha/quickstart/token)。
- 用命令行下载前，先在本机装好 Git 和 Git LFS。
- 用 SDK 前，先执行 `pip install moha-hub` 安装，再登录一次。

![数据集详情页：右上角是「下载数据集」与「使用数据集」，左侧是卡片正文，右侧是评分、下载次数与关联模型 / 空间](/assets/screenshots/moha/repo-dataset-content-01.png)

网页下载点右上角 **下载数据集** 即可。右侧信息栏里的 **使用该数据集训练或调优的模型** 和 **使用此数据集的 Spaces** 能帮你判断这份数据有没有被人用过。

## 方式一：网页直接下载

1. 打开数据集仓库详情页，点击 **文件** 标签页。
2. 在文件列表里找到目标文件，点击该行右侧的下载图标（悬停会显示 **下载文件**）。

适合零散的小文件。整份大数据集在网页下载容易中断，建议用 Git 方式。

## 方式二：Git 命令行下载

命令不用自己拼——在页面上直接复制即可。

1. 打开数据集仓库详情页，点击右上角 **下载数据集**。
2. 弹窗里选 **Git** 标签，按顺序复制这几条命令执行：

| 命令 | 作用 |
| --- | --- |
| `git lfs install` | 让 Git LFS 在你的电脑上生效，只需执行一次 |
| `git clone <仓库地址>` | 把整份数据集克隆到本地，大文件由 Git LFS 自动下载 |
| `GIT_LFS_SKIP_SMUDGE=1 git clone <仓库地址>` | 只下载文件名和指针，不下载大文件（想先看目录结构时用） |

仓库地址格式为 `https://<平台地址>/moha/<组织>/<资源类型>/<仓库名>.git`，例如 `https://<平台地址>/moha/ai-lab/datasets/chinese-qa.git`。

下载私有数据集时，Git 会提示输入用户名和密码，**密码填你的访问令牌**。

## 方式三：SDK 命令下载

先安装并登录：

```bash
pip install moha-hub
moha login https://<平台地址> --token <访问令牌>
```

然后下载整份数据集：

```bash
moha download --repo-type datasets ai-lab/chinese-qa
```

也可以指定保存目录，或只下载某几个文件：

```bash
moha download ai-lab/chinese-qa --local-dir ./data
moha download ai-lab/chinese-qa train.parquet test.parquet
```

在 Python 代码里下载：

```python
from xiaoshiai_hub import snapshot_download

# 下载整份数据集，返回本地目录路径
repo_path = snapshot_download(
    repo_id="ai-lab/chinese-qa",
    repo_type="datasets",
    token="<访问令牌>",

    # 可选：只下载需要的数据格式，忽略压缩包等
    allow_patterns=["*.parquet", "*.jsonl"],
    ignore_patterns=[".git*"],
)
print(repo_path)
```

## 只下载部分大文件

先跳过 LFS 大文件克隆下来，再按需拉取：

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone <仓库地址>
cd chinese-qa
git lfs pull --include="train/*.parquet"
```

## 直接加载，不落地

如果只是想在代码里读数据，可以配置魔哈的 HuggingFace 兼容接口，用 `datasets` 直接加载。

1. 在数据集详情页点击右上角 **使用数据集**，可以复制现成示例。
2. 先装库并配置接口地址和令牌：

```bash
pip install datasets

export HF_ENDPOINT=https://<平台地址>/moha/huggingface
export HF_TOKEN=<访问令牌>
```

3. 像用 HuggingFace 一样加载：

```python
from datasets import load_dataset

dataset = load_dataset("ai-lab/chinese-qa")
print(dataset)
```

## 下载指定版本

数据集用**分支**和**快照**区分版本。先克隆，再切到目标分支：

```bash
git checkout v1.0
```

用 SDK 时加 `--revision`：

```bash
moha download ai-lab/chinese-qa --revision v1.0
```

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 克隆下来的数据文件只有几 KB | 没装 Git LFS，只拿到了指针文件 | 安装 Git LFS 后执行 `git lfs install`，重新克隆 |
| 提示没有权限 | 下载的是私有 / 租户内数据集 | 配置访问令牌后重试 |
| `load_dataset` 报错找不到数据集 | 没配置接口地址或令牌 | 检查 `HF_ENDPOINT` 和 `HF_TOKEN` 环境变量 |
