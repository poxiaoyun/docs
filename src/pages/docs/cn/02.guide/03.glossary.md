# 术语表

这是全站被翻得最多的一页。每个词都按三件事写：**白话解释 + 生活类比 + 你第一次会在哪遇到它**。看不懂任何页面时，用 `Ctrl+F`（macOS 是 `Cmd+F`）在这里搜一下。

## 平台与角色

| 术语 | 白话解释与类比 | 我第一次会在哪遇到它 |
| --- | --- | --- |
| **晓石 AI** | 整套企业 AI 平台的品牌名，把算力、模型、对话、管理都包在一起 | 打开平台时，页面左上角的品牌名 |
| **智算平台** | 你日常干活的主界面。类比：车间 | 登录后默认进入 |
| **BOSS** | 平台管理员的后台。类比：厂长办公室 | 只有平台管理员能进入，普通用户看不到 |
| **魔哈 Hub** | 存放模型、数据集、镜像、演示应用的仓库。类比：货架 / 仓库 | 左上角切换到魔哈 Hub |
| **聚合网关** | 不用写代码就能和模型聊天、对比模型的界面。文档里统一叫「聚合网关」，界面上默认显示为「模型体验」，名称可由平台管理员修改 | 顶栏的「聚合网关」；产品里在左上角「产品与服务」中切换 |
| **租户** | 一家公司的独立空间，成员、资产、配额彼此隔离。类比：一栋独门独院的办公楼 | 登录后如果属于多个租户，会让你选一个 |
| **管理员（admin）** | 租户里权限最高的角色，能管成员、工作空间和配额 | 左侧菜单能看到的项最多；分配角色时 |
| **开发者（developer）** | 能部署服务、跑任务的角色，这是干活的主力 | 创建工作空间成员时；部署服务时 |
| **成员（member）** | 只能看不能改的角色，适合只了解进展的人 | 创建工作空间成员时；看不到「工作台」菜单时 |
| **平台管理员** | 管整个平台的人，能纳管集群、给租户分配额 | 进 BOSS 时 |
| **角色** | 决定你能看到哪些菜单、点哪些按钮的身份标签 | 界面上按钮不见了时，先想自己的角色 |

## 算力与资源

| 术语 | 白话解释与类比 | 我第一次会在哪遇到它 |
| --- | --- | --- |
| **集群** | 一栋机房大楼，里面是真实的机器。所有算力都来自某个集群 | 左侧菜单顶部的集群选择器 |
| **节点** | 大楼里的一台服务器。类比：一层楼里的一台电脑 | 实例详情里看容器跑在哪台机器上 |
| **加速卡** | 跑 AI 模型用的专用计算卡，最常见的是 GPU，也有 NPU 等国产卡。类比：给电脑加装的「显卡」 | 首页资源配额里的「加速卡」；选规格时 |
| **GPU** | 图形处理器，AI 训练和推理最常用的加速卡 | 首页配额、规格表、实例监控 |
| **NPU** | 神经网络处理器，国产加速卡，例如华为昇腾 | 有国产化集群时，规格表里会出现 |
| **vGPU** | 把一张物理卡切成几份给多个实例用。类比：一套房拆成几个单间分租 | 规格表里的「共享 GPU」类型 |
| **显存** | 加速卡自带的内存，模型越大占用越多。类比：显卡的「内存条」 | 实例监控里的「加速卡显存」 |
| **资源池** | 把集群里的机器分成几组，按用途或团队隔离。类比：把一整栋楼分成几个部门专区 | 平台管理员在 BOSS 里配置；普通用户不会直接操作 |
| **规格** | 一台实例的配置单：几核 CPU、多少内存、几张加速卡。类比：买电脑时选的配置 | 部署服务时的「规格」卡片；规格选不了时 |
| **配额** | 你能用多少资源的额度上限。类比：这个月的预算 | 首页「资源配额」「配额告警」；创建实例时规格不可选 |
| **命名空间** | Kubernetes 里用来隔离资源的方式。工作空间在底层通常对应一个命名空间，你不用直接操作 | 查看实例的 YAML 或资源详情时可能看到 |

## 工作空间与实例

| 术语 | 白话解释与类比 | 我第一次会在哪遇到它 |
| --- | --- | --- |
| **工作空间** | 大楼里的一间办公室，同事共享，是资源隔离的最小单位。所有操作都发生在某个工作空间里 | 左侧菜单顶部的工作空间选择器 |
| **工作空间选择器** | 左侧菜单顶部那两个下拉框，先选集群再选工作空间 | 每次登录后第一件事 |
| **实例** | 工作空间里跑起来的一台台「机器」的统称，包括推理服务、微调任务、开发环境、应用、实验、评测 | 各功能列表页里的每一行 |
| **推理服务** | 把模型部署成对外的在线接口，别人可以来调用。类比：让模型开门营业 | 左侧菜单「推理服务」 |
| **训练与微调** | 用你自己的数据让现成模型「补课」，变得更懂你的业务。类比：给员工做专项培训 | 左侧菜单「训练与微调」 |
| **开发服务** | 带图形界面的在线开发环境，能开 JupyterLab 或 VS Code。类比：一台随时可用的远程电脑 | 左侧菜单「开发服务」 |
| **应用实例** | 部署你自己或平台提供的 AI 应用 | 左侧菜单「应用实例」 |
| **指标** | 查看实验记录、对比不同实验的曲线。类比：实验记录本 | 左侧菜单「指标」 |
| **模型评测** | 给模型标准化打分，比较不同版本好坏。类比：期末考试 | 左侧菜单「模型评测」 |
| **状态** | 实例当前处于哪一步，常见的有 **已安装**（正在启动）、**健康**（可以用了）、**需关注**、**已暂停**、**处理失败** | 实例列表的「运行状态」列 |
| **已安装 / 健康** | 「已安装」表示容器还在拉起，「健康」表示服务已经可以访问 | 刚部署完的推理服务 |
| **副本数** | 同一个服务同时跑几份。类比：开几个收银台 | 部署参数里；扩缩容时 |
| **扩缩容** | 调整副本数量，忙的时候加，闲的时候减 | 实例详情里的「扩缩容」 |
| **启动 / 停止** | 停止会把实例暂停以释放算力，配置保留；启动则重新占用算力跑起来 | 实例列表的操作按钮 |
| **访问地址** | 服务对外的入口地址，程序用这个地址调用你的服务 | 实例详情的「概览」 |

## 模板与部署

| 术语 | 白话解释与类比 | 我第一次会在哪遇到它 |
| --- | --- | --- |
| **模板** | 一键部署的配方：规定用哪个镜像、要哪些参数。类比：菜谱 | 点「创建推理服务」后看到的模板列表 |
| **应用市场** | 浏览和挑模板的地方 | 左侧菜单「应用市场」 |
| **版本（包版本 / 应用版本）** | 模板的不同发布版本，优先选带「最新版本」标记的 | 部署页顶部选版本 |
| **参数配置** | 部署表单里填具体参数的区域，不同模板的字段不一样 | 部署页 |
| **表单模式 / JSON 模式** | 参数可以用可视化表单填，也可以直接编辑 JSON，右上角图标切换 | 部署页的参数配置卡片 |
| **镜像** | 一个装好系统和软件的「硬盘模板」，实例用它开出来。类比：装系统用的系统盘 | 魔哈 Hub 的「镜像仓库」；模板配置里 |
| **容器** | 用镜像跑起来的一个隔离环境。类比：一台按系统盘装好的虚拟机 | 实例详情里的「容器列表」 |
| **Pod** | Kubernetes 里最小的调度单位，一个实例通常对应一个或多个 Pod | 实例详情里的「容器组列表」 |
| **命名空间** | 见上文「算力与资源」 | 资源详情 |
| **端口 / 暴露服务** | 把容器里的服务端口开放出来给外部访问 | 部署参数里的「端口配置」 |

## 存储与文件

| 术语 | 白话解释与类比 | 我第一次会在哪遇到它 |
| --- | --- | --- |
| **文件存储** | 左侧菜单名，进去管理存储卷 | 左侧菜单「文件存储」 |
| **存储卷** | 一块可以反复插拔的网络硬盘，放模型和数据，实例删了文件还在。类比：U 盘 | 创建推理服务挂载数据时；文件管理 |
| **存储类** | 存储卷的规格档次，决定性能和可用特性；创建存储卷时必填 | 创建存储卷时的「存储类」 |
| **存储集群** | 存储卷背后真正的存储设施，由平台管理员维护。创建存储卷时选的是**存储类**，存储集群只是列表里的展示列 | 文件存储列表的「存储集群」列 |
| **容量** | 存储卷大小，先填数字再选单位（`Mi` / `Gi` / `Ti`），例如 `20` + `Gi`；创建后只能扩容，不能缩小 | 创建存储卷 |
| **读写权限** | 挂载这块卷的实例能不能写：选「读写」可读可写，选「只读」只能读 | 创建存储卷；文件存储列表的「读写权限」列 |
| **文件管理器** | 存储卷里的网页版文件管理器，能上传、下载、预览、建目录 | 点进某块存储卷 |
| **存储作业** | 后台帮你把文件搬进存储卷的任务 | 存储卷里点「创建存储作业」 |
| **HuggingFace** | 国外知名的公开模型与数据集网站，可以拉取模型 | 创建存储作业时选类型 |
| **ModelScope** | 国内的公开模型与数据集社区（魔搭），可以拉取模型 | 创建存储作业时选类型 |
| **Git LFS** | 让 Git 仓库能存大文件的技术，模型权重才能进仓库 | 魔哈 Hub 上传大模型文件时 |
| **分支 / 标签 / 提交** | Git 的版本管理概念：提交是一次改动记录，分支是并行开发线，标签是给某个提交起的版本名 | 魔哈 Hub 模型或数据集的仓库页 |
| **合并请求** | 想把自己的修改并进主版本时发起的申请，别人审完才合并 | 魔哈 Hub 仓库页 |
| **组织** | 魔哈 Hub 里按团队管理仓库归属的方式。类比：部门 | 魔哈 Hub「组织空间」 |
| **空间** | 魔哈 Hub 里放演示应用的地方，例如一个 Gradio 小网页。类比：模型的门面展示柜 | 魔哈 Hub 顶部「空间」 |

## 模型资产

| 术语 | 白话解释与类比 | 我第一次会在哪遇到它 |
| --- | --- | --- |
| **模型库** | 魔哈 Hub 里存放模型文件的地方，有版本记录 | 魔哈 Hub 顶部「模型库」 |
| **数据集** | 训练和评测用的数据文件集合 | 魔哈 Hub 顶部「数据集」 |
| **模型卡片** | 模型的说明页，写清用途、适用场景、怎么用 | 魔哈 Hub 点开某个模型 |
| **可见性** | 谁能看到这份资产：**公开**（所有人）、**租户内**（本租户）、**个人**（只有自己） | 创建模型或数据集时 |
| **微调** | 用自有数据继续训练现成模型，让它更懂你的业务。类比：给员工做岗前特训 | 左侧菜单「训练与微调」 |
| **实验** | 一次记录下来的训练配置与结果，方便对比哪组参数更好 | 左侧菜单「指标」 |
| **评测** | 用标准题目给模型打分，量化好坏 | 左侧菜单「模型评测」 |
| **基座模型** | 微调时的起点模型，微调是在它基础上继续训练 | 微调参数里 |

## 对话与模型调用

| 术语 | 白话解释与类比 | 我第一次会在哪遇到它 |
| --- | --- | --- |
| **大模型网关** | 专门处理模型调用流量的中间层，负责选模型、限速、审查、记录用量。类比：总机转接台 | 聚合网关、模型广场；BOSS 的「大模型网关」 |
| **渠道** | 一个模型可以走的某条具体通道（例如某个供应商或平台内部的某个推理服务） | 模型详情里的「可用渠道」 |
| **模型广场** | 浏览有哪些模型可以调用，看上下文长度、价格等 | 聚合网关顶部「模型广场」 |
| **模型体验** | 和模型对话的页面 | 聚合网关顶部「模型体验」 |
| **模型对比** | 两个模型并排回答同一句话，方便比较。类比：左右两栏同时问两个人 | 聚合网关顶部「模型对比」 |
| **API 密钥** | 程序调用模型时用的「钥匙」，区别于登录密码 | 聚合网关顶部「API 密钥」 |
| **令牌管理** | 平台管理员统一管理所有密钥的地方 | BOSS |
| **深度思考** | 让模型先推理再回答的模式，默认开启 | 模型体验页的开关 |
| **Token** | 模型处理文本的最小单位，可以粗略理解为「字数的计量单位」 | 调用分析里的「Token 消耗」 |
| **调用分析** | 看请求数、Token 用量、费用、成功率的页面 | 聚合网关顶部「调用分析」 |
| **限速（RPM / TPM）** | 限制调用频率：RPM 是每分钟请求数，TPM 是每分钟 Token 数，界面上按 `K` 填，`1K` = 1000 Token/分钟 | 创建或编辑 API 密钥时 |
| **内容审查** | 请求和回复的安全检查，命中策略会被拦截 | BOSS 的「内容审查」；对话被拦截时 |
| **敏感词 / 策略 / 命中记录** | 敏感词是词表，策略是使用规则，命中记录是被拦下的流水 | BOSS 的「安全服务」分组 |
| **调用日志 / 审计日志** | 每次调用的详细记录，用来排查问题和合规检查 | BOSS 的「用户管理」「安全审计」 |

## 账号与安全

| 术语 | 白话解释与类比 | 我第一次会在哪遇到它 |
| --- | --- | --- |
| **多因素认证（MFA）** | 登录时除了密码再要一个动态验证码。类比：门禁卡加指纹 | 登录时出现第二个验证码输入框 |
| **验证码** | 拖动滑块或输入图形字符，用来证明你是人 | 登录失败几次后 |
| **API Key（AK/SK）** | 个人在「个人中心」生成的访问凭证，给命令行或脚本用 | 个人中心 → API 密钥 |
| **SSH Key** | 让你免密推送 Git 仓库的密钥对 | 个人中心 → SSH Key |
| **个人中心** | 改资料、改密码、管密钥、切换租户的地方 | 右上角头像 |
| **主题 / 深色模式** | 界面的配色方案，可以切明亮或暗色 | 顶部导航的主题图标 |

## 监控与排查

| 术语 | 白话解释与类比 | 我第一次会在哪遇到它 |
| --- | --- | --- |
| **首页（工作空间概览）** | 当前工作空间的总览：负载、配额、存储、需要关注的项 | 登录后第一眼 |
| **需要关注** | 首页把异常工作负载、配额超阈值、存储容量偏高等汇总成一栏 | 首页「需要关注」 |
| **日志** | 实例运行过程打印的文字，排查错误的第一手资料 | 实例详情的「日志」页 |
| **事件** | 平台记录的调度、镜像拉取、健康检查等动作，部署失败时先看它 | 实例详情的「事件」页 |
| **监控** | 用曲线展示 CPU、内存、加速卡利用率、网络流量等 | 实例详情的「监控」页 |
| **AI 助手** | 贴在页面右侧边缘的智能助手，用自然语言描述问题，它会结合当前工作空间的资源状态给出排查路径 | 智算平台页面右侧边缘的悬浮入口 |
| **服务注册** | 把平台内的推理服务登记到大模型网关，之后可以用统一的密钥调用 | 推理服务的网关状态 |
