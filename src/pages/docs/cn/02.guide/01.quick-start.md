# 快速开始

这篇是给第一次上手的人准备的完整路线图。你不需要先懂容器和 Kubernetes，只要会点鼠标、会复制粘贴，就能走完。

整个过程分五个阶段，**每完成一个阶段再进下一个**。每个阶段都告诉你四件事：目标是什么、具体怎么点、做完会看到什么、卡住了该翻哪篇。

:::tip 先记住三句话
- **集群**是放机器的大楼，**工作空间**是你在楼里的办公室。所有操作都发生在某个工作空间里。
- 部署任何东西都是同一套流程：**挑一个模板 → 填参数 → 点确定**。
- 状态从「已安装」变成「健康」，就代表跑起来可以使用了。
:::

## 阶段一：登录并认识界面

### 目标

成功进入智算平台，并认清页面上三个关键位置：产品切换、左侧菜单、工作空间选择器。

### 怎么做

1. 在浏览器地址栏输入平台地址（问你的平台管理员要，通常以 `/console` 结尾）。
2. 在登录表单里填写**用户名**和**密码**，点击**登录**。
3. 如果页面弹出验证码，按提示拖动滑块或输入图形里的字符。
4. 如果你的账号开启了多因素认证，会再出现一个验证码输入框，打开手机上的验证器应用，填入当前的 6 位动态码。
5. 如果你属于多个租户，会出现租户选择列表，点击你要进入的那个租户。只属于一个租户时会自动跳过这一步。
6. 进入控制台后，从上到下认三个位置：
   | 位置 | 在哪里 | 作用 |
   | --- | --- | --- |
   | 产品与服务 | 页面左上角 | 在智算平台、魔哈 Hub、对话体验之间切换 |
   | 左侧菜单 | 页面左侧 | 进入推理服务、训练与微调、文件存储等功能 |
   | 工作空间选择器 | 左侧菜单顶部 | 切换当前操作的集群和工作空间 |

### 做完你会看到什么

出现「首页」，页面上有「工作负载总数」「运行中 / 健康」「配额告警」等卡片。如果首页提示「请选择区域和工作空间后查看概览数据」，说明阶段二还没做。

### 卡住了看哪篇

- 登录、验证码、忘记密码：[登录](/account/auth/login)
- 多因素认证：[多因素认证](/account/auth/mfa)
- 租户选择：[选择与注册租户](/account/auth/select-tenant)

## 阶段二：拿到算力（选好集群和工作空间）

### 目标

在某个集群下选定一个工作空间。算力配额是按工作空间分配的，没有工作空间就部署不了任何东西。

### 怎么做

1. 看左侧菜单顶部的工作空间选择器，先选**集群**，再选**工作空间**。
2. 如果下拉列表里没有工作空间，说明还没有人创建，需要先创建：
   1. 点击 **去创建工作空间**。
   2. 选择所属**集群**（进入创建页时通常会带出你在选择器里选的那个）。
   3. 填写**名称**，例如 `my-first-workspace`。
   4. 填写**描述**（可留空）。
   5. 检查自动生成的**ID**。规则是：以小写字母开头，只能包含小写字母、数字和连字符，最长 63 个字符。中文名称会自动转成拼音。ID 创建后一般不再改动，需要修改时点 ID 后面的铅笔图标手动编辑。
   6. 点击 **确定**。
3. 回到首页，确认上方不再提示「请选择区域和工作空间」。

:::warning 配额不足会创建失败
如果创建时提示「当前租户未配置该集群的资源配额，无法创建工作空间」，说明租户在这个集群上还没有配额。请联系租户管理员或平台管理员分配，见[配额](/rune/console/quota)。
:::

### 做完你会看到什么

左侧菜单顶部显示你选中的集群和工作空间；首页的「资源配额」区域出现 CPU、内存、加速卡的额度和已用量。

### 卡住了看哪篇

- 工作空间是什么、怎么管：[工作空间](/rune/console/workspace)
- 配额一直不够用：[配额](/rune/console/quota)
- 看不懂「规格」「加速卡」：[术语表](/guide/glossary)

## 阶段三：跑通第一个推理服务

### 目标

把平台里已有的一个推理模板部署成在线服务，并确认它进入「健康」状态。这是整套流程的核心。

### 怎么做

1. 确认左侧菜单顶部已经选好集群和工作空间。
2. 左侧菜单点击 **推理服务**，点击右上角 **创建推理服务**。
3. 进入模板列表后，用顶部的分类标签筛选，选 **推理**，然后点击你要用的模板卡片。
4. 在模板详情里点击 **部署**，进入部署表单。页面标题会显示「部署 / 模板名」。
5. 在模板信息卡片上选择**版本**。下拉里有多个版本时，优先选带「最新版本」标记的那个。
6. 填写**基础信息**：
   | 表单项 | 怎么填 |
   | --- | --- |
   | 名称 | 这个服务的显示名，必填 |
   | ID | 自动按名称生成，规则同工作空间；需要改就点旁边的铅笔图标 |
   | 描述 | 可留空 |
7. 在**参数配置**卡片里填写模板参数。不同模板的字段不一样，常见的有模型路径、副本数、最大序列长度、量化方式等。
   - 默认是**表单模式**，每个字段旁边有说明。
   - 点右上角的代码图标可以**切换到 JSON 编辑模式**，适合一次改多个参数，改完再切回来。
   - 如果这个模板需要选算力，参数里会出现一张标题为**规格**的卡片，勾选一行即可。表格里显示名称、类型、CPU、GPU。
   - 右上角的 **AI 配置指导** 可以帮你解释当前配置项，不确定怎么填时可以用。
8. 全部确认无误后，点击页面底部的 **确定**。

:::warning 规格选不了通常是配额问题
如果**规格**卡片里没有可选的规格，或提示资源不足，一般是当前工作空间的配额不够。联系租户管理员调整配额，或先停掉其他不用的服务释放资源。
:::

### 做完你会看到什么

页面回到推理服务列表，多出一条新服务：

1. **运行状态**先显示 **已安装**，表示正在拉起容器；稍等片刻会变成 **健康**。
2. 点进这条服务，能看到 **概览、监控、日志、事件** 等页面。
3. **概览**里有访问地址、资源规格、创建时间。
4. **日志**可以看到服务启动过程的输出；**事件**里能看到镜像拉取、调度等信息。

### 卡住了看哪篇

- 部署失败、状态一直是「需关注」或「处理失败」：[推理服务](/rune/console/inference)
- 想进容器看文件、连 SSH：[开发服务](/rune/console/devenv)
- 术语不明白：[术语表](/guide/glossary)

## 阶段四：把自己的模型传上来

### 目标

把你自己训练的模型文件放进平台，让阶段三的推理服务能引用它。有两种放法，选一种即可。

### 做法 A：放进文件存储（适合大文件、模型权重）

> 创建和删除存储卷需要**租户管理员**角色。如果你看不到「创建存储卷」按钮，改用做法 B，或请租户管理员帮你创建。

1. 左侧菜单点击 **文件存储**。
2. 点击 **创建存储卷**。
3. 填写表单：
   | 表单项 | 怎么填 |
   | --- | --- |
   | 名称 | 小写字母、数字和连字符，首尾必须是字母或数字 |
   | 存储集群 | 选择你的集群提供的存储 |
   | 存储类 | 选择可用的存储类 |
   | 容量 | 例如 `20Gi`，按模型体积留足余量 |
   | 访问模式 | 按需要选 `ReadWriteOnce`、`ReadOnlyMany` 或 `ReadWriteMany` |
   | 描述 | 可留空 |
4. 点击 **创建**，等待提示「存储卷创建成功」。
5. 点进这块存储卷，在 **文件管理器** 里上传模型文件。
6. 如果模型在 HuggingFace、ModelScope 或魔哈 Hub 上，可以不手动上传：在存储卷里点击 **创建存储作业**，选择对应的类型和仓库地址，平台会在后台把文件拉进来。

### 做法 B：放进魔哈 Hub（适合要长期管理版本的模型）

1. 点击左上角的**产品与服务**，切换到魔哈 Hub。
2. 顶部点击 **模型库**。
3. 点击 **创建模型**，填写模型名称、可见性等信息并提交。
4. 进入模型仓库后上传文件，或用 Git 命令推送。
5. 之后回到智算平台部署推理服务时，在参数里引用这个模型即可。

### 做完你会看到什么

- 做法 A：在 **文件存储** 列表能看到存储卷，点进去的 **文件管理器** 里能看到你上传的文件。
- 做法 B：在魔哈 Hub 的 **模型库** 里能看到这个模型，并且有版本记录。

### 卡住了看哪篇

- 存储卷和存储作业：[文件存储](/rune/console/storage)
- 魔哈 Hub 的模型管理：[模型库](/moha/models)
- 上传下载的完整说明：[模型的上传](/moha/models/upload)

## 阶段五：微调与评测

### 目标

用自己的数据给现成模型「补课」（微调），再给结果打分（评测）。这两步都用和阶段三一样的部署流程，只是换模板。

### 微调

1. 左侧菜单点击 **训练与微调**，点击 **创建训练与微调**。
2. 在模板列表里选 **微调** 分类下的一个训练任务模板，点 **部署**。
3. 选择版本，填写名称、ID、描述。
4. 在**参数配置**里填训练相关参数，常见的有基座模型、训练数据集、学习率、训练轮数、规格。
5. 点 **确定**。回到列表能看到这条任务，状态先 **已安装**，之后进入 **运行中**。
6. 点进任务详情，在 **监控** 里查看训练指标，例如损失值、学习率、准确率、当前 Epoch。训练结束后状态变成 **已完成**。

### 评测

1. 左侧菜单点击 **模型评测**，点击 **创建模型评测**。
2. 选择一个评测引擎模板，点 **部署**。
3. 选择版本，填写名称、ID、描述，并在参数里指定要评测的模型和评测数据集。
4. 点 **确定**，等待任务完成。

:::tip 微调结果放哪
微调产出的模型文件通常先落在存储卷里，然后你可以把它注册到魔哈 Hub 做成一个带版本的模型，供后续部署使用。
:::

### 做完你会看到什么

- **训练与微调** 列表里能看到任务，进入 **运行中 → 已完成**。
- 任务详情能看到损失值等训练曲线。
- **模型评测** 列表里能看到评测任务与结果。

### 卡住了看哪篇

- 微调参数的完整说明：[训练与微调](/rune/console/finetune)
- 评测怎么配：[模型评测](/rune/console/evaluation)
- 实验结果对比：[指标](/rune/console/experiment)
