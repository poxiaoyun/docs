# 常见问题 FAQ

按主题分组。每条都写成「现象 → 可能原因 → 怎么办」，**怎么办**那一列是可以直接照做的动作或界面路径。

## 登录与账号

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 登录时突然出现验证码 | 平台要求二次确认，或此前密码错误次数较多 | 按提示拖动滑块，或输入图形里的字符，然后重新登录 |
| 登录后要求再输一次验证码 | 你的账号开启了多因素认证 | 打开手机上的验证器应用，填当前 6 位动态码 |
| 提示用户名或密码错误 | 大小写、空格输错 | 重新输入；多次失败仍不行就走「忘记密码」 |
| 忘记密码 | — | 登录页点 **忘记密码？**，填写账号绑定的**邮箱**后点 **发送**；平台会把重置密码链接发到邮箱，从邮件里点链接设置新密码 |
| 找不到注册入口 | 平台关闭了自助注册 | 联系平台管理员，请他在 BOSS 里创建账号 |

## 租户与工作空间

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 登录后被要求选租户 | 你属于多个租户 | 在列表里点你要进入的租户；只属于一个会自动跳过 |
| 租户列表是空的 | 你还没加入任何租户 | 在租户选择页注册新租户，或请管理员把你加进某个租户 |
| 首页提示「请选择区域和工作空间后查看概览数据」 | 还没选工作空间 | 在左侧菜单顶部选择器里先选集群，再选工作空间 |
| 工作空间下拉里没有可选项 | 这个集群下还没创建工作空间 | 点 **去创建工作空间** 新建一个 |
| 创建工作空间失败，提示未配置该集群的资源配额 | 租户在这个集群上还没有配额 | 联系租户管理员或平台管理员分配配额 |

## 部署与实例

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 参数里的**规格**卡片没有可选项 | 当前工作空间的配额不足，或没有可用算力 | 联系租户管理员调整配额；或先停掉其他不用的实例 |
| 状态一直是**已安装** | 正在拉取镜像或加载模型 | 进入实例详情的 **事件** 页，确认镜像拉取是否成功 |
| 状态是**需关注** | 部分容器没就绪 | 进 **日志** 页看错误信息，常见是端口或健康检查配置问题 |
| 状态是**处理失败** | 容器启动失败 | 进 **日志** 页查看，常见原因是显存不足、模型路径填错 |
| 容器反复重启 | 启动即崩溃 | 进 **日志** 页读最后几行错误，通常是模型文件缺失或版本不兼容 |
| 看不到「创建推理服务」按钮 | 你没有创建实例的权限 | 见[权限说明](/reference/permissions) |
| 想省算力但不想删服务 | — | 在实例列表点 **停止**，会释放计算资源、保留配置；要用时点 **启动** |

## 模型与存储

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 看不到 **创建文件存储** 按钮 | 创建存储卷需要租户管理员角色，普通成员和开发都看不到这个按钮 | 请租户管理员创建，或改用魔哈 Hub 存放模型 |
| 实例里访问不到存储卷里的文件 | 挂载路径和文件实际存放位置不一致 | 检查部署参数里配置的挂载路径，再对照文件管理器里的目录结构调整 |
| 模型文件太大，上传很慢或中断 | 浏览器上传大文件本身不稳定 | 在存储卷里用 **创建存储作业**，从 HuggingFace、ModelScope、魔哈 Hub 或 Git 拉取 |
| 想用外部网站上的公开模型 | 平台不能直接访问外部网络 | 用 **创建存储作业** 从 HuggingFace 或 ModelScope 拉取到存储卷或魔哈 Hub |
| 模型改了名字但部署里还是旧的 | 参数里引用的是老名字 | 回到部署参数里更新模型名或路径后重新部署 |

## 对话与接口调用

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 模型广场里没有可用模型 | 没有把模型接入渠道 | 联系平台管理员在 BOSS 里配置渠道 |
| 提示先创建 API 密钥 | 当前用户还没有密钥 | 进入 [聚合网关](/airouter/) → **API 密钥** → 创建 |
| 调用返回 `401` | 密钥错误或过期 | 检查请求头是否为 `Bearer 你的密钥`；必要时重新创建密钥 |
| 调用返回 `403` | 密钥没有这个模型的权限，或内容审查拦截 | 检查密钥可用的模型范围；换一个模型试 |
| 调用返回 `429` | 触发限速 | 在 **API 密钥** 里调大 RPM / TPM，或降低调用频率 |
| 回复不是逐字出现的 | 没有开启流式 | 请求体设 `"stream": true`，并带上 `Accept: text/event-stream` |
| 回复被截断 | `max_tokens` 太小 | 调大 `max_tokens` |
| 回复质量不理想 | 参数或提示词不合适 | 调低 `temperature`，并把角色和要求写进 `system` 消息 |
| 模型对比页刷新后内容没了 | 对比内容只保存在当前页面内 | 这是预期行为，重要结果请先复制出来 |

## 权限与界面

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 左侧菜单少了「工作台」和「可观测性」 | 你是成员角色 | 见[权限说明](/reference/permissions) |
| 某个按钮或菜单项看不到 | 当前角色没有该权限，入口被隐藏 | 对照权限表找出需要的角色，联系管理员调整 |
| 切换租户后按钮没有变化 | 权限在登录状态变化时才刷新 | 刷新一次页面 |
| 页面提示 `403` | 当前角色确实没有该操作权限 | 找租户管理员调整角色，重试无效 |
| 页面提示 `401` | 登录状态已过期 | 重新登录 |

## 本地开发与部署

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 安装依赖或启动失败，提示 Node 版本 | 本地 Node 版本过低 | 升级到 Node 20 及以上，并用 pnpm 安装依赖 |
| 页面能打开，但接口全部报错 | 本地开发使用代理转发到后端，代理地址不对 | 检查后端代理地址配置，见[构建与环境](/reference/build-and-env) |
| 想要 BOSS 版页面 | 默认构建只产出普通用户界面 | 用 BOSS 模式构建，见[构建与环境](/reference/build-and-env) |
| 本地登录用什么账号 | 本地默认连的是开发环境后端 | 用该开发环境的账号登录 |

## 还是解决不了

1. 先在[术语表](/guide/glossary)确认你遇到的词是什么意思。
2. 再查[权限说明](/reference/permissions)，排除权限问题。
3. 涉及接口的，对照 [API 概览](/reference/api-overview)检查地址和鉴权。
4. 仍无法解决时联系平台管理员，并附上：**问题截图、浏览器控制台报错（按 F12 打开 Console）、你的操作步骤**。
