## 账号与登录

### Q: 如何创建平台账号？

**A:** 有两种入口：

1. **自助注册**：登录页的注册入口指向 `/auth/sign-up`（`src/routes/sections/auth.tsx:35-42`）。注册表单字段为 `username`、`password`、`email`、`phone`、短信/邮件验证码 `code`，并需勾选协议（`src/auth/view/centered/centered-sign-up-view.tsx:147-184`），提交到 `POST /api/iam/register`（`src/services/iam.ts:32-36`）。
2. **管理员创建**：由平台管理员在 BOSS 后台创建账号。

> ⚠️ 注意: 注册入口的可见性由全局设置 `enableBossSignup` 控制（默认 `false`，`src/settings/global/settings-config.ts:16`）。在 Console 构建下注册入口始终显示；在 BOSS 构建下必须先开启该开关（`src/auth/view/centered/centered-sign-up-view.tsx:80-82`、`centered-sign-in-view.tsx:687`）。管理员创建账号的后台菜单路径在本文档的另一章节说明，此处暂未确认。

### Q: 登录时验证码什么时候才出现？

**A:** 登录页会根据登录接口返回的验证码配置动态展示。验证码通过 `GET /api/iam/login-captcha` 获取（`src/services/iam.ts:16-19`），`provider` 可能为：

| provider | 交互方式 |
|----------|---------|
| `Slider` | 拖动滑块拼图 |
| `Graphic` | 输入图形字符 |

触发条件包括登录被锁定（错误原因 `LoginLocked`）等场景（`src/auth/view/centered/centered-sign-in-view.tsx:282-312`）。

> ⚠️ 注意: 验证码的有效期由后端决定，前端代码中没有时限常量，暂未确认。

### Q: 忘记密码怎么办？

**A:** 登录页提供「忘记密码」入口，跳转到 `/auth/reset-password`。重置流程需要先通过 `POST /api/iam/send-code` 获取验证码（`src/services/account.ts:73-77`）。验证码的投递渠道与校验规则以后端为准，暂未确认。

### Q: 如何配置多因素认证（MFA）？

**A:** 相关接口已存在：`POST /api/iam/init-mfa` 初始化、`POST /api/iam/verify-mfa` 校验（`src/services/account.ts:44-54`）。

> ⚠️ 注意: 恢复码机制、绑定后的强制策略等在前端代码中无法确认，暂未确认。

### Q: 平台支持 SSO / LDAP 吗？

**A:** 登录配置接口 `GET /api/iam/login-config` 返回 `allowSignup` 与 `methods` 列表，`methods` 中的项可包含 `OAuth2`、`OIDC`、`SAML`、`OTP`、`WebAuthn` 等类型（`src/types/iam.ts:18-44`）。也就是说是否启用取决于部署时的登录配置。

> ⚠️ 注意: 具体支持哪些外部认证源、如何配置，属于后端/部署范畴，前端代码中无法确认。

## 会话与令牌

### Q: 登录会话是怎么保存的？

**A:** 会话令牌保存在名为 `user_session` 的 **Cookie** 中（`src/auth/authn/token.ts:3`）。控制台的 axios 实例**不会**注入 `Authorization` 头（`src/lib/axios.ts:21-28`），管理面接口靠浏览器自动携带该 Cookie 完成鉴权。

> ⚠️ 注意: 会话的有效期由后端下发，前端没有相关常量，暂未确认。过期后需重新登录。

### Q: API Key 与登录会话有什么区别？

**A:**

| 对比项 | 登录会话 | API Key |
|--------|---------|---------|
| 载体 | Cookie `user_session` | 字符串令牌（`apiKey` 字段） |
| 创建入口 | 登录后自动生成 | ChatApp → 我的 Token |
| 典型用途 | 控制台页面访问管理面接口 | 以 `Authorization: Bearer` 调用数据面对话接口 |
| 管理接口 | — | `GET /api/airouter/v1/me/tokens`（`src/services/api-key.ts:128-133`） |

### Q: 如何退出登录？

**A:** 调用 `POST /api/iam/logout`（`src/services/iam.ts:27-30`），前端随后清除 `user_session` Cookie（`src/auth/authn/token.ts:9-11`）。

## 租户与工作空间

### Q: 什么是租户？如何切换？

**A:** 租户是资源隔离单元。当前用户可访问的租户列表来自 `GET /api/iam/current/tenants`（`src/services/tenant.ts:6-9`）；登录后若属于多个租户，会进入租户选择页 `/auth/select-tenant`（`src/routes/sections/auth.tsx`）。

### Q: 怎么创建一个新租户？

**A:** 入口为 `/auth/regist-tenant`，表单只需 `name`、`email`、`phone` 三项（`src/auth/view/centered/centered-regist-tenant-view.tsx:37-41`），提交到租户注册接口。创建成功后会直接进入 Rune 仪表盘（同文件 `:71-79`）。

### Q: 工作空间在哪里创建？

**A:** 工作空间列表页为 `/rune/tenants/:tenant/workspaces`（`src/routes/paths.ts:539`）。创建操作挂在具体集群下：`/rune/tenants/:tenant/clusters/:cluster/workspaces?action=create`（`src/routes/paths.ts:542-543`）。也就是说创建工作空间需要先选定集群。

> ⚠️ 注意: 创建工作空间所需的角色，取决于[权限设计](./permissions)中推导出的 `workspace:*` 等权限；服务端是否另有校验，暂未确认。

### Q: 为什么有些按钮看不到？

**A:** 控制台用 `can(action, resource)` 判断权限并据此隐藏入口（`src/auth/authz/context.tsx:153-167`）。角色与权限的对应关系见[权限设计](./permissions)。需要更多权限时请联系管理员调整角色。

## ChatApp

### Q: 如何在模型体验里开始对话？

**A:** 模型体验页为 `/rune/chatapp/experience`。页面会先拉取当前用户的 API Key（`GET /api/airouter/v1/me/profile`），并默认使用第一个 Key 作为数据面令牌（`src/pages/chatapp/chat.tsx:114-117`）。若没有任何 Key，页面会引导先去[我的 Token](/rune/chatapp/token)创建（`src/pages/chatapp/chat.tsx:466-475`）。

### Q: 可以调哪些参数？

**A:** 参数面板中的字段、取值范围与默认值如下（`src/pages/chatapp/chat.tsx:59-77`、`src/pages/chatapp/components/chat-params.tsx`）：

| 参数 | 默认值 | 范围 / 步长 |
|------|:---:|------|
| `temperature` | `0.7` | `0` ~ `1.999`，步长 `0.1` |
| `topP` | `0.8` | `0.1` ~ `1.0` |
| `maxTokens` | `4096` | `0` ~ `32768`，步长 `10` |
| `systemPrompt` | 空 | 文本 |
| `stop` | 空 | 为空时提交 `null` |

深度思考默认开启；关闭时请求体中的 `reasoning_effort` 为 `'none'`，开启时为 `'high'`（`src/pages/chatapp/chat.tsx:169`）。

### Q: 流式响应不工作怎么办？

**A:** 对话请求使用 SSE（`Accept: text/event-stream`，`src/pages/chatapp/chat.tsx:141-145`）。排查方向：

1. 确认网络链路没有代理/WAF 中断长连接；
2. 确认后端渠道返回的响应体不是一次性 JSON（页面会区分处理，`src/pages/chatapp/chat.tsx:204-210`）；
3. 查看浏览器控制台是否有中断或跨域错误。

### Q: 请求被限速了怎么办？

**A:** 数据面按 API Key 限速，字段为 `rateLimitRPM` 与 `rateLimitTPM`。调到上限会返回 `429`。可在[我的 Token](/rune/chatapp/token)中调整这两个值；填 `0` 或留空表示该项不限制。

### Q: 调用统计在哪里看？

**A:** 在 ChatApp → 调用分析（路由 `/rune/chatapp/analysis`）。数据来自 `GET /api/airouter/v1/me/usage/dashboard`（`src/services/usage.ts:110-122`），页面默认展示当天范围，并每 30 秒自动刷新。

## 故障排查

### Q: 页面报 401 / 403？

**A:**

| 现象 | 可能原因 | 处理 |
|------|---------|------|
| `401` | 未登录或 Cookie 会话已过期 | 重新登录 |
| `403` | 当前角色无该操作权限 | 参考[权限设计](./permissions)，联系管理员调整角色 |

### Q: 模型对比页刷新后内容没了？

**A:** 对比页的对话内容保存在页面内存中，刷新后会清空，这是当前实现的预期行为。

### Q: 上传或下载类操作失败？

**A:** 不同模块的上传实现和大小限制由各自后端决定，前端代码中无法给出统一结论。

> ⚠️ 注意: 单文件大小上限、是否支持断点续传等，暂未确认。
