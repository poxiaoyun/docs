# 权限说明

界面上有些按钮你看得到，有些看不到；同一条菜单，同事有、你没有。这不是页面出错，而是**角色不同**。这篇讲清三件事：平台有哪几种角色、每种角色能做什么、为什么你的按钮会消失。

## 一句话结论

平台只有**三种角色**：`admin`（管理员）、`developer`（开发）、`member`（普通成员）。同一个角色加上不同的作用范围，才形成你常听到的「平台管理员 / 租户管理员 / 开发 / 普通成员」这几种身份。

## 三种角色能做什么

| 能力 | 平台管理员 | 租户管理员 | 开发 | 普通成员 |
| --- | :---: | :---: | :---: | :---: |
| 查看工作空间 | ✅ | ✅ | ✅ | ✅ |
| 创建 / 编辑 / 删除工作空间 | ✅ | ✅ | ❌ | ❌ |
| 查看实例（推理服务、微调、开发环境等） | ✅ | ✅ | ✅ | ✅ |
| 创建 / 编辑 / 删除 / 启停实例 | ✅ | ✅ | ✅ | ❌ |
| 查看镜像 | ✅ | ✅ | ✅ | ✅ |
| 创建 / 编辑 / 删除镜像 | ✅ | ✅ | ❌ | ❌ |
| 查看模板 | ✅ | ✅ | ✅ | ❌ |
| 创建 / 编辑 / 删除模板 | ✅ | ✅ | ❌ | ❌ |
| 管理成员 | ✅ | ✅ | ❌ | ❌ |
| 管理配额 | ✅ | ✅ | ❌ | ❌ |
| 创建 / 删除存储卷 | ✅ | ✅ | ❌ | ❌ |
| 访问 BOSS 管理门户 | ✅ | ❌ | ❌ | ❌ |

:::tip 四句话记住差异
- **平台管理员**：什么都能做，包括进 BOSS。
- **租户管理员**：本租户内什么都能做，但进不了 BOSS。
- **开发**：能建工作空间以外的一切「跑起来的东西」——实例随便建、随便删，但管人、管配额、管存储卷要管理员。
- **普通成员**：只能看，不能改。
:::

## 角色和「作用范围」怎么组合

你会听到四种称呼，其实只有三种角色。区别在于角色被分配在**哪个范围**上：

| 你听到的称呼 | 实际是什么 | 看到哪套界面 |
| --- | --- | --- |
| **平台管理员** | 没有限定租户和工作空间的 `admin` | BOSS |
| **租户管理员** | 限定在某个租户内的 `admin` | 智算平台 |
| **开发** | 限定在某个租户内的 `developer` | 智算平台 |
| **普通成员** | 限定在某个租户内的 `member` | 智算平台 |

由此可以推出：**同一个人可以同时是多个租户的管理员**，在 A 租户是管理员、在 B 租户是普通成员。你当前的权限，取决于你**当前所在的那个租户**。

## 权限是怎么判断的

平台把你的角色翻译成一串权限条目，每条写成「资源:操作」的形式，例如：

| 权限条目 | 含义 |
| --- | --- |
| `instance:create` | 可以创建实例 |
| `instance:list` | 可以查看实例列表 |
| `workspace:get` | 可以查看某个工作空间的详情 |
| `member:*` | 可以对该资源做任何操作 |
| `*:*` | 可以做任何事（只有平台管理员有） |

判断时的顺序是：

1. 如果拥有 `*:*`，直接放行。
2. 如果拥有「这个资源:*」，该资源下任意操作都放行。
3. 否则精确匹配「资源:操作」。

所以平台管理员之所以什么都行，是因为他被赋予了 `*:*`。

:::info 这套权限在页面内生效
页面在渲染菜单和按钮前会先检查权限，没权限的入口**直接不显示**。这是为了让你不点进死胡同，而不是隐藏信息。当前版本的角色和权限由页面根据你的角色推导得出，登录后自动获取。
:::

## 没有权限会看到什么

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 左侧菜单少了「工作台」「可观测性」两组 | 你是**普通成员**角色 | 需要操作就走申请流程 |
| 「创建推理服务」之类的按钮不见了 | 你没有对应的创建权限 | 见下面的申请方式 |
| 「成员」「配额」入口看不到 | 只有管理员能管成员和配额 | 找租户管理员处理 |
| 页面提示 `403` | 当前角色没有该操作的权限 | 联系管理员调整角色 |
| 页面提示 `401` | 登录状态过期了，不是权限问题 | 重新登录 |
| 切换租户后按钮没变化 | 权限在登录状态变化时才刷新 | 刷新一次页面 |

:::warning 权限不足不要反复重试
`403` 是权限判定结果，刷新或重试都不会变。正确做法是确认自己需要哪个角色，再找有权限的人调整。
:::

## 我需要什么权限才能做某件事

| 我想做这件事 | 需要的角色 |
| --- | --- |
| 部署推理服务、跑微调、开开发环境 | 开发及以上 |
| 只是查看实例状态和日志 | 普通成员及以上 |
| 创建工作空间 | 租户管理员及以上 |
| 创建工作空间成员、分配角色 | 租户管理员及以上 |
| 调整工作空间配额 | 租户管理员及以上 |
| 创建 / 删除存储卷 | 租户管理员及以上 |
| 纳管集群、划分资源池、定义规格、给租户分配额 | 平台管理员 |
| 配置大模型网关渠道、内容审查、查看全局调用日志 | 平台管理员 |

## 怎么申请权限

1. 先确认你要做的是哪件事，对照上表找出需要的角色。
2. 联系**当前的租户管理员**（工作空间里的成员、配额、存储卷都由他管）。
3. 如果是平台级操作（集群、资源池、平台设置），联系**平台管理员**。
4. 拿到新角色后，**刷新页面**让权限生效。
