# 数字孪生

**数字孪生** 是 BOSS 里的一个产品入口页：它自己不做三维渲染，只负责告诉你「你这套平台有没有开通数字孪生」，并在有授权时把你送进真正的三维机房系统。

读完这页，你能看懂页面上的授权状态、知道按钮什么时候能点、进不去时该去哪里问。

:::tip 三句话理解这一页

- 这一页是**门口**，不是**房间**：真正的三维视图在独立部署的数字孪生系统里。
- 页面上那个彩色小标签就是**门禁状态**：已授权 / 未授权 / 校验中 / 校验失败。
- 只有 **已授权** 时，「进入数字孪生系统」按钮才可点。

:::

## 先认识几个词

| 名词 | 通俗解释 |
| --- | --- |
| 数字孪生 | 把真实机房做成一份可交互的三维模型，机柜、服务器、线缆的位置都能在屏幕上点开 |
| 授权（License） | 平台买到的产品许可；数字孪生是其中一个独立产品，需要单独开通 |
| 进入数字孪生系统 | 跳转到三维系统所在的地址，通常和 BOSS 同一个站点、路径在 `/twin/` 下 |

## 开始之前

- 需要 **系统管理员** 账号。
- 平台已经为 **数字孪生** 这个产品开通授权；没有授权也能打开本页，只是进不去。
- 想确认授权到期时间，见 [许可证](/boss/settings/license)。

## 打开这一页

顶部导航点击 **数字孪生**。

## 页面上有什么

| 区块 | 内容 |
| --- | --- |
| 标题行 | 标题 **RUNE 数字孪生系统**，右侧是授权状态标签 |
| 右上角按钮 | **进入数字孪生系统**，授权通过且不在校验时才能点 |
| 主介绍卡 | 左侧讲这套系统解决什么问题、三个能力亮点；右侧是三维机房视图的产品截图 |

三个能力亮点分别是 **三维机房可视化**、**设备拓扑追踪**、**硬件状态监控**：分别回答「机房长什么样」「这台机器接在哪」「现在温度功耗正常吗」。

## 看懂授权状态

标题旁的标签只有四种取值：

| 标签 | 含义 | 按钮能点吗 |
| --- | --- | --- |
| 已授权 | 这套平台已经买到数字孪生，且许可在有效期内 | 能点 |
| 未授权 | 没开通，或许可已失效 | 不能点 |
| 校验中 | 正在向平台查询授权结果 | 不能点，按钮显示 **正在校验进入权限…** |
| 校验失败 | 这次没问到结果（网络或许可服务异常） | 不能点，页面顶部给一条可重试的提示 |

:::info 校验失败不等于没开通
「校验失败」只说明这次没问到答案，页面不会替你判定成「没买」。点顶部提示里的重试，或刷新页面再看。
:::

## 进入数字孪生系统

1. 确认标题旁的标签是 **已授权**。
2. 点右上角 **进入数字孪生系统**。
3. 平台会**再校验一次**授权，然后跳转到三维系统。
4. 校验通过就直接进去了；没通过会停留在本页，并在页面顶部提示原因。

:::info 为什么点进去还要再校验
按钮是否可点是页面根据打开时的状态算出来的。如果这一页开了很久、期间许可到期，直接放行就会「点进去又被踢出来」。多问一次是为了让你在门口就知道结果。
:::

## 结果确认

| 你想确认的事 | 去哪里看 |
| --- | --- |
| 平台有没有开通 | 本页标题旁的标签是不是 **已授权** |
| 许可什么时候到期 | [许可证](/boss/settings/license) 里的记录 |
| 三维系统真的能打开 | 点 **进入数字孪生系统** 后地址跳到 `/twin/`，页面出现三维机房 |

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 标签是 **未授权**，按钮点不动 | 平台没有为数字孪生开通许可 | 到 [许可证](/boss/settings/license) 确认，联系商务开通后刷新本页 |
| 标签是 **校验失败** | 网络不通，或许可服务暂时不可用 | 点顶部提示里的重试；仍失败就检查网络后刷新 |
| 点了进入却没反应 | 授权在这期间失效，或校验没通过 | 看页面顶部的提示；确认标签是否已变成 **未授权** |
| 跳过去是空白页 | 数字孪生系统本身没部署好，或地址配错 | 这不是本页的问题，联系平台实施确认三维系统的部署地址 |
| 想看三维系统里某台机器 | 本页只有入口 | 进入系统后按机房 → 机柜 → 服务器逐级点开 |
