# 租户管理

**租户**就是「一家公司在平台上的独立账号空间」。一家公司开一个租户，这家公司的成员、算力配额、工作空间都装在租户里，和其他公司互不干扰。你在这里创建租户、维护租户资料、启用或禁用租户，并把成员加进来。

读完这页，你能完成：建一个租户、在创建成功页走完后续步骤、加成员、改资料与镜像推送配置、启用或禁用租户。

:::tip 用一个类比理解
把租户想成**一栋独立的办公楼**：成员是楼里的人，配额是这栋楼每月能用的水电额度，工作空间是楼里的一间间办公室。楼与楼之间互不打扰，你作为平台管理员，负责把楼盖好、把水电额度批下来、把门禁卡发给人。
:::

## 开始之前

- 你需要能登录 BOSS 的**系统管理员**账号。
- 建议先确认平台上**至少有一个集群**。没有集群的话，创建租户后无法立刻走「配置集群」这一步。
- 配额和工作空间**不在这一页**：它们在集群详情里的 **租户资源**，见[租户资源与配额](/boss/rune-admin/tenants)。

## 先弄清这几个词

| 名词 | 通俗解释 |
| --- | --- |
| 租户 | 一家公司的独立账号空间，成员和资源的归属单位 |
| 成员 | 加入了某个租户的用户，带着一个角色 |
| 角色 | 这个人在租户里能干什么（管理员 / 开发者 / 成员） |
| 集群开通 | 允许这个租户在某个集群上使用资源的前置关系 |
| 配额 | 这个租户在某个集群上最多能用多少算力 |
| 工作空间 | 租户内部再细分的协作单元，同事之间共享 |

## 租户列表里能看到什么

进入 **账户管理 → 租户管理**，列表有以下几列：

| 列 | 说明 |
| --- | --- |
| 名称 | 租户头像、租户名称（可点击进入详情）、名称下方的灰色小字是租户 ID |
| 邮箱 | 租户的管理联系邮箱 |
| 成员数量 | 这个租户里当前有多少成员 |
| 状态 | **激活**（绿色）或 **禁用**（红色） |
| 创建时间 | 租户创建的时间 |

每行右侧可以**编辑**这个租户，或者对它执行**禁用 / 激活**。

![租户管理列表：名称、邮箱、成员数量、状态、创建时间](/assets/screenshots/boss/tenant-list-01.png)

列表就是这样一页表格，只列五个字段。邮箱那列在这里已经做了模糊处理——真实页面上显示的是完整地址，截图会随文档一起公开，所以涉及个人信息的列都先抹掉。

## 新建一个租户

1. 进入 **账户管理 → 租户管理**。
2. 点击右上角的 **添加租户**。
3. 在表单里填写下面这些内容。
4. 点击 **确定**。

| 表单项 | 怎么填 | 说明 |
| --- | --- | --- |
| 名称 | 例如 `示例科技` | 必填。租户在界面上显示的名字，可以写中文 |
| ID | 不用手动填 | 必填。会根据「名称」自动生成（中文会转成拼音），只允许小写字母、数字和连字符，并且必须以小写字母开头。想自己指定，点那一行右侧的铅笔图标手动改 |
| 邮箱 | 例如 `admin@example.com` | **可以留空**；填了就必须符合邮箱格式 |
| 手机号码 | 例如 `13800000000` | **可以留空**；填了就必须是 6–16 位数字 |
| 描述 | 可留空 | 选填。补充说明 |

:::warning 租户 ID 创建后不能改
ID 是租户在系统里的唯一标识。创建时可以手动指定，但**创建完成后就锁定了**，之后编辑租户时改不了。所以如果打算自己指定，请在创建前想好。
:::

![「添加租户」表单：名称、ID、邮箱、手机号码、描述](/assets/screenshots/boss/tenant-create-01.png)

表单只有五项：**名称**、**ID**（不填会按名称自动生成）、**邮箱**、**手机号码**、**描述**。邮箱和手机号码都可以留空。

### 创建成功后会发生什么

点 **确定** 后不会停在表单，而是跳到一个成功页，标题是「**租户 xxx 创建成功**」，说明文字是「租户身份已创建。接下来可选择集群完成开通并配置配额、规格授权与工作空间。」，并提供三个按钮：

| 按钮 | 点了去哪 |
| --- | --- |
| 配置集群 | 进入为该租户开通集群、配配额与规格授权的流程 |
| 添加成员 | 进入为该租户添加成员的页面 |
| 返回列表 | 回到租户列表 |

三个按钮**始终都会出现**，和平台上有没有集群无关。

:::info 创建时看不到头像上传
**头像**和**镜像推送配置**这两项只在**编辑**租户时才会出现。创建时不用管，想补充的话创建完成后进入编辑页再设置。
:::

## 创建后还要做什么

新租户只是一个空壳，真正能用起来还需要三步：

1. **给它分配管理员和成员**：在租户列表点租户名称进入租户，切到 **成员** 页签，点 **添加成员**，选用户、给角色。
2. **给它开通集群**：进入 **智算平台 → 租户集群**，在这个租户那一行点 **在此集群开通**。见[租户集群](/boss/rune-admin/tenant-clusters)。
3. **给它分配算力配额**：进入该集群详情 → **租户资源** → 这个租户 → **配额**，创建配额。见[租户资源与配额](/boss/rune-admin/tenants)。

## 编辑租户

1. 进入 **账户管理 → 租户管理**。
2. 在目标租户那一行点击 **编辑**（或点租户名称进入后，在 **基本信息** 页签里逐项改）。

编辑页分成两块。

### 基本信息

| 表单项 | 能不能改 | 说明 |
| --- | --- | --- |
| 头像 | 能 | 只有编辑页有。单张最大 3 MB，上传前可以缩放和旋转裁剪 |
| 名称 | 能 | 中文可以 |
| ID | **不能** | 编辑时锁定，铅笔图标不再出现 |
| 邮箱 | 能 | 可以留空；填了要符合邮箱格式 |
| 手机号码 | 能 | 可以留空；填了要是 6–16 位数字 |
| 描述 | 能 | 多行文本 |

### 镜像推送配置

同样是编辑页才有。它决定这个租户的成员往镜像仓库推送镜像时的行为：

| 表单项 | 怎么填 | 说明 |
| --- | --- | --- |
| 允许直接推送未预创建的镜像 | 默认**开启** | 开启后，成员可以直接 `docker push`，系统会自动创建对应的镜像记录；关闭后，必须先在界面上创建好镜像才能推送 |
| 自动创建镜像的默认可见范围 | 默认 **个人** | 仅在上面开关开启时生效。可选 **个人**（仅推送者本人、租户管理员及授权成员可访问）、**租户内**（当前租户的成员都能访问）、**公开**（所有能访问魔哈Hub 的用户都能查看和拉取） |

改完点击 **确定** 保存。

## 启用 / 禁用租户

1. 进入 **账户管理 → 租户管理**。
2. 在目标租户那一行打开操作菜单，点击 **禁用**（对已激活的租户）或 **激活**（对已禁用的租户）。
3. 弹出确认框后点击确认。

状态列会立刻在 **激活** 和 **禁用** 之间切换。

:::warning 禁用前请想清楚
禁用会影响这个租户下所有成员的使用，而且**不会自动恢复**——想让租户重新可用，必须再手动点一次 **激活**。操作前请先确认该租户暂时不需要正常使用，并告知对方。
:::

:::info 界面上没有「删除租户」
租户列表没有删除入口。停止一个租户的使用，做法是**禁用它**；确实要彻底清空，请先移除成员，再保持禁用。
:::

## 租户详情：基本信息与成员

点击租户名称进入后，只有两个页签：**基本信息** 和 **成员**。

### 基本信息

一栏式资料卡，逐行显示 **头像**、**ID**、**租户名称**、**邮箱**、**手机号码**、**创建时间**。**ID** 是只读的租户标识（地址栏里出现的也是它）；租户名称、邮箱、手机号码每行右侧都有 **编辑**，点开填新值即可就地修改。

![租户详情「基本信息」页签：头像、ID、租户名称、邮箱、手机号码、创建时间，名称/邮箱/手机号码每行右侧「编辑」](/assets/screenshots/boss/iam-tenant-detail-01.png)

:::info 这里没有配额和工作空间
配额、规格授权、工作空间都在**集群维度**下，请到 **智算平台 → 集群管理** 点进集群，再从 **租户资源** 进入这个租户查看。
:::

### 成员

成员列表有 **用户名**、**邮箱**、**角色**、**加入时间** 四列。每行可以 **编辑**（只改角色）或 **删除**；勾选多行后可以批量删除，删除前都会弹确认框。

![租户成员列表：用户名、邮箱、角色、加入时间](/assets/screenshots/boss/tenant-members-01.png)

截图里三种角色都出现了，分别是 **管理员**、**开发者**、**成员**。

### 把成员加进租户

1. 进入 **账户管理 → 租户管理**，点击目标租户的名称进入。
2. 切到 **成员** 页签。
3. 点击右上角的 **添加成员**。
4. 填写成员信息：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 用户 | 在输入框里输入用户名搜索并选中 | 必填。只能从已创建的用户里选；编辑已有成员时这一项不能再改 |
   | 角色 | 从下拉里选一个 | 必填。可选项由平台后台返回，常见的有 **管理员**、**开发者**、**成员** |

5. 点击 **确定**，页面回到成员列表。

:::tip 至少留两个管理员
现实里总会遇到有人休假或离职。建议每个租户至少配 2 名管理员，避免唯一的管理员不可用时没人能接手。
:::

## 结果确认

| 你想确认的事 | 去哪里看 |
| --- | --- |
| 租户建好了 | **账户管理 → 租户管理** 列表里出现该租户，状态显示 **激活** |
| 成员加对了 | 进入该租户 → **成员** 页签，能看到这个人及他的角色 |
| 集群开通了吗 | **智算平台 → 租户集群**，该租户的「已开通集群」里能看到集群 |
| 配额批下来了 | 集群详情 → **租户资源** → 该租户 → **配额** |

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| ID 那一行提示格式不对 | 名称里没有可用的英文字母或数字 | 手动点铅笔图标指定一个以字母开头的 ID |
| 想改租户 ID | 不支持 | 创建后 ID 不可修改 |
| 添加成员时搜不到人 | 这个用户还没创建 | 先到 **账户管理 → 用户管理** 创建用户 |
| 找不到配额、工作空间 | 它们在集群维度下 | 到 **智算平台 → 集群管理** 进集群 → **租户资源** |
| 创建成功页上的「配置集群」点了没集群可选 | 平台上还没有已上线的集群 | 先在 **集群管理** 接入并上线集群 |
