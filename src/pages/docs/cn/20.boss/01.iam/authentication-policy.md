# 认证策略

认证策略决定**登录页长什么样、用户怎么进来**：能不能自己注册、有哪几种登录方式、密码最少几位、要不要强制二次验证、登录时要不要填验证码。它管的是所有人，改一次全平台生效。

读完这页，你能完成：打开或关闭自助注册、选择可用的登录方式、设置密码强度、把身份验证器设为可选或必需、配置登录验证码。

:::tip 这一页是「门禁规则」，不是「账号名单」
具体有哪些账号在 **用户管理**，谁属于哪个组织在 **租户管理**。这一页只定规则：门开不开、有几把钥匙、钥匙要多复杂。
:::

## 这一页管什么

进入 **账户管理 → 系统管理 → 认证策略**，页面是四张设置卡，每张卡右上角各有一个 **编辑**：

| 设置卡 | 管什么 | 编辑后影响谁 |
| --- | --- | --- |
| 登录与注册 | 自助注册、密码登录、邮箱验证码登录、短信验证码登录 | 登录页与注册页出现的入口 |
| 密码规则 | 密码最小长度、是否必须含大小写和数字、是否必须含特殊字符 | 用户设置或修改密码时的校验 |
| 多因素认证 | 身份验证器是「可选」还是「必需」 | 所有用户登录时是否要二次验证 |
| 登录验证码 | 是否出验证码、图形还是滑块、长度、有效期、滑块容差 | 登录页的验证码区域 |

每张卡下面有一句摘要，用一句话告诉你当前设置，例如「本地登录方式已关闭」「最小长度：8」。

![认证策略页：登录与注册、密码规则、多因素认证、登录验证码四张卡，各带编辑入口](/assets/screenshots/boss/auth-policy-01.png)

## 开始之前

- 你需要**系统管理员**账号。
- 改登录方式前，先确认**至少还有一种能用的登录途径**。
- 想开「邮箱验证码登录」或「短信验证码登录」，必须先在[邮件服务](/boss/iam/email-providers)或[短信服务](/boss/iam/sms-providers)里配好带**登录**用途的服务。
- 想开「开放注册」，还要确保有服务承担**注册**用途，否则登录页不会出现注册入口。

## 登录与注册

点第一张卡的 **编辑**，弹窗里有四个开关：

| 开关 | 打开后 | 关闭后 |
| --- | --- | --- |
| 开放注册 | 平台把可用的注册通道下发给登录页，登录页按收到的通道渲染注册方式（邮箱注册、手机号注册） | 登录页不出现注册入口，账号只能由管理员在 **用户管理** 里创建 |
| 密码登录 | 用户可以用用户名 + 密码登录 | 登录页隐藏密码登录表单 |
| 邮箱验证码登录 | 用户可以用邮箱收验证码登录 | 隐藏邮箱验证码登录 |
| 短信验证码登录 | 用户可以用手机号收验证码登录 | 隐藏短信验证码登录 |

弹窗里在「邮箱验证码登录」「短信验证码登录」下方各有一个链接，分别直达 **邮件服务** 和 **短信服务**，在新窗口打开，方便你当场去配发送服务。

:::info 「开放注册」是怎么生效的
这不是一个「登录页直接读开关」的设置。打开它以后，平台会把**当前可用的注册通道**下发给登录页；登录页只看收到了哪些通道——一个通道都没有，就不显示注册入口。所以「开关打开了但注册按钮没出现」通常是**没有配注册用途的发送服务**。
:::

:::info 和第三方认证的关系
第三方认证页面上的 **允许第三方注册** 只有在这张卡的 **开放注册** 打开时才有效。全局注册关掉后，走第三方登录只能登录已有账号，不能新建账号。见[第三方认证](/boss/iam/identity-providers)。
:::

:::warning 四个开关不要全关
密码登录、邮箱验证码登录、短信验证码登录全部关掉后，用户就没有任何本地登录途径；此时只能靠第三方认证登录，一旦第三方配置有问题，管理员也进不来。改之前先确认还有一条可用途径。
:::

## 密码规则

点第二张卡的 **编辑**：

| 设置项 | 可选值 | 说明 |
| --- | --- | --- |
| 密码最小长度 | **不附加长度限制** / **6** / **8** | 默认不附加限制；选 6 或 8 后，短于该长度的密码会被拒绝 |
| 必须包含大小写字母和数字 | 开关 | 打开后，密码里必须同时有大写字母、小写字母和数字 |
| 必须包含特殊字符 | 开关 | 打开后，密码里必须至少有一个特殊字符（如 `!` `@` `#`） |

摘要行会把当前规则拼成一句话，例如「最小长度：8，必须包含大小写字母和数字」。

:::info 只对本地密码生效
这条规则管的是平台自己保存的密码。通过第三方认证登录的用户，密码复杂度由对方系统决定，这里管不到。
:::

## 多因素认证

点第三张卡的 **编辑**，只有一个下拉 **身份验证器要求**：

| 选项 | 含义 |
| --- | --- |
| 可选 | 用户可自行绑定身份验证器；已绑定的用户登录时仍需完成验证。 |
| 必需 | 所有用户必须绑定身份验证器，登录时需完成验证；未绑定的用户须先完成绑定，且不能解除绑定。 |

选 **必需** 前请注意：这是全平台强制的，已绑定的人也不能解绑。如果用户把验证器删了，只能由你用管理员身份重置或协助恢复。

:::warning 改成「必需」会让未绑定的用户下次登录被拦住
上线前先通知用户完成绑定，并给一个过渡期（例如先发公告，再切「必需」）。
:::

## 登录验证码

点第四张卡的 **编辑**：

| 设置项 | 可选值 / 范围 | 说明 |
| --- | --- | --- |
| 触发规则 | **关闭** / **每次登录** | 选 **关闭** 时，下面的形式、长度等都不生效 |
| 验证码形式 | **图形** / **滑块** | 选图形时出现「验证码长度」；选滑块时出现「滑块容差（像素）」 |
| 验证码长度 | 数字 | 仅 **图形** 形式出现，指图形验证码的字符数 |
| 有效期（秒） | 数字 | 验证码的有效时间，过期要重新获取 |
| 滑块容差（像素） | 数字 | 仅 **滑块** 形式出现，指允许的像素误差 |

字段会随「验证码形式」显隐，换形式后另一组字段就消失，不用管它。

## 结果确认

| 你想确认的事 | 去哪里看 |
| --- | --- |
| 某张卡保存成功了 | 卡片右上角会给出保存成功提示，摘要行变成新值 |
| 登录方式变了 | 退出登录，打开登录页看有哪几个登录入口 |
| 注册入口出不出现 | 登录页上是否有「注册」；没有就回去检查「开放注册」与注册用途 |
| 密码规则生效了 | 让一个测试账号改密码，故意填短密码，看是否被拒绝 |

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 打开了「邮箱验证码登录」，登录页还是没有 | 没有配「登录」用途的邮件服务 | 到[邮件服务](/boss/iam/email-providers)把某个服务的用途勾上 **登录** |
| 打开了「开放注册」，注册入口还是不出现 | 没有服务承担「注册」用途 | 给邮件或短信服务勾上 **注册** 用途 |
| 第三方登录进去后提示不能注册 | 全局「开放注册」没开 | 先在本页打开 **开放注册** |
| 用户说密码明明够长还是被拒 | 还开了「必须包含大小写字母和数字」或「必须包含特殊字符」 | 按实际规则提示用户，或调整规则 |
| 用户被强制要求绑定验证器 | 多因素认证设成了 **必需** | 属预期行为；需要放开就改回 **可选** |
