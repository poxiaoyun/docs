# 用户管理

**用户**就是「一个人在平台上的账号」。人有了账号才能登录智算平台，才能被加进某个租户。你在这里创建账号、改资料、重置密码，也可以删除账号。

:::tip 一句话提醒
用户管理只管**账号本身**（用户名、邮箱、手机号、密码）。一个人「在哪个租户、是什么角色」要在**租户**里设置，见下方「怎么改用户角色」。
:::

## 开始之前

- 你需要能登录 BOSS 的管理员账号。
- 创建用户时**不需要你想密码**，系统会自动生成一个初始密码。

## 用户和角色是什么关系

| 名词 | 通俗解释 |
| --- | --- |
| 用户 | 一个平台账号，对应一个人 |
| 租户 | 一个组织（公司/团队）的独立空间 |
| 成员 | 这个用户加入某个租户后的身份 |
| 角色 | 这个人在**这个租户里**能干什么 |

关键点：**角色是挂在「成员」上的，不是挂在「用户」上的**。同一个用户可以在 A 租户当管理员、在 B 租户只是普通成员。所以你找不到「给用户设角色」的地方，这是正常的。

## 用户列表里能看到什么

进入 **账户管理 → 用户管理**，列表有以下几列：

| 列 | 说明 |
| --- | --- |
| 用户名 | 头像、用户名（可点击进入用户详情）、用户名下方的灰色小字是昵称 |
| 邮箱 | 用户的联系邮箱 |
| 手机号码 | 用户的联系电话 |
| 启用多因素认证 | 显示 **是** 或 **否**，表示这个人有没有开启多因素认证 |
| 创建时间 | 账号创建的时间 |

列表右上角的 **添加用户** 用来新建账号。顶部有搜索框，输入关键词可以筛选用户；列表支持翻页。

每行右侧可以**编辑**资料、**重置密码**、**删除**账号；勾选多行可以**批量删除**。

![用户管理列表：用户名、邮箱、手机号码、启用多因素认证、创建时间](/assets/screenshots/boss/user-list-01.png)

用户列表只有五列。注意 **用户名** 一列是上下两行的：上行的短名用于登录，下行的 `Nick` 是显示用昵称。**启用多因素认证** 显示「否」表示该用户还没绑定 MFA。邮箱与手机号码两列已做模糊处理。

## 新建用户

1. 进入 **账户管理 → 用户管理**。
2. 点击右上角的 **添加用户**。
3. 在表单里填写下面这些内容。

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 用户名 | 例如 `zhangsan` | 必填。登录用的唯一标识，**创建后不能修改** |
   | 昵称 | 例如 `张三` | 选填。中文名、显示名都可以 |
   | 邮箱 | 例如 `zhangsan@example.com` | 必填。要符合邮箱格式 |
   | 手机号码 | 例如 `13800000000` | 必填。要符合手机号格式 |

4. 点击 **确定**。

![「添加用户」表单：用户名、昵称、邮箱、手机号码](/assets/screenshots/boss/user-create-01.png)

新建用户的表单只有四项：**用户名**（登录用，必填）、**昵称**、**邮箱**（必填）、**手机号码**（必填）。建完之后系统会生成初始密码，按本节说的方法交给本人。

### 把初始密码交给本人

创建成功后，表单上方会出现一条绿色提示，里面写着：

- **您的用户名为** xxx
- **您的随机密码为** xxx（右侧有复制按钮）
- 请务必妥善保存！

:::warning 密码只在此时显示一次
这个初始密码**只在这里显示**，离开页面后就看不到了。请立刻点复制按钮，通过安全的方式（例如当面告知、单独的加密渠道）发给本人，并提醒他首次登录后尽快修改密码。
:::

目前**不支持**批量创建或导入用户，一次只能建一个；批量删除是支持的。

## 重置密码

当用户忘记密码时：

1. 进入 **账户管理 → 用户管理**。
2. 在目标用户那一行打开操作菜单，点击 **重置密码**。
3. 弹出确认框后点击 **确定**，系统会生成一个新密码。
4. 新密码显示在对话框里，点旁边的复制按钮复制，然后发给本人。

:::warning 重置会立即让旧密码失效
重置后旧密码马上不能用，用户必须用新密码登录。新密码同样**只显示这一次**，请当场复制保存。如果用户已经登录着，建议提醒他重新登录一遍。
:::

## 编辑用户资料

1. 进入 **账户管理 → 用户管理**。
2. 在目标用户那一行点击 **编辑**。
3. 修改内容：

   | 表单项 | 能不能改 | 说明 |
   | --- | --- | --- |
   | 用户名 | **不能** | 输入框是灰的并带一把锁的图标 |
   | 昵称 | 能 | — |
   | 邮箱 | 能 | 要符合邮箱格式 |
   | 手机号码 | 能 | 要符合手机号格式 |

4. 点击 **确定** 保存。

![租户成员列表：用户名、邮箱、角色、加入时间](/assets/screenshots/boss/tenant-members-01.png)

角色的真正落点在 **租户成员** 页签，不在用户列表。上图这一列就是本节要讲的 **角色**；截图里三种角色都出现了，分别是 **管理员**、**开发**、**普通成员**。

## 怎么改用户角色

角色要在租户里改，有两条路：

**方式一：从租户进**
1. 进入 **账户管理 → 租户管理**。
2. 点击目标租户的名称进入。
3. 左侧切到 **成员** 页签，找到这个用户。
4. 点击该行的 **编辑**，改 **角色**，然后点 **确定**。

**方式二：从用户进**
1. 进入 **账户管理 → 用户管理**，点击用户名进入 **用户详情**。
2. 在 **所属租户与角色** 卡片里找到对应的租户。
3. 点击该行最右侧的眼睛图标，会直接打开这个人**在这个租户里**的成员编辑页，改角色后保存。

如果这个卡片显示「该用户暂未加入任何租户」，说明他还没有被加进任何租户，请按上面的方式一添加成员。

## 每个角色能做什么

界面上会看到的角色名和差别如下：

| 角色 | 能做什么 |
| --- | --- |
| 管理员 | 在智算平台里能看到并使用 **工作台** 和 **可观测性** 两组菜单，包括推理服务、训练与微调、开发服务、应用实例、我的模板、文件存储、指标、日志、模型评测 |
| 开发 | 和「管理员」一样，能看到并使用上面这两组菜单 |
| 普通成员 | **看不到** 上面这两组菜单，只能使用其余页面（例如模型广场、数据广场） |

:::info 还有别的角色名
给成员选角色时，下拉里的选项由平台后台返回。你可能会看到「管理员」「普通成员」「开发」之外的名字，具体以你在 **成员** 页面看到的选项为准。
:::

## 停用账号

用户账号**没有**「启用 / 禁用」开关，列表里也没有「状态」列。如果你想停掉某个人的使用权限，只能二选一：

| 做法 | 效果 | 适用场景 |
| --- | --- | --- |
| 删除用户 | 账号被彻底删除，**无法恢复** | 离职、确定不再使用 |
| 把他从租户里移除 | 账号还在，但不再属于该租户，进不去租户里的资源 | 只想切断他在某个租户里的权限 |

## 删除用户

1. 进入 **账户管理 → 用户管理**。
2. 在目标用户那一行点击 **删除**；或勾选多个用户后在工具栏点击 **批量删除用户**。
3. 弹出确认对话框，确认后账号即被删除。

:::warning 删除不可恢复
删除后这个账号就找不回来了。删除前请先到该用户的 **用户详情** 页确认他属于哪些租户，判断会不会影响到正在运行的业务。
:::

## 结果确认

| 你想确认的事 | 去哪里看 |
| --- | --- |
| 用户建好了 | 用户列表里出现该用户 |
| 密码拿到了 | 创建成功后页面上的绿色提示块（含复制按钮） |
| 角色改对了 | 进入该租户 → **成员** 页签，看这个人的「角色」列 |
| 这个人在哪些租户 | 用户详情页的 **所属租户与角色** 卡片 |

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 创建用户时没让我填密码 | 设计如此 | 密码由系统生成，创建成功后显示一次 |
| 找不到改角色的地方 | 角色属于「成员」，不属于「用户」 | 按「怎么改用户角色」里的两条路操作 |
| 添加成员时搜不到刚建的用户 | 可能是搜索关键词不对 | 换用户名或邮箱的关键词重试 |
| 想帮他开多因素认证 | BOSS 只展示、不代改 | 请用户自己在智算平台的个人安全设置里开启 |
