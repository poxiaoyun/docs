# 账户管理

**账户管理**是 BOSS 里负责「谁可以上平台、谁属于哪个组织、怎么登录」的地方。顶部导航点击 **账户管理** 后，左侧栏会出现两个分组：

- **账户管理**：用户管理、租户管理——建账号和建组织。
- **系统管理**：认证策略、第三方认证、邮件服务、短信服务——决定用户**怎么登录**、验证码从哪发出去。

平台上的每一个账号、每一个组织都是在这里创建出来的。

:::tip 用户和租户的关系，一句话
**用户**是「一个人」，**租户**是「一家公司」。一个人必须先被创建成用户，再被加进某个租户，才能登录并使用智算平台。
:::

## 两个分组、六个页面

| 分组 | 子页面 | 管什么 | 详细说明 |
| --- | --- | --- | --- |
| 账户管理 | 用户管理 | 创建平台账号、改资料、重置密码、删除账号 | [用户管理](/boss/iam/users) |
| 账户管理 | 租户管理 | 创建租户、启用/禁用、配置镜像推送、管理租户成员 | [租户管理](/boss/iam/tenants) |
| 系统管理 | 认证策略 | 开放注册、密码规则、多因素认证、登录验证码 | [认证策略](/boss/iam/authentication-policy) |
| 系统管理 | 第三方认证 | 接入 OAuth2 第三方登录（企业微信、GitLab 等） | [第三方认证](/boss/iam/identity-providers) |
| 系统管理 | 邮件服务 | 配 SMTP，让验证码和通知能发到邮箱 | [邮件服务](/boss/iam/email-providers) |
| 系统管理 | 短信服务 | 配阿里云或腾讯云短信，让验证码能发到手机 | [短信服务](/boss/iam/sms-providers) |

## 先弄清这几个词

| 名词 | 通俗解释 |
| --- | --- |
| 用户 | 一个平台账号，对应一个人。一个用户可以在多个租户里 |
| 租户 | 一家公司在平台上的独立账号空间，有成员、配额和工作空间 |
| 成员 | 某个用户「加入某个租户」之后的身份，记录里带着他在这个租户里的角色 |
| 角色 | 这个人在这个租户里能干什么，例如管理员、开发、成员 |
| 发送用途 | 一个邮件/短信服务专门用来发哪类消息（登录、注册、账户资料修改……） |

## 该按什么顺序做

1. **先建租户**：没有租户，用户就没有归属，也算不出配额。见[租户管理](/boss/iam/tenants)。
2. **再建用户**：创建后系统会自动生成一个初始密码，记得复制下来交给本人。见[用户管理](/boss/iam/users)。
3. **把用户加进租户**：在租户的**成员**页签里点 **添加成员**，选用户、选角色。
4. **配好登录方式**：先到 **系统管理** 里配邮件服务或短信服务，再到 **认证策略** 里打开对应的验证码登录。见[认证策略](/boss/iam/authentication-policy)。
5. **给租户分配算力**：先在 **智算平台 → 租户集群** 给租户开通集群，再进集群的**租户资源**创建配额。见[租户集群](/boss/rune-admin/tenant-clusters)。

:::info 别和智算平台里的「个人资料」搞混
用户在智算平台里可以自己改昵称、邮箱、密码、开多因素认证；这些是「个人设置」。BOSS 这边的账户管理是**管理员视角**，用于批量地把人和组织搭起来。用户的密码如果忘了，管理员可以在 BOSS 里帮他重置。
:::

## 常见问题

| 现象 | 说明 | 怎么办 |
| --- | --- | --- |
| 用户列表里找不到「启用/禁用」开关 | 用户确实没有这个开关 | 想停用账号，请删除该用户，或把他从租户里移除 |
| 想删掉一个租户 | 界面上没有删除入口 | 只能**禁用**租户，或把成员移出后停用 |
| 登录页没有「注册」入口 | 开放注册没开，或可用的注册通道为空 | 到[认证策略](/boss/iam/authentication-policy)打开「开放注册」并配好发送服务 |
| 登录页没有验证码登录 | 没有配「登录」用途的邮件/短信服务 | 先到[邮件服务](/boss/iam/email-providers)或[短信服务](/boss/iam/sms-providers)配好用途 |
