# 短信服务

短信服务决定**平台的短信从哪个云平台、用哪个签名和模板发出去**。用户用手机号收验证码登录、注册时，发短信的就是这里配的服务。

读完这页，你能完成：新增一个阿里云或腾讯云短信服务、填对凭据与签名模板、分配发送用途，并知道什么时候不能删。

:::tip 一个服务 = 一个短信通道
和邮件服务一样：签名是「谁发的」，模板是「发什么内容」，密钥是「平台有没有资格发」。三者都对上，短信才发得出去。
:::

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 短信平台 | 短信由哪家云服务发出，目前支持 **阿里云** 和 **腾讯云** |
| Access Key ID / Secret | 调用云服务的凭据，相当于账号和密码 |
| 短信签名 | 短信开头显示的身份，例如「某某科技」，必须已在云平台审核通过 |
| 模板标识 | 云平台上备案的短信模板编号，内容由云平台审核 |
| 发送用途 | 这台服务专门发哪类验证码 |
| SDK App ID | **腾讯云** 专属的短信应用编号 |

## 开始之前

- 你需要**系统管理员**账号。
- 在阿里云或腾讯云控制台里**先把短信签名和模板申请下来并通过审核**。
- 准备好 Access Key ID / Secret；腾讯云还要 SDK App ID。

## 列表怎么看

进入 **账户管理 → 系统管理 → 短信服务**，列表有三列：

| 列 | 说明 |
| --- | --- |
| 名称 | 服务的名字，点击进入详情 |
| 发送用途 | 全部用途，或具体几种；未分配时显示 **未分配用途** |
| 短信平台 | **阿里云** 或 **腾讯云** |

行操作有 **编辑** 和 **删除**；**已分配用途的服务不能删除**，需要先清空用途。

## 新建一个短信服务

1. 进入 **账户管理 → 系统管理 → 短信服务**。
2. 点新建按钮，按下面三段填写。

### 第一段：基本配置

| 字段 | 说明 |
| --- | --- |
| Logo | 显示在列表里的图标，可选 |
| 名称 | 服务的显示名，例如「阿里云短信」 |

### 第二段：短信平台与凭据

先选 **短信平台**，下面的字段跟着变：

| 字段 | 阿里云 | 腾讯云 | 说明 |
| --- | --- | --- | --- |
| SDK App ID | — | 必填 | 腾讯云短信应用编号 |
| Access Key ID | 必填 | 必填 | 云账号的访问密钥 ID |
| Access Key Secret | 必填 | 必填 | 对应的密钥；已有配置时留空表示保留原值 |
| 短信签名 | 必填 | 必填 | 审核通过的签名内容 |
| 模板标识 | 必填 | 必填 | 审核通过的模板编号 |

:::warning 签名和模板必须先审核通过
短信内容由云平台审核。签名或模板没通过审核时，即使凭据正确，发送也会被云平台拒绝。先在云控制台确认状态，再回这里配置。
:::

### 第三段：发送用途

| 选项 | 含义 |
| --- | --- |
| 全部用途 | 这台服务承担所有短信发送，**不能**和具体用途同时选 |
| 登录 | 短信验证码登录 |
| 注册 | 注册时的手机号验证 |
| 账户资料修改 | 用户改手机号时的验证码 |
| 找回密码 | 自助找回密码的验证码，**当前属预留用途** |
| MFA 绑定 | 绑定身份验证器时的验证码 |
| MFA 验证 | 登录时的二次验证码 |

规则与邮件服务一致：**全部用途与具体用途互斥**；**同一渠道里每项用途只能关联一个服务**；清空用途后该服务不参与发送，也才可以删除。

:::warning 「账户资料修改」和「找回密码」别勾错
**账户资料修改** 对应改手机号；**找回密码** 对应自助重置密码。登录页的「找回密码」目前只有一句「当前平台尚未提供自助找回密码。请联系平台管理员重置密码」，所以勾 **找回密码** 只是把用途预留好，用户仍然不能自助重置，忘记密码要找管理员在[用户管理](/boss/iam/users)里重置。
:::

## 结果确认

| 你想确认的事 | 去哪里看 |
| --- | --- |
| 配置保存了 | 列表里出现该服务，短信平台正确 |
| 用途挂上了 | 列表的 **发送用途** 列显示对应用途名 |
| 短信真能收到 | 退出登录，走一次短信验证码登录，看手机是否收到 |

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 发送失败，提示签名或模板错误 | 签名/模板未审核通过，或模板编号填错 | 到云控制台核对签名名称与模板编号 |
| 发送失败，提示鉴权错误 | Access Key 不对或无短信权限 | 换用有短信权限的 Access Key |
| 腾讯云一直失败 | 少了 SDK App ID，或 App ID 与密钥不属于同一个账号 | 补齐 App ID，确认三者同源 |
| 登录页没有短信验证码入口 | 没有服务承担 **登录** 用途，或认证策略里该方式关着 | 两处都检查一遍 |
| 删除按钮不可用 | 服务还带着用途 | 先清空 **发送用途** 再删 |
