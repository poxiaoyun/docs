# 第三方认证

第三方认证让你把外部登录源接进来：用户在登录页点「用某某登录」，跳去对方系统授权，回来就是平台里的一个账号。常见的接入对象是企业微信、钉钉、GitLab、Keycloak 这类支持 OAuth2 授权码的服务。

读完这页，你能完成：新增一个第三方认证、填完三段配置、验证回调地址、启用或停用登录、以及删除不再用的接入。

:::tip 用一个类比理解
第三方认证像「门禁互认」：平台不自己验密码，而是相信对面那栋楼的门禁。用户在对面上班打卡成功，平台就认他是谁。**字段映射**就是两家核对身份时用的对照表——对方说「这个人是 sub=abc123」，平台要把它对上自己这边的用户。
:::

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| OAuth2 授权码 | 第三方登录的标准流程：浏览器先去对方页面登录，拿回一个一次性「授权码」，服务端再用它换令牌 |
| Client ID / Client Secret | 平台在对方系统里注册应用时拿到的一对凭据，相当于账号和密码 |
| 回调地址 | 对方登录完成后把用户送回平台的地址，必须和对方系统里登记的一字不差 |
| 授权地址 | 用户点登录时，浏览器跳过去的那个页面地址 |
| 令牌地址 | 平台用授权码换访问令牌的接口地址 |
| UserInfo 地址 | 平台用令牌读取用户资料的接口地址 |
| 字段映射 | 把对方返回的字段，对上平台的用户字段（身份 ID、用户名、显示名称……） |
| PKCE | 一种把授权码绑定到本次登录请求的加固手段，需要对方支持 |

## 开始之前

- 你需要**系统管理员**账号。
- 你需要在对方系统里**先建好一个应用**，拿到 Client ID、Client Secret，并把回调地址登记进去。
- 想允许第三方登录的人**自动注册成新账号**，全局的 **开放注册** 必须先打开，见[认证策略](/boss/iam/authentication-policy)。

## 列表怎么看

进入 **账户管理 → 系统管理 → 第三方认证**，列表有三列：

| 列 | 说明 |
| --- | --- |
| 名称 | 显示名 + 下方的内部名，前面带 Logo；点击进入详情 |
| 第三方登录 | **允许登录** 或 **已停用登录** |
| Client ID | 平台在对方系统里的客户端标识 |

右上角 **添加第三方认证** 新建。每行的操作：

| 操作 | 说明 |
| --- | --- |
| 编辑 | 进入编辑页，改配置或字段映射 |
| 启用登录 / 停用登录 | 只对当前状态相反的行出现；停用时会弹确认框，说明「停用阻止后续登录，不撤销已有会话」 |
| 删除 | 只在**已停用**的行出现；后端只允许删除没有账号绑定、也没有其他应用引用的配置 |

## 新建一个第三方认证

1. 进入 **账户管理 → 系统管理 → 第三方认证**。
2. 点右上角 **添加第三方认证**。
3. 按下面三段依次填写，最后保存。

### 第一段：基本配置

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| Logo | 否 | 显示在列表和登录按钮上的图标 |
| 名称 | 是 | 显示名，例如「企业微信」；同时会生成一个内部名用于地址 |
| 允许登录 | 开关 | 打开后，登录页才出现这个入口 |
| 允许第三方注册 | 开关 | 打开后，对方来的新用户可以在平台自动建号；说明文字提示「全局注册策略必须允许注册；创建账户不会自动授予租户成员关系或角色」 |

### 第二段：OAuth2 配置

| 字段 | 说明 |
| --- | --- |
| 回调地址 | 由当前访问地址自动生成，旁边有复制按钮。**必须在实际登录用的域名下复制**，协议、域名、端口、路径都要和对方系统里登记的一致 |
| Client ID | 对方分配给这个应用的客户端标识，要和 Client Secret 成对 |
| Client Secret | 对方分配给这个客户端的密钥；已有凭据时留空表示保留原值 |
| 授权地址 | 用户点登录时浏览器跳转的授权接口，由对方提供 |
| 令牌地址 | 用授权码换令牌的接口，**平台后端要能访问到** |
| UserInfo 地址 | 用令牌读用户资料的接口，它的返回字段会用于下面的字段映射 |
| OIDC Issuer | 可选。填了以后，从平台登出时会顺带结束对方那边的会话 |
| 授权范围 | 该客户端获准申请的范围，多个值用空格分隔，例如 `openid profile email`；具体取值以对方为准 |
| 启用 PKCE | 打开后用 S256 PKCE 把授权码绑定到本次登录请求；**先确认对方支持 S256** |

### 第三段：用户字段映射

左侧选平台的用户字段，右侧填对方 UserInfo 响应里的字段名，例如身份 ID 对应 `sub`。

| 平台字段 | 必填 | 说明 |
| --- | --- | --- |
| 身份 ID 字段 | 是 | 对方返回的稳定唯一标识。**必须稳定且唯一**，绑定后不能改 |
| 用户名字段 | 是 | 用来生成平台用户名 |
| 显示名称字段 | 是 | 界面上显示的名字 |
| 邮箱字段 | 否 | 有就映射，可用于通知 |
| 手机号字段 | 否 | 有就映射 |
| 头像字段 | 否 | 有就映射 |

点 **添加字段映射** 可以继续加可选字段。

:::warning 绑定后不能改的三样东西
已有账户绑定之后，**身份 ID 映射**、**认证端点**（授权 / 令牌 / UserInfo 地址）、**Client ID** 都不能再改。要换只能新建一个接入，并让用户重新绑定。
:::

:::info 不校验 OIDC ID Token
此接入走 OAuth2 授权码 + UserInfo，**不提供 OIDC ID Token 校验**。如果你的 IdP 只在 ID Token 里给关键声明，需要额外确认 UserInfo 是否也能返回同样的字段。
:::

## 启用 / 停用 / 删除

| 操作 | 效果 | 注意 |
| --- | --- | --- |
| 启用登录 | 登录页出现该入口，用户可以走这条路登录 | — |
| 停用登录 | 阻止后续登录，**不撤销已有会话** | 想立刻踢掉在线用户，还要让对方会话过期或在平台侧处理 |
| 删除 | 移除整个接入配置 | 只有**已停用**、且没有账号绑定与其他应用引用时才允许删除 |

## 结果确认

| 你想确认的事 | 去哪里看 |
| --- | --- |
| 接入配置存好了 | 列表里出现这条记录，Client ID 正确 |
| 登录能走通 | 退出登录，在登录页点该入口，走完对方授权后应回到平台并登录成功 |
| 有没有人绑过 | 打开 **用户管理 → 某个用户 → 第三方登录** 页签，看是否列出该身份 |
| 能不能删 | 先停用登录；删除入口仍不可用时，说明还有绑定或引用 |

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 点登录后对方报「回调地址不匹配」 | 回调地址和对方登记的不一致 | 在实际登录域名下重新复制回调地址，逐字符核对协议、域名、端口、路径 |
| 登录回来提示创建账号失败 | 不允许第三方注册，或全局开放注册关着 | 打开本接入的 **允许第三方注册**，并确认认证策略里 **开放注册** 已开 |
| 同一个人登录后出现两个账号 | 身份 ID 映射用了一个会变的字段（例如邮箱） | 换成稳定的唯一标识（通常是 `sub`），然后处理重复账号 |
| 删除按钮是灰的 / 不出现 | 配置还在启用，或有绑定与引用 | 先停用登录；仍有引用时先解绑再删 |
| 令牌地址报连接失败 | 平台后端访问不到对方接口 | 检查网络与证书，确认是服务端可达的地址 |
| 启用 PKCE 后登录失败 | 对方不支持 S256 | 关掉 PKCE 再试 |
