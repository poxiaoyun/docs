# 概览

BOSS（左上角显示为 **BOSS平台**）是**平台管理员专用**的管理后台，用来管整个平台的账号、租户、算力资源和各种开关。普通用户日常使用的那套业务界面叫**智算平台**，两套界面的入口不同、菜单也完全不同，但它们共用同一批数据——你在 BOSS 里创建的用户，就是之后能登录智算平台的那个人。

:::tip 一句话分清两者的分工
BOSS 管「谁可以用、能用多少」（账号、租户、配额、集群、平台开关）；智算平台管「具体怎么用」（建推理服务、跑微调、传模型）。你在 BOSS 里做的配置，决定了智算平台里能做什么。
:::

## BOSS 和智算平台的区别

| 对比项 | BOSS（本页介绍的管理后台） | 智算平台 |
| --- | --- | --- |
| 谁在用 | 平台管理员、运维 | 租户里的管理员、开发、普通成员 |
| 主要做什么 | 建账号、建租户、分算力、管集群、审内容 | 建推理服务、跑微调、管模型和数据集 |
| 能看到多少数据 | 全平台所有租户 | 只有自己所属的租户 |
| 怎么进 | 用管理员账号打开管理后台 | 用普通账号登录智算平台 |

两边共用同一批账号和租户数据，所以在 BOSS 里的任何改动都会立刻影响用户在智算平台里的体验。

## 左侧菜单的分组一览

登录 BOSS 后，左侧菜单从上到下分成若干组。前 15 组一直在，后 4 组要等你进入某个租户或某个集群之后才会出现。

| 分组 | 什么时候出现 | 管什么 | 组里的菜单 |
| --- | --- | --- | --- |
| 概览 | 一直在 | 看平台整体运行情况 | 首页 |
| 大模型网关 | 一直在 | 看外部调用大模型的量、延迟和排行 | 数据看板 |
| 模型服务 | 一直在 | 接入和管理对外提供的模型 | 渠道管理、模型配置 |
| 用户管理 | 一直在 | 管网关的调用凭证和调用记录 | 令牌管理、调用日志 |
| 安全服务 | 一直在 | 给模型调用做内容把关 | 敏感词管理、策略管理、命中记录 |
| 平台设置 | 一直在 | 调网关自身的运行参数和计价货币 | 网关配置、货币配置 |
| 资产管理 | 一直在 | 管全平台的模型、数据集、镜像、空间 | 模型库、数据集、镜像仓库、空间 |
| 数据同步 | 一直在 | 从外部镜像站同步模型 | 镜像站 |
| 安全审计 | 一直在 | 查谁在什么时候改了什么 | 审计日志 |
| 系统设置 | 一直在 | 维护给用户看的公告和首页轮播图 | 公告、轮播图 |
| 租户 | 一直在 | 预留的分组，当前没有子菜单 | — |
| 集群 | 一直在 | 预留的分组，当前没有子菜单 | — |
| 智算平台 | 一直在 | 管算力集群和租户的算力资源 | 集群管理、租户资源、应用模版 |
| 账户管理 | 一直在 | 管平台的用户账号和租户 | 用户管理、租户管理 |
| 平台 | 一直在 | 平台级配置 | 系统成员、平台设置、智算平台设置、魔哈Hub设置、网关设置、AI助手设置、许可证 |
| 租户管理 | 进入某个租户后 | 管这个租户的成员和算力配额 | 概览、成员、配额、工作空间 |
| 集群信息 | 进入某个集群后 | 看这个集群的健康状况 | 集群信息、节点状态、加速卡信息 |
| 资源管理 | 进入某个集群后 | 管这个集群里的算力怎么分 | 资源池、资源规格、租户配额 |
| 运维管理 | 进入某个集群后 | 看集群里跑着的东西和日志 | 工作负载、存储集群、系统应用、调度器管理、日志管理 |

## 平台管理员通常先做这几件事

1. **建租户**：进入 **账户管理 → 租户管理**，点 **添加租户**。详见[租户管理](/boss/iam/tenants)。
2. **建用户**：进入 **账户管理 → 用户管理**，点 **添加用户**，把系统生成的密码交给本人。详见[用户管理](/boss/iam/users)。
3. **把用户加进租户并给角色**：进入 **账户管理 → 租户管理**，点租户名称，切到 **成员** 页签，点 **添加成员**。
4. **接入算力**：进入 **智算平台 → 集群管理** 接入集群，再在集群里配好**资源池**和**资源规格**。详见 [Rune 智算管理](/boss/rune-admin)。
5. **给租户分算力**：进入 **智算平台 → 租户资源**，为该租户创建**配额**。详见[租户配额](/boss/rune-admin/tenants)。
6. **按需配置平台**：在 **平台** 分组里配置平台设置、智算平台设置、魔哈Hub设置、网关设置等。详见[平台](/boss/settings)。

:::info 顺序有讲究
没有租户，用户就没有归属；没有集群和配额，租户就分不到算力。建议按上面 1 到 5 的顺序做，后面的步骤才不会有「选不到东西」的情况。
:::
