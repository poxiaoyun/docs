# 概览

BOSS（左上角显示为 **BOSS平台**）是**平台管理员专用**的管理后台，用来管整个平台的账号、租户、算力资源和各种开关。普通用户日常使用的那套业务界面叫**智算平台**、**魔哈Hub**，两套界面的入口不同、菜单也完全不同，但它们共用同一批数据——你在 BOSS 里创建的用户，就是之后能登录智算平台的那个人。

读完这页，你能说出：顶部导航的八个入口分别去哪、左侧栏为什么有时只剩几项、集群详情里的三级菜单从哪来，以及接手平台后第一步该做什么。

:::tip 一句话分清两者的分工
BOSS 管「谁可以用、能用多少」（账号、租户、配额、集群、平台开关）；智算平台和魔哈Hub 管「具体怎么用」（建推理服务、跑微调、传模型）。你在 BOSS 里做的配置，决定了智算平台里能做什么。
:::

## BOSS 和智算平台的区别

| 对比项 | BOSS（本页介绍的管理后台） | 智算平台 / 魔哈Hub |
| --- | --- | --- |
| 谁在用 | 平台管理员、运维 | 租户里的管理员、开发、普通成员 |
| 主要做什么 | 建账号、建租户、分算力、管集群、审内容 | 建推理服务、跑微调、管模型和数据集 |
| 能看到多少数据 | 全平台所有租户 | 只有自己所属的租户 |
| 怎么进 | 用管理员账号打开管理后台 | 用普通账号登录智算平台或魔哈Hub |

两边共用同一批账号和租户数据，所以在 BOSS 里的任何改动都会立刻影响用户在智算平台里的体验。

## 顶部导航有哪八项

顶部导航是**产品级入口**，点一下整片切换区域，左侧栏也跟着换掉：

| 顶部入口 | 点进去看到什么 | 左侧栏此时显示 |
| --- | --- | --- |
| 首页 | 平台总览卡片：资源量、网关调用、待关注项 | 概览 |
| 智算平台 | 集群管理、租户集群、应用 | 智算平台 |
| 魔哈Hub | 模型库、数据集、镜像仓库、空间、镜像站、审计日志、公告、轮播图 | 资产管理 / 数据同步 / 安全审计 / 系统设置 |
| 大模型网关 | 网关数据看板、渠道、模型配置、令牌、调用日志、内容审查、网关配置、货币配置 | 大模型网关 / 模型服务 / 用户管理 / 安全服务 / 平台设置 |
| 账户管理 | 用户管理、租户管理，以及系统管理下的认证策略、第三方认证、邮件服务、短信服务 | 账户管理 / 系统管理 |
| 平台设置 | 系统成员、各子系统设置、许可证、平台审计 | 平台 |
| **告警渠道** | 告警往哪里发：飞书、邮件，以及内置的站内信 | 平台（**没有**本页的侧边栏条目） |
| **数字孪生** | 数字孪生的产品介绍与进入按钮 | 平台（**没有**本页的侧边栏条目） |

**告警渠道**和**数字孪生**是顶部一级入口，只在顶部出现，左侧栏里找不到它们。

## 左侧栏的分组

左侧栏只显示**当前区域**的分组，所以「看不到某个菜单」通常不是权限问题，而是还没切到它所属的区域。

| 分组（界面原文） | 什么时候出现 | 组里的菜单 |
| --- | --- | --- |
| 概览 | 停在首页 | 首页 |
| 智算平台 | 智算平台区域、应用页 | 集群管理、租户集群、应用 |
| 账户管理 | 账户管理区域 | 用户管理、租户管理 |
| 系统管理 | 账户管理区域 | 认证策略、第三方认证、邮件服务、短信服务 |
| 资产管理 | 魔哈Hub 区域 | 模型库、数据集、镜像仓库、空间 |
| 数据同步 | 魔哈Hub 区域 | 镜像站 |
| 安全审计 | 魔哈Hub 区域 | 审计日志 |
| 系统设置 | 魔哈Hub 区域 | 公告、轮播图 |
| 平台 | 平台设置区域、平台审计页 | 系统成员、平台设置、智算平台设置、魔哈Hub设置、网关设置、许可证、平台审计 |
| 集群信息 | 进入某个集群后 | 集群信息、节点状态、加速卡信息 |
| 资源管理 | 进入某个集群后 | 资源池、资源规格、租户资源 |
| 运维管理 | 进入某个集群后 | 工作负载、存储集群、系统应用、调度视图、调度器管理、日志管理、告警 |

**租户**、**集群**两个空分组当前没有任何菜单，界面上不会出现。

## 集群详情里的三级菜单

从 **集群管理** 点进任意一个集群，左侧会整片换成三组集群专用菜单：

| 分组 | 菜单 | 看什么 / 改什么 |
| --- | --- | --- |
| 集群信息 | 集群信息、节点状态、加速卡信息 | 三个看板：整个集群、逐台机器、逐张加速卡 |
| 资源管理 | 资源池、资源规格、租户资源 | 机器怎么分组、套餐怎么定义、额度怎么发给租户 |
| 运维管理 | 工作负载、存储集群、系统应用、调度视图、调度器管理、日志管理、告警 | 集群里跑着什么、怎么调度、出了问题怎么看 |

三个看板是同一套渲染，靠地址最后一段区分；**资源池 / 资源规格 / 租户资源** 是分算力的地方；**告警** 是真实可用的规则页，不是占位。

## 平台管理员通常先做这几件事

1. **建租户**：进入 **账户管理 → 租户管理**，点 **添加租户**。详见[租户管理](/boss/iam/tenants)。
2. **建用户**：进入 **账户管理 → 用户管理**，点 **添加用户**，把系统生成的密码交给本人。详见[用户管理](/boss/iam/users)。
3. **把用户加进租户并给角色**：进入 **账户管理 → 租户管理**，点租户名称，切到 **成员** 页签，点 **添加成员**。
4. **接入算力**：进入 **智算平台 → 集群管理** 接入集群，再在集群里配好**资源池**和**资源规格**。详见 [Rune 智算管理](/boss/rune-admin)。
5. **给租户开通集群并分算力**：在 **智算平台 → 租户集群** 里给租户开通集群，再进集群的**租户资源**创建配额。详见[租户集群](/boss/rune-admin/tenant-clusters)与[租户资源与配额](/boss/rune-admin/tenants)。
6. **配好登录与通知**：在 **账户管理 → 系统管理** 里配认证策略、邮件服务、短信服务；在 **告警渠道** 里配告警发送方式。详见[认证策略](/boss/iam/authentication-policy)、[告警渠道](/boss/settings/alert-channels)。
7. **按需配置平台**：在 **平台** 分组里配置平台设置、智算平台设置、魔哈Hub设置、网关设置等。详见[平台](/boss/settings)。

:::info 顺序有讲究
没有租户，用户就没有归属；没有集群、没有开通关系和配额，租户就分不到算力。建议按上面 1 到 5 的顺序做，后面的步骤才不会有「选不到东西」的情况。
:::

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 左侧栏只有两三项 | 顶部导航停在了别的区域 | 先点顶部的目标区域，左侧栏会整片换掉 |
| 找不到「告警渠道」「数字孪生」 | 它们是顶部入口，没有侧边栏条目 | 直接在顶部导航点 |
| 找不到「认证策略」 | 它挂在 **账户管理** 区域下的 **系统管理** 分组 | 顶部点 **账户管理** 再看左侧栏 |
| 找不到「租户资源」 | 它只出现在进入某个集群之后 | 先到 **集群管理** 点进集群 |
