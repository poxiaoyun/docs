# 智算平台设置

智算平台设置决定**智算平台（Rune）对外显示成什么样子**：叫什么名字、用什么 Logo、简介怎么写，以及平台内部要访问的 Moha、KMS 两个服务地址。

页面下方还有一张独立的卡片 **开发服务闲置监控**，可以让长期没人用的开发服务自动暂停，省下算力。

本页在左侧菜单 **平台 → 智算平台设置**。

:::tip 这里改的是「招牌」，不是「开关」
这一页的标题、Logo、简介只是让入口**看起来**是你们自己的产品。
它**不会**让智算平台的菜单出现或消失；能不能进智算平台由用户所属租户是否被分配了该产品决定。
本页唯一会直接影响用户的功能开关，是下面的「开发服务闲置自动暂停」。
:::

## 开始之前

- 你的账号需要是**系统管理员**。
- 准备好 Logo 图片：**PNG 或 SVG**，大小不超过 **128 KB**。
- 如果要用闲置监控，先确认哪些开发服务可以接受「无人使用时被自动暂停」。

## 页面结构

页面自上而下有两张卡片，各自独立保存：

| 卡片 | 管什么 |
| --- | --- |
| 标题与Logo | 智算平台的名称、Logo、简介、内部服务地址 |
| 开发服务闲置监控 | 是否在闲置时自动暂停开发服务，以及判定时长 |

## 设置名称与 Logo

1. 在 **标题与Logo** 卡片里填写：

   | 设置项 | 怎么填 | 改了会发生什么 |
   | --- | --- | --- |
   | Logo | 上传 PNG 或 SVG，不超过 **128 KB** | 换掉「产品与服务」入口和智算平台页面里的图标 |
   | 产品标题 | 最多 **10 个字符**，默认 `智算平台` | 换掉入口和导航栏上显示的名称 |
   | 产品描述 | 最多 **100 个字符**，可换行（4 行） | 换掉产品简介文字 |
   | Moha 地址 | 例如 `https://moha.example.com` | 平台内部访问 Moha 服务用的地址 |
   | KMS 地址 | 例如 `https://kms.example.com` | 平台内部访问 KMS 服务用的地址 |

2. 选择 Logo 文件会**立刻触发一次保存**，把 Logo、标题、描述、两个地址一起写进去。

3. 如果只改了文字，改完点击卡片底部的 **确定** 保存。

:::warning 两个地址填错会影响功能
Moha 地址、KMS 地址是平台内部调用这两个服务用的，填错会导致相关功能不可用。
不确定正确地址时，请先向部署/运维同学确认，不要凭感觉填。
:::

## 设置开发服务闲置监控

在 **开发服务闲置监控** 卡片里，系统会盯着开发服务用的 GPU 或 vGPU 使用率：**只要连续一段时间一直是 0%，就自动把这个服务暂停**，避免空转占着算力。

| 设置项 | 怎么填 | 改了会发生什么 |
| --- | --- | --- |
| 启用开发服务闲置自动暂停 | 开关，默认**关闭** | 开启后，满足闲置时长的开发服务会被自动暂停；关闭则永不自动暂停 |
| 闲置时长（分钟） | 整数，**1–10080** 之间，默认 `30` | 使用率连续为 0% 达到这个时长后触发暂停；超过 10080（7 天）会报错 |

- 开关**关闭**时，「闲置时长」输入框会变灰、不能编辑。
- 改完点击这张卡片的 **确定** 保存。

:::warning 自动暂停会中断用户正在用的服务
一旦触发，开发服务会被暂停，正在里面跑的任务可能中断。开启前请先和用户约定好合理的闲置时长；关闭该开关则不会自动暂停。
:::

## 结果确认

- 两张卡片保存成功后都会提示「**更新成功,请刷新页面**」。
- 刷新浏览器后，到「产品与服务」入口或智算平台页面看名称和 Logo 是否已更新。
- 要确认闲置监控是否生效，可观察闲置超过设定时长的开发服务状态是否变为暂停。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| Logo 传不上去 | 不是 PNG/SVG，或超过 128 KB | 这里比平台设置的 3 MB 限制更小，换成更小的图片 |
| 「闲置时长」点不动 | 上面的开关是关闭状态 | 先打开「启用开发服务闲置自动暂停」 |
| 服务被暂停了想恢复 | 触发了闲置自动暂停 | 重新启动该开发服务即可 |
