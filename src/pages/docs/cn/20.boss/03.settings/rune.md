# 智算平台设置

智算平台设置决定**智算平台对外显示成什么样子**：叫什么名字、用什么 Logo、简介怎么写，以及平台内部要访问的 Moha、KMS 两个服务地址。

本页在 **平台设置** 区域里：顶部导航点击 **平台设置**，再在左侧栏 **平台** 分组下点击 **智算平台设置**。

读完后你能完成：换掉智算平台的标题、描述与 Logo，填对两个内部服务地址，并知道填错会发生什么。

:::tip 这里改的是「招牌」，不是「开关」
这一页的标题、Logo、简介只是让入口**看起来**是你们自己的产品，**不会**让智算平台的菜单出现或消失。能不能进智算平台，由用户所属租户是否开通了集群、有没有配额决定。
:::

## 开始之前

- 你的账号需要是**系统管理员**。
- 准备好 Logo 图片：**PNG 或 SVG**，大小不超过 **1 MB**。
- 准备好 **Moha 地址** 与 **KMS 地址**。不确定时先向部署/运维同学确认，不要凭感觉填。

## 页面结构

页面只有一张卡片 **标题与Logo**，包含外观信息和两个内部服务地址：

| 区块 | 管什么 |
| --- | --- |
| Logo 与产品标题 | 智算平台在入口和导航上显示成什么 |
| 产品描述 | 产品简介文字 |
| Moha 地址 / KMS 地址 | 平台内部调用这两个服务的地址 |

## 设置名称与 Logo

1. 在 **标题与Logo** 卡片里填写：

   | 设置项 | 怎么填 | 改了会发生什么 |
   | --- | --- | --- |
   | Logo | 上传 PNG 或 SVG，不超过 **1 MB** | 换掉「产品与服务」入口和智算平台页面里的图标 |
   | 产品标题 | **必填**，不能只填空格，默认 `智算平台` | 换掉入口和导航栏上显示的名称 |
   | 产品描述 | **必填**，最多 **100 个字符**，可换行（4 行） | 换掉产品简介文字 |
   | Moha 地址 | 例如 `https://moha.example.com` | 平台内部访问 Moha 服务用的地址 |
   | KMS 地址 | 例如 `https://kms.example.com` | 平台内部访问 KMS 服务用的地址 |

2. 选择 Logo 文件会**立刻上传并保存 Logo**，同时把当前填的标题、描述和两个地址一并写入。

3. 如果只改了文字，改完点击卡片底部的 **确定** 保存。

:::warning 两个地址填错会影响功能
Moha 地址、KMS 地址是平台内部调用这两个服务用的，填错会导致相关功能不可用。地址要写成平台服务端能访问到的完整地址。
:::

## 结果确认

- 保存成功后提示「**更新成功,请刷新页面**」。
- 刷新浏览器后，到「产品与服务」入口或智算平台页面看名称、描述和 Logo 是否已更新。
- 涉及 Moha、KMS 的功能（例如模哈Hub 相关跳转、密钥服务）能正常打开，说明地址填对了。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| Logo 传不上去 | 不是 PNG/SVG，或超过 1 MB | 换成符合格式和大小要求的图片 |
| 提示产品描述不能为空 | 描述是必填项，且不能只填空格 | 写一句话简介 |
| 保存后改名影响到了智算平台之外 | 不会：这里只管子产品标题 | 如果平台总标题也变了，说明改的是[平台设置](/boss/settings/platform) |
| 某些功能提示连接失败 | Moha 或 KMS 地址填错 | 与运维核对地址后重新保存 |
