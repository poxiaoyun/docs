# AI助手设置

AI助手是一个**帮用户排查问题的小助手**。它出现在智算平台页面**右侧边缘**，点开后会弹出一个对话面板，用户可以直接问「我的实例为什么起不来」，它会去看当前工作空间的资源并给出诊断建议。

这一页用来设置助手的**头像、名称、鉴权密钥**，并决定**是否对用户启用**它。

本页在左侧菜单 **平台 → AI助手设置**。

:::tip 它长在哪里
开启后，用户在智算平台（需要先选好租户/工作空间）任一页面的右侧边缘会看到一个小小的竖条，上面是助手的头像；点一下就会从右边滑出对话面板。
关闭后，这个竖条**不会显示**，用户看不到入口。
:::

## 开始之前

- 你的账号需要是**系统管理员**。
- 助手要能使，底层诊断服务必须处于**就绪**状态，并且已经加载了可用模型；否则开关打不开。
- 如果要换 Holmes 鉴权密钥，先到 Holmes 插件里拿到 API Key。

## 页面结构

| 设置项 | 怎么填 | 改了会发生什么 |
| --- | --- | --- |
| 助手头像 | 上传 PNG/JPG/WEBP，不超过 **128 KB** | 换掉助手入口和对话面板里的头像；上传时会自动裁剪为 160px 见方 |
| 名称 | 最多 **32 个字符**，默认 `晓石 AI助手` | 换掉助手入口的悬停提示、对话面板标题；留空保存会恢复成默认名 |
| Holmes API Key | 密码输入框 | 用于 Holmes 插件鉴权；**留空保存不会覆盖已有密钥**，只有填了新值才会更新 |
| AI助手 | 开关 | 决定用户能不能看到并使用助手 |

## 设置助手外观与密钥

1. 在 **助手头像** 处选择图片。此时只是本地预览，页面会提示「头像已选择，保存后生效。」。
2. 在 **名称** 里填写助手名字，最多 32 个字符。
3. 如果要更新鉴权密钥，在 **Holmes API Key** 里粘贴新值。输入框下方的提示会告诉你当前状态：

   | 提示 | 含义 |
   | --- | --- |
   | 已由 Boss 设置管理…… | 密钥已经在这里配置过；留空保存保持原值，填新值则更新 |
   | 当前使用服务端兼容配置…… | 目前用的是服务端旧配置；填新密钥保存后就改由这里管理 |
   | 未配置…… | 还没配过，需要填入 Holmes 插件里的 API Key |

4. 点击页面底部的 **确定** 保存。如果填了新密钥，系统会先保存密钥，再保存头像、名称和开关状态。

## 启用或停用助手

1. 先看页面上的 **服务状态** 标签：

   | 标签 | 含义 |
   | --- | --- |
   | 就绪（后面跟数字） | 服务正常、已就绪，并且加载了模型，可以启用 |
   | 未就绪 | 服务在，但还没准备好或没有可用模型 |
   | 不可用 | 服务不健康，暂时用不了 |

2. 状态不是「就绪」时，可以点 **刷新状态** 重新检查。
3. 把它变成「就绪」后，打开 **AI助手** 开关，再点 **确定**。

:::warning 服务不可用时开关会被强制关闭
只要服务显示「未就绪」或「不可用」（或模型数为 0），**AI助手开关会被强制置为关闭且不能操作**；此时就算保存，系统也会按「关闭」处理。
:::

## 结果确认

- 保存成功后提示「**更新成功,请刷新页面**」。
- 刷新浏览器，进入智算平台任意页面（先选好租户/工作空间），看右侧边缘是否出现助手头像。
- 点头像能滑出对话面板，并显示你设置的名称和头像，就说明生效了。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 开关打不开、是灰的 | 服务未就绪、不可用，或没有可用模型 | 点 **刷新状态**；仍不行就检查 Holmes 服务 |
| 用户端看不到助手入口 | 开关没开、没选工作空间，或服务不健康 | 确认开关为开启，并让用户选好租户/工作空间再看 |
| 头像换了没生效 | 头像只在保存后写入配置 | 选完头像后记得点 **确定** |
| 不想暴露给用户 | 助手已启用 | 关闭 **AI助手** 开关并保存 |
