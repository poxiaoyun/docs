# 平台审计

平台审计记录的是**管理动作**：谁改了平台设置、谁删了集群、谁给租户发了配额、哪次调用失败了。出问题要追责、要排障、要回答「这个配置是谁在什么时候改的」，都从这里查。

读完这页，你能完成：用时间范围和条件筛出目标操作、看懂列表每一列的含义、打开单条记录看请求与响应的完整详情。

:::tip 这是「操作流水账」，不是业务日志
它记的是**管理面**的写操作（改配置、建资源、删资源），不是用户跑推理的调用日志，也不是集群里的容器日志。用户调用模型请到 **大模型网关 → 调用日志**；集群容器日志请到集群的 **日志管理**。
:::

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 审计事件 | 一次管理操作的记录，一行动作一条 |
| 来源服务 | 这个操作是哪个控制面记的，例如账户、智算平台、网关 |
| 操作主体 | 实际发起操作的身份 |
| 代理身份 | 代表别人执行操作的身份（服务账号代操作时才有） |
| 操作对象 | 被改动的东西：资源类型 + 资源 ID，以及调用的方法与路径 |
| 结果 / 状态码 | 这次操作成功还是失败，以及返回的 HTTP 状态码 |
| 请求 ID | 一次请求的编号，跨服务排查时用它串起来 |

## 和魔哈Hub 审计日志的区别

两者都能查「谁做了什么」，但数据源和用途不同，不要混用：

| 对比项 | 平台审计（本页） | 魔哈Hub 的审计日志 |
| --- | --- | --- |
| 记录范围 | 各控制面的管理操作 | 魔哈Hub 的数据操作（创建、更新、删除、推送、拉取、上线、重启） |
| 筛选维度 | 来源服务、请求 ID、身份 ID、操作、租户、组织、资源、结果 | 组织、操作类型、资源类型、日期 |
| 时间窗 | 单次最多 7 天 | 默认近 1 个月 |
| 能否导出 | 不支持导出 | 支持导出 JSON |

## 开始之前

- 你需要**系统管理员**账号。
- 入口在 **平台设置 → 平台 → 平台审计**（地址是独立的 `/boss/audit-events`，不在设置页里）。
- 想查更早的记录，要**分段查询**：一次最多 7 天。

## 怎么筛

页面顶部是一排筛选项：

| 筛选项 | 怎么用 |
| --- | --- |
| 时间范围 | 快捷选项 1 小时 / 6 小时 / 1 天 / 3 天 / 7 天，默认 **1 天** |
| 来源服务 | 按控制面过滤，例如只看账户相关的操作 |
| 请求 ID | 知道请求编号时直接定位 |
| 身份 ID | 按操作者过滤 |
| 操作 | 按动作名过滤 |
| 租户 ID | 只看某个租户下的操作 |
| 组织 ID | 只看某个组织下的操作 |
| 资源类型 | 例如只看集群、租户、配额 |
| 资源 ID | 定位到具体某个资源 |
| 结果 | 成功 / 失败 / 未知 |

:::info 单次最多 7 天
页头写明了「查询各控制面记录的管理操作，单次查询时间范围最多为 7 天」。要查一个月前的操作，请按 7 天为一段往前翻。
:::

## 列表怎么看

| 列 | 说明 |
| --- | --- |
| 操作身份 | 显示名，下面一行是「代理身份 → 操作主体」形式的补充信息；点击可打开详情 |
| 来源服务 | 这条记录由哪个控制面写入 |
| 操作 | 动作名，例如创建、更新、删除 |
| 操作对象 | 资源类型 / 资源 ID，以及 `方法 路径` |
| 租户 / 组织 | 这次操作发生在哪个租户、哪个组织下 |
| 状态码 | 按结果上色：成功、失败、未知 |
| 客户端 IP | 发起请求的来源地址 |
| 时间 | 操作发生的时间 |

![平台审计列表：操作身份、来源服务、操作、操作对象、租户 / 组织、状态码、客户端 IP、时间](/assets/screenshots/boss/platform-audit-01.png)

:::tip 先按「结果 = 失败」筛一遍
排查「某个配置为什么没生效」时，最快的一步是把 **结果** 筛成 **失败**，再看状态码和操作对象。很多问题在审计里直接能看到是被哪次请求拒掉的。
:::

## 看一条记录的详情

点击 **操作身份** 或行内的详情入口，打开 **审计事件详情**。弹窗顶部可以切换两个视图：**详情** 与 **Raw**。

| 分组 | 字段 |
| --- | --- |
| 标识 | 记录 ID、请求 ID、来源服务 |
| 身份 | 操作主体、代理身份 |
| 动作 | 操作、父资源 |
| 对象 | 资源类型、资源名称、租户、组织 |
| 时间与结果 | 发生时间、完成时间、结果 |
| 报文 | 请求、响应 |

**Raw** 视图给出这条记录的原始结构，排查接口问题时给研发看这个。

## 结果确认

| 你想确认的事 | 去哪里看 |
| --- | --- |
| 某次改动是谁做的 | 按资源类型 + 资源 ID 筛，看 **操作身份** 与 **时间** |
| 这次操作成没成功 | 看 **状态码** 与 **结果**，或打开详情看响应 |
| 某个时间段有哪些管理动作 | 只设时间范围，先看全量再逐步加条件 |
| 跨服务的一次请求链路 | 用 **请求 ID** 筛选，把同一请求的记录串起来 |

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 查不到想要的记录 | 时间范围太小，或条件太多 | 先放宽到 7 天、清掉其他条件再逐步收窄 |
| 想查一个月前 | 单次最多 7 天 | 按 7 天一段分段查 |
| 只有管理操作，没有用户调用 | 本页只记控制面管理动作 | 用户调用看 **大模型网关 → 调用日志** |
| 状态码是 403 | 操作被权限拒绝 | 看 **操作身份** 是否有对应角色 |
| 找不到导出口 | 本页不支持导出 | 需要导出请用魔哈Hub 的审计日志 |
