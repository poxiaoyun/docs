# 平台设置

平台设置决定**登录页和所有页面顶部栏长什么样**：平台叫什么名字、副标题写什么、用哪个 Logo、版权归谁，以及顶部栏上是否出现「文档」按钮、主题切换和语言切换。

读完这页，你能完成：换掉平台的标题与 Logo、填写版权主体、按需关掉顶部栏的文档或语言入口，并知道改完为什么要刷新。

这些改动是全平台可见的，普通用户在**打开登录页的第一眼**就能看到，所以改之前先确认这是你想对外展示的信息。

本页在 **平台设置** 区域里：顶部导航点击 **平台设置**，再在左侧栏 **平台** 分组下点击 **平台设置**。

## 开始之前

- 你的账号需要是**系统管理员**。
- 准备好要用的 Logo 图片，大小不超过 **3 MB**；上传时可以按 1:1 裁剪，输出 512×512。

## 页面结构

页面自上而下有两张卡片，每张卡片都有**自己独立的确定按钮**，改哪张就点哪张的按钮：

| 卡片 | 管什么 |
| --- | --- |
| 标题与Logo | 平台标题、副标题、版权主体、Logo |
| 平台头部栏配置 | 默认显示语言、文档入口、主题切换、语言切换 |

![平台设置页：标题与Logo 卡片（Logo、平台标题、副标题、版权主体）与平台头部栏配置卡片](/assets/screenshots/boss/settings-platform-01.png)

## 设置标题与 Logo

1. 在 **标题与Logo** 卡片里填写：

   | 设置项 | 怎么填 | 改了会发生什么 |
   | --- | --- | --- |
   | Logo | 上传图片，不超过 **3 MB**；可按 1:1 裁剪 | 换掉浏览器标签页的小图标，以及登录页、顶部栏的 Logo |
   | 平台标题 | **必填**，不能只填空格，例如 `晓石云` | 显示在浏览器标签页、顶部栏标题、登录页大标题 |
   | 副标题 | 选填，例如 `原生无界 · 破晓时刻` | 显示在登录页和侧边栏标题下方 |
   | 版权主体 | 选填，例如 `某某科技有限公司` | 用于门户和关于页的版权声明；**留空则不展示** |

2. 选择 Logo 文件后**图片会立刻上传**。此时图片地址已经拿到，但配置还没保存。

3. 点击卡片底部的 **确定**，才会把标题、副标题、版权主体和 Logo 一起存下来。

:::tip Logo 的上传分两步
上传只是把图片传到服务器；**必须再点一次确定**，平台才会开始使用这个新 Logo。
裁剪 Logo 时保持 1:1 比例，图片不会被拉变形。
:::

## 设置头部栏入口

在 **平台头部栏配置** 卡片里：

| 设置项 | 怎么填 | 改了会发生什么 |
| --- | --- | --- |
| 默认显示语言 | 下拉选择，**必填** | 用户第一次打开平台时使用的界面语言 |
| 显示文档入口 | 开关，默认**开启** | 关闭后，顶部栏的 **文档** 按钮消失，用户找不到文档入口 |
| 文档地址 | 文本，例如 `https://docs.example.com` | 点 **文档** 按钮时打开的地址；只在「显示文档入口」开启时出现 |
| 显示主题切换入口 | 开关，默认**开启** | 关闭后，用户不能在界面上切换明亮/暗夜模式 |
| 启用语言切换 | 开关，默认**开启** | 关闭后，顶部栏和登录页都不再显示语言切换入口 |

- **文档地址**只在「显示文档入口」开启时才会出现，关闭开关后这一项会跟着隐藏。
- 改完点击这张卡片的 **确定**。

:::warning 关掉语言切换前先确认默认语言
关掉语言切换后，所有用户只能用 **默认显示语言**。如果默认语言不是他们的母语，界面上就没有别的选择。改默认语言前先确认这是平台对外的主要语言。
:::

## 注册开关不在这里

以前「是否允许自助注册」放在本页，现在已迁到认证策略：

1. 顶部导航点 **账户管理**。
2. 左侧 **系统管理 → 认证策略**。
3. 在 **登录与注册** 卡片点 **编辑**，打开 **开放注册**。

详见[认证策略](/boss/iam/authentication-policy)。

## 结果确认

- 保存成功后，卡片上方会提示「**更新成功,请刷新页面**」。
- 按提示**刷新浏览器**，新名称、Logo、副标题和入口开关才会在界面上体现出来。
- 到登录页看一眼：标题、副标题、Logo 是否已经变成你设置的样子；关掉文档入口后，顶部栏应不再出现 **文档**。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 保存后界面没变化 | 配置已存下，但当前页面还是旧数据 | 刷新浏览器 |
| Logo 传不上去 | 图片超过 3 MB | 换一张更小的图片；平台设置的限制比子产品设置的 1 MB 更宽 |
| 改完标题后其他子系统也跟着变了 | 这里是平台级标题，子产品标题要分别到智算平台/魔哈Hub/网关设置里改 | 到对应子系统的设置页改 |
| 找不到「是否允许自助注册」 | 已迁到认证策略 | 到 **账户管理 → 系统管理 → 认证策略** |
| 文档按钮不见了 | 关闭了「显示文档入口」 | 打开该开关并保存 |
