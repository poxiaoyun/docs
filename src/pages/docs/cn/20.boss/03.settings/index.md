# 平台

这一组页面是**整个平台的总控台**：改平台叫什么名字、换成什么 Logo、各子系统在界面上怎么显示、许可证有没有过期、谁是平台管理员、谁在什么时候改了什么。

它们在 **平台设置** 区域里：顶部导航点击 **平台设置**，左侧栏的 **平台** 分组就是这一组页面。改完的效果通常**全平台可见**——包括登录页、顶部标题栏、普通用户看到的各个子系统入口，所以动手前先想清楚会影响谁。

读完这页，你能分清七个设置页各管什么、哪些改动只影响外观、哪些会影响用户能不能登录和使用。

:::tip 这些设置和「租户设置」不是一回事
这里的每项都是**平台级**的，一次改动影响所有租户和所有用户。
租户内部的成员、配额、工作空间属于租户级设置，请到 **账户管理** 和集群详情里改。
:::

## 开始之前

- 你的账号必须是**系统管理员**。普通用户看不到 **平台** 分组，即使拿到链接也打不开。
- 想修改哪个子系统，先想清楚它对应的入口在哪里显示，避免改完找不到按钮。

## 各设置页能干什么

| 页面 | 用来做什么 | 改了影响谁 |
| --- | --- | --- |
| [系统成员](/boss/settings/members) | 增删平台管理员、分配管理员角色 | 只有平台管理员名单，不影响普通用户 |
| [平台设置](/boss/settings/platform) | 改平台名称、副标题、版权主体、Logo，控制顶部「文档」入口、主题切换、语言切换 | 登录页、浏览器标签、所有页面的顶部栏 |
| [智算平台设置](/boss/settings/rune) | 改「智算平台」的名称、Logo、简介、Moha 地址、KMS 地址 | 智算平台入口与页面 |
| [魔哈Hub设置](/boss/settings/moha) | 改魔哈Hub 的名称、Logo、简介，以及空间的访问方式与 HTTPS 证书 | 魔哈Hub 入口与所有访问空间的人 |
| [网关设置](/boss/settings/chatapp) | 改网关对应的「模型体验」子系统的名称、Logo、简介 | 「产品与服务」里该子系统的入口 |
| [许可证](/boss/settings/license) | 查看许可证状态与到期时间、更新许可证 | 全平台可用功能范围与资源上限 |
| [平台审计](/boss/settings/platform-audit) | 查谁在哪个控制面改了什么 | 只读，不影响任何配置 |

**告警渠道**不在这个分组里：它是顶部导航的一级入口，左侧栏看不到对应条目。见[告警渠道](/boss/settings/alert-channels)。

## 四个容易记混的「展示设置」

**平台设置**、**智算平台设置**、**魔哈Hub设置**、**网关设置** 里都有一个叫 **标题与Logo** 的卡片。它们的区别只是**管的是哪一块产品**：

- **平台设置**管的是整个平台（登录页、浏览器标签、总标题），并且多一张 **平台头部栏配置** 卡片。
- 另外三个分别管**智算平台**、**魔哈Hub**、**模型体验**这三个子产品入口。

它们互不影响，改一个不会动到另一个。

## 平台设置里没有的东西

有两类设置以前放在「平台设置」，现在不在那里了：

| 想做的事 | 现在去哪里 |
| --- | --- |
| 开关自助注册 | **账户管理 → 系统管理 → 认证策略 → 登录与注册 → 开放注册** |
| 配邮件、短信、第三方登录 | **账户管理 → 系统管理** |

## 结果确认

每张卡片通常有自己独立的 **确定** 按钮，保存成功后会提示「更新成功,请刷新页面」。也就是说：**设置已经存下了，但当前页面还是旧的，需要刷新浏览器才能看到新样式**。
