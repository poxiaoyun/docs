# 魔哈Hub设置

魔哈Hub设置决定**魔哈Hub 对外显示成什么样子**（名称、Logo、简介），同时管理 **空间** 怎么被访问：直连还是走代理、用哪个域名或 IP、要不要 HTTPS。

页面有两张卡片：上方是展示信息，下方是空间配置，两者**各自独立保存**，改一张不会影响另一张。

本页在 **平台设置** 区域里：顶部导航点击 **平台设置**，再在左侧栏 **平台** 分组下点击 **魔哈Hub设置**。

读完后你能完成：换掉魔哈Hub 的标题、描述与 Logo，选对空间的访问方式，填对域名 / IP 和 TLS 证书。

:::tip 展示信息和空间配置分别管什么
上面一张卡只改「魔哈Hub 叫什么、长什么样」，用户能直接看到。
下面一张卡管「空间」这个功能怎么被访问——访问方式和证书改错，访问空间会直接失败，属更敏感的操作。
:::

## 开始之前

- 你的账号需要是**系统管理员**。
- 准备好 Logo 图片：**PNG 或 SVG**，不超过 **1 MB**。
- 如果要改空间配置，先准备**已解析到本平台的域名或一个可用 IP**；启用 HTTPS 时还要准备好证书和私钥内容。

## 页面结构

| 卡片 | 管什么 | 保存方式 |
| --- | --- | --- |
| 标题与Logo | 魔哈Hub 的名称、Logo、简介 | 点卡片内 **确定** |
| 空间配置 | 空间的访问方式、域名 / IP、是否启用 TLS 及证书 | 点卡片内 **确定** |

## 设置名称与 Logo

1. 在 **标题与Logo** 卡片里填写：

   | 设置项 | 怎么填 | 改了会发生什么 |
   | --- | --- | --- |
   | Logo | 上传 PNG 或 SVG，不超过 **1 MB** | 换掉「产品与服务」入口和魔哈Hub 页面里的图标 |
   | 产品标题 | **必填**，不能只填空格，默认 `魔哈Hub` | 换掉入口和导航栏上显示的名称 |
   | 产品描述 | **必填**，最多 **100 个字符**，可换行（4 行） | 换掉产品简介文字 |

2. 选择 Logo 文件会**立刻上传并保存 Logo**。

3. 只改文字时，改完点击卡片底部的 **确定**。

![魔哈Hub设置：标题与Logo，以及空间配置（访问方式、域名 / IP、TLS 证书与私钥）](/assets/screenshots/boss/settings-moha-01.png)

这一页比平台设置多了 **空间配置** 一段：先选 **空间访问方式**，再决定域名和证书。两段各有自己的 **确定** 按钮，改哪段点哪段。

## 设置空间配置

1. 在 **空间配置** 卡片里先选 **空间访问方式**：

   | 选项 | 含义 |
   | --- | --- |
   | 域名 / IP 直连 | 每个空间用独立子域名或 NodePort 直接对外；下面的域名 / IP 与 TLS 都在这条路上生效 |
   | 通过 apiserver 代理 | 访问统一走 apiserver 代理，不需要单独配域名和证书 |

   **空间访问方式** 的说明原文是「保存后在空间下次启动或重启时生效。代理模式需要支持代理访问的空间模板。」——也就是说改完不会立刻切换，已有空间要重启一次。

2. 选 **域名 / IP 直连** 时，继续填写：

   | 设置项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 域名 / IP | 必填，例如 `spaces.example.com` 或 `192.168.1.10` | **不含协议和端口**。域名使用空间子域名；IP 使用 NodePort |
   | 启用TLS | 开关，默认**关闭** | 开启后，平台用 HTTPS 访问空间 |
   | TLS证书 | 启用 TLS 时必填，PEM 格式 | 空间 HTTPS 用的证书 |
   | TLS私钥 | 启用 TLS 时必填，PEM 格式 | 空间 HTTPS 用的私钥 |

3. 点击卡片底部的 **确定** 保存。

校验规则：

- **域名 / IP** 去掉首尾空格后不能为空，否则无法保存。
- 打开 **启用TLS** 后，证书和私钥**必须都填**，只填一个会报错。
- 证书和私钥**要么都填，要么都留空**；只填其中一个会提示「TLS 证书和私钥必须成对填写；启用 TLS 时两项均为必填」。

:::warning 只有域名能配 TLS
说明文字明确写了「TLS 仅适用于域名」。用 IP 直连时启用 TLS，浏览器校验证书会失败，所以 IP 场景请不要开 HTTPS。
:::

:::warning 启用 HTTPS 前先确认证书正确
开启 TLS 后，平台会用 HTTPS 协议访问空间。请确保证书和私钥是配对的、且与域名匹配，否则用户会访问不了空间。
:::

## 结果确认

- 两张卡片保存成功后都会提示「**更新成功,请刷新页面**」。
- 刷新浏览器后，到「产品与服务」入口看魔哈Hub 的名称和 Logo 是否已更新。
- 用 **域名 / IP** 访问一个空间，确认能正常打开；启用 TLS 时地址应是 `https://` 开头。
- 改成代理模式后，重启一个空间，确认新的访问路径生效。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 空间配置保存不了 | 域名 / IP 留空了 | 填上正确的域名或 IP（不含协议和端口） |
| 提示 TLS 相关错误 | 只填了证书或只填了私钥 | 两栏一起填，或两栏都清空 |
| 启用 HTTPS 后打不开空间 | 证书与私钥不匹配，或与域名对不上 | 核对后重新粘贴保存 |
| 改成代理模式后访问方式没变 | 访问方式的变更在空间下次启动或重启时生效 | 重启对应空间 |
| 用 IP 启用 HTTPS 后报证书错误 | TLS 只适用于域名 | 用 IP 时关闭 TLS |
