# 告警渠道

告警渠道回答一个问题：**集群出问题时，消息发到哪里**。你可以配一个飞书机器人地址、也可以配一个 SMTP 邮件出口，还可以直接用系统内置的站内信。集群里的告警规则在选「通知渠道」时，选的正是这里配好的渠道。

读完这页，你能完成：新增一个飞书或邮件渠道、发一条测试消息确认能收到、编辑已有渠道、删除不再用的渠道。

:::tip 入口在顶部，不在左侧栏
**告警渠道** 是顶部导航的一级入口。点它以后左侧栏显示的是 **平台** 分组，但列表里**没有**「告警渠道」这一条，不要去找它。
:::

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 告警渠道 | 一条「往哪发」的配置，可以是飞书机器人，也可以是邮件 |
| 站内信（内置） | 平台自带的收件箱，不需要配置，也不需要密钥 |
| 飞书机器人地址 | 飞书群机器人的 Webhook 地址，往它发消息群里就能看到 |
| 飞书签名密钥 | 机器人开启签名校验时需要的密钥，用来证明消息来自平台 |
| 测试渠道 | 立刻往这个渠道发一条测试消息，验证配置是否真的通 |

## 开始之前

- 你需要**系统管理员**账号。
- 用飞书：先在飞书群里添加自定义机器人，拿到 Webhook 地址；如果机器人开了签名校验，还要拿到密钥。
- 用邮件：准备好 SMTP 地址、发件人、收件人，以及 SMTP 密码。

## 列表怎么看

进入顶部 **告警渠道**，列表有三列：

| 列 | 说明 |
| --- | --- |
| 名称 | 渠道名，可排序 |
| 类型 | **飞书** 或 **邮件** |
| 配置 | 飞书显示机器人地址，邮件显示 SMTP 地址；内置渠道显示 **站内信（内置）** |

右上角 **创建告警渠道** 新建。每行的操作：

| 操作 | 说明 |
| --- | --- |
| 测试渠道 | 立刻发一条测试消息 |
| 编辑 | 打开编辑弹窗 |
| 删除 | 带确认框；删除后引用它的告警规则就少了这个通知出口 |

![告警渠道列表：名称、类型、配置，右上角创建入口](/assets/screenshots/boss/alert-channels-01.png)

## 添加告警渠道

1. 点顶部 **告警渠道**。
2. 点右上角 **创建告警渠道**。
3. 填 **名称**，选 **类型**，再按类型填对应字段：

   类型 = **飞书**：

   | 字段 | 必填 | 说明 |
   | --- | --- | --- |
   | 飞书机器人地址 | 是 | 群机器人的 Webhook 地址 |
   | 飞书签名密钥 | 是（新建时） | 机器人开启签名校验时填写；**编辑时留空表示保持原有密钥不变** |

   类型 = **邮件**：

   | 字段 | 必填 | 说明 |
   | --- | --- | --- |
   | SMTP 地址 | 是 | 发信服务器地址 |
   | 发件人 | 是 | 告警邮件的发件地址 |
   | 收件人 | 是 | 多个地址用**逗号分隔** |
   | 密码 | 新建时必填 | SMTP 密码或授权码；**编辑时留空表示保持原密码** |
   | 传输加密 | 否 | 开关，默认**开启** |

4. 点 **保存**。必填项没填完时保存按钮不可点。

:::info 编辑时名称和类型不能改
渠道建好后，**名称**和**类型**在编辑弹窗里是灰的。想换成另一种类型的通知方式，请新建一个渠道，再把告警规则指过去。
:::

## 测试渠道

1. 在目标渠道那一行打开操作菜单，点 **测试渠道**。
2. 成功时页面提示「**测试消息已发送，请到对应渠道确认是否收到**」。

:::warning 测试消息是真的发出去
点一下就会往飞书群或收件人邮箱发一条真实消息。在正式群里测试前先打个招呼，也别把测试当成「只校验配置」。
:::

失败时页面顶部会出现错误条，按提示检查地址、密钥或 SMTP 认证信息。

## 编辑与删除

| 操作 | 说明 |
| --- | --- |
| 编辑 | 名称、类型不可改；地址、密钥（留空保持不变）、收件人、加密开关可改 |
| 删除 | 弹出确认框，确认后删除。删除前先确认没有告警规则还指着它 |

:::tip 删之前先看告警规则
规则里的 **通知渠道** 引用的就是这里的渠道。删掉渠道后，相关规则仍会触发，但消息发不出去。删之前先到集群的 **告警** 页看看哪些规则用了它。
:::

## 和集群告警的关系

告警功能分两层，缺一层都收不到消息：

| 层次 | 在哪配 | 作用 |
| --- | --- | --- |
| 渠道 | 本页（顶部 **告警渠道**） | 消息往哪里发 |
| 规则 | 集群详情 → **运维管理 → 告警** | 什么条件下发、发给哪些渠道 |

在 **告警** 页添加规则时，**通知渠道** 的下拉选项来自这里；不选渠道时使用内置的 **站内信（内置）**。见[告警](/boss/rune-admin/alerts)。

## 结果确认

| 你想确认的事 | 去哪里看 |
| --- | --- |
| 渠道建好了 | 列表里出现该渠道，类型和配置正确 |
| 配置真的通 | 点 **测试渠道**，看到「测试消息已发送…」并到飞书群或邮箱确认 |
| 告警真的会发 | 在集群的 **告警** 页确认规则的通知渠道里选中了这个渠道 |

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 测试失败，提示签名错误 | 机器人开了签名校验但密钥没填或填错 | 在飞书机器人设置里复制密钥重填 |
| 测试成功但群里没消息 | 机器人被移出群，或地址指向别的群 | 检查机器人是否还在群里、地址是否正确 |
| 邮件测试失败 | SMTP 地址/端口不对，或密码错 | 核对 SMTP 配置；必要时先在[邮件服务](/boss/iam/email-providers)里用同样的参数试连通 |
| 收件人只收到一个 | 多个地址没用逗号分隔 | 用英文逗号分隔多个地址 |
| 编辑时改不了类型 | 设计如此 | 新建渠道，再把规则指向新渠道 |
