# 系统成员

系统成员就是**平台管理员**：他们能登录 BOSS 运营平台，管理所有租户、集群、资源池和全局设置。可以把它理解成「平台最高权限的一份名单」。

这一页用来查看名单、添加管理员、调整他们的角色，以及把人从名单里移除。页面在左侧菜单 **平台 → 系统成员**。

:::tip 和租户成员不是一回事
系统成员是**平台级**的，管的是整个平台。
租户里的成员是**租户级**的，只管自己那一家租户。两者相互独立：用户被移出系统成员后，他在各租户里的身份不受影响。
:::

## 开始之前

- 你的账号本身需要是**系统管理员**才能打开这一页。
- 要添加的人**必须已经在平台上注册过账号**。如果还没有账号，请先到 **账户管理 → 用户管理** 里创建用户。

## 成员列表

列表每行显示：

| 列 | 说明 |
| --- | --- |
| 用户名 | 成员的名字，前面带头像 |
| 邮箱 | 成员注册时用的邮箱 |
| 角色 | 该成员的系统角色（界面显示为翻译后的中文，例如「管理员」） |
| 加入时间 | 成为系统成员的时间 |

每行右侧有 **编辑** 和 **删除** 两个操作。

## 添加系统成员

1. 点击右上角的 **添加成员**。
2. 在表单里填写：

   | 设置项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 用户 | 输入用户名搜索，从下拉结果里选择 | 只能选**已注册**的用户；添加后不能在这里改人 |
   | 角色 | 从下拉里选择系统角色 | 决定这个人在平台里的权限范围 |

3. 点击 **确定** 完成添加，页面会返回成员列表。
4. 想放弃则点 **取消**。

## 修改成员角色

1. 在成员列表里找到目标成员，点击 **编辑**。
2. 用户不可更改（会显示为不可编辑），在 **角色** 下拉里选择新角色。
3. 点击 **确定** 保存。

## 移除成员

1. 在成员列表里找到目标成员，点击 **删除**。
2. 在弹出的确认框里确认删除。

移除后，该用户会**立即失去 BOSS 运营平台的访问权限**。但请注意：

- 他的普通账号**不受影响**，仍然可以正常登录平台使用业务功能。
- 他在各个租户里的角色和权限**不受影响**。

:::warning 别把自己或最后一个管理员删掉
移除自己会**立刻让自己失去平台管理权限**，如果这是名单里最后一个管理员，将**没有人能再进入平台管理做任何调整**。
移除前请先确认名单里还有其他可用的管理员；如果确实要减少管理员，务必先添加一个新的管理员顶上。
:::

## 结果确认

- 添加成功：成员列表里出现该用户，**角色** 和 **加入时间** 都已显示。
- 修改角色：该成员的 **角色** 列变成新角色。
- 移除成功：名单里不再有该用户；让他重新登录 BOSS 会进不去。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 搜不到要添加的人 | 该用户还没在平台注册 | 先到 **账户管理 → 用户管理** 创建用户 |
| 角色下拉是空的 | 系统角色列表还没加载出来 | 刷新页面重试 |
| 不小心删错人 | 已失去 BOSS 权限 | 重新把他添加为系统成员，并分配原来的角色 |
