# 许可证

许可证（License）是**平台的产品授权凭证**：它决定了这套平台**能用哪些功能**，以及**各类资源能用多少**（比如集群数、节点数、加速卡数）。

你可以把它理解成一张**带有效期的授权证书**——证书里写明了授权的产品和数量上限，过期或数量超了，相应的功能就会被限制。

这一页用来看当前授权状态、到期时间，并粘贴新证书完成续期。页面在左侧菜单 **平台 → 许可证**（页面标题为「许可证管理」）。

## 开始之前

- 你的账号需要是**系统管理员**。
- 续期前先向许可证签发方拿到**新的许可证字符串**；如果换了集群，签发方还需要你提供**集群指纹**。

## 页面结构

| 区块 | 用来做什么 |
| --- | --- |
| 集群指纹 | 显示并复制当前集群的唯一标识，交给签发方用于签发匹配的许可证 |
| 许可证状态 | 授权是否正常、到期时间、授权给哪家公司等 |
| 产品配额状态 | 各功能的用量和上限，点功能名可查看资源明细 |

## 在哪里看到期时间

在 **许可证状态** 卡片里能看到这些信息：

| 展示项 | 说明 |
| --- | --- |
| 状态 | 用标签显示：正常、需注意、检查中、无效、检查失败 |
| 序列号 | 许可证的唯一编号 |
| 公司 | 授权给哪家公司 |
| 邮箱 | 授权联系人邮箱 |
| 版本 | 授权的产品版本 |
| 签发时间 | 证书签发日期 |
| **过期时间** | **证书到期日期，续期看这里** |

如果这里显示「未配置许可证」，说明平台还没有导入许可证，需要按下面的步骤更新。

## 过期后会限制什么

许可证一旦到期、无效、与当前集群不匹配，或用量超过授权上限，**部分功能会受限**，典型表现是：

- 新建或扩容资源（集群、节点、加速卡等）的操作会被限制。
- 未包含在授权范围内的产品或功能不可用。
- 页面会给出「当前产品许可证校验失败，部分功能可能受限」之类的提示。

:::warning 到期前请及时续期
许可证「需注意」通常代表**即将到期**。请在到期前联系签发方续期并更新，避免影响用户新建和扩容资源。
:::

## 更新许可证

1. 点击页面右上角的 **更新许可证**。
2. 在弹出的对话框里，把新许可证字符串**粘贴**到多行输入框（提示文字为「请粘贴许可证字符串」）。
3. 点击 **提交**。
4. 提交成功后提示「许可证更新成功」，对话框自动关闭，页面上的授权状态会刷新。

注意事项：

- 输入框为空时，**提交**按钮不可点。
- 提交过程中对话框**不能关闭**，请等待结果。
- 如果报错，错误信息会显示在对话框里，按提示检查许可证内容或联系签发方。

## 查看资源用量明细

当许可证里包含产品配额时，页面下方会出现 **产品配额状态**，每个产品一张表：

| 列 | 说明 |
| --- | --- |
| 功能 | 显示为可点击的链接，例如集群、节点、加速卡 |
| 资源用量 | 已用数量 / 授权上限 |
| 状态 | 该功能的授权状态 |

点击功能名会进入 **资源授权详情** 页，可以看到具体的资源记录；在详情页可以点 **刷新授权记录** 提交一次用量检查，检查结果会在后台更新。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 状态显示「无效」 | 许可证内容不对或已损坏 | 重新向签发方获取并粘贴 |
| 提示「与当前集群不匹配」 | 许可证是给别的集群签发的 | 把页面顶部的**集群指纹**提供给签发方，重新签发 |
| 状态显示「用量超限」 | 已用资源超过授权上限 | 清理不用的资源，或联系签发方扩容授权 |
| 提交按钮点不了 | 输入框是空的 | 先粘贴许可证字符串 |
