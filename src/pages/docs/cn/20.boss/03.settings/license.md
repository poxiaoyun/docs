## 功能简介

许可证页面用于查看当前集群的指纹、许可证状态与产品配额状态，并支持粘贴新许可证完成更新。产品配额中的每个功能可下钻到「资源授权详情」查看具体资源记录。

本页对应 BOSS 控制台「平台管理 → **许可证**」（菜单文案取自 `navbar.license`）。

## 进入路径

BOSS 控制台 → 平台管理 → **许可证**

| 操作 | 前端路由 |
|------|---------|
| 许可证主页 | `/settings/license` |
| 资源授权详情 | `/settings/license/records?product=...&feature=...`（或 `&service=...`） |

> ⚠️ 注意: 上表是 BOSS 控制台前端代码中的真实路径。文档站页面 URL 为 `/boss/settings/license`。

## 集群指纹

页面顶部展示集群指纹（`getClusterSerial` 返回的 `fingerprint`），并以等宽字体展示，右侧提供复制按钮。

> 💡 提示: 页面对指纹的说明是「请将此指纹提供给许可证签发方」——许可证需与当前集群匹配。

## 许可证状态

| 展示项 | 字段 | 说明 |
|--------|------|------|
| 状态指示 | `status.phase` | 见下方状态枚举 |
| 状态说明 | `status.code` / `status.message` | 按错误码给出提示文案 |
| 序列号 | `serial` | — |
| 公司 | `company` | — |
| 邮箱 | `email` | — |
| 版本 | `edition` | — |
| 签发时间 | `issueAt` | 日期时间 |
| 过期时间 | `expires` | 日期时间 |

未配置许可证（`serial` 为空）时，只显示「未配置许可证」提示。

### 状态枚举（`LicensePhase`）

| 标识 | 界面文案 |
|------|---------|
| `Active` | 正常 |
| `Warning` | 需注意 |
| `Pending` | 检查中 |
| `Invalid` | 无效 |
| `Error` | 检查失败 |

状态码文案覆盖：许可证有效、即将到期、未安装、未就绪、读取失败、无效、指纹不匹配、已过期、用量核验失败、产品未授权、功能未授权、用量超限等。

## 产品配额状态

当许可证包含产品状态时，页面按产品分组展示配额表：

| 列 | 字段 | 说明 |
|----|------|------|
| 功能 | `feature.name` | 显示为可点击链接，跳转到资源授权详情 |
| 资源用量 | `feature.used` | 已用 / 上限 |
| 状态 | `feature.phase` | 与许可证状态同一套枚举 |

内置功能名文案：`clusters`（集群）、`nodes`（节点）、`accelerators`（加速卡）。

## 更新许可证

点击页面右上角 **更新许可证** 打开对话框：

1. 在多行文本框中粘贴许可证字符串（`license_placeholder` = 「请粘贴许可证字符串」）
2. 点击 **提交**，调用 `POST /api/license/global`（请求体 `{ license }`）
3. 提交成功后提示「许可证更新成功」，关闭对话框并刷新许可证状态

> ⚠️ 注意: 提交按钮在文本框为空时禁用；提交过程中不可关闭对话框。

## 资源授权详情

从产品配额表中点击功能名（或带 `service` 参数）进入资源授权详情页。该页需要 URL 查询参数：

- `product` +（`feature` 或 `service`）

缺少上下文时会显示空态「请选择产品配额」，并提示返回许可证管理页选择一个配额项。

接口：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/license/global` | `GET` | 读取许可证信息 |
| `/api/license/cluster-serial` | `GET` | 读取集群指纹 |
| `/api/license/global` | `POST` | 更新许可证 |
| `/api/license/records` | `GET` | 查询授权资源记录 |
| `/api/license/record-scopes` | `GET` | 查询记录范围 |
| `/api/license/records:refresh` | `POST` | 刷新授权记录（提交用量检查，后台更新） |

> ⚠️ 注意: 许可证过期或校验失败会限制部分产品能力；页面对无效许可证会给出「当前产品许可证校验失败，部分功能可能受限」的提示。

## 权限要求

需要 **系统管理员** 角色。
