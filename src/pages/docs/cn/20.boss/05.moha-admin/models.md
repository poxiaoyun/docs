# 模型库

模型库列出**全平台**用户上传的模型仓库，包括被设为「个人」的私有模型。你可以在这里了解平台上都有哪些模型、占多大空间、被下载了多少次，也可以把不合规的模型下架，或者直接删除。

:::tip 模型和模型库是什么关系
一个「模型」就是一份打包好的模型文件，通常包含很多文件和一份版本历史。一个模型在平台里就是一个**仓库**，就像网盘里的一个文件夹，可以不断提交新版本。
:::

## 开始之前
- 需要 **系统管理员** 角色。
- 顶部导航点击 **魔哈Hub**，再在左侧栏 **资产管理** 分组下点击 **模型库**。

## 先认识几个词
| 名词 | 通俗解释 |
| --- | --- |
| 仓库 | 一份模型文件的集合，带版本历史 |
| 组织 | 这个模型属于哪个团队账号 |
| 可见性 | 谁能看到这个模型 |
| 推荐指数 | 管理员给模型打的分，会展示在用户端 |
| 加密 | 平台给这个模型打的加密标记 |
| 同步中 | 这个模型是从外部平台同步过来的，还没同步完 |

可见性有三种取值，决定了谁能看、谁能传：

| 显示 | 谁能看到并下载 | 谁能上传新版本 |
| --- | --- | --- |
| 公开 | 任何人，包括没有登录的访客 | 挂在个人名下时只有创建者本人；挂在组织下时该组织成员都可以 |
| 租户内 | 只有所属组织的成员 | 所属组织成员 |
| 个人 | 只有创建者本人 | 创建者本人 |

## 列表上有什么
列表上方是 5 张统计卡片。除了「模型总数」，其余卡片**只统计当前这一页**的模型，翻页后数字会跟着变。

| 卡片 | 含义 |
| --- | --- |
| 模型总数 | 全平台模型数量，副标题显示当前页模型的容量合计 |
| 公开模型 | 当前页里可见性为「公开」的模型数 |
| 加密模型 | 当前页里带加密标记的模型数 |
| 下载总量 | 当前页所有模型的下载次数合计 |
| 热门模型 | 当前页里有下载记录的模型数 |

列表每一行显示这些内容：

| 列 | 说明 |
| --- | --- |
| 别名 / 名称 | 模型名字；旁边有信息图标时，鼠标移上去可以看到描述 |
| 组织 | 模型所属的组织 |
| 可见性 | 公开 / 租户内 / 个人；「个人」还会在后面标出创建者 |
| 使用容量 | 仓库已占用的空间，统计完成前显示 `-` |
| 下载次数 | 累计下载次数 |
| 分类 | 模型能做的技术任务，多个时折叠显示 |
| 标签 | 模型自定义标签 |
| 推荐指数 | 管理员设置的分数，鼠标移上去能看到推荐理由 |
| 更新时间 | 最近一次修改时间 |

![模型管理：顶部五张统计卡（模型总数 57、容量、公开、加密、下载总量），下方是高级搜索与列表](/assets/screenshots/boss/moha-models-01.png)

模型管理是魔哈仓库管理中数据量最大的一页（截图里 57 个模型、容量 35.36 GB）。顶部三个下拉 **组织 / 可见性 / 分类** 可以叠加，配合左侧的 **高级搜索** 用来定位某一个模型。

## 找到要处理的模型
1. 在搜索框里输入模型的名称或别名，输入后会自动搜索。
2. 需要时用 **组织**、**可见性**、**分类** 三个下拉框筛选。
3. 点击搜索框右侧的 **高级搜索**，在弹出面板里可以按 **行业/业务域**、**适用场景**、**模型精度**、**硬件后端**、**加速卡**，以及 **创建时间起 / 止** 过滤，填完点 **应用筛选**。
4. 已经生效的筛选条件会显示成小标签，点标签上的叉可以单独去掉；也可以回到 **高级搜索** 面板点 **清空高级筛选** 全部清掉。

## 把模型下架（更改可见性）
平台没有单独的「审核 / 驳回」按钮。对不合规或不该公开的模型，管理员通过改可见性把它从用户端撤下来。

1. 在目标模型这一行，点击最右侧的 **⋯** 按钮（操作菜单）。
2. 点击 **更改可见性**。
3. 在 **可见性** 下拉框里选择目标值：**公开**、**租户内** 或 **个人**。
4. 点击 **确定**。

结果确认：列表里这一行的可见性标签立刻变成新值；改成「租户内」或「个人」后，普通用户就看不到、也搜不到这个模型了。

## 设置推荐
1. 在目标模型这一行点击最右侧的 **⋯** 按钮。
2. 点击 **推荐**。
3. 填写 **推荐指数**，取值是 0–100 的整数。
4. 在 **推荐理由** 里写推荐说明，支持富文本编辑。
5. 点击 **确定**。

结果确认：列表里「推荐指数」列会出现分值，鼠标停在分值上会弹出推荐理由。

## 编辑模型资料
1. 点击最右侧的 **⋯** 按钮 → **编辑**。
2. 页面分 **模型**、**元数据**、**可见性** 三张卡片，可以折叠展开：
   - **名称**不能改，输入框是灰色的。
   - 可以修改 **描述** 和元数据（分类、标签等）。
   - 可以在 **可见性** 里切换 个人 / 租户内 / 公开。
3. 改完点击 **确定**，会自动回到模型库列表。

## 删除模型
1. 点击最右侧的 **⋯** 按钮 → **删除**；也可以先勾选多行，再用列表上方的批量删除。
2. 弹出的确认框会显示「确定删除模型 xxx 吗？」。
3. 按提示手动输入这个模型的名称，**确定** 按钮才会变成可点。
4. 点击 **确定**。

:::warning 删了就找不回来
删除会永久删除这个模型仓库，以及里面的所有文件和历史版本，**无法恢复**。请先确认确实不再需要，或者已经另行备份。
:::

## 常见问题
| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 「使用容量」一直显示 `-` | 平台还在统计这个仓库的容量 | 稍后刷新页面再看 |
| 名称旁边有「同步中...」标签 | 这个模型来自外部平台，还没同步完 | 到 [镜像站](/boss/moha-admin/mirrors) 查看同步状态 |
| 名称旁边有一个锁图标 | 这个模型带加密标记 | 属于正常状态，不是出错 |
