## 功能简介

BOSS 端模型库管理提供**平台级别**的模型仓库全局管理。与 Console 端不同，这里面向系统管理员，可查看、审核与管理**所有租户 / 用户 / 组织**创建的模型仓库（含私有模型）。

## 进入路径

BOSS 控制台 → 资产管理 → **模型库**

前端路由：`/moha/models`

---

## 列表与标签页

模型库与数据集、镜像仓库、Space 共用同一个「数据管理」列表组件（`data-managers`），通过 URL 中的 `type` 区分：

| type | 页面 |
| --- | --- |
| `models` | 模型库 |
| `datasets` | 数据集 |
| `images` | 镜像仓库 |
| `spaces` | Space |

### 列表顶部统计卡片

列表上方展示五张统计卡片：资源总数（副文案显示当页仓库存储总量）、公开数、**加密资源数或私有数**（`models` / `datasets` 展示加密资源数，其余类型展示私有数）、下载量、热门资源数。

### 列字段

不同 `type` 的列并不完全相同，下面先列出模型与数据集共有的列：

| 列 | 字段路径 | 说明 |
| --- | --- | --- |
| 别名 / 名称 | `name` / `alias` | 名称列展示 `alias || name`；含描述悬浮提示；加密模型展示 🔒 图标；镜像来源（`hidden-from-index = true`）展示「同步中...」标签 |
| 组织 | `organization` | 组织头像 + 名称 |
| 可见性 | `visibility` | 公开 / 私有 / 租户内标签；私有时附带创建者 |
| 仓库容量 | `repositoryStorageSize` | 仅在仓库统计 `status = ready` 时展示，否则为 `-` |
| 下载量 | `annotations.downloads` | 数字格式化 |
| 任务 | `metadata.tasks` | 可折叠标签组 |
| 标签 | `metadata.tags` | 可折叠标签组 |
| 推荐指数 | `annotations.recommendation-score` | 推荐状态 |
| 更新时间 | `modified` | 时间 |

> ⚠️ 注意: 列表**没有「许可证」列**。

### 各类型的差异列

| type | 独有列 |
| --- | --- |
| `spaces` | 运行状态（`spaceMetadata.status.phase`）、领域（`metadata.domain`）、场景（`metadata.scene`） |
| `images` | 分类（`metadata.category`）、加速（`metadata.accelerate`）、架构（`metadata.arch`），且**没有**推荐指数列 |
| `models` / `datasets` | 任务、标签、推荐指数 |

### 筛选

- **名称搜索**、**组织筛选**、**可见性筛选**。
- **高级筛选**：按元数据 Facet 过滤（任务类别、标签等），已应用条件以 Chip 展示。

## 管理操作

操作列包含：

| 操作 | 说明 | 适用类型 |
| --- | --- | --- |
| 可见性 | 打开可见性对话框，切换公开 / 私有 | 全部 |
| 推荐 | 打开推荐对话框，配置推荐指数与推荐截图 | 除 `images` 外 |
| 编辑 | 进入编辑页 | 全部 |
| 删除 | 带确认弹窗，支持批量 | 全部 |

> ⚠️ 注意: 模型 / 数据集**没有「重启」「停止」「查看日志」等运行时操作**，这些不在数据管理列表中提供。

---

## 与 Console Moha 视图的区别

| 维度 | BOSS 模型管理 | Console 模型管理 |
| --- | --- | --- |
| 数据范围 | 全平台所有模型（含私有） | 仅当前用户 / 组织有权限的模型 |
| 可见性管理 | 可修改任意模型 | 仅能管理自己创建的模型 |
| 推荐管理 | 可设置推荐指数与推荐截图 | 无此功能 |
| 删除权限 | 可删除任意模型仓库 | 仅能删除自己的 |

---

## 权限要求

需要 **系统管理员** 角色。普通用户应通过 Console → Moha 管理自己的模型仓库。

相关页面：[数据集管理](./datasets)、[镜像仓库管理](./images)、[Space 管理](./spaces)。
