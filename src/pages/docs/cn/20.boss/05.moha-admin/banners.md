# Banner

轮播图（Banner）显示在**魔哈 Hub 首页的最上方**，会自动循环播放。你可以用它做活动宣传、新功能公告、或者引导用户去某个页面。

:::tip 轮播图长什么样
首页顶部一张大横幅图片，每 5 秒自动切换下一张，左下角有小圆点可以手动点选。图片上可以叠一句**标题**和一行**内容**；如果配了**链接**，用户点图片就会打开这个链接。
:::

## 开始之前
- 需要 **系统管理员** 角色。
- 顶部导航点击 **魔哈Hub**，再在左侧栏 **系统设置** 分组下点击 **轮播图**。
- 提前准备好图片文件（建议按 4:1 的横图准备，例如 1600×400）。

![轮播图列表：轮播图片、标题、内容、链接、生效时间、失效时间](/assets/screenshots/boss/moha-banners-01.png)

轮播图列表比公告多两列：**轮播图片**（缩略图）和 **链接**（点击后跳转的地址）。截图里这两列都是空的，说明这两条轮播图只放了图片和文案、没有配跳转；生效 / 失效时间的规则和公告一样。

## 列表上有什么
| 列 | 说明 |
| --- | --- |
| 轮播图片 | 图片缩略图，没上传时显示 `-` |
| 标题 | 叠在图片上的大标题 |
| 内容 | 叠在图片上的说明文字，过长会截断 |
| 链接 | 点击图片跳转的网址，可以点开预览 |
| 生效时间 | 从什么时间开始展示 |
| 失效时间 | 到什么时间停止展示 |

- 搜索框可以按**标题**搜索。
- 已经过了「失效时间」的记录会**整行变灰**，表示它已经不再展示了。

## 新建一张轮播图
1. 点击右上角 **添加轮播图**。
2. 在 **轮播配置** 卡片里填写：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 标题 | 例如 `新模型上线` | 可不填；填了会叠在图片上显示 |
   | 内容 | 例如 `一键体验最新开源大模型` | 可不填；多行文本，显示在标题下方 |
   | 链接 | 例如 `https://example.com/activity` | 可不填；填了必须是完整网址，否则保存会报错 |
   | 生效时间 | 选择日期和时间 | 必填，从这一刻开始展示 |
   | 失效时间 | 选择日期和时间 | 必填，必须**晚于**生效时间 |

3. 在 **轮播图片** 卡片里上传图片：点击上传区域选择文件，弹出裁剪框后按 4:1 的比例裁剪，确认即可。
4. 点击 **确定**。

结果确认：页面自动回到轮播图列表，能看到刚建的这条记录。到用户端的魔哈 Hub 首页顶部，在生效时间之后就能看到它开始轮播。

### 图片要求
| 项 | 要求 |
| --- | --- |
| 支持格式 | JPG、PNG、GIF、WebP、APNG 等常见图片格式 |
| 尺寸 | 静态图会按 **4:1** 裁剪，输出宽 1600 像素；建议直接准备 1600×400 |
| 动图 | GIF、APNG 这类动图会保留动画效果 |
| 大小 | 单张不超过 3 MB |

## 修改或删除
- **修改**：在目标行点击最右侧的 **⋯** 按钮 → **编辑**，改完点 **确定**。
- **删除**：在目标行点击最右侧的 **⋯** 按钮 → **删除**；也可以先勾选多行，再用列表上方的批量删除。删除前需要按提示做二次确认。

:::warning 删除后用户端立刻消失
删除是不可恢复的操作，用户端首页上正在展示的这张轮播图会立刻消失。如果只是临时不想展示，建议改用「失效时间」把它下线。
:::

## 什么时候生效、什么时候下线
| 时机 | 发生什么 |
| --- | --- |
| 到达「生效时间」 | 自动出现在用户端首页的轮播里 |
| 到达「失效时间」 | 自动不再展示，列表里整行变灰 |
| 想提前下线 | 点 **编辑**，把「失效时间」改到当前时间之前，再点 **确定** |

:::info
「失效时间」必须晚于「生效时间」，否则点 **确定** 时会提示「失效时间必须晚于生效时间」，保存不成功。
:::
