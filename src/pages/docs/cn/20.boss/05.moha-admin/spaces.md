# 空间管理

「空间」是用户在魔哈 Hub 里用代码搭出来的**在线 AI 应用**，类似一个能直接打开访问的小网站，可以发布上线、停止、重新发布。这个页面列出**全平台**所有组织创建的空间，包括被设为「个人」的私有空间。

:::tip 空间是什么
把空间想成「别人做好的在线小应用」：用户写好代码提交上去，平台自动把它跑起来并给一个访问地址。用户端可以看到运行状态、下载、收藏，管理员则在这里做治理。
:::

## 开始之前
- 需要 **系统管理员** 角色。
- 左侧菜单点击 **资产管理** → **空间**。

## 先认识几个词
| 名词 | 通俗解释 |
| --- | --- |
| 空间 | 用户用代码搭建的在线 AI 应用，有独立的访问地址 |
| 组织 | 这个空间属于哪个团队账号 |
| 可见性 | 谁能看到这个空间 |
| 运行状态 | 这个空间当前跑起来了没有 |
| 领域 / 场景 | 空间面向的业务领域和适用场景，用来做分类 |

可见性有三种取值：

| 显示 | 谁能看到 | 谁能修改 |
| --- | --- | --- |
| 公开 | 任何人，包括没有登录的访客 | 只有所属组织成员或仓库管理员 |
| 租户内 | 只有所属组织的成员 | 所属组织成员 |
| 个人 | 只有创建者本人 | 创建者本人 |

## 列表上有什么
列表上方是 5 张统计卡片。除了「空间总数」，其余卡片**只统计当前这一页**的空间，翻页后数字会跟着变。

| 卡片 | 含义 |
| --- | --- |
| 空间总数 | 全平台空间数量，副标题显示当前页空间的容量合计 |
| 公开空间 | 当前页里可见性为「公开」的空间数 |
| 私有空间 | 当前页里可见性为「个人」的空间数 |
| 下载总量 | 当前页所有空间的下载次数合计 |
| 热门空间 | 当前页里有下载记录的空间数 |

列表每一行显示这些内容：

| 列 | 说明 |
| --- | --- |
| 别名 / 名称 | 空间名字；旁边有信息图标时，鼠标移上去可以看到描述 |
| 组织 | 空间所属的组织 |
| 可见性 | 公开 / 租户内 / 个人；「个人」还会在后面标出创建者 |
| 使用容量 | 仓库已占用的空间，统计完成前显示 `-` |
| 运行状态 | 空间当前跑起来了没有，见下表 |
| 下载次数 | 累计下载次数 |
| 领域 | 空间面向的业务领域，多个时折叠显示 |
| 场景 | 空间的适用场景，多个时折叠显示 |
| 推荐指数 | 管理员设置的分数，鼠标移上去能看到推荐理由 |
| 更新时间 | 最近一次修改时间 |

运行状态可能出现的取值（与用户在空间详情页看到的叫法一致）：

| 状态 | 含义 |
| --- | --- |
| 部署中 | 平台正在把空间跑起来 |
| 运行中 | 空间已经跑起来了，可以访问 |
| 状态同步中 | 正在同步最新状态，稍等即可 |
| 已暂停 | 空间被停止，不再提供服务 |
| 处理失败 / 已完成（有失败） | 部署过程出错，需要到用户端看日志排查 |
| 删除中 | 空间正在被删除 |
| 已安装 | 组件已安装完成 |
| 未知 | 暂时取不到状态 |

## 找到要处理的空间
1. 在搜索框里输入空间的名称或别名，输入后会自动搜索。
2. 需要时用 **组织**、**可见性**、**领域**、**场景** 这几个下拉框筛选。
3. 已经选中的筛选条件会直接显示在对应的下拉框上，选回 **全部** 即可取消。

## 把空间下架（更改可见性）
1. 在目标空间这一行，点击最右侧的 **⋯** 按钮（操作菜单）。
2. 点击 **更改可见性**。
3. 在 **可见性** 下拉框里选择目标值：**公开**、**租户内** 或 **个人**。
4. 点击 **确定**。

结果确认：列表里这一行的可见性标签立刻变成新值；改成「租户内」或「个人」后，普通用户就看不到、也搜不到这个空间了。

## 设置推荐
1. 在目标空间这一行点击最右侧的 **⋯** 按钮。
2. 点击 **推荐**。
3. 填写 **推荐指数**，取值是 0–100 的整数。
4. 在 **推荐理由** 里写推荐说明，支持富文本编辑。
5. 点击 **确定**。

结果确认：列表里「推荐指数」列会出现分值，鼠标停在分值上会弹出推荐理由。

## 编辑空间资料
1. 点击最右侧的 **⋯** 按钮 → **编辑**。
2. 页面分 **空间**、**元数据**、**可见性** 三张卡片，可以折叠展开：
   - **名称**不能改，输入框是灰色的。
   - 可以修改 **描述**，以及 **许可证**、**领域**、**场景** 等元数据。
   - 可以在 **可见性** 里切换 个人 / 租户内 / 公开。
3. 改完点击 **确定**，会自动回到空间列表。

## 删除空间
1. 点击最右侧的 **⋯** 按钮 → **删除**；也可以先勾选多行，再用列表上方的批量删除。
2. 弹出的确认框会显示「确定删除空间 xxx 吗？」。
3. 按提示手动输入这个空间的名称，**确定** 按钮才会变成可点。
4. 点击 **确定**。

:::warning 删了就找不回来
删除会永久删除这个空间仓库，以及里面的所有文件和历史版本，**无法恢复**。请先确认确实不再需要，或者已经另行备份。
:::

## 常见问题
| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 想发布、停止或重启空间，但这里没有这些按钮 | 这一组页面只做内容治理，不负责运行控制 | 让空间创建者在用户端自己的空间详情页操作 |
| 「使用容量」一直显示 `-` | 平台还在统计这个仓库的容量 | 稍后刷新页面再看 |
| 运行状态一直「部署中」 | 应用还在构建，或者构建失败 | 到用户端的空间详情页查看日志 |
