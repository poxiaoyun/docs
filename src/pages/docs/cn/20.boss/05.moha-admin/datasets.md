## 功能简介

BOSS 端数据集管理提供**平台级别**的数据集仓库全局管理。系统管理员可查看和管理平台上所有租户 / 用户 / 组织创建的数据集仓库（含私有数据集）。

## 进入路径

BOSS 控制台 → 资产管理 → **数据集**

前端路由：`/moha/datasets`

---

## 列表

数据集与模型库、镜像仓库、Space 共用数据管理列表组件，`type = datasets`。

### 列字段

| 列 | 字段路径 | 说明 |
| --- | --- | --- |
| 别名 / 名称 | `name` / `alias` | 名称列展示 `alias || name`，含描述悬浮提示与镜像来源标签（`hidden-from-index = true`） |
| 组织 | `organization` | 组织头像 + 名称 |
| 可见性 | `visibility` | 公开 / 私有 / 租户内标签 |
| 仓库容量 | `repositoryStorageSize` | 仓库统计 `status = ready` 时展示，否则 `-` |
| 下载量 | `annotations.downloads` | — |
| 任务 | `metadata.tasks` | 可折叠标签组 |
| 标签 | `metadata.tags` | 可折叠标签组 |
| 推荐指数 | `annotations.recommendation-score` | 推荐状态 |
| 更新时间 | `modified` | — |

> ⚠️ 注意: 列表**没有「许可证」列**。数据集也不展示加密图标以外的加密列（加密状态以名称列中的图标体现）。

### 筛选

名称搜索、组织筛选、可见性筛选，以及基于元数据 Facet 的高级筛选（任务类别、标签等）。

---

## 管理操作

| 操作 | 说明 |
| --- | --- |
| 可见性 | 切换公开 / 私有 |
| 推荐 | 配置推荐指数与推荐截图 |
| 编辑 | 进入编辑页 |
| 删除 | 带确认弹窗，支持批量 |

---

## 权限要求

需要 **系统管理员** 角色。普通用户和租户管理员应通过 Console → Moha 管理自己的数据集仓库。
