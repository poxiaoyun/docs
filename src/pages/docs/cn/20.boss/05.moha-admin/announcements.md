# 公告

公告显示在**魔哈 Hub 首页的「公告」卡片**里，用来向所有用户发布通知，例如维护安排、新功能上线、使用规范。用户可以点标题查看全文。

:::tip 公告出现在哪里
用户打开魔哈 Hub 首页，右侧有一张「公告」卡片，按生效时间列出公告标题；点标题会弹出全文。卡片底部还有一个 **查看全部** 按钮，可以进入完整的公告列表页。
:::

## 开始之前
- 需要 **系统管理员** 角色。
- 顶部导航点击 **魔哈Hub**，再在左侧栏 **系统设置** 分组下点击 **公告**。

## 列表上有什么
| 列 | 说明 |
| --- | --- |
| 标题 | 公告标题，搜索框可以按标题搜索 |
| 内容 | 公告正文，列表里会去掉格式后截断显示 |
| 生效时间 | 从什么时间开始展示 |
| 失效时间 | 到什么时间停止展示 |

已经过了「失效时间」的公告会**整行变灰**，表示它已经不再展示了。

![公告列表：标题、内容、生效时间、失效时间](/assets/screenshots/boss/moha-announcements-01.png)

公告列表只有四列，重点是最后两列——**生效时间** 与 **失效时间** 一起决定这条公告什么时候出现在用户的魔哈 Hub 上。时间没到或已过期，公告会自动隐藏，不用手动下架。

## 发布一条公告
1. 点击右上角 **添加公告**。
2. 在 **公告配置** 卡片里填写：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 标题 | 例如 `平台维护通知` | 必填 |
   | 内容 | 例如 `本周日 02:00–04:00 进行升级，期间暂停服务。` | 必填，富文本编辑器，可加粗、分段、插入链接 |
   | 生效时间 | 选择日期和时间 | 必填，从这一刻开始展示 |
   | 失效时间 | 选择日期和时间 | 必填，必须**晚于**生效时间 |

3. 点击 **确定**。

结果确认：页面自动回到公告列表，能看到刚发布的这条记录。到用户端的魔哈 Hub 首页，在生效时间之后就能在「公告」卡片里看到它。

:::info
内容不能只输入空格：平台会先去掉格式再检查，如果去掉后没有任何文字，会提示必填。
:::

## 修改或删除
- **修改**：在目标行点击最右侧的 **⋯** 按钮 → **编辑**，改完点 **确定**。
- **删除**：在目标行点击最右侧的 **⋯** 按钮 → **删除**；也可以先勾选多行，再用列表上方的批量删除。删除前需要按提示做二次确认。

:::warning 删除后用户端立刻消失
删除是不可恢复的操作，用户端首页「公告」卡片里正在展示的这条公告会立刻消失。如果只是临时不想展示，建议改用「失效时间」把它下线。
:::

## 什么时候生效、什么时候下线
| 时机 | 发生什么 |
| --- | --- |
| 到达「生效时间」 | 自动出现在用户端首页的「公告」卡片里 |
| 到达「失效时间」 | 自动不再展示，列表里整行变灰 |
| 想提前下线 | 点 **编辑**，把「失效时间」改到当前时间之前，再点 **确定** |

:::info
「失效时间」必须晚于「生效时间」，否则点 **确定** 时会提示「失效时间必须晚于生效时间」，保存不成功。
:::

## 常见问题
| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 发布后在用户端看不到 | 还没到生效时间，或者已经过了失效时间 | 检查两个时间，必要时点 **编辑** 修改 |
| 点 **确定** 提示失效时间不对 | 失效时间早于生效时间 | 把失效时间改到生效时间之后 |
