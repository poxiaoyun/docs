# 审计日志

审计日志记录平台上对魔哈 Hub 内容的**每一次关键操作**：谁、在什么时候、对哪个模型或数据集、做了什么动作、成没成功。当你需要排查「这个模型是谁删的」「谁把它改成了公开」这类问题时，就来这里查。

:::tip 它和「调用日志」不是一回事
审计日志记录的是**对内容的管理动作**（创建、修改、删除、推送、拉取等）。大模型网关里还有另一个「调用日志」，记录的是 API 调用，两者互不相干。
:::

## 开始之前
- 需要 **系统管理员** 角色。
- 左侧菜单点击 **安全审计** → **审计日志**。

## 筛选记录
页面顶部有一排筛选条件，默认展示**近 1 个月到今天**的记录：

| 筛选项 | 怎么用 |
| --- | --- |
| 开始日期 | 点日期框选择起始日期，默认是当前日期往前一个月 |
| 结束日期 | 点日期框选择截止日期，默认是今天 |
| 组织 | 选择某个组织，或选 **全部组织** |
| 操作类型 | 选择某个动作，或选 **全部操作** |
| 资源类型 | 选择某类资源，或选 **全部资源** |

- 把开始日期选到结束日期之后时，结束日期会自动跟着往后调，反过来也一样，不会出现空区间。
- 条件选好后列表会按新条件重新查询；也可以点 **查询** 手动刷新，点 **重置** 恢复成默认条件。
- 每次改动筛选条件，列表都会自动回到第 1 页。

:::info
这里**没有**按用户搜索的输入框。想定位某个人，可以先用 **组织** 缩小范围，再在「操作用户」这一列里找。
:::

### 操作类型有哪些
| 显示 | 含义 |
| --- | --- |
| 创建 | 新建了一条内容 |
| 更新 | 修改了内容或属性 |
| 删除 | 删除了内容 |
| 推送 | 往仓库里提交了新版本 |
| 拉取 | 从仓库下载了内容 |
| 上线 | 把内容发布上线 |
| 重启 | 重新启动或重新发布 |

### 资源类型有哪些
下拉框里可以选模型、数据集、镜像、空间、组织、收藏、评论、提交、快照、镜像扫描、平台公告、轮播图、镜像站、成员、用户、运行实例、日志、下载、加密、评分、README 等；不确定时留 **全部资源** 即可。

## 列表上有什么
| 列 | 说明 |
| --- | --- |
| 操作时间 | 精确到毫秒，例如 `2026-09-12 14:03:27.481` |
| 操作用户 | 发起这次操作的用户，取不到时显示 `-` |
| 组织 | 操作发生在哪个组织 |
| 操作 | 创建 / 更新 / 删除 / 推送 等，用颜色标签区分 |
| 资源类型 / 名称 | 上行是资源类型，下行是具体资源名称 |
| 方法 | 请求使用的 HTTP 方法，例如 POST、PUT、DELETE |
| 状态码 | 2xx 表示成功（绿），4xx 表示请求有问题（黄），5xx 表示服务出错（红） |
| 耗时 | 这次操作花了多少毫秒 |
| 操作 | 点眼睛图标查看这次操作的详情 |

- 默认每页 **20** 条，按操作时间**从新到旧**排列，用底部分页器翻页。
- 这一页没有搜索框，找记录请用上面的筛选条件。

## 查看一条记录的详情
1. 在目标记录这一行，点击最后一列的**眼睛图标**。
2. 弹窗里会分块展示：
   - **基本信息**：操作时间、操作用户、操作、资源类型、资源名称、组织、耗时。
   - **请求信息**：请求方法、请求路径、来源 IP、请求内容。
   - **响应信息**：HTTP 状态码、响应内容。
   - **父资源链**：这次操作关联的上级资源。
3. 看完点 **关闭**。

## 导出记录
1. 点击页面右上角的 **导出**。
2. 平台会把**当前筛选条件下的全部记录**（不只是当前页）导出成一个 JSON 文件，文件名形如 `moha-audit-20260912-140327.json`。
3. 导出完成后会提示「已下载 N 条审计日志」；当前条件下没有记录时会提示没有可下载的日志。

:::info
记录多时导出需要一点时间，页面不会卡住，稍等提示即可。
:::

## 记录保留多久
默认保留 **90 天**，超过保留期的记录会被平台自动清理。这个保留天数由平台部署时配置：如果被设为 0，则表示永久保留。

## 常见问题
| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 查不到某个组织的历史操作 | 筛选日期区间太窄，或组织选错了 | 放宽开始 / 结束日期，或点 **重置** 后再查 |
| 想按某个用户筛选，但找不到输入框 | 页面不支持按用户筛选 | 先用 **组织** 缩小范围，再在「操作用户」列里找 |
| 状态码是 4xx / 5xx | 这次操作没有成功 | 点眼睛图标看详情里的响应内容，确认失败原因 |
