## 功能简介

BOSS 端镜像仓库管理提供**平台级别**的容器镜像仓库全局管理。系统管理员可查看和管理平台上所有组织创建的容器镜像仓库。

> 💡 提示: 此处的「镜像仓库」指容器镜像（Container Image），与数据镜像同步（[镜像源配置](./mirrors)）不是同一个功能。

## 进入路径

BOSS 控制台 → 资产管理 → **镜像仓库**

前端路由：`/moha/images`

---

## 列表

镜像仓库与模型库、数据集、Space 共用数据管理列表组件，`type = images`。

### 列字段

| 列 | 字段路径 | 说明 |
| --- | --- | --- |
| 别名 / 名称 | `name` / `alias` | 名称列展示 `alias || name`，含描述悬浮提示 |
| 组织 | `organization` | 组织头像 + 名称 |
| 可见性 | `visibility` | 公开 / 私有 / 租户内标签 |
| 仓库容量 | `repositoryStorageSize` | 仓库统计就绪时展示，否则 `-` |
| 下载量 | `annotations.downloads` | — |
| 分类 | `metadata.category` | 可折叠标签组 |
| 加速 | `metadata.accelerate` | 可折叠标签组 |
| 架构 | `metadata.arch` | 可折叠标签组 |
| 更新时间 | `modified` | — |

### 与模型 / 数据集的差异

镜像仓库**没有**以下列：

- 任务（`metadata.tasks`）
- 标签（`metadata.tags`）
- 推荐指数（`annotations.recommendation-score`）

> ⚠️ 注意: 相应地，镜像仓库的**操作列没有「推荐」**，也不展示加密相关标记。

### 筛选

名称搜索、组织筛选、可见性筛选，以及基于元数据 Facet 的高级筛选。

---

## 管理操作

| 操作 | 说明 |
| --- | --- |
| 可见性 | 切换公开 / 私有 |
| 编辑 | 进入编辑页 |
| 删除 | 带确认弹窗，支持批量 |

> ⚠️ 注意: 列表**没有「许可证」列**，也没有安全扫描 / 漏洞等级等列。

---

## 权限要求

需要 **系统管理员** 角色。普通用户和租户管理员应通过 Console → Moha 管理自己的容器镜像。

相关页面：[模型库管理](./models)、[数据集管理](./datasets)、[镜像源配置](./mirrors)。
