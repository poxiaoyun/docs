# 镜像仓库

镜像仓库页面列出**全平台**所有组织创建的容器镜像仓库。容器镜像可以理解成「装系统用的系统盘模板」，用户在智算平台创建实例时用它来决定环境。你可以在这里了解平台上都有哪些镜像、多大、被拉取了多少次，也可以把不该公开的镜像下架或删除。

:::tip 镜像仓库和镜像站不是一回事
- **镜像仓库**（本页）：存放的是**容器镜像**，给容器实例当系统盘用。
- **镜像站**：把 HuggingFace、ModelScope 上的模型和数据集**同步**进平台的任务，和容器镜像毫无关系。

两个名字很像，但一个管「系统盘」，一个管「数据搬运」。
:::

## 开始之前
- 需要 **系统管理员** 角色。
- 左侧菜单点击 **资产管理** → **镜像仓库**。

## 先认识几个词
| 名词 | 通俗解释 |
| --- | --- |
| 仓库 | 一份容器镜像的集合，可以不断推送新版本 |
| 组织 | 这个镜像属于哪个团队账号 |
| 可见性 | 谁能看到这个镜像 |
| 框架 | 镜像里预装的加速框架，例如 CUDA、CANN |
| 架构 | 镜像适用的机器架构，X86 或 ARM |

可见性有三种取值：

| 显示 | 谁能看到并拉取 | 谁能推送新版本 |
| --- | --- | --- |
| 公开 | 任何人，包括没有登录的访客 | 挂在个人名下时只有创建者本人；挂在组织下时该组织成员都可以 |
| 租户内 | 只有所属组织的成员 | 所属组织成员 |
| 个人 | 只有创建者本人 | 创建者本人 |

## 列表上有什么
列表上方是 5 张统计卡片。除了「镜像总数」，其余卡片**只统计当前这一页**的镜像，翻页后数字会跟着变。

| 卡片 | 含义 |
| --- | --- |
| 镜像总数 | 全平台镜像仓库数量，副标题显示当前页镜像的容量合计 |
| 公开镜像 | 当前页里可见性为「公开」的镜像数 |
| 私有镜像 | 当前页里可见性为「个人」的镜像数 |
| 下载总量 | 当前页所有镜像的下载次数合计 |
| 热门镜像 | 当前页里有下载记录的镜像数 |

列表每一行显示这些内容：

| 列 | 说明 |
| --- | --- |
| 别名 / 名称 | 镜像名字；旁边有信息图标时，鼠标移上去可以看到描述 |
| 组织 | 镜像所属的组织 |
| 可见性 | 公开 / 租户内 / 个人；「个人」还会在后面标出创建者 |
| 使用容量 | 仓库已占用的空间，统计完成前显示 `-` |
| 下载次数 | 累计拉取次数 |
| 分类 | 镜像用途分类，例如 网络、数据库、机器学习 |
| 框架 | 镜像支持的加速框架，多个时折叠显示 |
| 架构 | 镜像适用的机器架构，X86 或 ARM |
| 更新时间 | 最近一次修改时间 |

## 找到要处理的镜像
1. 在搜索框里输入镜像的名称或别名，输入后会自动搜索。
2. 需要时用 **组织**、**可见性**、**分类**、**框架**、**架构** 这几个下拉框筛选。
3. 已经选中的筛选条件会直接显示在对应的下拉框上，选回 **全部** 即可取消。

## 把镜像下架（更改可见性）
1. 在目标镜像这一行，点击最右侧的 **⋯** 按钮（操作菜单）。
2. 点击 **更改可见性**。
3. 在 **可见性** 下拉框里选择目标值：**公开**、**租户内** 或 **个人**。
4. 点击 **确定**。

结果确认：列表里这一行的可见性标签立刻变成新值；改成「租户内」或「个人」后，普通用户就看不到、也搜不到这个镜像了。

## 编辑镜像资料
1. 点击最右侧的 **⋯** 按钮 → **编辑**。
2. 页面分 **镜像**、**简介**、**标签**、**可见性** 四张卡片，可以折叠展开：
   - **名称**和 **组织** 不能改，输入框是灰色的。
   - 可以修改 **描述**，以及 **简介**（仓库说明正文）。
   - 可以修改 **分类**、**框架** 这些标签。
   - 可以在 **可见性** 里切换 个人 / 租户内 / 公开。
3. 改完点击 **确定**，会自动回到镜像仓库列表。

## 删除镜像
1. 点击最右侧的 **⋯** 按钮 → **删除**；也可以先勾选多行，再用列表上方的批量删除。
2. 弹出的确认框会显示「确定删除镜像 xxx 吗？」。
3. 按提示手动输入这个镜像的名称，**确定** 按钮才会变成可点。
4. 点击 **确定**。

:::warning 删了就找不回来
删除会永久删除这个镜像仓库，以及里面的所有版本，**无法恢复**。请先确认确实不再需要，再执行删除。
:::

## 常见问题
| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| **⋯** 菜单里没有「推荐」 | 镜像不支持推荐功能 | 需要推荐请用 [模型库](/boss/moha-admin/models) 或 [数据集](/boss/moha-admin/datasets) |
| 「使用容量」一直显示 `-` | 平台还在统计这个仓库的容量 | 稍后刷新页面再看 |
| 列表里没有「漏洞等级」「许可证」等列 | 这些信息不在镜像列表里展示 | 属于正常现象 |
