# 镜像站

镜像站用来把外部平台（**HuggingFace**、**ModelScope 魔搭社区**）上现成的模型和数据集**同步**到本平台。同步完成后，用户在本平台就能直接下载这些内容，不必再翻墙或受外部网络影响。你在这里负责建同步任务、触发同步、查看同步结果。

:::tip 镜像源是什么
镜像源就是「内容从哪来」。一条镜像任务 = 一个外部仓库 + 一个本平台的目标组织。可以理解成给外部仓库在本平台开了一个「自动更新的分身」。
:::

## 开始之前
- 需要 **系统管理员** 角色。
- 左侧菜单点击 **数据同步** → **镜像站**。

## 镜像站和镜像仓库不一样
| | 镜像站（本页） | [镜像仓库](/boss/moha-admin/images) |
| --- | --- | --- |
| 管什么 | 从外部平台同步模型、数据集 | 存放容器镜像 |
| 内容 | 模型文件、数据文件 | 容器镜像（当系统盘用） |

## 两种内容分开管
页面顶部有 **模型** 和 **数据集** 两个页签，分别列出模型镜像任务和数据集镜像任务。切换页签会切到对应的列表。

## 列表上有什么
| 列 | 说明 |
| --- | --- |
| 名称 | 同步后在本平台的名称 |
| 镜像源 | 内容来自哪个平台：ModelScope (魔搭社区) 或 HuggingFace |
| 组织 | 同步到哪个组织名下 |
| 状态 | 同步中 / 已同步 / 同步失败 / 已暂停 |
| 上次同步时间 | 最近一次同步完成的时间 |

## 新增一条镜像任务
1. 先切到 **模型** 或 **数据集** 页签。
2. 点击右上角 **添加模型镜像任务**（或 **添加数据集镜像任务**）。
3. 在 **任务配置** 卡片里填写：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 组织 | 选择同步到哪个组织 | 同步进来的内容会挂在这个组织下；创建后不能改 |
   | 镜像源 | 选 ModelScope (魔搭社区) 或 HuggingFace | 创建后不能改 |
   | 名称 | 填外部仓库路径，例如 `Qwen/Qwen2.5-7B` | 创建后不能改；同步后在平台上的名字取路径最后一段 |
   | Token | 仓库需要授权时才出现 | 受限仓库（例如 Gated Models）必须填；公开仓库不用填 |
   | 同步所有引用 | 默认关闭 | 打开后按界面提示，同步所有远程分支、标签（Tags）和提交记录 |

4. 填完 **镜像源** 和 **名称** 后，平台会自动探测这个仓库是否存在：
   - 探测期间，名称输入框右侧会显示 **验证中**。
   - 仓库不存在时，**确定** 按钮不可点。
   - 仓库存在但需要授权时，才会出现 **Token**（访问令牌）输入框，并且必须填写。
5. 点击 **确定**。

结果确认：回到列表后，这条任务的状态先变成 **同步中**，同步完成后变成 **已同步**，「上次同步时间」也会更新。同步期间，[模型库](/boss/moha-admin/models) 或 [数据集](/boss/moha-admin/datasets) 里对应条目的名称旁边会显示 **同步中...** 标签，同步完成后这个标签消失。

:::info
公开仓库不需要填任何认证信息；受限仓库必须提供 Token，否则探测会失败、无法提交。
:::

## 手动同步和停止
1. 在目标任务这一行点击最右侧的 **⋯** 按钮（操作菜单）。
2. 状态不是「同步中」时，菜单显示 **同步**；点击后确认，会立即同步一次。
3. 状态是「同步中」时，菜单显示 **停止**；点击后确认，会中止这次同步。

平台每天还会自动同步一次，不需要你手动点。

## 修改一条镜像任务
1. 点击最右侧的 **⋯** 按钮 → **编辑**。
2. 只能修改 **Token** 和 **同步所有引用**；**组织**、**镜像源**、**名称** 创建后都不能改。
3. 改完点击 **确定**。如果想改来源或仓库，请删掉重建一条任务。

## 删除一条镜像任务
1. 点击最右侧的 **⋯** 按钮 → **删除**；也可以先勾选多行，再用列表上方的批量删除。
2. 按提示手动输入任务名称，**确定** 按钮才会变成可点。
3. 点击 **确定**。

:::warning 删除镜像任务不会删掉已同步的内容
删除只是停止这个任务继续同步。之前已经同步下来的模型或数据集仓库会**保留**在原组织下，之后不再自动更新。如果连内容也要清理，请到 [模型库](/boss/moha-admin/models) 或 [数据集](/boss/moha-admin/datasets) 里删除对应仓库。
:::

## 常见问题
| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 提交时提示「仓库不存在」 | 仓库路径写错了 | 核对 `组织名/仓库名` 的拼写后重新填写 |
| 提交后一直同步失败 | Token 失效，或外部平台网络异常 | 点 **编辑** 更新 Token，再点 **同步** 重试 |
| 模型库 / 数据集里有「同步中...」标签但一直不消失 | 同步还没跑完，或同步失败 | 回到本页看这条任务的状态和上次同步时间 |
| 状态是「已暂停」 | 系统当前没有在跑这条同步 | 点 **同步** 手动触发一次 |
