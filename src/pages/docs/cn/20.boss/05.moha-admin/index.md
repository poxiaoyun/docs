# Moha 仓库管理

魔哈 Hub 是平台内部的「模型应用商店 + 网盘」：用户把自己做好的模型、数据集、容器镜像、空间上传上来，也可以直接下载别人公开的内容。这一组页面是**平台管理员**的后台，你在这里能看到全平台所有用户的内容（包括没有公开的），并对它们做治理。

:::tip 把魔哈 Hub 想成什么
可以把它想成公司内部的「应用商店 + 网盘」：模型和数据集是货架上的商品，容器镜像是装系统用的系统盘，空间是别人做好的在线小应用。用户自己上架，管理员负责维持货架秩序。
:::

## 开始之前
- 你的账号需要有 **系统管理员** 角色。普通用户看不到这一组菜单，他们只能在自己的魔哈 Hub 里管理自己创建的内容。
- 顶部导航点击 **魔哈Hub** 后，这一组页面分散在左侧栏的四个分组里：**资产管理**、**数据同步**、**安全审计**、**系统设置**。

## 先认识几个词
| 名词 | 通俗解释 |
| --- | --- |
| 魔哈 Hub | 平台内部托管模型与数据的站点，用户在这里上传、下载、分享 AI 资产 |
| 仓库 | 一个可以上传、下载、带版本记录的内容单元；模型、数据集、镜像、空间都是仓库 |
| 模型 | 训练好的模型文件包，下载后可以拿去推理或继续微调 |
| 数据集 | 用来训练或评测的数据文件包 |
| 镜像仓库 | 容器镜像的存放处，容器镜像可以理解成「装系统用的系统盘模板」 |
| 空间 | 用户用代码搭出来的在线 AI 应用，有自己的访问地址，可以发布上线或停止 |
| 可见性 | 谁能看到这个仓库：公开 / 租户内 / 个人 |
| 组织 | 内容归属的团队账号，每个仓库都属于某个组织 |
| 推荐 | 管理员给优质仓库打的标记，带推荐指数和推荐理由，会进入用户端的推荐位 |
| 镜像源 | 帮用户把 HuggingFace、ModelScope 上的现成内容同步进平台的中转站 |
| 公告 | 展示在魔哈 Hub 首页的信息 |
| 轮播图 | 展示在魔哈 Hub 首页顶部的横幅图片，可以点击跳转 |

## 你能做什么
- **看全量数据**：四个资产管理页面都列出全平台所有组织的内容，包括被设为「个人」的私有仓库，这是普通用户在用户端看不到的。
- **改可见性（下架）**：把不该公开的内容从「公开」改成「租户内」或「个人」，用户端就看不到、也搜不到了。
- **设置推荐**：给模型、数据集、空间打推荐指数并写推荐理由，它们就能进入用户端的推荐位。
- **删除**：删除任意组织下的仓库，也可以删除镜像任务、公告、轮播图。
- **查审计、导数据**：按时间等条件筛选全平台操作记录，并导出成文件。

## 你不能做什么
- 不能替用户上传、提交或修改仓库里的文件内容——上传和版本管理都在用户自己的魔哈 Hub 里完成。
- 不能启动、停止或重启实例：空间和镜像的运行控制不在这一组页面里。
- 没有单独的「审核通过 / 驳回」流程，治理手段就是**改可见性**和**删除**这两类。
- 公告和轮播图只控制「什么时候显示」，不能只投放给某个组织或某个用户。
