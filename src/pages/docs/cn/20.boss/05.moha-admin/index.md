## 概述

Moha 仓库管理是 Boss 运营平台中用于维护 Moha 模型仓库的模块。管理员可在此统一管理平台内所有模型、数据集、镜像与 Space 资源，配置镜像源，并维护审计日志与首页运营内容。

## 章节导航

| 模块 | 说明 |
| --- | --- |
| [模型库管理](/boss/moha-admin/models) | 查看和管理平台内所有模型资源 |
| [数据集管理](/boss/moha-admin/datasets) | 查看和管理平台内所有数据集 |
| [镜像仓库管理](/boss/moha-admin/images) | 查看和管理平台内所有容器镜像 |
| [Space 管理](/boss/moha-admin/spaces) | 查看和管理所有组织创建的 Space |
| [镜像源配置](/boss/moha-admin/mirrors) | 配置外部镜像源（HuggingFace、ModelScope）并同步 |
| [审计日志](/boss/moha-admin/audit) | 查看平台级操作审计日志并导出 |
| [公告管理](/boss/moha-admin/announcements) | 维护平台首页公告 |
| [Banner 管理](/boss/moha-admin/banners) | 维护平台首页横幅位 |
