# 首页

首页是你登录 BOSS 后看到的第一屏，用来**一眼掌握平台整体情况**。它由三块卡片组成：上面一整行是 Moha 资源，左下是 LLM 网关概览，右下是平台管理。三块卡片的数据都来自真实接口，不是示例数据。

:::tip 怎么用这一页
把它当成「仪表盘」：每天上班先扫一眼——平台管理卡片里的**待关注项**是不是空的，网关卡片的**错误率**是不是接近 0。有红色或警告就点进去处理。
:::

## 开始之前

- 你需要一个能登录 BOSS 的管理员账号，不需要其他前置操作。
- 本页只负责「看」，具体改动要到对应的管理菜单里做。

## 三块卡片分别是什么

| 卡片 | 看什么 | 数据范围 |
| --- | --- | --- |
| Moha 资源 | 平台上模型、数据集、空间、镜像的总量和热门排行 | 全平台 |
| LLM 网关概览 | 大模型调用的请求量、延迟、Token 消耗、错误率 | 最近 24 小时 |
| 平台管理 | 租户、集群、用户的数量，以及需要你处理的异常项 | 全平台 |

## Moha 资源卡片

卡片标题是 **Moha 资源**，副标题是 **资产统计**。

### 左侧的四个数字

| 指标 | 代表什么 |
| --- | --- |
| 模型 | 全平台模型库里的模型总数 |
| 数据集 | 全平台的数据集总数 |
| 空间 | 全平台的开发空间总数 |
| 镜像 | 全平台的镜像仓库里镜像总数 |
| 存储 | 标题右侧单独显示，是这些资源占用的总存储用量 |

### 下面的「分布」

一条三段式的比例条，配上文字百分比，说明资源分别有多少是公开、多少是租户内、多少是个人：

| 名称 | 含义 |
| --- | --- |
| 公开 | 所有人都能看到和下载 |
| 租户内 | 只有资源所属租户的成员能看到 |
| 个人 | 只有创建者本人（以及授权成员）能看到 |

如果三类资源加起来是 0，这里会显示「暂无数据」。

### 右侧的「热门排行」

列出近期下载最多的资源，每条显示资源名称（鼠标悬停可以看到它的「空间/名称」全名）、体积、下载次数，以及右侧的类型标签（模型 / 数据集 / 空间 / 镜像）。没有数据时显示「暂无热门项目」。

:::info 热门排行是只读的
这里的条目不能点开，只用于观察趋势。想管理某个资源，请到 **资产管理** 分组下对应的菜单。
:::

## LLM 网关概览卡片

卡片标题是 **LLM 网关概览**，副标题是 **最近 24 小时流量与调用统计**。这一屏固定展示**最近 24 小时**，页面上没有时间范围筛选，也不能改成「最近 7 天」之类。

### 顶部四个关键数字

| 指标 | 代表什么 | 数字下面的涨跌怎么看 |
| --- | --- | --- |
| 总请求数 | 这 24 小时内所有模型被调用了多少次 | 变绿代表变多，是好事 |
| 平均延迟 | 每次调用的平均耗时，单位毫秒（ms） | 变绿代表变快，是好事 |
| 总 Token 消耗 | 这 24 小时消耗的 Token 总量 | 变绿代表变多 |
| 错误率 | 调用失败的比例 | 变绿代表变低，是好事 |

涨跌幅是和上一个同样长度的时间段比出来的。变化极小（几乎为 0）时直接显示 `0%`，不带正负号。

### 中间的「流量趋势（24h）」

一张面积图，横轴是最近的 24 个小时（格式如 `14:00`），里面有两条曲线：**请求数**和 **Token 消耗**。鼠标移到图上可以看到具体时刻的数值。没有任何调用时显示「暂无数据」。

### 右侧的「模型调用排行」

按请求量从多到少列出最多 5 个模型。每条包含模型名、请求次数、一条表示「该模型占总请求量比例」的进度条，下面还有一行「多少 tokens · 多少 次请求」。没有调用记录时显示「暂无模型调用数据」。

:::warning 整块报错时
如果这块卡片只显示一条红色错误提示、没有任何数字，说明网关的统计数据接口暂时取不到。这不代表网关坏了，可以稍后重新进入本页再看。
:::

## 平台管理卡片

卡片标题是 **平台管理**，右上角有一个 **打开管理** 按钮，点击会跳到[租户管理](/boss/iam/tenants)。

### 顶部的三个数字

| 指标 | 代表什么 |
| --- | --- |
| 租户 | 平台上的租户总数 |
| 集群 | 已接入的算力集群总数 |
| 用户 | 平台上的用户账号总数 |

### 中间的「平台快照」

只有把对应列表完整取回来之后才会显示，某一项取不到就不显示（而不是显示 0）：

| 快照项 | 代表什么 |
| --- | --- |
| 已启用租户 | 状态为「激活」的租户有多少个 |
| 已连接集群 | 已经成功连上的集群有多少个 |
| 已发布集群 | 已经发布、可以给租户使用的集群有多少个 |
| 已开启 MFA 用户 | 自己开启了多因素认证的用户有多少个 |

### 底部的「待关注项」

这里只列出**真的有**的问题，每条都带一个 **详情** 按钮，点了直接跳到能处理它的页面：

| 待关注项 | 什么情况下出现 | 点「详情」去哪 |
| --- | --- | --- |
| 已禁用租户 | 有租户处于禁用状态 | 租户管理 |
| 未连接集群 | 有集群连不上 | 集群管理 |
| 未发布集群 | 有集群还没发布 | 集群管理 |

如果这些都不存在，底部会显示绿色的「当前无待关注项」，说明平台处于正常状态。

:::info 数据取不全时会怎样
只要租户、用户、集群三份数据里有任意一份取不到，卡片顶部会出现一条黄色提示，写明是哪一类数据暂时不可用，其余数据照常显示。
:::

## 数据多久更新一次

页面打开时会自动加载一次数据，并缓存在本次会话里。页面上**没有刷新按钮**，也没有设置自动刷新间隔的入口。想拿到最新数字，重新进入本页即可。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 首页看不到任何筛选或时间选择 | 本页设计如此 | 需要更细的统计请到 **大模型网关 → 数据看板** 或集群的仪表盘页面 |
| 某个数字显示为 `-` | 该数据源这一次没取到 | 稍后重新进入本页 |
| 想调整卡片顺序或换掉某块卡片 | 不支持 | 三块卡片的内容和位置是固定的 |
