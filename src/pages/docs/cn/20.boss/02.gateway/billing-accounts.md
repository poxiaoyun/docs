# 计费账户

计费账户是**每个人的默认钱包**。模型调用产生的费用、购买套餐花的钱，都从这个账户进出。这一页是全平台唯一能给账户加钱、减钱的地方。

读完你能完成：找到某个人的账户、看它的余额构成、给它充值或退款、设信用额度、换绑账户费率，以及查每一笔流水。

:::tip 账户像公司给每个人开的备用金
每个人一个钱包，花完就没了。信用额度是「允许先欠一点」的额度，不是白给的钱；套餐是提前买好的一包点数，用的时候先扣点数，点数不够才动余额。
:::

## 开始之前

- 权限：需要平台管理员账号（能进入 Boss 管理控制台）。
- **这一页不能新建、也不能删除账户**。账户在用户注册、创建 API 密钥、或打开费用页时自动生成；找不到某人的账户，说明他还没产生过这些动作。
- 需要先有费率方案，才能给账户换绑账户费率。

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 计费账户 | 每个人的默认钱包，自动生成，全平台唯一 |
| 余额 | 账户里的钱，充值加、扣费减，可以是负数 |
| 可用余额 | 现在真正能用的钱。被冻结的金额不计入，所以通常小于或等于余额 |
| 冻结额 | 暂时被占住、不能动用的金额 |
| 信用额度 | 允许透支的额度。`0` 表示没有信用额度 |
| 账户费率 | 这个账户默认按哪份费率方案算钱。没单独选时用平台默认方案 |
| 套餐点数 | 订阅套餐里的预付费点数，1 点 = 0.01 元；生效期内优先于账户费率 |
| 幂等键 | 每笔资金变动自带的一串标识。同一笔重复提交不会重复入账，可在流水里核对 |

## 账户列表怎么看

| 列 | 含义 |
| --- | --- |
| 用户 | 账户所有者，显示头像与昵称 |
| API KEY | 这个人名下的密钥数量 |
| 可用余额 | 现在真正能用的金额 |
| 余额 | 账户账面金额 |
| 冻结额 | 被占住不能动的金额 |
| 信用额度 | 允许透支的额度 |
| 费率方案 | 绑定的方案名；没有单独绑定时显示平台默认方案的名字 |
| 状态 | 正常 / 冻结 / 欠费 / 停用 |

这一页**没有搜索框、没有筛选，也没有新建按钮**——列表就是全平台所有账户。账户多了以后按列排序或翻页查找。

行末折叠菜单有七个操作：**充值金额**、**调整金额**、**退款**、**信用额度**、**账户费率**、**账户流水**、**账户订阅**。

## 充值、调整、退款

三个操作长得几乎一样，区别只在金额能不能为负、以及记成什么类型的流水。

1. 在目标账户那一行点 **充值金额**（或 **调整金额** / **退款**）。
2. 填 **金额**：充值退款必须大于 `0`；调整可以为负数，但不能是 `0`。最多 6 位小数。
3. 填 **原因**（必填，例如「客户对公转账，工单 1234」）。
4. 点 **确认**。

| 操作 | 金额规则 | 记成什么流水 |
| --- | --- | --- |
| 充值金额 | 必须大于 `0`，最多 6 位小数 | 充值 |
| 调整金额 | 可以为负数，不能为 `0` | 调整 |
| 退款 | 必须大于 `0`，最多 6 位小数 | 退款 |

:::warning 原因一定要写清楚
流水是事后对账的唯一凭据。原因写得含糊，三个月后没人说得清这笔钱是为什么动的。建议写上来源（对公转账、工单号、补偿原因）。
:::

:::info 幂等键是自动的
你不需要手填幂等键。每笔操作由系统生成一个，重复提交不会重复入账；在 **账户流水** 里能看到每笔的幂等键，用来和财务系统对账。
:::

## 设置信用额度

信用额度决定这个人能欠多少钱。它**不改余额**，也不等于给了钱。

1. 在目标账户那一行点 **信用额度**。
2. 填一个大于等于 `0` 的数，最多 6 位小数。
3. 点 **确认**。

界面上写着：**0 表示没有信用额度。这不改变余额，也不打开全局欠费。**

:::info 信用额度和「允许欠费使用」不是一回事
[网关配置](/boss/gateway/config) 里的「允许欠费使用」开关是固定关闭、不可修改的。真正决定某个人能不能继续用的，是这里的**信用额度**加上余额预检：余额不足、又超出信用额度时，请求会被拒绝。
:::

## 设置账户费率

账户费率决定这个账户按哪份价目表算钱。

1. 在目标账户那一行点 **账户费率**。
2. 在列表里选一份费率方案。每个选项后面标着它的范围（平台/租户）· 状态 · 是否默认 · 明细条数。
3. 点 **确认**。

:::warning 套餐生效期内，套餐费率优先
账户上绑的方案只是「没有套餐时的默认价」。只要这个人有生效中的订阅，且套餐挂了自己的费率方案，就优先用套餐那份。所以换绑账户费率后，如果发现价格没变，先看有没有生效中的订阅。
:::

## 查流水

在目标账户那一行点 **账户流水**，弹窗标题是「（昵称）的流水」。

| 列 | 含义 |
| --- | --- |
| 时间 | 这笔资金变动发生的时间 |
| 类型 | 扣费 / 充值 / 退款 / 调整 / 购买套餐 |
| 金额 | 变动金额，正负号表示方向 |
| 余额 | 这笔之后的账户余额 |
| 幂等键 | 这笔操作的唯一标识，用于对账 |

想直接看这个人的订阅，点 **账户订阅**，会跳到 [订阅管理](/boss/gateway/billing-subscriptions) 并自动按这个用户筛好。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 找不到某个人的账户 | 他还没注册完、没有密钥、也没打开过费用页 | 让他先在 Console 打开一次费用页，或先给他建一把 API 密钥，账户会自动生成 |
| 余额是负数 | 开着超额扣费，用量超过了点数与余额 | 充值补平，或关掉该订阅的超额扣费 |
| 可用余额比余额小 | 有金额被冻结 | 看 **冻结额** 列，冻结通常来自进行中的结算 |
| 状态是「欠费」 | 余额低于可用下限 | 充值，或调高信用额度 |
| 改了账户费率但价格没变 | 有生效中的订阅，套餐费率优先 | 到订阅管理确认订阅状态 |
| 想删掉一个账户 | 这一页不支持删除 | 账户随用户存在，不能单独删除 |
