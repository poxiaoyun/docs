# 费率方案

费率方案是全平台的**价目表**。每次调用用掉多少 Token，就按这里写的价格折成金额。没在方案里单独标价的模型，一律按**平台默认方案**算钱。

读完你能完成：建一份方案、给模型设置价格、看懂每条明细的时效和渠道覆盖、在调价前跑一次影响分析，以及安全地停用或切换默认方案。

:::tip 价目表只改未来，不改过去
费率方案像餐厅的菜单：今天改了价，今天之后的账单按新价算，昨天已经结过的单不会重算。所以调价的做法不是「改掉旧价」，而是「加一条新价，把旧价结束掉」。
:::

## 开始之前

- 权限：需要平台管理员账号（能进入 Boss 管理控制台）。
- 先理解一条规则：**全平台只保留一个默认方案**。设为默认会取消其他方案的默认标记。
- 如果只是想让渠道能启用，最少需要在默认方案里给那个模型加一条**当前有效**的价格。

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 费率方案 | 一份价目表。所有价格都挂在某一份方案上 |
| 默认方案 | 带星标的那一份。没有任何专属价格的模型都按它算；全平台只有一份 |
| 价格明细 | 方案里的一行价格，写明「哪些模型、走哪条渠道、多少钱、什么时候有效」 |
| 模型匹配 | 这条价格适用于哪些模型。可写精确名、`gpt-*` 这类通配，或 `*`（全部模型） |
| 渠道覆盖 | 只对某一条渠道生效的价格。留空表示这是该模型的**统一价** |
| 统一价 | 不绑渠道的价格，模型走任何渠道都用它 |
| 未定价 | 没有任何有效明细覆盖这个模型，调用会被记成缺价 |
| 0 元 | 明确写了 `0` 的价格，表示免费。和「未定价」是两种状态 |
| 价层 | 这次调用最终用了哪一层价格：专属费率、套餐费率、账户费率、租户默认、平台默认、目录价、补价 |

:::info 价格最多 6 位小数
金额按十进制输入，最多保留 6 位小数。内部按微元记账（1 元 = 1,000,000 微元），页面显示的仍然是普通金额。
:::

## 方案列表怎么看

| 列 | 含义 |
| --- | --- |
| 名称 | 方案名称，默认方案后面带一颗星；点名称进入价格明细 |
| 默认 | 是 / 否。全平台只有一个「是」 |
| 价格明细 | 这份方案里有几条价格，显示为「N条」 |
| 状态 | 启用 / 停用 |

列表上方有 **状态** 筛选，取值 **启用** 与 **全部**，**默认只看启用**的方案。停用的方案要切到「全部」才看得到。

行末折叠菜单有五个操作：

| 操作 | 作用 |
| --- | --- |
| 编辑方案 | 改名称、状态、是否默认 |
| 价格明细 | 打开明细页，看历史价和当前价 |
| 设置价格 | 直接给这份方案追加一条价格 |
| 影响分析 | 看停用这份方案会影响多少账户、密钥绑定和渠道 |
| 克隆方案 | 只对默认方案出现，按折扣复制出一份新方案 |

## 创建一份方案

1. 点击右上角 **创建费率方案**。
2. 填 **名称**（必填）。
3. 选择是否设为 **默认**（是 / 否），默认是「否」。
4. 点 **保存**。

弹窗上方有两段提示：一是「先建空方案，再追加价格」；二是把「是否默认」选成「是」时出现的红字——**设为默认会取消其他方案的默认标记。全平台只保留这一个默认方案。**

:::info 先建空方案是正常做法
新建的方案里没有价格，这是可以的。价格要一条一条 **设置价格** 追加进去。空方案如果设为默认，会让原本有价的模型变成未定价，所以更常见的顺序是：先建方案 → 加价格 → 确认无误后再设为默认。
:::

## 设置价格

设置价格就是给方案**追加一条明细**。入口有两个：方案列表行末的 **设置价格**，或明细页右上角的 **设置价格**。

1. 在 **模型匹配** 里选或输入模型名。下拉里是渠道里出现过的全部模型，选项后面会标出它当前的状态（未定价 / 0 元 / 当前价）。
2. **渠道覆盖** 留空，表示这是模型的**统一价**；只有想让某条渠道单独定价时才选一条渠道。
3. 填 **输入价** 和 **输出价**，两项都必填，单位是元 / 百万 Token。填 `0` 表示免费，不能留空。
4. 按需填 **缓存读取价**、**缓存写入价**（默认 `0`）和 **按次价**（默认 `0`，单位元 / 次）。
5. 点 **保存**。

| 字段 | 必填 | 单位 | 说明 |
| --- | --- | --- | --- |
| 模型匹配 | 是 | — | 精确名、glob 或 `*` |
| 渠道覆盖 | 否 | — | 留空即统一价 |
| 输入价 | 是 | 元 / 百万 Token | 按发给模型的输入 Token 计费 |
| 输出价 | 是 | 元 / 百万 Token | 按模型生成并返回的 Token 计费 |
| 缓存读取价 | 否 | 元 / 百万 Token | 命中缓存读取内容时的价格 |
| 缓存写入价 | 否 | 元 / 百万 Token | 把本次上下文写入缓存时的价格 |
| 按次价 | 否 | 元 / 次 | 每次**成功**请求收一次，失败不收；适合图片、语音这类模型 |

:::warning 留空不等于未定价
留空会让保存按钮点不动；只有填了数才能保存。想表达「这个模型没有价」，正确做法是**不建这条明细**，让调用落到 [计价异常](/boss/gateway/usage-events)，而不是随手填 `0`。填 `0` 会被当成免费。
:::

## 价格明细怎么读

在方案列表点方案名称（或行末 **价格明细**）进入明细页。页面顶部说明这份方案的价格明细：当前价仍参与计价，历史价只用来对照当时的账单。

| 列 | 含义 |
| --- | --- |
| 模型匹配 | 这条价格覆盖的模型；后面带「有效」或「过期」徽标。`*` 显示为「\*(全部模型)」 |
| 渠道覆盖 | 空白表示模型统一价；写明的渠道若已删除会标「渠道已失效」，已停用会标「渠道已停用」 |
| 输入价、输出价、缓存读取价、缓存写入价 | 元 / 百万 Token。没有单独写价的列会显示「统一价」，表示用同名模型统一价；完全没有价则显示「未定价」 |
| 按次价 | 元 / 次 |
| 生效时间 | 这条价格从什么时候开始算 |
| 结束时间 | 没有值时显示「仍有效」 |

列表上方有 **时效** 筛选：**有效**（默认）或 **全部**。切到「全部」才能看到已经过期的历史价格。

行末操作只有一个 **提前结束**，且仅对「没有结束时间、又是真实存在的明细」出现。

## 提前结束一条价格

1. 打开明细页，把 **时效** 切到 **有效**。
2. 找到要停掉的那条价格，点行末 **提前结束**。
3. 结束时间是「现在」，之后不再参与计价。

:::error 会被拒绝的情况
如果结束这条价格会让某条**已启用渠道**的某个模型失去定价，控制面会拒绝，并提示「已启用渠道将失去定价：（模型名）」。

正确做法是：先给这些模型补一条新的有效价格，再结束旧的；或者先禁用相关渠道。
:::

## 影响分析

在方案列表行末点 **影响分析**，会看到这份方案当前的影响面：

| 提示 | 含义 |
| --- | --- |
| 影响 N 个账户、M 个密钥绑定，回退到 X | 停用后有这么多人/密钥会改用回退方案 |
| 失去默认价 | 列出会失去默认价的模型 |
| 已启用渠道将失去定价 | 这些渠道会因为没价而无法继续启用 |
| 受影响的渠道 | 具体是哪几条渠道 |
| 套餐 X 用这份方案折算点数 | 有套餐引用这份方案。**先给这些套餐换一份方案，才能停用** |

停用、删除方案，或者取消默认标记之前，先看一次影响分析，比事后查账单便宜得多。

## 克隆方案

**克隆方案** 只对默认方案出现，用来快速做一份「同价但打折」的方案。

1. 在默认方案那一行点 **克隆方案**。
2. 填新方案名称。
3. 填 **折扣（折）**：`10` 是原价，`8` 是 8 折，`8.5` 是 8.5 折。
4. 点 **保存**。

克隆只复制默认方案里**当前有效**的价格，历史价不会带过来。复制出来的每条价格之后都可以单独再改。

## 停用与切换默认方案

- **停用**：在 **编辑方案** 里把状态改成「停用」。停用后这份方案不再参与计价；引用它的套餐必须先换方案。
- **切换默认**：把另一份方案设为默认即可。原默认方案的默认标记会被自动取消。

:::warning 默认方案不能直接取消
编辑默认方案时，「是否默认」这一项是禁用的，并提示「这是平台唯一的默认方案，不能直接取消。要更换默认方案，请把另一份方案设为默认。」
:::

## 实时价格工具

明细页右上角的 **实时价格工具** 会拉取一份上游官网价，方便你和自己的定价对照。

| 元素 | 说明 |
| --- | --- |
| 获取时间 | 这批价格是什么时候抓的 |
| 平台汇率 | 显示 1 人民币兑多少美元、1 美元兑多少人民币 |
| 重新获取 | 再拉一次最新价格 |
| 搜索模型 | 在这批价格里按模型名过滤 |
| 供应商 | 每条价格来自哪家 |

:::info 抓不到价时会怎样
如果这次没有拿到新价格，弹窗会提示下面仍是浏览器上次缓存的结果；如果没有配置人民币兑美元汇率，则只显示美元价，需要先去 [货币配置](/boss/gateway/currency-settings) 填汇率。
:::

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 方案列表是空的 | 筛选停在「启用」，而方案都是停用状态 | 把 **状态** 切成 **全部** |
| 保存价格按钮点不动 | 输入价或输出价留空了 | 两项都必填；要免费就填 `0` |
| 调用日志显示「未定价」 | 没有有效明细覆盖这个模型，或模型名对不上 | 给这个模型加一条当前有效的价格，注意精确匹配名称 |
| 明细里的渠道标「渠道已失效」 | 这条价格绑的渠道被删了 | 重新追加一条不绑渠道的统一价，或改绑到现有渠道 |
| 结束价格被拒绝 | 已启用渠道会因此失去定价 | 先补新价再结束旧价，或先禁用相关渠道 |
| 想停用方案但停不了 | 有套餐正在用它折算点数 | 先在这些套餐上换一份方案，再停用 |
| 想改一条老价格 | 已生效的价格不能改 | 追加一条新价，旧价会自动结束，或手动 **提前结束** |
