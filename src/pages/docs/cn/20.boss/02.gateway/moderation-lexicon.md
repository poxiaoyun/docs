# 敏感词管理

敏感词管理维护的是内容审核的**词库**：有哪些词要盯、每个词有多敏感。网关在请求进出时按词库逐条匹配，匹配到的分数再交给 [策略管理](/boss/gateway/moderation-policies) 判断该放行、该替换还是该拦截。

读完你能完成：新建和编辑词条、按分类和风险等级找词、批量导入一批词、导出备份，以及批量启用或停用。

:::tip 词库是违禁品清单
安检机需要两样东西：一份**违禁品清单**（这一页），和一套**处置规则**（策略管理）。清单只负责「什么算敏感、有多敏感」，规则负责「查到了怎么办」。改清单不用动规则，改规则也不用重录清单。
:::

## 开始之前

- 权限：需要平台管理员账号（能进入 Boss 管理控制台）。
- 确认总开关是开的：到 **大模型网关 → 平台设置 → 网关配置**，检查 **启用内容审核** 处于开启状态。关掉它，词库和策略都会暂停生效（配置不会丢）。

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 词条 | 一条要被检测的敏感词 |
| 评分 | 这个词有多敏感，`1`–`10`。分数会累加进这次调用的总风险分 |
| 风险等级 | 评分换算出的档位：高（≥ 8）/ 中（≥ 5）/ 低 |
| 分类 | 这个词属于哪一类，可多个。只用于归类和筛选，不参与匹配 |
| 词性 | 文字属性（名词、动词等），选填，只用于描述 |
| 标签 | 自定义标签，可多个，方便筛选 |

## 创建与编辑敏感词

1. 点右上角 **创建敏感词**。
2. 填写表单：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 敏感词 | 要检测的词 | 必填，创建后**不能修改** |
   | 评分 | 例如 `5` | 必填，范围 `1`–`10`，默认 `5`；越高越敏感 |
   | 分类 | 从预置项里选，或自己输入 | 可多个，输入后回车添加 |
   | 词性 | 例如「名词」 | 选填 |
   | 标签 | 从常用标签里点选，或自己输入 | 可多个 |

3. 点 **确定**。

**常用分类**：政治、暴恐、民生、涉枪涉爆、色情、非法网站、广告、GFW、反动。

**常用标签**：中文、英文、拼音、政治敏感、选举相关、人名、个人信息、网址、营销、高风险。

:::info 匹配靠词条，不靠正则
检测是按词库里的**词条**逐条匹配的，分类和标签只用于归类筛选，不参与匹配。界面里没有写正则表达式的地方。
:::

## 批量导入与批量导出

- **批量导入**：点 **批量导入**，在弹窗里点 **选择文件** 上传一个 JSON 文件；解析成功会显示「已解析 N 个词条」，再点 **批量导入** 提交。文件最大 2MB，内容必须是 JSON 数组。
- **批量导出**：点 **批量导出** 并确认，会把全部词条下载成一个 JSON 文件（文件名形如 `moderation-lexicon-日期.json`），方便备份或迁移。

:::warning 导入前先导出一份
导入只做新增，不做去重提示。改词库之前先 **批量导出** 备份，出问题时才有对照。
:::

## 批量启用、禁用与删除

勾选词条后，列表上方会出现操作条，显示「已选择 N 个词条」，可执行：

| 操作 | 效果 |
| --- | --- |
| 批量启用 | 把选中的词条全部改为启用 |
| 批量禁用 | 把选中的词条全部改为禁用，暂停参与检测 |
| 批量删除 | 从词库中删除选中的词条 |

:::warning 批量删除不可撤销
删除词条会立刻从检测范围里移除，且无法恢复。删除前先 **批量导出** 备份。
:::

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 命中记录一直为空 | 总开关关闭、词条未启用，或没有策略 | 检查网关配置的「启用内容审核」，确认词条已启用，并到策略管理建一条规则 |
| 敏感词改不了 | 词条创建后不可修改 | 新建一条需要的词，再删掉旧的 |
| 导入失败 | 文件不是 JSON 数组，或超过 2MB | 按格式重新导出、修改后再导入 |
| 想用正则但找不到入口 | 检测按词条匹配 | 把需要拦截的字符串逐个加进词库 |
| 同一个词命中次数很高 | 确实被反复命中 | 属正常；想减少干扰就调整评分或策略阈值 |
