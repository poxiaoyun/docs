# 模型配置

模型配置维护的是模型的**名片**：它叫什么、属于哪家、上下文能放多长、每次调用怎么收费。列表页、调用日志里的费用、数据看板里的成本，都读这里的数据。

读完你能完成：新建一个模型条目、补全它的展示信息和价格、上传图标，以及在不用时删除它。

:::tip 模型配置是「名片」，不是「线路」
名片上印的是这个模型的对外信息（名称、类型、价格）。至于请求到底从哪条线路发出去，由 [渠道管理](/boss/gateway/channels) 决定。两者分开管理：一个模型可以同时被好几条渠道提供，而价格只在名片上写一次。
:::

:::warning 模型配置不参与调度
这里只维护模型的展示信息和价格，**不会决定请求走哪条渠道**。请求能不能用某个模型，取决于渠道的「支持模型」里有没有它。
:::

## 开始之前

- 权限：需要平台管理员账号（能进入 Boss 管理控制台）。
- 先确认渠道已经建好，并且渠道的「支持模型」里已经列出这个模型名，否则配好价格也没法被调用。

## 进入模型配置

1. 顶部导航点击 **大模型网关**。
2. 展开 **模型服务**，点击 **模型配置**。

## 模型列表怎么看

| 列 | 含义 |
| --- | --- |
| 模型名称 | 模型标识，下方小字是模型描述 |
| 类型 | 对话 / 生图 / 视频等 |
| 厂家 | 模型出自哪家 |
| 类别 | 视觉、推理等标签，可多个 |
| 上下文 | 上下文窗口的 Token 数，以 K / M 缩写显示 |
| 参数规模 | 模型参数量，以 B（十亿）或 T（万亿）显示 |
| 价格 | 输入、输出单价，单位为「货币 / 1M」 |
| 渠道商 | 有几条渠道提供这个模型，鼠标悬停可看渠道名和优先级 |

列表上方可按 **类型** 和 **厂家** 两个条件筛选。每行末尾的操作菜单里有 **编辑** 与 **删除**。

![模型配置列表：模型名称、类型、厂家、类别、上下文、参数规模、价格、渠道商](/assets/screenshots/boss/gateway-modelmeta-01.png)

模型配置只维护**元数据**，页面上那行提示写得很清楚：这一页不参与模型调度。列表里的 **渠道商** 一列是模型挂在哪些渠道下；想看真正能调用的模型，要去 [渠道管理](./channels.md)。

## 新建一个模型

1. 在 **模型配置** 页面点击右上角 **创建模型**。
2. 在 **基础信息** 区域填写：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 模型名称 | 例如 `gpt-4o-mini` | 必填，创建后**不能修改**，要和渠道里填的模型名完全一致 |
   | 类型 | 默认「对话」 | 见下方「类型」 |
   | 厂家 | 默认「OpenAI」 | 见下方「厂家」 |
   | 模型描述 | 一句话说明 | 选填，会显示在列表名称下方 |
   | 类别 | 从预置项里多选 | 选填，见下方「类别」 |
   | 自定义标签 | 输入后回车添加 | 选填，方便自己归类 |
   | 上下文 | 例如 `128000` | 选填，单位是 Token |
   | 参数规模 | 例如 `7` | 选填，单位是 B（十亿），可带小数 |

3. 需要图标时可以点 **上传图标**，选一张图片（不限格式，常用 PNG / SVG）。
4. 在 **价格** 区域填写四个单价，单位是 **CNY / 1M**（人民币 / 每百万 Token）：

   | 表单项 | 说明 |
   | --- | --- |
   | 输入价格 | 用户输入部分每百万 Token 的价格 |
   | 补全价格 | 模型输出部分每百万 Token 的价格 |
   | 缓存读价格 | 命中缓存读取时的价格 |
   | 缓存写价格 | 写入缓存时的价格 |

5. 点击 **创建模型** 完成。若在编辑页，按钮显示为 **保存**。

编辑已有模型时，如果已经有渠道在用它，表单底部还会多出一块 **渠道商**，列出这些渠道及其优先级，方便你判断改动的影响范围；没有任何渠道引用它时，这块不显示。

![「创建模型」表单：基础信息（模型名称、类型、厂家、描述、类别、标签、上下文、参数规模、图标）与价格](/assets/screenshots/boss/gateway-modelmeta-02.png)

创建模型表单分成 **基础信息** 与 **价格** 两段。**模型名称** 必填，其余可以留空后补；**参数规模** 输入框右边带一个 `B` 单位提示；**类别** 与 **自定义标签** 都是多选，用来给模型打筛选标签。

### 类型

| 界面文案 | 适合什么模型 |
| --- | --- |
| 对话 | 聊天、问答类大语言模型 |
| 生图 | 文生图、图生图模型 |
| 视频 | 视频生成模型 |
| 语音 | 语音识别或语音合成模型 |
| 嵌入 | 把文本转成向量，用于检索 |
| 重排序 | 对检索结果重新排序 |

### 厂家

可选：DeepSeek、Qwen、智谱、Kimi、OpenAI、Anthropic、Google、MiniMax、豆包。

:::info 两套「供应商」不要混用
这里的「厂家」说的是模型出自哪家公司，和 [渠道管理](/boss/gateway/channels) 里选的「模型服务供应商」不是同一份名单，各选各的即可。
:::

### 类别

可选：视觉、MoE、推理、Tools、FIM、Math、Coder。类别只是标签，便于筛选，不影响调用。

## 价格与币种

价格一律按 **CNY / 1M Tokens** 填写。当 [货币配置](/boss/gateway/currency-settings) 选择用美元展示时，页面会按配置的汇率自动换算显示，你不需要改成美元来填。

## 删除一个模型

1. 在列表某一行点击 **删除**。
2. 在确认弹窗里**手动输入模型名称**才能执行删除。

:::warning 删除前先确认没有渠道在用
如果还有渠道把它的「支持模型」指向这个模型，删掉名片后价格和展示信息就没了。删除前先在编辑页的「渠道商」区域确认引用情况。
:::

## 结果确认

回到 **模型配置** 列表，能看到新模型及其类型、厂家、价格；在 [调用日志](/boss/gateway/audit) 里查询该模型的调用，**费用** 列能显示出金额，就说明价格配置生效了。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 模型名改不了 | 名称创建后固定 | 名称只用于标识，如需改名请新建后删除旧的 |
| 调用日志费用为空 | 该模型还没配价格，或调用的模型名不匹配 | 在模型配置里补上价格，并核对模型名 |
| 模型建好了却调不到 | 渠道的「支持模型」里没有它 | 到渠道管理里把模型名加进对应渠道 |
| 列表价格显示货币不同 | 受货币配置影响 | 到货币配置里切换显示货币 |
