# 模型配置

模型配置维护的是模型的**名片**：它叫什么、属于哪家、上下文能放多长、显示什么图标。列表、模型广场和调用日志里看到的模型名与描述，读的都是这里的数据。

读完你能完成：新建一个模型条目、补全它的展示信息、上传图标，以及在不用时删除它。这一页**不管价格**，价格统一在 [费率方案](/boss/gateway/rate-plans) 里设置。

:::tip 名片和价目表是两件事
名片上印的是这个模型的对外信息（名称、类型、上下文）。至于这次调用该收多少钱，写在**费率方案**里；请求到底走哪条线路，由 [渠道管理](/boss/gateway/channels) 决定。三者分开管理，改一处不会牵动另外两处。
:::

:::warning 模型配置不参与调度
页面顶部固定写着「模型配置仅管理模型元数据，不参与模型调度。」请求能不能用某个模型，取决于渠道的「支持模型」里有没有它。
:::

## 开始之前

- 权限：需要平台管理员账号（能进入 Boss 管理控制台）。
- 想给模型改价格，请直接去 [费率方案](/boss/gateway/rate-plans)，这里没有价格字段。
- 想让模型真的能被调用，还要有渠道的「支持模型」里写着它，并且平台默认方案给它定过价。

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 模型元数据 | 模型的描述信息：名称、类型、供应商、类别、上下文、参数规模、图标 |
| 渠道引用 | 有几条渠道把「支持模型」指向了这个模型。引用只影响展示，不决定计价 |
| 未定价 | 没有任何生效的价格明细覆盖这个模型。这种调用会落到 [计价异常](/boss/gateway/usage-events) |
| 0 元 | 明确写了价格 `0`，表示免费。和「未定价」完全不是一回事 |

## 模型列表怎么看

| 列 | 含义 |
| --- | --- |
| 模型名称 | 模型标识，左侧是图标，下方小字是模型描述 |
| 类型 | 对话 / 生图 / 视频 / 语音 / 嵌入 / 重排序 |
| 供应商 | 模型出自哪家 |
| 类别 | 视觉、推理等标签，可多个 |
| 上下文 | 上下文窗口的 Token 数，以 K / M 缩写显示 |
| 参数规模 | 模型参数量，以 B（十亿）或 T（万亿）显示 |
| 渠道 | 有几条渠道提供这个模型（显示「N 个」），鼠标悬停可看渠道名和优先级 |

列表**没有价格列**。列表上方可按 **类型** 和 **供应商** 两个条件筛选。每行末尾的操作菜单里有 **编辑** 与 **删除**。

![模型配置列表：模型名称、类型、供应商、类别、上下文、参数规模、渠道](/assets/screenshots/boss/gateway-modelmeta-01.png)

这一页只维护**元数据**。列表里的 **渠道** 一列是模型挂在哪些渠道下；想看真正能调用的模型，要去 [渠道管理](/boss/gateway/channels)；想看价格，要去 [费率方案](/boss/gateway/rate-plans)。

## 新建一个模型

1. 在 **模型配置** 页面点击右上角 **创建模型配置**。
2. 在 **基础信息** 区域逐项填写：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 模型名称 | 例如 `gpt-4o-mini` | 必填，创建后**不能修改**，要和渠道里填的模型名完全一致 |
   | 类型 | 默认「对话」 | 见下方「类型」 |
   | 供应商 | 默认「OpenAI」 | 见下方「供应商」 |
   | 模型描述 | 一句话说明 | 选填，会显示在列表名称下方 |
   | 类别 | 从预置项里多选 | 选填，见下方「类别」 |
   | 自定义标签 | 输入后回车添加 | 选填，方便自己归类 |
   | 上下文 | 例如 `128000` | 选填，单位是 Token |
   | 参数规模 | 例如 `7` | 选填，单位是 B（十亿），可带小数 |

3. 需要图标时可以点 **上传图标**，选一张图片（不限格式，常用 PNG / SVG）。
4. 点击 **创建模型配置** 完成。若在编辑页，按钮显示为 **保存**。

编辑已有模型时，如果已经有渠道在用它，表单会多出一块只读的 **渠道** 区域，列出这些渠道及其优先级，方便你判断影响范围；没有任何渠道引用它时，这块不显示。

![「创建模型配置」表单：基础信息（模型名称、类型、供应商、描述、类别、标签、上下文、参数规模、图标）](/assets/screenshots/boss/gateway-modelmeta-02.png)

创建表单只有 **基础信息** 一段。**模型名称** 必填，其余可以留空后补；**参数规模** 输入框右边带一个 `B` 单位提示；**类别** 与 **自定义标签** 都是多选，用来给模型打筛选标签。

### 类型

| 界面文案 | 适合什么模型 |
| --- | --- |
| 对话 | 聊天、问答类大语言模型 |
| 生图 | 文生图、图生图模型 |
| 视频 | 视频生成模型 |
| 语音 | 语音识别或语音合成模型 |
| 嵌入 | 把文本转成向量，用于检索 |
| 重排序 | 对检索结果重新排序 |

### 供应商

可选：DeepSeek、Qwen、智谱、Kimi、OpenAI、Anthropic、Google、MiniMax、豆包。

:::info 两套「供应商」不要混用
这里的「供应商」说的是模型出自哪家公司，和 [渠道管理](/boss/gateway/channels) 里选的「供应商」不是同一份名单，各选各的即可。
:::

### 类别

可选：视觉、MoE、推理、Tools、FIM、Math、Coder。类别只是标签，便于筛选，不影响调用。

## 价格在哪里改

这一页**没有任何价格字段**，也改不了某次调用花多少钱。价格统一在 [费率方案](/boss/gateway/rate-plans) 维护：

1. 打开 **模型服务 → 费率方案**。
2. 找到带星标的方案（平台默认方案），点行末的 **设置价格**。
3. 在 **模型匹配** 里填这个模型的名称（可从渠道已有模型里选），填好输入价和输出价，保存。

保存后，之后再发生的调用就会按新价格算钱；已经发生过的调用保留当时的计价快照，不会追溯重算。

:::warning 模型名必须完全一致
费率方案里的模型匹配、渠道的「支持模型」、调用方请求里的模型名，三处必须能对上，价格才会被命中。名字多一个空格或大小写不同，都可能变成「未定价」。
:::

## 编辑与删除

- **编辑**：点行末 **编辑**，可改类型、供应商、描述、类别、标签、上下文、参数规模和图标；**模型名称** 是灰色只读的。
- **删除**：点行末 **删除**，需要在确认弹窗里**手动输入模型名称**才能执行。

:::warning 删除前先确认没有渠道在用
如果还有渠道把它的「支持模型」指向这个模型，删掉名片后列表和模型广场里就没有这条记录了。删除前先在编辑页的「渠道」区域确认引用情况。
:::

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 模型名改不了 | 名称创建后固定 | 名称只用于标识，如需改名请新建后删除旧的 |
| 找了半天没看到价格 | 这一页本来就不管价格 | 到 [费率方案](/boss/gateway/rate-plans) 设置或查看 |
| 调用日志里费用显示「未定价」 | 没有生效的价格明细覆盖这个模型 | 到费率方案给这个模型加一条当前有效的价格，或在 [计价异常](/boss/gateway/usage-events) 补价 |
| 模型建好了却调不到 | 渠道的「支持模型」里没有它 | 到渠道管理里把模型名加进对应渠道，并确认该模型已定价 |
| 列表里的渠道数是 0 | 没有渠道引用这个模型 | 属正常；把模型名加进某条渠道的「支持模型」即可 |
