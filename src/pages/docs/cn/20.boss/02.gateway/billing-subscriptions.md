# 订阅

订阅是**某个人正在生效中的套餐**。它决定了这段时间里，调用先扣哪个套餐的点数、点数用完之后还能不能继续用。开通入口只在这一页，套餐页只管「卖什么」。

读完你能完成：给某个人开通套餐、按状态找出所有生效中和快到期的订阅、开关超额扣费与自动续费、调整重置券，以及取消一份订阅。

:::tip 订阅像一张有效期内的健身卡
卡里有多少次入场（套餐点数）、什么时候到期（结束时间）、用完能不能继续刷（超额扣费）、到期要不要自动续（自动续费）。卡本身是在这里发的，卖卡的地方（套餐页）只管定价。
:::

## 开始之前

- 权限：需要平台管理员账号（能进入 Boss 管理控制台）。
- 需要先有可用的 [套餐](/boss/gateway/billing-plans)；没有套餐就开不了订阅。
- 要开通的人必须已有 [计费账户](/boss/gateway/billing-accounts)（注册、建密钥或打开过费用页后会自动生成）。

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 订阅 | 一份生效中的套餐，绑定到某个人的账户上 |
| 生效中 | 当前正在扣点数。只有这个状态能改设置或取消 |
| 待生效 | 已经开通，但还没到开始时间 |
| 已到期 | 周期结束，不再扣点数 |
| 已取消 | 被管理员取消，立即失效 |
| 已用点数 | 这轮周期里已经扣掉的点数，用进度条显示已用 / 总量 |
| 超额扣费 | 点数用完后要不要继续从账户余额扣。关着就直接拒绝调用 |
| 自动续费 | 到期后按原价续订并重新发点数 |
| 额度重置券 | 额外的「重置一次额度」次数。只在这里改，购买、升级和续期都不会改变它 |

## 列表与筛选

| 列 | 含义 |
| --- | --- |
| 用户 | 订阅属于谁，显示昵称（没有昵称时显示用户 ID） |
| 计划 | 这档套餐所属的计划 |
| 套餐 | 具体哪一档 |
| 状态 | 生效中 / 待生效 / 已到期 / 已取消 |
| 已用点数 | 已用 / 总量，带进度条 |
| 超额扣费 | 是 / 否 |
| 自动续费 | 是 / 否 |
| 额度重置券 | 剩余次数 |
| 结束时间 | 这轮周期什么时候结束 |

筛选有两项：

- **状态**：默认 **生效中**，另有 全部 / 待生效 / 已到期 / 已取消。想看历史就切到「全部」。
- **用户**：下拉里只列出**有订阅的人**，按昵称排序。

搜索框按关键词匹配 用户 ID、昵称、套餐名、计划名，四项任一命中即可。

## 开通订阅

1. 点右上角 **开通订阅**。
2. 选 **用户账户**（可以按用户名或用户 ID 搜索）。从账户页跳进来时会自动预选那个人。
3. 选 **计划**（全平台通常只有一个，只有一个时会自动选中）。
4. 选 **套餐**。停用的套餐也会列出来，并在选项里标注「已停用」——管理员开通不受上架状态限制。
5. 点 **确认**。

:::info 管理员开通不扣余额
在这一页开通订阅是**免费授予**，不会从账户余额里扣钱，也不会触发自动试用。真正花钱购买套餐的动作发生在 Console 侧的费用中心。
:::

:::warning 同一档套餐重复开通要小心
已经有一个生效中的订阅时，再开一份会让点数与结束时间按新订阅计算。开之前先确认这个人当前有没有生效中的订阅（筛选默认就停在「生效中」）。
:::

## 调整超额扣费与自动续费

这两项在行末菜单里，都以「开启 / 关闭」的形式出现，**只对生效中的订阅可用**。

| 操作 | 效果 |
| --- | --- |
| 开启超额扣费 | 点数用完后，超出的用量按费率从账户余额扣 |
| 关闭超额扣费 | 点数用完后直接拒绝调用，即使账户还有余额 |
| 开启自动续费 | 到期按原价续订并重新发点数 |
| 关闭自动续费 | 到期即结束，不续订 |

:::info 关闭超额扣费是「硬停」
很多人以为关掉超额扣费只是「不自动续钱」。实际效果更硬：点数一用完，请求立刻被拒绝。给客户关这个开关之前，最好先打个招呼。
:::

## 调整重置券

1. 在生效中的订阅行末点 **调整重置券**。
2. 填 **剩余次数**。
3. 点 **确认**。

界面上写着：**只对生效中的订阅有效。次数只能在这里修改，购买、升级和续期都不会改变它。到期后次数还在，但不能再用。**

:::warning 重置券不是点数
重置券只决定能不能「额外重来一轮额度」，不增加点数总额。它和 [额度计划](/boss/gateway/quota-plans) 里的重置券是两套东西，别混用。
:::

## 取消订阅

1. 在生效中的订阅行末点 **取消订阅**。
2. 确认弹窗会提示：**取消后这档订阅立即失效，已使用的额度不会退回。**
3. 点确认。

:::warning 取消是立即生效的
不会等到周期结束，也不会退还剩余点数。取消之后，这个人的调用会立刻回落到账户费率或平台默认方案；如果余额也不够，请求就会被拒绝。
:::

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 列表里只有几条 | 状态筛选默认「生效中」 | 切到「全部」看历史 |
| 用户下拉里找不到某人 | 他从没有过订阅 | 下拉只列有订阅的用户；直接搜索框搜昵称也能找到记录 |
| 点数用完了请求被拒 | 超额扣费是关闭的 | 按业务需要开启超额扣费，或给账户充值后重新开通套餐 |
| 到期了没有自动续 | 自动续费是关闭的 | 在生效期内开启自动续费；已到期的只能重新开通 |
| 行末没有「调整重置券」 | 订阅不是生效中 | 只有生效中的订阅能改设置 |
| 换了套餐但点数没变 | 已开通的订阅在续期或重开时才用新点数 | 属于预期；见 [套餐](/boss/gateway/billing-plans) |
