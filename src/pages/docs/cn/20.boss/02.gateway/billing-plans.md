# 套餐

套餐是**提前买下的一包用量**：付一笔钱，换一段时间内的一批点数，调用时先扣点数。这一页维护「卖什么」——先建计划（一组套餐的容器），再在计划下面建一档档套餐。

读完你能完成：建一个计划、给计划建套餐档位、算清点数够用多久、设置推荐与续费，以及在删除前判断有没有人正在用。

:::tip 计划是「套餐册」，套餐是册子里的一页
一个计划可以有多档套餐：基础版、专业版、旗舰版。用户买到的是**某一档套餐**，不是整个计划。计划本身只是把同一类套餐放在一起，并决定哪些租户能看到它。
:::

## 开始之前

- 权限：需要平台管理员账号（能进入 Boss 管理控制台）。
- 先准备好至少一份 [费率方案](/boss/gateway/rate-plans)：套餐点数要靠它把「用了多少」折成「扣多少点」。
- 这一页**只维护商品，不负责开通**。给某个人开通套餐请到 [订阅管理](/boss/gateway/billing-subscriptions)。

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 计划 | 一组套餐的容器，界面上也叫「商品」。它决定有哪些租户能看到、能买 |
| 套餐 | 一档具体的售卖单元：多少钱、多少点、多久、什么权益 |
| 套餐等级 | 同一计划内的档位序号，数字越大档位越高，价格也必须越贵 |
| 套餐点数 | 这档套餐包含的可用量，1 点 = 0.01 元 |
| 周期 | 按月 / 按季 / 按年。决定这档套餐多久续一次 |
| 点数重置 | 不重置 / 每月重置。决定点数用完后会不会在周期内回满 |
| 自动续费 | 到期后按原价续订并重新发点数；关掉就到期结束 |
| 推荐 | 在用户订阅页高亮这档套餐 |
| 卖点 | 显示在套餐名称下面的一句短标题 |
| 权益 | 每行一条的卖点列表，显示在价格下面 |

## 页面结构

页面分上下两部分：

- **上半部分**：计划卡片。每张卡片显示计划名称、状态、套餐数量、关联租户数（没有关联租户时显示「全平台」），右下角有 **编辑**。
- **下半部分**：选中某个计划后出现的套餐表。没选中任何计划时提示「选择上方的计划，查看并维护它的套餐。」
- 右上角有两个入口：**创建计划** 和 **创建套餐**。

![套餐页：上半部分是计划卡片，下半部分是选中计划的套餐表](/assets/screenshots/boss/gateway-billing-plans-01.png)

## 计划怎么建、怎么改

1. 点右上角 **创建计划**。
2. 填 **名称**（必填）。
3. 填 **说明**（选填）。
4. 选 **状态**：启用 / 停用，默认启用。
5. 选 **关联租户**：可多选。**不选表示这个计划对所有用户可见**（卡片上显示「全平台」）。
6. 点 **保存**。

改计划：在卡片右下角点 **编辑**，可以改名称、说明、状态和关联租户；弹窗里还能 **删除计划**。

## 套餐怎么建

1. 先在页面上半部分**点选一个计划**（套餐必须挂在某个计划下）。
2. 点右上角 **创建套餐**。
3. 逐项填写：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 计划 | 选择所属计划 | 必填 |
   | 名称 | 例如「专业版月付」 | 必填 |
   | 价格 | 例如 `99` | 必填，单位人民币，最多 6 位小数 |
   | 周期 | 按月 / 按季 / 按年 | 必填，默认按月 |
   | 套餐等级 | 例如 `2` | 必填，`1`–`1000`。同一计划内不能重复，等级越高价格必须越贵 |
   | 套餐点数 | 例如 `10000` | 填正整数。**填了点数就必须选费率方案** |
   | 费率方案 | 选择一份费率方案 | 点数按这份价目折算，包括按次价 |
   | 点数重置 | 不重置 / 每月重置 | 默认不重置 |
   | 自动续费 | 开 / 关 | 默认关。开启后到期按原价续订并重新发点数 |
   | 推荐 | 开 / 关 | 默认关。开启后在用户的订阅页高亮 |
   | 卖点 | 一句话 | 选填，显示在套餐名称下方 |
   | 权益 | 每行一条 | 选填，显示在价格下方；留空时显示点数和续费说明 |

4. 点 **保存**。

:::warning 改点数只影响之后
编辑套餐时，保存只会更新这档套餐的点数；**已经开通的订阅**要等到续期或重新开通时才用新点数。想立刻生效，只能取消订阅后重开。
:::

## 套餐列表怎么看

| 列 | 含义 |
| --- | --- |
| 名称 | 套餐名称 |
| 套餐等级 | 档位序号，从低到高排列 |
| 价格 | 金额 + 币种 |
| 周期 | 按月 / 按季 / 按年 |
| 套餐点数 | 显示为「N 点（价值约 ¥X）」 |
| 点数重置 | 不重置 / 每月重置 |
| 自动续费 | 是 / 否 |
| 推荐 | 是 / 否 |
| 状态 | 启用 / 停用 |

行末菜单有 **编辑套餐** 和 **删除套餐**。

## 点数怎么折算

点数不是「次数」，而是**金额的另一种单位**：1 点 = 0.01 元。一次调用先按费率方案算出金额，再除以 0.01 得到要扣的点数。

> 扣除点数 = 请求费用（元）÷ 0.01

费用本身这样算：

> 请求费用 = 输入 Token ÷ 1,000,000 × 输入价 + 输出 Token ÷ 1,000,000 × 输出价 + 缓存读写同理 + 按次价

举个例子：输入价 2 元、输出价 8 元（均为元 / 百万 Token），一次请求用了 1,000,000 输入 Token 和 200,000 输出 Token，费用 = 1 × 2 + 0.2 × 8 = 3.6 元，扣 **360 点**。按次价 0.2 元 / 次的模型，每次扣 **20 点**。

:::info 点数用完了会怎样
由订阅上的 **超额扣费** 开关决定：开着就继续从账户余额按价扣；关着就直接拒绝调用。所以「点数」和「余额」是两道独立的闸门。
:::

:::warning 没定价的模型不扣点数
价目里没有的模型不会被折成点数，它会走超额计费那条路，同时这次调用会在 [计价异常](/boss/gateway/usage-events) 里留下一条缺价记录。套餐不是「未定价也能用」的通行证。
:::

## 删除计划与套餐

| 操作 | 限制 | 提示原文 |
| --- | --- | --- |
| 删除计划 | 计划下面还有套餐时不能删 | 删除计划 X。下面还有套餐时不能删。 |
| 删除套餐 | 已经有人订阅时不能删 | 删除套餐 X。已经有人订阅时不能删。 |

:::warning 删除不可撤销
计划和套餐删除后无法恢复。已经有订阅的套餐会挡住删除，这层保护不要绕过——先处理订阅，再删商品。
:::

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 创建套餐时保存不了 | 没选计划、没填等级、或填了点数没选费率方案 | 补齐必填项；点数与费率方案必须成对出现 |
| 提示等级重复或价格不对 | 同一计划内等级必须唯一，且等级越高价格必须越贵 | 调整等级或价格 |
| 用户看不到这档套餐 | 计划关联了租户，用户不在其中；或套餐/计划状态是停用 | 检查关联租户与状态 |
| 订了套餐但没扣点数 | 模型没在套餐引用的费率方案里定价 | 到费率方案补价，套餐只按这份方案的价折点 |
| 改了点数但用户没感觉 | 已开通的订阅在续期或重开时才用新点数 | 属于预期；需要立刻生效就取消后重开 |
| 删不掉套餐 | 已经有人订阅 | 先取消相关订阅再删 |
