# 命中记录

命中记录是内容审查的**结果存档**。每一次请求或响应触发了敏感词检测，这里都会留一条记录，写清楚是谁、什么时候、命中了哪些词、风险有多高，以及系统最终是怎么处理的。

读完你能完成：按时间和用户筛出关心的记录、看懂风险等级和处理方式，并打开详情看具体命中了什么内容。

:::tip 像安检仪的记录回放
安检机每天扫过成千上万件行李，事后要复盘「那次报警到底扫到了什么」，就要靠记录回放。命中记录就是内容审核的回放：不用翻全部调用，系统已经帮你筛出「只有报警的那些」。
:::

## 开始之前

- 权限：需要平台管理员账号（能进入 Boss 管理控制台）。
- 需要先配好词库和策略，并有实际命中发生，这一页才会有数据。配置方法见 [内容审查](/boss/gateway/moderation)。

## 进入命中记录

1. 顶部导航点击 **大模型网关**。
2. 展开 **安全服务**，点击 **命中记录**。

![命中记录：时间范围固定为最近一个月，右侧是用户与渠道商筛选，表格按时间倒序](/assets/screenshots/boss/gateway-hits-01.png)

打开就是这个样子：**开始时间** 与 **结束时间** 已经填好（默认最近一个月），页面顶部没有额外开关。表格里 **敏感词** 一列显示 `-`，表示这一条是策略按 **风险总分** 拦下来的、没有单独命中某个词；**风险等级** 那一列的 `中` 就是评分落到的档位。

## 这一页已经帮你筛好了

你不需要手动指定「只看命中」——页面固定只查询命中过敏感内容的记录。列表按请求时间**倒序**排列，最新的在最上面，默认每页 **15** 条。

默认的时间范围是**最近 1 个月**：从当前时间往前一个月的当天 0 点，到当天的 24 点。

## 怎么筛选

| 筛选项 | 说明 |
| --- | --- |
| 开始时间 | 精确到分钟 |
| 结束时间 | 精确到分钟 |
| 用户 | 按用户名查询 |
| 渠道商 | 下拉选择，含「全部」 |

工具条上有 **重置** 和 **刷新**：重置会把时间范围恢复成默认的最近 1 个月，并清空用户和渠道商。

## 列表里有什么

| 列 | 含义 |
| --- | --- |
| 时间 | 请求发生时间，下方小字是这次调用的结果 |
| 用户 | 发起调用的用户，带头像和租户名 |
| 模型 | 请求的模型，带模型图标 |
| 类型 | 敏感内容所属类型 |
| 敏感词 | 命中的词，多个之间用「、」连接 |
| 风险等级 | 高 / 中 / 低，按颜色区分 |
| Token | 使用的密钥名称（没有名称时显示掩码后的密钥） |
| 处理方式 | 策略最终执行的动作 |

### 风险等级是怎么定的

风险等级由命中内容的**最高评分**推导：

| 评分 | 等级 |
| --- | --- |
| 8 分及以上 | 高 |
| 5 分及以上 | 中 |
| 其他 | 低 |

如果这次调用的报告里没有评分可用，被拦截的记为 **高**，其余记为 **中**。

### 处理方式有哪几种

处理方式与 [策略管理](/boss/gateway/moderation) 里配置的动作一致：

| 处理方式 | 含义 |
| --- | --- |
| 记录日志 | 内容正常通过，只留了一笔记录 |
| 替换敏感词 | 命中的词被替换成掩码后继续 |
| 委托外部服务 | 交给外部审核服务判定 |
| 拦截请求 | 请求被直接拒绝 |

## 查看命中详情

1. 在列表点击某条记录的**时间**列（或时间旁边的查看详情图标）。
2. 弹窗顶部以标签形式列出命中的敏感词。
3. 下方是请求内容，命中的词会高亮标出，方便你判断是真命中还是误报。

:::info 这是个只读页面
命中记录只用于查询，页面不提供删除、导出或对单条记录做处置的操作。要调整判定结果，请回到词库或策略去改规则。
:::

## 和别的页面的关系

- 词条和评分在 **敏感词管理** 里维护。
- 触发条件和动作在 **策略管理** 里配置。
- 全部调用（包括没有命中敏感内容的）在 [调用日志](/boss/gateway/audit) 里查询。

## 结果确认

调整时间范围和用户后，列表随之变化、点开详情能看到高亮的命中词，就说明查询正常。若长时间为空，先确认总开关和词条是否启用。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 列表为空 | 总开关关闭、词条未启用，或所选区间内确实没有命中 | 检查 [网关配置](/boss/gateway/config) 的审核开关，放宽时间范围 |
| 找不到更早的记录 | 默认只查最近 1 个月 | 手动把开始时间往前调 |
| 想删掉某条记录 | 本页只读 | 页面不支持，按需调整词库或策略即可 |
| 处理方式是「记录日志」但内容没被改 | 该策略只记录不处理 | 如需拦截或替换，修改对应策略的动作 |
