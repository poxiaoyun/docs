## 功能简介

敏感命中页汇总所有**触发了内容检测**的调用记录，用于追溯敏感内容的命中情况、风险等级与最终处置方式。

本页对应 BOSS 控制台「大模型网关 → 安全服务 → **命中记录**」（菜单文案取自 `navbar.sensitive_hits`）。

## 进入路径

BOSS 控制台 → 大模型网关 → 安全服务 → **命中记录**

前端真实路由：`/gateway/moderation/sensitive-hits`

> ⚠️ 注意: 上表是 BOSS 控制台前端代码中的真实路径，不是文档站 URL。

## 查询行为

页面请求时固定带上 `sensitiveDetected: true`，因此列表中只会出现命中过敏感检测的记录，无需用户手动指定。结果按请求时间（`requestStarted`）**倒序**排列，分页默认每页 **15** 条。

时间范围默认回溯 **1 个月**（起始时间为「当前时间往前 1 个月的当日 0 点」，结束时间为「当日 24 点」）。

## 筛选条件

| 筛选器 | 类型 | 说明 |
|--------|------|------|
| 开始时间 | 日期时间 | 精确到分钟 |
| 结束时间 | 日期时间 | 精确到分钟 |
| 用户 | 文本 | 按用户名查询 |
| 渠道商 | 下拉 | 选项来自渠道列表，含「全部」 |

工具条提供 **刷新** 与 **重置**（重置会恢复默认的 1 个月时间范围）。

## 记录列表

| 列 | 字段 | 说明 |
|----|------|------|
| 时间 | `requestStarted` | 请求发生时间 |
| 用户 | `username` | 含头像与租户名 |
| 模型 | `model` | 请求模型（带模型图标） |
| 类型 | `sensitiveType` | 敏感内容类型 |
| 敏感词 | `sensitiveTerms` | 命中的词条，多个以「、」连接 |
| 风险等级 | `riskLevel` | 彩色标签 |
| Token | `tokenId` | 优先显示 `tokenName`，否则显示掩码后的 Token |
| 处理方式 | `moderationDecision` | 策略动作 |

多值单元格为空时显示占位符。

### 风险等级

风险等级由命中内容的**最高评分**推导：

| 评分区间 | 等级 | 界面文案 |
|----------|------|---------|
| `>= 8` | `high` | 高 |
| `>= 5` | `medium` | 中 |
| 其余 | `low` | 低 |

### 处理方式

处理方式展示策略执行的动作，取值与 [策略管理](/boss/gateway/moderation) 一致：`log`（记录日志）/ `replace`（替换敏感词）/ `webhook`（委托外部服务）/ `block`（拦截请求）。

## 命中详情

点击记录打开详情弹窗，展示：

- 命中的敏感词（标签形式）
- 请求内容，其中命中的词条以高亮片段标出

> ⚠️ 注意: 该页为**只读查询**页面，不提供删除、导出或处置操作。

## 与其他模块的关系

- 词条与评分在 [敏感词管理](/boss/gateway/moderation) 中维护
- 触发条件与动作在 [策略管理](/boss/gateway/moderation) 中配置
- 全量调用记录（含未命中敏感内容的请求）在 [调用日志](/boss/gateway/audit) 中查询

## 权限要求

需要 **系统管理员** 角色。
