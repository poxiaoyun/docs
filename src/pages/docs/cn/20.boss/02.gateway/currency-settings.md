# 货币配置

货币配置决定**价格和费用在页面上用哪种货币显示**。所有金额实际都按人民币记账，切到美元只是加一层展示换算。

读完你能完成：切换人民币 / 美元显示、调整汇率，并理解改完之后哪些页面会跟着变、哪些不会。

:::tip 像手机上的「货币换算」
手机银行里余额其实只有一种货币，但你可以切换「折算成美元看」。汇率一变，页面上折出来的数字就变，账户里真实的钱没变。货币配置就是网关的这层换算开关。
:::

## 开始之前

- 权限：需要平台管理员账号（能进入 Boss 管理控制台）。
- 只在需要对外用美元报价或对账时才切换；对内人民币结算的团队保持默认即可。

## 进入货币配置

1. 顶部导航点击 **大模型网关**。
2. 展开 **平台设置**，点击 **货币配置**。

## 两个配置项

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 货币显示模式 | 人民币 CNY | 可选 人民币 CNY 或 美元 USD。只影响价格和费用的展示，记账货币固定为人民币 |
| 人民币兑美元汇率 | `0.14` | 美元只作为展示参考，按这个汇率从人民币换算，不参与扣费 |

- **货币显示模式** 只影响展示：选人民币就显示 ¥，选美元就按汇率折算成 $。
- **人民币兑美元汇率** 是展示换算用的比率。界面提示要求精确到小数点后 2 位，后端用定点整数换算，避免浮点误差。

![货币配置：货币显示模式与人民币兑美元汇率](/assets/screenshots/boss/gateway-currency-01.png)

全页只有两项：**货币显示模式** 与 **人民币兑美元汇率**。截图里模式是人民币，所以平台里所有金额都按人民币展示；改成美元后，凡是按汇率折算的地方都会跟着变。改完点 **保存**。

## 修改与保存

1. 在 **货币显示模式** 下拉里选择人民币或美元。
2. 需要时修改 **人民币兑美元汇率**。
3. 点击 **保存**。

保存成功后页面提示「货币设置已保存」，并重新拉取一次配置。

:::warning 输入框没有格式校验
这个输入框没有前端格式限制，只有提示文案要求 2 位小数。实际换算以后端的定点运算为准，别在这里填较长的小数位然后期待页面自行截断。
:::

## 影响哪些页面

货币设置影响三类会显示金额的地方：

| 位置 | 变化 |
| --- | --- |
| [费率方案](/boss/gateway/rate-plans) 的价格明细 | 单价按所选货币显示 |
| [调用日志](/boss/gateway/audit) 的费用与标准列 | 每条记录的费用、单价按所选货币显示，美元金额可能标注为「参考价」 |
| [数据看板](/boss/gateway/operations) 的模型排行 | 排行里的费用列按所选货币显示 |

价格本身始终以人民币存储，你录入时照常填人民币即可，不需要换算成美元。

## 改了会不会影响历史账单

不会改写任何已记录的数据，但**历史费用在页面上的显示数字会变**。

- 每条调用的费用在计价时就已按当时的价格算好并保存下来（计价快照），切换货币或改汇率不会去重写这些金额。
- 页面展示时会用**当前的**汇率重新折算，所以改完汇率后再回头看旧记录，显示的美元数字会和新汇率一致。
- 换句话说：记录里的人民币金额不变，变的只是折算出来的展示值。

:::info 想让历史金额保持原样
如果你希望旧记录显示的数字不随汇率波动，就不要频繁调整汇率，或始终保持人民币显示。
:::

## 结果确认

保存后到 [费率方案](/boss/gateway/rate-plans) 看某条价格明细，或到 [调用日志](/boss/gateway/audit) 看某条记录的费用，确认金额已经用你选择的货币显示，就说明设置生效了。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 改了货币但某些金额没变 | 该金额没有可换算的来源数据 | 到费率方案确认对应模型已有价格明细 |
| 历史费用数字变了 | 展示按当前汇率重新折算 | 属预期行为，原始记录未被改写 |
| 金额前面出现「参考价」 | 当前显示的是美元折算值 | 属预期；美元只用于展示，不参与扣费 |
| 汇率填了很长的数字 | 输入框没有格式校验 | 按 2 位小数填写，实际以后端定点换算为准 |
