# 货币配置

货币配置决定**价格和费用在页面上用哪种货币显示**。模型价格在录入时统一按人民币填写，展示时再按这里设置的货币和汇率换算。它只影响「显示」，不改变任何已记录的数据。

读完你能完成：切换人民币 / 美元显示、调整汇率，并理解改完之后哪些地方会跟着变。

:::tip 像手机上的「货币换算」
手机银行里余额其实只有一种货币，但你可以切换「折算成美元看」。汇率一变，页面上折出来的数字就变，账户里真实的钱没变。货币配置就是网关的这层换算开关。
:::

## 开始之前

- 权限：需要平台管理员账号（能进入 Boss 管理控制台）。
- 只在需要对外用美元报价或对账时才切换；对内人民币结算的团队保持默认即可。

## 进入货币配置

1. 顶部导航点击 **大模型网关**。
2. 展开 **平台设置**，点击 **货币配置**。

## 两个配置项

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 货币显示模式 | `CNY` | 可选 `CNY`（人民币）或 `USD`（美元） |
| 美元汇率 | `0.14` | 人民币兑美元的换算比率，精确到小数点后 2 位 |

- **货币显示模式** 只影响展示：选 `CNY` 就显示人民币，选 `USD` 就按汇率折算成美元显示。
- **美元汇率** 是人民币兑美元的比率。系统用定点整数方式换算，避免小数误差。

![货币配置：货币显示模式（CNY）与美元汇率](/assets/screenshots/boss/gateway-currency-01.png)

全页只有两项：**货币显示模式** 与 **美元汇率**。截图里模式是 `CNY`，所以平台里所有金额都按人民币展示；改成 USD 后，凡是按汇率折算的地方都会跟着变。改完点 **保存**。

## 修改与保存

1. 在 **货币显示模式** 下拉里选择 `CNY` 或 `USD`。
2. 需要时修改 **美元汇率**。
3. 点击 **保存**。

保存成功后页面提示「货币设置已保存」，并重新拉取一次配置。

## 影响哪些页面

货币设置主要影响三类会显示金额的地方：

| 位置 | 变化 |
| --- | --- |
| [模型配置](/boss/gateway/model-metadata) 的价格列 | 价格按所选货币显示 |
| [调用日志](/boss/gateway/audit) 的费用与标准列 | 每条记录的费用按所选货币显示 |
| [数据看板](/boss/gateway/operations) 的模型排行 | 排行里的成本列按所选货币显示 |

价格本身始终以人民币存储，你录入时照常填人民币即可，不需要换算成美元。

## 改了会不会影响历史账单

不会改写任何已记录的数据，但**历史费用在页面上的显示数字会变**。

- 每条调用的费用在生成时就已按当时的价格算好并保存下来，切换货币或改汇率不会去重写这些历史金额。
- 页面展示时会用**当前的**汇率重新折算，所以改完汇率后再回头看旧记录，显示的美元数字会和新汇率一致。
- 换句话说：记录里的人民币金额不变，变的只是折算出来的展示值。

:::info 想让历史金额保持原样
如果你希望旧记录显示的数字不随汇率波动，就不要频繁调整汇率，或始终保持人民币显示。
:::

## 结果确认

保存后回到 [调用日志](/boss/gateway/audit) 或 [模型配置](/boss/gateway/model-metadata)，确认金额已经用你选择的货币显示，就说明设置生效了。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 改了货币但某些金额没变 | 该金额没有可换算的来源数据 | 确认对应模型在模型配置里已填价格 |
| 历史费用数字变了 | 展示按当前汇率重新折算 | 属预期行为，原始记录未被改写 |
| 汇率填了很长的数字 | 只保留到小数点后 2 位 | 按两位小数填写 |
