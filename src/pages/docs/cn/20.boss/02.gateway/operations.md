# 数据看板

数据看板是网关的**运行仪表盘**。它把一段时间内的请求量、成功率、Token 消耗、费用、响应速度和渠道健康状况汇总成指标卡、趋势图和排行榜，帮你在几秒内判断「今天网关好不好」。

读完你能完成：按时间和维度筛选数据、看懂每张图的含义、在数字异常时快速定位该去查哪个页面。

:::tip 数据看板是汽车的仪表盘
开车时你不会盯着发动机看，而是看仪表盘上的速度和油量。网关的仪表盘就是这一页：只给结论性的数字，要看某一次具体调用，请到 [调用日志](/boss/gateway/audit)。
:::

## 开始之前

- 权限：需要平台管理员账号（能进入 Boss 管理控制台）。
- 无需前置配置；页面数据来自已经发生的调用记录。

## 进入数据看板

1. 左侧菜单点击 **大模型网关**。
2. 点击 **数据看板**。

页面每 **30 秒** 会自动刷新一次，你也可以随时手动刷新。

## 怎么筛选

| 筛选项 | 说明 |
| --- | --- |
| 时间范围 | 今日 / 7天 / 30天 / 自定义 |
| 开始时间、结束时间 | 仅在选「自定义」时可填 |
| 租户 | 只看某个租户的调用 |
| 渠道 | 只看某条渠道的调用 |
| 模型 | 只看某个模型的调用 |
| 时间粒度 | 只读，由时间范围自动推导，显示「按小时」或「按天」 |

工具条上的两个按钮：

- **刷新数据**：立刻重新拉取一次。
- **重置筛选**：清空租户、渠道、模型三个筛选，并把时间范围恢复为「今日」。

时间粒度是自动推导的，不用手动改：

| 时间范围 | 粒度 |
| --- | --- |
| 今日 | 按小时 |
| 7天 / 30天 | 按天 |
| 自定义 | 跨度不超过 240 小时按小时，否则按天 |

## 七个指标卡

页面顶部一排卡片，从左到右：

| 指标卡 | 含义 |
| --- | --- |
| 请求总量 | 区间内的请求总数，带「较前期」的变化率 |
| 成功率 | 成功请求占比，单位是百分点变化 |
| Token 消耗 | 区间内消耗的总 Token，以 K / M 缩写展示 |
| 敏感词命中 | 命中内容审核的请求数 |
| TTFT | 首 Token 延迟，展示最近窗口内的最大值，越低越好 |
| 活跃 API Key | 期间有调用行为的密钥数量 |
| 运行时长 | 网关已持续运行的时长，按「天 / 时 / 分」显示 |

:::info 「暂无前期」是什么意思
如果所选时间范围之前没有可比的数据，成功率卡会显示「暂无前期」，表示这一项没有环比可算，不是出错了。
:::

## 图表与排行

**趋势图**：按当前粒度，展示每个时间段内的请求量（单系列柱状）。

**模型用量**：按模型拆分的堆叠柱状，最多取前 10 个模型，其余合并为「其他模型」。

下半部分三栏：

| 卡片 | 内容 |
| --- | --- |
| 模型排行 | 按请求量排序，列出每个模型的请求数、Token 数与成本 |
| 用户使用排行 | 按用户统计前 10 名，显示请求数与 Token，带占比进度条 |
| TTFT 趋势 + 网关健康度 | 见下 |

**TTFT 历史耗时趋势**：折线图，含两条线——**TTFT 最大值** 与 **TTFT P95**。前者看最慢的情况，后者看「大多数请求」的体验。

**网关健康度**：显示可用率（百分比加进度条），以及三项明细——上游渠道的「健康数 / 总数」、限流事件次数、异常请求数。

## 这一页没有明细和导出

数据看板只给汇总结果。它**不提供逐条记录表，也没有导出功能**。要看某一次调用、某个人用了多少、某个请求为什么失败，请到 [调用日志](/boss/gateway/audit) 查询。

## 结果确认

选好时间范围后，指标卡和图表出现数字且随筛选联动变化，就说明数据已正常加载。想验证某条渠道或某个模型是否在正常服务，可先用 **渠道** 或 **模型** 筛选，再看请求量与成功率的走势。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 图表一片空白 | 所选区间内没有调用 | 放宽时间范围或清空筛选 |
| 想按 Token 或用户筛 | 页面只有租户 / 渠道 / 模型三个维度 | 用这三个维度，或到调用日志按用户、Token 精确查 |
| 数字和调用日志对不上 | 看板按时间粒度聚合，日志是逐条 | 看板看趋势，日志看明细，口径不同属正常 |
| 找不到导出按钮 | 看板不提供导出 | 如需明细数据，请从调用日志页查询 |
