## 功能简介

运营概览是 LLM 网关的运行看板，展示请求量、成功率、Token 消耗、敏感命中、TTFT、活跃密钥与运行时长等指标，并提供模型/用户排行、模型用量分布和网关健康度。

本页对应 BOSS 控制台「大模型网关 → **数据看板**」（菜单文案取自 `navbar.data_dashboard`）。

## 进入路径

BOSS 控制台 → 大模型网关 → **数据看板**

前端真实路由：`/gateway/operations`

> ⚠️ 注意: 上表是 BOSS 控制台前端代码中的真实路径，不是文档站 URL。

## 筛选条件

| 筛选器 | 类型 | 说明 |
|--------|------|------|
| 时间范围 | 预设 | 今日 / 近 7 日 / 近 30 日 / 自定义 |
| 开始日期、结束日期 | 日期选择 | 仅「自定义」时生效 |
| 租户 | 下拉 | 选项来自数据中的租户维度 |
| 渠道 | 下拉 | 选项来自数据中的渠道维度 |
| 模型 | 下拉 | 选项来自数据中的模型维度 |

工具条还提供：

- **刷新**：手动重新拉取数据
- **重置**：清空三个维度筛选并把时间范围恢复为「今日」
- **时间粒度**（只读）：根据时间范围自动推导，显示为「小时」或「天」

> ⚠️ 注意: 页面**只有租户 / 渠道 / 模型三个维度筛选**，没有 Token、用户、提供商筛选器。

页面每 **30 秒** 自动刷新一次。

时间范围与粒度的对应关系（`resolveDashboardInterval`）：

| 时间范围 | 粒度 |
|----------|------|
| 今日 | 小时 |
| 近 7 日 / 近 30 日 | 天 |
| 自定义 | 跨度 `<=` 240 小时用小时，否则用天 |

## 指标卡

看板顶部展示 **7 个** 指标卡（响应式 1 / 2 / 4 / 7 列）：

| 指标 | 字段 | 说明 |
|------|------|------|
| 请求数 | `summary.requestCount` | 区间内请求总数，附环比变化率 |
| 成功率 | `summary.successCount` / `summary.requestCount` | 以百分比展示，环比按百分点计算 |
| Token 数 | `summary.totalTokens` | 以 K/M 缩写展示，附环比变化率 |
| 敏感命中 | `sensitiveHitCount` | 命中敏感内容的请求数，附环比变化率 |
| TTFT | `recentTTFTMaxMillis` | 最近窗口内的首 Token 时间最大值，越低越好 |
| 活跃密钥 | `activeTokenCount` | 活跃 Token 数量，附环比变化率 |
| 运行时长 | `uptimeSeconds` | 按「天/时/分」格式化，无环比 |

> 💡 提示: 无上一周期数据时，成功率卡的环比会显示「暂无前期」提示（i18n `dashboard_no_previous`）。

## 图表与排行

页面中部为两块图表并排：

| 图表 | 内容 |
|------|------|
| 趋势图 | 按当前粒度展示每桶的**请求量**（单系列柱状） |
| 模型用量分布 | 按模型拆分的**堆叠柱状**，最多取 Top 10 模型，其余归入「其他模型」 |

下方为三栏布局：

| 卡片 | 内容 |
|------|------|
| 模型排行 | 每个模型的请求数、Token 数、费用 |
| 用户排行 | 排名、用户、请求数、总 Token（带占比进度条） |
| TTFT 趋势 + 网关健康度 | 见下 |

### TTFT 趋势

折线图，包含两条系列：

| 系列 | 字段 |
|------|------|
| TTFT 最大值 | `maxTTFTMillis` |
| TTFT P95 | `p95TTFTMillis` |

TTFT 的时间粒度独立推导：跨度 `<= 24 小时` 用分钟，`<= 31 天` 用小时，否则用天；序列点数上限 1500。

### 网关健康度

| 指标 | 字段 | 说明 |
|------|------|------|
| 可用率 | `gatewayHealth.availablePercent` | 百分比 + 60 格进度条 |
| 上游渠道 | `healthyChannels` / `totalChannels` | 健康渠道数 / 渠道总数 |
| 限流事件 | `rateLimitEvents` | 区间内触发限流的次数 |
| 异常请求 | `abnormalRequests` | 区间内异常请求数 |

> ⚠️ 注意: 页面**没有使用记录明细表，也没有导出功能**；明细查询请使用 [调用日志](/boss/gateway/audit)。旧文档中的「使用记录表」「数据导出」「排行榜维度切换」等内容在当前代码中没有对应实现。

## 数据来源

看板通过两个接口取数：

| 用途 | 接口 |
|------|------|
| 看板汇总、排行、健康度 | `getUsageDashboard`（含 `summary` / `previousSummary` / `timeseries` / `topModels` / `topUsers` / `filterOptions` / `gatewayHealth`） |
| TTFT 时间序列 | `getUsageTimeseries`（`order: 'asc'`） |
