## 功能简介

令牌管理是 LLM 网关的**管理端 API 密钥管理**，供系统管理员查看和管理平台中所有 API 密钥。API 密钥是调用网关 API 的认证凭证，每个请求都必须携带有效的密钥。

本页对应 BOSS 控制台「大模型网关 → 用户管理 → **令牌管理**」（菜单文案取自 `navbar.apikey`）。

## 进入路径

BOSS 控制台 → 大模型网关 → 用户管理 → **令牌管理**

| 操作 | 前端路由 |
|------|---------|
| 列表 | `/tokens` |
| 创建 | `/tokens?action=create` |
| 编辑 | `/tokens/:id?action=edit` |

> ⚠️ 注意: 上表是 BOSS 控制台前端代码中的真实路径（`src/routes/paths.ts`），不是文档站 URL。

## 密钥列表

| 列 | 字段 | 说明 |
|----|------|------|
| 名称 | `name` | 密钥名称 |
| API 密钥 | `apiKey` | 掩码显示（见下），右侧提供复制按钮 |
| 所有者 | `belongTo` | 密钥归属用户 |
| RPM | `rateLimitRPM` | `undefined` 或 `0` 显示为无穷符号（不限制） |
| TPM(K) | `rateLimitTPM` | `undefined` 或 `0` 显示为无穷符号；否则显示 `{数值}K` |
| 访问 IP 白名单 | `allowedIPs` | 为空或仅含 `*` 时显示 `*`，否则折叠展示 |
| 过期时间 | `expiresAt` | 未设置显示「永不过期」；已过期时显示红色 `已过期` 标签与红色时间 |
| 创建时间 | `createdAt` | 日期时间格式 |

### 密钥掩码

列表中的密钥值只截取前 6 个字符，其余固定用 12 个星号覆盖：

```
sk-abc************
```

复制按钮复制的是**列表数据中的完整密钥值**（`item.apiKey`），不是掩码串。

> ⚠️ 注意: 代码中**没有**「完整密钥仅创建时展示一次」的逻辑；创建成功后页面直接返回列表。此外，创建页没有独立的成功弹窗。

列表支持多选；每行提供 **编辑** 与 **删除**（删除需二次确认）。

### 筛选条件

| 筛选器 | 说明 |
|--------|------|
| 所有者 | 按用户搜索，选中后按该用户过滤（来自 `searchUsers`） |

> ⚠️ 注意: 列表仅有「所有者」一个筛选器，没有 RPM / TPM / 状态 / 过期等筛选。

## 创建 / 编辑密钥

创建页与编辑页共用同一套表单，字段如下：

| 字段 | 标识 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|------|--------|------|
| 名称 | `name` | 文本 | ✅ | 空 | 编辑时禁用，不可修改 |
| 所有者 | `account` | 用户选择 | ✅ | 空 | 提交时同时写入 `account` 与 `belongTo` |
| RPM | `rateLimitRPM` | 数字 | — | 空 | `0`–`10000`；为空或 `0` 时不提交该字段 |
| TPM(K) | `rateLimitTPM` | 数字 | — | 空 | `0`–`100000`；为空或 `0` 时不提交该字段 |
| 访问 IP 白名单 | `allowedIPs` | 多行文本 | — | `*` | 见下方格式说明 |
| 永不过期 | `noExpires` | 开关 | — | 开启 | 关闭后必须填写过期时间 |
| 过期时间 | `expiresAt` | 日期时间 | 条件必填 | — | 仅在关闭「永不过期」时出现 |

提交时的处理：

- `expiresAt` 转为 **Unix 秒**；开启「永不过期」时提交 `0`
- `allowedIPs` 按换行或英文逗号拆分并去除空白；拆分结果为空时提交 `['*']`
- RPM / TPM 只有在大于 `0` 时才写入请求体

> 💡 提示: 数字输入框禁止输入 `e` / `E` / `+` / `-` / `.`，只能填整数。

## IP 白名单格式

`allowedIPs` 支持以下写法，多个值用英文逗号或换行分隔：

| 写法 | 示例 | 说明 |
|------|------|------|
| 单个 IPv4 | `192.168.1.100` | 精确匹配 |
| CIDR 网段 | `10.0.0.0/8` | 前缀范围 `0`–`32` |
| 通配 | `*` | 允许所有 IP（默认值） |

校验规则（`form.tsx` 的 `isValidIPOrCIDR`）：

- 仅支持 **IPv4**，段数必须为 4，每段 `0`–`255`
- 禁止前导零（如 `01`、`001`）
- CIDR 前缀 `0`–`32`
- **不支持 IPv6**

> ⚠️ 注意: 网关配置中的全局白名单同样只校验 IPv4。

## 删除密钥

点击 **删除** 并在确认弹窗中确认后，密钥被删除。

> ⚠️ 注意: 没有任何前端逻辑提示「删除后请求立即失败」，是否立即生效取决于服务端实现，文档不做保证。

## 类型中存在但页面未使用的字段

`ApiKey` 类型定义了 `status`（`active` / `expired`），类型中**并不存在** `usage` / `remain` 字段；i18n 中另有「已用额度」「剩余额度」「用量概览」「费用估算」等文案，但**当前列表与表单均未使用**。

> ⚠️ 注意: 上述用量/额度相关能力在前端没有入口，服务端是否支持未确认，文档暂不展开。

## 权限要求

需要 **系统管理员** 角色，可查看和管理平台中所有用户的 API 密钥。
