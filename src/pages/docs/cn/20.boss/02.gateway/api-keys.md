# API 密钥

API 密钥是调用网关的**门禁卡**：调用方每次请求模型都必须带上它。这一页让你查看和管理**全平台**的 API 密钥——不管是哪个用户、哪个租户的，都能在这里统一维护。

读完你能完成：为某个用户新建一把密钥、设置它的限流与访问范围、让它定时过期、在可疑时立即禁用，以及查看或删除已有密钥。

:::tip API 密钥就像门禁卡
卡上写着「你是谁」（所有者）和「你能走哪些门」（访问 IP 白名单、限流）。卡丢了要立刻停用，否则别人也能刷开门。给不同的人发不同的卡，出问题时才好定位。
:::

## 开始之前

- 权限：需要平台管理员账号（能进入 Boss 管理控制台）。
- 先确认这把密钥要发给**哪个用户**——创建时必须指定所有者。
- 想限制来源时，先准备好允许访问的 IP 或网段。

## 进入 API 密钥

1. 顶部导航点击 **大模型网关**。
2. 展开 **用户管理**，点击 **API 密钥**。

## 密钥列表怎么看

| 列 | 含义 |
| --- | --- |
| 名称 | 密钥名称 |
| API 密钥 | 掩码显示，右侧有复制按钮 |
| 状态 | 启用 / 已禁用 / 已过期 |
| 所有者 | 这把密钥归属哪个用户 |
| RPM | 每分钟请求数上限，显示「∞」表示不限制 |
| TPM(K) | 每分钟 Token 上限，显示「∞」表示不限制，否则形如 `48K` |
| 访问 IP 白名单 | 允许的来源 IP；显示 `*` 表示所有 IP 都可以 |
| 过期时间 | 未设置显示「永不过期」；已过期会标红并显示时间 |
| 创建时间 | 密钥创建时间 |

列表上方有**搜索框**，以及 **所有者** 筛选（至少输入一个字符才会出现候选用户）。勾选多行后可以**批量删除**。

:::info 掩码只是显示效果
列表里密钥只显示前 6 位，后面固定用 12 个星号遮住。点右侧的**复制按钮**复制到的是**完整密钥**，所以别把页面截图发给不该看到的人。
:::

![API 密钥列表：名称、API 密钥、状态、所有者、RPM、TPM(K)、访问 IP 白名单、过期时间](/assets/screenshots/boss/gateway-token-01.png)

Boss 的 API 密钥和普通用户的 [API 密钥](../../15.airouter/token.md) 长得几乎一样，只多一列 **所有者**——因为这一页管的是整个平台的密钥，得看清每一把属于谁。

## 新建一把 API 密钥

1. 在 **API 密钥** 页面点击右上角 **添加 API 密钥**。
2. 填写表单：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 名称 | 例如 `team-a-key` | 必填，创建后不能修改 |
   | 所有者 | 搜索并选择一个用户 | 必填，决定这把密钥归谁 |
   | RPM | 例如 `600` | 选填，`0`–`10000`；留空表示不限制 |
   | TPM(K) | 例如 `48` | 选填，`0`–`100000`，单位 K（1K = 1000 Token/分钟） |
   | 访问 IP 白名单 | 默认 `*` | 选填，格式见下节 |
   | 永不过期 | 默认开启 | 关掉后必须填写过期时间 |
   | 过期时间 | 选择到分钟 | 仅在关闭「永不过期」时出现 |

3. 点击 **确认**。创建成功后页面返回列表。

![「创建 API 密钥」表单：名称、所有者、RPM、TPM(K)、访问 IP 白名单](/assets/screenshots/boss/gateway-token-02.png)

创建表单比用户侧多一个必填的 **所有者**，其余字段（名称、RPM、TPM(K)、访问 IP 白名单、永不过期）含义完全一致。

### 数字输入的小规则

RPM 和 TPM 只能填**整数**，输入框不接受 `e`、`E`、`+`、`-`、`.` 这些字符。

### IP 白名单怎么写

多个值用**英文逗号**或**换行**分隔。

| 写法 | 示例 | 说明 |
| --- | --- | --- |
| 单个 IP | `192.168.1.100` | 精确匹配这一个地址 |
| 网段 | `10.0.0.0/8` | 允许整段地址，前缀范围 `0`–`32` |
| 通配 | `*` | 允许所有 IP，也是默认值 |

:::warning 只支持 IPv4
白名单只接受 IPv4 地址，每段取值 `0`–`255`，且不能有前导零（如 `01` 不合法）。IPv6 地址填进去不会被识别。
:::

## 启用与禁用

行末菜单里有 **启用** 和 **禁用**，各自会先弹一次确认：

| 操作 | 对调用方的影响 |
| --- | --- |
| 禁用 | 用这把密钥发起的**新请求**会被拒绝；已经开始的请求不会被主动中断。之后可以重新启用，密钥和配置保持不变 |
| 启用 | 恢复这把密钥的访问权限。原有的过期时间、访问限制和限流仍然生效 |

操作成功后右上角会提示「API 密钥「xxx」已禁用 / 已启用」。

:::info 禁用比删除更常用
怀疑密钥泄露时先**禁用**：一秒生效、可随时恢复；确认不再需要后再删除。被管理员禁用的密钥，用户自己无法在 Console 里启用，必须由你处理。
:::

## 编辑一把密钥

1. 在列表某一行点击 **编辑**。
2. 可以修改所有者、限流、IP 白名单和过期时间；**名称不可修改**，是灰色只读状态。
3. 点击 **确认** 保存。

## 删除一把密钥

1. 在列表某一行点击 **删除**。
2. 在确认弹窗里**手动输入密钥名称**才能执行删除。

勾选多行后还能 **批量删除**，同样需要二次确认。

:::warning 删除不可撤销
删除后这把已发出的密钥立刻失效，且无法恢复。删之前先确认没有正在依赖它的应用；只是想临时停掉，用 **禁用**。
:::

## 这张卡上没有余额

需要区分清楚：API 密钥只负责**认证和限流**，它本身不带「额度」「余额」，也不在这里绑定账户或专属费率。表单里没有「已用额度」「剩余额度」这类字段。要看费用和余额，去 [调用日志](/boss/gateway/audit) 与 [计费账户](/boss/gateway/billing-accounts)。

## 结果确认

回到 **API 密钥** 列表，能看到新密钥，且 **API 密钥** 列显示掩码；把完整密钥复制出来发给调用方，对方能成功调用模型，就说明配置生效了。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 「所有者」搜不到用户 | 输入字符太少 | 至少输入一个字符再选择 |
| 保存后密钥点不出来 | 只看到掩码 | 点右侧复制按钮，复制的是完整密钥 |
| 调用被拒绝 | 密钥已禁用、IP 不在白名单内，或已过期 | 看 **状态** 列，再编辑密钥补 IP 或延长过期时间 |
| 状态显示「已禁用」但不是我操作的 | 可能被其他管理员禁用 | 确认业务需要后点 **启用**，并核实操作记录 |
| 改了限流但没感觉 | 密钥限流与渠道限流是两层 | 两层都会生效，确认不是另一层在限制 |
