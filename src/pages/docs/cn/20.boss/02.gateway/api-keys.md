# 令牌管理

API 密钥是调用网关的**门禁卡**：调用方每次请求模型都必须带上它。这一页让你查看和管理**全平台**的 API 密钥——不管是哪个用户、哪个租户的，都能在这里统一维护。

读完你能完成：为某个用户新建一把密钥、设置它的限流与访问范围、让它定时过期，以及查看或删除已有密钥。

:::tip API 密钥就像门禁卡
卡上写着「你是谁」（所有者）和「你能走哪些门」（访问 IP 白名单、能调用哪些模型）。卡丢了要立刻注销，否则别人也能刷开门。给不同的人发不同的卡，出问题时才好定位。
:::

## 开始之前

- 权限：需要平台管理员账号（能进入 Boss 管理控制台）。
- 先确认这把密钥要发给**哪个用户**——创建时必须指定所有者。
- 想限制来源时，先准备好允许访问的 IP 或网段。

## 进入令牌管理

1. 左侧菜单点击 **大模型网关**。
2. 展开 **用户管理**，点击 **令牌管理**。

## 密钥列表怎么看

| 列 | 含义 |
| --- | --- |
| 名称 | 密钥名称 |
| API 密钥 | 掩码显示，右侧有复制按钮 |
| 所有者 | 这把密钥归属哪个用户 |
| RPM | 每分钟请求数上限，显示「∞」表示不限制 |
| TPM(K) | 每分钟 Token 上限，显示「∞」表示不限制，否则形如 `48K` |
| 访问IP白名单 | 允许的来源 IP；显示 `*` 表示所有 IP 都可以 |
| 过期时间 | 未设置显示「永不过期」；已过期会标红并显示「已过期」 |
| 创建时间 | 密钥创建时间 |

列表支持多选，右上角有 **刷新** 按钮。上方可按 **所有者** 筛选（至少输入一个字符才会出现候选用户）。

:::info 掩码只是显示效果
列表里密钥只显示前 6 位，后面固定用 12 个星号遮住。点右侧的**复制按钮**复制到的是**完整密钥**，所以别把页面截图发给不该看到的人。
:::

## 新建一把 API 密钥

1. 在 **令牌管理** 页面点击右上角 **添加 API 密钥**。
2. 填写表单：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 名称 | 例如 `team-a-key` | 必填，创建后不能修改 |
   | 所有者 | 搜索并选择一个用户 | 必填，决定这把密钥归谁 |
   | RPM | 例如 `600` | 选填，`0`–`10000`；留空表示不限制 |
   | TPM(K) | 例如 `48` | 选填，`0`–`100000`，单位 K（1K = 1000 Token/分钟） |
   | 访问IP白名单 | 默认 `*` | 选填，格式见下节 |
   | 永不过期 | 默认开启 | 关掉后必须填写过期时间 |
   | 过期时间 | 选择到分钟 | 仅在关闭「永不过期」时出现 |

3. 点击 **确认**。创建成功后页面返回列表。

### 数字输入的小规则

RPM 和 TPM 只能填**整数**，输入框不接受 `e`、`E`、`+`、`-`、`.` 这些字符。

### IP 白名单怎么写

多个值用**英文逗号**或**换行**分隔。

| 写法 | 示例 | 说明 |
| --- | --- | --- |
| 单个 IP | `192.168.1.100` | 精确匹配这一个地址 |
| 网段 | `10.0.0.0/8` | 允许整段地址，前缀范围 `0`–`32` |
| 通配 | `*` | 允许所有 IP，也是默认值 |

:::warning 只支持 IPv4
白名单只接受 IPv4 地址，每段取值 `0`–`255`，且不能有前导零（如 `01` 不合法）。IPv6 地址填进去不会被识别。
:::

## 编辑一把密钥

1. 在列表某一行点击 **编辑**。
2. 可以修改所有者、限流、IP 白名单和过期时间；**名称不可修改**，是灰色只读状态。
3. 点击 **确认** 保存。

## 删除一把密钥

1. 在列表某一行点击 **删除**。
2. 在确认弹窗中确认，密钥即被删除。

:::warning 删除前先确认没有业务在用
删除后这把已发出的密钥就失效了。删之前先确认没有正在依赖它的应用，避免线上调用突然中断。
:::

## 这张卡上没有余额

需要区分清楚：API 密钥只负责**认证和限流**，它本身不带「额度」「余额」。列表和表单里都没有「已用额度」「剩余额度」这类字段。要看某把密钥实际用了多少，请到 **调用日志** 按它筛选。

## 结果确认

回到 **令牌管理** 列表，能看到新密钥，且 **API 密钥** 列显示掩码；把完整密钥复制出来发给调用方，对方能成功调用模型，就说明配置生效了。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 「所有者」搜不到用户 | 输入字符太少 | 至少输入一个字符再选择 |
| 保存后密钥点不出来 | 只看到掩码 | 点右侧复制按钮，复制的是完整密钥 |
| 调用被拒绝 | IP 不在白名单内，或已过期 | 编辑密钥，补充来源 IP 或延长过期时间 |
| 改了限流但没感觉 | 密钥限流与渠道限流是两层 | 两层都会生效，确认不是另一层在限制 |
