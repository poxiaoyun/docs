# 调用日志

调用日志记录**每一次**经过网关的请求，包括调用方、渠道、模型、耗时、Token 数和费用。它是排查问题、核对用量、追溯敏感内容的主要依据。

读完你能完成：按时间、用户、密钥、渠道商、模型筛出想要的记录，打开某条记录查看请求与响应详情。

:::tip 像小区的监控录像
数据看板给你「今天小区进出多少人」的统计；调用日志是逐帧的监控录像，谁在几点、从哪个门进来、去了哪栋楼都记得清清楚楚。出问题时，就靠它逐条回看。
:::

## 开始之前

- 权限：需要平台管理员账号（能进入 Boss 管理控制台）。
- 需要 **网关配置** 里的 **启用审计日志** 处于开启状态，否则不会记录新的调用。

## 进入调用日志

1. 左侧菜单点击 **大模型网关**。
2. 展开 **用户管理**，点击 **调用日志**。

## 怎么筛选

页面顶部是筛选工具条：

| 筛选项 | 说明 |
| --- | --- |
| 时间范围 | 今日 / 昨日 / 近 3 日 / 近一周 / 自定义 |
| 开始日期、结束日期 | 仅在选「自定义」时可填 |
| 用户 | 按用户名模糊查询 |
| Token | 按密钥查询 |
| 渠道商 | 下拉选择，含「全部」 |
| 模型 | 按模型名模糊查询 |

工具条上有 **刷新** 和 **重置**：重置会把时间范围恢复为「今日」。

:::info 没有「结果」筛选器
界面上没有按成功 / 失败筛选的选项。要定位失败请求，可以观察列表中带红色标记的行，或按用户、模型先缩小范围。
:::

## 列表里有什么

| 列 | 含义 |
| --- | --- |
| 时间 | 请求发生时间，下方小字是这次调用的结果；点它可打开详情 |
| 渠道 | 实际路由到的渠道，下方小字是供应商 / 租户 / 工作空间 |
| 用户 | 发起调用的用户，带租户名 |
| Token | 使用的密钥 |
| 模型 | 请求的模型 |
| 耗时 | 端到端耗时；有首 Token 时间时，会同时显示「首 token」与「耗时」 |
| Token 数 | 本次消耗的总 Token |
| 费用 | 本次计费金额，按货币配置换算显示 |
| 标准 | 按模型价格表算出的标准价格 |

结果不是「成功」的行，左侧会固定显示一条红色竖线，方便一眼扫到异常。

:::info 费用是「算出来的数字」
这里的费用是按模型价格算出的**费用快照**，用于对账和分析。网关本身不做充值或扣款，费用列只是金额统计。
:::

## 查看某次调用的详情

1. 点击某条记录的 **时间** 列。
2. 弹窗里有若干标签页：

   | 标签页 | 内容 |
   | --- | --- |
   | 基本信息 | 请求 ID、用户、渠道、模型、耗时、状态码、Token 明细等 |
   | 请求数据 | 发给模型的请求内容（只读） |
   | 响应数据 | 模型返回的内容（只读） |
   | 元数据 | 附加信息（只读） |
   | 内容审查 | 敏感内容报告，仅当这次调用命中过审核时才出现 |

3. 各标签页没有内容时会显示「无数据」。

### 结果状态

| 结果 | 含义 |
| --- | --- |
| 成功 | 请求正常完成 |
| 失败 | 请求出错 |
| 已拦截 | 被内容审核拦下 |
| 超出配额 | 达到限额，未继续处理 |

列表中把「成功」和其他结果用颜色区分开，方便快速定位异常。

## 记录会保留多久

页面本身**没有保留期设置，也没有清理入口**。也就是说：

- 你无法在界面上删除或设定自动清理调用日志。
- 记录实际保留多久，取决于平台的部署与数据库策略。

如果因为容量或合规原因需要清理历史记录，请联系平台运维处理。

## 结果确认

设定好时间范围后，列表出现对应记录、点开某条能看到请求与响应内容，就说明查询正常。要验证某个渠道或密钥是否在用，用对应的筛选条件过滤，看是否还有记录产生。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 查不到任何记录 | 审计日志被关闭，或时间范围太窄 | 到 [网关配置](/boss/gateway/config) 确认审计开关，放宽时间范围 |
| 某条请求显示失败 | 上游渠道故障、密钥无效等 | 打开详情看错误信息，再到 [渠道管理](/boss/gateway/channels) 检查渠道 |
| 费用列是空的 | 对应模型还没配价格 | 到 [模型配置](/boss/gateway/model-metadata) 补上价格 |
| 状态是「已拦截」 | 命中了内容审核策略 | 到 [命中记录](/boss/gateway/sensitive-hits) 查看具体命中了什么 |
| 想删除旧记录 | 页面不提供清理功能 | 联系平台运维处理 |
