# 策略管理

策略管理定义**命中敏感词之后怎么办**。它把词库里的评分汇成一个总分，再按你设的阈值决定：只记一笔、把词替换成星号、交给外部审核服务，还是直接把请求拦下来。

读完你能完成：建一条「分数到多少就做什么」的规则、给替换动作配掩码、接入一个外部审核服务、调整多条规则的先后顺序，以及在需要时停用某条规则。

:::tip 策略是安检的处置手册
词库告诉你「箱子里有违禁品」，策略告诉你「发现了怎么办」：登记放行、当场没收（拦截），还是拿去复检（委托外部服务）。同一份清单可以配多套处置规则。
:::

## 开始之前

- 权限：需要平台管理员账号（能进入 Boss 管理控制台）。
- 确认 **网关配置** 里的 **启用内容审核** 是开的，否则所有策略都不执行。
- 词库里要有已启用的词条，否则没有分数可以比，策略永远不会触发。
- 选「委托外部服务」时，先准备好对方服务的地址，以及它返回什么算放行、什么算拦截。

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 触发条件 | 「评分 与 阈值」的比较方式，列表里显示为 `≥ 50` 这种形式 |
| 阈值 | 分界线，`0`–`100`，默认 `50`。分数过了这条线才执行动作 |
| 执行动作 | 命中后做什么：记录日志 / 替换敏感词 / 委托外部服务 / 拦截请求 |
| 优先级 | `1`–`10`，多条策略同时命中时决定先后。**数字越小优先级越高** |
| 掩码 | 替换动作使用的字符，默认 `*` |

## 策略列表

| 列 | 含义 |
| --- | --- |
| 策略名称 | 策略名字，下方小字是描述；点名称可直接编辑 |
| 触发条件 | 形如 `≥ 50` |
| 执行动作 | 这条策略命中后执行哪种动作 |
| 优先级 | `1`–`10` |
| 启用状态 | 已启用 / 已禁用，用彩色标签显示，**不是开关** |
| 更新时间 | 最近一次修改时间 |

上方只有 **是否启用** 一个筛选（启用 / 未启用），**没有搜索框**。行末菜单有 **启用**、**禁用**、**编辑**、**删除**。

![策略管理列表：策略名称、触发条件、执行动作、优先级、启用状态、更新时间](/assets/screenshots/boss/gateway-policy-01.png)

一行就是一条规则：**触发条件** 是分数阈值（截图里是 `≥ 50`），**执行动作** 是命中后做什么（截图里是「拦截请求」）。启用状态是标签，切换要点行末的 **启用 / 禁用**。

## 创建策略

1. 点右上角 **创建策略**。
2. 填写表单：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 策略名称 | 例如「高分拦截」 | 必填 |
   | 描述 | 一句话说明 | 选填 |
   | 比较运算符 | 默认「大于等于 (≥)」 | 必填，见下表 |
   | 阈值 | 默认 `50` | 必填，`1`–`100` |
   | 执行动作 | 默认「拦截请求」 | 必填，见下表 |
   | 优先级 | 默认 `1` | `1`–`10` |
   | 启用 | 默认开启 | 关闭则这条策略暂不生效 |

3. 如果动作选的是「替换敏感词」或「委托外部服务」，下方会展开对应配置（见下两节）。
4. 点 **确定**。

**比较运算符**只有四种：

| 选项 | 含义 |
| --- | --- |
| 大于等于 (≥) | 评分达到或超过阈值时触发 |
| 大于 (>) | 评分超过阈值时触发 |
| 小于等于 (≤) | 评分不高于阈值时触发 |
| 小于 (<) | 评分低于阈值时触发 |

**执行动作**有四种：

| 选项 | 命中后会怎样 |
| --- | --- |
| 记录日志 | 内容照常通过，只在命中记录里留一笔 |
| 替换敏感词 | 把命中的词替换成掩码字符后继续 |
| 委托外部服务 | 把内容发给一个外部审核服务，由它判定 |
| 拦截请求 | 直接拒绝这次请求，返回错误 |

:::info 建议从「记录日志」开始
第一次配置时先用低风险动作跑一段时间，观察命中记录是否准确，再逐步改成替换或拦截。一上来就拦，很容易把正常业务打停。
:::

## 替换敏感词的配置

动作选 **替换敏感词** 后，下方展开两项：

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 掩码字符 | `*` | 用来替换的字符 |
| 掩码模式 | 逐字替换 | 逐字替换（`敏感词` → `***`）/ 固定长度（统一替换成固定长度）/ 单字符替换（整词换成单个字符） |

## 委托外部服务的配置

动作选 **委托外部服务** 后，下方展开 Webhook 配置。

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| 请求地址 | 空 | 必填，外部审核服务的 URL |
| HTTP 方法 | `POST` | 可选 POST / GET |
| 超时时间（秒） | `5` | 请求超时时间 |
| 自定义请求头 | 空 | 点 **创建请求头** 添加键值对，可删 |

**响应判断**用来解释对方的返回：

| 配置项 | 说明 |
| --- | --- |
| JSON Path | 从返回里取出判定值，例如 `$.result.blocked` |
| 放行值列表 | 视为放行的返回值，输入后回车添加 |
| 拦截值列表 | 视为拦截的返回值 |
| 默认动作 | 返回值不在任何列表里时采用：放行 / 拦截请求 |
| 消息路径 | 可选，从返回里取出要展示给调用方的提示 |

:::warning 超时默认值以输入框为准
界面上的说明文案写的是「默认 30 秒」，但新建策略时输入框里预填的是 `5`。按输入框里的实际值理解，别把 30 秒当成默认值。
:::

:::info 没有「认证配置」这一节
界面里只有请求头可以填。需要 Bearer、Basic 之类的认证时，用 **自定义请求头** 手动加一条（例如 `Authorization: Bearer xxx`）。
:::

## 启用、禁用与删除

| 操作 | 说明 |
| --- | --- |
| 启用 | 在行末菜单点 **启用**，策略立即参与判定 |
| 禁用 | 在行末菜单点 **禁用**，策略保留但不再执行 |
| 编辑 | 回到表单修改各项配置 |
| 删除 | 需要在确认弹窗里**手动输入策略名称**才能删除 |

:::warning 删除不可撤销
删掉的策略无法恢复。临时不想用时用 **禁用**，别删。
:::

## 优先级怎么理解

优先级取值 `1`–`10`。**数字越小优先级越高**，多条策略同时命中时先执行优先级高的那条。页面提示还建议：高阈值规则给它更高的优先级。

举个实用的配法：

| 策略 | 条件 | 动作 | 优先级 |
| --- | --- | --- | --- |
| 记录观察 | `≥ 5` | 记录日志 | `5` |
| 中分替换 | `≥ 8` | 替换敏感词 | `3` |
| 高分拦截 | `≥ 9` | 拦截请求 | `1` |

这样低分只留痕，中分改写，高分才拦，误伤最小。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 策略不生效 | 总开关关闭，或这条策略被禁用 | 检查网关配置的审核开关与这条策略的启用状态 |
| 命中记录里一条都没有 | 阈值设得太高，或词条评分太低 | 调低阈值，或提高词条评分 |
| 内容里的词变成了星号 | 动作是「替换敏感词」 | 属预期；想直接拒绝就把动作改成拦截 |
| 请求直接被拒 | 动作是「拦截请求」 | 检查阈值是否过低，或改成记录 / 替换 |
| 外部服务明明说放行却被拦 | 返回值和放行值列表格式不一致，或 JSON Path 取错了字段 | 核对 JSON Path 与列表取值，必要时设好默认动作 |
| 删不掉策略 | 删除需要输入策略名称 | 按提示手动输入名称确认 |
