# 加速卡信息

加速卡信息是**按卡看集群**的看板：GPU 和 NPU 的使用率、显存、功耗、温度，以及卡与卡之间是否均衡。怀疑「算力不够用」或「卡分得不均」时看这一页。

读完这页，你能找到入口、看懂汇总卡与趋势图，并知道页面为空时该怎么排查。

:::tip 两个词对照

- **加速卡** ≈ 服务器里专门算 AI 的引擎，包括 GPU 和 NPU。
- **显存（HBM / VRAM）** ≈ 卡上自带的内存，模型越大占用越多。

:::

## 开始之前

- 需要 **系统管理员** 账号。
- 前置：集群已接入平台，并且已安装加速卡监控组件（可在 **系统应用** 里部署）。

## 进入方式

1. 顶部导航点击 **智算平台**，再在左侧栏 **智算平台** 分组下点击 **集群管理**。
2. 点进目标集群。
3. 左侧 **集群信息** 分组下点击 **加速卡信息**。

## 这一页看什么

加速卡信息把**名称或标题里含 `gpu` 或 `npu`** 的监控看板聚在一起：

| 关注点 | 说明 |
| --- | --- |
| 卡使用率 | 有多少卡在算、平均利用率多少 |
| 显存占用 | 显存是否快满，模型能不能再放 |
| 负载均衡 | 卡与卡之间是否一张忙一张闲 |
| 型号分布 | 某些型号设备的繁忙与空闲情况 |
| 功耗与温度 | 是否接近上限、有没有过热风险 |

![加速卡信息页：五张汇总卡与下方的使用率、显存、功耗趋势图](/assets/screenshots/boss/cluster-gpu-01.png)

页面顶部是汇总卡（例如 NPU 总数、节点数、平均使用率、平均显存使用率、集群总功耗），下面是趋势图。如果这一页全是 0 或者没有卡，通常是**这个集群本来就没有这类卡**，不是页面坏了。

:::info NPU 看板排在前面
如果集群里同时有 NPU 和 NVIDIA GPU 看板，**NPU 看板会排在前面**，方便国产加速卡优先展示。
:::

## 结果确认

- 看板能正常出图，说明加速卡监控数据已经采集上来。
- 图表空白：到 **系统应用** 检查加速卡监控组件是否已部署。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 看不到任何卡 | 集群没有加速卡，或未安装加速卡监控组件 | 先确认集群实际有卡，再到 **系统应用** 部署组件 |
| 同一型号只显示汇总容量 | 该型号未上报逐设备指标 | 属正常现象，汇总容量仍可参考 |
| 使用率一直 0 但业务在跑 | 监控采集延迟，或采集组件异常 | 换更长时间窗再看；仍为 0 就到 **系统应用** 检查组件 |
| 想看是哪个工作负载占着卡 | 这一页只看卡 | 到 **工作负载** 或 **调度视图** 交叉排查 |
