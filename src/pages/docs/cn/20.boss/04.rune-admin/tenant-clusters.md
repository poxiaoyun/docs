# 租户集群

**租户集群**是「租户视角的集群开通管理」：选一个租户，就能看到它在每个集群上的开通状态，并在需要的集群上完成开通。

读完这页，你能完成：找到某个租户开通了哪些集群、给它在某个集群上开通、进入已开通的集群做配额配置、以及在状态读不到时重试。

:::tip 一个类比
开通（enablement）就像**给这家公司在这栋楼里发门禁卡**：楼是现成的（集群已经接入平台），卡发下去之后，这家公司的人才能进这栋楼用里面的机器。
:::

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 已开通集群 | 这个租户已经被允许使用的集群 |
| 开通状态 | 未开通 / 开通中 / 已开通 / 开通失败 |
| 配置 | 进入「这个租户 + 这个集群」的详情，去分配额、规格授权、工作空间 |
| 在此集群开通 | 给这个租户在当前集群新建开通关系 |

## 开始之前

- 需要 **系统管理员** 账号。
- 前置：租户已创建（见[租户管理](/boss/iam/tenants)），集群已接入并上线（见[集群管理](/boss/rune-admin/clusters)）。

## 进入方式

顶部导航点击 **智算平台**，再在左侧栏 **智算平台** 分组下点击 **租户集群**。

## 租户列表怎么看

| 列 | 说明 |
| --- | --- |
| 名称 | 租户名，点击进入该租户的集群列表 |
| 已开通集群 | 这个租户开通了哪些集群。可能显示：**正在加载已开通集群**、**暂未开通**、**查看全部 N 个已开通集群**（点开看列表）、**加载更多集群** |
| 创建时间 | 租户创建时间 |

![租户集群列表：每行一个租户，已开通集群一列用胶囊展示开通数量与展开入口](/assets/screenshots/boss/rune-tenant-clusters-01.png)

## 租户详情：集群 × 开通状态

点租户名进入后，标题是「租户 / 租户名 / 选择集群」，下面是这个租户在**所有集群**上的开通情况：

| 列 | 说明 |
| --- | --- |
| 集群 | 集群名与 ID，点击可进入该集群的看板 |
| 开通状态 | 未开通 / 开通中 / 已开通 / 开通失败；失败时会带出原因 |

每行的操作按状态出现，同一行通常只出现一个：

| 操作 | 什么时候出现 | 点了做什么 |
| --- | --- | --- |
| 配置 | 已经开通、能读到开通状态时 | 进入集群内的租户详情（概览 / 配额 / 规格授权 / 工作空间） |
| 在此集群开通 | 这个集群还**未开通**时 | 打开开通表单，为这个租户在当前集群开通 |
| 重试 | 状态读取失败时 | 重新读取一遍集群列表与开通状态 |

## 给租户开通一个集群

1. 进入 **智算平台 → 租户集群**，点目标租户名。
2. 在 **未开通** 的那个集群行点 **在此集群开通**。
3. 在表单里确认租户与集群，提交开通。
4. 状态会先变成 **开通中**，成功后变成 **已开通**；失败时显示 **开通失败** 并在状态信息里给出原因。

开通成功后，回到该行点 **配置**，去配[配额](/boss/rune-admin/tenants)、规格授权与工作空间。

:::warning 开通只是「发门禁卡」
开通之后租户还**没有额度**。必须再进 **配置 → 配额** 创建配额，用户才能真正用上算力。
:::

## 结果确认

| 你想确认的事 | 去哪里看 |
| --- | --- |
| 租户开通了几个集群 | 租户集群列表的 **已开通集群** 列 |
| 某个集群开通成功了吗 | 租户详情里该集群行的开通状态 |
| 开通后能用了吗 | 点 **配置** 进 **配额** 页，确认已有配额 |

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 已开通集群显示「暂未开通」 | 这个租户还没在任何集群开通 | 点租户名进去，在目标集群点 **在此集群开通** |
| 没有「在此集群开通」 | 该集群已经开通，或状态还在加载 | 稍等刷新；已开通的行走 **配置** |
| 开通一直停在「开通中」 | 平台正在准备资源 | 等一会儿点 **重试**；长时间不变请查集群状态 |
| 开通失败，提示资源不足 | 集群资源池没有可用容量 | 先扩充资源池或调整配额上限 |
| 列表里只有部分集群 | 分页 | 页底翻页查看更多集群 |
