# 系统应用

系统应用是部署在集群里的**基础设施级组件**，比如监控、日志、存储、网关。它们服务于整个集群，由系统模版市场里的模版一键部署出来。

读完这页，你能完成：查看已部署的系统应用、部署一个新的、以及编辑或删除它们。

:::tip 两个词对照

- **系统应用** ≈ 平台自带的中间件（监控、日志、网关等）。
- **模版** ≈ 提前配好的「装机清单」，系统应用就是按模版装出来的。

:::

## 开始之前

- 你需要 **系统管理员** 账号。
- 前置：集群已接入平台；要部署新组件，市场里需要有对应的系统域模版。

## 进入方式

1. 左侧菜单点击 **智算平台** → **集群管理**，点进目标集群。
2. 左侧 **运维管理** 分组点击 **系统应用**。

## 实例列表怎么看

| 列 | 说明 |
| --- | --- |
| 名称 | 实例名称，点击进入详情页 |
| 版本 | 部署所用的模版版本 |
| 状态 | 实例当前状态 |
| 创建时间 | — |

每行的操作：**编辑**、**删除**（带确认框）；支持多选批量删除。

## 部署一个新的系统应用

1. 在实例列表点击右上角 **创建系统应用**。
2. 页面跳到 **系统模版市场**。
3. 选择一个模版并选好版本，点击 **部署**。
4. 在部署页按模版要求填写参数。
5. 提交后回到列表，新实例先出现在列表里，状态逐步变为运行中。

详见 [系统模版市场](/boss/rune-admin/system-market)。

## 管理已有实例

- **看详情**：点击实例名称进入详情页，查看基本信息和关联资源。
- **编辑**：修改这个实例可配置的部分。
- **删除**：点击 **删除** 并确认，删除后释放相关资源。

:::warning 删掉中间件会影响整集群

删除系统应用可能导致集群的监控、日志或网关能力不可用。请先确认没有业务在依赖它，再执行删除。

:::

## 和用户应用实例的区别

| 对比项 | 系统应用 | 用户应用实例 |
| --- | --- | --- |
| 来自哪 | 系统模版市场 | 用户应用市场 |
| 作用范围 | 整个集群 | 某个工作空间 |
| 从哪管 | 集群 → 系统应用 | 智算平台的 **应用** |

## 结果确认

- 新实例在列表里出现，**状态** 最终变为运行中。
- 点进去能看到基本信息和关联资源，没有报错。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 状态一直不是运行中 | 部署参数不对或集群资源不足 | 进详情看事件，修正后重试 |
| 日志 / 监控页面没数据 | 对应组件没装或已删 | 到本页确认组件是否在运行 |
