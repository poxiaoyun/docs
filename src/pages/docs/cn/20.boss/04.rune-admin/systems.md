# 系统应用

系统应用是部署在集群里的**基础设施级组件**，比如监控、日志、网关。它们服务于整个集群，由「系统」域的应用按版本一键部署出来。

读完这页，你能完成：查看已部署的系统应用、从应用目录里选一个组件部署到集群、编辑或删除已有实例。

:::tip 两个词对照

- **系统应用** ≈ 平台自带的中间件（监控、日志、网关等）。
- **应用** ≈ 提前配好的「装机清单」，系统应用就是按系统域的应用装出来的，在 **智算平台 → 应用** 里维护。

:::

## 开始之前

- 你需要 **系统管理员** 账号。
- 前置：集群已接入平台；要部署新组件，应用目录里需要有「系统」域的应用，并且它至少有一个可用版本。

## 进入方式

1. 顶部导航点击 **智算平台**，再在左侧栏 **智算平台** 分组下点击 **集群管理**。
2. 点进目标集群。
3. 左侧 **运维管理** 分组点击 **系统应用**。

## 实例列表怎么看

| 列 | 说明 |
| --- | --- |
| 名称 | 实例名称，点击进入详情页 |
| 版本 | 部署时选的应用版本 |
| 状态 | 实例当前阶段 |
| 创建时间 | — |

每行的操作：**编辑**、**删除**（带确认框）；勾选多行可以批量删除；右上角有刷新。

![系统应用列表：名称、版本、状态、创建时间，右上角是创建系统应用](/assets/screenshots/boss/cluster-systems-01.png)

## 部署一个新的系统应用

1. 在实例列表点右上角 **创建系统应用**。
2. 页面打开**应用目录**：一张张卡片列出当前集群可部署的系统类应用，支持搜索与翻页。
3. 点选一个应用，进入配置页。
4. 在配置页顶部的应用信息卡里，用**版本选择器**选一个版本。下拉里只列出**校验通过**的版本；应用不可用或版本不可用时，页面会直接给出提示。
5. 在下方部署表单里按应用要求填写参数。实例名称有默认值，可以改。
6. 点 **创建** 提交，页面回到实例列表。

:::info 目录里没有想要的组件
应用目录里只出现「系统」域且已发布的版本。找不到说明还没有对应的应用或版本——请先到 **智算平台 → 应用** 创建应用、上传版本并调整可见性。
:::

## 管理已有实例

| 操作 | 说明 |
| --- | --- |
| 详情 | 点实例名称进入，查看基本信息与关联资源 |
| 编辑 | 修改这个实例可配置的部分 |
| 删除 | 确认后删除，释放相关资源；支持批量删除 |

:::warning 删掉中间件会影响整集群
删除系统应用可能导致集群的监控、日志或网关能力不可用。请先确认没有业务在依赖它，再执行删除。
:::

## 和用户应用实例的区别

| 对比项 | 系统应用 | 用户的应用实例 |
| --- | --- | --- |
| 来自哪 | 应用目录里的「系统」域应用 | 用户自己的应用或公开应用 |
| 作用范围 | 整个集群 | 某个工作空间 |
| 从哪管 | 集群 → 系统应用 | 智算平台的业务页面 |

## 结果确认

- 新实例出现在列表里，**状态** 最终进入运行态。
- 点进去能看到基本信息和关联资源，没有报错。
- 监控、日志相关页面开始有数据，说明对应组件已就绪。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 应用目录是空的 | 没有系统域应用，或版本未发布 | 先到 **应用** 创建并上传版本 |
| 版本下拉是空的 | 该应用没有校验通过的版本 | 重新上传或修复版本 |
| 状态一直不是运行中 | 部署参数不对或集群资源不足 | 进详情看事件，修正后重试 |
| 日志 / 监控页面没数据 | 对应组件没装或已删 | 到本页确认组件是否在运行 |
| 部署后提示应用不可用 | 应用分类或域不匹配 | 确认所选应用属于「系统」域且分类正确 |
