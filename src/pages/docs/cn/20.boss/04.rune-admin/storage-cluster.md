# 存储集群

用户创建的推理服务、微调任务、开发环境都需要「存东西」：模型文件、数据集、中间结果。存储集群就是集群里负责这件事的组件，它和系统应用一样，由应用按版本部署出来。

读完这页，你能完成：查看集群里已有的存储实例、部署一个新的存储集群、排查存储相关异常。

:::tip 两个词对照

- **存储集群** ≈ 集群里专门负责存文件的组件。
- **存储卷 / 存储类** ≈ 具体的一块存储与它的类型定义，在 **工作负载** 里查看。

:::

## 开始之前

- 你需要 **系统管理员** 账号。
- 前置：集群已接入平台；应用目录里需要有「存储」类应用与可用版本。

## 进入方式

1. 顶部导航点击 **智算平台**，再在左侧栏 **智算平台** 分组下点击 **集群管理**。
2. 点进目标集群。
3. 左侧 **运维管理** 分组点击 **存储集群**。

## 存储集群列表

列表字段和系统应用一致：

| 列 | 说明 |
| --- | --- |
| 名称 | 实例名称，点击进入详情页 |
| 版本 | 部署时选的应用版本 |
| 状态 | 实例当前阶段 |
| 创建时间 | — |

每行的操作：**编辑**、**删除**（带确认框）；支持批量删除。

![存储集群列表：名称、版本、状态、创建时间，右上角是创建存储集群](/assets/screenshots/boss/cluster-storages-01.png)

**状态** 是关键：刚建好时可能显示同步中，等一会儿刷新即可；稳定后进入运行态。

## 部署一个存储集群

1. 在实例列表点右上角 **创建存储集群**。
2. 在应用目录里选一个存储类应用。
3. 选一个**校验通过**的版本。
4. 按应用要求填写部署参数。
5. 点 **创建** 提交，回到列表确认状态逐步进入运行态。

:::info 存储和系统应用是同一套列表
两者共用同一套实例列表与详情页，只是按类别筛选。所以列、操作、详情页完全一样，差别只在入口和所选的分类。
:::

## 常见适用场景

- 初始化一个新集群的基础存储能力。
- 补装缺的存储组件。
- 排查平台级存储实例运行异常。

## 结果确认

- 新实例出现在列表里，**状态** 最终进入运行态。
- 用户侧创建工作负载时能选到对应的存储类与存储卷。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 创建存储卷时没有可选项 | 集群没有可用的存储组件 | 到本页部署一个存储集群 |
| 应用目录里没有存储类应用 | 还没有对应的应用或版本 | 到 [应用](/boss/rune-admin/applications) 创建并上传版本 |
| 存储实例异常 | 参数不对或节点资源不足 | 进详情看状态与事件后重试 |
| 列表一直显示同步中 | 刚部署完，状态还没同步 | 稍等刷新 |
