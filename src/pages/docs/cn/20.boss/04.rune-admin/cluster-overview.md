# 集群信息

集群信息是你进入一栋「机房大楼」（集群）后的总看板：把 CPU、内存、节点数量和核心服务的情况集中在一屏，用来判断整体是否健康。要下钻到某台机器或某张卡，再点左侧的 **节点状态** 和 **加速卡信息**。

## 开始之前

- 需要 **系统管理员** 账号。
- 前置：已经有一个接进平台的集群，见 [集群管理](/boss/rune-admin/clusters)。

## 查看集群总览

1. 顶部导航点击 **智算平台**，再在左侧栏 **智算平台** 分组下点击 **集群管理**。
2. 在集群列表里点击你要看的集群名称。
3. 左侧子菜单点击 **集群信息**。

:::info 这一页是「基础看板」

集群信息页只渲染基础类监控看板，**不包含加速卡看板**。要看每张卡的使用率、显存、温度，请到 **加速卡信息** 子页。

:::

![集群信息页：上方是集群摘要卡（节点总数、就绪节点数、Pod 总数、CPU 容量），下方是按小时刷新的监控图](/assets/screenshots/boss/cluster-overview-01.png)

这一页就是集群的体检报告：**集群摘要** 四张卡给当前快照，下面的趋势图默认看 1 小时窗口，右上角能把刷新间隔从 `1 小时` 改短，或把 `refresh` 从 `off` 打开成自动刷新。

## 页面上有什么

| 区块 | 内容 |
| --- | --- |
| 基础监控图 | 集群的 CPU、内存、节点数量、核心服务等指标 |
| 变量筛选 | 顶部若出现下拉筛选，说明这个监控模板提供了可切换的视角 |
| 下钻入口 | 左侧子菜单可继续进入节点、加速卡、存储、日志等页面 |

## 结果确认

- 页面上的图表能正常画出来（不是一直转圈），说明集群监控数据已经接上。
- 图表长时间空白：通常是集群还没装监控组件，去 **系统应用** 看看监控相关组件是否已经部署。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 图表一直转圈或空白 | 集群未安装监控采集组件 | 到 **系统应用** 部署监控组件 |
| 只看到基础指标，找不到卡的信息 | 加速卡看板在别的子页 | 点左侧 **加速卡信息** |
