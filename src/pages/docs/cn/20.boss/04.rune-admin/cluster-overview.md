# 集群信息

集群信息是你进入一栋「机房大楼」（集群）后的总看板：把 CPU、内存、节点数量和核心服务的情况集中在一屏，用来判断整体是否健康。要下钻到某台机器或某张卡，再点左侧的 **节点状态** 和 **加速卡信息**。

## 开始之前

- 需要 **系统管理员** 账号。
- 前置：已经有一个接进平台的集群，见 [集群管理](/boss/rune-admin/clusters)。

## 查看集群总览

1. 顶部导航点击 **智算平台**，再在左侧栏 **智算平台** 分组下点击 **集群管理**。
2. 在集群列表里点击你要看的集群名称。
3. 左侧子菜单点击 **集群信息**。

:::info 三个看板是同一套渲染
**集群信息**、**节点状态**、**加速卡信息** 用的是同一个看板页面，只靠地址最后一段区分取哪一组监控图：`basic` 取基础看板，`nodes` 取节点看板，`accelerator` 取加速卡看板。所以三页的操作方式完全一样，差别只在内容。
:::

![集群信息页：上方是集群摘要卡（节点总数、就绪节点数、Pod 总数、CPU 容量），下方是按小时刷新的监控图](/assets/screenshots/boss/cluster-overview-01.png)

这一页就是集群的体检报告：**集群摘要** 几张卡给当前快照，下面的趋势图默认看 1 小时窗口，右上角能把刷新间隔改短，或把自动刷新打开。

## 页面上有什么

| 区块 | 内容 |
| --- | --- |
| 基础监控图 | 集群的 CPU、内存、节点数量、核心服务等指标 |
| 变量筛选 | 顶部若出现下拉筛选，说明这个监控模板提供了可切换的视角 |
| 时间窗与刷新 | 右上角切换时间范围和自动刷新间隔 |
| 下钻入口 | 左侧子菜单可继续进入节点、加速卡、资源、运维等页面 |

## 动态仪表盘

除了固定的三个看板，集群还有一个 **动态仪表盘** 页面：左边用 YAML 编辑看板定义，右边实时预览，改完点重置可以恢复。它**不在左侧菜单里**，需要用地址直接打开，也没有保存按钮，属于临时拼看板用的进阶页面。见[动态仪表盘](/boss/rune-admin/dynamic-dashboard)。

## 结果确认

- 页面上的图表能正常画出来（不是一直转圈），说明集群监控数据已经接上。
- 图表长时间空白：通常是集群还没装监控组件，去 **系统应用** 看看监控相关组件是否已经部署。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 图表一直转圈或空白 | 集群未安装监控采集组件 | 到 **系统应用** 部署监控组件 |
| 只看到基础指标，找不到卡的信息 | 加速卡看板在别的子页 | 点左侧 **加速卡信息** |
| 左侧找不到「动态仪表盘」 | 它不在菜单里 | 用地址直接打开，或从本页的链接进入 |
