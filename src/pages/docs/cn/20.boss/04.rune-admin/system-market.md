# 系统模版市场

系统模版市场是集群级的「基础设施应用商店」：这里列的都是「系统」域的模版（监控、日志、存储、网关这类平台自带的中间件）。你挑一个模版、选个版本、把参数填好，就能把它部署到当前集群。

读完这页，你能完成：从市场里部署一个系统应用或存储集群。

:::tip 两个词对照

- **模版** ≈ 提前配好的「装机清单」。
- **系统应用** ≈ 平台自带的中间件（监控、日志、网关等）。

:::

## 开始之前

- 你需要 **系统管理员** 账号。
- 前置：集群已接入平台；市场里要有对应的模版，如果没有，先去 [应用模版](/boss/rune-admin/templates) 创建并发布。

## 进入方式

市场没有独立的左侧菜单，它由 **系统应用** 或 **存储集群** 页面的新增按钮带进去：

- 部署系统中间件：**集群管理** → 选集群 → **运维管理** 分组 → **系统应用** → 点击 **创建系统应用**。
- 部署存储：**集群管理** → 选集群 → **运维管理** 分组 → **存储集群** → 点击 **创建存储集群**。

进入后页面标题会根据类别显示为 **系统应用模版** 或 **存储集群模版**。

![系统应用模版：每张卡片是一个可部署的系统组件（如 vpa），带版本与语言标签，右侧是部署按钮](/assets/screenshots/boss/cluster-market-system-01.png)

系统模版市场是一张张卡片，每张卡片给出组件名、一句话说明、语言和版本，点卡片右侧的 **部署** 直接装到集群里。截图里第一张是 `vpa`（Kubernetes Vertical Pod Autoscaler，1.6.0 版本）。

## 一键部署

1. 在市场里找到目标模版卡片，点击 **部署**。
2. 选择要部署的 **版本**。
3. 进入部署页，按模版给出的表单逐项填写参数（参数由模版自身定义，不同模版不一样）。
4. 提交部署，平台会开始创建对应的实例。

部署完成后，回到 **系统应用** 或 **存储集群** 列表就能看到这个实例的运行状态。

:::info 市场里没有分类筛选

市场页只展示「系统」域的模版，所以不提供分类筛选；具体是系统类还是存储类，由模版自身的分类决定。

:::

![存储集群模版：卡片列出 storage-nfs、storagevolume 等存储组件与其版本](/assets/screenshots/boss/cluster-market-storage-01.png)

存储模版和系统应用模版是同一个市场的两个分类，切换靠顶部地址末段（`system` 与 `storage`）。存储类模版部署出来的是存储底座（如 `storage-nfs`、`storagevolume`），供后续的存储卷使用。

## 和用户应用市场的区别

| 对比项 | 系统模版市场 | 用户应用市场 |
| --- | --- | --- |
| 面向谁 | 系统管理员 | 普通用户 |
| 用哪些模版 | 系统域模版 | 用户域模版 |
| 部署到哪 | 整个集群 | 某个工作空间 |
| 从哪进 | 系统应用 / 存储集群 → 新增 | 智算平台的 **应用市场** |

## 结果确认

- 提交部署后，在 **系统应用** 或 **存储集群** 列表里出现新实例，**状态** 会从部署中逐步变为运行中。
- 点实例名称进详情页，能看到基本信息和关联资源。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 市场里找不到想要的模版 | 没有发布对应的系统域模版 | 先到 [应用模版](/boss/rune-admin/templates) 创建并发布 |
| 部署后一直没起来 | 参数填错或资源不足 | 到实例详情看状态和事件，修正后重试 |
| 看不到「部署」按钮 | 该模版没有可部署的版本 | 到 [应用模版](/boss/rune-admin/templates) 给模版发布版本 |
