# 工作负载

工作负载（Kubernetes 资源浏览器）是集群的「对象视角」：把集群里正在运行的东西按类型列出来，方便你确认某个对象到底建成功了没有、在哪里。

这里的名字都比较技术，对照一下就好：

| 界面上的标签 | 通俗解释 |
| --- | --- |
| 节点 | 一台机器 |
| 容器组 | 一组一起运行的容器，是最小运行单位 |
| 无状态服务 / 有状态服务 / 守护进程服务 | 三种把程序跑起来的方式 |
| 任务 / 定时任务 | 跑一次 / 按时间跑的任务 |
| 服务 / 路由 / Ingress 类 | 把程序对外提供访问的方式 |
| 存储类 / 存储卷 | 定义和使用存储的方式 |
| 配置 / 密钥 | 存配置和敏感信息的地方 |

## 开始之前

- 需要 **系统管理员** 账号。
- 前置：集群已接入平台。

## 进入方式

1. 左侧菜单点击 **智算平台** → **集群管理**，点进目标集群。
2. 左侧 **运维管理** 分组点击 **工作负载**。

页面默认落在 **容器组** 标签，顶部可切换 14 类资源。

## 支持的标签

容器组、节点、无状态服务、有状态服务、守护进程服务、任务、定时任务、服务、路由、Ingress 类、存储类、配置、密钥、存储卷。

## 能做什么

| 能力 | 说明 |
| --- | --- |
| 切换标签 | 在不同资源类型之间切换，查看对象列表 |
| 查看列表 | 按该类型的定义显示名称、命名空间、状态等列 |
| 查看详情 | 点对象名称进入详情，能看到基本信息、状态、事件和 YAML |
| 节点操作 | 在 **节点** 标签下，可对某台机器执行 **禁止调度 / 允许调度**，带确认框 |

:::tip 什么时候用这一页

- 想确认某个对象是不是创建成功了。
- 想知道某个服务、路由、存储卷在哪个命名空间。
- 想对某台机器临时禁止调度（比如准备维护）。

如果你关注的是容量、负载或性能，先去看 **集群信息**、**节点状态** 或 **加速卡信息** 更直接。

:::

## 结果确认

- 能在对应标签下找到目标对象，且状态符合预期。
- 在 **节点** 标签执行 **禁止调度** 后，该机器的状态会标记为不再接受新任务；**允许调度** 可恢复。
