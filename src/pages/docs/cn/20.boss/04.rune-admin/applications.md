# 应用

**应用**是一份提前配好的「装机清单」：把某个软件需要的东西打包成一个 Chart，用户（或平台自己）点一下就能按这份清单部署，不用从零配环境。

读完这页，你能完成：在列表里找到某个租户的应用、改它的可见性、给它设推荐、上传新版本，以及把某个版本标记为弃用。

:::tip 三个词对照

- **应用** ≈ 提前配好的「装机清单」，用户一键就能用。
- **版本** ≈ 同一份清单的不同修订版，比如 1.0、1.1。
- **可见性** ≈ 这份应用能被谁看到：个人、租户内还是公开。

:::

## 开始之前

- 你需要 **系统管理员** 账号。
- 上传版本前准备好 Chart 包：**`.tgz` 格式** 的压缩文件。
- 应用属于某个**租户**，列表里每一行都带租户；同一个应用名在不同租户下是两条记录。

## 进入方式

顶部导航点击 **智算平台**，再在左侧栏 **智算平台** 分组下点击 **应用**。

## 应用列表怎么看

| 列 | 说明 |
| --- | --- |
| 名称 | 应用名，点击进入该应用的**版本列表**；名称下方是应用标识 |
| 租户 | 这个应用属于哪个租户 |
| 最新公开版本 | 最新公开的应用版本，下方一行是 Chart 版本 |
| 分类 | 应用分类，例如推理、微调、开发、系统、存储 |
| 可见性 | 个人 / 租户内 / 公开 |
| 推荐指数 | 推荐评分；系统类应用不参与推荐 |
| 封面 | 应用封面图，没有封面时显示占位文案 |
| 创建时间 | — |

顶部筛选：

| 筛选项 | 说明 |
| --- | --- |
| 搜索 | 按应用名搜索 |
| 租户 | 只看某个租户下的应用 |
| 分类 | 按应用分类过滤 |
| 排序 | **最近更新** 或 **推荐排序** |

每行的操作：

| 操作 | 说明 |
| --- | --- |
| 推荐 | 配置推荐指数与推荐截图；**系统类应用没有这个操作** |
| 更改可见性 | 在个人 / 租户内 / 公开之间切换，选完确认 |
| 编辑 | 进入编辑页改名称、分类、描述、头像等 |
| 删除 | 带确认框，删除的是这个租户下的这条应用记录 |

右上角 **创建应用** 新建。

![应用列表：名称、租户、最新公开版本、分类、可见性、推荐指数、封面与创建时间](/assets/screenshots/boss/rune-products-01.png)

列表把同一批应用按**租户**摊开，所以第一眼看「租户」列能避免改错对象。**最新公开版本** 为空说明这个应用还没有公开版本，用户侧也就看不到可部署的版本。

## 新建一个应用

1. 点右上角 **创建应用**。
2. 填写表单：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 租户 | 选择归属租户 | 决定这个应用属于谁 |
   | Chart 名称 | 例如 `my-inference` | 应用包的唯一标识，**创建后不可修改** |
   | 名称 | 例如「我的推理引擎」 | 界面上展示的名字 |
   | 分类 | 例如推理、开发、系统、存储 | 决定它在哪个场景下被筛出来 |
   | 描述 | 可选 | 一句话说明用途 |

3. 点 **确定** 保存。

:::info 头像和封面在编辑时补充
新建表单只填基本信息；头像、截图、封面在创建完成后进入 **编辑** 页上传。
:::

## 上传并维护版本

1. 在列表点应用名称，进入这个应用的**版本列表**。
2. 点 **上传**，在弹窗里选择 Chart 文件（`.tgz`），确认后上传。
3. 上传成功后列表出现新版本，可以看到 **应用版本**、**Chart 版本**、**版本创建时间**。
4. 需要的版本可以继续做这些操作：

   | 操作 | 效果 |
   | --- | --- |
   | 弃用 | 标记该版本不再推荐使用，需要填写 **弃用原因**；应用市场和部署页会展示原因，但版本**仍可部署**，已有实例不受影响 |
   | 取消弃用 | 移除弃用警告并清空原因；可见性和已有实例不变 |
   | 删除版本 | 永久删除该版本记录，**无法恢复**，以后要用必须重新上传同一个 Chart 版本 |

:::warning 弃用不等于下架
弃用只是「不推荐」，用户仍能选到并部署。真要阻止使用，请删除该版本或调整应用的可见性。
:::

## 改可见性

1. 在列表点某一行的 **更改可见性**。
2. 选择 **个人**、**租户内** 或 **公开**。
3. 确认后立即生效。

| 可见性 | 谁能看到 |
| --- | --- |
| 个人 | 只有创建者本人、租户管理员及被授权的成员 |
| 租户内 | 该租户的所有成员 |
| 公开 | 所有能访问平台的用户 |

## 设推荐

1. 在列表点某一行的 **推荐**。
2. 设置推荐指数与推荐截图。
3. 保存后，列表 **推荐指数** 列会显示分值，排序切到 **推荐排序** 时按它排列。

## 结果确认

| 你想确认的事 | 去哪里看 |
| --- | --- |
| 应用建好了 | 列表里出现新记录，租户与分类正确 |
| 版本传上去了 | 进入该应用的版本列表，能看到新版本与 Chart 版本 |
| 用户能看到 | 把可见性调成 **公开**，再到用户侧的应用市场确认 |
| 推荐生效了 | 列表的 **推荐指数** 有分值，推荐排序下顺序变化 |

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 上传被拒 | 不是 `.tgz` 格式 | 重新打包成 `.tgz` 再上传 |
| 用户看不到应用 | 可见性是个人或租户内 | 改成 **公开** |
| 用户看不到某个版本 | 该版本不可用，或没有公开版本 | 检查版本状态，重新上传或调整 |
| 改不了 Chart 名称 | 创建后不可修改 | 如确需更换，新建一个应用 |
| 系统类应用没有「推荐」 | 设计如此，系统类应用不参与推荐 | 属正常现象 |
