# 存储集群与运行时

用户创建的推理服务、微调任务、开发环境都需要「存东西」：模型文件、数据集、中间结果。存储集群页就是管理这些存储能力的入口，它和系统应用一样，都是用模版部署出来的实例。

读完这页，你能完成：查看集群里已有的存储实例、部署一个新的存储集群、以及排查存储相关异常。

:::tip 两个词对照

- **存储集群** ≈ 集群里专门负责存文件的组件。
- **系统应用** ≈ 平台自带的中间件（监控、日志、网关等）。

:::

## 开始之前

- 你需要 **系统管理员** 账号。
- 前置：集群已接入平台；市场里需要有存储类的系统域模版。

## 进入方式

1. 左侧菜单点击 **智算平台** → **集群管理**，点进目标集群。
2. 左侧 **运维管理** 分组点击 **存储集群**。

## 存储集群列表

列表字段和系统应用一致：

| 列 | 说明 |
| --- | --- |
| 名称 | 实例名称，点击进入详情页 |
| 版本 | 部署所用的模版版本 |
| 状态 | 实例当前状态 |
| 创建时间 | — |

每行的操作：**编辑**、**删除**（带确认框）。

## 部署一个存储集群

1. 在实例列表点击右上角 **创建存储集群**。
2. 页面跳到 **系统模版市场**（存储类别）。
3. 选择存储类模版和版本，点击 **部署**。
4. 在部署页按模版要求填写参数。
5. 提交后回到列表，确认实例状态逐步变为运行中。

:::info 存储和系统应用是同一套列表

存储集群和系统应用共用同一个实例列表，只是按类别区分。所以操作方式、列、详情页都一样，只是进来的入口和模版类别不同。

:::

## 平台运行时组件

除了存储，集群里还要跑一些平台运行时组件（比如监控、日志、网关）。这些在 **系统应用** 页管理，部署来源同样是系统模版市场，详见 [系统应用](/boss/rune-admin/systems) 与 [系统模版市场](/boss/rune-admin/system-market)。

## 常见适用场景

- 初始化一个新集群的基础存储能力。
- 补装缺的公共运行时组件。
- 排查平台级存储实例运行异常。

## 结果确认

- 新实例在列表里出现，**状态** 最终变为运行中。
- 用户侧创建实例时能选到对应的存储能力。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 创建存储卷时没有可选项 | 集群没有可用的存储组件 | 到本页部署一个存储集群 |
| 存储实例异常 | 参数不对或节点资源不足 | 进详情看状态与事件后重试 |
