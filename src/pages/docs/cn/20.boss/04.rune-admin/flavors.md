## 功能简介

规格（Flavor）定义部署实例时可选的**计算资源组合**。管理员在集群维度创建与管理规格，规格随后被配额引用，最终以选项形式展示给用户。

> 💡 提示: 本页是**管理员视角**，可创建 / 编辑 / 启用 / 停用 / 删除规格。租户侧只能查看和选择被授权的规格。

## 进入路径

BOSS 控制台 → 集群管理 → 选择集群 → **资源规格**

前端路由：`/rune/clusters/:cluster/flavors`

## 规格列表

### 列字段

| 列 | 字段路径 | 展示 | 说明 |
| --- | --- | --- | --- |
| 名称 | `name` | 文本 + 描述 | 规格名称，下方显示描述 |
| 类型 | `type` | 资源类型标签 | 由 `QuotaResourceType` 渲染 |
| 型号 | `model` | 型号标签 | 由 `QuotaResourceModel` 渲染，结合 `vendor` |
| 规格 | `config` | 标签组 | `FlavorResources` 按资源项渲染标签 |
| 资源池 | `resourcePool` | 链接文本 | 后端返回池 ID，前端解析后显示 `名称 (ID)`；为空显示 `-` |
| 状态 | `enabled` | 标签 | 启用（`enabled = true`）/ 未启用 |

### 筛选

| 筛选项 | 来源 | 可选值 |
| --- | --- | --- |
| 状态 | 表格筛选栏 | 已启用（`available`）/ 未启用（`unavailable`） |
| 类型 | 规格筛选条 | 由接口返回的型号集合动态去重得到 |
| 厂商 | 规格筛选条 | 随所选类型动态变化 |
| 型号 | 规格筛选条 | 随所选类型 / 厂商动态变化 |

> 💡 提示: 规格筛选条还内置一份允许的类型白名单（`GPU`、`Accelerator`、`VGPU`、`FPGA`、`ASIC`、`NPU`、`DPU`、`TPU`、`CPU`、`MEMORY`），但实际展示的类型仍来自后端返回的数据，并非固定 6 类。

### 操作

| 操作 | 说明 |
| --- | --- |
| 启用 / 停用 | 切换 `enabled`，带确认弹窗 |
| 编辑 | 进入编辑页 |
| 删除 | 带确认弹窗删除；支持多选 |

## 创建 / 编辑规格

前端路由：

- 创建：`/rune/clusters/:cluster/flavors?action=create`
- 编辑：`/rune/clusters/:cluster/flavors/:flavor?action=edit`

### 表单字段

| 字段 | 字段名 | 必填 | 说明 |
| --- | --- | --- | --- |
| 名称 | `name` | — | 由系统根据资源配置与所选资源池自动生成并预览，表单不手填 |
| 资源配置 | `config[]` | ✅ | 至少一项，字段见下表 |
| 资源池 | `resourcePool` | — | **可选**，决定规格可调度到的节点范围 |
| 描述 | `description` | — | 文本域 |

### 资源配置项字段（`config[]`）

| 字段 | 说明 |
| --- | --- |
| `resourceName` | Kubernetes 资源名，如 `cpu`、`memory`、`nvidia.com/gpu` |
| `name` | 显示名 |
| `type` | 资源类型，如 `cpu`、`gpu`、`vgpu`、`storage` |
| `limit` | 限制值（Quantity），必填 |
| `request` | 请求值（Quantity），可选 |
| `model` / `vendor` | 型号 / 厂商 |
| `ratio` | 换算比例（Quantity） |
| `candidates` | 可选值（如 vNPU 模板） |
| `default` / `min` / `max` | 默认值 / 最小 / 最大分配单位（Quantity） |
| `nodeSelector` | 节点选择器标签键值对 |

表单校验：`limit` 需满足 `min ≤ limit ≤ max`；`nodeSelector` 的键与值必须成对填写。

### 可选资源项来源

可选的资源项来自接口 `listClusterFlavorResources`，并随所选资源池变化动态加载，因此**资源类型并非固定枚举**。

> 💡 提示: 创建时若资源池已选且资源项已加载，系统会为 CPU / 内存预填默认值：`cpu.limit = 2`、`memory.limit = 4Gi`。

## 启用 / 停用

| 操作 | 效果 |
| --- | --- |
| 启用 | 对已获配额的用户可见，可被选择 |
| 停用 | 从选择列表中隐藏；已使用该规格运行的实例不受影响 |

---

## 关于「售罄」

> ⚠️ 注意: 前端规格列表只呈现 `enabled` 标签，**没有「售罄」UI**。若后端契约中存在 `status.soldOut` 等字段，当前前端未呈现、未使用，文档不对其行为做确认。

---

## 关于「多级作用域」

> ⚠️ 注意: 前端**没有**集群 → 租户 → 工作空间的规格可见性配置界面。规格在租户 / 工作空间维度的可用性由配额分配决定，而非在规格页配置。

---

## 删除规格

点击 **删除**（带确认弹窗）。删除不会影响已运行实例，但无法再基于该规格新建实例。

> ⚠️ 注意: 删除前建议确认没有租户配额或工作空间配额引用该规格。

---

## 权限要求

需要 **系统管理员** 角色。可查看、创建、编辑、启用 / 停用与删除集群规格。
