# 资源规格

资源规格（Flavor）就是一张「套餐规格表」，用一句话说清一份计算资源是多少：比如「2 核 CPU + 4Gi 内存」或「8 核 CPU + 32Gi 内存 + 1 张 GPU」。管理员在集群维度定义这些套餐，用户创建实例时就在这些套餐里挑。

读完这页，你能完成：新建一条规格、看懂每个字段、启用或停用规格、以及删除不再用的规格。

:::tip 两个词对照

- **资源规格** ≈ 套餐规格表，写明「几核 CPU / 多少内存 / 几张卡」。
- **加速卡（GPU / NPU）** ≈ 服务器里专门算 AI 的「引擎」。

:::

## 开始之前

- 你需要 **系统管理员** 账号。这里是管理员视角，可新建 / 编辑 / 启用 / 停用 / 删除；租户侧只能查看和选择被授权的规格。
- 前置：集群已接入平台；如果想让规格只落在部分机器上，请先建好 [资源池](/boss/rune-admin/resource-pools)。

## 进入方式

1. 左侧菜单点击 **智算平台** → **集群管理**，点进目标集群。
2. 左侧 **资源管理** 分组点击 **资源规格**。

## 规格列表怎么看

| 列 | 说明 |
| --- | --- |
| 名称 | 规格名，下方小字是描述 |
| 类型 | 资源类型（如 CPU、GPU） |
| 型号 | 卡或设备的型号 |
| 规格 | 这份规格包含的资源项标签，例如 CPU、内存、卡的张数 |
| 资源池 | 绑定的资源池，显示为「名称 (ID)」；没绑定时显示 `-` |
| 状态 | 启用 / 未启用 |

顶部筛选：

- **状态**：启用 / 未启用。
- **类型 / 厂商 / 型号** 筛选条：选项来自当前集群已有的数据，会随选择联动。

每行的操作：

| 操作 | 说明 |
| --- | --- |
| 启用 / 停用 | 切换规格状态，会弹确认框 |
| 编辑 | 进入编辑页 |
| 删除 | 删除规格，会弹确认框；支持多选批量删除 |

## 新建一条规格

1. 在规格列表点击右上角 **创建规格**。
2. 页面顶部会实时显示一个 **自动生成的名称**，你不用手填名称。
3. 在 **资源配置** 里点击 **创建资源** 添加资源项（至少一项）：

| 字段 | 含义 | 怎么填 |
| --- | --- | --- |
| 分类 | 资源大类，如 CPU / 内存 / GPU | 按界面下拉选 |
| 资源 | 具体资源，如 CPU、内存 | 选好分类后再选 |
| 型号 | 卡或设备型号（涉及加速卡时才有） | 按需选，比如某型号 GPU / NPU |
| 限制 | 这份规格最多给多少，**必填** | 例如 CPU 填 `2`、内存填 `4Gi`、卡填 `1` |
| 请求 | 实际预留多少，可不填 | 不填时通常按限制处理 |
| 最小 / 最大 / 默认 | 允许的取值范围 | 限制值必须落在「最小 ≤ 限制 ≤ 最大」之间 |
| 换算比例 | 不同单位之间的换算系数 | 涉及共享卡等场景时使用 |
| 节点标签 | 限定只能落到带某个标签的机器上 | Key 和 Value 必须成对填写，只填一个会报错 |

4. 选择 **资源池**（可选）：选了以后这份规格只会落到这个池里的机器；不选则范围更广。
5. 填写 **描述**（可选）。
6. 点击 **确定** 保存。

:::tip 新建时会帮你预填默认值

如果已经选了资源池、资源项也加载出来了，平台会替 CPU 预填 `2`、内存预填 `4Gi`，你可以按需改。

:::

:::info 类型不是固定几类

可选的资源类型和型号来自当前集群的实际能力，所以不同集群看到的类型可能不同，不必担心没有某一类。

:::

## 编辑一条规格

1. 在列表点击某行的 **编辑**。
2. 编辑页里 **名称** 可改，同时可调整资源配置、资源池和描述。
3. 点击 **确定** 保存。

## 启用 / 停用规格

| 操作 | 效果 |
| --- | --- |
| 启用 | 对已获配额的用户可见，可以被选择 |
| 停用 | 从可选列表里隐藏；**已经用这份规格跑起来的实例不受影响** |

## 规格怎么「下发」给租户

规格页本身不直接选择租户，规则是：

1. 规格先 **启用**，才会进入可选范围。
2. 具体某个租户能用哪些规格，由该租户拿到的 **配额** 决定；配额在 [租户配额](/boss/rune-admin/tenants) 里按「集群 + 资源池 + 资源项」分配。

也就是说：**启用规格 + 给租户发配额**，两者都做到了，租户才能在创建实例时选到。

## 删除规格

点击 **删除** 并确认。删除后仍可继续运行用这份规格起的历史实例，但**无法再基于它新建实例**。

:::warning 删除前先确认没人引用

删除前请确认没有租户配额或工作空间配额还在引用这份规格，否则可能影响后续分配。

:::

## 结果确认

- 新建后列表里出现这条规格，名称为自动生成的名字。
- 启用后 **状态** 显示为启用；在对应的租户配额与实例创建页里，能看到这份规格可选。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 保存报错「限制必须不小于最小值 / 不大于最大值」 | 限制值超出范围 | 调整限制，或改最小 / 最大 |
| 节点标签报错 | Key / Value 只填了一个 | 两者成对填写，或都留空 |
| 可选资源类型很少 | 该集群实际能力如此 | 属正常现象，按实际选 |
| 租户看不到规格 | 规格未启用，或该租户没有对应配额 | 先启用规格，再检查配额 |
