# 资源规格

资源规格就是一张「套餐规格表」，用一句话说清一份计算资源是多少：比如「2 核 CPU + 4Gi 内存」或「8 核 CPU + 32Gi 内存 + 1 张 GPU」。管理员在集群维度定义这些套餐，用户创建实例时就在这些套餐里挑。

读完这页，你能完成：看懂规格列表的四个关键信息、新建一条规格、启用或停用、决定它是全局可用还是需要租户授权。

:::tip 两个词对照

- **资源规格** ≈ 套餐规格表，写明「几核 CPU / 多少内存 / 几张卡」。
- **配额** ≈ 这个租户总共能用多少，和套餐不是一回事，见[租户资源](/boss/rune-admin/tenants)。

:::

## 开始之前

- 你需要 **系统管理员** 账号。这里是管理员视角，可新建 / 编辑 / 启用 / 停用 / 删除；租户侧只能查看和选择被授权的规格。
- 前置：集群已接入平台；想让规格只落在部分机器上，请先建好 [资源池](/boss/rune-admin/resource-pools)。

## 进入方式

1. 顶部导航点击 **智算平台**，再在左侧栏 **智算平台** 分组下点击 **集群管理**，点进目标集群。
2. 左侧 **资源管理** 分组点击 **资源规格**。

## 规格列表怎么看

| 列 | 说明 |
| --- | --- |
| 名称 | 规格名（后面带资源类型标签），下方小字是描述 |
| 资源配置 | 这份规格包含的资源项标签，例如 CPU、内存、卡的张数 |
| 资源池 | 绑定的资源池，显示为「名称 (ID)」；没绑定时显示 `-` |
| 可用性 | 两个标签：**启用 / 未启用**，以及 **全局可用 / 需租户授权** |

顶部是一条筛选带，不是多组按钮：

| 筛选项 | 说明 |
| --- | --- |
| 类型 | 资源类型，例如 CPU、GPU、共享GPU |
| 厂商 | 例如英伟达、昇腾、AMD、Intel |
| 型号 | 例如 RTX 3080、A100 |
| 状态 | 启用 / 未启用 |
| 搜索 | 按规格名搜索 |

筛选条件叠加生效，例如「GPU + 英伟达 + A100」就能收出这一类规格。

## 新建一条规格

1. 在列表点击右上角 **创建规格**。
2. **资源配置** 卡片顶部有一个名称预览框，会随资源配置和资源池自动生成名称，最后也可以手动改。
3. 点击 **创建资源** 添加资源项（至少一项）：

   | 字段 | 含义 | 怎么填 |
   | --- | --- | --- |
   | 分类 | 资源大类，如 CPU / 内存 / GPU | 按下拉选 |
   | 资源 | 具体资源 | 选好分类后再选 |
   | 型号 | 卡或设备型号 | 可不选；不选表示「所有型号」 |
   | 限制 | 这份规格最多给多少，**必填** | 例如 CPU 填 `2`、内存填 `4Gi`、卡填 `1` |
   | 节点标签 | 限定只能落到带某个标签的机器上 | 加速卡项才有；键和值必须成对填写 |

4. 选择 **资源池**（可选）：选了以后这份规格只会落到这个池里的机器。
5. 在 **使用范围** 里决定 **全局可用**：

   | 开关 | 效果 |
   | --- | --- |
   | 打开 | 所有租户**无需单独授权**即可选择这份规格 |
   | 关闭 | 只有已被授权的租户才能选择（需租户授权） |

6. 填 **描述**（可选），点 **确定** 保存。

:::info 全局可用需要规格处于启用状态
「全局可用」只在规格**启用**时才有意义：未启用的规格即使标了全局可用，也不会出现在可选列表里。
:::

:::info 可选资源类型来自集群实际能力
资源类型和型号由当前集群上报的能力决定，所以不同集群看到的类型可能不同。
:::

## 编辑一条规格

1. 在列表点某行的编辑入口。
2. 名称会随资源配置与资源池重新生成，也可以手动改；能调整的是资源配置、资源池、使用范围、描述。
3. 点 **确定** 保存。

## 启用 / 禁用规格

| 操作 | 效果 |
| --- | --- |
| 启用 | 进入可选范围，可被全局使用或被授权租户选择 |
| 禁用 | 从可选列表里隐藏；**已经用这份规格跑起来的实例不受影响** |

操作会弹确认框，例如「确定禁用该规格？」。

## 规格怎么下发给租户

规格页本身不直接选租户，规则是：

1. 规格先 **启用**，才会进入可选范围。
2. **全局可用** 打开时，所有租户都能选；关闭时，需要在集群的 [租户资源 → 规格授权](/boss/rune-admin/tenants) 里给具体租户开通。
3. 租户还要有对应的 **配额**，才能真正创建实例。

也就是说：**启用规格 + 全局可用或租户授权 + 有配额**，三者齐了才选得到。

## 删除规格

删除前会弹确认框。删除后，用这份规格起的历史实例仍可继续运行，但**无法再基于它新建实例**。

:::warning 删除前先确认没有引用
删除前请确认没有租户配额或工作空间配额还在引用这份规格，否则可能影响后续分配。
:::

## 结果确认

- 新建后列表里出现这条规格，名称符合预期。
- **可用性** 列显示 **启用**，并按需要显示 **全局可用** 或 **需租户授权**。
- 租户侧创建实例时能看到这份规格（前提是有配额且已授权）。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 保存报错「低于最小值限制」或「超出最大值限制」 | 填的限制超出了这个资源型号允许的范围 | 按提示把限制调进范围，或换一个型号 |
| 节点标签报错 | 键 / 值只填了一个 | 两者成对填写，或都留空 |
| 租户看不到规格 | 规格未启用、不是全局可用且未授权、或没有配额 | 依次检查这三项 |
| 「全局可用」开了但没人能选 | 规格本身未启用 | 先启用规格 |
| 可选资源类型很少 | 该集群实际能力如此 | 属正常现象 |
