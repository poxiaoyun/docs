# 资源池

资源池（Resource Pool）就是把集群这台「机房大楼」里的机器，按用途划成几个「功能区」：比如一个池给推理业务、一个池给训练任务、一个池留给平台自己用。同一台机器**同一时间只能属于一个资源池**；没有明确划走的机器，都归在系统保留的 **默认** 池里。

读完这页，你能完成：新建一个资源池、把机器划进池里、改池的名字、以及把池里的机器归还后删除这个池。

:::tip 三个词对照

- **集群** ≈ 一栋机房大楼。
- **节点** ≈ 大楼里的一台服务器。
- **资源池** ≈ 把大楼里的机器划成几个「功能区」，不同部门分着用。

:::

## 开始之前

- 你需要 **系统管理员** 账号。
- 前置：集群已接入平台，并且资源池完成初始化（初始化没完成前，**创建资源池** 按钮会被禁用并提示）。
- 一个集群最多 **10 个**资源池；到上限后按钮同样会被禁用。

## 进入方式

1. 左侧菜单点击 **智算平台** → **集群管理**，点进目标集群。
2. 左侧 **资源管理** 分组点击 **资源池**。

## 页面长什么样

页面是「左边列表 + 右边详情」的两栏结构：

| 区域 | 内容 |
| --- | --- |
| 左栏 | 资源池卡片列表，顶部显示「已用数量 / 上限 10」，可搜索显示名称或唯一 ID |
| 右栏 | 选中资源池的容量快照、加速卡视图、最近 1 小时趋势和操作按钮 |

右栏顶部有三个状态标签，帮你判断这个池是否正常：

| 标签 | 含义 |
| --- | --- |
| 同步 | 机器归属是否已经同步成功 |
| 节点健康 | 池里机器是否 Ready、是否有压力 |
| 监控 | 监控数据是否采集完整 |

右栏的 **资源容量视角** 可以切换：

- **加速卡视角**：按物理卡 / 虚拟卡看每一组的容量。
- **主机视角**：按机器看每张卡的明细（利用率、显存、功耗、温度等）。

:::info 页面会自动刷新

正常情况下每 30 秒自动刷新一次；如果集群正在初始化资源池，会改成每 2 秒刷新一次，初始化失败则停止刷新并给出提示。

:::

## 创建资源池

1. 在资源池页面点击右上角 **创建资源池**。
2. 填写 **资源池信息**：

| 表单项 | 怎么填 | 说明 |
| --- | --- | --- |
| 名称 | 例如 `pool-inference` | 1–128 个字符，去空格后不能为空；这是显示名 |
| 唯一 ID | 自动生成 | 输入名称后自动生成，创建后不可修改 |
| 描述 | 例如「推理业务专用」 | 可选，≤ 500 个字符 |

3. 在 **初始节点（可选）** 里勾选要一开始就划进来的机器：

   - 只能选 **当前属于默认池** 的机器；已经属于其他池的机器会置灰，需要先归还默认池。
   - 支持按名称搜索、**选择当前页**，每页可选 20 / 50 / 100。

4. 点击 **检查并创建**，系统会先做一次变更检查。
5. 弹出 **确认创建资源池** 对话框后：

   - 查看检查结论：通过 / 需确认 / 被阻断 / 没有实际变更。
   - 核对 **初始节点列表**（序号、节点名称、加速卡）。
   - 逐条勾选需要确认的风险项。
   - 点击 **创建资源池** 提交；想改就点 **返回编辑**。

提交后出现「资源池创建请求已提交，将在后台执行」的提示，页面会跳回列表。

:::warning 创建时机器只能来自默认池

如果某台机器已经属于别的资源池，在创建页里选不了。请先到那个池里把机器划回默认池。

:::

## 编辑资源池（改名字和描述）

1. 在右栏点击 **编辑信息**。
2. 修改 **名称**（1–128 字符）或 **描述**（≤ 500 字符）。
3. 点击 **保存信息**，看到「资源池信息已更新」即成功。

:::tip 机器不在这里增减

编辑页只改名字和描述。要把机器划进 / 划出这个池，用下面的 **调整节点划分**。

:::

## 调整机器划分

1. 在右栏点击 **调整节点划分**，打开 **节点划分工作台**。
2. **1. 选择节点**：勾选要迁移的机器，可搜索、**选择当前页**，每页 20 / 50 / 100。
3. **2. 选择单一目标**：在 **目标资源池** 里选一个目标池（一次只能选一个，所有选中的机器都进这个池）。
4. 点击 **检查变更**，右侧会显示「将更新期望归属」「无需变化，自动跳过」的数量和阻断原因。
5. 勾选需要确认的风险项后，点击 **提交节点划分**。

提交后出现「节点划分已提交，将在后台执行」的提示。

:::warning 改动选择后要重新检查

只要你重新勾选机器、切换目标池、翻页或改搜索，上一次的检查结果就作废了，必须重新点 **检查变更** 才能提交。

:::

## 把机器归还并删除资源池

1. 在右栏点击 **归还节点并删除**（**默认池没有这个按钮**）。
2. 对话框会自动检查能否删除：
   - 如果这个池正被 **资源规格** 或 **配额** 引用，删除会被阻断，对话框会列出每一条引用并给出 **去处理** 入口。
   - 没有阻断时，按提示输入这个资源池的 **唯一 ID** 做二次确认。
3. 勾选风险确认项，点击 **归还节点并删除**。

:::warning 删除不可逆

删除资源池后，里面的机器会回到 **默认** 池，操作在后台完成。请先确认没有业务还在依赖这个池。

:::

## 资源和租户是怎么关联的

资源池本身不会直接发给某个租户，它通过两步和租户、工作空间挂上关系：

1. **资源规格（Flavor）** 可以绑定到某个资源池，决定这份规格能调度到哪些机器，见 [资源规格](/boss/rune-admin/flavors)。
2. **配额** 在「集群 + 资源池 + 资源项」这一层把额度发给租户，工作空间配额再把租户配额往下细分，见 [租户配额](/boss/rune-admin/tenants)。

所以：**删资源池之前，先确认没有规格或配额还引用它**，否则会被安全阻断。

## 默认资源池

- 系统保留一个 ID 固定为 `default` 的默认池，**不能删除**。
- 默认池置顶显示，且不显示同步与监控状态。
- 创建资源池选机器时，只能选当前属于默认池的机器。
- 删除其他资源池后，里面的机器会回到默认池。

## 结果确认

- 列表左上角的数量从「n / 10」变成「n+1 / 10」，左栏出现新卡片。
- 点进新池，右栏 **容量快照** 里的期望成员数、可分配 CPU / 内存有数值。
- 划入机器后，机器的 **同步** 状态最终变为已同步。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| **创建资源池** 点不动 | 已达 10 个上限，或资源池还没初始化完 | 删掉不用的池，或等初始化完成 |
| 选不了某台机器 | 它已属于别的池 | 先把该机器划回默认池 |
| 提交按钮是灰的 | 检查未通过 / 没有实际变更 / 风险项没勾完 | 重新 **检查变更** 并勾选风险项 |
| 删除被拦住 | 仍被规格或配额引用 | 按提示去处理对应引用后再删 |
