# 告警

集群告警解决「出问题要有人知道」：按模板给集群里的指标配规则，达到阈值并持续一段时间就发通知，同时留下历史记录。

读完这页，你能完成：添加一条告警规则、选对严重等级与通知渠道、暂停或恢复规则，以及在告警历史里查和清理记录。

:::tip 告警的四个零件

- **模板** ≈ 一个预设的检查项（例如节点 CPU 使用率），决定了要填哪些参数。
- **规则** ≈ 把模板落到这个集群上：填阈值、定持续多久算异常。
- **通知渠道** ≈ 消息往哪发，来自顶部 **告警渠道**。
- **告警历史** ≈ 每次触发与恢复的记录。

:::

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 告警模板 | 平台预设的检查项，一个模板只能配一条规则 |
| 规则名称 | 这条规则的名字，字母、数字、`-`、`_`、`.`，最长 63 个字符 |
| 严重等级 | 严重 / 警告 / 提示，用来区分优先级 |
| 持续时间 | 条件满足多久才真正告警，避免抖动误报 |
| 通知间隔 | 同一告警持续触发时，最多每隔多久通知一次；留空用系统默认 |
| 通知渠道 | 规则触发后往哪里发，可多选；不选则用内置 **站内信（内置）** |
| 告警历史 | 每次状态变化的记录：告警中、待确认、未触发、已暂停、已恢复、未知、错误 |

## 开始之前

- 需要 **系统管理员** 账号。
- 想发到飞书或邮件，先在顶部 **告警渠道** 里配好渠道，见[告警渠道](/boss/settings/alert-channels)。
- 集群已接入平台，并且已部署监控采集组件，否则模板拿不到数据。

## 进入方式

1. 顶部导航点击 **智算平台**，再在左侧栏 **智算平台** 分组下点击 **集群管理**。
2. 点进目标集群。
3. 左侧 **运维管理** 分组下点击 **告警**。

## 规则列表怎么看

| 列 | 说明 |
| --- | --- |
| 规则名称 | 规则的显示名，可排序 |
| 告警模板 | 上面一行是模板说明，下面带模板名 |
| 持续时间 | 按级别列出，例如「严重: 5m, 警告: 10m」 |
| 通知间隔 | 未设置时显示 `-` |
| 通知渠道 | 渠道名标签；为空时显示 **站内信（内置）** |
| 状态 | **已启用** 或 **已暂停** |

每行的操作：

| 操作 | 说明 |
| --- | --- |
| 暂停告警 / 恢复告警 | 切换规则的启用状态，立即生效 |
| 编辑告警规则 | 打开规则弹窗修改参数与渠道 |
| 删除 | 带确认框；删除后该模板可以重新创建规则 |

## 添加告警规则

1. 点右上角 **添加告警规则**。
2. 选择 **告警模板**。**已经配过规则的模板不会出现在下拉里**——一个模板只允许一条规则。
3. 填写 **规则名称**（字母、数字、`-`、`_`、`.`，最长 63 个字符）。
4. 按模板要求填写 **参数**，例如阈值、警告阈值、严重阈值。
5. 勾选 **严重等级**，并为每个等级设置 **持续时间**（例如 30s、5m、1h）。
6. 选择 **通知渠道**（可多选；不选则用内置站内信）。
7. 按需填写 **通知间隔**，例如 `10m`；留空使用系统默认。
8. 保存。

:::warning 模板用完了怎么办
每个模板只能有一条规则。想用同一个模板再配一条（例如不同阈值），只能先删除已有规则，再新建。删除规则**不会**删除已有的告警历史。
:::

## 告警历史

页面下方的 **告警历史** 记录每次触发与恢复：

| 列 | 说明 |
| --- | --- |
| 状态 | 告警中 / 待确认 / 未触发 / 已暂停 / 已恢复 / 未知 / 错误 |
| 级别 | 严重 / 警告 / 提示 |
| 发生时间 | 这次状态变化的时间 |
| 触发次数 | 累计触发了几次 |

可以单条删除，也可以勾选多条批量删除。

:::info 历史是「发生过什么」，不是当前状态
规则暂停后，历史里仍然能看到之前的记录。判断现在是否告警，看规则列表的 **状态** 和历史的最近一条。
:::

## 结果确认

| 你想确认的事 | 去哪里看 |
| --- | --- |
| 规则建好了 | 规则列表出现新行，状态 **已启用** |
| 通知渠道对吗 | 规则行的 **通知渠道** 列 |
| 消息真的能收到 | 先在 **告警渠道** 里点 **测试渠道**；规则触发后在飞书群或邮箱确认 |
| 有没有真的告警过 | 下方 **告警历史** 的最近记录 |

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 下拉里找不到想要的模板 | 该模板已经配过规则 | 找到已有规则编辑它，或先删除再新建 |
| 规则名称保存报错 | 用了中文或超长 | 只用字母、数字、`-`、`_`、`.`，且不超过 63 个字符 |
| 规则一直在但从不告警 | 持续时间设得太长，或阈值太高 | 调短持续时间、调低阈值 |
| 收不到通知 | 没选渠道且没人看站内信，或渠道配置错 | 选渠道，并在 **告警渠道** 里测试 |
| 删除规则后模板还不在下拉里 | 页面未刷新 | 刷新后重试 |
