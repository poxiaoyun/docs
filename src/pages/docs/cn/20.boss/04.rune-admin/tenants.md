# 租户资源

**租户资源**是「集群视角的租户管理」：这个集群上开通了哪些租户、谁提交了开通申请、每个租户能用多少算力、能用哪些资源规格、有哪些工作空间。

读完这页，你能完成：审核开通申请、进入某个租户、创建配额、给租户开规格授权、创建工作空间。

:::tip 和「租户集群」的区别

- **智算平台 → 租户集群**：从租户出发，看它开通了哪些集群。
- **集群详情 → 租户资源**：从集群出发，看这个集群上有哪些租户。

两边是同一份「开通关系」的两个视角。

:::

## 开始之前

- 需要 **系统管理员** 账号。
- 前置：租户已在这个集群开通（未开通的租户不会出现在 **已开通** 页签）；需要先有 [资源池](/boss/rune-admin/resource-pools)，配额要选池。

## 进入方式

1. 顶部导航点击 **智算平台**，再在左侧栏 **智算平台** 分组下点击 **集群管理**。
2. 点进目标集群。
3. 左侧 **资源管理** 分组下点击 **租户资源**。

## 两个页签

| 页签 | 内容 |
| --- | --- |
| 已开通 | 已在这个集群开通的租户列表 |
| 开通申请 | 租户提交的开通申请与审核记录 |

### 已开通

| 列 | 说明 |
| --- | --- |
| 租户 | 租户名与 ID，点击进入该租户的集群内详情 |
| 开通状态 | 未开通 / 开通中 / 已开通 / 开通失败 |
| 创建时间 | 这条开通记录的时间 |

每行的操作有 **配置**（进入租户详情）与删除开通关系。

### 开通申请

| 列 | 说明 |
| --- | --- |
| 租户 | 提交申请的租户 |
| 申请说明 | 租户填写的用途或理由 |
| 审核状态 | 待审核 / 已通过 / 已拒绝 |
| 审核意见 | 审核时填写的原因 |
| 创建时间 | — |

行操作：

| 操作 | 说明 |
| --- | --- |
| 通过 | 打开「租户 xxx 的开通申请」，点 **同意并开通** 后系统开始配置集群资源 |
| 拒绝 | 需填写拒绝原因；拒绝后该申请不再进入开通流程，租户可调整申请说明后重新提交 |
| 删除开通申请 | 删除申请及审核记录，**不会**关闭或删除已经存在的开通关系 |

:::warning 删除申请不等于关闭租户
删除开通申请只清掉这条申请记录。要停止租户使用这个集群，请处理「已开通」里的开通关系。
:::

## 租户详情：四个页签

点开一个已开通的租户，页面有四个页签：

| 页签 | 用途 |
| --- | --- |
| 概览 | 名称、ID、开通状态、开通时间、描述、状态信息 |
| 配额 | 给这个租户分配资源额度 |
| 规格授权 | 这个租户在这个集群能用的资源规格 |
| 工作空间 | 这个租户下的工作空间及其配额 |

![租户资源：左侧是租户列表，右侧是租户的概览 / 配额 / 规格授权 / 工作空间四个页签](/assets/screenshots/boss/rune-tenant-quota-01.png)

## 分配配额

1. 进入租户详情，点 **配额** 页签。
2. 点右上角 **创建配额**。
3. 在表单里填写：

   | 表单项 | 怎么填 | 说明 |
   | --- | --- | --- |
   | 资源池 | 选择从哪个池里划额度 | 切换资源池会重新加载可选资源项 |
   | 资源 | 逐项填写上限与保障值 | 每项资源可填 **限制**（最多能用多少）和 **保障值**（至少保障多少），至少要加一项 |

4. 点 **确定** 保存。

配额列表里每条记录可以 **编辑** 或 **删除**，也可以按 **类型 / 厂商 / 型号** 筛选。

:::tip 配额不是挑一条规格
配额是「资源池 + 逐项资源上限」，和 [资源规格](/boss/rune-admin/flavors) 不是一回事：规格决定「一台实例长什么样」，配额决定「这个租户总共能用多少」。
:::

## 规格授权

**规格授权** 页签列出这个租户在本集群可用的资源规格：

| 列 | 说明 |
| --- | --- |
| 规格 | 资源规格名称与资源配置 |
| 资源池 | 该规格所在的资源池 |
| 状态 | 是否已授权 |

只有 **全局可用** 的规格才能被租户直接用；需要租户授权的规格，必须在这里给该租户开通，否则他在创建实例时选不到。见[资源规格](/boss/rune-admin/flavors)。

## 工作空间

1. 点 **工作空间** 页签。
2. 点右上角 **创建工作空间**，填写名称、集群（固定为当前集群）、描述。
3. 保存后，工作空间列表里可以继续 **配额**、**编辑**、**删除**。

工作空间配额把租户的总配额再往下细分，进入某个工作空间后在其 **配额** 页配置。

## 结果确认

| 你想确认的事 | 去哪里看 |
| --- | --- |
| 申请处理完了 | **开通申请** 页签的审核状态变成已通过 / 已拒绝 |
| 租户真的开通了 | **已开通** 页签里该租户状态为 **已开通** |
| 配额生效了 | 租户详情 **配额** 页签出现记录；用户侧创建实例时能用到额度 |
| 规格能选了 | 租户详情 **规格授权** 里出现该规格，用户侧能选到 |

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 资源池下拉是空的 | 这个集群还没有资源池 | 先建 [资源池](/boss/rune-admin/resource-pools) |
| 租户不在「已开通」里 | 还没开通，或开通失败 | 看 **开通申请**，或到 **租户集群** 里点 **在此集群开通** |
| 用户创建实例时选不到规格 | 规格是「需租户授权」，但没给这个租户开 | 在 **规格授权** 里开通 |
| 通过申请后状态一直是开通中 | 集群资源准备中，或配置失败 | 等一会儿刷新；仍失败看状态信息里的消息 |
| 配额保存报错 | 超出资源池可用量，或没加任何资源项 | 降低上限，或至少保留一项资源 |
