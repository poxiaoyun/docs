## 功能简介

Rune 租户资源管理在标准租户信息基础上扩展了**集群资源配额**与**工作空间**管理，用于管控每个租户在各集群中的资源分配。

与 [IAM 租户管理](/boss/iam/tenants) 不同，本页聚焦**计算资源层面**。

## 进入路径

BOSS 控制台 → 租户资源

前端路由：`/rune/tenants`

---

## 租户列表

| 列 | 字段路径 | 说明 |
| --- | --- | --- |
| 名称 | `name` | 头像 + 名称 + 租户 ID，点击进入租户详情（默认落到「配额」） |
| 配额 | `quota` | `TenantQuota` 组件（宽度 600px），按集群展示各资源类型的配额使用情况 |
| 创建时间 | `creationTimestamp` | 租户创建时间 |

> ⚠️ 注意: 列表**只有这三列**，没有「成员数」列，也**没有操作列**。所有详情操作都从点击租户名称进入。

---

## 租户详情子页

侧边栏实际只有 **2 个子页**：

| 子页 | 前端路由 |
| --- | --- |
| 配额 | `/rune/tenants/:tenant/quotas` |
| 工作空间 | `/rune/tenants/:tenant/workspaces` |

> ⚠️ 注意: 代码中「概览（Overview）」与「算力规格（Flavor）」导航项**已被注释停用**，当前不呈现。

## 配额管理

### 筛选

- **集群选择**：切换目标集群（工具栏左侧）。
- **配额筛选条**：按类型 / 厂商 / 型号筛选（选项来自租户配额 selector）。

### 列表字段

| 列 | 字段路径 | 说明 |
| --- | --- | --- |
| 类型 | `type` | 资源类型 |
| 型号 | `model` | 型号（结合 `vendor`） |
| 资源池 | `resourcePool` | 关联资源池 |
| 配额 | `quota` | 配额用量组件 |

操作：创建（右上角）、编辑、删除。

### 创建 / 编辑配额

| 字段 | 字段名 | 说明 |
| --- | --- | --- |
| 集群 | `cluster` | 创建时选择目标集群 |
| 资源池 | `resourcePool` | 切换集群会清空资源池 |
| 资源配置 | `config[]` | 资源项数组，字段与规格一致：`resourceName` / `name` / `type` / `limit` / `request` 等 |

> ⚠️ 注意: 配额表单**不选 Flavor**，而是选择集群 + 资源池 + 逐项资源配置。可选资源项由 `listClusterQuotaResources(集群, 租户, 资源池)` 动态返回。

> 💡 提示: 创建时 CPU / 内存的默认值取自资源项自身的 `default`（其次 `min`），回落值为 `2` 与 `4Gi`。

## 工作空间管理

### 列表字段

| 列 | 字段路径 | 说明 |
| --- | --- | --- |
| 名称 | `name` | 名称 + 描述同列 |
| 命名空间 | `namespace` | Kubernetes Namespace，为空显示 `-` |
| 状态 | `status` | 状态组件 |
| 创建时间 | `creationTimestamp` | — |

操作：配额（跳转工作空间配额）、编辑、删除；工具栏左侧可按集群筛选。

### 创建 / 编辑工作空间

| 字段 | 字段名 | 必填 | 说明 |
| --- | --- | --- | --- |
| 名称 | `name` | ✅ | 工作空间名称（ID 自动生成，可手动调整） |
| 集群 | `cluster` | ✅ | 选择所属集群；编辑时禁用（带锁标识） |
| 描述 | `description` | — | 文本域 |

> 💡 提示: 工作空间详情（前端 `/rune/tenants/:tenant/clusters/:cluster/workspaces/:workspace`）下还有**工作空间配额**与**成员**子页，用于把租户配额细分到工作空间。

---

## 权限要求

需要 **系统管理员** 角色。可查看所有租户的资源分配，并进行配额与工作空间的管理操作。
