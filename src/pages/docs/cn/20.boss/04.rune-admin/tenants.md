# 租户配额

租户（可以理解成一家公司的独立账号空间）要用平台的算力，就得先被分配「额度」。这一页就是发额度的地方：按「集群 + 资源池 + 资源项」把 CPU、内存、加速卡的用量上限发给租户，再把租户的额度往下细分到工作空间。

读完这页，你能完成：给某个租户分配资源配额、创建工作空间、并把配额细分到工作空间。

:::tip 三个词对照

- **租户** ≈ 一家公司的独立账号空间。
- **工作空间** ≈ 大楼里的一间办公室，同事之间共享。
- **配额** ≈ 这个月你能花的额度上限。

:::

## 开始之前

- 你需要 **系统管理员** 账号。
- 前置：集群已接入平台，并且已经建好 [资源池](/boss/rune-admin/resource-pools)（配额要选资源池）。

## 进入方式

顶部导航点击 **智算平台**，再在左侧栏 **智算平台** 分组下点击 **租户资源**。

## 租户列表

| 列 | 说明 |
| --- | --- |
| 名称 | 头像 + 租户名称 + 租户 ID；点击进入详情，默认停在 **配额** |
| 配额 | 按集群展示这个租户各资源类型的配额用量 |
| 创建时间 | 租户创建时间 |

:::info 列表没有操作列

所有操作都要点租户名称进详情后再做；列表本身只有上面三列。

:::

![租户资源列表：每个租户一行，配额列用进度条显示 CPU / 内存 / GPU / 存储的已用与总量](/assets/screenshots/boss/rune-tenant-list-01.png)

**租户资源** 和 **租户管理** 看的是同一批租户，但重点不同：这里每行都直接摊开四类配额的进度条。截图里 `chart-test` 的 CPU 用了 `18core / 20core`（90%），进度条已经变黄——这类租户就该去看看是不是要扩配额了。

## 租户详情里的两个子页

进入某个租户后，左侧有两个子页：

| 子页 | 用途 |
| --- | --- |
| 配额 | 给这个租户分配资源额度 |
| 工作空间 | 管理这个租户下的工作空间 |

## 给租户分配配额

1. 在租户详情左侧点击 **配额**。
2. 在工具栏左侧选择 **集群**（切换集群后，配额列表跟着变）。
3. 点击右上角 **创建配额**。
4. 在表单里填写：

| 表单项 | 怎么填 | 说明 |
| --- | --- | --- |
| 集群 | 选择要把资源发在哪个集群 | 创建时选择 |
| 资源池 | 选择从这个池里划额度 | **切换集群会清空这里，需要重新选** |
| 资源 | 逐项填写各类资源的额度 | 按类型逐项填限制值，至少要加一项 |

5. 点击 **确定** 保存。

:::tip 这里不选「规格」

配额不是挑一条现成的规格，而是选择「集群 + 资源池 + 逐项资源」。可选的资源项由平台按当前集群和资源池动态给出，CPU / 内存会带默认值，你可以直接改。

:::

配额列表里每一行可以 **编辑** 或 **删除**；列表上方还能按 **类型 / 厂商 / 型号** 筛选，方便定位。

![租户配额页：顶部用「集群」下拉切换集群，表格按配额类型 / 型号 / 资源池列出已用与总量](/assets/screenshots/boss/rune-tenant-quota-01.png)

配额是按**集群**分别算的，所以这一页顶部有个 **集群** 下拉（截图里是 Beijing A）；换集群就是换一份配额表。左侧还有 **类型** 筛选（CPU / 内存 / 磁盘）。表格里的 **配额** 列会显示成 `0 / 3` 这样的已用 / 总量形式。

## 创建工作空间

1. 在租户详情左侧点击 **工作空间**。
2. 点击右上角 **创建工作空间**。
3. 填写表单：

| 表单项 | 怎么填 | 说明 |
| --- | --- | --- |
| 名称 | 例如「算法一组」 | 必填；下面的 ID 自动生成，可手动调整 |
| 集群 | 选择所属集群 | 必填；**编辑时不可修改**（会显示锁标识） |
| 描述 | 可选 | 一句话说明用途 |

4. 点击 **确定** 保存。

工作空间列表里每一行可以：

| 操作 | 说明 |
| --- | --- |
| 配额 | 跳转到这个工作空间的配额页 |
| 编辑 | 修改名称或描述（集群不可改） |
| 删除 | 删除工作空间，带确认框 |

列表上方左侧可按 **集群** 筛选。

![租户下的工作空间列表：集群、名称、命名空间、状态、创建时间](/assets/screenshots/boss/rune-tenant-workspace-01.png)

工作空间列表同样有 **集群** 下拉（工作空间本来就从属于某个集群），列出该租户在这个集群下的所有空间。**命名空间** 一列是它对应的 Kubernetes namespace（截图里是 `dev`），**状态** 显示 `Ready` 才算可用。

## 把配额细分到工作空间

租户拿到总配额后，通常还要把额度分给下面各个工作空间：

1. 在 **工作空间** 列表找到目标工作空间，点 **配额**。
2. 进入工作空间详情，这里有 **配额** 和 **成员** 两个子页。
3. 在 **配额** 页按同样的方式创建工作空间配额，把租户的额度分下去。

## 结果确认

- 租户列表的 **配额** 列能看到各集群的额度用量。
- 租户详情 **配额** 页出现刚创建的配额记录。
- **工作空间** 列表出现新工作空间，状态正常。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 资源池下拉是空的 | 配额表单里没选集群，或该集群没建资源池 | 先选集群；没有池就去建 [资源池](/boss/rune-admin/resource-pools) |
| 切换集群后资源池被清空 | 这是有意设计 | 重新选择目标资源池 |
| 编辑工作空间时集群是灰的 | 集群创建后不可改 | 属正常现象 |
