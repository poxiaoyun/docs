# 应用模版

模版（Template）就是一份提前配好的「装机清单」：把某个应用需要的东西打包好，用户（或平台自己）点一下就能按这份清单部署，不用从零配置。

模版按用途分成两个 **域**：

- **用户**：给用户在应用市场里用，比如推理、微调、开发环境。
- **系统**：给平台自己在集群里部署中间件用，比如监控、日志、存储。

读完这页，你能完成：新建一个模版、上传它的版本、发布出去，以及管理已有模版。

:::tip 三个词对照

- **模版** ≈ 提前配好的「装机清单」，用户一键就能用。
- **版本** ≈ 同一份清单的不同修订版，比如 1.0、1.1。
- **域** ≈ 这份清单是给「用户」用还是给「平台」用。

:::

## 开始之前

- 你需要 **系统管理员** 账号。
- 准备好要上传的模版包：**`.tgz` 格式** 的 Chart 压缩包。

## 进入方式

左侧菜单点击 **智算平台** 分组下的 **应用模版**。

## 模版列表怎么看

| 列 | 说明 |
| --- | --- |
| 名称 | 头像 + 名称（括号里是 ID）+ 描述；点击进入介绍页 |
| 应用版本 | 最新版本的应用版本号，下方显示包版本 |
| 域 | 用户 / 系统 |
| 分类 | 模版分类，如推理、微调、存储等 |
| 已发布 | 是否已发布 |
| 推荐指数 | 推荐评分 |
| 推荐截图 | 是否已配置推荐截图 |
| 创建时间 | — |

顶部筛选与排序：

- **域**：在用户 / 系统之间切换。
- **分类**：选项随所选域变化（见下表）。
- **搜索**：按关键词搜索。
- **时间排序 / 推荐排序**：切换排序方式。
- **显示未发布**：默认不显示未发布的模版。
- **刷新**：重新拉取列表。

### 域与分类的对应关系

| 域 | 可选的分类 |
| --- | --- |
| 用户 | 推理、微调、开发、实验、评测、应用 |
| 系统 | 系统、存储 |

切换域时，如果当前选的分类不属于新域，会被自动清空。

每行的操作：**推荐**（配置推荐指数与截图）、**发布 / 取消发布**（带确认框）、**编辑**、**删除**（带确认框，支持多选）。

## 新建一个模版

1. 在列表右上角点击 **创建应用模版**。
2. 填写表单：

| 表单项 | 怎么填 | 说明 |
| --- | --- | --- |
| Chart 名称 | 例如 `my-inference` | 模版包的唯一标识，**创建后不可修改** |
| 名称 | 例如「我的推理引擎」 | 界面上展示的名字；创建时会跟随 Chart 名称自动填，可手动改 |
| 域 | 默认「用户」 | 决定这份模版给谁用 |
| 分类 | 先选域再选分类 | 没选域时不可选 |
| 描述 | 可选 | 一句话说明用途 |

3. 点击 **确定** 保存。

:::info 头像只在编辑时能上传

新建时没有上传头像的入口；创建完成后进入 **编辑** 页，才能上传模版头像并裁剪。

:::

## 上传版本并发布

模版建好后，还要上传具体版本，用户才能部署。

1. 点击模版名称进入详情页，切到 **版本** 标签。
2. 上传 Chart 包（`.tgz` 格式）。
3. 在版本列表里确认 **Chart**、**包版本**、**已发布** 三列。
4. 对需要的版本执行 **发布**；已经发布的版本可以 **取消发布** 或 **删除**。

:::warning 没发布就没人能用

只有**已发布**的版本，用户或平台才能部署。上传后记得点 **发布**。

:::

## 推荐模版

在列表点某行的 **推荐**，在弹出的对话框里设置推荐指数和推荐截图，设置后会在推荐排序里生效。

## 结果确认

- 列表里出现新模版，**域** 和 **分类** 符合预期。
- 进入详情 **版本** 标签，能看到刚上传并发布的版本。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 上传被拒 | 不是 `.tgz` 格式 | 重新打包成 `.tgz` 再上传 |
| 用户看不到模版 | 模版或版本未发布 | 发布模版和对应版本 |
| 改不了 Chart 名称 | 创建后不可修改 | 如确需更换，新建一个模版 |
