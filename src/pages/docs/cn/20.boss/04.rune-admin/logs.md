# 日志管理

日志管理是集群排障的第一站：系统组件为什么起不来、某个 Pod 一直重启、节点上有没有异常，都在这里按条件查出来。

读完这页，你能完成：选择查全部日志还是某台节点的日志、用正则与标签过滤缩小范围、开实时跟踪、把结果下载下来。

:::tip 先把范围框小再查
日志量很大，最省时间的顺序是：先选 **全部日志** 或 **节点日志** → 限定 **时间范围** → 用查询表达式或标签过滤 → 再看结果。
:::

## 开始之前

- 需要 **系统管理员** 账号。
- 日志功能依赖集群里已部署的日志采集组件；没有部署时页面查不到数据，先去 **系统应用** 装。
- 集群已接入平台，见 [集群管理](/boss/rune-admin/clusters)。

## 进入方式

1. 顶部导航点击 **智算平台**，再在左侧栏 **智算平台** 分组下点击 **集群管理**。
2. 点进目标集群。
3. 左侧 **运维管理** 分组下点击 **日志管理**。

## 页面结构

顶部两个标签页决定查哪一类日志：

| 标签页 | 用途 |
| --- | --- |
| 全部日志 | 查整个集群范围的日志 |
| 节点日志 | 先选 **节点**（默认全部节点），再看这台机器上的日志 |

查询区可以设置：

| 设置项 | 说明 |
| --- | --- |
| 日志查询 | 输入简单的正则，例如 `error\|exception`；按 Ctrl+Enter 执行 |
| 时间范围 | 查询的时间窗 |
| 条数 | 一次返回多少条，以及「最新在前 / 最新在后」的排序 |
| 标签过滤 | 按标签名和标签值精确过滤，可添加多条、可清除全部 |
| 搜索日志内容 | 在结果里按关键字搜索 |

结果区的操作：

| 操作 | 说明 |
| --- | --- |
| 开始实时日志 / 停止实时日志 | 打开或关闭实时滚动 |
| 跟随 | 视图始终滚到最新一条 |
| 折行 | 长日志换行显示 |
| 下载 | 把当前结果下载下来 |
| 清除日志 | 清空当前结果 |
| 查看上下文 | 打开某条日志前后的上下文 |

![日志管理页：顶部可选全部日志 / 节点日志，设置时间范围与条数后查询，支持实时与下载](/assets/screenshots/boss/cluster-logs-01.png)

页面结构是「先框范围，再拿结果」：选标签页、定时间范围与条数、点 **查询**；要看实时滚动就开 **实时日志**。截图里显示「没有找到日志」，说明这个时间窗内条件没有命中；换 **全部日志** 或放宽时间范围即可。

## 查一次日志

1. 选 **全部日志**（或 **节点日志** 并选节点）。
2. 设好 **时间范围** 和 **条数**。
3. 在 **日志查询** 里输入关键字或正则，例如 `error|exception`。
4. 点 **查询**（或按 Ctrl+Enter）。
5. 需要持续观察时点 **开始实时日志**，看完点 **停止实时日志**。

## 结果确认

- 结果区出现日志条目，顶部显示「共 N 条日志」。
- 实时模式下会不断刷出新条目，并显示「最后接收 … 前」。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 页面显示「没有找到日志」 | 时间窗内无命中，或查询条件太严 | 放宽时间范围、清掉标签过滤再查 |
| 一直是空白 | 集群没装日志采集组件 | 到 **系统应用** 部署日志组件 |
| 节点日志里没有可选节点 | 节点列表未加载或没有可用节点 | 刷新重试，或先确认集群节点正常 |
| 实时日志不刷新 | 实时已停止，或采集端断了 | 重新点 **开始实时日志**，仍不行就检查采集组件 |
| 下载的文件不完整 | 只下载了当前已加载的结果 | 先放宽条数并重新查询，再下载 |
