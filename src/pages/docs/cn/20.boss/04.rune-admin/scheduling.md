# 调度视图

调度视图回答「任务为什么还没跑起来」：队列还有没有额度、工作负载卡在等待还是队列中、是不是 Gang 成员没凑齐。它是**看结果**的页面，改策略请到 **调度器管理**。

读完这页，你能完成：读懂队列总览、判断某个负载卡在哪个阶段、下钻到具体负载看 Pod 调度结果与事件。

:::tip 一个类比
队列像食堂的取餐窗口，额度是每个窗口的备餐量。**应得 / 保障 / 上限** 决定这个窗口能拿多少；任务在窗口前排队时，调度视图告诉你它排到哪一步、为什么还没打上饭。
:::

## 认识概念

| 名词 | 通俗解释 |
| --- | --- |
| 队列 | 一组工作负载共享的调度额度，可以再有父队列 |
| 调度阶段 | 工作负载当前走到哪一步：等待中 / 队列中 / 运行中 / 已完成 / 失败 / 未知 |
| 已分配资源 | 这个队列当前已经用掉的量 |
| 资源上限 | 这个队列最多能用的量 |
| 应得资源 | 按权重算出来「应该分到」的量 |
| 保障资源 | 这个队列至少能拿到的量 |
| 允许回收 | 空闲额度能否被其他队列回收使用 |
| Gang 进度 | 一组必须同时起来的任务，当前起来了几个、最少要几个 |
| 调度证据 | 阶段、原因、消息与时间，用来解释「为什么停在这里」 |

## 开始之前

- 需要 **系统管理员** 账号。
- 集群里已安装调度器组件（Volcano）。没装时页面会提示「调度数据暂不可用」，并说明可能是未安装或平台访问不到调度资源。
- 集群已接入平台，见 [集群管理](/boss/rune-admin/clusters)。

## 进入方式

1. 顶部导航点击 **智算平台**，再在左侧栏 **智算平台** 分组下点击 **集群管理**。
2. 点进目标集群。
3. 左侧 **运维管理** 分组下点击 **调度视图**。

## 页面结构

| 区块 | 内容 |
| --- | --- |
| 顶部状态行 | 调度器类型标签、**观测时间**、**刷新** |
| 汇总 | 全部工作负载的总数，按阶段分布 |
| 队列总览 | 每个队列的已分配资源、资源上限、应得资源、保障资源、权重与优先级、是否允许回收 |
| 调度工作负载 | 工作负载、调度阶段、队列、Gang 进度、原因与最近转换时间 |

![调度视图：顶部是观测时间与刷新，中间是队列总览，下方是调度工作负载表](/assets/screenshots/boss/rune-scheduling-01.png)

队列卡片上的 **优先级 / 权重** 决定它分额度的次序；**允许回收** 打开时，空闲额度可以被别的队列临时借用。工作负载表的 **调度阶段** 是排查时最先看的一列。

## 判断任务卡在哪

1. 先看 **队列总览**：这个队列的 **已分配资源** 是否已经顶到 **资源上限**。
2. 再看 **调度工作负载**：找到目标负载，看它的 **调度阶段**。
3. 阶段是 **等待中** 或 **队列中** 时，看右侧的 **原因** 与 **消息**。
4. 展开 **Gang 进度**：如果「运行 N / 最少 M」里 N 小于 M，说明成员没凑齐，任务会一直等。
5. 需要更细的信息时，点工作负载进详情，看 **Pod 调度结果**、**相关事件** 与 **调度时间线**。

详情页的 **调度时间线** 由当前对象状态和 Kubernetes 事件整理而成；事件过期后历史记录可能不完整。

## 和调度器管理的分工

| 页面 | 定位 | 什么时候用 |
| --- | --- | --- |
| 调度视图（本页） | 看结果 | 任务不跑、排队久、额度不够 |
| [调度器管理](/boss/rune-admin/schedulers) | 改策略 | 要调整流程顺序或插件开关 |

## 结果确认

- 队列总览有数据、工作负载表能列出条目，说明平台能读到调度资源。
- 任务起来后，它的 **调度阶段** 会从等待中/队列中变为 **运行中**。
- 详情页能看到 Pod 的 **已调度** 状态和所在 **节点**。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 页面提示「调度数据暂不可用」 | 集群未安装 Volcano，或平台访问不到调度资源 | 到 **系统应用** 部署调度器后重试 |
| 队列是空的 | 还没有创建队列，或队列里没有负载 | 先确认业务侧已提交负载 |
| 任务一直在等待中 | 队列额度用满、Gang 成员不够、资源规格过大 | 依次看队列上限、Gang 进度、资源请求 |
| 时间线不完整 | 相关事件已过期 | 属正常现象，可结合 **日志管理** 排查 |
| 数据不是最新 | 页面是快照 | 点 **刷新** |
