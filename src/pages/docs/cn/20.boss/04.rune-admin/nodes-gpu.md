# 节点与加速卡状态

节点页与 GPU 页用于从“机器视角”观察集群运行状况，是平台运维排查资源瓶颈的主要入口。

## 进入路径

- Boss -> 集群管理 -> 选择集群 -> 节点状态
- Boss -> 集群管理 -> 选择集群 -> 加速卡信息

> ⚠️ 注意: 两个页面都是**按名称聚合的监控看板**，本身不提供节点清单或节点明细表。节点对象信息请到集群详情「工作负载」子页的 Nodes 标签查看。

## 节点仪表盘

节点仪表盘聚合所有**名称中包含 `node`** 的监控看板，适合关注：

- 节点在线状态
- CPU 与内存使用率
- 节点压力与异常告警
- 节点级负载分布

## 加速卡仪表盘

加速卡仪表盘聚合所有**名称或标题（小写后）包含 `gpu` 或 `npu`** 的监控看板；若同时存在 NVIDIA GPU 看板与 NPU 看板，且 NPU 看板原本排在 NVIDIA GPU 看板之后，则 NPU 看板会被前移到 NVIDIA GPU 看板之前。适合关注：

- 加速卡利用率
- 显存占用
- 卡级别负载不均衡
- 特定型号设备的热点与空闲情况

## 推荐排查顺序

1. 先看集群总览确认是整体异常还是局部异常。
2. 若怀疑节点故障，进入节点仪表盘确认受影响机器。
3. 若怀疑算力不足或卡分配不均，再进入加速卡仪表盘。
4. 需要进一步落到对象层时，再结合 Kubernetes 资源浏览或日志页面。
