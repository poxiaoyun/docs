# 调度器管理

调度器管理用来改**集群的作业调度策略**：任务先排队还是先抢占、按什么顺序分配、哪些插件参与决策。它面向比较熟悉调度的管理员，改一次影响整个集群的排队与分配。

读完这页，你能完成：载入一份推荐配置、调整流程与插件顺序、预览改动、保存下发，并知道改错了怎么退回。

:::tip 和「调度视图」的分工

- **调度视图** 是**看结果**：现在有哪些队列、任务卡在哪个阶段。
- **调度器管理** 是**改策略**：影响接下来任务怎么排队和分配。

:::

## 开始之前

- 需要 **系统管理员** 账号。
- 集群里已部署调度器组件（可在 **系统应用** 里部署）；没有组件时这一页无法保存。
- 建议先在测试集群验证策略，再改生产集群。

## 进入方式

1. 顶部导航点击 **智算平台**，再在左侧栏 **智算平台** 分组下点击 **集群管理**。
2. 点进目标集群。
3. 左侧 **运维管理** 分组下点击 **调度器管理**。

## 页面结构

| 区域 | 内容 |
| --- | --- |
| 左侧配置库 | **自定义配置** 与 **推荐配置**，可以点 **使用** 载入一份 |
| 中间 **流程** 区 | 调度主流程的顺序编排，例如 enqueue、allocate、backfill、reclaim、preempt |
| 中间 **插件** 区 | 插件按「插件层」分组，可拖动调整顺序 |
| 右上角 | **预览**、**刷新**、**保存** |

![调度器管理页：左侧可选自定义配置或推荐配置，右侧分为流程与插件两段](/assets/screenshots/boss/cluster-schedulers-01.png)

每一项都能单独展开看它的作用。右上角 **预览** 看一眼改动后的完整配置，确认无误再点 **保存**。改之前建议先切到 **推荐配置** 对照默认值。

## 调整调度策略

1. 在左侧 **自定义配置 / 推荐配置** 里找到想用的配置，点 **使用** 载入。
2. 从左侧把 **流程** 或 **插件** 拖到右侧对应区域；也可以在同一个层里拖动调整先后顺序。
3. 点右上角 **预览** 查看调整后的效果。
4. 如果期间别处改过配置，点 **刷新** 重新拉取最新配置。
5. 确认无误后点 **保存**，看到 **保存成功** 提示即已下发。

:::warning 调度策略会影响全集群作业
流程顺序和插件开关会直接改变任务的排队与分配。改错了可能导致任务排队变长甚至分配不出去，所以务必先在测试集群验证。
:::

:::info 小屏不支持编辑
这一页在窄屏下会提示不适合在手机操作，请在电脑上使用。
:::

## 结果确认

- 点 **保存** 后出现 **保存成功** 提示。
- 到 **调度视图** 看队列与任务阶段是否按预期变化。
- 保存后策略没有生效时，先点 **刷新** 看是不是被别处的改动覆盖了。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 保存按钮不可用 | 调度器组件未部署，或没有实际改动 | 到 **系统应用** 部署调度器；确认改动后再保存 |
| 保存后任务反而排队更久 | 新策略不适合当前负载 | 载入 **推荐配置** 恢复，再逐步调整 |
| 页面提示需要更大屏幕 | 窄屏限制 | 用电脑浏览器打开 |
| 刷新后改动消失 | 别处也改了同一份配置 | 重新载入并保存，或与同事协调修改时间 |
