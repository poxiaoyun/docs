# 日志与调度器

这两个页面是集群运维的常用工具：

- **日志管理**：按条件查集群里的日志，支持实时滚动查看，用来定位报错。
- **调度器管理**：用拖拽的方式调整集群的作业调度策略（Volcano）。

## 开始之前

- 需要 **系统管理员** 账号。
- 日志功能依赖集群里已部署的日志采集组件；调度功能依赖集群里已部署调度器。缺组件时先到 **系统应用** 部署。

## 进入方式

1. 顶部导航点击 **智算平台**，再在左侧栏 **智算平台** 分组下点击 **集群管理**，点进目标集群。
2. 左侧 **运维管理** 分组下：
   - 点击 **日志管理** 查日志。
   - 点击 **调度器管理** 调策略。

## 查日志

日志页顶部有两个标签：

| 标签 | 用途 |
| --- | --- |
| 全部日志 | 查整个集群范围的日志 |
| 节点日志 | 先选机器，再看这台机器上的日志 |

在日志查询区你可以：

1. 在查询框里输入过滤表达式，例如 `level=error`。
2. 用 **标签过滤** 勾选标签：输入框会联想可用的标签名和标签值。
3. 选择 **时间范围**，或直接在 **搜索日志内容** 里搜关键字。
4. 点 **开始实时日志** 打开实时滚动，再点 **停止实时日志** 结束；**跟随** 可以让视图一直滚到最新一条。
5. 用 **折行** 让长日志换行显示，用 **清除** 重置条件。

:::tip 查不到日志怎么办

页面无数据时，先确认集群里是否已经通过 **系统应用** 安装了日志采集组件，再确认查询的时间范围是否正确。

:::

![日志管理页：顶部可选全部日志 / 节点日志，设置时间范围与条数后查询，支持实时与下载](/assets/screenshots/boss/cluster-logs-01.png)

日志页的结构是「先框范围，再拿结果」：顶部选 **全部日志** 或 **节点日志**、定时间范围与条数，点 **查询**；想看实时滚动就打开 **实时**。右侧还有 **折行**、**下载**、**清除日志**。截图里显示「没有找到日志」，因为选的时间窗内这条查询没有命中；换 **全部日志** 或放宽时间范围即可。

## 调整调度策略

调度器管理面向较熟悉调度的管理员，页面左侧是可选配置，中间是 **流程**（动作编排）和 **插件**（插件按「插件层」分组）两块编排区。操作方式：

1. 在左侧 **自定义配置 / 推荐配置** 里找到想用的配置，点 **使用** 载入。
2. 从左侧把 **流程** 或 **插件** 拖到右侧对应区域；也可以在同一个层里拖动调整先后顺序。
3. 点右上角 **预览** 查看调整后的效果。
4. 如果期间别处改过配置，点 **刷新** 图标重新拉取最新配置。
5. 确认无误后点 **保存**，看到 **保存成功** 提示即已下发。

:::warning 调度策略会影响全集群作业

调度配置会直接影响集群里作业的排队和分配方式。建议先在测试集群验证，再改生产集群。

:::

:::info 手机 / 小屏不支持编辑

调度器管理页在窄屏下会提示不适合在手机操作，请在电脑上使用。

:::

![调度器管理页：配置项可选自定义配置或推荐配置，分为流程（enqueue/allocate/backfill/reclaim/preempt）与插件两段](/assets/screenshots/boss/cluster-schedulers-01.png)

调度器页把策略拆成 **流程** 与 **插件** 两类配置项，每一项都能单独查看它的作用（截图里展开的是 `enqueue`）。右上角 **预览** 看一眼改动后的完整配置，确认无误再点 **保存**。改之前建议先切到 **推荐配置** 对照一下默认值。

## 另外两个预留页面

集群里还有 **监控告警** 和 **事件日志** 两个入口，目前是占位页面（打开后显示「即将展现！我们目前正在努力完善此页面！」），它们不在左侧子菜单里，暂时可以不关注。

## 结果确认

- 日志页能查到记录，或实时模式能持续刷出新日志。
- 调度器页点 **保存** 后出现 **保存成功** 提示。
