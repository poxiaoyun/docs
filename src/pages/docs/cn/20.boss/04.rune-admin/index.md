# Rune 智算管理

这里是平台管理员维护「算力底座」的地方。用户在智算平台上能用的每一台机器、每一张加速卡、每一条资源规格，都是先在这里接进来、分配好，之后才能创建实例。

读完这页，你知道这一组页面各管什么、维护顺序是什么、以及为什么有些菜单要点进集群才会出现。

:::tip 先记住这几个词

- **集群** ≈ 一栋机房大楼，里面有很多台机器。
- **节点** ≈ 大楼里的一台服务器。
- **加速卡（GPU / NPU）** ≈ 服务器里专门算 AI 的「引擎」。
- **资源池** ≈ 把大楼里的机器划成几个「功能区」，不同部门分着用。
- **资源规格** ≈ 一张套餐规格表，写明「几核 CPU / 多少内存 / 几张卡」。
- **配额** ≈ 这个租户在某个集群上最多能用多少。
- **应用** ≈ 提前配好的「装机清单」，用户或平台一键就能部署。

:::

## 开始之前

- 你需要 **系统管理员** 账号；普通成员看不到左侧的 **智算平台** 分组。
- 建议先在测试集群上完整走一遍流程，再操作生产集群。

## 维护顺序

1. **接入集群**：把机房接进平台，测试连接并上线。
2. **开通租户**：在某个集群上给租户开通，租户才有资格用这个集群。
3. **划分资源池**：把机器按用途分组。
4. **定义资源规格**：规定「几核几卡」的套餐，并决定哪些规格需要租户授权。
5. **分配配额**：按「集群 + 资源池 + 资源项」把额度发给租户，再细分到工作空间。
6. **部署公共组件**：用系统应用和存储集群补齐监控、日志、存储等能力。
7. **配好运维手段**：告警规则、调度策略、日志查询。

## 怎么确认自己进对了地方

- 顶部导航点击 **智算平台** 后，左侧栏能看到 **智算平台** 分组，下面是 **集群管理**、**租户集群**、**应用** 三项。
- 从 **集群管理** 点进某个集群后，左侧会出现 **集群信息 / 资源管理 / 运维管理** 三组子菜单——这三组只在集群里出现。
- **动态仪表盘** 不在任何菜单里，只能用地址打开。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 左侧只有集群管理 | 顶部停在了别的区域 | 顶部点 **智算平台** |
| 找不到「租户资源」 | 它只出现在集群里 | 先点进一个集群，再看 **资源管理** 分组 |
| 找不到「告警渠道」 | 它在顶部导航，是平台级设置 | 点顶部 **告警渠道** |
| 找不到「动态仪表盘」 | 它不在菜单里 | 用地址打开，或从[集群信息](/boss/rune-admin/cluster-overview)进入 |
