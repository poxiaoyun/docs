# 产品概述

晓石 AI 是一套**给企业使用的 AI 平台**。它把机房里的 GPU 机器变成「可以按需领用、用完释放」的算力，把一个大模型变成「随时能被网页和程序调用的在线服务」，还替你把模型文件、数据集、容器镜像统一管起来。

作为使用者，你在这套平台上通常只做三件事：**领到算力**、**把模型跑起来**、**把模型和数据管好**。本页不讲具体操作，只帮你先看懂整张地图：每一块叫什么、归谁管、你现在该读哪一篇。

第一次来，建议读完本页后直接去[快速开始](/guide/quick-start)：那里按五个阶段，从登录一直带你把第一个推理服务跑起来。

:::tip 用一个类比理解整个平台
把晓石 AI 想成一栋「AI 工厂」：

- **BOSS** 是厂长办公室：规划产线、分配产能、制定安全规则。
- **智算平台** 是车间：真正干活的地方，模型在这里被部署、训练、调试。
- **魔哈 Hub** 是仓库：模型、数据集、镜像都存放在这里，随取随用。
:::

## 平台由三块组成

| 这一块 | 谁在用 | 帮你做什么 | 怎么进入 |
| --- | --- | --- | --- |
| **智算平台**（租户门户） | 租户管理员、开发者、普通成员 | 你的日常主界面：部署推理服务、提交微调任务、开开发环境、建文件存储、看日志与评测，还能直接和模型对话 | 登录后默认进入，网址以 `/console` 结尾 |
| **BOSS**（管理门户） | 平台管理员 | 平台级管理：纳管集群、划分资源池、定义资源规格、给租户分配配额、维护大模型网关与内容审核 | 独立入口，网址以 `/boss` 结尾 |
| **魔哈 Hub** | 需要管理模型与数据集的团队 | 模型与数据集的托管仓库：上传、版本管理、分支与合并请求、镜像仓库、在线展示空间，也能从 HuggingFace 等外部来源同步 | 从页面左上角的**产品与服务**切换到魔哈 Hub |

### 三者的关系

1. **BOSS 先铺路**：平台管理员先在 BOSS 里接入集群、定义资源规格、给租户分配配额，算力才有得用。
2. **智算平台干活**：租户管理员在自己的工作空间里把配额再分给成员，成员在智算平台里部署服务、跑任务。
3. **魔哈 Hub 供货**：模型和数据放在魔哈 Hub。智算平台可以直接把 Hub 里的模型部署成推理服务；服务跑起来后，既能用网页对话试用，也能拿到接口地址给程序调用。

:::warning 两个入口互不相通
智算平台和 BOSS 是两个独立界面。普通用户只会看到智算平台；只有平台管理员能进入 BOSS。你在智算平台里找不到 BOSS 的菜单，这是正常的。
:::

## 智算平台里的菜单

登录后左侧菜单分成三组。**工作台**和**可观测性**两组只对租户管理员、开发者显示，普通成员看不到。

| 分组 | 菜单 | 用来做什么 |
| --- | --- | --- |
| **首页** | 首页 | 当前工作空间的资源、配额、负载总览 |
| | 应用市场 | 从现成模板一键部署应用 |
| **工作台** | 推理服务 | 把模型部署成对外的在线接口 |
| | 训练与微调 | 用你自己的数据继续训练模型 |
| | 开发服务 | 开一台带图形界面的开发机（JupyterLab、VS Code） |
| | 应用实例 | 部署自定义的 AI 应用 |
| | 我的模板 | 管理你自己发布的应用模板 |
| | 文件存储 | 创建网络硬盘，存放模型文件与数据集 |
| **可观测性** | 指标 | 查看实验记录的曲线与对比 |
| | 日志 | 检索实例运行日志 |
| | 模型评测 | 给模型批量打分、比较版本 |

此外，左上角**产品与服务**里还有一块 **AIRouter**：不用写代码就能与模型聊天、让两个模型同时回答同一句话做对比、管理 API 密钥、查看调用量和费用。

## BOSS 里的菜单

| 分组 | 用来做什么 |
| --- | --- |
| **概览** | 平台整体仪表盘 |
| **大模型网关 / 模型服务 / 用户管理 / 安全服务 / 平台设置** | 配置模型渠道、模型元数据、网关令牌、调用日志、内容审查策略与敏感词、网关与货币设置 |
| **资产管理 / 数据同步 / 安全审计 / 系统设置** | 平台级管理模型库、数据集、镜像仓库、展示空间，配置镜像同步、审计日志、公告与横幅 |
| **智算平台** | 集群管理、租户资源、应用模板 |
| **账户管理** | 用户管理、租户管理 |
| **平台** | 系统成员、平台设置、智算平台设置、魔哈 Hub 设置、网关设置、AI 助手设置、许可证 |

## 魔哈 Hub 里的内容

| 内容 | 用来做什么 |
| --- | --- |
| **模型库** | 存放模型文件，带版本、分支和合并请求 |
| **数据集** | 存放训练与评测数据，同样支持版本管理 |
| **镜像仓库** | 存放容器镜像 |
| **展示空间** | 放 Gradio、Streamlit 之类的小应用，做成模型在线试用页 |
| **组织** | 按团队管理仓库归属和成员 |
| **镜像同步** | 把 HuggingFace、ModelScope 上的公开模型或数据集同步进来 |
