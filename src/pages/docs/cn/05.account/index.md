# 账号与权限

账号与权限是整个平台的「门禁系统」：它决定你是谁、你能进哪家公司的空间、进去以后能做什么。
第一次使用平台，你会按「登录 → 选择租户 → 进入平台」的顺序走一遍；之后忘记密码、换头像、
生成访问密钥、连接代码仓库，也都在这组页面里处理。

:::tip 用一个场景理解
把平台想成一栋写字楼：登录是刷卡进楼，租户是你所在的公司，角色是你在公司里的权限级别，
个人设置是改你工牌上的照片和昵称。下面几个页面分别对应这几件事。
:::

## 先记住这几个词

| 名词 | 通俗解释 |
| --- | --- |
| 登录 | 用账号和密码证明「我是谁」 |
| 租户 | 一家公司在平台上的独立账号空间，不同租户的数据互不干扰 |
| 角色 | 你在租户里的身份，决定你能操作哪些功能 |
| 多因素认证 | 除了密码，再补一个手机上会变的 6 位验证码，账号更安全 |
| API 密钥 | 一串给程序用的「账号密码」，让脚本或应用替你调用平台接口 |
| SSH 密钥 | 一对钥匙，用来免密连接 Git 仓库或服务器 |

## 第一次使用怎么走

1. 打开平台地址，在登录页填写 **用户名/邮箱/手机号** 和 **密码**，勾选协议后点击 **登录**。
2. 登录后进入选择租户页，从下拉框选中你的租户，点击 **进入平台**。
3. 进入平台后，点击右上角头像 → **个人设置**，可以完善头像、昵称，并设置密码、密钥等。
