# 账号与权限

账号与权限决定三件事：**你是谁**、**你能进哪家公司空间**、**进去以后能做什么**。
第一次使用会按「登录 → 选择租户 → 进入平台」的顺序走一遍；之后改头像、换密码、绑定二次验证、
生成访问密钥，也都在这一组页面里完成。读完这一页，你能分清哪些事该去登录页、哪些事在个人设置里。

:::tip 用一个场景理解
把平台想成一栋写字楼：登录是刷卡进楼，租户是你所在的公司，角色是你在公司里的权限级别，
个人设置是改你工牌上的照片和昵称。下面几个页面分别对应这几件事。
:::

## 先记住这几个词

| 名词 | 通俗解释 |
| --- | --- |
| 登录 | 用密码或一次性验证码证明「我是谁」 |
| 租户 | 一家公司在平台上的独立账号空间，不同租户的数据互不干扰 |
| 角色 | 你在租户里的身份，决定你能操作哪些功能 |
| 多因素认证 | 除了密码，再补一个验证码（认证器 App、邮箱或短信），账号更安全 |
| API Key | 一对给程序用的「账号密码」，让脚本或外部应用替你调用平台接口 |
| SSH 密钥 | 一对钥匙，用来免密连接 Git 仓库或服务器 |

## 第一次使用怎么走

1. 打开平台地址，在登录页选择登录方式（**密码登录**、**邮箱验证码**、**短信验证码**，出现哪几种由平台开启决定），填好凭据。
2. 勾选 **我已阅读并同意《服务条款》与《隐私政策》。** 没勾选之前 **登录** 按钮点不动。
3. 点击 **登录**。
4. 账号属于多个租户时，会停在 **选择您的租户** 页面，选好租户后点击 **进入平台**；只属于一个租户时会直接进入平台。
5. 进入平台后，点击右上角头像 → **个人设置**，可以改头像、昵称、密码，并管理访问密钥。

整个流程的第一步就是登录页：

![登录页：左侧是产品介绍与四条能力卡片，右侧是登录卡片，包含登录方式切换、账号输入框、密码输入框、服务条款勾选框和登录按钮](/assets/screenshots/account/login-01.png)

登录成功后是否需要选租户，取决于你属于几个租户，详见 [选择/注册租户](/account/auth/select-tenant)。

### 个人设置（四个页签）

| 页签 | 页面 | 能改什么 |
| --- | --- | --- |
| 基本信息 | [基本信息](/account/iam/profile) | 头像、昵称、邮箱、手机号码；用户名只读 |
| 账户安全 | [账户安全](/account/iam/security) | 密码、多因素认证，以及绑定的第三方登录方式 |
| 访问密钥 | [API Key](/account/iam/api-key) · [SSH 密钥](/account/iam/ssh-key) | 给程序用的 API Key，连接仓库用的公钥 |
| 偏好设置 | [偏好设置](/account/iam/preferences) | 亮暗模式、主题色、界面语言 |

### 租户

| 页面 | 帮你解决什么 |
| --- | --- |
| [租户管理](/account/iam/tenant) | 看租户资料、管成员；入口在头像抽屉里，不在个人设置页签中 |

:::info 两件常被找错的事
**切换租户** 在头像抽屉底部的 **切换租户** 按钮上；**租户资料与成员** 在头像抽屉里的 **租户 {租户名}** 一行。
这两件事都不在个人设置的页签里。
:::
