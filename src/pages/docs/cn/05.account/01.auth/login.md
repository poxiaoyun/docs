# 登录

登录就是用你的账号进入平台。平台可能同时开放密码、邮箱验证码、短信验证码三种登录方式，
也可能只开放其中一种。这篇会讲清三种方式分别怎么填、什么时候会弹出 **安全验证** 窗口，
以及登录不成功时该怎么看提示。

:::tip 登录分两步，但常常只感觉一步
先在登录页证明身份，再进入某一家公司的空间。账号只属于一个租户、或平台记住了上次的租户时，
第二步会自动完成，所以你经常只点一次就进去了。
:::

## 开始之前

- 有一个已注册的账号。还没有账号，先看 [注册](/account/auth/register)。
- 知道平台访问地址，并且记得自己的密码（用验证码登录则不需要密码）。
- 用邮箱验证码登录时，要能打开绑定到账号的邮箱；用短信验证码登录时，要能收到绑定手机号的短信。

## 登录页长什么样

宽屏下左侧是品牌介绍和四张能力卡片（训推一体管理 / AI数据治理 / MaaS 服务 / 团队合作），
右侧是登录卡片。卡片最上方是标题 **欢迎来到{平台标题}**，下面是登录方式切换、凭据表单、
协议勾选框和 **登录** 按钮。

![登录页：左侧是平台介绍与能力卡片，右侧是登录卡片，顶部有登录方式切换，中部是账号与密码输入框，底部是协议勾选与登录按钮](/assets/screenshots/account/login-01.png)

## 选择登录方式

登录卡片顶部可能有一排切换控件（**密码登录** / **邮箱验证码** / **短信验证码**）。
它只在平台开启了**多于一种**方式时出现；只有一种方式时看不到切换，直接就是那一种。

| 登录方式 | 需要填什么 | 适合什么情况 |
| --- | --- | --- |
| **密码登录** | **用户名/邮箱/手机号** + **密码** | 常用方式 |
| **邮箱验证码** | **邮箱** + **验证码** | 忘了密码，但能收邮件 |
| **短信验证码** | **手机号码** + **验证码** | 忘了密码，但手机在身边 |

## 用密码登录

1. 确认顶部选中的是 **密码登录**。
2. 在 **用户名/邮箱/手机号** 里填账号，三者中填哪个都行。
3. 在 **密码** 里填密码。字符默认显示为圆点，点输入框右侧的眼睛图标可以切换成明文核对。
4. 勾选 **我已阅读并同意《服务条款》与《隐私政策》。** 没勾选时 **登录** 按钮是灰的。
5. 点击 **登录**，按钮上会短暂显示 **登录中...**。

## 用验证码登录

1. 在顶部切到 **邮箱验证码** 或 **短信验证码**。
2. 在 **邮箱** 或 **手机号码** 里填绑定到账号的地址/号码。
3. 点击 **验证码** 输入框右侧的 **发送验证码**。发送成功后按钮变成 60 秒倒计时，倒计时结束才能重发。
4. 去收件箱或短信里取验证码，填进 **验证码**。
5. 勾选协议，点击 **登录**。

:::info 验证码有有效期
验证码只能用一次，且会过期。改动了上面的邮箱或手机号之后，原来收到的验证码立即失效，需要重新发送。
:::

## 用第三方账号登录

如果平台接入了第三方登录，凭据表单下方会有一条虚线分隔线，文字是 **第三方登录**，
下面是各个服务商的按钮（按钮上写的是平台给该服务商起的显示名，可能带图标）。

1. 点击你要用的服务商按钮。
2. 浏览器跳到该服务商的登录/授权页，完成登录并同意授权。
3. 授权完成后自动回到平台，继续后面的流程。

:::warning 第三方授权没完成，会回到登录页
中途关掉服务商页面或拒绝授权时，会回到登录页并提示授权未完成，重新点一次按钮即可。
:::

## 可能出现的「安全验证」

安全验证不是表单里的字段，而是一个弹窗，标题是 **安全验证**。它**只在平台判定本次提交需要验证时**出现，
也就是说：正常填完不会看到它，看到它也不是出错。

| 弹窗里的形式 | 怎么操作 |
| --- | --- |
| 图形验证码 | 在 **验证码** 里输入图片上的字符；填满后自动提交。看不清就点右侧图片换一张 |
| 滑块 | 按住底部滑块向右拖动，让拼图块对齐缺口后松手，松手后自动提交 |

:::tip 什么时候会触发
常见于同一账号密码连续输错、或从没见过的网络环境登录。通过一次验证后，正常登录不会每次都弹。
:::

## 登录成功后会发生什么

- 如果账号开启了多因素认证，会先进 **验证登录** 一步：选 **验证方式**（身份验证器 / 邮箱 / 短信）填 **验证码**，
  或点下方的 **使用恢复码** 改填恢复码。详见 [多因素认证](/account/auth/mfa)。
- 属于多个租户、且平台没有记住上次的租户时，会停在 **选择您的租户**，详见 [选择/注册租户](/account/auth/select-tenant)。
- 只属于一个租户时，直接进入该租户的首页。
- 长时间没操作导致会话过期，页面会提示 **登录已失效，请重新登录。**，重新登录即可。

## 登录失败怎么办

提示通常出现在表单下方或页面顶部。常见情况：

| 你看到的提示 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 账号或密码错误 | 账号或密码输错（注意大小写、空格、输入法） | 重新输入；忘了密码看 [重置密码](/account/auth/reset-password) |
| 验证码错误，请重新输入 | 验证码填错或已过期 | 重新点 **发送验证码**，或点图片换一张 |
| 登录失败次数过多，请在…后重试 | 连续失败太多次，账号被临时锁定 | 等提示里的时间过去再试；急用可联系平台管理员 |
| 请先同意服务条款和隐私政策 | 协议没勾选 | 勾选后再点 **登录** |
| 没有可用的登录方式，请联系平台管理员。 | 平台没有给你开放任何登录方式 | 联系平台管理员开通账号或登录方式 |
| 第三方授权未完成 | 在服务商页面中途退出 | 重新点一次第三方登录按钮 |

## 退出登录

点击右上角头像打开抽屉，点底部的 **登出**，本机登录状态会被清空并回到登录页。

:::info 选择租户页也有退出入口
还没进入平台时（停在选择租户页），页面底部是 **退出登录**，作用相同。
:::
