# 多因素认证 (MFA)

多因素认证就是给账号再加一道锁：除了密码，还要输入一个一次性的验证码。
即使别人知道了你的密码，没有你手上的验证码也进不来。这篇会带你从 **账户安全** 页绑定身份验证器、
保存恢复码，并说清登录时那一步该怎么做。

:::tip 类比
密码像家门钥匙，多因素认证像门口的指纹锁。两样都对得上才能进门，单有钥匙进不去。
:::

## 开始之前

- 在手机上装一个身份验证器 App，例如 Google 身份验证器（Google Authenticator）。
- 确保你能正常登录平台，因为绑定动作在登录之后做。
- 准备一个能保存恢复码的地方：密码管理器，或者纸笔。

## 在哪里设置

多因素认证没有单独的页签，入口在账户安全页的一行里：

1. 点击右上角头像 → **个人设置**。
2. 点击顶部页签 **账户安全**，找到分组 **密码与认证**。
3. 找到 **多因素认证** 一行。右侧是状态标签：**未启用** 或 **已启用**。
4. 点行尾的操作：未启用时是 **设置身份验证器**，已启用时是 **更换身份验证器**。

这一行的说明文字是 **设置身份验证器后，登录时需提供应用生成的验证码。**

## 设置身份验证器

点 **设置身份验证器** 后弹出一个窗口，窗口里从上到下是：

1. 提示 **用你的身份验证应用扫描二维码(例如： Google身份验证器)**。
2. 一张二维码。
3. 一个只读的 **设置密钥** 字段，右侧有复制按钮。扫码失败时用它手动添加，帮助文字是 **无法扫码时，在身份验证应用中手动输入此密钥。**
4. **验证码** 输入框。

接着按顺序操作：

1. 打开手机上的身份验证器 App，选择「扫描二维码」，对着屏幕扫。
2. 扫不出来时，在 App 里选「手动输入密钥」，把 **设置密钥** 复制过去，账号名随便填一个能认出来的即可。
3. App 里会出现一个每 30 秒变化一次的 6 位数字。
4. 把这个数字填进 **验证码**。
5. 点击 **绑定**。

## 保存恢复码（这一步不能跳）

绑定成功后，同一个窗口会切换成恢复码内容：

- 成功提示 **您已成功启用多因素认证！**
- 说明 **请保存此恢复代码。一旦您的设备无法提供身份验证码，您可以通过此恢复码登录**
- **恢复码 1**、**恢复码 2**……**一次给出多条**，每条都是只读字段，右侧各带一个复制按钮
- 底部按钮 **已保存恢复码，继续**

:::warning 必须点「已保存恢复码，继续」
不点这个按钮，窗口不会关闭，绑定流程也没有真正结束。请先把每一条恢复码复制到密码管理器里，
或抄到纸上，再点它。
:::

:::warning 恢复码只在这一刻可见
关闭窗口后就再也看不到这批恢复码了。恢复码是手机丢失时唯一能自己进去的途径，
丢了只能联系平台管理员协助处理。
:::

## 登录时怎么过二次验证

开启之后，每次登录在提交账号密码后都会多出一步，标题是 **验证登录**：

| 界面元素 | 说明 |
| --- | --- |
| **验证方式** 下拉 | 可选 **身份验证器**、**邮箱**、**短信**；能选哪些取决于平台为你开通了哪些 |
| **验证码** | 填当前验证码。选身份验证器就填 App 里的 6 位数字；选邮箱或短信就填收到的验证码 |
| **登录** | 提交这一步 |
| 底部文字按钮 **使用恢复码** | 切到填恢复码的模式，字段标签变成 **恢复码**；再点同一个位置的 **使用验证码** 可以切回来 |

:::tip 验证方式可以换
手机不在身边但能收邮件时，把 **验证方式** 切成 **邮箱** 就行，不必先去改设置。
:::

## 首次登录被要求设置

如果平台策略要求必须开启多因素认证，而你还没绑定，登录过程中会直接出现
**设置身份验证器以完成登录**，并就地展示扫码绑定界面。按上面的「设置身份验证器」做完，
保存恢复码后即可完成这次登录。

:::info 不是「身份验证器」的方式不能就地绑定
如果被要求绑定的方式不是身份验证器，会提示 **该验证方式需要绑定，请联系平台管理员。**
:::

## 更换手机 / 换验证器

1. 进入 **个人设置 → 账户安全**，**多因素认证** 行的状态此时是 **已启用**。
2. 点击 **更换身份验证器**，重新弹出扫码窗口。
3. 按上面的步骤在新手机上重新扫码、填验证码、绑定，并保存新的恢复码。

:::warning 这里没有「停用」按钮
页面只能设置或更换身份验证器，不能关掉多因素认证，也没有「重置」按钮。
旧的恢复码在更换后不再可用，请以最新一次给出的为准。
:::

## 恢复码也丢了怎么办

两条都用不上时（手机丢了、恢复码也没保存），联系平台管理员处理身份验证器绑定，
之后重新登录并按上面的步骤再绑定一次。
