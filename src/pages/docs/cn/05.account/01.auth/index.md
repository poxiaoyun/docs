# 认证与登录

这一组页面只做一件事：**确认你是谁，并把你带进正确的公司空间**。
无论你是第一次注册的新用户，还是每天登录的老用户，都在这里完成登录、找回密码、
绑定二次验证和选择租户。

:::tip 登录其实分成两小步
先在登录页证明身份，再到选择租户页选一家公司进入。如果账号只属于一个租户，
第二步会自动完成，看起来就像一步。
:::

## 你会用到哪些页面

| 页面 | 什么时候用 |
| --- | --- |
| [登录](/account/auth/login) | 每天进入平台 |
| [注册](/account/auth/register) | 第一次使用、还没有账号 |
| [重置密码](/account/auth/reset-password) | 忘记密码 |
| [多因素认证](/account/auth/mfa) | 想给账号再加一道保护 |
| [角色与权限](/account/auth/roles) | 想知道自己能做什么、看别人的角色 |
| [选择/注册租户](/account/auth/select-tenant) | 登录后选公司空间，或新建一个 |

登录分两小步，第二步（选择租户）长这样：

![选择租户页：右侧卡片问候语「Admin 您好，选择您的租户」，下方依次是租户下拉框、进入平台按钮、创建租户按钮与退出登录](/assets/screenshots/account/select-tenant-01.png)

页面上除了 **租户** 下拉框和 **进入平台**，还给了一手兜底：一个租户都没有时，点 **创建租户** 就能给自己开一家。

## 几个要知道的规则

- 登录成功后一定会先经过租户选择页；只属于一个租户时会自动进入。
- 登录页没有「记住我」，每次登录都要重新输入账号和密码。
- 登录页必须先勾选「我已阅读并同意《服务条款》与《隐私政策》。」，否则 **登录** 按钮点不动。
- 登录页的验证码有两种样式（图形验证码、滑块验证码），出现哪一种由平台决定。
- 忘记密码页面目前还不能自助改密码，需要联系管理员处理（见 [重置密码](/account/auth/reset-password)）。
