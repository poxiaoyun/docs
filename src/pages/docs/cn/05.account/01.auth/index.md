# 认证与登录

这一组页面只做一件事：**确认你是谁，并把你带进正确的公司空间**。
无论你是第一次注册的新用户，还是每天登录的老用户，都在这里完成登录、找回密码、
绑定二次验证和选择租户。读完这一页，你会知道每一步能跳过什么、什么时候必须停下来做选择。

:::tip 登录其实分成两小步
先在登录页证明身份，再进入某一家公司的空间。如果账号只属于一个租户，第二步会自动完成，
看起来就像一步。属于多个租户时，才会让你自己挑一个。
:::

## 你会用到哪些页面

| 页面 | 什么时候用 |
| --- | --- |
| [登录](/account/auth/login) | 每天进入平台 |
| [注册](/account/auth/register) | 第一次使用、还没有账号 |
| [重置密码](/account/auth/reset-password) | 忘记密码 |
| [多因素认证](/account/auth/mfa) | 想给账号再加一道保护 |
| [选择/注册租户](/account/auth/select-tenant) | 选择公司空间，或新建一个 |
| [角色与权限](/account/auth/roles) | 想知道自己能做什么、看别人的角色 |

属于多个租户时，登录后这一步长这样：

## 几个要知道的规则

- **登录方式由平台决定。** 平台可能开放 **密码登录**、**邮箱验证码**、**短信验证码** 中的一种或多种；
  只有多于一种时，登录卡片顶部才会出现切换控件。三种方式的具体操作见 [登录](/account/auth/login)。
- **必须先勾协议。** 没勾选 **我已阅读并同意《服务条款》与《隐私政策》。** 时，**登录** 按钮是灰的、点不动。
- **登录页没有「记住我」。** 每次都要重新填凭据，会话过期时页面会提示 **登录已失效，请重新登录。**
- **安全验证是弹窗，不是表单字段。** 只有平台判定本次登录需要验证时，提交后才会弹出 **安全验证** 窗口，
  按窗口里的提示完成图形或滑块验证即可。
- **开启多因素认证后，密码对不对都不够。** 登录会先进 **验证登录** 一步，选验证方式或改用恢复码。
- **可能落在选择租户页，也可能直接进平台。** 属于多个租户、且没有记住上次的租户时，才会让你选。
- **忘记密码不能自助重置。** 页面只提示联系平台管理员，详见 [重置密码](/account/auth/reset-password)。
