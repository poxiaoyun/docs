# 角色与权限

角色决定你在当前租户里能点哪些按钮。同一条菜单，**管理员**能改、**开发**只能看，
差别就来自你们被分到的角色不同。读完这页，你会知道三种角色分别能做什么、自己的角色在哪里看，
以及为什么有些入口干脆不显示。

:::tip 类比
角色就像公司里的门禁级别：**管理员**有一整层的门禁卡，**开发**能进机房但不能动人事档案，
普通成员只能刷卡进入公共区域。你能看到哪些菜单、能点哪些按钮，都由它决定。
:::

## 开始之前

- 角色是「在某个租户里」生效的，登录后先确认你在哪个租户。
- 想看成员名单和自己的角色，需要在这个租户里是 **管理员**；其他人的角色信息你看不到。

## 三种角色分别能做什么

| 能力 | 管理员 | 开发 | 普通成员 |
| --- | :---: | :---: | :---: |
| 查看工作空间 | ✅ | ✅ | ✅ |
| 创建 / 修改 / 删除工作空间 | ✅ | ❌ | ❌ |
| 查看实例（推理服务、训练与微调、开发服务等） | ✅ | ✅ | ✅ |
| 创建 / 启停 / 删除实例 | ✅ | ✅ | ❌ |
| 查看镜像 | ✅ | ✅ | ✅ |
| 创建 / 修改 / 删除镜像 | ✅ | ❌ | ❌ |
| 查看规格与我的预设 | ✅ | ✅ | ❌ |
| 创建 / 修改 / 删除规格与我的预设 | ✅ | ❌ | ❌ |
| 管理成员 | ✅ | ❌ | ❌ |
| 管理配额 | ✅ | ❌ | ❌ |
| 创建 / 删除存储卷 | ✅ | ❌ | ❌ |

:::info 系统管理员
不属于任何租户、也没有限定工作空间的 **管理员**，平台视其为系统管理员，拥有全部权限，
并且能进 BOSS 管理门户。通常只有平台运维人员才是这种账号。
:::

## 角色和「作用范围」怎么组合

平台的角色只有三种，差别在于它被分配在**哪个范围**上：

| 你听到的称呼 | 实际是什么 | 主要界面 |
| --- | --- | --- |
| 平台管理员 | 不限定租户的 **管理员** | BOSS |
| 租户管理员 | 限定在某个租户的 **管理员** | 智算平台 |
| 开发 | 限定在某个租户的 **开发** | 智算平台 |
| 普通成员 | 限定在某个租户的 **普通成员** | 智算平台 |

由此可以推出：**同一个人可以同时是多个租户的管理员**，在 A 租户是管理员、在 B 租户可能只是普通成员。

## 在哪里看到自己是什么角色

1. 点击右上角头像，在抽屉里点击 **租户** 后面跟着当前租户名的那一行，进入租户管理。
2. 在左侧导航点击 **成员**（只有租户管理员能看到这个入口）。
3. 在成员表格里找到你自己的用户名，**角色** 列就是你在这个租户里的角色。

成员表格有四列：**用户名 / 邮箱 / 角色 / 加入时间**，角色列显示的是 **管理员**、**开发** 或 **普通成员**。

![租户管理的成员页签：上方是搜索和添加成员入口，下方表格列出用户名、邮箱、角色、加入时间四列](/assets/screenshots/account/roles-01.png)

:::warning 看不到「成员」入口，就是没有管理权限
**成员** 只出现在租户管理员的左侧导航里。看不到它，说明你在当前租户不是管理员，
这时也没有别的地方能查到角色，需要向租户管理员确认。
:::

## 角色改了为什么不立刻生效

页面在登录后读取一次你的角色，之后用这份数据控制菜单和按钮。
如果管理员刚调整了你的角色，**刷新页面或重新登录一次**，菜单才会跟着变。

## 一些要知道的规则

- 如果某个菜单看不到、某个按钮点不动，多半是角色权限不够，而不是页面出错。完整的能力对照见 [权限说明](/reference/permissions)。
- 如果被分配的角色不在 **管理员 / 开发 / 普通成员** 之内（例如平台自定义的角色），界面会按最小权限处理，绝大多数菜单和按钮都不显示；需要权限请让管理员改成上面三种之一。
- 改昵称、换头像都不会影响你的角色。
