# 角色与权限

角色决定你在当前租户里能点哪些按钮。同一条菜单，**管理员**能改、**开发**只能看，
差别就来自你们被分到的角色不同。读完这页，你会知道三种角色分别能做什么，
也能找到自己的角色在哪里看。

:::tip 类比
角色就像公司里的门禁级别：**管理员**有一整层的门禁卡，**开发**能进机房但不能动人事档案，
普通成员只能刷卡进入公共区域。你能看到哪些菜单、能点哪些按钮，都由它决定。
:::

## 三种角色分别能做什么

| 角色（界面显示名） | 能做什么 | 不能做什么 |
| --- | --- | --- |
| 管理员 | 管理本租户的工作空间、成员和配额；对实例、镜像、模板、存储卷可以做完整操作 | 只能管自己所在的租户，看不到别的租户 |
| 开发 | 完整操作实例（创建、启动、停止、删除等）；查看工作空间、镜像、模板 | 不能管理成员和配额；镜像和模板只能看不能改；不能新建或修改工作空间 |
| 普通成员 | 查看工作空间、实例、镜像 | 不能创建或操作实例；不能管理成员、配额、模板、存储卷 |

:::info 同一个角色，两处叫法略有不同
租户管理 **成员** 页签的表格里，这三种角色显示为 **管理员**、**开发**、**普通成员**；
**概览** 页签左侧的成员列表里则显示为 **管理员**、**开发者**、**成员**。
指的是同一套角色，只是两处文案没统一。
:::

:::info 系统管理员
还有一种特殊的管理员：不属于任何租户的管理员，平台会把它视为系统管理员，拥有全部权限。
通常只有平台运维人员才是这种账号。
:::

## 在哪里看到自己是什么角色

1. 点击右上角头像，在弹出的菜单里点击 **租户**，菜单上会显示你当前所在租户的名字。
2. 进入租户管理页后点击 **成员** 页签（只有管理员能看到这个页签）。
3. 在成员表格里找到你自己的用户名，**角色** 列就是你在这个租户里的角色。

如果你的账号不是管理员、看不到 **成员** 页签，可以退一步看 **概览** 页签的成员列表：
用户名下方的小字同样是角色，只是那里不是按列排的。两处都找不到，说明你当前的角色看不到成员信息，
需要向租户管理员确认一下自己的角色。

成员表格长这样，第一列是 **用户名**、第三列是 **角色**：

## 角色改了为什么不立刻生效

平台在你登录时读取一次角色，之后一直用这份数据控制菜单和按钮。
如果管理员刚刚调整了你的角色，你需要刷新页面或重新登录一次，菜单才会跟着变化。

## 一些要知道的规则

- 角色是「在某个租户里」生效的。你在 A 公司是管理员，在 B 公司可能只是普通成员。
- 如果某个菜单看不到、某个按钮点不动，多半是角色权限不够，而不是页面出错了。
- 改昵称、换头像都不会影响你的角色。
