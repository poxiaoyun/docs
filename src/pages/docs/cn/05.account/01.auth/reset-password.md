# 重置密码

忘记密码时，你会从登录页的「忘记密码？」进入这个页面。这一页会说明页面上有什么、
点击之后会发生什么，以及现在该怎样真正把密码改回来。

:::warning 目前还不能自助重置
这个页面已经搭好了界面，但还没有接通发送邮件的功能：填写邮箱并点击 **发送** 之后，
页面不会真的发出邮件，也不会跳到下一步。想改密码请直接联系平台管理员，由管理员在后台为你重置。
:::

## 从登录页进入

1. 打开登录页。
2. 点击密码输入框下方的 **忘记密码？**。
3. 页面跳转到忘记密码页。

## 页面上有什么

| 元素 | 说明 |
| --- | --- |
| 标题 | 忘记密码？ |
| 说明文字 | 请输入您的邮箱地址，我们将发送一封包含重置密码链接的邮件到您的邮箱 |
| **邮箱** 输入框 | 填写你注册时使用的邮箱 |
| **发送** 按钮 | 点击后按钮显示「发送中...」 |
| **返回登录** 链接 | 回到登录页 |

页面只有这一张卡片，没有别的入口：

## 现在的实际行为

1. 在 **邮箱** 输入框里填写你的邮箱地址；格式不对时输入框下方会提示「请输入正确的邮箱地址」。
2. 点击 **发送**。
3. 页面短暂显示「发送中...」，随后停止，**不会发送邮件，也不会跳转或提示成功**。

:::warning 想改密码怎么办
请直接联系平台管理员，说明你的账号和需要重置密码，由管理员在后台处理。
:::

## 修改成功之后怎么登录

管理员重置后，用新密码在登录页登录即可，详见 [登录](/account/auth/login)。
