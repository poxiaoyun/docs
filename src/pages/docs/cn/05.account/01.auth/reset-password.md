# 重置密码

忘记密码时，你会从登录页的 **忘记密码？** 进入这一页。需要先说清一件事：
**这一页不提供自助找回密码**，它只给出一条提示和一个返回链接。这篇会讲清页面上到底有什么，
以及忘记密码时你到底能做哪三件事。

:::warning 这一页没有输入框
它不是「填邮箱 → 收重置链接」的流程。页面上没有邮箱输入框、没有发送按钮、也不会发邮件，
看到这里请直接看下面的「忘记密码怎么办」。
:::

## 从登录页进入

1. 打开登录页。
2. 在密码输入框下方点击 **忘记密码？**。
3. 进入页面，你只会看到三样东西：

| 页面上有什么 | 内容 |
| --- | --- |
| 标题 | **忘记密码？** |
| 提示 | **当前平台尚未提供自助找回密码。请联系平台管理员重置密码；如已开通验证码或第三方登录，也可返回登录页使用这些方式。** |
| 链接 | **返回登录** |

![忘记密码页：标题、一行不可自助找回的提示、返回登录链接](/assets/screenshots/account/reset-password-01.png)

:::info 为什么还要留这一页
这个入口仍然保留，是为了在你点错时明确告诉你「这里没有自助重置」，而不是让你在一堆表单里猜。
:::

## 忘记密码怎么办

按你能拿到的条件，从下面三条里选一条：

1. **联系平台管理员重置。** 告诉管理员你的用户名，请他为你设置新密码。这是唯一一定能走通的路。
2. **改用验证码登录。** 如果平台开通了 **邮箱验证码** 或 **短信验证码** 登录，返回登录页切到这两种方式，
   不输密码也能进去。进去以后再到 **个人设置 → 账户安全** 自己设一个新密码。
3. **改用第三方登录。** 如果之前绑定过第三方账号，返回登录页点对应的服务商按钮即可进入。

:::tip 推荐顺序
先试第 2、3 条，都不用等人；两条都不可用时再联系管理员。
:::

## 登录后自己改密码

能进平台之后，改密码不需要管理员：点击右上角头像 → **个人设置** → **账户安全**，
在 **密码** 一行点 **修改密码**（从未设过密码的账号显示 **设置密码**）。
需要填旧密码、新密码和确认密码。详细步骤见 [账户安全](/account/iam/security)。
