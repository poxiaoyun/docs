# 注册

注册就是创建一个属于你自己的平台账号。注册页会填什么，取决于平台开放了哪些注册通道：
可能要求邮箱、手机号或两者都要，也可能还要设置密码。这篇按「页面上出现什么就填什么」的方式讲，
读完你能独立完成一次注册，并知道注册成功后该做什么。

:::tip 注册和登录是分开的
注册只负责创建账号，不会顺便帮你登录。注册成功后页面会就地显示 **注册成功**，
你点旁边的 **去登录** 再登录一次。
:::

## 开始之前

- 确认平台开放了自助注册：登录页底部出现 **没有账户？ 去注册** 才有入口。
- 准备好要用的邮箱或手机号，并且能收到验证码。
- 如果平台要求设置密码，先想好一个符合页面提示要求的密码。

:::warning 看不到「去注册」= 当前平台不允许自助注册
这种情况下联系平台管理员为你开通账号，页面上的任何入口都开不出账号。
:::

## 注册页有哪些字段

注册页是一张卡片，从上到下是这些内容。**不是每个字段都会出现**，取决于平台开放了哪些通道。

| 字段 | 什么时候出现 | 怎么填 |
| --- | --- | --- |
| **用户名** | 总是出现 | 你以后登录用的账号名，必填 |
| **密码** | 平台开放了密码注册时 | 按密码框下方的规则提示填，见下文 |
| **确认密码** | 与 **密码** 同时出现 | 再输一遍密码，必须完全一致 |
| **邮箱** 或 **手机号码** | 看平台开放的注册方式 | 二选一，切换控件在最上方；填哪一个就收哪一个的验证码 |
| **验证码** | 该通道要求验证时出现 | 点右侧 **发送验证码**，把收到的验证码填进来 |
| **协议勾选** | 总是出现 | 必须勾选，否则 **注册账户** 点不动 |

:::info 只有一种联系方式时没有切换控件
平台只开邮箱或只开手机号时，注册卡片顶部不会出现切换控件，直接显示那一个字段。
:::

## 注册步骤

1. 在登录页底部点击 **去注册**。
2. 如果需要选注册方式，先在卡片顶部切到 **邮箱** 或 **手机号码**。
3. 填写 **用户名**。
4. 如果页面出现密码字段，填写 **密码** 和 **确认密码**。
5. 填写 **邮箱** 或 **手机号码**。手机号要带国际区号，例如中国大陆是 `+86`。
6. 点击 **验证码** 输入框右侧的 **发送验证码**，去邮箱或短信里取验证码并填入。
7. 勾选 **我已阅读并同意《服务条款》与《隐私政策》。**
8. 点击 **注册账户**，按钮上会短暂显示 **注册中...**。

## 密码有什么要求

密码规则由平台配置，**以密码框下方那几行提示为准**。常见的是这三条，页面会按实际配置显示：

- 至少 N 个字符（N 由平台设定）。
- 包含大小写字母和数字。
- 包含特殊字符。

:::tip 两次密码必须一致
两次输入不一致时，**确认密码** 下方会提示 **密码不一致**，改到一致才能提交。
:::

## 关于联系方式

- 只填平台开放的那一种：它既是你的联系方式，也是接收验证码的地方。
- 手机号必须是合法号码，格式不对时提交会在字段下方提示；填写时带上国际区号。
- 改动邮箱或手机号之后，之前收到的验证码立即失效，需要重新发送。

## 可能的「安全验证」弹窗

点 **注册账户** 后，如果平台判定这次提交需要验证，会弹出 **安全验证** 窗口：
按窗口提示输入图形验证码或拖动滑块，验证通过后注册继续完成，不需要重新填表。

## 注册结果

| 结果 | 你会看到 | 下一步 |
| --- | --- | --- |
| 成功 | 卡片就地变成绿色提示 **注册成功**，右边有 **去登录** 链接 | 点 **去登录**，用新账号登录 |
| 失败 | 表单上方出现红色提示，说明原因 | 按提示修改后重新提交，草稿会保留 |
| 没有可用通道 | **当前没有可用的注册方式，请联系平台管理员。** | 找平台管理员开通 |

:::warning 注册成功不会自动登录
页面停在这里不会自己跳走，也不会自动登录。请点 **去登录** 手动登录一次。
:::

## 注册之后

新账号默认不属于任何租户。首次登录后需要创建或加入一个租户才能开始使用平台，
具体见 [选择/注册租户](/account/auth/select-tenant)。
