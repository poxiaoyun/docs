# 选择/注册租户

租户可以理解成**一家公司在平台上的独立账号空间**。同一家公司的成员、数据、算力和配额
都放在同一个租户里，不同租户之间互相看不到对方的东西。登录平台后，你要先选定一个租户才能开始干活。

:::tip 类比
把平台想成一栋写字楼，租户就是楼里的一家公司。你可以同时属于多家公司（拥有多个租户），
登录后先选今天要进哪一家，再开始工作。
:::

## 开始之前

- 先完成登录。还没有账号，见 [注册](/account/auth/register)。
- 如果下拉框里一个租户都没有，你需要先创建一个（见下文），或请管理员把你加进他的租户。

## 什么时候会看到这个页面

- 登录成功后，你属于多个租户、且平台没有记住上次进入的租户时，会停在这里。
- 只属于一个租户、或上次的租户仍然有效时，平台会直接进入，跳过这一页。
- 在平台内想换一家公司时，点击右上角头像 → 抽屉底部的 **切换租户**，也会回到这一页。

## 选择已有租户

1. 页面标题是 **{你的昵称}您好，选择您的租户**（没有昵称时显示 **选择您的租户**），下方一行说明
   **请选择您的租户或创建一个新租户**。
2. 点击 **租户** 下拉框，列表里列出你可以进入的全部租户。
3. 选中你要进入的租户。
4. 点击 **进入平台**，按钮上会短暂显示 **进入中...**。
5. 进入后就是该租户的首页。

:::tip 只有一个租户时会自动进入
账号只属于一个租户时，这一页会直接跳过，你几乎看不到它。
:::

## 关于被禁用的租户

下拉框里有些租户右侧带有红色的 **禁用** 标签。这类租户当前不可进入：

- 它们排在列表最后；
- 无法选中，也就无法进入。

如果某个你需要的租户被禁用了，联系平台管理员。

## 创建一个新租户

如果你还没有任何租户，或者想为自己新开一家公司空间：

1. 在选择租户页面，点击下方的 **没有租户？ 创建租户** 里的 **创建租户**。
2. 新页面标题是 **创建租户**，说明是 **为您自己创建一个租户**。
3. 填写下面三个输入框，三项都必填。
4. 点击 **创建租户**，按钮上会短暂显示 **创建账户...**。
5. 创建成功后，卡片就地显示 **租户创建成功** 和 **进入平台** 链接；点 **进入平台** 才真正进去。

| 输入框 | 怎么填 |
| --- | --- |
| **名称** | 这个租户的名字，例如你的公司名或团队名 |
| **邮箱** | 用于联系的邮箱地址，要符合邮箱格式 |
| **手机号码** | 用于联系的手机号，要符合号码格式 |

:::warning 创建成功不会自动进入
页面只给一个 **进入平台** 链接，不会自己跳转。没点它之前，你仍然停在创建页。
:::

创建过程中想放弃，可以点击页面下方的 **选择租户** 返回上一步。

:::info 新建的租户你是管理员
谁创建租户，谁就是这个租户的 **管理员**，之后可以在里面管理成员和配额。
:::

## 退出登录

在选择租户页面底部点击 **退出登录**，可以退出当前账号并回到登录页。
