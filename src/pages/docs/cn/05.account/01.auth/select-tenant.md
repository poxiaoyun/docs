# 选择/注册租户

租户可以理解成**一家公司在平台上的独立账号空间**。同一家公司的成员、数据、算力和配额
都放在同一个租户里，不同租户之间互相看不到对方的东西。登录平台后，你要先选一个租户才能开始干活。

:::tip 类比
把平台想成一栋写字楼，租户就是楼里的一家公司。你可以同时属于多家公司（拥有多个租户），
登录后先选今天要进哪一家，再开始工作。
:::

## 什么时候会看到这个页面

- 每次登录成功后都会先经过这个页面。
- 在平台内想换一家公司时，点击右上角头像 → **切换租户**，也会回到这个页面。

## 选择已有租户

1. 登录成功后，页面显示问候语和「请选择您的租户或创建一个新租户」。
2. 点击 **租户** 下拉框，列表里会显示你可以进入的所有租户。
3. 选中你要进入的租户。
4. 点击 **进入平台**，按钮上会短暂显示「进入中...」。
5. 进入后就是该租户的平台首页。

:::tip 只有一个租户时会自动进入
如果你的账号只属于一个租户，页面会跳过选择、自动进入该租户，你几乎看不到这一步。
:::

## 关于被禁用的租户

下拉框里可能有些租户右侧带有红色的 **禁用** 标签。这类租户当前不可进入：

- 它们排在列表最后；
- 你无法选中它们，也就无法进入。

如果某个你需要的租户被禁用了，请联系平台管理员。

## 创建一个新租户

如果你还没有任何租户，或者想为自己新开一家公司空间：

1. 在选择租户页面，点击下方的 **创建租户** 按钮。
2. 新页面显示「创建租户」和「为您自己创建一个租户」。
3. 填写下表三个输入框。
4. 点击 **创建租户**，按钮上会短暂显示「创建账户...」。
5. 创建成功后系统会直接带你进入这个新租户的平台首页。

| 输入框 | 怎么填 |
| --- | --- |
| 名称 | 这个租户的名字，例如你的公司名或团队名 |
| 邮箱 | 用于联系的邮箱地址 |
| 手机号码 | 用于联系的手机号 |

:::warning 三个输入框都是必填
名称、邮箱、手机号码都必须填写，且邮箱要符合邮箱格式，否则无法提交。
:::

创建过程中想放弃，可以点击页面下方的 **选择租户** 返回上一步。

## 退出登录

在选择租户页面底部点击 **退出登录**，可以退出当前账号并回到登录页。
