# 第三方登录

第三方登录是把你在别处已有的账号（企业微信、OIDC 身份源等，具体看平台接入了哪些）绑定到平台账号上。
绑定之后，登录页上就多一个可以直接点的入口，不用再输账号密码。

:::tip 类比
账号密码是你自己配的一把钥匙，第三方登录是把公司门禁卡也登记成能开这扇门。
卡丢了还能用钥匙，钥匙忘带了还能刷卡。
:::

## 开始之前

- 已经登录平台。绑定动作在登录之后做，因为绑定的是**当前这个账号**。
- 你能登录要绑定的那个第三方账号。
- 平台接入了至少一种第三方登录方式；一种都没有时这一页只有空态。

## 在哪里

1. 点击右上角头像 → **个人设置**。
2. 点击页签 **账户安全**，往下找到分组 **第三方登录**。
3. 分组说明是 **管理可用于登录的第三方账号关联。**

## 看到哪些行

| 行的来源 | 说明 |
| --- | --- |
| 平台当前接入的服务商 | 每个服务商一行，图标和名字取自平台配置 |
| 已绑定但平台不再提供的服务商 | 仍会列在这里，方便你把它解绑 |

每行右侧是状态标签：**已绑定** 或 **未绑定**。已绑定的行在标签旁还会显示该第三方账号的标识，
方便你确认绑的是哪一个账号。

![账户安全的「第三方登录」分组：每个服务商一行，右侧是已绑定/未绑定标签与绑定或解绑操作](/assets/screenshots/account/linked-accounts-01.png)

## 绑定

1. 在要绑定的服务商那一行，点击 **绑定**。
2. 浏览器跳到该服务商的登录/授权页。
3. 用你要绑定的那个第三方账号登录，并同意授权。
4. 授权完成后自动回到本页，该行状态变成 **已绑定**。

:::warning 授权没走完就等于没绑
在服务商页面关掉窗口或拒绝授权时，不会产生绑定关系，页头会提示失败原因，重新点 **绑定** 即可。
:::

## 解绑

1. 在已绑定的那一行，点击 **解绑**。
2. 弹出确认窗，标题是 **解绑 {服务商}**，正文写明影响：
   **解绑后你将无法再使用该第三方账号登录。**
3. 确认后解除绑定，状态回到 **未绑定**，页头提示 **已解绑第三方账号**。

:::warning 解绑前先确认还有别的登录方式
如果这个账号你一直只用第三方登录，解绑后可能进不来。请先确认自己记得密码，
或平台开通了 **邮箱验证码** / **短信验证码** 登录；都没有时，先找平台管理员确认再解绑。
:::

## 空态

平台没有接入任何第三方登录方式时，这个分组显示 **没有可用的第三方登录方式**。
需要开通请联系平台管理员。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 登录页看不到第三方按钮 | 平台没有接入，或没有为你所在的部署开启 | 联系平台管理员 |
| 绑定后登录页仍只有密码输入 | 第三方按钮只在平台开启该方式时显示 | 刷新登录页；仍然没有就联系管理员 |
| 绑定失败并提示回调无效 | 授权页停留太久或链接被重复使用 | 重新点一次 **绑定**，一次走完 |
