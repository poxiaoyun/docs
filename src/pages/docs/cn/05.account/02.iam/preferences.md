# 偏好设置

**偏好设置** 是个人设置的最后一个页签，只提供三项：**偏好模式**、**色彩**、**语言偏好**。
改动保存在你的账号上，换浏览器、换电脑登录后仍然生效；它只影响你自己的界面，不影响同事。

:::tip 只改你自己的界面
这里调的每一项都只对你生效，同事看到的仍然是他们自己设置的样子。
:::

## 开始之前

- 登录后就能操作，不需要租户角色。
- 想清楚要不要换界面语言：**语言偏好** 改的是账号级设置，和顶部那个语言快捷开关不是一回事。

## 怎么进入

1. 点击右上角头像 → **个人设置**。
2. 点击页签 **偏好设置**。

![偏好设置页：偏好模式的三个选项、六个色彩色板、语言偏好单选，底部保存按钮](/assets/screenshots/account/preferences-01.png)

## 三项设置

| 设置项 | 可选值 | 效果 |
| --- | --- | --- |
| **偏好模式** | **亮色** / **暗色** / **跟随系统** | 整个界面的明暗。没设置过时按 **亮色** 显示 |
| **色彩** | 6 个预设色板：绿色 / 天蓝 / 紫色 / 蓝色 / 橙色 / 红色 | 换掉界面的主色，按钮、链接、选中状态都跟着变 |
| **语言偏好** | 中文 / English | 界面语言。**没有选过时不预选**，保持系统当前语言 |

## 改完要保存

1. 按上表选好三项。
2. 点击 **保存**。
3. 保存成功后按钮反馈完成，界面按新设置显示。

:::warning 不点保存就不会生效
这一页不是即时生效的。改了选项但没点 **保存**，离开页面后改动会丢掉。
保存失败时页面会提示 **偏好保存失败，请重试。**（语言单独保存失败时提示 **语言保存失败，请重试。**），
你刚才选的内容会留在表单里，重试即可。
:::

## 和顶部快捷切换的区别

| 你在哪改 | 改了谁 | 会不会写进账号 |
| --- | --- | --- |
| 顶部导航的明暗/语言快捷开关 | 只改当前这个浏览器里的显示 | 不会，换设备登录看不到 |
| **偏好设置** 页 + **保存** | 改你账号上的偏好 | 会，换设备登录后仍然是这个设置 |

:::info 本机选择优先
如果顶部快捷开关把界面切成了暗色，而账号偏好是亮色，你在本机看到的是暗色。
想让所有设备统一，请在这里设置并保存一次。
:::
