# 租户管理

租户是**一家公司在平台上的独立账号空间**。同一家公司的人、算力、数据、配额都放在同一个租户里，
不同租户之间互相看不到。这页讲清租户资料在哪里看和改、成员怎么管，以及常常被找错的
「配额 / 规格 / 工作空间」到底在哪。

:::tip 租户像一栋独立的办公楼
每个租户是一栋楼，楼里的房间（工作空间）、设备（实例）和员工（成员）都归这栋楼所有。
你在不同的楼里，可以被安排成不同的身份。
:::

## 开始之前

- 你能看到什么、能改什么，取决于你在**当前租户**里的角色：改资料和管成员都需要 **管理员**。
- 先进入某个租户。还没选定租户时，看不到这一页的入口。

## 这一页在哪里

1. 点击右上角头像，右侧滑出抽屉。
2. 点击 **租户** 后面跟着当前租户名的那一行。
3. 页面会整页跳到 **租户管理**，地址形如 `/console/iam/tenants/{租户}/overview`。

:::info 它不在个人设置的页签里
租户管理属于公司层面的设置，和个人设置（只管你自己）是两套页面。
切换公司空间请用抽屉底部的 **切换租户**。
:::

## 进去以后能看到什么

左侧导航只有一个分组 **租户管理**，里面是：

| 导航项 | 谁能看到 | 内容 |
| --- | --- | --- |
| **概览** | 当前租户的所有成员 | 概览页有 **基本信息** 和 **成员** 两个页签 |
| **成员** | 只有租户管理员 | 成员名单与增删改 |

如果你是从智算平台进来的，左侧还会多一个 **租户集群** 分组，用于查看这个租户在各集群上的资源。

## 概览：基本信息

**基本信息** 页签是一张资料卡片，从上到下这几行：

| 行 | 说明 |
| --- | --- |
| 头像 | 点击即可上传替换，租户内所有人都会看到 |
| **租户名称** | 公司/团队在平台上的名字 |
| **邮箱** | 租户的联系邮箱，不是你的登录邮箱 |
| **手机号码** | 租户的联系电话 |
| **创建时间** | 只读，不能改 |

修改方式：

1. 在要改的一行点击行尾的 **编辑**（只有管理员能看到这个操作）。
2. 弹出 **编辑{字段名}** 的窗口，里面只有一个输入框，填新值。不能为空，邮箱和手机号还会校验格式。
3. 点击 **保存**，按钮上出现对勾表示已保存。

:::warning 这些改动影响整个租户
租户资料是全体成员共用的，改完所有人都会看到。请确认你改的是**公司**的信息，
而不是你自己的资料（你自己的资料在 **个人设置 → 基本信息**）。
:::

## 概览：成员页签

点 **成员** 页签会切到成员列表，表格有四列：

| 列 | 内容 |
| --- | --- |
| **用户名** | 成员的账号名，旁边带头像和昵称 |
| **邮箱** | 成员的邮箱 |
| **角色** | 该成员在本租户的角色，显示为 **管理员** / **开发** / **普通成员** 等 |
| **加入时间** | 成为本租户成员的时间 |

列表支持搜索、分页；只有管理员能勾选多行并批量 **移除所选成员**。

## 管理成员（仅管理员）

### 添加成员

1. 在左侧导航点击 **成员**，再点右上角的 **添加成员**。
2. 进入表单页，卡片名是 **成员信息**，里面两个字段：

   | 字段 | 怎么填 |
   | --- | --- |
   | **用户** | 输入用户名搜索平台里已有的用户；下拉选项显示为 `用户名 (昵称或邮箱)` |
   | **角色** | 从下拉里选一个角色，选项由平台角色列表提供 |

3. 点击 **确定**。

:::info 没有邀请链接
平台不发邀请邮件，也没有邀请码。要让人加入，先让他注册好账号，再由管理员在这里搜到他并添加。
:::

### 修改成员角色

在成员列表里点该成员所在行的编辑入口，进入编辑页。**用户** 不能改，只能改 **角色**，改完点 **确定**。

### 移除成员

| 操作 | 怎么做 | 结果 |
| --- | --- | --- |
| 移除单个 | 点该行的删除操作并确认 | 提示删除成员后，该成员不再属于本租户 |
| 批量移除 | 勾选多行，点 **移除所选成员** 并确认 | 标题为 **移除所选租户成员** |

:::warning 移除的是成员关系，不是账号
确认框里写明：**移除所选用户与当前租户的成员关系，用户账号仍然保留。** 被移除的人下次进平台时，
下拉框里就看不到这个租户了；想恢复需要重新添加。
:::

## 配额 / 规格 / 工作空间在哪

**不在这一页。** 它们是「集群维度」的数据，要再往下钻一层：

1. 在左侧导航点击 **租户集群**。
2. 在列表里点某个集群名，进入该集群的详情。
3. 详情里的页签才是 **概览 / 配额 / 规格 / 工作空间**。

详见 [租户集群](/rune/console/tenant-clusters)。

:::info 为什么拆成两层
同一个租户可以在多个集群上都有资源，每一份配额、规格可用量都是按集群分别统计的。
把三层页签平铺在一起会混淆「哪个集群的配额」。
:::

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 左侧没有 **成员** | 你在当前租户不是管理员 | 找租户管理员处理，或让他给你管理员角色 |
| 资料行没有 **编辑** | 同上，只有管理员能改 | 同上 |
| 找不到「配额」入口 | 配额在集群详情里 | 左侧 **租户集群** → 点集群名 |
| 刚被加入却看不到这个租户 | 租户列表还是旧的 | 退出登录再重新登录一次 |
