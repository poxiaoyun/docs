# 租户管理

租户是**一家公司在平台上的独立账号空间**。同一家公司的人、算力、数据、配额都放在同一个租户里，
不同租户之间互相看不到。这页讲清你怎么查看自己属于哪些租户、怎么切换、切换后有什么变化，
以及别人怎么把你加进一个租户。

:::tip 租户像一栋独立的办公楼
每个租户是一栋楼，楼里的房间（工作空间）、设备（实例）和员工（成员）都归这栋楼所有。
你在不同的楼里，可以被安排成不同的身份。
:::

## 开始之前

- 你能看到什么、能改什么，取决于你在**当前租户**里的角色。
- 租户管理不是个人设置里的页签，它有自己的入口（见下）。

## 先记住这几个词

| 名词 | 通俗解释 |
| --- | --- |
| 租户 | 一家公司在平台上的独立账号空间 |
| 成员 | 被加入这个租户的用户 |
| 角色 | 你在租户里的身份，决定你能操作哪些功能 |

## 我属于哪些租户、怎么切换

1. 点击右上角头像，右侧滑出菜单。
2. 菜单顶部显示你的昵称、用户名和邮箱。
3. 菜单里有一项 **租户**，后面跟着你**当前所在租户**的名字。
4. 要查看或切换其他租户，点击菜单底部的 **切换租户**。
5. 进入 **选择您的租户** 页，在 **租户** 下拉框里选择要进入的租户。
6. 点击 **进入平台**。

下拉框里列出的是你**全部**可进入的租户。如果某个租户后面标着 **禁用**，说明它已被停用，无法选择。
如果你只有一个租户，系统会直接把你送进去，不显示这一页。

:::tip 没有租户怎么办
在 **选择您的租户** 页底部点击 **创建租户**，填写名称、邮箱和手机号码，就能给自己建一个新租户，
建好后你就是它的管理员。
:::

## 切换租户后有什么不一样

| 会变的东西 | 说明 |
| --- | --- |
| 菜单 | 只显示你在新租户里有权限的功能 |
| 数据 | 实例、存储卷、成员、配额等都换成新租户的，旧租户的数据看不到 |
| 角色 | 同一个人在不同租户里可以是不同角色，权限也随之变化 |

切换回原来的租户，看到的数据和权限又会回到原来的样子。

## 进入租户管理页

1. 点击右上角头像。
2. 点击菜单里的 **租户**（后面跟着当前租户名）。
3. 进入租户管理页，顶部是一排页签。

**概览** 页签把租户信息、算力资源、工作空间和成员放在一屏里：

![租户管理概览页：顶部是概览/成员/配额/规格/工作空间页签，左侧卡片显示租户头像、租户名称、邮箱、手机号码和创建时间（邮箱与手机号已打码），右侧是算力资源、工作空间统计、最近工作空间和成员列表](/assets/screenshots/account/tenant-01.png)

## 页签能做什么

| 页签 | 需要什么角色 | 能做什么 |
| --- | --- | --- |
| 概览 | 管理员 / 开发 | 看租户信息、成员、配额、工作空间和最近事件 |
| 成员 | 仅管理员 | 添加、修改、删除成员 |
| 配额 | 管理员 / 开发 | 查看各集群的算力额度 |
| 规格 | 管理员 / 开发 | 查看可用的算力规格 |
| 工作空间 | 管理员 / 开发 | 查看租户下的工作空间 |

具体能看到哪几个页签，和你从哪个产品进入、以及你的角色有关。权限不够的页签不会显示。

## 查看和修改租户信息

概览页左侧的 **租户信息** 卡片显示租户头像、租户名称、邮箱、手机号码和创建时间。

1. 只有**管理员**能修改。点击字段右侧的铅笔图标进入编辑。
2. 在输入框里填新值。

   | 设置项 | 怎么填 | 改了会发生什么 |
   | --- | --- | --- |
   | 租户头像 | 点击头像上传并裁剪 | 整个租户的成员都会看到新头像，只影响这个租户 |
   | 租户名称 | 填写新名称，不能为空 | 成员在头像菜单、切换租户页看到的名字都会变 |
   | 邮箱 | 填写租户联系邮箱，格式要正确 | 改的是租户的联系邮箱，不是你的登录邮箱 |
   | 手机号码 | 填写租户联系电话，不能为空 | 改的是租户的联系电话 |
   | 创建时间 | 只读 | 无法修改 |

3. 点击 **确定** 保存，点击 **取消** 放弃这次修改。

:::warning 这些改动影响整个租户
租户信息是全体成员共用的，改完所有人都会看到。请确认你改的是**公司**的信息，
而不是你自己的个人信息。
:::

概览页还会显示成员统计、成员列表、配额、工作空间和 **最近事件**（按时间倒序显示最近的操作记录），
具体出现哪几块取决于你的角色，以及你是从哪个产品进来的。

## 管理成员（仅管理员）

### 添加成员

1. 进入 **成员** 页签。
2. 点击右上角的 **添加成员**。
3. 在 **用户** 下拉框里搜索并选择要加入的人，选项会显示用户名和昵称或邮箱。
4. 在 **角色** 下拉框里选择要给他的角色。
5. 点击 **确定**。

### 修改成员角色

在成员表格里点击该成员所在行的编辑入口，改好角色后点击 **确定**。

### 删除成员

勾选要移除的成员（可以多选），点击删除并在确认框中确认。
成员表格默认显示**用户名、邮箱、角色、加入时间**四列。

:::warning 删除成员会立即生效
被移除的人下次切换租户时，下拉框里就看不到这个租户了。删除前请确认对方确实不再需要访问。
:::

成员管理在 **成员** 页签里，表格默认四列：用户名、邮箱、角色、加入时间。

![租户管理的成员页签：上方是搜索框和添加成员按钮，表格列出用户名、邮箱、角色、加入时间四列，邮箱列已打码](/assets/screenshots/account/roles-01.png)

## 别人怎么把我加进租户

平台没有「邀请链接」这一说，加入租户靠管理员把你加进去：

1. 你先注册好自己的平台账号。
2. 把你的**用户名**（或注册邮箱）告诉租户管理员。
3. 管理员在 **租户管理 → 成员 → 添加成员** 里搜索你、选好角色、点击 **确定**。
4. 你重新登录后，在 **选择您的租户** 页的下拉框里就能看到这个租户，选中后点击 **进入平台**。

:::tip 下拉框里没出现新租户
先退出登录再重新登录一次，让页面重新拉取你的租户列表。
:::
