# 个人设置

个人设置是管理「你自己」的地方：头像昵称、密码、二次验证、访问密钥、界面外观都在这里改。
它和租户管理不同——这里每一项都只影响你自己，不会动到同事。

:::tip 类比
租户管理像公司行政，改的是整家公司的信息；个人设置像你的工牌和办公桌，只调你一个人的东西。
:::

## 开始之前

- 只要登录了就能打开，不需要任何租户角色。
- 打开时会整页跳到账户应用，左上角的返回按钮会带你回到进来时的那一页。

## 怎么进入

1. 点击右上角头像，右侧滑出抽屉。
2. 点击抽屉里的 **个人设置**。
3. 进入后页面标题是 **个人设置**，标题下面一排四个页签，默认停在 **基本信息**。

![个人设置顶部：标题、返回按钮与四个横向页签（基本信息 / 账户安全 / 访问密钥 / 偏好设置）](/assets/screenshots/account/profile-01.png)

## 四个页签

| 页签 | 管什么 | 详细步骤 |
| --- | --- | --- |
| **基本信息** | 头像、昵称、邮箱、手机号码；用户名只读 | [基本信息](/account/iam/profile) |
| **账户安全** | 改密码 / 设置密码、多因素认证、第三方登录的绑定与解绑 | [账户安全](/account/iam/security) · [第三方登录](/account/iam/linked-accounts) |
| **访问密钥** | 给程序用的 API Key，连接仓库用的 SSH 公钥 | [API Key](/account/iam/api-key) · [SSH 密钥](/account/iam/ssh-key) |
| **偏好设置** | 偏好模式（亮色/暗色/跟随系统）、色彩、语言偏好 | [偏好设置](/account/iam/preferences) |

:::info 邮箱和手机号码在「基本信息」里改
它们不是独立页签。进入 **基本信息**，在对应一行点 **修改**（未绑定时是 **添加**），
在弹出的窗口里填新地址并接收验证码。
:::

## 不在个人设置里的两件事

| 你想做的事 | 去哪 |
| --- | --- |
| 切换公司空间 | 头像抽屉底部的 **切换租户**，详见 [选择/注册租户](/account/auth/select-tenant) |
| 看租户资料、管理成员 | 头像抽屉里的 **租户 {租户名}** 一行，详见 [租户管理](/account/iam/tenant) |
