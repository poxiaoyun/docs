# 基本信息

**基本信息** 是个人设置的第一个页签，用来看和改你自己的身份资料：头像、昵称、邮箱、手机号码。
用户名（登录用的账号名）在这里只能看不能改。改密码、管二次验证、换界面外观在别的页签。

:::tip 昵称和用户名不是一回事
用户名是你登录时用的账号，在系统里唯一、不能改；昵称是别人在成员列表、头像抽屉里看到的名字，可以随时换。
:::

## 开始之前

- 登录后就能操作，不需要任何租户角色。
- 换绑邮箱或手机号前，先确认你能登录**新邮箱**、拿到**新手机号**，验证码会发到新地址上。

## 这一页有哪几行

| 行 | 能做什么 | 说明 |
| --- | --- | --- |
| **头像** | 点击上传 | 上传成功立即生效，不需要点保存 |
| **用户名** | 只读 | 系统里的唯一标识，没有修改入口 |
| **昵称** | 行尾 **修改** | 弹窗里改，保存后生效 |
| **邮箱** | 行尾 **修改**（未绑定时是 **添加**） | 需要新邮箱收到的验证码；未绑定时值显示 **未绑定** |
| **手机号码** | 行尾 **修改**（未绑定时是 **添加**） | 需要新手机号收到的短信验证码；未绑定时值显示 **未绑定** |

## 怎么进入

1. 点击右上角头像 → **个人设置**。
2. 默认就停在 **基本信息** 页签；从别的页签切回来点一下 **基本信息** 即可。

![基本信息页：左侧头像上传区，右侧依次是用户名（只读）、昵称、邮箱、手机号码四行，每行行尾有修改入口](/assets/screenshots/account/profile-01.png)

## 改头像

1. 点击头像区域，选择本地图片。
2. 在弹出的裁剪窗口里缩放、旋转，调整好构图。
3. 确认上传。

图片要求：常见图片格式（JPEG、PNG、WebP 等），**大小不超过 3 MB**。

:::info 头像上传即生效
头像不需要点保存，上传成功后所有显示你头像的地方都会换成新图。
:::

## 改昵称

1. 在 **昵称** 一行点击行尾的 **修改**。
2. 弹出 **修改昵称** 窗口，在 **昵称** 输入框里填新名字。不能为空。
3. 点击 **保存**。

窗口关闭、页面上的昵称同步更新，不需要重新登录。

## 改邮箱 / 手机号码

1. 在 **邮箱** 或 **手机号码** 一行点击 **修改**（还没绑定时是 **添加**）。
2. 弹窗里有两个输入框：

   | 输入框 | 怎么填 |
   | --- | --- |
   | **邮箱** 或 **手机号码** | 填要换绑的新地址/新号码，格式要正确；手机号要带国际区号 |
   | **验证码** | 点右侧 **发送验证码**，把**新地址**收到的验证码填进来 |

3. 点击 **保存**。

:::warning 验证码发到新地址，不是旧地址
所以换绑时旧邮箱/旧手机收不到验证码也没关系，只要能登录新地址即可。
:::

## 保存之后

- 保存成功时不会弹「更新成功」提示，**窗口关闭、页面上的值变成新值**就是成功。
- 如果资料写入成功、但页面刷新当前登录信息失败，页头会出现一条提示
  **修改已保存，但当前会话资料刷新失败：…**，右侧带重试。**这时不要重复提交**，
  点重试刷新即可，资料已经存下了。

## 用户名为什么改不了

**用户名** 没有输入框也没有修改入口，这是有意设计——它是你在系统里的唯一标识，
账号、成员记录都靠它对应。确实需要变更时，联系平台管理员处理。
