# 账户安全

**账户安全** 是个人设置的第二个页签，页面上只有两个分组：**密码与认证** 和 **第三方登录**。
密码、多因素认证、第三方账号的绑定与解绑都在这里，改完立即作用于你下一次登录。

:::tip 门和备用钥匙
密码是进门的钥匙；多因素认证相当于在门上再加一道只认你手机的锁；
第三方登录是另一把备用钥匙，钥匙丢了还能从这扇门进来。
:::

## 开始之前

- 登录后就能操作，改的都是你自己账号的设置。
- 修改密码前记好新密码；开启多因素认证前，手机上先装好身份验证器 App。
- 绑定第三方账号时，你需要能登录那个第三方账号。

## 这一页有什么

| 分组 | 里面有什么 |
| --- | --- |
| **密码与认证** | **密码** 一行、**多因素认证** 一行，每行右侧一个状态和行尾操作 |
| **第三方登录** | 平台接入的每个服务商各一行，显示 **已绑定 / 未绑定** 和 **绑定 / 解绑** 操作 |

:::info 邮箱和手机号码不在这里
换绑邮箱、换绑手机号在 **基本信息** 页的行内弹窗里完成，见 [基本信息](/account/iam/profile)。
:::

## 修改密码

1. 点击右上角头像 → **个人设置** → **账户安全**。
2. 在 **密码** 一行点击行尾操作。有密码时是 **修改密码**，从未设过密码时是 **设置密码**。
   这一行的说明文字会告诉你当前状态：**通过当前密码验证后设置新密码。** 或 **尚未设置密码，设置后可用密码登录。**
3. 弹窗里按下面填：

   | 输入框 | 什么时候出现 | 怎么填 |
   | --- | --- | --- |
   | **旧密码** | 只有已设置过密码时出现 | 现在正在用的密码，填错无法提交 |
   | **新密码** | 总是出现 | 按字段下方提示的规则填写，规则由平台配置 |
   | **确认密码** | 总是出现 | 再输一遍新密码，必须完全一致 |

4. 点击 **保存**。

:::warning 两个常见校验提示
**新旧密码不能相同**：新密码和旧密码一样，换一个没用过的。
**密码不一致**：两次输入的新密码不同，重新输入两遍。
:::

:::info 密码强度要求不是固定的
**新密码** 下方的提示来自平台配置，可能是「至少 N 个字符」「包含大小写字母和数字」「包含特殊字符」中的一条或几条，
以你看到的为准。改完不会把你踢下线。
:::

## 多因素认证

**多因素认证** 一行右侧是状态标签：**未启用** 或 **已启用**。下面的说明是
**设置身份验证器后，登录时需提供应用生成的验证码。**

- 未启用时，行尾操作是 **设置身份验证器**。
- 已启用时，行尾操作是 **更换身份验证器**。

两种情况都会弹出扫码窗口，操作步骤、恢复码的保存方式、以及登录时怎么过二次验证，
都在 [多因素认证](/account/auth/mfa) 里。

:::warning 这里没有停用开关
页面只能设置或更换身份验证器，不能关掉多因素认证。
:::

## 第三方登录

这个分组列出平台已接入的第三方登录方式，每个服务商一行，右侧是 **已绑定** 或 **未绑定**。

| 状态 | 行尾操作 | 点了会怎样 |
| --- | --- | --- |
| **未绑定** | **绑定** | 跳到该服务商的授权页，同意后回到本页，状态变成 **已绑定** |
| **已绑定** | **解绑** | 弹出确认窗 **解绑 {服务商}**，确认后解除绑定 |

:::warning 解绑会影响你的登录方式
确认窗里写明 **解绑后你将无法再使用该第三方账号登录。** 如果你平时只用它登录，
请先确认自己记得密码，或已经开通了验证码登录。
:::

没有接入任何第三方登录时，这个位置显示 **没有可用的第三方登录方式**。完整的绑定/解绑说明见
[第三方登录](/account/iam/linked-accounts)。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 点 **修改密码** 提示新旧密码不能相同 | 新密码和旧密码一样 | 换一个没用过的密码 |
| 提示密码不一致 | 两次输入的新密码不同 | 重新输入两遍一致的新密码 |
| 新密码总被提示不合规 | 不满足字段下方列出的规则 | 按提示逐条满足（长度、大小写与数字、特殊字符） |
| 收不到换邮箱/换手机号的验证码 | 验证码发到**新**地址 | 检查新地址是否填对，见 [基本信息](/account/iam/profile) |
