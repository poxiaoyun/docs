# SSH 密钥

SSH 密钥是一对配套的「钥匙」，让你连接 Git 仓库或服务器时不用每次都输密码。
平台只保存**公钥**，私钥一直留在你自己的电脑上。这页会带你走完「生成密钥 → 把公钥填进平台」
的完整过程，并说清哪些操作不可逆。

:::tip 公钥像锁，私钥像钥匙
你把锁（公钥）交给平台保管，钥匙（私钥）自己收好。别人拿到锁也打不开你的门，
但只要钥匙泄露，任何人都能冒充你。
:::

## 开始之前

- 这是你自己账号的设置，登录后就能操作，不需要租户角色。
- 你需要能打开本机的终端：macOS 用「终端」，Windows 用 PowerShell。
- 如果你已经生成过密钥，不用重新生成，直接用现有的公钥文件。

## 先分清公钥和私钥

| 名词 | 通俗解释 |
| --- | --- |
| 公钥 | 文件名以 `.pub` 结尾，可以公开，就是要粘贴到平台上的那串内容 |
| 私钥 | 不带 `.pub` 的那个文件，是你真正的钥匙，绝不能发给任何人 |
| 指纹 | 从公钥算出来的一串短编码，用来核对平台上的记录和本地是不是同一把 |

:::warning 只粘贴公钥
平台需要的是公钥。把私钥内容贴进来等于把你的钥匙交出去，任何人都能拿它冒充你。
:::

## 第 1 步：生成密钥对

在终端里执行下面的命令（邮箱只是备注，换成你自己的即可）：

```bash
ssh-keygen -t ed25519 -C "your-email@example.com"
```

执行后一路回车即可，默认会生成两个文件：`~/.ssh/id_ed25519`（私钥）和 `~/.ssh/id_ed25519.pub`（公钥）。
提示设置密码短语时可以直接回车留空。

查看公钥内容，并把它复制下来：

```bash
cat ~/.ssh/id_ed25519.pub
```

Windows PowerShell 用这一条：

```powershell
Get-Content ~/.ssh/id_ed25519.pub
```

公钥通常是**一整行**，以 `ssh-ed25519`、`ssh-rsa` 或 `ecdsa-sha2-nistp256` 开头。

## 第 2 步：把公钥填进平台

1. 点击右上角头像 → **个人设置**。
2. 点击页签 **访问密钥**，找到下方的 **SSH 密钥** 区块。
3. 点击区块右侧的 **添加 SSH 密钥**，弹出同名窗口。
4. 在窗口里填两项：

   | 输入框 | 怎么填 |
   | --- | --- |
   | **密钥名称** | 列表里显示的名字，例如 `我的工作电脑`。不能为空 |
   | **公钥内容** | 粘贴上一步复制的**整行**公钥。下方帮助文字会提示公钥文件通常在哪 |

5. 点击 **添加**。

:::tip 名称可以偷懒
先粘贴公钥、名称还空着时，页面会自动用公钥末尾的注释（通常是生成时填的邮箱）补上名称。
公钥末尾没有注释就手动填一个。
:::

## 结果确认

- 页头出现绿色提示 **SSH 密钥添加成功**。
- 窗口关闭，列表里多出一行：名称、指纹、创建时间。

## 同一把密钥能用在哪

| 场景 | 能不能用 | 建议 |
| --- | --- | --- |
| 同一台电脑连接多个平台 | 可以，把同一份公钥分别添加过去即可 | 私钥不用动 |
| 多台电脑共用一个身份 | 可以，但需要把私钥复制到每台机器上 | 更推荐每台电脑各生成一把 |
| 某台电脑不再使用 | 在列表里删掉对应的那一条 | 其他电脑不受影响 |

每台电脑单独生成密钥的好处是：万一某台设备丢失，删掉它那一条就能单独作废，不用连累其他设备。

## 删除密钥

1. 在 **SSH 密钥** 列表里找到要删的那一行。
2. 点击行尾的 **删除**。
3. 弹出确认窗，标题是 **删除 SSH 密钥 {名称}**，正文说明删除后无法撤销。
4. 确认后页头提示 **SSH 密钥删除成功**。

:::warning 删除无法撤销
删除后这把公钥会从平台移除，使用对应私钥的连接会立即失效。要用回来只能重新添加一次。
:::

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 提交时提示 **请输入密钥名称** | 名称为空，且公钥末尾没有注释 | 手动填一个名称 |
| 提交时提示 **请输入公钥内容** | 公钥框是空的 | 回到终端重新复制 `.pub` 文件的整行内容 |
| 添加成功但连不上 | 平台上是公钥，本地用的私钥不是同一对 | 核对列表里的指纹与本地私钥是否匹配 |
| 私钥丢了 | 私钥不在平台上，平台无法帮你找回 | 在本地重新生成一对，把新公钥添加进来，删掉旧的那条 |
