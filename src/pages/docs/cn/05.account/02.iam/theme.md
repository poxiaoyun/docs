# 主题设置

主题设置就是个人设置里的 **主题** 页签，用来调你自己的界面外观：明暗、对比度、紧凑程度、
主题色、字体和字号。改完立即生效，不用点保存按钮。

:::tip 只改你自己的界面
这里调的每一项都只对你自己的浏览器生效，同事看到的是他们自己设置的样子。
:::

## 开始之前

- 登录后就能操作，不需要租户角色。

## 怎么进入

1. 点击右上角头像 → **个人设置**。
2. 点击顶部的 **主题** 页签。

## 每一项怎么调

| 设置项 | 怎么调 | 改了会发生什么 |
| --- | --- | --- |
| 模式 | 打开或关闭卡片上的开关 | 关闭是亮色，打开是暗色，整个界面立刻变亮或变暗 |
| 对比度 | 打开或关闭卡片上的开关 | 打开后界面颜色对比更强，文字更分明 |
| 紧凑 | 打开或关闭卡片上的开关 | 收紧内容间距，一屏能显示更多内容 |
| 预设色彩 | 点击一个色块 | 换掉界面的主色，按钮、链接、选中状态都跟着变 |
| 字体类型 | 点击一张字体卡片 | 换掉界面使用的字体 |
| 字体大小 | 拖动滑块 | 调整界面文字大小，可选 12–20 px，每档相差 1 |

各项的细节：

- **预设色彩**：一共有 6 个色板。改动后点击这一节右侧的 **重置** 可以回到默认颜色。
- **字体类型**：一共有 4 种，卡片上显示的就是字体名（Public Sans、Inter、DM Sans、Nunito Sans）。
- **字体大小**：拖动滑块时上方会实时显示当前像素值。

:::info 紧凑模式不一定看得出来
紧凑只作用于主体布局，而且屏幕宽度要大于 1600px 才明显。窗口不够宽时，开关似乎没反应是正常的。
:::

## 设置存在哪里

| 问题 | 答案 |
| --- | --- |
| 要不要点保存 | 不用，改动立即生效并自动保存 |
| 存在本机还是账号上 | 保存在你的账号上（浏览器本地也留了一份），换浏览器或换电脑登录后仍然生效 |
| 会影响别人吗 | 不会，只影响你自己的界面 |

## 结果确认

- 每次改动界面都会立刻变化，无需刷新页面。
- 退出后重新登录，外观设置仍然是你调过的样子。
