# 概述

这个分区是集群侧组件的索引。动手之前先在这里对一遍：每个组件干什么、要用哪些镜像、
机器和集群是否满足要求。对完再装，能省掉装到一半才发现版本不匹配的返工。

## Kubernetes 是什么

Kubernetes（简称 k8s）是一套开源的容器编排平台，负责自动部署、扩容和管理容器化的应用。
它把一批机器组成一个集群来统一调度：你提交一个任务，它帮你挑一台合适的机器跑起来。

集群可以理解成一栋机房大楼，每台服务器是大楼里的一间机房。DCU 插在某几间机房里，
但大楼管理处（Kubernetes）一开始并不知道哪间有卡、卡还有没有空位，需要下面这组组件把卡登记进去。

## 组件都有哪些

| 组件 | 一句话说明 | 类比 |
| --- | --- | --- |
| DCU-Label-Node | 检查节点上有没有卡，有就给节点贴标签写明卡的信息 | 给机房挂门牌 |
| DCU-Exporter | 采集卡的温度、功耗、显存、利用率等指标，供监控抓取 | 装在卡上的电表 |
| DCU-Device-Plugin | 把卡注册成集群能分配的资源，业务才能申请使用 | 给卡上户口 |
| vDCU-Scheduler | 与设备插件配合，完成 vDCU 的动态分配 | 给共享卡排座的调度员 |

这几种组件各自独立部署，先说清它们的职责边界：

- **DCU-Label-Node**：以 DaemonSet 形式部署（即每个节点跑一个），运行时检查节点是否存在 DCU，
  存在就自动创建节点标签来描述 DCU 信息。
- **DCU-Exporter**：暴露 DCU / vDCU 的监控指标，可接入 Prometheus，实时监控温度、功耗、显存使用率等。
- **DCU-Device-Plugin**：把 DCU / vDCU 暴露给 Kubernetes，完成资源注册、调度与分配；
  支持物理卡、预切分 vDCU 与动态切分 vDCU。
- **vDCU-Scheduler**：由 `k8s-vdcu-admission-webhook` 与 `k8s-vdcu-scheduler` 两个组件组成，
  与 DCU-Device-Plugin 协同完成 vDCU 动态分配。

## 系统要求

装之前逐项确认，不满足的项要先解决：

| 类别 | 要求 |
| --- | --- |
| 硬件要求 | 安装海光 DCU，目前支持的型号为：Z100L、K100/K100-AI/K100-AI-ECO、BW 系列 |
| 软件要求 | 驱动版本 ≥ 6.2.26；k8s 版本 ≥ 1.18 |
| OS 要求 | Linux（建议 Ubuntu 20.04 及以上、CentOS 7.6 及以上）；不支持 Windows |

驱动版本 ≥ 6.2.26 这条对上具体安装包，大约是 [`rock-6.2.35-V1.6.7d`](/ecosystem/hygon/driver-runtime)
及以后的版本。**组件是拿驱动接口做事，驱动版本不够时组件即使装成功也认不到卡。**

## 版本口径

各组件有一条自己的最低版本线，低于这条线会出现上面「常见问题」里描述的现象。
**镜像标签就是版本号**，落地时按组件包配套给的版本装，不要只单独升某一个组件：

| 组件 | 最低版本 | 低于这条线会怎样 |
| --- | --- | --- |
| DCU-Label-Node | V2.2.0 | 与当前驱动不兼容，节点上加不上 DCU 标签 |
| DCU-Device-Plugin | V2.1.0 | 容器里没有 `/opt/hyhal` 目录，卡在容器内不可用 |
| DCU-Exporter | v2.2.0 | 指标采集异常或标签缺失 |
| vDCU-Scheduler | 与 k8s 集群版本匹配 | 调度器起不来；低版本 k8s 需改 scheduler 配置版本 |

:::warning 组件版本要成套
这一组组件之间有配套关系，平台侧又是手工部署，**升级前先确认这套版本是配套发布的**。
只把设备插件单独升上去，常出现「标签在、资源名不在」这类半通不通的状态。
:::

## 装之前先确认

按顺序执行下面几条命令，输出符合预期再往下走：

### 1. 确认驱动版本与模块已加载

```bash
lsmod | grep -E "hydcu|hycu"
```

能看到驱动模块，说明宿主机侧已就绪。驱动版本可用对应工具查看，需满足 ≥ 6.2.26。

### 2. 确认集群版本

```bash
kubectl version
```

输出中的 Server 版本需 ≥ 1.18。

### 3. 确认操作系统

```bash
cat /etc/os-release
```

确认是受支持的 Linux 发行版与版本。

### 4. 确认镜像可拉取

在节点上检查镜像是否已存在（Docker 场景）：

```bash
docker images | grep -E "dcu-label-node|dcu-exporter|dcu-device-plugin|vdcu"
```

使用 containerd 时改用：

```bash
ctr -n k8s.io c ls | grep -E "dcu-|vdcu"
```

:::warning 驱动版本低于 6.2.26 不要继续
组件依赖 6.2.26 及以上的驱动接口。驱动版本过低时，即使组件安装成功也无法识别到卡。
请先按 [DCU 驱动安装](/ecosystem/hygon/driver-runtime) 升级驱动。
:::
