# 制品与安全

这一页讲**模型、数据集、镜像这些「制品」存在哪，以及它们怎么安全地读写和传输**。
你要建存储、规划容量、给服务配 HTTPS、排查「存储卷创建失败」，就会用到这一层的组件。

:::tip 三类存储先分清
**对象存储** ≈ 网盘，放模型文件、数据集这种大文件，按「桶」组织，通过网址访问（RustFS、MinIO）。
**块存储** ≈ 外接硬盘，给实例挂一块持久盘，读写方式像本地磁盘（Longhorn）。
**本地盘** ≈ 直接征用节点自己的一块硬盘，简单但不跨机器（Local Path Provisioner）。
:::

## 这个分类解决什么问题

| 问题 | 由谁负责 |
| --- | --- |
| 模型、数据集放哪、怎么共享 | RustFS / MinIO（对象存储） |
| 实例重启后文件还在，且能跨节点 | Longhorn（分布式块存储） |
| 只想快速用一台机器的本地盘 | Local Path Provisioner |
| 已经买了 NFS、Ceph、JuiceFS，怎么接进来 | 对应存储插件 |
| 服务要上 HTTPS、证书怎么自动续 | cert-manager |

## 包含哪些组件

| 组件 | 作用 | 关键特性 | 平台里怎么用 |
| --- | --- | --- | --- |
| RustFS（分布式对象存储，0.0.77） | 提供 S3 兼容的对象存储，放大文件和制品 | 默认分布式部署、建议偶数副本、提供 API 端口和控制台端口 | 运维管理 → 存储集群 → 创建存储集群，选 RustFS |
| MinIO（对象存储，5.4.0） | 平台内置的 S3 兼容对象存储 | 随平台部署，作为平台自身的数据和制品存储 | 随平台部署，通常不需要单独安装 |
| Longhorn（分布式块存储，1.10.1） | 给 Pod 提供持久卷，支持跨节点冗余 | 默认 3 副本、数据落在节点本地路径、可选为默认存储类 | 运维管理 → 存储集群 → 创建存储集群，选 Longhorn |
| Local Path Provisioner（本地盘存储，0.0.34） | 用节点本地磁盘提供持久卷 | 部署简单、不跨节点；平台默认存储类就是它 | 运维管理 → 存储集群；不装其他存储时先用它 |
| NFS / CephFS / JuiceFS（外部共享存储） | 把已有的共享存储接成集群可用的存储类 | 直接对接你现有的存储系统，不动原有数据 | 运维管理 → 存储集群 → 创建存储集群，选对应类型 |
| cert-manager（证书管理，1.19.2） | 自动签发和续期 HTTPS 证书 | 到期自动续期，服务不用手动换证书 | 运维管理 → 系统应用，安装证书组件 |

## 用户侧怎么用

存储组件装好后，用户不是直接操作存储集群，而是在**智算平台**里使用：

1. 左侧菜单点击 **文件存储**。
2. 点击 **创建存储卷**。
3. 填写名称、选择**存储集群**、填**容量**、选**访问模式**。
4. 点击**创建**，在列表里等状态变为可用。

创建推理服务、微调任务、开发环境时挂载这块存储卷，实例重启或删除后文件仍然保留。

## 什么时候需要关注它

- **存储卷创建失败**：先到**运维管理 → 存储集群**确认有可用的存储集群，且状态正常。
- **不知道选哪种存储**：要跨节点、要冗余选 **Longhorn**；放大文件、要给多个服务共享选 **RustFS**；只是单机试跑用 **Local Path Provisioner**。
- **节点磁盘被占满**：Longhorn 的数据默认放在节点本地路径下，长期运行要留意磁盘水位并规划扩容。
- **要上 HTTPS**：确认 **cert-manager** 已安装且运行正常，再给服务配置域名和证书。
- **对象存储要长期保存**：在创建存储集群时把数据存储容量和日志存储容量一起规划好。

:::warning 删存储会丢数据
删除存储集群或存储卷通常会连同里面的数据一起删除，且**无法恢复**。操作前请先确认数据已经备份，正在被实例挂载的存储卷不要直接删除。
:::

## 这一页不覆盖什么

平台的开源组件里**没有独立的镜像/依赖扫描（SBOM、漏洞扫描）组件**。如果你需要这类能力，要在自己的构建流水线里接入扫描工具，产物再发布到平台的镜像仓库。
