# 框架与推理生态

这一页讲**模型怎么在平台上跑起来**：推理引擎负责把模型变成可以调用的服务，微调框架负责拿现成模型再训练。
你在**智算平台**里创建推理服务、训练与微调任务时选的「模版」，就是这里的组件。

:::tip 推理引擎和微调框架的区别
**推理引擎** ≈ 把模型「开门营业」的店面，顾客（业务代码）来调用就能拿到结果。
**微调框架** ≈ 给模型「补课」的培训班，训练完产出新的模型文件，再交给推理引擎上线。
:::

## 这个分类解决什么问题

| 问题 | 由谁负责 |
| --- | --- |
| 用哪套引擎把大模型跑成 API 服务 | vLLM / SGLang / Xinference 等推理引擎 |
| 一张卡装不下模型，怎么多卡协同 | 引擎的张量并行能力（vLLM、vLLM Ascend 均支持） |
| 同时要跑对话、向量、语音、图像模型 | Xinference（一个服务支持多类型模型） |
| 模型文件需要加密、防止直接读取 | vLLM ENX / vLLM Ascend ENX（加密模型推理） |
| 只有 CPU 或显存很小怎么跑 | llama.cpp |
| 拿现成模型再补课 | LLaMA-Factory（微调训练） |
| 还没准备好模型，先联调接口 | mock-openai-api（模拟 OpenAI 接口） |

## 包含哪些组件

| 组件 | 作用 | 关键特性 | 平台里怎么用 |
| --- | --- | --- | --- |
| vLLM（大模型推理引擎，v0.27.1） | 把大模型跑成 OpenAI 兼容的推理服务 | 高并发吞吐、连续批处理、多卡分布式推理 | 工作台 → 推理服务 → 创建，选择 vLLM 模版 |
| vLLM ENX（加密模型推理） | 在 vLLM 基础上支持加密模型推理 | 增强模型解密与安全加载 | 工作台 → 推理服务 → 创建，选择加密版模版 |
| SGLang（高性能推理引擎，0.5.17） | 高吞吐推理服务，适合大语言模型对外服务 | 高性能、OpenAI 兼容 | 工作台 → 推理服务 → 创建，选择 SGLang 模版 |
| SGLang PD（预填充/解码分离，v0.5.8） | 把推理拆成 Prefill、Decode、Router 三段 | 三段可分别设置副本数和资源规格、独立扩缩 | 工作台 → 推理服务 → 创建，选择 PD 模版 |
| Xinference（多类型模型推理，v2.12.0） | 一个服务同时提供多种模型能力 | 支持 LLM、向量、重排、图像、语音、视频等 | 工作台 → 推理服务 → 创建，选择 Xinference 模版 |
| llama.cpp（轻量推理） | 在 CPU 或少量显存上跑开源模型 | C/C++ 实现、支持量化、适配 LLaMa/Qwen 等 | 工作台 → 推理服务 → 创建，选择 llama.cpp 模版 |
| vLLM Ascend（昇腾推理引擎，v0.23.0） | 面向华为昇腾 NPU 的 vLLM | OpenAI 兼容、模型下载、张量并行、LoRA | 昇腾集群的工作台 → 推理服务 → 创建 |
| vLLM Ascend ENX（昇腾加密推理） | 昇腾版 vLLM 的加密模型推理 | 增强模型解密与安全加载 | 昇腾集群的工作台 → 推理服务 → 创建 |
| LLaMA-Factory（微调训练框架） | 对大模型做微调训练 | 支持训练与运行两种模式，任务进度可见 | 智算平台 → 训练与微调 → 创建，选择 LLaMA-Factory 模版 |
| mock-openai-api（接口模拟服务） | 模拟 OpenAI 的对话与补全接口 | 不占卡、启动快，返回模拟结果 | 工作台 → 推理服务 → 创建，用于联调演示 |

## 什么时候需要关注它

| 你的场景 | 建议用哪个 |
| --- | --- |
| NVIDIA GPU 上跑通用大模型，追求高吞吐 | vLLM |
| 要求模型文件加密、不能直接读 | vLLM ENX |
| 想换一套推理引擎、对比吞吐 | SGLang |
| 想把预填充和解码分开部署、各自扩缩 | SGLang PD |
| 一个服务要同时提供向量、重排、语音、图像 | Xinference |
| 只有 CPU 或显存很小 | llama.cpp |
| 华为昇腾 NPU | vLLM Ascend（要加密选 ENX 版） |
| 拿现成模型做微调 | LLaMA-Factory |
| 没有可用模型，先联调业务接口 | mock-openai-api |

## 开始之前

- 创建推理服务和训练任务需要所在租户的**管理员**或**开发者**角色，并先选好**集群**和**工作空间**。
- 推理服务要跑起来，集群里需要有可调度的加速卡（或选 CPU 规格）；卡是否可见看**集群信息 → 加速卡信息**。
- 模型文件建议先放进**文件存储**或对象存储，创建服务时挂载或指定模型。

:::warning 引擎版本与硬件要匹配
昇腾机器只能用昇腾版引擎（vLLM Ascend）；加密版引擎只能加载加密后的模型。选错版本服务会起不来，创建前先确认硬件类型和模型格式。
:::
