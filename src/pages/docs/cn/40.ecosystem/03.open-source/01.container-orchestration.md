# 容器与编排

这一页讲平台的**调度与网络底座**：任务提交后由谁决定放到哪台机器、容器之间怎么联网、外部访问怎么进入集群。
你要接入新硬件、给实例配固定 IP 或域名、排查「任务一直排队」这类问题时，就会用到这一层的组件。

:::tip 一句话理解这一层
把集群想成一栋写字楼：**调度器**是分配办公室的物业，**网络组件**是楼里的道路和门牌，**入口网关**是楼门口的前台。
写字楼的地基（Kubernetes）已经打好，这一页讲的是地基之上的这些「物业设施」。
:::

## 这个分类解决什么问题

| 问题 | 由谁负责 |
| --- | --- |
| 任务放哪台机器、多卡任务怎么成组一起跑 | 调度组件（Volcano） |
| 一张卡怎么分给多个任务 | GPU 虚拟化（Volcano vGPU） |
| 容器需要固定 IP 或第二张网卡 | Multus-CNI |
| 外部怎么用域名访问集群里的服务 | ingress-nginx / Higress |
| 怎么进到实例里做运维 | kube-ssh / sshpiper |
| 镜像从哪拉、默认用哪个存储类 | 全局配置（global） |

## 包含哪些组件

| 组件 | 作用 | 关键特性 | 平台里怎么用 |
| --- | --- | --- | --- |
| Kubernetes（容器编排底层） | 把多台服务器组成集群，统一调度容器 | 声明式管理、故障自愈、可扩展 | 整个平台的运行底座，集群信息页可以看到集群概况 |
| Volcano（批量与 AI 训练调度器） | 给批量任务、训练任务排队并成组调度 | 队列、成组调度、公平共享、抢占、装箱 | 运维管理 → 调度器管理；安装后由平台按调度器配置派发任务 |
| Volcano vGPU（GPU 虚拟化） | 把一张 GPU 按份数切开给多个任务共用 | 每张卡默认切 10 份、每份内存按 128 MiB 为单位折算 | 在调度组件里开启「GPU 虚拟化」，创建实例时申请 vGPU 份额（仅 NVIDIA） |
| GPU Operator / 昇腾调度组件 | 把加速卡注册成集群可调度的资源，并交给 Volcano 调度 | NVIDIA 侧集成 GPU Operator 与 Volcano vGPU；昇腾侧集成 Device Plugin、NPU Exporter 与 Volcano | 运维管理 → 系统应用，按集群硬件类型选对应调度组件 |
| Multus-CNI（多网卡固定 IP） | 给容器额外挂一张虚拟网卡，分配固定 IP | 基于 IPvlan / Macvlan，为容器提供固定 IP | 运维管理 → 系统应用；需要固定 IP、双网隔离的实例用它 |
| ingress-nginx（NGINX 入口控制器） | 把集群外的 HTTP 流量按域名转发到集群内服务 | 以 NGINX 做反向代理和负载均衡，是默认入口实现 | 运维管理 → 系统应用；实例的访问域名由它接住 |
| Higress（统一入口网关） | 另一种入口网关实现，可替代 nginx-ingress | 安装时选择网关实现，并填写用于路由的主机名列表 | 运维管理 → 系统应用；在入口网关组件里切换实现 |
| kube-ssh（SSH 接入网关） | 为集群提供统一的 SSH 接入入口 | 与全局配置里的 SSH 网关服务端点配合使用 | 运维管理 → 系统应用；配合全局配置的端点对外暴露 |
| sshpiper（SSH 反向代理） | 按登录用户名把 SSH 连接转发到不同后端 | 支持密码和公钥两种转发方式 | 运维管理 → 系统应用；需要跳板机接入多台目标时使用 |
| 全局配置（global） | 集中管理所有系统应用共用的默认值 | 镜像仓库、镜像拉取密钥、默认存储类、调度器列表、服务端点 | 运维管理 → 系统应用；其他组件安装时从这里读取默认值 |

## 什么时候需要关注它

- **任务一直排队、跑不满卡**：先看**调度器管理**，确认 Volcano 已安装、队列没有把任务卡住。
- **要接一批新机器（尤其带卡）**：先装对应的**硬件调度组件**（NVIDIA 或昇腾），再回到调度器管理确认调度器生效。
- **实例需要固定 IP 或内外网隔离**：安装 **Multus-CNI**，创建实例时挂第二张网卡。
- **域名访问不通**：确认 **ingress-nginx** 或 **Higress** 已安装，再检查网关的主机名列表是否包含你的域名。
- **镜像拉不下来**：到**全局配置**里补镜像仓库地址和拉取密钥，其他组件会自动读取。

:::warning 调度组件不要重复装
同一个集群只保留一套调度组件。已经在用的集群不要直接切换或重装调度器，否则正在排队的任务可能被中断。
:::
