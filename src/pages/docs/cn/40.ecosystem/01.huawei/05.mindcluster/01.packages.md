# 获取软件包

开始装集群组件之前，先把要用的东西一次性拿到手并校验完。MindCluster 组件通常以
**「组件二进制 + Dockerfile / YAML + 配置文件」**的形式交付，个别组件还需要配套镜像。
这一步做对，后面每一步才有稳定的输入。

:::tip 为什么先做这一步
就像装修前先把材料都验一遍：型号不对、包装被拆过，后面装到一半才发现就要返工。
软件包也一样，**版本不配套**和**包被篡改**是两类必须提前排除的问题。
:::

## 开始之前

- 确认目标版本：本目录以 **MindCluster 26.0.0** 为准，各组件的镜像标签要与它配套，不要混用其他版本。
- 确认节点 CPU 架构：`x86_64` 或 `aarch64`，下载包和插件库都要选对架构。
- 具备官方软件包的下载权限，并能访问存放软件包的位置。

## 操作步骤

### 1. 确认版本与架构

在每台目标节点上确认架构：

```bash
uname -m
```

输出 `x86_64` 对应 x86 架构，`aarch64` 对应 ARM 架构。后续下载的二进制与昇腾 NPU 插件库都要匹配这个结果。

### 2. 按组件下载交付物

| 组件 | 需要准备的交付物 |
| --- | --- |
| Ascend Docker Runtime | 安装用的 `.run` 包 |
| NPU Exporter | 二进制、Dockerfile、DaemonSet 用的 YAML |
| Ascend Device Plugin | 二进制、Dockerfile，以及按处理器型号 / 是否使用 Volcano 区分的多份 YAML |
| NodeD | DaemonSet 用的 YAML、配置文件、Dockerfile |
| Volcano（昇腾定制，可选） | Volcano 组件包，以及与架构匹配的昇腾 NPU 插件库 |

### 3. 准备镜像

如果组件以容器方式部署，还需要把镜像放到集群能拉取的位置（例如企业镜像仓库）。以下是与 MindCluster 26.0.0 配套的镜像及标签：

| 镜像 | 标签 |
| --- | --- |
| `ascend-k8sdeviceplugin` | `v26.0.0` |
| `npu-exporter` | `v26.0.0` |
| `vc-scheduler` | `v1.9.0-v26.0.0` |
| `vc-controller-manager` | `v1.9.0-v26.0.0` |
| `vc-webhook-manager` | `v1.9.0` |

:::warning 调度器镜像不能用上游版本替代
Volcano 的 `vc-scheduler` 和 `vc-controller-manager` 必须使用**带昇腾插件**的配套标签（形如 `v1.9.0-v26.0.0`）。
换成上游 Volcano 的 `v1.9.0` 同标签镜像，调度时会缺少昇腾 NPU 插件，卡无法被正确调度。
:::

### 4. 校验软件包签名

下载软件包的同时下载对应的签名文件，在安装或升级前完成 OpenPGP 校验。具体的公钥获取方式与验签命令以官方签名验证指南为准。

:::warning 校验不通过就停手
签名校验失败说明包在传输或存储过程中可能被动过。**不要继续安装**，先重新下载；仍然失败就联系技术支持排查。
:::

### 5. 解压并确认目录内容

解压软件包，确认每个组件目录里都能找到第 2 步列出的那几类文件（二进制、Dockerfile、YAML）。缺文件说明下载不完整，重新下载。

### 6. 记录交付信息

在交付单里固定记录以下四项，后面排查问题时直接对照：

- 各组件版本
- 各镜像标签
- 容器运行时类型（Docker / containerd）
- 集群的 Kubernetes 版本范围

## 结果确认

- 每个组件的解压目录里都能找到二进制、Dockerfile 和 YAML。
- 签名校验全部通过。
- 交付单里的版本、镜像标签、运行时类型、K8s 版本都已记录。

## 常见问题

| 现象 | 可能原因 | 怎么办 |
| --- | --- | --- |
| 解压后缺少 YAML 或二进制 | 下载不完整 | 重新下载对应组件的完整包 |
| 签名校验失败 | 包被篡改或签名文件不匹配 | 停止安装，重新下载；仍失败联系技术支持 |
| 二进制在节点上报架构错误 | 下载了不对的 CPU 架构 | 用 `uname -m` 确认后重新下载匹配架构的包 |
| 调度器 Pod 起不来，日志提示找不到插件 | 用了上游 Volcano 镜像 | 换成带昇腾插件的配套标签镜像 |
