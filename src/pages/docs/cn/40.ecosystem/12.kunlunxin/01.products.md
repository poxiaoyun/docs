# 产品与软件栈

## 产品线

昆仑芯把所有数据中心加速卡统称为 XPU，官网没有给出「训练卡 / 推理卡」的二分口径，型号按代际往下排。

### 第一代

| 型号 | 已知信息 |
| --- | --- |
| K100 | 第一代产品。详细规格官方未公开 |
| K200 | 第一代产品。详细规格官方未公开 |

### 第二代

| 型号 | 已知信息 |
| --- | --- |
| R100 | 第二代产品。详细规格官方未公开 |
| R200 系列 | 第二代产品。详细规格官方未公开 |
| RG800 | 面向边缘场景。详细规格官方未公开 |
| R480-X8 | 以加速器组形式交付。详细规格官方未公开 |

### 第三代

| 型号 | 显存 | 接口 | TDP |
| --- | --- | --- | --- |
| P800 | 96 GB | PCIe 5.0 | 400 W |
| P800-OAM | 96 GB | PCIe 5.0 | 400 W |

官方没有给出 P800 与 P800-OAM 的形态对照说明，选型时以整机厂商的适配清单为准。
第三代是当前唯一有公开规格的一代，前两代只能查到型号名。

2025 年 11 月的百度世界大会上发布了 M100 与 M300，计划分别在 2026 年与 2027 年上市，属于下一代规划，
不在当前选型范围内。

:::warning R300 是未确认型号
网上能看到的 R300 在昆仑芯官网上没有对应产品页，属于未确认型号。这条信息来自第三方转述，
未获官方来源印证，选型与报障时不要按它来。
:::

## 资料可得性

这家要单独说一下，因为公开资料确实少，而且分散在第三方。

| 资料类型 | 现状 |
| --- | --- |
| 官网产品页 | 有，型号与简要规格在 `https://www.kunlunxin.com` |
| 独立开发者文档站 | 官方未确认。`developer.kunlunxin.com` 与 `docs.kunlunxin.com` 都无法解析 |
| 软件栈各层口径 | 主要来自腾讯云 TKE 的昆仑芯组件文档。第三方整理，但引用的是官方说法 |
| 官方 GitHub 组织 | `kunlunxin` 这个组织不存在，`github.com/kunlunxin/xpu-device-plugin` 返回 404 |
| 官方公开仓库 | 已复核存在的是推理侧的 `https://github.com/baidu/vLLM-Kunlun`，2025 年 12 月建仓 |
| Docker 镜像 | Docker Hub 组织 `kunlunxpu` 下有插件与导出器镜像，但最后更新时间停在 2022 至 2023 年 |
| Gitee 组织 | `kunlunxin` 组织下只有两个仓库，不含设备插件 |

这几条决定了后面几页的写法：能写的是分层结构和验证方法，安装命令与包名一律以随卡驱动包为准。

## 软件栈分四层

软件栈整体叫 XRE，公开口径里的组件分布在下面四层：

| 层 | 组件 | 装在哪 | 作用 |
| --- | --- | --- | --- |
| 内核驱动 | XRE 里的 kmd | 宿主机 | 让操作系统认识卡 |
| 用户态运行时 | XRE 用户态部分，含 `xpu-smi` | 宿主机 | 提供运行时与设备管理工具 |
| 编译与算子 | XDNN、XBLAS、XTDK、XCCL、XHPC | 宿主机或业务镜像 | 通信、算子与调优依赖 |
| 框架与推理 | XPyTorch（也写作 xPytorch）、`xtorch_ops`、`XTCL`、vLLM-Kunlun | 业务镜像 | 让框架跑在 XPU 上 |

另外有一个 XDR，是可编译驱动，源码形式提供，给需要适配特定内核版本的场景用。

框架层的官方写法有 `XPyTorch` 和 `xPytorch` 两种，搜资料时两个都要试。

## 版本口径

昆仑芯没有把驱动、软件栈、框架拆成独立的公开版本序列，网页上也查不到兼容性矩阵。
本分区不锁版本，现场一律以三样东西为准：随卡驱动包里的说明、机器上 `xpu-smi` 的实际输出、官网产品页的规格。

| 要查什么 | 去哪查 |
| --- | --- |
| 公司与产品型号 | `https://www.kunlunxin.com` |
| 驱动与运行时版本 | 机器上跑 `xpu-smi` |
| 软件栈各层口径 | 腾讯云 TKE 昆仑芯组件文档（第三方整理，含官方口径） |
| 推理侧代码 | `https://github.com/baidu/vLLM-Kunlun` |
| 独立开发者文档站 | 官方未确认，相关域名无法解析 |

:::tip 三处口径对不上时按哪个
先看机器上 `xpu-smi` 的输出，再看随卡驱动包说明，最后才看第三方文档。第三方文档里的版本号与包名会过期，
用来理解分层可以，照着抄命令不行。
:::
