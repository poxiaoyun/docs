# 产品与软件栈

## 产品线

壁砺是壁仞的加速卡产品名，芯片按芯粒口径分 BR106 与 BR166 两档，BR166 由两颗 BR106 芯粒组成。同一个芯片按形态拆出不同后缀的型号：

| 代际 | 型号 | 形态与定位 |
| --- | --- | --- |
| BR106（单芯粒） | 壁砺 106M | 风冷 OAM，训练 |
| BR106 | 壁砺 106L | 液冷 OAM，训练 |
| BR106 | 壁砺 106B | 2 slot FHFL PCIe，推理 |
| BR106 | 壁砺 106C | PCIe，主打推理 |
| BR166（双 BR106 芯粒） | 壁砺 166M | 训练 |
| BR166 | 壁砺 166L | 训练 |
| BR166 | 壁砺 166C | 推理 |

BR166 三种型号的形态划分官方没有逐项列出，选型时按交付清单确认。产品矩阵里另有 BR110，面向边缘与云推理。

按用途可以粗分成两类：

| 划分 | 型号 |
| --- | --- |
| 训练卡 | 106M、106L、166M、166L |
| 推理卡 | 106B、106C、166C、BR110 |

早期公布的 BR100 与 BR104 已经不在官网当前的产品矩阵里，招股书也没有把它们列为在售型号，后续供货状态未确认。选型不要按旧资料去找这两款。

## 公司经营与产品路线现状

| 项 | 内容 |
| --- | --- |
| 上市 | 2026-01-02 在香港交易所上市，股份代号 `06082.HK` |
| 2025 年收入 | 10.346 亿元，同比 +207.2% |
| 2025 年毛利率 | 53.8% |
| 2025 年研发投入 | 14.76 亿元 |
| 2025 年经调整净亏损 | 8.74 亿元 |
| 量产状态 | BR106 / BR166 全形态已量产，交付过多个千卡级集群 |
| 路线图 | BR20X 计划 2026 年内推出，支持 FP8 / FP4 与 Blink 2.0 |
| 已知背景 | 2023-10 被列入美国实体清单 |

166L 与 166M 在 2025-08 量产，166C 在 2025-12 量产。这几条对交付判断有影响：卡是在售的，路线图也有下一代的明确时间点，但公司的经营口径是经调整净亏损 8.74 亿元，选型时把长期供货与替代方案一起考虑。

## 软件栈分层

官方平台名是 **BIRENSUPA™**，官方描述里把这套栈分成四层。文档页只公开了平台名与分层，没有逐个列出组件名与版本。

| 层 | 官方分层 | 覆盖什么 |
| --- | --- | --- |
| 第一层 | 驱动与 HAL | 卡与操作系统之间的驱动和硬件抽象 |
| 第二层 | 编程平台 | 编译、算子、通信这类编程接口 |
| 第三层 | 框架层 | 对上承接深度学习框架 |
| 第四层 | 解决方案层 | 面向具体场景的训练与推理方案 |

第三方整理的 SDK 资料里会出现下面这些名字，官方文档页没有直接列出过，按线索看待：

| 第三方资料里出现的名字 | 类别 | 官方核实状态 |
| --- | --- | --- |
| BRCC | 编译器 | 文档页未列出 |
| suBLAS、suDNN、suFFT、suRAND、suCCL | 算子与通信库 | 文档页未列出 |
| suInfer | 推理套件 | 文档页未列出 |
| brvllm | vLLM 适配 | 文档页未列出 |
| BRML、suDCGM | 管理与监控 | 文档页未列出 |
| `brsmi`（BR-SMI） | 命令行工具 | 确认存在，但不是 metrics exporter |

## 版本口径

壁仞没有公开一张统一的「驱动 / 固件 / SDK / 框架」兼容性矩阵。目前能拿到的最硬的一条版本线来自设备插件仓库：驱动要求 ≥ 1.2.2。其余版本配套一律以随卡交付说明和开发者社区为准，不要在文档里锁死版本号。

:::tip 别拿第三方组件名对官方口径
网上整理的 BIRENSUPA 资料会列出一串 `su*` 组件名，官方文档页并没有直接给出这些名字，只公开了平台名和四层分层。按第三方列表排查缺库问题时，先回开发者社区确认当前的组件命名，对不上不等于环境装坏了。
:::
