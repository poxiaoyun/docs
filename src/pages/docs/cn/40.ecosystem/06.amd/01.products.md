# 产品与软件栈

## 产品线

数据中心这一条线叫 **Instinct**，型号以 MI 开头。AMD 官网没有把型号硬分成「训练卡」和「推理卡」，
MI350 系列在官方页面上同时标注训练与推理；只有 MI350P 明确写了面向分布式推理。

| 型号 | 显存 | 形态 | 说明 |
| --- | --- | --- | --- |
| MI355X | 288 GB HBM3E | OAM | CDNA 4 架构，当前最高一档 |
| MI350X | 288 GB HBM3E | OAM | CDNA 4 架构 |
| MI350P | 288 GB HBM3E | PCIe | 官方标注面向分布式推理，风冷机箱可用 |
| MI325X | 256 GB HBM3E | OAM | 上一代 |
| MI300X | 192 GB HBM3 | OAM | |
| MI300A | 128 GB HBM3 | APU | CPU 与 GPU 在同一封装里 |

选型时注意两件事：**OAM 卡需要整机配套的基板**，不能当 PCIe 卡插；**MI300A 是 APU**，
分区模式与纯 GPU 型号不同（见 [Kubernetes 组件](/ecosystem/amd/k8s-components) 里的分区那节）。

## 软件栈分四层

ROCm 是一个整体的名字，实际装的时候要分清下面四层，缺哪层后面的都跑不起来：

| 层 | 组件 | 装在哪 | 作用 |
| --- | --- | --- | --- |
| 内核驱动 | AMD GPU Driver（`amdgpu`） | 宿主机 | 让操作系统认识卡，提供 `/dev/kfd`、`/dev/dri/renderD*` |
| 用户态运行库 | ROCm（`rocminfo`、`amd-smi` 等） | 宿主机 | 提供 HSA 运行时与设备管理工具 |
| 编译与算子 | `amdclang`、HIP / HIPIFY、rocBLAS、hipBLASLt、MIOpen、rocFFT、RCCL、Composable Kernel | 宿主机或镜像 | 业务镜像编译与运行依赖 |
| 容器与框架 | AMD Container Toolkit、PyTorch / JAX / TensorFlow / ONNX Runtime / vLLM / SGLang / Triton | 宿主机 + 业务镜像 | 让容器拿到卡，让框架跑在 ROCm 上 |

命名上有个容易踩的地方：**`roc*` 是 ROCm 原生库，`hip*` 是 CUDA 兼容封装层**。
排查缺库问题时先看清报错里的是哪一类：引 `hip*` 说明代码是从 CUDA 迁过来的，引 `roc*` 说明是原生 ROCm 代码。

## 版本口径

ROCm 从 **7.0 起把内核驱动与用户态拆成两个独立发布的包**：驱动走单独版本序列（30.10 系起步），
ROCm 用户态走自己的版本号。所以「装哪个驱动」不再由 ROCm 版本唯一决定，查兼容性要看
AMD 官方的兼容性矩阵（Compatibility matrix），上面按型号和操作系统分别给了驱动与 ROCm 的对应关系。

本分区写的是方法，不锁死版本。现场一律以 **AMD 官方兼容性矩阵 + 随卡发布的说明**为准。

| 要查什么 | 去哪查 |
| --- | --- |
| 型号与规格 | `https://www.amd.com/en/products/accelerators/instinct.html` |
| 驱动与 ROCm 的兼容组合 | `https://rocm.docs.amd.com/projects/install-on-linux/en/latest/` 的 Compatibility matrix |
| 安装方法 | 同上，五种方式：包管理器 / `amdgpu-install` / pip / tarball / runfile |
| 容器工具链 | `https://github.com/ROCm/container-toolkit` |
| 集群组件 | `https://github.com/ROCm/gpu-operator` |
| ROCm 全部组件库 | `https://github.com/ROCm` |

:::tip 包管理器还是 amdgpu-install
AMD 官方的对比表写得很清楚：`amdgpu-install` 目前只面向 **Radeon 与 Ryzen**，
且会把显卡驱动和 ROCm 一起装；**Instinct 装内核驱动要按 AMD Instinct 数据中心的文档单独做**，
ROCm 用户态则推荐走系统包管理器（apt / dnf / zypper）。
:::
