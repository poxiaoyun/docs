# FAQ

Grouped by topic. Every row is written as "symptom → possible cause → what to do", and the **what to do** column is an action or a UI path you can follow directly.

## Sign-in and accounts

| Symptom | Possible cause | What to do |
| --- | --- | --- |
| A captcha suddenly appears at sign-in | The platform wants a second confirmation, or you have mistyped your password several times | Follow the prompt: drag the slider, or type the characters in the image, then sign in again |
| You are asked for a second code after signing in | Multi-factor authentication is enabled on your account | Open the authenticator app on your phone and enter the current 6-digit code |
| It says the username or password is wrong | A capitalisation or whitespace mistake | Type it again; if it keeps failing, use "Forgot password?" |
| You forgot your password | — | On the sign-in page click **Forgot password?**, verify your identity with a code as prompted, then set a new password |
| You cannot find a registration entry | Self-registration is switched off on this platform | Ask a platform admin to create the account in BOSS |

## Tenants and workspaces

| Symptom | Possible cause | What to do |
| --- | --- | --- |
| You are asked to choose a tenant after signing in | You belong to more than one tenant | Click the tenant you want in the list; with only one tenant this is skipped automatically |
| The tenant list is empty | You have not joined any tenant yet | Register a new tenant on the tenant selection page, or ask an administrator to add you to one |
| Home says "Select a region and workspace to view overview data" | No workspace has been selected yet | In the selector at the top of the left menu, pick the cluster first, then the workspace |
| The workspace dropdown has nothing in it | No workspace has been created on this cluster yet | Click **Create Workspace** to make one |
| Creating a workspace fails and mentions resource quota | The tenant has no quota on this cluster yet | Ask a tenant admin or platform admin to allocate quota |

## Deployment and instances

| Symptom | Possible cause | What to do |
| --- | --- | --- |
| The **Flavor** card has no selectable rows | The current workspace is short of quota, or there is no free compute | Ask a tenant admin to adjust the quota, or stop other instances you are not using |
| The status stays on **Installed** | An image is being pulled, or a model is loading | Open the **Events** page of the instance and check whether the image pull succeeded |
| The status is **Needs attention** | Some containers are not ready | Open the **Log** page and read the errors; common causes are port or health-check configuration |
| The status is **Processing failed** | A container failed to start | Open the **Log** page; common causes are insufficient VRAM and a wrong model path |
| Containers keep restarting | It crashes as soon as it starts | Read the last few error lines in **Log**; usually a missing model file or an incompatible version |
| You cannot see the **Create Inference** button | You do not have permission to create instances | See the [Permission Guide](/reference/permissions) |
| You want to save compute without deleting the service | — | Click **Stop** in the instance list to release compute while keeping the configuration; click **Start** when you need it again |

## Models and storage

| Symptom | Possible cause | What to do |
| --- | --- | --- |
| You cannot see the **Create Storage Volume** button | Creating storage volumes needs the Tenant Admin role | Ask a tenant admin to create it, or store the model in Moha Hub instead |
| An instance cannot reach files in the storage volume | The mount path and the files' real location do not match | Check the mount path in the deployment parameters, then compare it with the folders in the File Manager |
| A model file is too large, so uploads are slow or break | Browsers are not reliable for very large uploads | Inside the storage volume use **Create Storage Job** to pull from HuggingFace, ModelScope, Moha Hub or Git |
| You want to use a public model from an external site | The platform cannot reach the external network directly | Use **Create Storage Job** to pull it from HuggingFace or ModelScope into a storage volume or Moha Hub |
| You renamed a model but the deployment still uses the old one | The parameters still reference the old name | Go back to the deployment parameters, update the model name or path, and redeploy |

## Chat and API calls

| Symptom | Possible cause | What to do |
| --- | --- | --- |
| No models available in the Marketplace | No model has been connected to a channel | Ask a platform admin to configure a channel in BOSS |
| It asks you to create an API key first | The current user has no key yet | Go to [AIrouter](/airouter/) → **API Keys** → create one |
| A call returns `401` | The key is wrong or expired | Check that the header is `Bearer YOUR_KEY`; create a new key if needed |
| A call returns `403` | The key has no access to that model, or content moderation blocked it | Check the key's allowed model scope; try another model |
| A call returns `429` | You hit the rate limit | Raise RPM / TPM in **API Keys**, or slow down your calls |
| The reply does not appear token by token | Streaming is off | Set `"stream": true` in the request body and send `Accept: text/event-stream` |
| The reply is cut off | `max_tokens` is too small | Increase `max_tokens` |
| The reply quality is poor | Parameters or prompt are not suitable | Lower `temperature`, and put the role and requirements into the `system` message |
| The Comparison page is empty after a refresh | Comparison content lives only in the current page | This is expected; copy anything important out first |

## Permissions and interface

| Symptom | Possible cause | What to do |
| --- | --- | --- |
| The left menu is missing **Workbench** and **Observability** | You are a Member | See the [Permission Guide](/reference/permissions) |
| A button or menu item cannot be seen | The current role lacks that permission, so the entry is hidden | Find the role you need in the permission table and ask an administrator |
| Buttons did not change after switching tenant | Permissions refresh only when the sign-in state changes | Refresh the page once |
| The page returns `403` | The current role really does lack that permission | Ask a tenant admin to change your role; retrying will not help |
| The page returns `401` | The sign-in state expired | Sign in again |

## Local development and deployment

| Symptom | Possible cause | What to do |
| --- | --- | --- |
| Installing dependencies or starting fails with a Node version error | Local Node is too old | Upgrade to Node 20 or above and install dependencies with pnpm |
| The page opens but every API call errors | Local development proxies to a back end and the proxy address is wrong | Check the back-end proxy address — see [Build & Environment](/reference/build-and-env) |
| You want the BOSS build | The default build only produces the regular-user interface | Build in BOSS mode — see [Build & Environment](/reference/build-and-env) |
| Which account do I sign in with locally | Locally the console connects to a development back end by default | Use an account for that development environment |

## Still stuck

1. First check the [Glossary](/guide/glossary) for the meaning of the term you ran into.
2. Then check the [Permission Guide](/reference/permissions) to rule out a permissions problem.
3. For anything involving APIs, compare your address and authentication against the [API Overview](/reference/api-overview).
4. If it still is not resolved, contact a platform admin and include: **a screenshot of the problem, the browser console errors (press F12 to open Console), and the steps you took**.
