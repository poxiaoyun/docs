# Personal Center

The Personal Center is where you manage "yourself": your avatar and nickname, password, email and mobile number, access keys, second factor, and the look of the interface are all changed here. It differs from tenant management — every item here affects only you and never touches your colleagues.

:::tip A comparison
Tenant management is like the company's administration desk, changing things for the whole company; the Personal Center is your badge and your desk, adjusting only your own things.
:::

## How to open it

1. Click your avatar in the top-right corner.
2. In the menu that opens, click **Settings**.
3. The page opens with a row of tabs at the top; click a tab name to switch.

Once inside, the top of the page is a row of tabs, starting on **Basic Info**:

![Personal settings page: the heading "User Center" with a horizontal row of tabs — Basic Info, Password, Email, Mobile Number, API Key, SSH Key, Multi-Factor Authentication, Theme](/assets/screenshots/account/profile-01.png)

## What is in the Personal Center

| Tab | What it is for | Detailed steps |
| --- | --- | --- |
| General | Change your avatar and nickname; the username is read-only | [User Profile](/account/iam/profile) |
| Password | Replace your password using the old one | [Security Settings](/account/iam/security) |
| Email | Change your email; requires an email verification code | [Security Settings](/account/iam/security) |
| Mobile Number | Change your mobile number; requires an SMS verification code | [Security Settings](/account/iam/security) |
| API Key | Generate an access key for programs that call the API | [IAM API Key (AK/SK)](/account/iam/api-key) |
| SSH Keys | Add a public key for passwordless connections | [SSH Key Management](/account/iam/ssh-key) |
| Multi-factor Authentication | Add a second lock with your phone's authenticator app | [Multi-Factor Authentication (MFA)](/account/auth/mfa) |
| Theme | Switch light / dark, font, and primary color | [Theme & Preferences](/account/iam/theme) |

:::info Tenant management is not one of these tabs
The entry for viewing tenant information and managing members is the **Tenant** item in the avatar menu. Opening it takes you to tenant management, which is not one of the Personal Center tabs. See [Tenant Management](/account/iam/tenant).
:::
