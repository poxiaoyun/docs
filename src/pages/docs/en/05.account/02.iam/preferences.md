# Preferences

**Preferences** is the last tab of personal settings and offers exactly three settings: **Appearance mode**, **Color**, and
**Language preference**. Changes are stored on your account, so they survive a different browser or computer, and they only
affect your own interface.

:::tip Only your own interface changes
Every setting here applies to you alone; colleagues keep seeing whatever they chose for themselves.
:::

## Before you start

- You can use it as soon as you sign in; no tenant role is needed.
- Decide whether you really want to change the interface language: **Language preference** is an account-level setting,
  and it is not the same as the quick language switch in the header.

## How to open it

1. Click your avatar in the top-right corner → **Personal settings**.
2. Open the **Preferences** tab.

![Preferences page: the three appearance mode options, six color swatches, the language preference selector, and the Save button](/assets/screenshots/account/preferences-01.png)

## The three settings

| Setting | Options | Effect |
| --- | --- | --- |
| **Appearance mode** | **Light** / **Dark** / **System** | The overall light or dark look. Light is used until you choose |
| **Color** | Six swatches: Green / Sky blue / Purple / Blue / Orange / Red | Changes the primary color used by buttons, links, and selected states |
| **Language preference** | 中文 / English | The interface language. **Nothing is preselected** until you choose one |

## Save your changes

1. Pick the three settings from the table above.
2. Click **Save**.
3. On success the button confirms and the interface switches to the new settings.

:::warning Nothing applies until you save
This page is not live. If you change options and leave without clicking **Save**, the changes are discarded.
A failure shows **Could not save preferences. Please retry.** (or **Could not save language. Please retry.** for the language
field alone), and your selections stay in the form so you can retry.
:::

## How this differs from the header switch

| Where you change it | What it changes | Written to your account? |
| --- | --- | --- |
| The light/dark and language switches in the header | Only the display in this browser | No — another device will not see it |
| This page plus **Save** | Your account preferences | Yes — another device sees the same settings |

:::info The local choice wins
If the header switch put the interface into dark mode while your account preference is light, this browser shows dark.
To make every device consistent, set it here and save once.
:::
