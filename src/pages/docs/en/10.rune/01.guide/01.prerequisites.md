# Prerequisites

Before you create anything in Rune, you only need to confirm three things: **which account you sign in with, what role you hold in the tenant, and which resources an administrator has prepared for you**.
Rune requires no software installed on your computer and has no command-line tool — everything is done in the browser.

:::tip Why do this first
It is like joining a gym: you need a membership card, a locker, and the right clothes, or you are stopped at the door.
The most common "why does this button not work" in Rune comes from a region or workspace not being ready.
:::

![Workspace list: name, namespace, status and creation time per row, with the Region and Workspace selectors at the top left](/assets/screenshots/rune/workspace-01.png)

When self-checking, look at **Status** first: only a `Ready` workspace can host instances. If the list is empty the page reports **no workspace available**, and a tenant administrator can create one straight from here.

## Self-check list

| What to confirm | How to check it |
| --- | --- |
| I can sign in | You reach the console normally, with no wrong account or password message |
| I have a tenant | The top of the console shows the tenant you intend to use |
| I have picked a region | A usable region (data center) is selected in the **Region** selector at the top |
| I have picked a workspace | An office is selected in the **Workspace** selector at the top |
| Quota is still available | If creating something reports not enough resource, the quota is the cause and an administrator must adjust it |
| Templates and flavors are available | You can see templates in the Marketplace and pick a usable resource spec when creating |

## What is my role

Rune has three tenant roles: **Administrator**, **Developer**, and **Member**.

| Role | Which features you can use |
| --- | --- |
| Administrator | Manage members, quota, and workspaces; can use every feature |
| Developer | Create workloads, view metrics and logs; can use every feature |
| Member | Can only see **Home** and **Marketplace**; cannot see **Workbench** or **Observability** |

:::info How to tell whether you are an Administrator or Developer
Look at the left sidebar for the **Workbench** and **Observability** groups.
If they are there, you are an Administrator or Developer; if not, you are a Member — that is not a fault, it is a permission setting.
:::

![Flavour list: Resource flavours selected under the Resource management group on the left, with the cluster switchable at the top right](/assets/screenshots/rune/flavor-01.png)

**Flavours** decide how much CPU, memory and accelerator an instance can ask for. They are defined per cluster by platform administrators and cannot be created by users — if the dropdown has nothing you want, this is the layer that is incomplete.

## What an administrator needs to prepare for you

The resources below cannot be created by you; a tenant administrator or platform administrator must set them up in advance:

| Resource | Who prepares it | What happens without it |
| --- | --- | --- |
| Tenant and membership | Platform administrator | After signing in you see no business content at all |
| Region (cluster) access | Platform administrator | No region is selectable at the top and the page says **No available cluster** |
| Workspace | Tenant administrator | The page says **No available workspace** and you cannot create instances |
| Quota | Tenant administrator | Creating something reports not enough resource |
| Usable flavors | Platform administrator | No usable compute spec is selectable when creating |

:::warning An empty page is not always an error
If there is no region, the page says "No available cluster. Please contact admin to create or assign a cluster".
If the current region has no workspace, it says "No available workspace. Please contact admin to create or assign a workspace".
A tenant administrator can click **Create Workspace** directly on these two screens; everyone else should contact an administrator.
:::

## Confirming the result

Your environment is ready when the left sidebar shows all four groups — **Home / Marketplace / Workbench / Observability** — and both the **Region** and **Workspace** selectors at the top show a specific name.
