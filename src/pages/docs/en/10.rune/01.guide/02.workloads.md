## Overview

Inference services, fine-tuning jobs, dev environments, applications, experiments, and evaluations all follow the same basic deployment shape in Rune: pick a template, fill in the basic fields, fill in the template parameters, and submit an instance.

## Shared Workflow

- Start from the App Market or a product list page.
- Fill in the three fixed base fields (`id` / `name` / `description`) and the runtime parameters in the generated form.
- Template parameters are rendered from the selected version's JSON Schema; whether fields such as flavor, storage volume, or replica count exist depends entirely on that Schema, not on a fixed console step.
- Submit the instance, then follow status, logs, events, and monitoring from the instance detail page.
