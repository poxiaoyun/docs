# Templates

**Templates** saves a **reusable instance configuration**.
Once you save a tuned inference service or fine-tuning job with **Save as Task Template**, the next time you want to open a similar instance you can deploy straight from that template instead of filling in every parameter from scratch.

:::tip What a template saves you from filling in
Without a template, every new instance means picking a template and filling in a pile of parameters again.
With a template, the application, version, type, and all parameters are already remembered for you — you only need to give the new instance a name.
Saving your usual configuration as a template turns "fill it in every time" into "fill it in once, use it many times".
:::

## Before you start

- Your tenant role must be **Administrator** or **Developer**, otherwise **Workbench → Templates** is hidden from the left sidebar.
- The **Region** and **Workspace** at the top are selected. Templates are **isolated per workspace**, so only members of the same workspace can see them.
- You already have an instance whose configuration you are happy with (an inference service or a fine-tuning job); otherwise there is nothing to save.

## Core concepts

| Term | Plain explanation |
| --- | --- |
| Template Source | Which application and version this template was saved from |
| Category | What kind of template it is: an inference service or a fine-tuning task |
| Deploy | Use this template to create a new instance |

## Save an existing instance as a template

1. In the left sidebar click **Workbench → Inference** (for fine-tuning jobs, click **Traning&Fine tuning** instead).
2. Find the instance you want to save and click the **⋮** icon at the far right of its row.
3. Click **Save as Task Template**.
4. In the dialog, fill in:

   | Field | What to fill | Notes |
   | --- | --- | --- |
   | Name | For example `Qwen inference standard config` | Required; an ID is generated automatically below it, and you can click the pencil icon next to it to change it |
   | Template Description | For example `8B model + 1 card, team standard` | Optional; it helps to state the purpose and prerequisites |

5. Click **Confirm**; when the message "Saved as task template successfully" appears, you are done.

:::info What exactly a template stores
When saving, Rune records the tenant, region, and workspace the instance belongs to, plus its application, version, and all parameters.
That is why a template can only be used to create new instances **inside the same workspace** — and also why it can be shared by the team.
:::

## Create a new instance from a template

1. In the left sidebar click **Workbench → Templates**.
2. Find the template you want in the list and click the **⋮** icon at the far right of its row.
3. Click **Deploy**.
4. In the "Deploy from Task Template" dialog, fill in:

   | Field | What to fill | Notes |
   | --- | --- | --- |
   | Name | For example `qwen-demo-2` | Required; the name the new instance shows; an ID is generated automatically below it |
   | Instance Description | For example `for the test team` | Optional, to make it easier to recognize later |

5. Click **Confirm**.
6. Rune creates the new instance with the application and parameters from the template, then jumps automatically to the instance list for that type.

## About the template list

The list has these columns:

| Column | What to look at |
| --- | --- |
| Template Source | Which application and version it comes from |
| Template Name | The template's name |
| Template Description | The purpose note you wrote |
| Category | Inference Service or Fine-tuning Task |
| Creator / Created At | Who created it and when |

The list supports search, multi-select, refresh, and delete; the **⋮** menu at the far right of each row also has **Edit** and **Delete**.

## Edit a template

1. In the template list, click the **⋮** icon at the far right of a row and click **Edit**.
2. In **Basic Info** on the edit page you can change the **Name** and **Description**.
3. In **Parameters** you can change the parameter values. The icon in the top-right switches between form mode and JSON mode:
   - Form mode: a form generated from the template, good for changing a few values day to day.
   - JSON mode: edit the parameter text directly, good for bulk replacement.
4. Click **Confirm** to save.

:::warning Think before you edit
A template is shared by the team, so changing parameters affects every new instance deployed from it afterwards (instances already deployed are unaffected).
If you only want to try a new set of parameters, save or copy the current template first so the original is preserved.
:::

:::info The parameter form may fail to load
If this application version is no longer available, the page says "Template … is not available, only basic config and JSON parameters can be edited".
In that case you can only change the basic info and the JSON parameters, and you can no longer switch back to form mode.
:::

## Delete a template

In the list, click the **⋮** icon at the far right of a row and click **Delete**; Rune asks you to **type the template name** as a second confirmation and deletes it only after that.

:::warning Deletion cannot be undone
After deletion the template **cannot be recovered**.
Deleting a template **does not** affect instances already deployed from it; those keep running as usual.
:::
