# Quick Start

This page walks through the core Moha flow: sign in -> create -> upload -> use -> deploy.

## Prerequisites

1. A platform account and sign-in (`/auth/sign-in`).
2. A selected tenant/organization (`/auth/select-tenant`).
3. A working token from the [Access Tokens](/moha/quickstart/token) page for Git and API auth.

## 1. Enter Moha

After sign-in, Moha opens on the overview page:

```text
/moha  ->  /moha/home/overview
```

The home sidebar contains Overview, Created by Me, Liked by Me, Access Tokens and Announcements.

## 2. Create a repository

| Type | List page | Detail after creation |
| --- | --- | --- |
| Models | `/moha/models` | `/moha/models/:organization/:id/content` |
| Datasets | `/moha/datasets` | same, `type` = `datasets` |
| Images | `/moha/images` | `/moha/images/:organization/:id/tags` |
| Spaces | `/moha/spaces` | `/moha/spaces/:organization/:id/content` |

The create form requires `organization`, `name` (`^[a-zA-Z0-9][a-zA-Z0-9._-]*$`) and `alias`; `visibility` defaults to `private` and is forced to `internal` in an organization context.

## 3. Upload files

Open the repository -> **File** tab:

```bash
git lfs install
git clone https://moha.your-domain/moha/models/ai-lab/my-model.git
cd my-model
cp /path/to/weights/* .
git add . && git commit -m "Add weights" && git push origin main
```

Or use the SDK:

```bash
pip install moha-hub
moha download --repo-type models ai-lab/my-model
```

## 4. Use resources

Moha exposes a HuggingFace-compatible endpoint:

```bash
export HF_ENDPOINT=https://moha.your-domain/moha/huggingface
export HF_TOKEN=<access-token>
```

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained("ai-lab/my-model", torch_dtype="auto", device_map="auto")
tokenizer = AutoTokenizer.from_pretrained("ai-lab/my-model")
```

See [Transformers & Datasets integration](/moha/sdk-tutorial/transformers-datasets) for more.

## 5. Deploy a Space

1. When creating a Space, fill in `spaceMetadata` (`cluster` / `namespace` / `flavorID` / `product` / `gitAddress`, ...).
2. On the detail page click **Online** to start the instance.
3. While running you can **Stop / Restart / view logs**; saving deploy settings restarts automatically.
4. Use **version freezes** for snapshots.

> 💡 Tip: Whether a Space is deployed is determined by `spaceMetadata.status` being non-empty; when empty only "Online" is shown.
