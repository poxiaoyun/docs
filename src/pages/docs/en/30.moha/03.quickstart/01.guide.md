# Quick Start

This page lines up every action for "using Moha for the first time", start to finish: open the site, create an account, sign in, select an organization, copy your access token, and finally download your first model onto your own computer.

Do them in order and do not skip steps. Each step says where to click, what to fill in, and what you will see — once you see it, that step is done.

:::tip What you end up with

A working Moha account, an access token, and a model folder already downloaded to your machine. Every later download or upload uses this same account and token.

:::

## Before you start

- Have an email address that can receive mail — registration needs a verification code.
- Install Python 3.10 or later on your computer, which step 5 needs. You can confirm by running `python --version` in a terminal; anything `Python 3.10` or above is fine.
- If your administrator has turned off self-service registration, the register entry will be missing. Ask your administrator to open an account for you, then continue from step 3.

## Step 1: Open the site

Type the platform address your administrator gave you into the browser (usually of the form `https://<platform-address>`) and press Enter.

Seeing the sign-in page means the site is reachable.

## Step 2: Create an account

If you already have an account, skip to step 3.

1. At the bottom of the sign-in page, find **Don't have an account?** and click **Register now**.
2. Fill in the registration form:

   | Field | What to enter | Notes |
   | --- | --- | --- |
   | Username | For example `zhangsan` | Used to sign in; better not to change it later |
   | Password | A password of your own choosing | Remember it — you need it to sign in |
   | Email | An email address you use often | Used to receive the verification code |
   | Mobile Number | Your phone number | Choose the country/region first, then type it |
   | Verification Code | The digits just sent to your email | Check spam if it does not arrive |
   | I have read and agree to the Terms of Service and Privacy Policy | Tick it | Until you tick it, the button below stays disabled |

3. Click **Create Account**.
4. After a successful registration you are taken back to the sign-in page with a prompt to sign in.

## Step 3: Sign in and select your organization

1. On the sign-in page, fill in **Username/Email/Mobile Number** and **Password**, tick the agreement, and click **Login**.
2. If a graphical or slider verification appears, enter the digits or drag the slider as prompted, then click **Verify and sign in**.
3. After signing in you land on the **Select your tenant** page:
   - If your organization is in the list, select it and click **Enter Platform**.
   - If the list is empty, click **Create Tenant** and follow the prompt to create an organization for yourself, then come back to this step to enter.
4. Once inside the platform you will see its home page.
5. Open Moha: find the product name at the top left, click the dropdown arrow beside it to open the **Products** menu, and select **Moha**.
   - If you cannot find the entry, type the Moha address your administrator gave you into the browser address bar instead.

Inside Moha, the top navigation shows **Home**, **Models**, **Datasets**, **Images** and **Spaces**.

:::info What an organization is

"Organization" is the "tenant" on this page — think of it as a team space: your models and datasets live inside some organization, and colleagues in the same organization can see each other's resources by default.

:::

## Step 4: Copy your access token

The token is the pass the command line uses to prove your identity. You do not apply for it separately — once you are signed in it already exists.

1. Click **Home** in the top navigation.
2. Click **Access Tokens** in the left menu.
3. The page shows a long string — click the copy icon to its right and the token goes to your clipboard.
4. Paste it somewhere safe first (a password manager, for example); you need it in the next step.

:::warning A token is your identity

Anyone who has the token can act as you. Do not paste it into chat groups, public code, or screenshots.

:::

## Step 5: Install the command-line tool on your computer

Open a terminal (PowerShell on Windows, Terminal on macOS) and run:

```bash
pip install moha-hub
```

When it finishes, run the command below — printing a version number means it is installed:

```bash
moha --version
```

## Step 6: Let the command line know your account

Hand the token from the previous step to the command line, together with the platform address:

```bash
moha login https://<platform-address> --token <your-access-token>
```

- Replace `<platform-address>` with the address you opened in the browser in step 1. It **must include `https://`**.
- Replace `<your-access-token>` with the token you copied in step 4.

On success it prints a table like this:

```text
Token saved
Current Organization  <your organization name>
Endpoint              https://<platform-address>
Config File           ~/.moha/config.json
```

Seeing **Token saved** means the command line knows who you are. Double-check with:

```bash
moha whoami
```

The login status should read `Logged in`.

## Step 7: Download your first model

1. Back in the browser, click **Models** in the Moha top navigation.
2. Open any model and find its "organization / name", for example `ai-lab/qwen2-7b`.
3. Back in the terminal, run the download command (replace `ai-lab/qwen2-7b` with the model you want):

```bash
moha download ai-lab/qwen2-7b
```

4. Wait a moment: the command line prints download progress, then finishes with a table:

```text
Download completed
Local Path  <local folder path of the model>
```

## Confirm it worked

- The command line ends with **Download completed** and one **Local Path** row.
- Open that path and you can see the model files (for example `config.json` and the weight files).
- The username shown by `moha whoami` matches the one you signed in with in the browser.

If all three hold, the whole path is working.

## Common problems

| Symptom | Likely cause | What to do |
| --- | --- | --- |
| The registration form does nothing | The agreement is not ticked, or the verification code is wrong | Tick the agreement and fetch a fresh code from your email |
| Cannot get past sign-in, it says locked | Too many wrong passwords in a row | Retry after the time shown; if you forgot the password, click **Forgot password?** to reset it by email |
| The tenant page is empty | Your account does not belong to any organization yet | Click **Create Tenant** to make one yourself, or ask an administrator to add you |
| `moha login` complains the address is invalid | The address is missing `https://` | Add `https://` and run it again |
| Download says you have no permission | The model is private or internal | Confirm the token works and that you belong to the organization; try a public model to check |
| Cannot find the Moha entry | It is not in the Products menu | Use the Moha address your administrator gave you |
