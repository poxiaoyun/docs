# Access Tokens

The access token authenticates Git operations and API calls.

## Get the token

Moha does **not** provide a token create/delete UI. The token page simply shows the token bound to the current session and offers a copy button.

Route:

```text
/moha/home/token
```

| Element | Description |
| --- | --- |
| Token value | The token of the current session |
| Copy button | Copy to clipboard |

> ⚠️ Note: The token is tied to your session and is sensitive; never expose it in public code or docs.

## Finer-grained credentials

For multiple API keys, SSH keys or two-factor authentication, use the IAM security pages:

| Capability | Route |
| --- | --- |
| Account | `/iam/account/general` |
| Password | `/iam/account/change-password` |
| API Key | `/iam/account/api-key` |
| SSH Key | `/iam/account/ssh-key` |
| MFA | `/iam/account/mfa` |

## Use the token with Git

```bash
git clone https://<username>:<token>@moha.your-domain/moha/models/my-org/my-model.git
git config --global credential.helper 'cache --timeout=3600'
```

> ⚠️ Note: `credential.helper store` writes the token to disk in plain text; avoid it in shared environments.

## Use the token with the API

```bash
curl -H "Authorization: Bearer <token>" \
  https://moha.your-domain/api/moha/organizations/my-org/models/my-model
```

> ⚠️ Note: Paths follow the repository resolve API (`/api/moha/organizations/<organization>/<type>/<repository>/...`); the exact contract is not confirmed here.

## Use the token with the SDK

```bash
pip install moha-hub
```

```python
from xiaoshiai_hub import snapshot_download

snapshot_download(
    repo_id="my-org/my-model",
    repo_type="models",
    username="your-username",
    password="<token>",
)
```
