# Account Settings

Moha has no standalone account-settings page. Account information, security policy and credentials are managed in the **IAM account centre**, reachable from the avatar menu.

## IAM account centre

| Page | Route | Description |
| --- | --- | --- |
| General | `/iam/account/general` | Personal information |
| Change password | `/iam/account/change-password` | Update the login password |
| Change email | `/iam/account/change-email` | Bind/change email |
| Change mobile | `/iam/account/change-mobile` | Bind/change mobile |
| MFA | `/iam/account/mfa` | Two-factor authentication |
| API Key | `/iam/account/api-key` | Manage API keys |
| SSH Key | `/iam/account/ssh-key` | Manage SSH public keys |
| Theme | `/iam/account/theme` | UI theme |

## Tenant and organization

- After sign-in you can select a tenant (`/auth/select-tenant`) or register one (`/auth/regist-tenant`).
- Organization members and roles are managed on the organization page, see [Organizations](/moha/home/organizations).

> ⚠️ Note: Moha only displays and copies the current access token (`/moha/home/token`). Create, rotate or revoke credentials in IAM (API Key / SSH Key).
