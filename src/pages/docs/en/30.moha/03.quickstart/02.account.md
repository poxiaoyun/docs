# Account Settings

Moha has no separate "account settings" page. Your account, password, phone and email are all managed in **Settings** (also called the user centre), which you open from the avatar in the top-right corner.

This page explains what each tab there does, and how Moha's **access token** differs from the platform's **API key**.

## Before you start

- You are signed in to the platform and can see the avatar in the top-right corner.

## Open your settings

1. Click the **avatar** in the top-right corner.
2. In the panel that slides out on the right, click **Settings**.
3. The page title shows **User Center**, with a row of tabs below it — click a tab to switch.

The avatar panel also has two handy buttons:

- **Switch Tenant**: move to another organization.
- **Sign out**: sign out of the current account.

## What each settings tab does

| Tab | What you can do |
| --- | --- |
| General | View and change personal information such as your nickname |
| Password | Change the login password — enter the old one, then the new one twice |
| Email | Bind or change your email; a verification code is required |
| Mobile Number | Bind or change your phone number |
| API Key | Create and manage keys for **calling model APIs** |
| SSH Keys | Add a local SSH public key so you can pull repositories without a password |
| Multi-factor Authentication | Turn on two-factor sign-in, verified with an authenticator app on your phone |
| Theme | Switch the interface theme |

## Switch to another organization

1. Click the **avatar** in the top-right corner.
2. Click **Switch Tenant**.
3. On the **Select your tenant** page, select the target organization and click **Enter Platform**.
4. If the organization is not listed, click **Create Tenant** to make one yourself.

## An access token is not an API key

Both are called "keys", but they are used for completely different things — do not mix them up:

| Name | Where it lives | What it is for |
| --- | --- | --- |
| Access token | Moha **Home → Access Tokens** | Command-line downloads and uploads, Git pull/push, SDK authentication |
| API Key | Settings → API Key | Calling model inference APIs (the AI capabilities) |

For downloads and uploads in Moha you use the **access token**, see [Access Tokens](/moha/quickstart/token).

:::warning The Secret Key is shown only once

When you generate an API key you are given both an Access Key and a Secret Key, and the Secret Key **appears only this one time**. Copy and save it immediately; once you close the dialog it is gone and you can only generate a new one.

:::

:::tip How to find your SSH public key

Adding an SSH key requires pasting a public key, usually stored at `~/.ssh/id_rsa.pub` or `~/.ssh/id_ed25519.pub` on your machine. Open it in a text editor and copy the whole line — do not paste the private key (the file without the `.pub` suffix).

:::
