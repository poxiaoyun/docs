# Resources I created

This page is your **asset list** in Moha. The models, datasets, images and Spaces you created are gathered here by type, so you can confirm at a glance what you have uploaded and whether it succeeded.

## How to get there

Click **Home** in the top navigation, then click **Created by Me** in the left menu.

## The blocks on this page

| Area | What it shows you | What you can do |
| --- | --- | --- |
| Type tabs | Four tabs: Model / Dataset / Images / Space, each with a count | Click to switch the resource type |
| Search box | Search by name or alias | Type a keyword and press Enter |
| Advanced search | Filters such as category, organization and license | Expand it, tick conditions to narrow the list |
| Refresh icon | A refresh button | Click once to fetch the latest list |
| Create button | The **Create Model** and similar buttons at the top right | Go straight to the creation page for that type |
| Resource list | Cards for the repositories you created in the current type | Click a card to open the repository details |

## Browse by type

1. Click the **Model**, **Dataset**, **Images** or **Space** tab at the top of the page.
2. The number next to each tab is how many you have created in that type.
3. The list below switches to the matching type.

## Find a resource

1. Type a name in the search box, or use the `organization/name` format, for example `ai-lab/qwen2-7b`.
2. For finer conditions, click the filter button to the right of the search box and tick category, organization or license in the drawer.
3. Active conditions appear as small tags under the search box. Click the cross on a tag to remove it.

## Create a new resource

1. Click a creation button at the top right: **Create Model**, **Create Dataset**, **Create Image** or **Create Space**.
2. The create button follows the current tab: whichever type you are viewing is the type you create.
3. Submit the form and the new resource appears in the current list.

## Confirm it worked

- Switching tabs updates both the list and the counts on the tabs.
- After a successful creation, the new resource appears in the list; click it to see the details.
- If the list shows **No data**, you have not created any resource of that type yet.
