# Home page overview

The home overview page integrates resource discovery with quick actions and is a natural first page after entering Moha.

## Entry path

Moha -> Home -> Overview

Path: `/moha/home/overview`

## Page blocks

According to the front-end implementation, the home overview mainly contains:

| Block | Description |
| --- | --- |
| Banner carousel | Displays platform banners, which can link to external or featured content |
| Quick creation cards | Quickly create models, datasets, images and Spaces |
| Recommended resources | Displays recommended models or resource lists according to the current paging conditions |
| Announcement list | Displays active announcements and opens a detail dialog |

## Quick creation

The home page provides four direct entries:

- Create a new model
- Create a new dataset
- Create a new image
- Create a new Space

These entries jump straight to the corresponding creation page, which is convenient when you already know what you want.

## Applicable scenarios

- New users can see what the platform is currently recommending.
- Maintainers can start a creation flow directly from the home page.
- Follow announcements, events, featured content or resource recommendations.
