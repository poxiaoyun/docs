# Access tokens and announcements

The left side of the Moha home page has two small, frequently used pages: **Access Tokens** does one thing — hand you the current token — while **Announcements** is where the platform publishes messages. Both live in the left menu and open with a single click.

## Access Tokens

### How to get there

Click **Home** in the top navigation, then click **Access Tokens** in the left menu.

![Access token page: one line of explanatory text and a single token box, with a copy icon on the right](/assets/screenshots/moha/token-01.png)

The whole page is that one token box — there is no generate, refresh or revoke button — and the token in the screenshot is blurred. That string stands in for your identity and is shared by the command line, Git and the SDK.

### What is on the page

| Element | Description |
| --- | --- |
| Token value | The token for the current session, a long string of characters |
| Copy button | Click it to put the token on your clipboard |

Above the token there is a line of explanation: the access token verifies your identity and gives you access to restricted resources, and it can also be used to call other Moha services such as API-Inference.

### How to use it

1. Click the copy button and paste the token somewhere safe.
2. Use it when logging in from the command line: `moha login https://<platform-address> --token <token>`.
3. Use it as the password when pulling a private repository over Git.

:::warning A token is your identity

Anyone who has the token can act as you. Do not commit it to a code repository, do not post it in chat groups, and do not leave it in screenshots. For what to do if a token leaks, see [Access Tokens](/moha/quickstart/token).

:::

## Announcements

### How to get there

Click **Home** in the top navigation, then click **Announcements** in the left menu.

![Announcements page: a table with just three columns — title, content and time — showing "No data" when nothing is published, with page size and paging at the bottom](/assets/screenshots/moha/home-announcements-01.png)

The page is read-only: only a search box and a refresh button, no create entry. An empty table simply means the platform has no live announcement — a normal state, not a permissions problem.

### What columns the table has

| Column | Description |
| --- | --- |
| Title | The announcement name; click it to open the full text |
| Content | A summary of the announcement body |
| Time | When the announcement takes effect |

### How to read them

1. Click the **Title** of any row to open a dialog with the full text.
2. Click **Close** in the dialog to return to the list.
3. When there are many announcements, type a title keyword in the search box above the table to filter.

Announcements are typically used for platform updates, maintenance notices and event information, so it is worth checking back regularly.
