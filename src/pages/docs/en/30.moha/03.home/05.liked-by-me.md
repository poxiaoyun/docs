# Liked by Me

"Liked by Me" is a personal workspace view that collects the models, datasets, images and Spaces you have starred.

## Entry

Home sidebar -> **Liked by Me**

Route: `/moha/home/liked-by-me`

## Page structure

| Block | Description |
| --- | --- |
| Type tabs | Switch between Models / Datasets / Images / Spaces; each tab shows the favourite count |
| Toolbar | Keyword search, advanced filters, total and refresh |
| Resource list | Unified data cards for the selected type |

## Types and statistics

The current type comes from the `type` query parameter (default `models`):

| Tab | Value | Statistics field |
| --- | --- | --- |
| Models | `models` | `statistics.models` |
| Datasets | `datasets` | `statistics.datasets` |
| Images | `images` | `statistics.images` |
| Spaces | `spaces` | `statistics.spaces` |

Counts come from `getMyFavoriteDataManagersStatistics`. Switching type updates the query parameter and resets to page 1.

## List and filters

- Data comes from `listMyFavoriteDataManagers`, `size=24` per page.
- Keyword search is supported.
- Advanced filters scope facets with `kind: 'my-favorite'`; models and datasets use their own faceted endpoints.

## Use cases

- Jump back to a model or dataset you starred earlier.
- Check whether a starred resource has been updated.
- Complements [Created by Me](/moha/home/created-by-me) and [Organizations](/moha/home/organizations): mine / starred / team-shared.
