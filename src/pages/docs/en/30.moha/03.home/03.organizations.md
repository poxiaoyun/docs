# Organizations

Organizations manage resources from a team perspective. Each organization exposes models, datasets, images and Spaces, together with avatars, descriptions and resource statistics.

## Entry

Home sidebar -> **Organization homepage**.

Real route: `/moha/organizations/:organization`, and `/moha/organizations/:organization/:type` when entering a resource type (`type` is `models` / `datasets` / `images` / `spaces`).

> ⚠️ Note: The sidebar's "Organization" button points to `/moha/organizations/:organization` (`home/layouts/layout.tsx` uses `paths.moha.organization.root(tenantId)`), which is not under `/moha/home`. Under `/moha/home` only `overview`, `created-by-me`, `liked-by-me`, `token` and `announcements` exist.

## Page structure

| Block | Description |
| --- | --- |
| Organization info card | Avatar, alias and description |
| Resource tabs | Switch between models, datasets, images and Spaces |
| Resource list | Resources of the selected type in this organization |
| Other organizations | Switch between organizations |

## Resource view

- See how resources accumulate from a team perspective.
- Browse public or internal resources shared by the organization.
- Enter a repository to work on files, discussions and settings.

> 💡 Tip: To see only what you created, use "Created by Me" / "My resources"; use organizations for the whole team's assets.
