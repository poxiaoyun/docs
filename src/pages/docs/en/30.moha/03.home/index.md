# Home page and personal workbench

The Moha home page is not a simple landing page, but a workbench built around "discovering resources, managing personal assets and entering organization space".

## Page composition

| Region | Description |
| --- | --- |
| Home overview | Recommended resources, banners, quick creation entry, announcements |
| Created by me | View the models, datasets, images and Spaces you created, by resource type |
| Liked by me | Aggregate the resources you liked for easy access again |
| Access token | Copy the access token of the current session |
| Announcements | View platform announcement details |
| Organization home | Enter the resource list under an organization |
