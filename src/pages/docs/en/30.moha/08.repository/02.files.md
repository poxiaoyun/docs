# File browsing and version viewing

The file page is one of the core pages for repository collaboration. It is used to inspect the directory structure, preview file contents and trace historical changes.

## Capabilities

| Capability | Description |
| --- | --- |
| File tree browsing | Browse directories and sub-files |
| File content preview | Switches between directory view and file view based on file type |
| Commit history | View commits under a specified reference |
| Diff comparison | Compare a file across versions |
| Propose changes | Enter the Pull Request flow from the file page |
| Download and pull | Download files or run Git operations with a token |

## Typical paths

All file routes hang off `/moha/:type/:organization/:id/file` (`:type` is `models` / `datasets`; Spaces use `/moha/spaces/:organization/:id/file`):

- File tree: `/file/:reference`
- Specific file: `/file/:reference/:file`
- Commit history: `/file/:reference/commits`, `/file/:reference/:file/commits`
- Diff: `/file/:reference/diff`, `/file/:reference/:file/diff`
- Propose changes: `/file/:reference/:file/pullrequest`

## Usage tips

1. Select a reference version or branch (`reference`).
2. Browse the directory to find the target file.
3. Go to the commit history or diff page when you need to review history.
4. After editing, open a Pull Request from the diff page and record the background in the discussion page.

> 💡 Tip: Image repositories have no file page, only a "Tags" page. `freezes` is its own tab and is not nested under the file page.
