# Repository detail page structure

Open a model, dataset, image or Space and you get the same layout: **a top info bar, a row of tabs, and the tab content**. Once you understand this page, you will know where to start on every other tab.

## Opening a repository

1. Choose the resource type from the Moha top navigation: **Models**, **Datasets**, **Images** or **Spaces**.
2. Click any card in the list.

It opens on the first tab (the description page), with the repository name shown at the top.

## The top info bar

The top bar differs slightly between resource types:

| Where | What you can do |
| --- | --- |
| **Back** at the top left | Return to the list page you came from |
| Organization name / repository name | Click the organization name to see that organization's resources; the copy button next to the repository name copies "organization/repository" |
| Favorite button (heart with a number) | Click to add or remove a favorite; the number is the favorite count |
| Metadata tags | Group, framework, license, tags, language, type and so on, to help you judge quickly whether this resource suits you |
| Action buttons at the top right | Models have **Download Models**, **Deploy** and **Use this model**; datasets have **Download Datasets** and **Use this dataset**; images have **Download image** |

A Space detail page has two extra items in the top bar: a label showing the running status, and an **Operations** button on the right (publish, stop, republish, logs).

## Switching tabs

Click a tab name to switch; the page does not reload. Which tabs are available depends on the resource type:

| Tab | Model | Dataset | Image | Space |
| --- | --- | --- | --- | --- |
| Description (Model card / Dataset card / Image card / Overview) | Yes | Yes | Yes | Yes |
| File | Yes | Yes | No | Yes |
| Snapshot | Yes | Yes | No | Yes |
| Tags | No | No | Yes | No |
| Discussion & Feedback | Yes | Yes | No | Yes |
| Settings | With permission | With permission | With permission | With permission |

## Why can't I see Settings?

The **Settings** tab is only shown to people with management permission. Any one of the following is enough:

- A system administrator.
- The owner of this repository.
- An administrator of the organization that owns this repository.
- Someone added to this repository with the **Admin** role (models, datasets and images also accept the **read-write** role).

If you need to manage this repository but cannot see Settings, leave a message under **Discussion & Feedback**, or contact the repository owner or an organization administrator and ask them to add you as a member on the settings page.

:::tip Want to check whether you have permission?
Look for **Settings** among the tabs. If it is missing, your account has no management permission in this repository. If it is there, you can change visibility, members and metadata.
:::

## Confirming the result

- When you switch tabs the last part of the address bar changes with it (such as `/content`, `/file`, `/freezes`, `/setting`), so refreshing the page returns you to the same tab.
- The favorite button turns solid and the number goes up by one, which means the favorite was saved.
