# Version Freezes

"Version Freezes" is a tab shared by model, dataset and Space repositories (`value` = `freezes`). It freezes a branch/commit into an immutable snapshot with diff and rollback support.

## Entry

Repository detail page -> **Version Freezes** tab

```text
/moha/<type>/<organization>/<repository>/freezes
```

> 💡 Tip: Freezes also appear in the section switcher at the top of the File tab, where you can switch the view to a freeze like a branch.

## Freeze list

The list requests `size=100` by default and shows:

| Column | Field | Description |
| --- | --- | --- |
| Title | `title` | Falls back to the freeze `id` when empty |
| Branch | `ref` | Reference that was frozen |
| Commit | `commit` | Commit hash (first 12 chars in the list) |
| Creator | `createdBy` | Who created the freeze |
| Created | `createdAt` | Formatted time |
| Actions | — | Diff / Rollback / Delete |

The `reason` is shown beneath the title.

## Create a freeze

| Field | Description |
| --- | --- |
| `title` | Title, at most 32 characters |
| `reason` | Multi-line reason (optional) |

Submission uses `reference` (default `main`) and an optional `commit` to locate the version.

## Diff

The diff request renders a split view of changed files. If the diff data exceeds 4 MiB (`4 * 1024 * 1024`) it is not rendered and a "too large" notice is shown instead.

## Rollback

Rollback resets the repository to the freeze:

- Called with `{ ref: freeze.ref, mode: 'reset' }`.
- It is destructive; the dialog shows the target `ref` and `commit` and asks for confirmation.

> ⚠️ Note: Rollback changes the current repository state; confirm the target freeze first.

## Delete

Deleting a freeze removes the freeze record only (current files are unaffected).
