# Discussions & Collaboration

The **Discussion & Feedback** tab is this repository's message board plus code review area. Ask about a problem you ran into, suggest an improvement, or ask someone to review a file change — all of it happens here. Discussions stay with the repository, which makes them much easier to trace than a conversation.

## Before you start

Sign in to Moha and make sure you can open this repository. Image repositories do not have this page.

![The Discussions tab: the All / Discussions / Pull requests sub-tabs, Refresh and "+ Add discussion" on the right, and the discussion entries with reply counts below](/assets/screenshots/moha/repo-model-discussion-01.png)

The number after the **Discussions** tab counts the entries (3 here). **Pull requests** is for reviewing changes to repository files; ordinary questions go under **Discussions**.

## Page layout

There are three sub-tabs at the top that filter the list:

| Sub-tab | What it shows |
| --- | --- |
| **All** | Every discussion and pull request |
| **Discussion** | Only questions and feedback topics |
| **Pull Request** | Only reviews of code changes |

**Add Discussion** in the top right starts a new topic. Each entry in the list shows its title, the author, the creation time and the reply count; pull requests also show a **Merged** or **Closed** status.

## Starting a discussion

1. Open the repository's **Discussion & Feedback** tab.
2. Click **Add Discussion** in the top right (on mobile it is in the menu icon on the right of the page).
3. Fill in the **Title** (required).
4. Fill in the **Content** (required); it supports rich text such as formatting, lists and code blocks.
5. Click **Confirm**.

## Reading and replying

1. Click a discussion title in the list to open its details.
2. Type into the box at the bottom of the detail page and submit to reply.
3. Content you published yourself can be changed with **Edit Content**; click delete to remove the whole discussion.

:::warning Deleting a discussion also deletes its replies
After you delete a discussion, **all replies under it are deleted as well** and cannot be recovered. Deleting a single reply only affects that reply.
:::

## Reviewing code changes (pull requests)

A pull request is the flow "change a file → ask for review → merge":

1. First change the file in the **File** tab, or click **Create Pull Request** on the file preview page.
2. On the **Create Pull Request** page, check the changes and submit. It then appears automatically in the **Pull Request** list under **Discussion & Feedback**.
3. For a pull request in the list you can:
   - **View**: compare the before and after in a side-by-side layout;
   - **Merge**: merge the change for real;
   - **Close**: mark it **Closed** and leave it unmerged for now;
   - **Reopen**: open a closed one again.

:::warning Look at the diff before merging
**Merge** writes the change into the repository for real. Check the diff first with **View** to confirm every change is what you expect, then merge.
:::

## Confirming the result

- After you start a discussion the topic appears in the list immediately, with the reply count starting at 0.
- Once a pull request is merged its status shows **Merged**; a closed one shows **Closed**.
