# Integrate with Transformers & Datasets

You already use the Hugging Face style (`AutoModel.from_pretrained(...)`, `load_dataset(...)`) and want to consume models and datasets from the platform directly.
This page gives you two working routes and spells out what each one needs and what its limits are.

## Before you start

What you need to install on top of the SDK:

| What you want to do | What to install |
| --- | --- |
| Download files only | `pip install moha-hub` |
| Load models and run inference | Also `pip install transformers torch` |
| Load datasets | Also `pip install datasets` |
| Use the "platform as endpoint" route | Also `pip install huggingface_hub` |

The easiest way to supply the platform address and access token is through environment variables:

```bash
export MOHA_ENDPOINT="<platform-url>"
export MOHA_TOKEN="<access-token>"
```

## Choosing between the two routes

| Route | How it works | Advantages | Cost |
| --- | --- | --- | --- |
| Download first, then load locally | Download a directory with the SDK and hand the local path to `from_pretrained()` / `load_dataset()` | Most reliable, independent of the network, reusable offline | You manage the disk space and the directory |
| Use the platform as a Hugging Face endpoint | Set `HF_ENDPOINT` and let `transformers` / `huggingface_hub` pull by repository name | Smallest code change, fetches only the files it needs | Needs a token; covers only the repository read and write style APIs |

**Start with the first route**, then decide later whether to switch to the endpoint.

## Route 1: download first, then let the libraries load it

This is the least error-prone path: the SDK fetches the files and `transformers` / `datasets` only ever see a local directory.

```python
from transformers import AutoModelForCausalLM, AutoTokenizer
from xiaoshiai_hub import snapshot_download

# 1. Pull the whole model repository to the local machine
local_dir = snapshot_download(
    repo_id="ai-lab/qwen2-7b",
    local_dir="./models/qwen2-7b",
    token="<access-token>",
)
print("Model downloaded to:", local_dir)

# 2. From here on use the normal local-directory style
tokenizer = AutoTokenizer.from_pretrained(local_dir, trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained(local_dir, device_map="auto")
```

When you want only part of the files, use the filter parameters so you do not pull weights you do not need:

```python
local_dir = snapshot_download(
    repo_id="ai-lab/qwen2-7b",
    local_dir="./models/qwen2-7b",
    allow_patterns=["*.json", "*.safetensors", "*.model"],
    token="<access-token>",
)
```

How you load a dataset depends on the format stored in the repository; use `load_dataset` with the matching format:

```python
from datasets import load_dataset

# The repository stores parquet
ds = load_dataset("parquet", data_files="./data/train-*.parquet", split="train")

# The repository stores json / jsonl
ds = load_dataset("json", data_files="./data/train.jsonl", split="train")

print(ds[0])
print("Samples:", len(ds))
```

`data_files` accepts local paths and wildcards, so download the dataset directory first (`repo_type="datasets"`) and then load it by format.

## Route 2: use the platform as a Hugging Face endpoint

The platform provides a read-only interface compatible with Hugging Face, so `huggingface_hub` and `transformers` can treat it as `HF_ENDPOINT`.

:::warning Set the environment variable before importing
`HF_ENDPOINT` is read the first time `huggingface_hub` / `transformers` is imported. Setting it after the `import` has no effect, so always set the environment variable before importing.
:::

```python
import os

# Must be set before the imports
os.environ["HF_ENDPOINT"] = "<platform-url>/moha/huggingface"
os.environ["HF_TOKEN"] = "<access-token>"

from transformers import AutoModelForCausalLM, AutoTokenizer

# Write the repository name as "organization/repository"
tokenizer = AutoTokenizer.from_pretrained("ai-lab/qwen2-7b", trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained("ai-lab/qwen2-7b", device_map="auto")
```

To download just one file, or to control where it lands:

```python
from huggingface_hub import hf_hub_download, snapshot_download

path = hf_hub_download(
    repo_id="ai-lab/qwen2-7b",
    filename="config.json",
    revision="main",
)
print(path)

snapshot_download(
    repo_id="ai-lab/qwen2-7b",
    revision="main",
    local_dir="./qwen2-7b",
)
```

### What the endpoint supports

| Capability | Supported |
| --- | --- |
| Repository info (including the file list) | Yes |
| Directory tree listing and browsing | Yes |
| Listing branches and tags | Yes |
| Downloading a single file by branch or tag | Yes |
| Batch queries for information about several files | Yes |
| On-the-fly dataset conversion and website-style preview APIs | No, load local files instead |

About versions: `revision` must be a **branch name or a tag name** (run `moha refs <organization>/<repository>` to see what is available), not a commit SHA, because the mirror endpoint resolves references by name only.

To reproduce a frozen version exactly, use the tag name that corresponds to that snapshot.

### Private repositories

The endpoint layer requires authentication, so **always setting `HF_TOKEN`** is the safest option. For a private repository use an access token generated on the platform; an invalid or expired token results in a 404 or an authentication failure.

## Full example: load a model and data, then run inference

```python
import os

os.environ["HF_ENDPOINT"] = "<platform-url>/moha/huggingface"
os.environ["HF_TOKEN"] = "<access-token>"

from datasets import load_dataset                       # noqa: E402
from transformers import AutoModelForCausalLM, AutoTokenizer  # noqa: E402
from xiaoshiai_hub import snapshot_download              # noqa: E402

# Model: fetch on demand through the endpoint
MODEL_ID = "ai-lab/qwen2-7b"
tokenizer = AutoTokenizer.from_pretrained(MODEL_ID, trust_remote_code=True)
model = AutoModelForCausalLM.from_pretrained(MODEL_ID, device_map="auto")

# Dataset: download locally first, then load by format (more reliable)
data_dir = snapshot_download(
    repo_id="ai-lab/my-dataset",
    repo_type="datasets",
    local_dir="./data/my-dataset",
)
ds = load_dataset("json", data_files=f"{data_dir}/*.jsonl", split="train")
print("Sample:", ds[0])

# Inference
prompt = "Introduce yourself in one sentence:"
inputs = tokenizer(prompt, return_tensors="pt").to(model.device)
outputs = model.generate(**inputs, max_new_tokens=64, do_sample=True, temperature=0.7)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
```

## Common errors

| Error | Meaning | What to do |
| --- | --- | --- |
| `HF_ENDPOINT` is set but requests still go to huggingface.co | It was set too late | Move the `os.environ[...]` lines above every `import` |
| `RepositoryNotFoundError` / 404 | The repository does not exist, you have no access, or `HF_TOKEN` did not take effect | Check the `organization/repository` name; confirm the token is valid and `HF_TOKEN` is set |
| `RevisionNotFound` | The name in `revision` does not exist in the repository | Use `moha refs <organization>/<repository>` to see the available branches and tags |
| `EntryNotFound` | The repository has no such file or path | Check `filename`, or list the directory to see the real file names |
| `OSError: ... does not appear to have a file named config.json` | This is a dataset or a weights-only repository, not a complete transformers model | Confirm you are loading a model repository, or load it manually according to the actual file structure |
| `load_dataset("organization/name")` cannot find the data files | The endpoint has no automatic dataset conversion | Download the dataset locally first, then use `load_dataset("<format>", data_files=...)` |
| `snapshot_download` reports no permission | A private repository without a token | Set `HF_TOKEN`, or use the SDK's `snapshot_download(token=...)` instead |
