# SDK introduction

The Moha SDK is a toolkit that lets you **work with Moha repositories without opening a web page**: install it once and you can log in, upload, download, and manage repositories from the terminal with the `moha` command, and call the same capabilities from Python code. If you frequently upload models in bulk or write automation scripts, it saves a lot of clicking.

## It has two parts

| Part | What it is | How you use it |
| --- | --- | --- |
| The `moha` command line tool | A terminal command available after installation | Type `moha <subcommand>` in a terminal |
| The Python library | A set of functions and classes you can import | `from xiaoshiai_hub import ...` in a `.py` file |

Both parts are installed from the same package, so one install gives you both.

## What you can do

| Capability | Command line | Python |
| --- | --- | --- |
| Log in and out | `moha login` / `moha logout` | `login()` / `delete_token()` |
| Select the current organization | `moha organization use` | `save_current_organization()` |
| List, create, inspect, update, and delete repositories | `moha list` / `create` / `info` / `update` / `delete` | The matching methods on `HubClient` |
| Manage branches | `moha refs` / `branch-create` / `branch-delete` / `branch-list` | `get_repository_refs()` / `create_branch()` and others |
| Upload and download | `moha upload` / `download` | `upload_file()` / `upload_folder()` / `moha_hub_download()` / `snapshot_download()` |
| Publish and manage Spaces | `moha deploy` / `status` / `logs` | `deploy_space()` / `get_space_status()` |
| Encrypt large model files | `moha upload --encrypt` | `upload_file(encryption_password=...)` |
| AI assistant | `moha ai` | Not available |

## Minimal working example

Once installed, one line in the terminal lists the repositories in the current organization:

```bash
moha list model
```

The same thing in Python:

```python
import os

from xiaoshiai_hub import HubClient

# Pass the token explicitly (or export MOHA_TOKEN first)
client = HubClient(token=os.environ["MOHA_TOKEN"])
repos = client.list_repositories(
    repo_type="models",
    scope="organization",
    organization="<organization>",
)
for repo in repos:
    print(repo.name)
```

Line by line:

| Code | Meaning |
| --- | --- |
| `HubClient(token=...)` | Creates an object connected to the platform. The token **must be passed explicitly** — `HubClient()` does not read the login saved on this machine |
| `repo_type="models"` | List model repositories only; you can also use `"datasets"` or `"spaces"` |
| `base_url` | The platform address. When omitted it comes from `MOHA_ENDPOINT`, and falls back to a built-in default |
| `scope="organization"` | Look at one organization only; when you use this you must also pass `organization` |
| `organization="<organization>"` | The organization to look at |
| `repo.name` | The repository name |

:::warning Logging in on the command line is not logging in for Python
`moha login` only writes the token into a local config file for the `moha` command itself. `HubClient` does **not** read that file, nor `~/.moha/config.json`, so Python code always has to pass `token` itself.
:::

:::info Where the token comes from
Copy it from the **Access Tokens** page in the web UI and put it in the `MOHA_TOKEN` environment variable. See [Authentication and Token Management](./authentication) for details.
:::

## Relationship to the Hugging Face ecosystem

The platform provides an interface compatible with the Hugging Face Hub. On a machine that already has `transformers`, `datasets`, and `huggingface_hub` installed, you only need to point the address at the platform and your existing code mostly works unchanged:

```bash
export HF_ENDPOINT=https://<platform-url>/moha/huggingface
export HF_TOKEN=<access-token>
```

Option reference:

| Option | Description |
| --- | --- |
| `HF_ENDPOINT` | Points at the platform's compatible endpoint; it must end with `/moha/huggingface` |
| `HF_TOKEN` | Your access token; you can leave it out for public repositories |

Besides the SDK, every repository on the platform also exposes a Git address, so you can pull it directly with `git clone`, with large files going through Git LFS.

## What you need to do

1. Install the tool as described in [Installation and environment configuration](./install).
2. Log in once as described in [Authentication and Token Management](./authentication).
3. Then run your first command from [Quick start in 5 minutes](./quick-start).

## Common problems

| Symptom | Likely cause | What to do |
| --- | --- | --- |
| `import xiaoshiai_hub` reports that the module cannot be found | It is not installed, or it was installed into a different Python environment | Run your code with the same Python that installed the package; see [Installation and environment configuration](./install) |
| The SDK connects to an internal test address instead of your platform | An old address is left in an environment variable | Check and clear `MOHA_ENDPOINT`, then try again |
