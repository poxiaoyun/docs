# SDK introduction

The Moha repository is compatible with HuggingFace Hub's API and SDK, so you can use familiar tools to interact with the platform.

## Compatibility

The Moha repository is compatible with the following tools and libraries:

| Tool | Description |
|------|------|
| `git` + `git-lfs` | Standard Git operations |
| `transformers` | Model loading and inference |
| `datasets` | Dataset loading and processing |
| `huggingface_hub` | Hub API operations |

## Configure the environment

Before using the SDK, point it at the Moha HuggingFace-compatible endpoint. The endpoint is `${origin}/moha/huggingface`:

```bash
# Option 1: environment variable
export HF_ENDPOINT=https://moha.your-domain/moha/huggingface

# Option 2: set it in Python
import os
os.environ["HF_ENDPOINT"] = "https://moha.your-domain/moha/huggingface"
```

## Authentication

```bash
# Configure the access token
export HF_TOKEN=your_access_token
```

> 💡 Tip: Any tool compatible with HuggingFace Hub can be used directly by configuring `HF_ENDPOINT` to point at the Moha repository.
