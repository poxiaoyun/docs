# Quick start in 5 minutes

This page takes you from zero to a working `moha` command line tool, then walks through login, downloading a repository, and uploading a local file.
You only need to copy and paste commands. No Python code required.

:::tip Three things you need

- A computer with internet access and Python installed
- The address of your Moha platform (in the form `https://<platform-url>`, ask your administrator)
- Your platform username and password, or an access token

In the examples below, replace anything inside angle brackets such as `<platform-url>`, `<organization>`, and `<model-name>` with your own real values.

:::

## Before you start

- Make sure **Python 3.10 or later** is installed. Run `python3 --version` in a terminal and check that the version is 3.10 or higher.
- If Python is not installed yet, download it from the [Python website](https://www.python.org/downloads/).
- Have your platform **address** and **username/password** (or an access token) ready.

## Step 1: install the command line tool (about 30 seconds)

Copy the following line into your terminal and press Enter:

```bash
pip install moha-hub
```

After it finishes, run this command to confirm the tool works:

```bash
moha --version
```

If you see a version number such as `moha 2.0.1`, the tool is installed.

Option reference:

| Option | Description |
| --- | --- |
| `pip install moha-hub` | Installs the Moha command line tool from the official Python package index; the package name is always `moha-hub` |
| `moha --version` | Prints the installed version number; if nothing is printed, the installation failed |

## Step 2: log in (about 1 minute)

Replace the address with your own and run:

```bash
moha login https://<platform-url>
```

The terminal then asks you a few questions in order:

1. When you see `Token (leave empty to log in with username/password):`, **press Enter** to log in with a username and password.
2. When you see `Username:`, type your platform username and press Enter.
3. When you see `Password:`, type your password and press Enter (the screen shows no characters while you type, which is normal).
4. If the platform has several organizations, it lists them with numbers. Type the **number or the organization name** you want to use and press Enter.

On success the terminal shows `Login succeeded` together with the current organization and the path of the configuration file.

Option reference:

| Option | Description |
| --- | --- |
| `https://<platform-url>` | The platform address. It **must start with `https://`**; a bare domain is not accepted |
| `--username <username>` | Optional. Put the username in the command to skip the interactive prompt |
| `--password <password>` | Optional. Put the password in the command to skip the interactive prompt |
| `--token <access-token>` | Optional. Use an existing access token instead of a username and password |

:::warning About the platform address
Always write the address as `https://<platform-url>`. A form without the scheme, such as `moha.example.com`, fails immediately with an error saying the address format is wrong.
:::

## Step 3: download a repository (about 1 minute)

Using a repository ID that someone shared with you (the format is `organization/repository`), run:

```bash
moha download <organization>/<model-name>
```

For example:

```bash
moha download demo/my-model
```

When the command finishes it prints `Download completed` and the local path.
If you do not specify a directory, files are downloaded to `./downloads/<organization>_models_<repository>/` inside the current directory.

Option reference:

| Option | Required | Default | Description |
| --- | --- | --- | --- |
| `<organization>/<repository>` | Yes | None | The repository to download; always the first positional argument |
| `--local-dir` | No | `./downloads/<organization>_models_<repository>/` | Where to save the download |
| `--repo-type` | No | `model` | Repository type: `model`, `dataset`, or `space` |
| `--revision` | No | The repository default branch | Which branch or tag to download |

## Step 4: upload a local file (about 2 minutes)

First `cd` into the directory that holds your files, then run:

```bash
moha upload <organization>/<model-name> ./your-file-or-folder
```

For example, to upload a local `config.yaml`:

```bash
moha upload demo/my-model ./config.yaml
```

When the command finishes it prints `Upload succeeded`.

Option reference:

| Option | Required | Default | Description |
| --- | --- | --- | --- |
| `<organization>/<repository>` | Yes | None | The target repository; the first positional argument **is the repository** |
| `./local-path` | Yes | None | The file or folder to upload; the second positional argument **is the local path** |
| `--revision` | No | `main` | Which branch to upload to |
| `--message` | No | None | A commit message for this upload |

:::tip Keep the order right
The upload command takes two positional arguments: **repository first, local path second**. If you swap them, the new version still recognises the command, but it is best to remember "repository first".
:::

## Verify the results

- Login: the terminal shows `Login succeeded`, and running `moha whoami` afterwards shows `Login Status: Logged in`.
- Download: the terminal shows `Download completed`, and `ls ./downloads` shows a folder named after the repository.
- Upload: the terminal shows `Upload succeeded`; open the repository on the Moha website and the file you just uploaded appears in the file list.

## Common problems

| Symptom | Likely cause | What to do |
| --- | --- | --- |
| `command not found: moha` | The install failed, or the command is not on your PATH | Check that `pip install moha-hub` printed no error, then run `python3 -m pip show moha-hub` to confirm it is installed |
| Login says the address format is wrong | The address has no `https://` | Use `https://<platform-url>` and log in again |
| Login says the username or password is wrong | The credentials are incorrect | Check your username and password, or log in with an access token instead |
| Download reports the repository does not exist | The repository name is misspelled, or you have no access | Check the spelling of `organization/repository`; for a private repository, log in with an account that has access |
| Upload reports that `--encrypt` needs a password | You passed `--encrypt` without a password | Remove `--encrypt`, or add `--encryption-password <password>` |
