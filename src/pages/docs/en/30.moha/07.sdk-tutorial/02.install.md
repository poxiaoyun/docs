# Installation and environment configuration

This page helps you install the Moha `moha` command and Python library on your computer, and confirm that the installation really worked.
Installation itself is a single command. The usual stumbling blocks are "the Python version is too old" and "the package index cannot be reached", so both are covered below.

## Before you start

| Prerequisite | Requirement | How to check |
| --- | --- | --- |
| Python | Version 3.10 or later | Run `python3 --version`; 3.10 or higher is fine |
| pip | Installed together with Python | Run `python3 -m pip --version`; it should print a version number |
| Network | Access to the Python package index | A normal internet connection works; on a corporate intranet you may need a mirror |

:::info Git LFS is not required
The Moha SDK uploads and downloads through platform APIs and **does not depend on Git or Git LFS**, so you do not need to install `git` or `git-lfs`.
You only need Git on your machine if you plan to pull repositories with `git clone`, and Git LFS only for the large files in them.
:::

## Install

Copy the following line into a terminal and press Enter to complete the main installation:

```bash
pip install moha-hub
```

If `pip` reports "command not found", use this form instead (more reliable, it does not depend on PATH):

```bash
python3 -m pip install moha-hub
```

Option reference:

| Command | Description |
| --- | --- |
| `pip install moha-hub` | Installs the latest version; the package name is always `moha-hub` (lowercase, with a hyphen in the middle) |
| `pip install "moha-hub[upload]"` | Also installs the upload dependencies; recommended if you plan to use upload commands |
| `pip install "moha-hub==2.0.1"` | Installs a specific version; replace `2.0.1` with the version you need |

:::tip Installing into a virtual environment is cleaner

If you have several Python projects on your machine, create a separate environment first to avoid interference:

```bash
python3 -m venv moha-env
source moha-env/bin/activate     # Linux / macOS
pip install moha-hub
```

Run `deactivate` when you are done. On Windows the activation command is `moha-env\Scripts\activate`.

:::

## Verify the installation

The install command finishing does not mean it succeeded. Run the following two commands in order to confirm.

First, check that the command exists and can print a version number:

```bash
moha --version
```

Second, check the help output to confirm the command starts normally:

```bash
moha --help
```

Option reference:

| Command | What you should see |
| --- | --- |
| `moha --version` | One line with a version number, such as `moha 2.0.1` |
| `moha --help` | A screen of commands listing subcommands such as `login`, `upload`, and `download` |
| `python3 -c "import xiaoshiai_hub; print(xiaoshiai_hub.__version__)"` | A version number, which means the Python library is installed too |

If either command reports that the `moha` command cannot be found, the installation did not succeed. Work through "Common installation errors" below.

## Environment variables

Besides saving credentials with login, you can pass authentication information directly to commands and code with environment variables.

| Environment variable | Purpose | Example |
| --- | --- | --- |
| `MOHA_TOKEN` | Access token, highest priority | `export MOHA_TOKEN=<access-token>` |
| `MOHA_USERNAME` / `MOHA_PASSWORD` | Authenticate with a username and password | `export MOHA_USERNAME=<username>` |
| `MOHA_ORGANIZATION` | Set the current organization | `export MOHA_ORGANIZATION=<organization>` |
| `MOHA_ENDPOINT` | Default platform address for Python code | `export MOHA_ENDPOINT=https://<platform-url>` |
| `MOHA_ENCRYPTION_PASSWORD` | Password used when encrypting uploads | `export MOHA_ENCRYPTION_PASSWORD=<encryption-password>` |
| `MOHA_AI_API_BASE` / `MOHA_AI_API_KEY` / `MOHA_AI_MODEL` | Large model configuration for the AI assistant | See [CLI tool reference](./cli-reference) |

:::warning An address in an environment variable does not override the saved one
The command line tool uses the platform address saved by `moha login`; `MOHA_ENDPOINT` mainly serves as the default address for Python code.
If you switch platforms, run `moha login https://<new-platform-url>` again.
:::

## Common installation errors

| Symptom | Likely cause | What to do |
| --- | --- | --- |
| `moha: command not found` | The package installed outside your PATH, or into a different Python environment | Run `python3 -m pip show moha-hub` to confirm it is installed; then add its `bin`/`Scripts` directory to PATH, or run scripts with `python3 -m` |
| `ERROR: Could not install packages due to an EnvironmentError: [Errno 13] Permission denied` | No permission to write to system directories | Install into your user directory with `--user`: `pip install --user moha-hub`; or use a virtual environment |
| The install hangs or reports `Read timed out` | The package index is slow to reach | Use a mirror: `pip install -i https://pypi.tuna.tsinghua.edu.cn/simple moha-hub`, or raise the timeout: `pip install --default-timeout=1000 moha-hub` |
| The install reports `No matching distribution found for moha-hub` | The Python version is below 3.10, or the system architecture does not match | Run `python3 --version` and confirm it is 3.10 or higher; upgrade Python if it is not |
| `pip` itself asks to be upgraded | The pip version is too old | Follow the prompt and run `python3 -m pip install --upgrade pip`, then retry |
| It is installed, but `import xiaoshiai_hub` fails in your code | The Python running the code is not the Python that installed the package | Use the same interpreter: `python3 -m pip install moha-hub`, then run `python3 your_script.py` |
| The corporate intranet cannot install it | There is no external network, or a proxy is required | Configure a proxy or an internal mirror first; you can also download a wheel on a connected machine and copy it over |
