# Dataset Maintenance

## Version management

Use Git branches for ongoing work and **version freezes** for immutable snapshots:

- **Branches**: `main` is the official version; create others for cleaning or experiments.
- **Freezes**: create a freeze on the "Version Freezes" tab to lock a branch/commit, with diff and rollback support (see [Version Freezes](/moha/repository/freezes)).
- The branch selector on the File tab lists both branches and freezes.

> 💡 Tip: Create a freeze before others start consuming the data, so later commits do not affect them.

## Data update

### Append data

```bash
cd my-dataset
cp /path/to/new-data/*.parquet .
git add .
git commit -m "Append 2025-01 training data"
git push origin main
```

### Roll back

```bash
git revert HEAD
git push origin main
```

## Cleaning and archiving

- Remove expired or unused data files.
- Archive historical versions to a separate branch.

> ⚠️ Note: Git history for large datasets can consume a lot of storage; periodically clean up historical large files that are no longer needed.
