# Upload Datasets

Once the dataset repository exists, the next step is moving your data files into it. There are three ways, so **pick one by file size and count**:

| Way | Best for | Limit |
| --- | --- | --- |
| Web upload | A few small files, adding a README or a config | At most 100 files and 100 MiB in total per upload |
| Git command line | Large batches of data, keeping a record of every change | Large files must go through Git LFS |
| SDK commands | Scripted uploads, or many/large files | No practical file-count limit |

## Before you start

- You need to be an **admin** or **read-write** member of the repository, otherwise there is no upload entry on the **File** page.
- For any single file larger than 5 MB, use Git LFS or the SDK rather than plain Git, or the push is rejected.
- Before using the command line, install Git and Git LFS on your machine.
- Before using the SDK, run `pip install "moha-hub[upload]"` and sign in once.

## Way 1: Upload from the web page

1. Open the dataset repository detail page and click the **File** tab.
2. Click **Add files** at the top right and choose from the menu:
   - **Upload files**: select one or more data files.
   - **Upload folder**: select a whole directory; the directory structure is kept.
   - **Create file** / **Create folder**: make a small file or an empty directory directly on the page.
3. In the window, check the file list, fill in the **Commit Message** (for example `Add training data`), and submit.
4. When it finishes you see **Committed successfully** together with this commit's ID.

:::warning Web upload size limits

- At most 100 files and 100 MiB in total per upload.
- If you go over, the page tells you to use the Moha SDK. Switch to the SDK way below.

:::

## Way 2: Upload with the Git command line

Good for batches of data files. Clone the repository first, then commit and push.

1. Open the dataset repository detail page and click **Download Datasets** at the top right.
2. In the dialog choose the **Git** tab, copy the **Clone Repository** command and run it in your terminal:

```bash
git lfs install
git clone <repository-url>
cd <repository-name>
```

3. Put the data files in this directory and tell Git LFS which large files it should handle:

```bash
# Let LFS take over the usual data files
git lfs track "*.parquet" "*.jsonl" "*.csv.gz" "*.tar.gz"

# Copy your local data in
cp /path/to/data/* .

git add .
git commit -m "Add dataset v1"
git push origin main
```

After a successful push, refresh the page and the files appear in the **File** list.

:::tip Large files must go through LFS
Plain Git refuses to push new files larger than 5 MB and asks you to use Git LFS or the Moha SDK.
Run `git lfs track` before `git add`; the registration is stored in the repository's `.gitattributes`.
:::

## Way 3: Upload with SDK commands

Good for scripted uploads; there is no file-count limit like the web page.

```bash
pip install "moha-hub[upload]"
moha login https://<platform-host> --token <access-token>
```

Upload a whole directory, or just one file:

```bash
# Upload a folder (the directory structure is kept)
moha upload ai-lab/my-dataset ./my_dataset

# Upload a single file and give it a path inside the repository
moha upload ai-lab/my-dataset ./train.parquet data/train.parquet
```

You can also add a commit message, a target branch and ignore rules:

```bash
moha upload ai-lab/my-dataset ./my_dataset \
  --message "Add training data" \
  --revision main \
  --exclude "*.log" --exclude ".git*"
```

To upload from Python:

```python
from xiaoshiai_hub import upload_folder

upload_folder(
    folder_path="./my_dataset",
    repo_id="ai-lab/my-dataset",
    repo_type="datasets",
    commit_message="Add training data",
    ignore_patterns=["*.log", ".git*"],
    token="<access-token>",
)
```

## Common data formats

| Format | Extension | Use case |
| --- | --- | --- |
| CSV | `.csv` | Tabular data anyone can read |
| Parquet | `.parquet` | Columnar, small and fast to read, good for large datasets |
| JSONL | `.jsonl` | One record per line, good for instruction and dialogue data |
| Image | `.jpg` / `.png` | Vision datasets |
| Audio | `.wav` / `.mp3` | Speech datasets |
| Archive | `.tar.gz` / `.zip` | Bundle loose files before uploading |

## Confirm the result

Go back to the **File** tab; the new files appear in the list with their sizes. Click a file name to preview text files online and check the content quickly.

## Common problems

| What you see | Likely cause | What to do |
| --- | --- | --- |
| File count exceeds 100 | The web page has a file-count limit | Use the SDK to upload |
| Total file size exceeds 100 MB | The web page has a size limit | Use the SDK to upload |
| The push is rejected for exceeding a size limit | Large files did not go through Git LFS | Run `git lfs track` first and commit again |
| A large file will not preview | The file is over the online preview size limit | Download it and look at it locally |
| There is no **Add files** button | You have no write access to the repository | Ask a repository admin for **read-write** access |
