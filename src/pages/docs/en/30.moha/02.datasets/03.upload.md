# Upload Datasets

After creating a dataset, upload files on the repository **File** tab.

## Web upload

1. Open the dataset detail page -> **File** tab.
2. Click **Upload file** and choose files or a whole folder.
3. Submitting produces one commit.

Uploads run as sessions: request capabilities, initialise the session, upload, then finalize. What you can do depends on the server-provided `supports` flags.

> ⚠️ Note: The front end enforces its own hard caps — at most 100 files and 100 MiB in total per upload (`BROWSER_UPLOAD_MAX_FILES = 100`, `BROWSER_UPLOAD_MAX_TOTAL_BYTES = 100 * 1024 * 1024`). The server may also advertise stricter values through `limits` (`maxFiles`, `maxTotalBytes`, `maxManifestBytes`, `maxPathBytes`, `maxEditableBytes`); the smaller of the two applies. The earlier "5 GB per file" claim has no basis in the front-end code and is treated as unconfirmed.

## Git push

```bash
git lfs install
git clone https://moha.your-domain/moha/datasets/my-org/my-dataset.git
cd my-dataset
git lfs track "*.parquet" "*.csv.gz" "*.tar.gz"
cp /path/to/data/* .
git add . && git commit -m "Upload dataset v2" && git push origin main
```

## SDK

```bash
pip install moha-hub
moha download --repo-type datasets my-org/my-dataset
```

## Common formats

| Format | Extension | Use case |
| --- | --- | --- |
| CSV | `.csv` | Tabular data |
| Parquet | `.parquet` | Columnar, large datasets |
| JSONL | `.jsonl` | Structured text |
| Image | `.jpg` / `.png` | Vision datasets |
| Audio | `.wav` / `.mp3` | Speech datasets |
| Archive | `.tar.gz` / `.zip` | Bundled data |

> 💡 Tip: The file page previews text files such as Markdown, JSON and YAML.
