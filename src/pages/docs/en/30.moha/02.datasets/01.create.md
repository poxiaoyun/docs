# Create Datasets

A dataset is created as a **repository**. Creating an empty repository takes a minute; you upload the data files afterwards.

## Before you start

- Sign in to your platform account first.
- Have a readable name ready, for example `chinese-qa-v2`.

## Create the dataset

1. Open the home page and click **Created by Me** on the left, then switch to the **Datasets** category.
2. Click **Create Dataset** at the top right.
3. In the **Datasets** card, fill in the basics:

   | Field | How to fill it | Notes |
   | --- | --- | --- |
   | Name | For example `Chinese QA Dataset v2` | Required. The display name others see; you can change it later |
   | ID | Generated automatically, normally leave it alone | Shown under the name as `ID: xxx`. This is the repository identifier used in repository URLs and on the command line |
   | Organization | Pick from the dropdown | Required. Decides who owns this dataset |
   | Description | For example `100,000 Chinese question-answer pairs` | Can be empty, but one sentence about the purpose helps |

   :::info
   The ID is generated from the name: Chinese characters become pinyin and only lowercase letters, digits and hyphens are kept.
   You can also click the pencil icon under the name to set it by hand. A manual ID must start with a lowercase letter and may contain only lowercase letters, digits and hyphens.
   **The ID cannot be changed after creation**, so confirm it before submitting.
   :::

4. In the **Metadata** card, add classification information (all optional, but the more you fill in the easier it is for others to find):

   | Field | How to fill it | Notes |
   | --- | --- | --- |
   | License | Pick from the dropdown, for example `apache-2.0` | Tells others how they may use this data |
   | Task | Multiple choice, for example `Question answering`, `Text Classification` | The task type |
   | Library | Multiple choice, and you can type your own | Related frameworks or tools; the list shows at most 5 |

5. In the **Dataset classification and quality** card, add more (optional):

   | Field | Notes |
   | --- | --- |
   | Industry / business domain | Which industry this data serves |
   | Project stage | Research, Development, Production and so on |
   | Languages | Which languages the data contains |
   | Text types | Dialogue, Question answering, Instruction, Code and so on |
   | Data quality level | Bronze / Silver / Gold |
   | Acquisition methods | First-party collection, Public collection, Synthetic generation and so on |
   | Custom tags | Your own tags, to make searching easier |

   :::info
   Each dimension accepts up to 30 values, each tag is at most 32 characters, and each value is at most 128 characters.
   :::

6. In the **Members** card, give colleagues access (optional):
   - Click **Add Member**, enter the **Username**, pick a **Role**, and click **Confirm**.
   - The roles are **Admin** (can manage members and has read/write access), **Read/Write** and **Read Only**.
7. Click **Confirm** to submit. Click **Cancel** to give up.

:::tip Who can see the dataset you created

- Created from **Created by Me**, a new dataset is **Private** by default, so only you can see it.
- To share it with colleagues or the public, change it to **Internal** or **Public** afterwards under **Settings** then **Visibility**.
- If you create it from an organization page, the visibility is set to **Internal** directly and all organization members can see it.

:::

## Confirm the result

After submitting you go back to the **Created by Me** list and can see the new dataset. Clicking it opens its repository detail page, which is empty for now. Go to the **File** tab to upload data, see [Upload Datasets](/moha/datasets/upload).

## Common problems

| What you see | Likely cause | What to do |
| --- | --- | --- |
| "Required" when submitting | The name or organization is missing | Fill them in and submit again |
| The name format is rejected | The name uses Chinese punctuation or special characters | Use a plain letters-and-digits name |
| There is no **Create Dataset** button | You are not in the **Datasets** category | Switch to the **Datasets** category first |
