# Create Datasets

Datasets are created as repositories, from either:

- Global list `/moha/datasets` -> New dataset (personal space, `/moha/my/datasets/create`).
- Organization list `/moha/organizations/:organization/datasets` -> New dataset (owned by the organization).

## Form fields

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `organization` | Select | Yes | Owner organization or personal space |
| `name` | Text | Yes | Repository identifier used in URLs and Git |
| `alias` | Text | Yes | Display name |
| `description` | Multiline | No | Purpose description |
| `visibility` | Radio | Yes | Defaults to `private`; forced to `internal` when created in an organization |
| `license` | Autocomplete | No | From `LICENSE_OPTIONS` |
| `tasks` | Task selector (multi) | No | Task metadata |
| `frameworks` | Autocomplete (multi, freeSolo) | No | From `LIBRARY_OPTIONS`, up to 5 tags shown |
| `members` | Member manager | No | Repository members with `admin` / `member` roles |

### Name validation

```text
^[a-zA-Z0-9][a-zA-Z0-9._-]*$
```

Must start with a letter or digit; the rest may contain letters, digits, `.`, `_`, `-`.

> ⚠️ Note: The name cannot be changed after creation.

### Visibility

| Scenario | `visibility` |
| --- | --- |
| Default | `private` |
| Created under an organization | Forced to `internal` |

## Upload after creation

Open the repository -> **File** tab.

### Web upload

Upload file/folder through upload sessions; one submit produces one commit.

### Git push

```bash
git lfs install
git clone https://moha.your-domain/moha/datasets/my-org/my-dataset.git
cd my-dataset
git lfs track "*.parquet" "*.csv" "*.jsonl"
cp /path/to/data/* .
git add . && git commit -m "Add training data" && git push origin main
```

### SDK

```bash
pip install moha-hub
moha download --repo-type datasets my-org/my-dataset
```

> 💡 Tip: Use Git LFS for large data files and prefer Parquet/JSONL; you can also use the HuggingFace-compatible endpoint `${origin}/moha/huggingface`.
