# Dataset Overview

The dataset hub is the **dataset list page**. It puts every dataset you can see on this platform in one place. Start here when you are looking for training data or want to see what data the team already has.

## Where to enter

Click **Datasets** in the top navigation.

## Finding a dataset: search, filter, sort

There is a search box at the top, a column of filters on the left, and a sort selector at the top right.

| I want to... | How |
| --- | --- |
| Find by name | Type the dataset name in the top search box and press Enter; you can also type `organization/dataset-name` to target one exactly |
| Narrow down by conditions | Click **Advanced search** next to the search box, tick language, data quality level, acquisition method and similar conditions, then click **Apply filters** |
| Browse by task | Click **Task** on the left (for example Text Classification, Question answering) |
| Browse by industry | Click **Domain** on the left (for example Finance, Healthcare) |
| Browse by license | Click **License** on the left |
| Browse by publisher | Click **Organization** on the left |
| Change the order | Click **Sort: Comprehensive** at the top right and pick from the menu |

The sort menu has four options:

| Option | Meaning |
| --- | --- |
| Comprehensive | The platform's default recommendation order |
| Download Count | Most downloaded first |
| Like Count | Most liked first |
| User Rating | Highest rated first |

Filters you have chosen appear as chips above the list. Click the cross on a chip to remove that one filter, or click **Clear advanced filters** to remove them all.

## What is on a card

| On the card | Meaning |
| --- | --- |
| Name | The dataset name; the small icon at the top left is the organization that uploaded it |
| Description | One sentence about what this data is |
| Tags | Task category, industry, language and so on |
| Updated At | When it was last changed |
| Download Count | How many times it has been downloaded |
| Like | How many times it has been liked (favourited) |

## Favouriting a dataset

Click the favourite icon on a card and the dataset goes into your favourites. You can then find it quickly under **My Favorites** on the home page's left sidebar.
