# Dataset Overview

## Entry

Top navigation -> **Datasets**, route `/moha/datasets`.

## List capabilities

| Capability | Description |
| --- | --- |
| Keyword search | Search by name/keyword |
| Metadata filters | Filter by task, language, framework, tags and dataset size |
| Sorting | `''` (comprehensive), `downloads`, `likes`, `rating` |
| Visibility | Switch between `public` / `private` / `internal`; default `public` |
| Pagination | `size=16` by default |

> 💡 Tip: The list renders as a card grid; there is no table view.

## Dataset card

| Field | Description |
| --- | --- |
| Name | `organization/name` |
| Visibility | `public` / `internal` / `private` |
| Description | Purpose summary |
| Tags | Data type, domain, language |
| Downloads | Total downloads |
| Favourites | Star count |

## Favourites

Click star on a card or detail page to add the dataset to your favourites, then review it in [Liked by Me](/moha/home/liked-by-me).
