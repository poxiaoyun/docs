# Dataset card

The dataset repository detail page opens on the **Dataset Card** (`content`) tab by default. As with the model card, its body comes from the `README.md` at the repository root, and the right-hand column renders several blocks that depend on the repository metadata.

## Page structure

| Area | Block | Shown when |
| --- | --- | --- |
| Left (main) | README render area | Always |
| Right (info column) | Rating and download stats | Dataset resources |
| Right (info column) | Recommendation | A `RECOMMEND_COMMENT` annotation exists |
| Right (info column) | Training relations / Used by Spaces | Model or dataset resources |

Datasets never show the genealogy (model family tree) or hardware requirements blocks; those render for model resources only.

## README render area

Create a `README.md` at the dataset repository root to serve as the dataset card. Before rendering, relative image, video and attachment links are rewritten to repository endpoint URLs, so the README can reference files inside the repository directly.

Relative links in the README are resolved against the currently viewed branch (reference), so switching branches changes the referenced content.

## Rating and download stats

| Field | Source annotation key | Description |
| --- | --- | --- |
| User rating | `RECOMMEND_RATE_COUNT` | Average score; read-only once rated, otherwise you can rate |
| Downloads | `RECOMMEND_DOWNLOAD_COUNT` | Formatted with `fNumber` |

## Recommendation

When a `RECOMMEND_COMMENT` annotation exists in the metadata, a "Recommendation" card appears on the right showing the recommendation score (`RECOMMEND_SCORE`) and comment.

## Training relations and Used by Spaces

Datasets and models both show this block, which consists of two parts:

| Component | Description |
| --- | --- |
| Training relations | From a dataset, shows the models trained on it |
| Used by Spaces | Shows the Spaces that reference this dataset |

Clicking the block opens a right drawer with `datasets` / `models` / `spaces` tabs listing the full set.

## Authoring tips

A good README usually covers:

```markdown
# Dataset name

## Overview
Briefly describe the purpose and source of the dataset.

## Contents
- Size: 100k rows
- Format: JSONL
- Language: Chinese

## Fields
| Field | Type | Description |
|-------|------|-------------|
| text | string | Raw text |
| label | int | Class label |

## Usage
Explain how to load and use the dataset.

## License
License information for the data.
```

> 💡 Tip: A complete dataset card significantly improves discoverability and usage. The right-hand blocks and filters also depend on repository metadata, so fill it in as completely as possible.
