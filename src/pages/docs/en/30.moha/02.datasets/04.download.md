# Download Datasets

This page either brings a Moha dataset onto your machine or reads it straight from your code. There are three ways, so **pick one by purpose**:

| Way | Best for | What you need installed |
| --- | --- | --- |
| Web page | Grabbing one or two small files | Nothing |
| Git command line | A whole dataset, a tens-of-GB dataset | Git and Git LFS |
| SDK commands | Scripting a batch download, or loading directly in Python | Python and moha-hub |

## Before you start

- Downloading a **public** dataset needs no sign-in. Downloading a **private** or tenant-only dataset needs an **access token**, see [Access Tokens](/moha/quickstart/token).
- Before using the command line, install Git and Git LFS on your machine.
- Before using the SDK, run `pip install moha-hub` and sign in once.

## Way 1: Download from the web page

1. Open the dataset repository detail page and click the **File** tab.
2. Find the file in the list and click the download icon at the end of its row (hovering shows **Download file**).

This suits a few loose small files. A whole large dataset is easy to interrupt in a browser, so use the Git way instead.

## Way 2: Download with the Git command line

You do not have to build the commands yourself — just copy them from the page.

1. Open the dataset repository detail page and click **Download Datasets** at the top right.
2. In the dialog, choose the **Git** tab and copy these commands in order:

| Command | What it does |
| --- | --- |
| `git lfs install` | Turns Git LFS on for your machine; you only run this once |
| `git clone <repository-url>` | Clones the whole dataset; Git LFS downloads the large files for you |
| `GIT_LFS_SKIP_SMUDGE=1 git clone <repository-url>` | Downloads only file names and pointers, not the large files (useful to inspect the layout first) |

The repository URL looks like `https://<platform-host>/moha/<organization>/<resource-type>/<repository>.git`, for example `https://<platform-host>/moha/ai-lab/datasets/chinese-qa.git`.

When you download a private dataset, Git asks for a username and password. **Use your access token as the password.**

## Way 3: Download with SDK commands

Install and sign in first:

```bash
pip install moha-hub
moha login https://<platform-host> --token <access-token>
```

Then download the whole dataset:

```bash
moha download --repo-type datasets ai-lab/chinese-qa
```

You can also choose the output directory, or download only a few files:

```bash
moha download ai-lab/chinese-qa --local-dir ./data
moha download ai-lab/chinese-qa train.parquet test.parquet
```

To download from Python:

```python
from xiaoshiai_hub import snapshot_download

# Download the whole dataset and return the local directory path
repo_path = snapshot_download(
    repo_id="ai-lab/chinese-qa",
    repo_type="datasets",
    token="<access-token>",

    # Optional: download only the formats you need and skip archives
    allow_patterns=["*.parquet", "*.jsonl"],
    ignore_patterns=[".git*"],
)
print(repo_path)
```

## Download only some of the large files

Clone first while skipping the LFS files, then pull what you need:

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone <repository-url>
cd chinese-qa
git lfs pull --include="train/*.parquet"
```

## Load directly without downloading

If you only want to read the data in code, configure Moha's HuggingFace-compatible endpoint and load it with `datasets`.

1. On the dataset detail page, click **Use this dataset** at the top right to copy a ready-made example.
2. Install the library and set the endpoint and token:

```bash
pip install datasets

export HF_ENDPOINT=https://<platform-host>/moha/huggingface
export HF_TOKEN=<access-token>
```

3. Load it just like a HuggingFace dataset:

```python
from datasets import load_dataset

dataset = load_dataset("ai-lab/chinese-qa")
print(dataset)
```

## Download a specific version

Datasets separate versions with **branches** and **snapshots**. Clone first, then switch to the branch you want:

```bash
git checkout v1.0
```

With the SDK, add `--revision`:

```bash
moha download ai-lab/chinese-qa --revision v1.0
```

## Common problems

| What you see | Likely cause | What to do |
| --- | --- | --- |
| Cloned data files are only a few KB | Git LFS is missing, so you only got the pointer files | Install Git LFS, run `git lfs install`, and clone again |
| "No permission" | You are downloading a private or tenant-only dataset | Configure an access token and retry |
| `load_dataset` cannot find the dataset | The endpoint or token is not configured | Check the `HF_ENDPOINT` and `HF_TOKEN` environment variables |
