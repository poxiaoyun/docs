# Download Datasets

## Web download

Open the dataset detail page -> **File** tab, then click the download button next to a file.

## Git clone

```bash
git lfs install
git clone https://moha.your-domain/moha/datasets/ai-lab/my-dataset.git
```

## SDK download

```bash
pip install moha-hub
moha download --repo-type datasets ai-lab/my-dataset
```

## Selective download

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone https://moha.your-domain/moha/datasets/ai-lab/my-dataset.git
git lfs pull --include="train/*.parquet"
```

## Load directly

Configure the HuggingFace-compatible endpoint to load with the `datasets` library:

```bash
export HF_ENDPOINT=https://moha.your-domain/moha/huggingface
export HF_TOKEN=<access-token>
```

```python
from datasets import load_dataset

dataset = load_dataset("ai-lab/my-dataset")
print(dataset)
```

## Authentication

Private datasets require a token, see [Access Tokens](/moha/quickstart/token).
