# Upload Models

Once a model repository exists, files are managed on the **File** tab. It offers a web upload entry plus a download/upload dialog with **Git** and **SDK** tabs.

## Three ways to upload or fetch

| Method | Entry | Use case |
| --- | --- | --- |
| Web upload | File tab -> Upload file | A few files, quick single-file commit |
| Git push | File tab -> download/upload dialog -> Git | Large or bulk files, keep Git history |
| SDK | File tab -> download/upload dialog -> SDK | Scripted upload/download (`moha-hub`) |

## Web upload

1. Open the repository detail page and switch to **File**.
2. Click **Upload file** and pick files or a whole folder.
3. The upload runs as an upload session and produces one commit.

The server advertises capabilities (`uploadFiles`, `uploadFolder`, `createFile`, `createDirectory`, `editFile`, `deleteFile`); writes are only allowed when `canWrite` is true.

> ⚠️ Note: The front end enforces its own hard caps — at most 100 files and 100 MiB in total per upload (`BROWSER_UPLOAD_MAX_FILES = 100`, `BROWSER_UPLOAD_MAX_TOTAL_BYTES = 100 * 1024 * 1024`). On top of that, the server may advertise stricter values through `limits` (`maxFiles`, `maxTotalBytes`, `maxManifestBytes`, `maxPathBytes`, `maxEditableBytes`); the smaller of the two applies. The earlier "5 GB per file" claim has no basis in the front-end code and is treated as unconfirmed.

## Git push

```bash
git lfs install
git clone https://moha.your-domain/moha/models/ai-lab/my-model.git
cd my-model
git lfs track "*.safetensors" "*.bin" "*.pt"
cp /path/to/model/* .
git add . && git commit -m "Add model weights" && git push origin main
```

## SDK

```bash
pip install moha-hub
moha download --repo-type models ai-lab/my-model
```

```python
from xiaoshiai_hub import snapshot_download

repo_path = snapshot_download(
    repo_id="ai-lab/my-model",
    repo_type="models",
    username="your-username",
    password="your-password",
)
```

## Use the model

The **How to use** dialog provides examples per target:

| Target | Description |
| --- | --- |
| Transformers | `pipeline` and `AutoModelForCausalLM` snippets |
| vLLM | `pip install vllm` + `vllm serve`, plus an OpenAI-compatible call |
| SGLang | `pip install "sglang[all]"` + `python -m sglang.launch_server` |

All examples use the HuggingFace-compatible endpoint:

```bash
export HF_ENDPOINT=https://moha.your-domain/moha/huggingface
export HF_TOKEN=<access-token>
```

> 💡 Tip: Prefer `.safetensors` for weights and Git LFS for large files.
