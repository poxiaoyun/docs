# Upload Models

This page moves model files from your machine into a Moha model repository. There are three ways, so **pick one by file size**:

| Way | Best for | Limit |
| --- | --- | --- |
| Web upload | A few small files, adding one config file | At most 100 files and 100 MiB in total per upload |
| Git command line | Large models, bulk files, keeping a record of every change | Large files must go through Git LFS |
| SDK commands | Scripted uploads, or many/large files | No practical file-count limit |

## Before you start

- You need to be an **admin** or **read-write** member of the repository, otherwise there is no upload entry on the **File** page.
- Do not commit files larger than 5 MB with plain Git, or the push is rejected. Use Git LFS or the SDK.
- Before using the command line, install Git and Git LFS on your machine.
- Before using the SDK, run `pip install "moha-hub[upload]"` and sign in once.

![The Add file dropdown: Upload file, New folder and New file](/assets/screenshots/moha/repo-model-upload-01.png)

Browser upload goes through **Add file → Upload file**. The address in the commit message above is blurred: it comes from the upstream model's original metadata, not from your account.

## Way 1: Upload from the web page

1. Open the model repository detail page and click the **File** tab.
2. Click **Add files** at the top right and choose from the menu:
   - **Upload files**: select one or more files.
   - **Upload folder**: select a whole directory; the directory structure is kept.
   - **Create file** / **Create folder**: make a small file or an empty directory directly on the page.
3. In the upload window, check the file list, fill in the **Commit Message** (for example `Add model weights`), and submit.
4. When it finishes you see **Committed successfully** together with this commit's ID.

:::warning Web upload size limits

- At most 100 files and 100 MiB in total per upload.
- If you go over, the page tells you to use the Moha SDK. Switch to the SDK way below.

:::

## Way 2: Upload with the Git command line

Good for larger models. Clone the repository locally first, then commit and push.

1. Open the model repository detail page and click **Download Models** at the top right.
2. In the dialog choose the **Git** tab, copy the **Clone Repository** command and run it in your terminal:

```bash
git lfs install
git clone <repository-url>
cd <repository-name>
```

3. Put the model files in this directory and tell Git LFS which large files it should handle:

```bash
# Let LFS take over the usual model weight files
git lfs track "*.safetensors" "*.bin" "*.pt"

# Copy your local model files in
cp /path/to/model/* .

git add .
git commit -m "Add model weights"
git push origin main
```

After a successful push, refresh the page and the files appear in the **File** list.

:::tip Why large files must go through LFS
Plain Git refuses to push new files larger than 5 MB and asks you to use Git LFS or the Moha SDK.
`git lfs track` only "registers" which files go through LFS, so run it before `git add`; the registration is stored in the repository's `.gitattributes`.
:::

## Way 3: Upload with SDK commands

Good for scripted uploads; there is no file-count limit like the web page.

```bash
pip install "moha-hub[upload]"
moha login https://<platform-host> --token <access-token>
```

Upload a whole folder, or just one file:

```bash
# Upload a folder (the directory structure is kept)
moha upload ai-lab/my-model ./my_model

# Upload a single file and give it a path inside the repository
moha upload ai-lab/my-model ./config.yaml configs/config.yaml
```

You can also add a commit message, a target branch and ignore rules:

```bash
moha upload ai-lab/my-model ./my_model \
  --message "Add model weights" \
  --revision main \
  --exclude "*.log"
```

To upload from Python:

```python
from xiaoshiai_hub import upload_folder, upload_file

# Upload a whole folder
upload_folder(
    folder_path="./my_model",
    repo_id="ai-lab/my-model",
    repo_type="models",
    commit_message="Add model weights",
    ignore_patterns=["*.log", ".git*"],
    token="<access-token>",
)

# Upload a single file
upload_file(
    path_file="./config.yaml",
    path_in_repo="config.yaml",
    repo_id="ai-lab/my-model",
    repo_type="models",
    commit_message="Add a config file",
    token="<access-token>",
)
```

## How to use the model after uploading

Go back to the model detail page and click **Use this model** at the top right, then pick an example:

| Purpose | Description |
| --- | --- |
| Transformers | Load the model with `pipeline` or `from_pretrained` |
| vLLM | Start an OpenAI-compatible inference server |
| SGLang | Start the model server with SGLang |

All of these reach the model through Moha's HuggingFace-compatible endpoint, so set the environment variables first:

```bash
export HF_ENDPOINT=https://<platform-host>/moha/huggingface
export HF_TOKEN=<access-token>
```

Then load it as shown:

```python
from transformers import AutoModelForCausalLM, AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("ai-lab/my-model")
model = AutoModelForCausalLM.from_pretrained(
    "ai-lab/my-model",
    torch_dtype="auto",
    device_map="auto",
)
```

## Common problems

| What you see | Likely cause | What to do |
| --- | --- | --- |
| File count exceeds 100 | The web page has a file-count limit | Use the SDK to upload |
| Total file size exceeds 100 MB | The web page has a size limit | Use the SDK to upload |
| The push is rejected for exceeding a size limit | Large files did not go through Git LFS | Run `git lfs track` first and commit again |
| There is no **Add files** button | You have no write access to the repository | Ask a repository admin for **read-write** access |
| Uploaded model files are only a few KB | Large files were treated as pointers | Confirm Git LFS is installed and enabled, then upload again |
