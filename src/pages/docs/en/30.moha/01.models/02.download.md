# Download Models

The File tab provides a download/upload dialog with Git and SDK commands.

## Web download

1. Open the model detail page -> **File** tab.
2. Browse the file tree.
3. Click the download button on a file.

> 💡 Tip: Web download suits single or small files; use Git for large models.

## Git clone

The repository URL is `<console-host>/moha/<type>/<organization>/<repository>.git`:

```bash
git lfs install
git clone https://moha.your-domain/moha/models/ai-lab/qwen2-7b.git
```

Skip LFS objects:

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone https://moha.your-domain/moha/models/ai-lab/qwen2-7b.git
```

## SDK download

```bash
pip install moha-hub
moha download --repo-type models ai-lab/qwen2-7b
```

```python
from xiaoshiai_hub import snapshot_download

repo_path = snapshot_download(
    repo_id="ai-lab/qwen2-7b",
    repo_type="models",
    username="your-username",
    password="<access-token>",
)
```

## Download a specific version

```bash
git checkout v1.0
```

## Authentication

Private models require a token, see [Access Tokens](/moha/quickstart/token):

```bash
git clone https://<username>:<token>@moha.your-domain/moha/models/ai-lab/my-private-model.git
```

> ⚠️ Note: Keep your token secret; never commit it to public code or docs.

## Selective LFS download

```bash
git lfs pull --include="*.safetensors"
```
