# Download Models

This page gets a model from Moha onto your own machine. There are three ways, so **pick one by file size and purpose**:

| Way | Best for | What you need installed |
| --- | --- | --- |
| Web page | Grabbing one or two small files (a config, a README) | Nothing |
| Git command line | A whole repository, a tens-of-GB model, keeping version history | Git and Git LFS |
| SDK commands | Scripting a batch download, or loading directly in Python | Python and moha-hub |

## Before you start

- Downloading a **public** model needs no sign-in. Downloading a **private** or tenant-only model needs an **access token**, see [Access Tokens](/moha/quickstart/token).
- Before using the command line, install Git and Git LFS on your machine.
- Before using the SDK, run `pip install moha-hub` and sign in once.

![Model detail page: Download model / Deploy / Use model at the top right, the card body on the left, and rating, downloads and the model lineage on the right](/assets/screenshots/moha/repo-model-content-01.png)

A browser download is just the **Download model** button. If you only need a few files, going to the **Files** tab and grabbing them individually is far faster — see "download only some of the large files" below.

## Way 1: Download from the web page

Good for small files. Large models are easy to interrupt in a browser, so use the Git way below instead.

1. Open the model repository detail page and click the **File** tab.
2. Find the file in the list and click the download icon at the end of its row (hovering shows **Download file**).
3. The browser saves the file to your default download folder.

## Way 2: Download with the Git command line

Good for downloading a whole model. You do not have to build the commands yourself — just copy them from the page.

1. Open the model repository detail page and click **Download Models** at the top right.
2. In the dialog, choose the **Git** tab and copy these commands in order:

| Command | What it does |
| --- | --- |
| `git lfs install` | Turns Git LFS on for your machine; you only run this once |
| `git clone <repository-url>` | Clones the whole model repository; Git LFS downloads the large files for you |
| `GIT_LFS_SKIP_SMUDGE=1 git clone <repository-url>` | Downloads only file names and pointers, not the large files (useful to inspect the layout first) |

The repository URL looks like `https://<platform-host>/moha/<organization>/<resource-type>/<repository>.git`, for example `https://<platform-host>/moha/ai-lab/models/qwen2-7b.git`.

:::tip Why Git LFS is required
Plain Git is bad at moving multi-GB files; it makes the repository slow and bloated. Git LFS is a Git extension built exactly for this job.
Without it, the model file you clone may be a tiny "pointer" rather than the real weights.
:::

When you download a private model, Git asks for a username and password. **Use your access token as the password.** You can also put the token straight into the URL:

```bash
git clone https://<username>:<access-token>@<platform-host>/moha/<organization>/models/<repository>.git
```

## Way 3: Download with SDK commands

Good for batches or scripts. Install and sign in first:

```bash
pip install moha-hub
moha login https://<platform-host> --token <access-token>
```

Then download the whole repository:

```bash
moha download --repo-type models ai-lab/qwen2-7b
```

You can also choose the output directory, or download only a few files:

```bash
moha download ai-lab/qwen2-7b --local-dir ./my-model
moha download ai-lab/qwen2-7b config.json tokenizer.json
```

To download from Python:

```python
from xiaoshiai_hub import snapshot_download

# Download the whole repository and return the local directory path
repo_path = snapshot_download(
    repo_id="ai-lab/qwen2-7b",
    repo_type="models",
    token="<access-token>",

    # Optional: download only matching files and skip logs and similar
    allow_patterns=["*.safetensors", "*.json"],
    ignore_patterns=[".git*", "*.log"],
)
print(repo_path)
```

## Download a specific version

Model repositories separate versions with **branches** and **snapshots**.

- Web page and command line: clone the repository as above, then switch to the branch you want:

```bash
git checkout v1.0
```

- SDK: add `--revision` with a branch, tag or commit:

```bash
moha download ai-lab/qwen2-7b --revision v1.0
```

## Download only some of the large files

Clone first while skipping the LFS files, then pull only the kinds you need. This saves a lot of time and bandwidth:

```bash
GIT_LFS_SKIP_SMUDGE=1 git clone <repository-url>
cd qwen2-7b
git lfs pull --include="*.safetensors"
```

## Common problems

| What you see | Likely cause | What to do |
| --- | --- | --- |
| Cloned model files are only a few KB | Git LFS is missing, so you only got the pointer files | Install Git LFS, run `git lfs install`, and clone again |
| "No permission" | You are downloading a private or tenant-only model | Configure an access token and retry |
| The clone fails halfway | The network dropped | Go into the cloned directory and run `git lfs pull` to continue |
