# Model Versions

Versioning is built on Git branches and commits. It lives on the **File** and **Freezes** tabs; there is no dedicated "Version" tab.

## Actual repository tabs

For models and datasets (not images):

| Tab | `value` | Description |
| --- | --- | --- |
| Model/Dataset Card | `content` | README, rating, recommendation, genealogy, related content, hardware |
| File | `file` | File tree, preview, commits, branch switching |
| Freezes | `freezes` | Freeze list (create / diff / rollback / delete) |
| Discussion | `discussion` | Discussions and replies |
| Setting | `setting` | Only for system admin, owner, org admin, or repo admin/readwrite |

Image repositories use `content`, `tags`, `setting` (no file/freeze tabs).

> ⚠️ Note: The earlier "switch to the Version tab / version dropdown" description did not match the implementation and has been rewritten.

## View and switch versions

1. Open the repository and switch to the **File** tab.
2. Click the **branch** selector at the top.
3. Branches are listed under the `branch` group; if freezes exist, a `freeze` group is added.

Selecting a branch sets `reference` to the branch name; selecting a freeze sets `reference` to its commit.

> 💡 Tip: Internal freeze branches (`freezes/*`) are hidden from the `branch` group.

## Create a new version

```bash
cd my-model
git checkout -b feature/new-version
git add . && git commit -m "Update weights" && git push origin feature/new-version
```

For an immutable snapshot of a stable build, use **version freezes** (see [Version Freezes](/moha/repository/freezes)); freezes lock a branch/commit and support diff and rollback.

> 💡 Tip: Prefer semantic version names such as `v1.0.0` for branches or freeze titles.
