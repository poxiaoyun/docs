# Model Hub Overview

The model hub is the model list page and shows all visible model resources.

## Entry

Top navigation -> **Models**, route `/moha/models`.

## List capabilities

| Capability | Description |
| --- | --- |
| Keyword search | Search by name/keyword |
| Metadata filters | Filter by task, framework, license and language; selections appear as removable chips |
| Sorting | `''` (comprehensive), `downloads`, `likes`, `rating` |
| Visibility | Switch between `public` / `private` / `internal`; default `public` |
| Pagination | `size=16` by default |

> 💡 Tip: The list renders as a card grid (1 column on small screens, 2 on medium). There is no table view.

## Model card

| Field | Description |
| --- | --- |
| Name | `organization/name`, e.g. `ai-lab/qwen2-7b` |
| Visibility | `public` / `internal` / `private` |
| Description | Short summary |
| Tags | Task, framework, language metadata |
| Downloads | Total download count |
| Favourites | Number of stars |

## Favourites

Click star on a card or detail page to add the model to your favourites, then review it in [Liked by Me](/moha/home/liked-by-me).
