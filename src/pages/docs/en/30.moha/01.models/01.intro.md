# Models Overview

The model hub is the **model list page**. It puts every model you can see on this platform in one place. Start here when you are looking for a specific model or just want to see what others have uploaded.

## Where to enter

Click **Models** in the top navigation.

![Models library: filter by category / framework / licence / tag / organization on the left, with category, framework, size and owner on each card](/assets/screenshots/moha/models-list-01.png)

Filters stack. The **Category** tab is expanded on the left, so the multimodal and natural-language sub-tags are laid out in full. **Sort** at the top right switches between recommended and newest.

## Finding a model: search, filter, sort

There is a search box at the top, a column of filters on the left, and a sort selector at the top right.

| I want to... | How |
| --- | --- |
| Find by name | Type the model name in the top search box and press Enter; you can also type `organization/model-name` to target one exactly |
| Narrow down by conditions | Click **Advanced search** next to the search box, tick task, framework, license and similar conditions, then click **Apply filters** |
| Browse by task | Click **Task** on the left (for example Text Generation, Image Classification) |
| Browse by framework | Click **Library** on the left (for example PyTorch, Transformers) |
| Browse by license | Click **License** on the left (for example apache-2.0) |
| Browse by tag | Click **Tags** on the left (custom tags) |
| Browse by publisher | Click **Organization** on the left |
| Change the order | Click **Sort: Comprehensive** at the top right and pick from the menu |

The sort menu has four options:

| Option | Meaning |
| --- | --- |
| Comprehensive | The platform's default recommendation order |
| Download Count | Most downloaded first |
| Like Count | Most liked first |
| User Rating | Highest rated first |

Filters you have chosen appear as chips above the list. Click the cross on a chip to remove that one filter, or click **Clear advanced filters** to remove them all.

:::info
Search results are shown as cards, 16 per page. Scroll to the bottom of the list to load more.
:::

## What is on a card

Each model is one card. Hover over it to see more:

| On the card | Meaning |
| --- | --- |
| Name | The model name; the small icon at the top left is the organization that uploaded it |
| Description | One sentence about what the model does |
| Tags | Task category, framework, language and so on |
| Updated At | When it was last changed |
| Download Count | How many times it has been downloaded |
| Like | How many times it has been liked (favourited) |

## Favouriting a model

Click the favourite icon at the bottom right of a card and the model goes into your favourites. You can then find it quickly under **My Favorites** on the home page's left sidebar.
