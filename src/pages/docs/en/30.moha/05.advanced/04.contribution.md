# Community Contribution

Contribution in Moha means collaborating inside repositories. There is no points/badges/forum feature in the frontend.

## Share resources

- Create `public` models, datasets, images or Spaces.
- Maintain the root README; it becomes the model/dataset card body.
- Fill in metadata (license, task, framework, tags) so resources are discoverable and recommendable.

## Collaboration

| Method | Description |
| --- | --- |
| Members | Add repository members with `admin` / `readwrite` roles; org admins and the owner can manage too |
| Discussions | Open, reply to and close topics on the `discussion` tab |
| Pull requests | Branch-based changes with diff, commits and merge in discussions |
| Commits and revert | Reset / revert through the commit history on the File tab |
| Version freezes | Freeze stable versions for others to reference and roll back |

## Community signals

| Capability | Description |
| --- | --- |
| Favourite (star) | Starred resources appear in [Liked by Me](/moha/home/liked-by-me) |
| Rating | Model/dataset cards support scoring; the average is shown |
| Recommendation | Operators can set `RECOMMEND_SCORE` and a recommendation comment; these feed the Space featured section |
| Downloads | Automatically counted and used for sorting and cards |

## Permissions

| Action | Requirement |
| --- | --- |
| Browse public | Everyone |
| Browse internal | Same-organization members |
| Browse private | Repository members |
| Change settings / delete | System admin, owner, org admin, or repo admin/readwrite |
| Open discussions / PRs | Signed-in users |

> 💡 Tip: Keep review context in discussions/PRs for traceability, and freeze stable outputs.
