# Space List & Filters

The Space list (`/moha/spaces`) adds a **featured section** and `domain` / `scene` filtering on top of the shared list framework.

## Page structure

| Block | Description |
| --- | --- |
| Toolbar | Keyword search, total count, refresh, sorting |
| Featured section | Recommended Spaces selected by recommendation score |
| All | The paginated Space card list under the current filters |

## Search and total

The toolbar searches by name/keyword and shows the total for the current filters, plus a refresh button.

## Featured section

1. Requests the recommendation list with `sort=recommendation` and a candidate limit of 100.
2. Keeps only resources with `RECOMMEND_SCORE > 0`.
3. Sorts by `RECOMMEND_SCORE` descending and shows at most 8.

Only Spaces with a recommendation score appear here, and the search applies to the featured section too.

## Sorting

| Value | Meaning |
| --- | --- |
| `''` | Comprehensive (default) |
| `downloads` | By downloads |
| `likes` | By likes |

## Visibility

- `public`: the platform-wide resource list.
- `private` / `internal`: the "my resources" API scoped to the current organization.

## Category filters

The filter panel has `domain` and `scene` groups:

- Both are multi-select; a selection is written into the query `selector` and resets to page 1.
- The `scene` panel shows at most 4 options by default and can expand.
- A group is only rendered when its option list is non-empty.

## Pagination

The list uses `size=12` per page with pagination / continue loading (`continue`).

## Use cases

- Find demos or app templates to try.
- Filter organization-shared interactive apps by domain/scene.
- Open a Space repository to view files, discussions and deployment configuration.
