# Image List & Filters

The image list reuses the shared Moha list framework.

## List capabilities

| Capability | Description |
| --- | --- |
| Visibility | Switch between `public` / `private` / `internal`; default `public` |
| Search | Locate images by name or keyword |
| Sorting | `''` (comprehensive), `downloads`, `likes` (no `rating` for images) |
| Pagination | `size=16` by default |
| Cards | View basic info and open the detail page |

## Image detail tabs

Image repositories use `content`, `tags`, `setting`:

- `content`: image card / README.
- `tags`: tags and security scans.
- `setting`: visibility, alias, members, image metadata, README and delete (no file/freeze tabs).

## Tags and security scan

| Capability | Description |
| --- | --- |
| Tag list | Tags in the image repository |
| Trivy scan | Start/stop a vulnerability scan for a tag, and view scan status |
| Severity | Counts for `critical` / `high` / `medium` / `low`, expandable to CVE details |

> ⚠️ Note: Fields come from the parsed Trivy report; the page only aggregates the four severity levels above.

## Recommendations

- Keep clear descriptions and tags for shared base images.
- Use private or internal visibility for team-only images.
- Maintain metadata, cover, README and members on the repository settings page.
