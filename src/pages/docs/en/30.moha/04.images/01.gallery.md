# Image List & Filters

The image list page is how you **find an environment**: filter by category, framework and architecture, open an image to see its versions and vulnerabilities, then copy the pull command to your own machine.

## Before you start

- Browsing **Public** images needs no sign-in.
- To see **Internal** or **Private** images you must be signed in and belong to the matching organization.

## Find the image you want

1. Click **Images** in the top navigation.
2. Type the image name or alias in the search box to locate it quickly.
3. Use the filter panel on the left to narrow things down, switching tabs as needed:
   - **Category**: the purpose, such as Network, Security or ML.
   - **Accelerates**: the acceleration framework, such as CUDA, CANN or ROCm.
   - **Architecture**: X86 or ARM.
4. To change the order, click the sort button at the top right and choose **Comprehensive**, **Download Count** or **Like Count**.
5. Click the card of the image you want to open its detail page.

:::info The list only shows Public images by default
The image list shows **Public** images by default. **Internal** and **Private** images of your organization are under [Organization](/moha/home/organizations) or [Created by Me](/moha/home/created-by-me).
:::

## What the image detail page has

After opening an image there are three tabs at the top:

| Tab | What it shows you | What you can do |
| --- | --- | --- |
| Image card | The image's description text | Learn what this environment contains and how to use it |
| Tags | All versions of this image and their vulnerability scan results | Copy the pull command, start a scan |
| Settings | Visibility, alias, members, metadata, description, delete | Only maintainers can see and change it |

## View versions and pull locally

1. On the detail page, click the **Tags** tab.
2. Each version is a card showing the tag name and an architecture table (Digest, Architecture, Image Scan, Size).
3. The card's top right has a `docker pull ...` command and a copy button; click to copy.
4. Paste the command into your terminal to pull the image locally.

To pull a private image, sign in to the registry first:

1. Click **Download image** at the top right of the detail page.
2. The first command in the dialog is **Login to Registry**, containing your username and token; copy it and run it once on the command line.
3. The other two are **Tag Image** and **Push Image**, used only when you upload your own image.

:::warning The login command contains your token
The `docker login` command includes your access token. Be careful not to expose it on a shared screen when copying or running it, and do not paste it anywhere public.
:::

## Check an image for vulnerabilities

1. On a version card in the **Tags** tab, click **Image Scan**.
2. While the scan runs the button becomes **Stop Scan**; click it to interrupt.
3. When the scan finishes, the card shows counts in four severities: **Critical**, **High**, **Medium** and **Low**.
4. Click one of those counts to open the **CVE Report**, where you can go through each vulnerability's ID, package, severity and fixed version.
5. The refresh icon at the top right of the card reloads the latest scan results.

## Confirm the result

- Clicking a card opens the image detail page, and the tabs switch correctly between **Image card**, **Tags** and **Settings**.
- On the **Tags** tab you see at least one version card and its `docker pull` command.
- After a scan finishes, the card shows vulnerability counts, or says that no vulnerabilities were found.
